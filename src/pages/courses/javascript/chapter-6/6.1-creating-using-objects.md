# Chapter 6: Objects and Modern JavaScript

## Section 1: Creating and Using Objects

An **object** stores related data as **key-value pairs**. Instead of keeping a name, an age and a city in three separate variables, you can group them into one object that represents a person, a product or a student.

---

## 1. What Is an Object?

An object is written inside curly braces `{ }`. Each entry has a **key** (also called a property name) and a **value**, separated by a colon.

```javascript
const person = {
  name: "Asha",
  age: 20,
  isStudent: true
};

console.log(person);
console.log(typeof person);
```

```output
{ name: 'Asha', age: 20, isStudent: true }
object
```

* Entries are separated by commas.
* Values can be any type: strings, numbers, booleans, arrays, functions or other objects.
* Keys are strings (or symbols), even when you write them without quotes.

---

## 2. Creating Objects

The **object literal** `{ }` is the most common and recommended way to create an object.

```javascript
const empty = {};

const book = {
  title: "JavaScript Basics",
  pages: 250
};

const created = new Object();
created.language = "JavaScript";

console.log(empty);
console.log(book);
console.log(created);
```

```output
{}
{ title: 'JavaScript Basics', pages: 250 }
{ language: 'JavaScript' }
```

`new Object()` works but is rarely used. Prefer the literal syntax.

---

## 3. Nested Objects and Arrays

A value can itself be an object or an array. This lets you describe real-world data.

```javascript
const student = {
  name: "Ravi",
  address: {
    city: "Chennai",
    pin: 600001
  },
  skills: ["HTML", "CSS", "JavaScript"]
};

console.log(student.address.city);
console.log(student.skills[1]);
console.log(student.skills.length);
```

```output
Chennai
CSS
3
```

Use a chain of dots and indexes to go deeper: `student.address.city`, `student.skills[1]`.

---

## 4. Accessing Properties

You can read a property with **dot notation** or **bracket notation**.

```javascript
const user = {
  name: "Asha",
  "favorite color": "blue"
};

console.log(user.name);
console.log(user["favorite color"]);

const key = "name";
console.log(user[key]);

console.log(user.age);
```

```output
Asha
blue
Asha
undefined
```

* Dot notation is shorter and cleaner: `user.name`.
* Bracket notation is required when the key has spaces or special characters, or when the key is stored in a variable.
* Reading a property that does not exist gives `undefined`.

---

## 5. Optional Chaining

Reading a property of `undefined` causes an error. The **optional chaining** operator `?.` stops safely and returns `undefined` instead.

```javascript
const user = { name: "Asha" };

console.log(user.address?.city);
console.log(user.address?.city ?? "No city saved");
```

```output
undefined
No city saved
```

Without `?.`, the expression `user.address.city` would throw a `TypeError` because `user.address` is `undefined`. The `??` operator provides a fallback value when the left side is `undefined` or `null`.

---

## 6. Adding, Changing and Deleting Properties

Objects are **mutable**, so you can change them after creation. Even an object declared with `const` can be modified.

```javascript
const car = { brand: "Toyota" };

car.year = 2024;
console.log(car);

car.brand = "Honda";
console.log(car);

delete car.year;
console.log(car);
```

```output
{ brand: 'Toyota', year: 2024 }
{ brand: 'Honda', year: 2024 }
{ brand: 'Honda' }
```

* Assigning to a new key **adds** the property.
* Assigning to an existing key **replaces** the value.
* `delete` removes a property completely.

---

## 7. Shorthand and Computed Properties

When a variable has the same name as the key, you can write the name once. Square brackets let you build a key from an expression.

```javascript
const name = "Asha";
const age = 20;

const person = { name, age };
console.log(person);

const field = "score";
const result = {
  [field]: 90,
  [`${field}Max`]: 100
};
console.log(result);
```

```output
{ name: 'Asha', age: 20 }
{ score: 90, scoreMax: 100 }
```

---

## 8. Checking Whether a Property Exists

```javascript
const person = { name: "Asha", age: 0 };

console.log("name" in person);
console.log(Object.hasOwn(person, "age"));
console.log("email" in person);
console.log(person.age !== undefined);
```

```output
true
true
false
true
```

* The `in` operator checks whether a key exists.
* `Object.hasOwn(object, key)` checks only the object's own properties.
* Do not use `if (person.age)` to test for existence, because a value such as `0` is falsy.

---

## 9. Looping Through an Object

Use `Object.keys()`, `Object.values()` and `Object.entries()` to get arrays that you can loop over.

```javascript
const marks = { math: 90, science: 85, english: 78 };

console.log(Object.keys(marks));
console.log(Object.values(marks));
console.log(Object.entries(marks));

for (const subject in marks) {
  console.log(`${subject}: ${marks[subject]}`);
}

const total = Object.values(marks).reduce((sum, m) => sum + m, 0);
console.log(total);
```

```output
[ 'math', 'science', 'english' ]
[ 90, 85, 78 ]
[ [ 'math', 90 ], [ 'science', 85 ], [ 'english', 78 ] ]
math: 90
science: 85
english: 78
253
```

* `Object.keys()` returns an array of keys.
* `Object.values()` returns an array of values.
* `Object.entries()` returns an array of `[key, value]` pairs.
* `for...in` loops over the keys of an object.

---

## 10. Objects Are Reference Types

Like arrays, objects are stored by **reference**. Assigning an object to another variable does not copy it.

```javascript
const a = { x: 1 };
const b = a;

b.x = 2;
console.log(a.x);
console.log(a === b);
console.log({} === {});
```

```output
2
true
false
```

* `a` and `b` point to the **same** object.
* Two separate objects are never equal with `===`, even if they look identical.

---

## 11. Copying Objects

Use the spread syntax or `Object.assign()` for a **shallow copy**. Use `structuredClone()` for a **deep copy**.

```javascript
const original = { x: 1 };
const copy = { ...original };

copy.x = 99;
console.log(original.x);
console.log(copy.x);

const nested = { n: { v: 1 } };
const shallow = { ...nested };

shallow.n.v = 5;
console.log(nested.n.v);

const deep = structuredClone(nested);
deep.n.v = 100;
console.log(nested.n.v);
```

```output
1
99
5
5
```

A shallow copy duplicates only the top level. Inner objects are still shared, which is why `nested.n.v` changed. A deep copy duplicates everything.

---

## 12. Objects and JSON

**JSON** is a text format for data. `JSON.stringify()` converts an object to a string, and `JSON.parse()` converts it back.

```javascript
const person = { name: "Asha", age: 20, isStudent: true };

const json = JSON.stringify(person);
console.log(json);

const back = JSON.parse(json);
console.log(back.name);
```

```output
{"name":"Asha","age":20,"isStudent":true}
Asha
```

You will use JSON heavily with the Fetch API in Chapter 9 and with `localStorage` in Chapter 8.

---

## 13. Preventing Changes with Object.freeze

`Object.freeze()` makes an object read-only.

```javascript
const settings = Object.freeze({ theme: "dark" });

settings.theme = "light";
settings.fontSize = 16;

console.log(settings);
console.log(Object.isFrozen(settings));
```

```output
{ theme: 'dark' }
true
```

In strict mode (and inside modules), these changes throw a `TypeError` instead of being ignored silently. `Object.freeze()` is shallow: nested objects can still be changed.

## Real-World Example 🌍

A student record with calculated results:

```javascript
const student = {
  name: "Asha",
  marks: { math: 90, science: 85, english: 78 }
};

const subjects = Object.keys(student.marks).length;
const total = Object.values(student.marks).reduce((sum, m) => sum + m, 0);
const average = (total / subjects).toFixed(1);

student.grade = average >= 80 ? "A" : "B";

console.log(`Student: ${student.name}`);
console.log(`Total: ${total}`);
console.log(`Average: ${average}`);
console.log(`Grade: ${student.grade}`);
```

```output
Student: Asha
Total: 253
Average: 84.3
Grade: A
```

## Common Mistakes

### Using Dot Notation with a Variable Key

```javascript
const key = "name";
const user = { name: "Asha" };

console.log(user.key);     // undefined, looks for a property called "key"
console.log(user[key]);    // "Asha", correct
```

### Reading from a Missing Nested Object

```javascript
const user = {};

console.log(user.address.city);      // TypeError
console.log(user.address?.city);     // undefined, safe
```

### Believing const Makes an Object Unchangeable

```javascript
const user = { name: "Asha" };
user.name = "Ravi";    // allowed
user = {};             // TypeError: Assignment to constant variable.
```

### Comparing Objects with ===

```javascript
const a = { id: 1 };
const b = { id: 1 };

console.log(a === b);                                      // false
console.log(JSON.stringify(a) === JSON.stringify(b));      // true for simple data
```

### Using = Instead of a Colon Inside an Object

```javascript
const wrong = { name = "Asha" };    // SyntaxError
const right = { name: "Asha" };
```

---

## Key Points

* An object stores data as key-value pairs inside `{ }`.
* Read properties with dot notation (`user.name`) or bracket notation (`user["name"]`).
* Use bracket notation for keys with spaces or keys stored in variables.
* Optional chaining `?.` safely reads deep properties without errors.
* Add, change and remove properties with assignment and `delete`.
* `Object.keys()`, `Object.values()` and `Object.entries()` turn an object into arrays.
* Objects are reference types: `const b = a` does not make a copy.
* Use `{ ...obj }` for a shallow copy and `structuredClone()` for a deep copy.
* `JSON.stringify()` and `JSON.parse()` convert between objects and text.
* A `const` object can be modified, but `Object.freeze()` makes it read-only.

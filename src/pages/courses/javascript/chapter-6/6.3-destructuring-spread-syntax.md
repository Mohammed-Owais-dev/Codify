# Chapter 6: Objects and Modern JavaScript

## Section 3: Destructuring and Spread Syntax

**Destructuring** unpacks values from arrays and objects into separate variables in one short line. The **spread** (`...`) syntax expands an array or object into individual items, and the **rest** syntax (`...`) collects items back together. Together they make modern JavaScript shorter and cleaner.

---

## 1. Array Destructuring

Instead of reading each index by hand, you can unpack an array by position.

```javascript
const colors = ["red", "green", "blue"];

const [first, second] = colors;

console.log(first, second);
```

```output
red green
```

```javascript
const colors = ["red", "green", "blue"];

const [, , last] = colors;

console.log(last);
```

```output
blue
```

* Variables are matched **by position**.
* Leave a gap with an extra comma to skip an element.

---

## 2. Defaults and Rest in Arrays

```javascript
const [x = 1, y = 2] = [5];
console.log(x, y);

const [head, ...tail] = [1, 2, 3, 4];
console.log(head, tail);
```

```output
5 2
1 [ 2, 3, 4 ]
```

* A **default value** is used when the position has no value (`undefined`).
* `...tail` collects all remaining elements into a new array. It must be the **last** item.

---

## 3. Swapping Variables

Destructuring can swap two values without a temporary variable.

```javascript
let m = 1;
let n = 2;

[m, n] = [n, m];

console.log(m, n);
```

```output
2 1
```

Start the line with a semicolon in your own code if the previous line does not end with one, to avoid parsing problems.

---

## 4. Object Destructuring

Object destructuring matches by **property name**, not by position.

```javascript
const person = { name: "Asha", age: 20, city: "Chennai" };

const { name, age } = person;

console.log(name, age);
```

```output
Asha 20
```

The order of the variables does not matter. Only the names must match the keys.

---

## 5. Renaming, Defaults and Rest in Objects

```javascript
const person = { name: "Asha", age: 20, city: "Chennai" };

const { name: userName } = person;
console.log(userName);

const { country = "India" } = person;
console.log(country);

const { name, ...others } = person;
console.log(name);
console.log(others);
```

```output
Asha
India
Asha
{ age: 20, city: 'Chennai' }
```

* `{ name: userName }` reads the `name` property and stores it in a variable called `userName`. The key is on the **left**, the new variable is on the **right**.
* `{ country = "India" }` sets a default when the property is missing.
* `...others` collects all remaining properties into a new object.

---

## 6. Nested Destructuring

```javascript
const student = {
  id: 1,
  address: { city: "Chennai", pin: 600001 },
  skills: ["HTML", "CSS"]
};

const { address: { city }, skills: [firstSkill] } = student;

console.log(city);
console.log(firstSkill);
```

```output
Chennai
HTML
```

Only `city` and `firstSkill` become variables. `address` and `skills` are just paths used to reach them.

---

## 7. Destructuring in Function Parameters

You can destructure right in the parameter list. This is very common in modern code.

```javascript
function show({ name, age = 18 }) {
  return `${name} (${age})`;
}

console.log(show({ name: "Asha" }));
console.log(show({ name: "Ravi", age: 22 }));
```

```output
Asha (18)
Ravi (22)
```

A function can also return an array, and the caller can unpack it:

```javascript
function minMax(numbers) {
  return [Math.min(...numbers), Math.max(...numbers)];
}

const [min, max] = minMax([4, 9, 2]);

console.log(min, max);
```

```output
2 9
```

---

## 8. Destructuring in Loops

```javascript
const marks = { math: 90, science: 85 };

for (const [subject, score] of Object.entries(marks)) {
  console.log(`${subject}: ${score}`);
}

const players = [
  { name: "Asha", score: 420 },
  { name: "Ravi", score: 560 }
];

for (const { name, score } of players) {
  console.log(`${name} scored ${score}`);
}
```

```output
math: 90
science: 85
Asha scored 420
Ravi scored 560
```

## 9. The Spread Operator with Arrays

The spread operator `...` expands an array into individual elements.

```javascript
const a = [1, 2];
const b = [3, 4];

console.log([...a, ...b]);
console.log([0, ...a, 99, ...b]);
console.log(Math.max(...[3, 9, 4]));
console.log([..."Hi!"]);

const copy = [...a];
copy.push(100);
console.log(a);
```

```output
[ 1, 2, 3, 4 ]
[ 0, 1, 2, 99, 3, 4 ]
9
[ 'H', 'i', '!' ]
[ 1, 2 ]
```

* Spread can combine arrays, insert items, copy arrays and pass array values as separate arguments.
* `Math.max(...numbers)` works because spread turns the array into separate arguments.

---

## 10. The Spread Operator with Objects

Spread can copy and merge objects. When keys repeat, the **later** value wins.

```javascript
const defaults = { theme: "light", size: "md" };
const user = { size: "lg" };

console.log({ ...defaults, ...user });

const state = { count: 1, name: "App" };
const next = { ...state, count: 2 };

console.log(next);
console.log(state);
```

```output
{ theme: 'light', size: 'lg' }
{ count: 2, name: 'App' }
{ count: 1, name: 'App' }
```

Creating a new object with `{ ...state, count: 2 }` updates a value **without changing** the original. This pattern is used widely in modern web applications.

---

## 11. Rest Parameters

Rest syntax in a function definition collects extra arguments into an array.

```javascript
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}

function describe(first, ...others) {
  return `${first} and ${others.length} more`;
}

console.log(sum(1, 2, 3, 4));
console.log(sum());
console.log(describe("Asha", "Ravi", "Meena"));
```

```output
10
0
Asha and 2 more
```

* A rest parameter is a real array, so you can use `map`, `filter` and `reduce` on it.
* It must be the **last** parameter.

---

## 12. Spread vs Rest

The symbol `...` is the same, but the job depends on where it is used.

| | Spread | Rest |
| - | ------ | ---- |
| Purpose | **Expands** items | **Collects** items |
| Where | In calls, arrays and objects | In parameters and destructuring |
| Example | `[...a, ...b]` | `function f(...args)` |

---

## 13. Shallow Copies Only

Spread copies only the first level. Nested objects are still shared.

```javascript
const original = { inner: { v: 1 } };
const copy = { ...original };

copy.inner.v = 2;

console.log(original.inner.v);
```

```output
2
```

Use `structuredClone(original)` when you need a fully independent copy.

---

## Real-World Example

Merging default settings with a user's choices:

```javascript
const defaultSettings = { theme: "light", fontSize: 16, notifications: true };
const userSettings = { theme: "dark", fontSize: 18 };

const settings = { ...defaultSettings, ...userSettings };
console.log(settings);

const { theme, fontSize, ...rest } = settings;

console.log(`Theme: ${theme}`);
console.log(`Font size: ${fontSize}`);
console.log(rest);
```

```output
{ theme: 'dark', fontSize: 18, notifications: true }
Theme: dark
Font size: 18
{ notifications: true }
```

## Common Mistakes

### Destructuring undefined or null

```javascript
const { name } = undefined;     // TypeError
const { name } = user || {};    // safe, falls back to an empty object
```

### Mixing Up the Rename Direction

```javascript
const person = { name: "Asha" };

const { name: userName } = person;    // creates userName, not name
const { userName: name } = person;    // wrong, looks for a key called userName
```

### Missing Parentheses in Object Assignment

```javascript
let a, b;
{ a, b } = { a: 1, b: 2 };      // SyntaxError, braces look like a block
({ a, b } = { a: 1, b: 2 });    // correct
```

### Spreading an Object into an Array

```javascript
const obj = { a: 1 };
const list = [...obj];            // TypeError: obj is not iterable
const entries = [...Object.entries(obj)];    // [ [ 'a', 1 ] ], correct
```

### Expecting Spread to Deep Copy

```javascript
const copy = { ...original };    // nested objects are still shared
const deep = structuredClone(original);    // fully independent
```

---

## Key Points

* Array destructuring matches by **position**; object destructuring matches by **name**.
* Use defaults (`{ age = 18 }`) for missing values.
* Rename while destructuring with `{ name: userName }`.
* `...rest` in destructuring or parameters collects the remaining items.
* Destructuring works in function parameters, loops and return values.
* The spread operator expands arrays and objects into separate items.
* In object spread, later properties overwrite earlier ones.
* `{ ...obj, key: value }` creates an updated copy without changing the original.
* Spread makes only a shallow copy; use `structuredClone()` for a deep copy.
* Spread **expands**; rest **collects**.

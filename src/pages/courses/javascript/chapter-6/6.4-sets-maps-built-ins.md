# Chapter 6: Objects and Modern JavaScript

## Section 4: Sets, Maps and Useful Built-ins

Besides arrays and objects, JavaScript provides two more collections: **Set** (a list of unique values) and **Map** (key-value pairs with any type of key). It also includes helpful built-in objects such as `Math`, `Number` and `Date`.

---

## 1. What Is a Set?

A **Set** stores **unique** values. If you add the same value twice, only one copy is kept. Values stay in the order they were added.

```javascript
const ids = new Set([1, 2, 2, 3, 3, 3]);

console.log(ids);
console.log(ids.size);
```

```output
Set(3) { 1, 2, 3 }
3
```

Use `size` (not `length`) to count the values in a Set.

---

## 2. Set Methods

```javascript
const ids = new Set([1, 2, 3]);

ids.add(4);
ids.add(2);
console.log(ids.has(4));
console.log(ids.has(10));

ids.delete(1);
console.log([...ids]);

ids.clear();
console.log(ids.size);
```

```output
true
false
[ 2, 3, 4 ]
0
```

| Method | Purpose |
| ------ | ------- |
| `add(value)` | Adds a value (ignored if it already exists) |
| `has(value)` | Checks whether a value exists |
| `delete(value)` | Removes a value |
| `clear()` | Removes everything |
| `size` | Number of values |

---

## 3. Removing Duplicates from an Array

The most popular use of a Set is removing duplicates.

```javascript
const tags = ["js", "css", "js", "html", "css"];

const unique = [...new Set(tags)];

console.log(unique);
```

```output
[ 'js', 'css', 'html' ]
```

Convert the array to a Set, then spread the Set back into a new array.

## 4. Looping Through a Set

```javascript
const letters = new Set(["a", "b", "c"]);

for (const letter of letters) {
  console.log(letter);
}

letters.forEach(value => console.log(value.toUpperCase()));
```

```output
a
b
c
A
B
C
```

---

## 5. Set Operations

Sets are ideal for comparing groups: union, intersection and difference.

```javascript
const A = new Set([1, 2, 3]);
const B = new Set([2, 3, 4]);

const union = new Set([...A, ...B]);
const intersection = [...A].filter(x => B.has(x));
const difference = [...A].filter(x => !B.has(x));

console.log(union);
console.log(intersection);
console.log(difference);
```

```output
Set(4) { 1, 2, 3, 4 }
[ 2, 3 ]
[ 1 ]
```

* **Union:** everything from both sets.
* **Intersection:** values found in both sets.
* **Difference:** values in `A` that are not in `B`.

---

## 6. How a Set Compares Values

```javascript
console.log(new Set([NaN, NaN]).size);
console.log(new Set([{}, {}]).size);
console.log(new Set(["1", 1]).size);
```

```output
1
2
2
```

* `NaN` is treated as equal to `NaN`.
* Two different objects are always different, even if they look the same.
* The string `"1"` and the number `1` are different values.

---

## 7. What Is a Map?

A **Map** stores key-value pairs like an object, but its keys can be **any type**, and it remembers insertion order.

```javascript
const scores = new Map();

scores.set("Asha", 90);
scores.set("Ravi", 85);

console.log(scores);
console.log(scores.get("Asha"));
console.log(scores.has("Meena"));
console.log(scores.size);

scores.delete("Ravi");
console.log(scores.size);
```

```output
Map(2) { 'Asha' => 90, 'Ravi' => 85 }
90
false
2
1
```

| Method | Purpose |
| ------ | ------- |
| `set(key, value)` | Adds or updates an entry (returns the Map, so calls can be chained) |
| `get(key)` | Returns the value, or `undefined` |
| `has(key)` | Checks whether a key exists |
| `delete(key)` | Removes an entry |
| `clear()` | Removes everything |
| `size` | Number of entries |

---

## 8. Keys of Any Type

Object keys are always strings, but Map keys can be numbers, objects or anything else.

```javascript
const data = new Map();
const keyObject = { id: 1 };

data.set(keyObject, "object key");
data.set(42, "number key");

console.log(data.get(keyObject));
console.log(data.get(42));
console.log(data.get({ id: 1 }));
```

```output
object key
number key
undefined
```

The last line returns `undefined` because `{ id: 1 }` is a **different** object in memory.

---

## 9. Looping Through a Map

```javascript
const scores = new Map([
  ["Asha", 90],
  ["Ravi", 85]
]);

for (const [name, score] of scores) {
  console.log(`${name}: ${score}`);
}

console.log([...scores.keys()]);
console.log([...scores.values()]);

scores.forEach((value, key) => console.log(key, value));
```

```output
Asha: 90
Ravi: 85
[ 'Asha', 'Ravi' ]
[ 90, 85 ]
Asha 90
Ravi 85
```

* Looping a Map gives `[key, value]` pairs.
* In `forEach`, the **value comes first**, then the key.

## 10. Converting Between Maps, Objects and Arrays

```javascript
const map = new Map([["a", 1], ["b", 2]]);

console.log(map);
console.log(Object.fromEntries(map));
console.log(new Map(Object.entries({ x: 10, y: 20 })));
console.log([...map]);
```

```output
Map(2) { 'a' => 1, 'b' => 2 }
{ a: 1, b: 2 }
Map(2) { 'x' => 10, 'y' => 20 }
[ [ 'a', 1 ], [ 'b', 2 ] ]
```

## 11. Counting with a Map

A Map is a good tool for counting how many times each value appears.

```javascript
const words = "to be or not to be".split(" ");
const counts = new Map();

for (const word of words) {
  counts.set(word, (counts.get(word) || 0) + 1);
}

console.log(counts);
```

```output
Map(4) { 'to' => 2, 'be' => 2, 'or' => 1, 'not' => 1 }
```

---

## 12. Object vs Map

| | Object | Map |
| - | ------ | --- |
| Key types | Strings and symbols | **Any** type |
| Size | Count keys manually | `map.size` |
| Order | Mostly insertion order | Always insertion order |
| Best for | Fixed records (a user, a product) | Dynamic collections and lookups |

## 13. The Math Object

`Math` provides ready-made mathematical functions. You do not create it with `new`.

```javascript
console.log(Math.round(4.5));
console.log(Math.floor(4.9));
console.log(Math.ceil(4.1));
console.log(Math.trunc(-4.9));
console.log(Math.max(3, 9, 4));
console.log(Math.min(3, 9, 4));
console.log(Math.pow(2, 5), 2 ** 5);
console.log(Math.sqrt(49));
console.log(Math.abs(-8));
```

```output
5
4
5
-4
9
3
32 32
7
8
```

### Random Numbers

`Math.random()` returns a decimal from `0` up to (but not including) `1`. Scale it to make whole numbers in a range.

```javascript
function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

const roll = randomInt(1, 6);

console.log(roll >= 1 && roll <= 6);
```

```output
true
```

The value of `roll` changes every run, but it is always between 1 and 6.

## 14. Number Helpers

```javascript
console.log((3.14159).toFixed(2));
console.log(Number.isInteger(5));
console.log(parseFloat("3.5kg"));
console.log(Number("abc"));
console.log(Number.isNaN(NaN));
console.log(0.1 + 0.2);
console.log((0.1 + 0.2).toFixed(2));
console.log((1234567.891).toLocaleString("en-IN"));
console.log((1234567.891).toLocaleString("en-US"));
```

```output
3.14
true
3.5
NaN
true
0.30000000000000004
0.30
12,34,567.891
1,234,567.891
```

* `toFixed(n)` rounds to `n` decimals and returns a **string**.
* Decimal fractions such as `0.1 + 0.2` have tiny rounding errors in every language that uses binary floating-point numbers.
* `toLocaleString()` formats numbers for a region, such as Indian or US digit grouping.

## 15. The Date Object

A `Date` represents a moment in time. The examples below use UTC so that the results are the same everywhere.

```javascript
const d = new Date("2026-10-19T00:00:00Z");

console.log(d.toISOString());
console.log(d.getUTCFullYear());
console.log(d.getUTCMonth());
console.log(d.getUTCDay());

d.setUTCDate(d.getUTCDate() + 30);
console.log(d.toISOString());

const start = new Date("2026-10-19");
const end = new Date("2026-12-25");
const days = (end - start) / (1000 * 60 * 60 * 24);
console.log(days);
```

```output
2026-10-19T00:00:00.000Z
2026
9
1
2026-11-18T00:00:00.000Z
67
```

* `getMonth()` starts at **0** (January is `0`, so October is `9`).
* `getDay()` returns the weekday from `0` (Sunday) to `6` (Saturday), so `1` is Monday.
* Subtracting two dates gives the difference in **milliseconds**.
* `new Date()` with no arguments gives the current date and time.

## Real-World Example 🌍

Counting unique visitors and finding the most active one:

```javascript
const visits = ["asha", "ravi", "asha", "meena", "ravi", "asha"];

const unique = new Set(visits);
const counts = new Map();

for (const name of visits) {
  counts.set(name, (counts.get(name) || 0) + 1);
}

const top = [...counts.entries()].sort((a, b) => b[1] - a[1])[0];

console.log(`Total visits: ${visits.length}`);
console.log(`Unique visitors: ${unique.size}`);
console.log(`Most active: ${top[0]} (${top[1]} visits)`);
```

```output
Total visits: 6
Unique visitors: 3
Most active: asha (3 visits)
```

## Common Mistakes

### Using length Instead of size

```javascript
const set = new Set([1, 2, 3]);

console.log(set.length);    // undefined
console.log(set.size);      // 3, correct
```

### Using Bracket Syntax on a Map

```javascript
const map = new Map();

map["name"] = "Asha";       // adds a normal property, not a Map entry
map.set("name", "Asha");    // correct
```

### Expecting a Set to Treat Equal Objects as the Same

```javascript
const set = new Set();

set.add({ id: 1 });
set.add({ id: 1 });
console.log(set.size);    // 2, they are different objects
```

### Forgetting That Months Start at Zero

```javascript
new Date(2026, 0, 1);     // January 1, 2026
new Date(2026, 10, 1);    // November 1, 2026, not October
```

### Treating toFixed as a Number

```javascript
const price = (9.5).toFixed(2);

console.log(typeof price);    // "string"
console.log(Number(price));   // 9.5
```

## Key Points

* A **Set** stores unique values; use `add`, `has`, `delete`, `clear` and `size`.
* `[...new Set(array)]` removes duplicates from an array.
* A **Map** stores key-value pairs and allows keys of any type.
* Use `set`, `get`, `has`, `delete` and `size` with a Map, and loop with `for (const [key, value] of map)`.
* Choose objects for fixed records and Maps for dynamic lookups and counting.
* `Math` provides `round`, `floor`, `ceil`, `trunc`, `max`, `min`, `sqrt`, `abs` and `random`.
* `toFixed()` returns a string, and `toLocaleString()` formats numbers for a region.
* Decimal calculations such as `0.1 + 0.2` can have small rounding errors.
* `Date` months start at `0`, and subtracting two dates gives milliseconds.

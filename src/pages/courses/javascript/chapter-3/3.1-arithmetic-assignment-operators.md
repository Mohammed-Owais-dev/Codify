# Chapter 3: Operators and Control Flow

## Section 1: Arithmetic and Assignment Operators

An **operator** is a symbol that performs an action on values, which are called **operands**. In this section you will learn the operators used for calculations and for storing results in variables.

---

## 1. Arithmetic Operators

| Operator | Name | Example (`a = 10`, `b = 3`) | Result |
| --- | --- | --- | --- |
| `+` | Addition | `a + b` | `13` |
| `-` | Subtraction | `a - b` | `7` |
| `*` | Multiplication | `a * b` | `30` |
| `/` | Division | `a / b` | `3.3333333333333335` |
| `%` | Remainder (modulus) | `a % b` | `1` |
| `**` | Exponent (power) | `a ** b` | `1000` |

```javascript
let a = 10;
let b = 3;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** b);
```

```output
13
7
30
3.3333333333333335
1
1000
```

> 💡 Division in JavaScript always gives a decimal result when needed. There is no separate integer division operator.

---

## 2. The Remainder Operator `%`

`%` gives the **remainder** after division. It is useful for many everyday checks.

```javascript
console.log(17 % 5);
console.log(10 % 2);
console.log(7 % 2);
console.log(1234 % 10);
```

```output
2
0
1
4
```

* `n % 2 === 0` means `n` is even.
* `n % 10` gives the last digit of `n`.

---

## 3. Division by Zero

JavaScript does not crash when you divide by zero.

```javascript
console.log(10 / 0);
console.log(-10 / 0);
console.log(0 / 0);
console.log(10 % 0);
```

```output
Infinity
-Infinity
NaN
NaN
```

---

## 4. Increment and Decrement

`++` adds 1 and `--` subtracts 1.

```javascript
let count = 5;

count++;
console.log(count);

count--;
console.log(count);
```

```output
6
5
```

### Prefix vs Postfix

* **Postfix** (`x++`) returns the **old** value, then increases.
* **Prefix** (`++x`) increases first, then returns the **new** value.

```javascript
let x = 5;

console.log(x++);
console.log(x);
console.log(++x);
console.log(--x);
```

```output
5
6
7
6
```

## 5. Operator Precedence

When an expression has several operators, JavaScript follows an order, like BODMAS in mathematics.

| Priority | Operators |
| --- | --- |
| 1 (highest) | `( )` parentheses |
| 2 | `++`, `--` |
| 3 | `**` (evaluated right to left) |
| 4 | `*`, `/`, `%` |
| 5 | `+`, `-` |
| 6 (lowest) | `=`, `+=`, `-=` and other assignments |

```javascript
console.log(2 + 3 * 4);
console.log((2 + 3) * 4);
console.log(10 - 4 - 3);
console.log(2 ** 3 ** 2);
```

```output
14
20
3
512
```

`2 ** 3 ** 2` is calculated as `2 ** (3 ** 2)`, which is `2 ** 9`.

> 💡 When in doubt, use parentheses. They make the order clear to every reader.

## 6. The `+` Operator with Strings

When either operand is a string, `+` **joins** the values.

```javascript
let first = "Asha";
let last = "Reddy";

console.log(first + " " + last);
console.log("Total: " + 5 + 5);
console.log("Total: " + (5 + 5));
```

```output
Asha Reddy
Total: 55
Total: 10
```

## 7. Assignment Operators

The `=` operator stores a value in a variable. **Compound assignment operators** combine a calculation with assignment.

| Operator | Example | Same as |
| --- | --- | --- |
| `=` | `x = 5` | Assign 5 to `x` |
| `+=` | `x += 3` | `x = x + 3` |
| `-=` | `x -= 3` | `x = x - 3` |
| `*=` | `x *= 3` | `x = x * 3` |
| `/=` | `x /= 3` | `x = x / 3` |
| `%=` | `x %= 3` | `x = x % 3` |
| `**=` | `x **= 3` | `x = x ** 3` |

```javascript
let n = 10;

n += 5;
console.log(n);
n -= 3;
console.log(n);
n *= 2;
console.log(n);
n /= 4;
console.log(n);
n %= 4;
console.log(n);
n **= 3;
console.log(n);
```

```output
15
12
24
6
2
8
```

`+=` also works with strings.

```javascript
let message = "Hello";
message += ", World";
console.log(message);
```

```output
Hello, World
```

## 8. The `Math` Object

JavaScript has a built-in `Math` object with useful methods and constants.

| Method | Purpose | Example | Result |
| --- | --- | --- | --- |
| `Math.round(x)` | Round to nearest integer | `Math.round(4.6)` | `5` |
| `Math.floor(x)` | Round down | `Math.floor(4.9)` | `4` |
| `Math.ceil(x)` | Round up | `Math.ceil(4.1)` | `5` |
| `Math.trunc(x)` | Remove the decimal part | `Math.trunc(-4.9)` | `-4` |
| `Math.abs(x)` | Absolute value | `Math.abs(-7)` | `7` |
| `Math.sqrt(x)` | Square root | `Math.sqrt(16)` | `4` |
| `Math.pow(x, y)` | Power | `Math.pow(2, 3)` | `8` |
| `Math.max(...)` | Largest value | `Math.max(4, 9, 2)` | `9` |
| `Math.min(...)` | Smallest value | `Math.min(4, 9, 2)` | `2` |

```javascript
console.log(Math.round(4.6));
console.log(Math.floor(4.9));
console.log(Math.ceil(4.1));
console.log(Math.trunc(-4.9));
console.log(Math.sqrt(16));
console.log(Math.max(4, 9, 2));
console.log(Math.PI);
console.log(Math.round(-2.5));
```

```output
5
4
5
-4
4
9
3.141592653589793
-2
```

`Math.round()` rounds halves **upward** (toward positive infinity), so `-2.5` becomes `-2`.

`Math.random()` returns a random decimal from `0` up to (but not including) `1`.

```javascript
const dice = Math.floor(Math.random() * 6) + 1;
console.log(dice >= 1 && dice <= 6);
```

```output
true
```

The line prints `true` every time, even though `dice` is a different number on each run.

## 9. Floating-Point Precision

```javascript
console.log(0.1 + 0.2);

console.log(Math.round((0.1 + 0.2) * 100) / 100);
```

```output
0.30000000000000004
0.30
0.3
```

## Real-World Example 🌍

Converting seconds into hours, minutes and seconds:

```javascript
const totalSeconds = 3725;

const hours = Math.floor(totalSeconds / 3600);
const minutes = Math.floor((totalSeconds % 3600) / 60);
const seconds = totalSeconds % 60;

console.log(`${hours} hour(s), ${minutes} minute(s), ${seconds} second(s)`);
```

```output
1 hour(s), 2 minute(s), 5 second(s)
```

A bill with discount and tax:

```javascript
let amount = 1200;

amount -= amount * 10 / 100;
console.log("After discount:", amount);

const tax = amount * 5 / 100;
const total = amount + tax;
console.log("Total:", total);
```

```output
After discount: 1080
Total: 1134
```

## Common Mistakes

### Confusing `=` with `==`

```javascript
let x = 5;
x = 10;     // assigns 10
x == 10;    // compares
```

### Joining Strings Instead of Adding

```javascript
console.log("5" + 3);    // "53", not 8
```

### Forgetting That `**` Is Right-to-Left

`2 ** 3 ** 2` is `512`, not `64`.

### Expecting Exact Decimal Results

`0.1 + 0.2` is not exactly `0.3`. Round the result when showing money.

### Using `x = x++`

```javascript
let x = 5;
x = x++;
console.log(x);    // 5, because the old value is assigned back
```

Use `x++;` on its own.

---

## Key Points

* Arithmetic operators: `+`, `-`, `*`, `/`, `%`, `**`.
* `%` gives the remainder, and `n % 2 === 0` tests for even numbers.
* Dividing by zero gives `Infinity` or `NaN`, not an error.
* `x++` returns the old value; `++x` returns the new value.
* Use parentheses to control the order of calculation.
* `+` joins text when either side is a string.
* Compound operators such as `+=` and `*=` update a variable in one step.
* `Math.round()`, `Math.floor()`, `Math.ceil()`, `Math.sqrt()`, `Math.max()` and others help with calculations.

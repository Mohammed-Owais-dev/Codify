# Chapter 3: Operators and Control Flow

## Section 3: if, else if and else

Conditional statements let your program choose which code to run depending on a condition. They are the main decision-making tool in JavaScript.

---

## 1. The `if` Statement

The `if` block runs only when its condition is `true`.

**Syntax:**

```text
if (condition) {
  // code runs when the condition is true
}
```

```javascript
const temperature = 35;

if (temperature > 30) {
  console.log("It is a hot day.");
}

console.log("Program ended.");
```

```output
It is a hot day.
Program ended.
```

* The condition goes inside parentheses `( )`.
* The code to run goes inside curly braces `{ }`.
* If the condition is `false`, the block is skipped.

---

## 2. The `if...else` Statement

`else` runs when the condition is `false`.

```javascript
const age = 15;

if (age >= 18) {
  console.log("Eligible to vote");
} else {
  console.log("Not eligible to vote");
}
```

```output
Not eligible to vote
```

Exactly one of the two blocks runs.

---

## 3. Even or Odd

```javascript
const number = 7;

if (number % 2 === 0) {
  console.log("Even number");
} else {
  console.log("Odd number");
}
```

```output
Odd number
```

---

## 4. The `else if` Ladder

Use `else if` to check more than two conditions. JavaScript tests them from top to bottom and runs the **first** block whose condition is true.

**Syntax:**

```text
if (condition1) {
  ...
} else if (condition2) {
  ...
} else if (condition3) {
  ...
} else {
  ...
}
```

```javascript
const marks = 72;

if (marks >= 90) {
  console.log("Grade A+");
} else if (marks >= 75) {
  console.log("Grade A");
} else if (marks >= 60) {
  console.log("Grade B");
} else if (marks >= 40) {
  console.log("Grade C");
} else {
  console.log("Fail");
}
```

```output
Grade B
```

* `72 >= 90` and `72 >= 75` are false, `72 >= 60` is true, so `Grade B` is printed and the rest is skipped.
* `else` is optional and must come last.

---

## 5. Multiple `if` vs `else if`

Separate `if` statements are all checked. An `else if` chain stops at the first match.

```javascript
const x = 15;

if (x > 10) {
  console.log("Greater than 10");
}
if (x > 5) {
  console.log("Greater than 5");
}
```

```output
Greater than 10
Greater than 5
```

```javascript
const y = 15;

if (y > 10) {
  console.log("Greater than 10");
} else if (y > 5) {
  console.log("Greater than 5");
}
```

```output
Greater than 10
```

---

## 6. Combining Conditions

Use `&&`, `||` and `!` to build bigger conditions.

```javascript
const year = 2024;

if ((year % 4 === 0 && year % 100 !== 0) || year % 400 === 0) {
  console.log("Leap year");
} else {
  console.log("Not a leap year");
}
```

```output
Leap year
```

---

## 7. Nested `if` Statements

An `if` can be placed inside another `if`.

```javascript
const age = 25;
const hasTicket = true;

if (age >= 18) {
  if (hasTicket) {
    console.log("Entry allowed");
  } else {
    console.log("Please buy a ticket");
  }
} else {
  console.log("Adults only");
}
```

```output
Entry allowed
```

> 💡 Deep nesting is hard to read. Combine conditions with `&&` when you can: `if (age >= 18 && hasTicket)`.

---

## 8. Truthy and Falsy Conditions

The condition does not have to be a boolean. JavaScript converts it.

```javascript
const username = "";

if (username) {
  console.log("Welcome, " + username);
} else {
  console.log("Username cannot be empty");
}
```

```output
Username cannot be empty
```

Falsy values are `false`, `0`, `""`, `null`, `undefined` and `NaN`. Everything else is truthy.

---

## 9. The Ternary (Conditional) Operator

The **ternary operator** is a one-line `if...else` that produces a value.

**Syntax:**

```text
condition ? valueIfTrue : valueIfFalse
```

```javascript
const age = 17;

const status = age >= 18 ? "Adult" : "Minor";
console.log(status);

console.log(7 % 2 === 0 ? "Even" : "Odd");
```

```output
Minor
Odd
```

Ternaries can be chained, but keep them short.

```javascript
const score = 68;

const result = score >= 75 ? "Distinction" : score >= 60 ? "First Class" : "Pass";
console.log(result);
```

```output
First Class
```

---

## 10. Using Braces

Braces are optional for a **single** statement, but always using them avoids bugs.

```javascript
const n = 5;

if (n > 3) console.log("Greater than 3");
```

```output
Greater than 3
```

```javascript
// Risky: only the first line belongs to the if
const m = 1;
if (m > 3)
  console.log("A");
  console.log("B");
```

```output
B
```

The second line is **not** part of the `if`, so it always runs. Using braces makes the structure obvious.

---

## Real-World Example

An ATM withdrawal with nested checks:

```javascript
let balance = 5000;
const amount = Number(prompt("Enter amount to withdraw:"));

if (amount > 0) {
  if (amount <= balance) {
    balance -= amount;
    console.log("Withdrawal successful. Remaining balance: " + balance);
  } else {
    console.log("Insufficient balance");
  }
} else {
  console.log("Enter a valid amount");
}
```

If the user enters:

```text
2000
```

The output will be:

```output
Withdrawal successful. Remaining balance: 3000
```

## Common Mistakes

### Using `=` Instead of `===`

```javascript
if (age = 18) { }    // assigns 18, which is always truthy
```

Use `if (age === 18)`.

### Putting a Semicolon After the Condition

```javascript
if (age >= 18);    // the semicolon ends the if with an empty body
{
  console.log("Adult");    // always runs
}
```

### Writing `elseif` or `else if` Without a Condition

JavaScript uses two words: `else if (condition)`. `else` alone never takes a condition.

### Wrong Order of Conditions

```javascript
const marks = 95;

if (marks >= 40) {
  console.log("Grade C");    // runs first!
} else if (marks >= 90) {
  console.log("Grade A+");
}
```

Test the most specific (highest) condition first.

### Forgetting Braces for Several Statements

Only the first statement belongs to an `if` without braces.

---

## Key Points

* `if` runs a block when its condition is true; `else` runs when it is false.
* `else if` checks extra conditions, and only the first true block runs.
* The condition goes in parentheses and the code in curly braces.
* Use `&&`, `||` and `!` to combine conditions.
* Any value can be used as a condition (truthy or falsy).
* The ternary operator `condition ? a : b` is a one-line `if...else`.
* Always use braces, and place the most specific condition first.

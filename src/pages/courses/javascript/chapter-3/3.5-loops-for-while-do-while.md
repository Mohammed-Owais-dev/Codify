# Chapter 3: Operators and Control Flow

## Section 5: Loops: for, while and do...while

A **loop** repeats a block of code many times, so you do not have to write the same lines again and again. JavaScript has several loops. In this section you will learn `for`, `while` and `do...while`, and a first look at `for...of` and `for...in`.

---

## 1. Why Use Loops?

Printing "Hello" five times without a loop needs five lines. With a loop it takes three:

```javascript
for (let i = 0; i < 5; i++) {
  console.log("Hello");
}
```

```output
Hello
Hello
Hello
Hello
Hello
```

---

## 2. The `for` Loop

**Syntax:**

```text
for (initialization; condition; update) {
  // code to repeat
}
```

| Part | Purpose | Example |
| --- | --- | --- |
| Initialization | Runs once at the start | `let i = 1` |
| Condition | Checked before every round | `i <= 5` |
| Update | Runs after every round | `i++` |

```javascript
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

```output
1
2
3
4
5
```

Each round of a loop is called an **iteration**.

---

## 3. Counting Down and Skipping

```javascript
for (let i = 5; i >= 1; i--) {
  console.log(i);
}
```

```output
5
4
3
2
1
```

```javascript
for (let i = 1; i <= 10; i += 3) {
  console.log(i);
}
```

```output
1
4
7
10
```

---

## 4. Sum of Numbers

A running total is stored in a variable that starts at `0`.

```javascript
let total = 0;

for (let i = 1; i <= 5; i++) {
  total += i;
}

console.log("Sum =", total);
```

```output
Sum = 15
```

---

## 5. Multiplication Table

```javascript
const n = 5;

for (let i = 1; i <= 5; i++) {
  console.log(`${n} x ${i} = ${n * i}`);
}
```

```output
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
```

---

## 6. The `while` Loop

A `while` loop repeats **as long as its condition is true**. Use it when you do not know in advance how many times to repeat.

**Syntax:**

```text
while (condition) {
  // code to repeat
}
```

```javascript
let count = 1;

while (count <= 5) {
  console.log(count);
  count++;
}
```

```output
1
2
3
4
5
```

A `while` loop needs:

1. A **starting value** (`let count = 1`).
2. A **condition** (`count <= 5`).
3. An **update** that moves toward ending the loop (`count++`).

### Sum of Digits

```javascript
let n = 1234;
let total = 0;

while (n > 0) {
  total += n % 10;
  n = Math.floor(n / 10);
}

console.log("Sum of digits =", total);
```

```output
Sum of digits = 10
```

---

## 7. The `do...while` Loop

A `do...while` loop runs the code **first** and checks the condition **afterwards**. It always runs **at least once**.

**Syntax:**

```text
do {
  // code to repeat
} while (condition);
```

```javascript
let i = 10;

do {
  console.log(i);
  i++;
} while (i < 5);
```

```output
10
```

The condition `i < 5` is false from the start, but the body still ran once.

---

## 8. `break` and `continue`

* `break` **stops the loop** immediately.
* `continue` **skips** the rest of the current iteration.

```javascript
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;
  }
  console.log(i);
}
```

```output
1
2
3
4
```

```javascript
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue;
  }
  console.log(i);
}
```

```output
1
2
4
5
```

---

## 9. Nested Loops

A loop inside another loop runs completely for every iteration of the outer loop.

```javascript
for (let i = 1; i <= 4; i++) {
  let row = "";

  for (let j = 1; j <= i; j++) {
    row += "*";
  }

  console.log(row);
}
```

```output
*
**
***
****
```

The outer loop controls the rows, and the inner loop builds the stars in each row.

---

## 10. Looping Over Arrays with `for` and `for...of`

An array is a list of values. You will study arrays in Chapter 5, but loops are the natural way to read them.

```javascript
const fruits = ["apple", "banana", "mango"];

for (let i = 0; i < fruits.length; i++) {
  console.log(i, fruits[i]);
}
```

```output
0 apple
1 banana
2 mango
```

`for...of` is simpler when you only need the values.

```javascript
const fruits = ["apple", "banana", "mango"];

for (const fruit of fruits) {
  console.log(fruit);
}
```

```output
apple
banana
mango
```

---

## 11. Looping Over Objects with `for...in`

`for...in` goes through the **keys** of an object.

```javascript
const student = { name: "Asha", age: 20, city: "Hyderabad" };

for (const key in student) {
  console.log(key + ": " + student[key]);
}
```

```output
name: Asha
age: 20
city: Hyderabad
```

> 💡 Use `for...of` for arrays and `for...in` for objects. `for...in` on an array gives the indexes as **strings**.

---

## 12. Infinite Loops

If the condition never becomes false, the loop runs forever and freezes the page.

```javascript
let i = 1;

while (i <= 5) {
  console.log(i);
  // i is never updated, so the loop never ends
}
```

Always make sure something inside the loop moves it toward ending.

---

## 13. Choosing a Loop

| Loop | Use when |
| --- | --- |
| `for` | You know how many times to repeat |
| `while` | You repeat until a condition changes |
| `do...while` | The body must run at least once |
| `for...of` | You need every value of an array or string |
| `for...in` | You need every key of an object |

---

## Real-World Example

A program that keeps asking for numbers until the user enters `0`:

```javascript
let total = 0;
let num;

do {
  num = Number(prompt("Enter a number (0 to stop):"));
  total += num;
} while (num !== 0);

console.log("Total:", total);
```

If the user enters:

```text
10
20
5
0
```

The output will be:

```output
Total: 35
```

## Common Mistakes

### Forgetting to Update the Counter

```javascript
let i = 0;
while (i < 5) {
  console.log(i);    // infinite loop
}
```

Add `i++` inside the loop.

### Off-by-One Errors

```javascript
for (let i = 1; i < 5; i++) { }    // runs for 1 to 4, not 5
```

Use `i <= 5` to include `5`.

### Using `=` in the Condition

```javascript
while (x = 5) { }    // assigns 5 and never stops
```

Use `===` to compare.

### Using `for...in` on Arrays

```javascript
for (const i in ["a", "b"]) {
  console.log(typeof i);    // "string"
}
```

Use `for...of` for the values.

### Using `continue` Before Updating a `while` Counter

```javascript
let i = 0;
while (i < 5) {
  if (i === 2) { continue; }    // i never changes, infinite loop
  i++;
}
```

---

## Key Points

* Loops repeat a block of code.
* `for (init; condition; update)` is best when the number of repeats is known.
* `while` repeats while a condition is true; `do...while` runs at least once.
* `break` ends a loop, and `continue` skips to the next iteration.
* Nested loops run the inner loop fully for every outer iteration.
* `for...of` loops over values of arrays and strings; `for...in` loops over object keys.
* Always update the loop variable to avoid infinite loops.

# Chapter 3: Operators and Control Flow

## Section 2: Comparison and Logical Operators

Programs make decisions by asking questions: Is the age above 18? Is the password correct? In this section you will learn the operators that compare values and combine conditions.

---

## 1. Comparison Operators

A comparison always produces a **boolean**: `true` or `false`.

| Operator | Meaning | Example (`a = 10`, `b = 20`) | Result |
| --- | --- | --- | --- |
| `==` | Loose equal | `a == "10"` | `true` |
| `===` | Strict equal | `a === "10"` | `false` |
| `!=` | Loose not equal | `a != b` | `true` |
| `!==` | Strict not equal | `a !== 10` | `false` |
| `>` | Greater than | `a > b` | `false` |
| `<` | Less than | `a < b` | `true` |
| `>=` | Greater than or equal | `a >= 10` | `true` |
| `<=` | Less than or equal | `b <= 10` | `false` |

```javascript
let a = 10;
let b = 20;

console.log(a == "10");
console.log(a === "10");
console.log(a != b);
console.log(a !== 10);
console.log(a > b);
console.log(a < b);
console.log(a >= 10);
console.log(b <= 10);
```

```output
true
false
true
false
false
true
true
false
```

---

## 2. Strict vs Loose Equality

* `==` converts the types before comparing, which gives surprising results.
* `===` compares the value **and** the type. No conversion happens.

```javascript
console.log(5 == "5");
console.log(5 === "5");
console.log(0 == false);
console.log(0 === false);
console.log(null == undefined);
console.log(null === undefined);
```

```output
true
false
true
false
true
false
```

> 💡 Always use `===` and `!==` unless you have a specific reason not to.

---

## 3. Comparing Strings

Strings are compared character by character, using their Unicode order. Uppercase letters come before lowercase letters.

```javascript
console.log("apple" < "banana");
console.log("a" < "B");
console.log("A" < "a");
console.log("10" < "9");
console.log(10 < 9);
console.log("10" < 9);
```

```output
true
false
true
true
false
false
```

* `"10" < "9"` is `true` because the text `"1"` comes before `"9"`.
* `"10" < 9` converts the string to a number, so it is `false`.

For case-insensitive comparison, convert both sides first:

```javascript
console.log("Asha".toLowerCase() === "asha".toLowerCase());
```

```output
true
```

---

## 4. Comparing Objects and Arrays

Objects and arrays are compared by **reference**, not by their contents.

```javascript
const a = [1, 2];
const b = [1, 2];
const c = a;

console.log(a === b);
console.log(a === c);
```

```output
false
true
```

`a` and `b` look the same but are two different arrays. `c` points to the same array as `a`.

## 5. Logical Operators

Logical operators combine conditions.

| Operator | Name | Meaning |
| --- | --- | --- |
| `&&` | AND | `true` only if **both** sides are true |
| `\|\|` | OR | `true` if **at least one** side is true |
| `!` | NOT | Reverses `true` and `false` |

```javascript
const age = 20;
const hasId = true;

console.log(age >= 18 && hasId);
console.log(age < 18 || hasId);
console.log(!hasId);
```

```output
true
true
false
```

### Truth Table

| A | B | `A && B` | `A \|\| B` |
| --- | --- | --- | --- |
| `true` | `true` | `true` | `true` |
| `true` | `false` | `false` | `true` |
| `false` | `true` | `false` | `true` |
| `false` | `false` | `false` | `false` |

### Order of Evaluation

`!` runs first, then `&&`, then `||`.

```javascript
console.log(true || false && false);
console.log((true || false) && false);
```

```output
true
false
```

---

## 6. Short-Circuit Evaluation

JavaScript stops as soon as it knows the answer.

* `A && B`: if `A` is falsy, the result is `A` and `B` is never evaluated.
* `A || B`: if `A` is truthy, the result is `A` and `B` is never evaluated.

```javascript
function check() {
  console.log("check() was called");
  return true;
}

console.log(false && check());
console.log(true || check());
console.log(true && check());
```

```output
false
true
check() was called
true
```

---

## 7. `&&` and `||` Return Values, Not Just Booleans

Logical operators return one of the original values.

```javascript
console.log("Hello" && "World");
console.log(0 && "World");
console.log("" || "Default");
console.log("Asha" || "Default");
```

```output
World
0
Default
Asha
```

A common use of `||` is to provide a **default value**:

```javascript
const username = "" || "Guest";
console.log(username);
```

```output
Guest
```

---

## 8. Nullish Coalescing `??`

`||` replaces **every falsy value**, including `0` and `""`. The `??` operator replaces only `null` and `undefined`.

```javascript
console.log(0 || 10);
console.log(0 ?? 10);
console.log(null ?? 10);
console.log(undefined ?? "none");
console.log(("" ?? "none") === "");
```

```output
10
0
10
none
true
```

The last line is `true` because `""` is not `null` or `undefined`, so `??` keeps the empty string.

---

## 9. Logical Assignment Operators

| Operator | Meaning |
| --- | --- |
| `a ||= b` | Assign `b` only if `a` is falsy |
| `a &&= b` | Assign `b` only if `a` is truthy |
| `a ??= b` | Assign `b` only if `a` is `null` or `undefined` |

```javascript
let theme = null;
theme ??= "light";
console.log(theme);

let count = 0;
count ||= 5;
console.log(count);
```

```output
light
5
```

---

## 10. Checking a Range

A chained comparison like `1 < x < 10` does **not** work as in mathematics.

```javascript
const x = 15;

console.log(1 < x < 10);
console.log(x > 1 && x < 10);
```

```output
true
false
```

`1 < 15` is `true`, which becomes `1`, and `1 < 10` is `true`. The correct way is to combine two comparisons with `&&`.

## Real-World Example 🌍

A login and discount check:

```javascript
const username = "admin";
const password = "1234";

if (username === "admin" && password === "1234") {
  console.log("Login successful");
} else {
  console.log("Invalid credentials");
}

const isMember = false;
const cartTotal = 1500;
const getsDiscount = isMember || cartTotal > 1000;

console.log("Discount applied:", getsDiscount);
```

```output
Login successful
Discount applied: true
```

## Common Mistakes

### Using `=` Instead of `===`

```javascript
if (age = 18) { }    // assigns 18, always truthy
```

Use `if (age === 18)`.

### Using `==` Out of Habit

`"" == 0` and `0 == false` are both `true`. Use `===`.

### Comparing Two Arrays or Objects Directly

`[1, 2] === [1, 2]` is `false`, because they are different objects.

### Chaining Comparisons

Write `x > 1 && x < 10`, not `1 < x < 10`.

### Using `||` for Defaults When `0` Is Valid

`quantity || 1` replaces `0` with `1`. Use `quantity ?? 1`.

---

## Key Points

* Comparison operators return `true` or `false`.
* Prefer `===` and `!==` over `==` and `!=`.
* Strings are compared by Unicode order, and `"10" < "9"` is `true`.
* Arrays and objects are compared by reference.
* `&&` is AND, `||` is OR and `!` is NOT.
* `&&` and `||` short-circuit and return one of their operands.
* `||` gives a default for any falsy value; `??` only for `null` and `undefined`.
* Use `&&` to check a range of values.

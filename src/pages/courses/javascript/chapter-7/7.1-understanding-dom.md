# Chapter 7: The Document Object Model (DOM)

## Section 1: Understanding the DOM

The **DOM (Document Object Model)** is a representation of a web page that the browser builds from your HTML. JavaScript uses the DOM to read and change the page: its text, its structure and its styles, without reloading it.

---

## 1. What is the DOM?

When a browser loads an HTML file, it does not keep it as plain text. It parses the HTML and builds a **tree of objects** in memory. Each tag becomes an object that JavaScript can access.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <h1 id="title">Hello DOM</h1>
  <p id="info"></p>

  <script>
    const heading = document.getElementById("title");
    document.getElementById("info").textContent =
      "The heading says: " + heading.textContent;
  </script>
</body>
</html>
```

JavaScript found the `<h1>` object and read its text. That is the DOM at work.

> **Tip:** HTML is the *source code* of the page. The DOM is the *live version* of it that the browser creates, and which JavaScript can change.

---

## 2. The DOM Tree

The DOM is organized as a **tree**. Consider this HTML:

```html
<body>
  <h1>Title</h1>
  <ul>
    <li>One</li>
    <li>Two</li>
  </ul>
</body>
```

The browser builds this tree:

```text
body
├── h1
│   └── "Title"
└── ul
    ├── li
    │   └── "One"
    └── li
        └── "Two"
```

* The top of the tree is the `document` object, then `<html>`, then `<head>` and `<body>`.
* Every tag becomes a **node**, and the text inside tags becomes **text nodes**.

---

## 3. Types of Nodes

| Node Type     | Example                | Description                         |
| ------------- | ---------------------- | ----------------------------------- |
| Document      | `document`             | The root of the whole tree          |
| Element       | `<p>`, `<div>`, `<h1>` | An HTML tag                         |
| Text          | `"Hello"`              | The text inside an element          |
| Attribute     | `id="title"`           | A property written inside a tag     |
| Comment       | `<!-- note -->`        | An HTML comment                     |

Most of the time you will work with **element nodes**.

---

## 4. The `document` Object

`document` is the entry point to the DOM. It is a global object available in every browser script.

```javascript
console.log(document.title);
console.log(document.URL);
console.log(document.body.tagName);
console.log(document.documentElement.tagName);
```

```output
My First Page
https://example.com/index.html
BODY
HTML
```

The exact title and URL depend on your page.

| Property                    | Gives you                        |
| --------------------------- | -------------------------------- |
| `document.title`            | The page title                   |
| `document.body`             | The `<body>` element             |
| `document.head`             | The `<head>` element             |
| `document.documentElement`  | The `<html>` element             |
| `document.URL`              | The address of the page          |

---

## 5. Parent, Child and Sibling Relationships

Nodes in the tree are related like a family.

```html
<ul id="menu">
  <li>Home</li>
  <li>Courses</li>
  <li>Contact</li>
</ul>
```

* `<ul>` is the **parent** of each `<li>`.
* Each `<li>` is a **child** of the `<ul>`.
* The three `<li>` elements are **siblings** of each other.

---

## 6. Navigating the DOM

You can move from one element to another using these properties.

| Property                  | Returns                          |
| ------------------------- | -------------------------------- |
| `parentElement`           | The parent element               |
| `children`                | All child elements               |
| `firstElementChild`       | The first child element          |
| `lastElementChild`        | The last child element           |
| `nextElementSibling`      | The next sibling element         |
| `previousElementSibling`  | The previous sibling element     |

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <ul id="menu">
    <li>Home</li>
    <li id="middle">Courses</li>
    <li>Contact</li>
  </ul>
  <pre id="result"></pre>

  <script>
    const menu = document.getElementById("menu");
    const middle = document.getElementById("middle");

    const lines = [
      "Children count: " + menu.children.length,
      "First child: " + menu.firstElementChild.textContent,
      "Last child: " + menu.lastElementChild.textContent,
      "Previous of middle: " + middle.previousElementSibling.textContent,
      "Next of middle: " + middle.nextElementSibling.textContent,
      "Parent of middle: " + middle.parentElement.id
    ];

    document.getElementById("result").textContent = lines.join("\n");
  </script>
</body>
</html>
```

> **Tip:** Use the `...Element...` versions such as `firstElementChild`. The versions without it, such as `firstChild`, can return whitespace text nodes between tags.

---

## 7. Where to Place Your Script

The browser reads HTML from top to bottom. If your script runs **before** an element exists, JavaScript cannot find it.

```javascript
const box = document.getElementById("box");
console.log(box);
```

```output
null
```

This prints `null` when the script is placed above the `<div id="box">`.

There are three safe solutions:

```text
<!-- 1. Put the script at the end of <body> -->
<body>
  <div id="box">Hello</div>
  <script src="app.js"></script>
</body>

<!-- 2. Use the defer attribute in <head> -->
<head>
  <script src="app.js" defer></script>
</head>
```

```javascript
// 3. Wait for the DOMContentLoaded event
document.addEventListener("DOMContentLoaded", () => {
  const box = document.getElementById("box");
  console.log(box.textContent);
});
```

```output
Hello
```

## 8. `window` vs `document`

| Object     | Represents                                              |
| ---------- | ------------------------------------------------------- |
| `window`   | The browser window or tab (the global object)           |
| `document` | The web page loaded inside that window                  |

`document` is actually a property of `window`, so `window.document` and `document` are the same thing.

```javascript
console.log(window.document === document);
console.log(window.innerWidth > 0);
```

```output
true
true
```

---

## 9. Inspecting the DOM in the Browser

Press `F12` (or right-click and choose **Inspect**) and open the **Elements** tab. You will see the live DOM tree.

If JavaScript changes the page, the Elements tab shows the **updated** DOM, while *View Page Source* still shows the original HTML.

You can also type this in the **Console** tab to see any element as an object:

```javascript
console.dir(document.body);
```

## Real-World Example

A page that shows how many items are in a menu and the name of the first one, using only DOM navigation:

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <h2>Course Menu</h2>
  <ul id="courses">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
    <li>Python</li>
  </ul>
  <p id="summary"></p>

  <script>
    const list = document.getElementById("courses");
    const total = list.children.length;
    const first = list.firstElementChild.textContent;

    document.getElementById("summary").textContent =
      `${total} courses available. Start with ${first}!`;
  </script>
</body>
</html>
```

## Common Mistakes

### Running the Script Before the Element Exists

```javascript
// script is in <head> without defer
const title = document.getElementById("title");
title.textContent = "Hi";    // TypeError: Cannot set properties of null
```

Move the script to the end of `<body>`, use `defer`, or wait for `DOMContentLoaded`.

### Confusing HTML with the DOM

Changing the DOM with JavaScript does **not** edit your `.html` file. Refresh the page and the changes are gone.

### Using `children` and `childNodes` Interchangeably

`children` contains only elements. `childNodes` also includes text and comment nodes, such as the line breaks between tags.

### Expecting `children` to Be a Real Array

`children` is an `HTMLCollection`. It has `length` and indexes, but not array methods like `map()`. Convert it first with `Array.from(menu.children)`.

---

## Key Points

* The DOM is a tree of objects that the browser builds from HTML.
* JavaScript uses the DOM to read and change the page.
* `document` is the entry point to the DOM.
* The main node types are document, element, text, attribute and comment nodes.
* Elements are related as parent, child and sibling.
* Use `parentElement`, `children`, `firstElementChild` and `nextElementSibling` to navigate.
* Scripts must run after the elements exist: use the end of `<body>`, `defer` or `DOMContentLoaded`.
* `window` is the browser window; `document` is the page inside it.
* Changing the DOM does not change the HTML file.

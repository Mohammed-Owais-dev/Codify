# Chapter 7: The Document Object Model (DOM)

## Section 4: Creating, Adding and Removing Elements

JavaScript can build new HTML elements, insert them into the page and delete them when they are no longer needed. This is how to-do lists, comment sections and dynamic product lists are made.

---

## 1. The Three Steps

Adding a new element to a page always follows the same pattern:

```text
1. Create the element      →  document.createElement("li")
2. Set its content/style   →  li.textContent = "New item"
3. Insert it into the page →  list.append(li)
```

---

## 2. Creating an Element: `createElement()`

`createElement()` builds a new element in memory. It is **not** visible until you insert it into the page.

```javascript
const item = document.createElement("li");

item.textContent = "Learn the DOM";
item.className = "task";

console.log(item.tagName);
console.log(item.textContent);
console.log(item.parentElement);
```

```output
LI
Learn the DOM
null
```

`parentElement` is `null` because the element has not been added to the page yet.

---

## 3. Adding an Element: `append()` and `appendChild()`

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <ul id="list">
    <li>HTML</li>
    <li>CSS</li>
  </ul>
  <button id="addBtn">Add JavaScript</button>

  <script>
    const list = document.getElementById("list");

    document.getElementById("addBtn").addEventListener("click", () => {
      const item = document.createElement("li");
      item.textContent = "JavaScript";
      list.append(item);
    });
  </script>
</body>
</html>
```

| Method              | Notes                                                   |
| ------------------- | ------------------------------------------------------- |
| `append(...nodes)`  | Adds nodes or text at the **end**; accepts several items |
| `appendChild(node)` | Adds one node at the end; accepts only nodes (not plain text) |

---

## 4. Choosing the Position

| Method                | Where the new item goes                    |
| --------------------- | ------------------------------------------ |
| `parent.append(x)`    | Inside the parent, at the end              |
| `parent.prepend(x)`   | Inside the parent, at the start            |
| `element.before(x)`   | Just before the element (as a sibling)     |
| `element.after(x)`    | Just after the element (as a sibling)      |

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <ul id="steps">
    <li id="second">Step 2</li>
  </ul>

  <script>
    const steps = document.getElementById("steps");
    const second = document.getElementById("second");

    const first = document.createElement("li");
    first.textContent = "Step 1";
    steps.prepend(first);

    const third = document.createElement("li");
    third.textContent = "Step 3";
    second.after(third);

    const last = document.createElement("li");
    last.textContent = "Step 4";
    steps.append(last);
  </script>
</body>
</html>
```

The list now shows: Step 1, Step 2, Step 3, Step 4.

## 5. Inserting HTML Strings: `insertAdjacentHTML()`

When you want to add HTML written as a string, `insertAdjacentHTML()` is faster and safer than rebuilding with `innerHTML +=`.

```javascript
const box = document.querySelector("#box");

box.insertAdjacentHTML("beforeend", "<p>Added at the end</p>");
box.insertAdjacentHTML("afterbegin", "<p>Added at the start</p>");
```

| Position        | Meaning                                  |
| --------------- | ---------------------------------------- |
| `"beforebegin"` | Before the element itself                |
| `"afterbegin"`  | Inside the element, before its first child |
| `"beforeend"`   | Inside the element, after its last child |
| `"afterend"`    | After the element itself                 |

> ⚠️ **Warning:** Like `innerHTML`, `insertAdjacentHTML()` runs HTML from a string. Never use it with raw user input.

## 6. Removing Elements: `remove()`

`element.remove()` deletes an element from the page.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <div id="notice" style="background:#fef3c7; padding:12px; border-radius:8px;">
    Cookies are used on this site.
    <button id="closeBtn">Dismiss</button>
  </div>

  <script>
    const notice = document.getElementById("notice");

    document.getElementById("closeBtn").addEventListener("click", () => {
      notice.remove();
    });
  </script>
</body>
</html>
```

The older way is `parent.removeChild(child)`, which you may see in existing code.

```javascript
const list = document.querySelector("#list");
const first = list.firstElementChild;

list.removeChild(first);   // older style
// first.remove();         // modern style
```

## 7. Replacing and Cloning Elements

```javascript
const oldItem = document.querySelector("#old");
const newItem = document.createElement("li");
newItem.textContent = "Replacement";

oldItem.replaceWith(newItem);
```

`cloneNode()` makes a copy of an element.

```javascript
const card = document.querySelector(".card");

const shallow = card.cloneNode(false);   // only the element itself
const deep = card.cloneNode(true);       // the element and everything inside it

document.body.append(deep);
```

---

## 8. Removing All Children

To empty a container before filling it again:

```javascript
const list = document.querySelector("#list");

list.innerHTML = "";          // simple way
// list.replaceChildren();    // modern way
```

## 9. Rendering a List from an Array

A very common pattern is to turn array data into elements using a loop.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <ul id="courseList"></ul>

  <script>
    const courses = ["HTML", "CSS", "JavaScript", "Python"];
    const list = document.getElementById("courseList");

    courses.forEach(course => {
      const li = document.createElement("li");
      li.textContent = course;
      list.append(li);
    });
  </script>
</body>
</html>
```

---

## 10. `DocumentFragment` for Many Elements

Adding elements one by one makes the browser update the page every time. A **DocumentFragment** lets you build everything first and insert it **once**.

```javascript
const list = document.querySelector("#bigList");
const fragment = document.createDocumentFragment();

for (let i = 1; i <= 100; i++) {
  const li = document.createElement("li");
  li.textContent = `Item ${i}`;
  fragment.append(li);
}

list.append(fragment);
console.log(list.children.length);
```

```output
100
```

## Real-World Example 🌍

A simple to-do list. Type a task, click **Add**, and use **Delete** to remove it.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <input id="taskInput" type="text" placeholder="New task">
  <button id="addTask">Add</button>
  <ul id="tasks"></ul>

  <script>
    const input = document.getElementById("taskInput");
    const tasks = document.getElementById("tasks");

    document.getElementById("addTask").addEventListener("click", () => {
      const text = input.value.trim();
      if (text === "") return;

      const li = document.createElement("li");
      const span = document.createElement("span");
      span.textContent = text + " ";

      const deleteBtn = document.createElement("button");
      deleteBtn.textContent = "Delete";
      deleteBtn.addEventListener("click", () => li.remove());

      li.append(span, deleteBtn);
      tasks.append(li);

      input.value = "";
      input.focus();
    });
  </script>
</body>
</html>
```

## Common Mistakes

### Forgetting to Insert the Element

```javascript
const p = document.createElement("p");
p.textContent = "Hello";
// nothing appears, because p was never added to the page
```

Add it with `append()`, `prepend()`, `before()` or `after()`.

### Reusing the Same Element Instead of Creating New Ones

```javascript
const li = document.createElement("li");   // created once

for (const name of ["A", "B", "C"]) {
  li.textContent = name;
  list.append(li);          // moves the same element, so only one <li> remains
}
```

Create a new element **inside** the loop.

### Using `innerHTML +=` in a Loop

```javascript
for (const name of names) {
  list.innerHTML += `<li>${name}</li>`;   // rebuilds the whole list every time
}
```

Use `createElement()`, `append()` or a `DocumentFragment` instead.

### Removing an Element That Does Not Exist

```javascript
document.querySelector("#missing").remove();   // TypeError: null
```

Check that the element exists first.

---

## Key Points

* Create elements with `document.createElement("tag")`.
* A new element is invisible until you insert it into the page.
* Use `append()` and `prepend()` to add inside a parent, and `before()` and `after()` to add beside an element.
* `insertAdjacentHTML()` inserts an HTML string at a chosen position.
* `element.remove()` deletes an element from the page.
* `replaceWith()` swaps one element for another, and `cloneNode(true)` copies an element with its children.
* Create a new element for every item when looping.
* Use a `DocumentFragment` to add many elements efficiently.
* Prefer `textContent` over `innerHTML` when inserting user text.

# Chapter 7: The Document Object Model (DOM)

## Section 5: Events and Event Listeners

An **event** is something that happens on a web page: a click, a key press, a form submission or a page load. With **event listeners**, JavaScript can react to these events and run code when they happen.

---

## 1. What is an Event?

Every user action creates an event.

* Clicking a button
* Typing in an input box
* Moving the mouse over an image
* Submitting a form
* Finishing the loading of a page

To respond, you attach a **callback function** (called an **event handler**) to the element. The browser runs it each time the event occurs.

---

## 2. `addEventListener()`

The standard way to handle events is `addEventListener(eventType, handler)`.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <button id="greetBtn">Say Hello</button>
  <p id="message"></p>

  <script>
    const button = document.getElementById("greetBtn");

    button.addEventListener("click", function () {
      document.getElementById("message").textContent = "Hello from JavaScript!";
    });
  </script>
</body>
</html>
```

* `"click"` is the **event type**.
* The function is the **handler**. Pass it without parentheses so it runs later, not immediately.
* The same element can have **many** listeners for the same event.

---

## 3. Common Events

| Category   | Event                         | Fires when                               |
| ---------- | ----------------------------- | ---------------------------------------- |
| Mouse      | `click`                       | An element is clicked                    |
| Mouse      | `dblclick`                    | An element is double-clicked             |
| Mouse      | `mouseover` / `mouseout`      | The pointer enters / leaves an element   |
| Keyboard   | `keydown` / `keyup`           | A key is pressed / released              |
| Form       | `input`                       | The value of an input changes (every keystroke) |
| Form       | `change`                      | A value is committed (after leaving a field or selecting an option) |
| Form       | `submit`                      | A form is submitted                      |
| Form       | `focus` / `blur`              | An element gains / loses focus           |
| Page       | `DOMContentLoaded`            | The HTML has been fully loaded           |
| Page       | `load`                        | Everything (images, styles) has loaded   |
| Page       | `scroll` / `resize`           | The page is scrolled / the window resized |

---

## 4. Using Named Functions

Instead of writing the function inline, you can define it separately and reuse it.

```javascript
function showMessage() {
  console.log("Button clicked!");
}

const button = document.querySelector("#btn");
button.addEventListener("click", showMessage);   // no parentheses
```

```output
Button clicked!
```

The output appears each time the button is clicked. An arrow function works just as well:

```javascript
button.addEventListener("click", () => console.log("Clicked with an arrow function"));
```

---

## 5. The Event Object

The browser passes an **event object** to the handler. It describes what happened.

| Property / Method        | Description                                          |
| ------------------------ | ---------------------------------------------------- |
| `event.type`             | The event name, such as `"click"`                    |
| `event.target`           | The element that **triggered** the event             |
| `event.currentTarget`    | The element the **listener is attached to**          |
| `event.preventDefault()` | Stops the browser's default action                   |
| `event.stopPropagation()`| Stops the event from reaching parent elements        |
| `event.key`              | The key pressed (keyboard events)                    |
| `event.clientX / clientY`| Mouse position in the window (mouse events)          |

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <button id="infoBtn">Click me</button>
  <pre id="info"></pre>

  <script>
    document.getElementById("infoBtn").addEventListener("click", event => {
      document.getElementById("info").textContent =
        "type: " + event.type + "\n" +
        "target: " + event.target.tagName + "\n" +
        "x: " + event.clientX + ", y: " + event.clientY;
    });
  </script>
</body>
</html>
```

## 6. Keyboard Events

Use `keydown` to react to key presses. `event.key` tells you which key was pressed.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <input id="searchBox" type="text" placeholder="Type here and press Enter">
  <p id="keyInfo"></p>

  <script>
    const box = document.getElementById("searchBox");

    box.addEventListener("keydown", event => {
      if (event.key === "Enter") {
        document.getElementById("keyInfo").textContent =
          "You searched for: " + box.value;
      }
    });
  </script>
</body>
</html>
```

Common values of `event.key`: `"Enter"`, `"Escape"`, `"ArrowUp"`, `"ArrowDown"`, `" "` (space) and letters such as `"a"`.

---

## 7. The `input` Event: Live Updates

`input` fires on **every change**, so it is perfect for live previews and character counters.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <textarea id="bio" rows="3" cols="30" maxlength="100" placeholder="Write your bio"></textarea>
  <p>Characters: <span id="count">0</span> / 100</p>

  <script>
    const bio = document.getElementById("bio");
    const count = document.getElementById("count");

    bio.addEventListener("input", () => {
      count.textContent = bio.value.length;
    });
  </script>
</body>
</html>
```

## 8. Mouse Events

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <div id="hoverBox" style="width:220px; padding:24px; text-align:center; background:#e2e8f0; border-radius:10px;">
    Hover over me
  </div>

  <script>
    const box = document.getElementById("hoverBox");

    box.addEventListener("mouseover", () => {
      box.style.background = "#bbf7d0";
      box.textContent = "Mouse is over me!";
    });

    box.addEventListener("mouseout", () => {
      box.style.background = "#e2e8f0";
      box.textContent = "Hover over me";
    });
  </script>
</body>
</html>
```

## 9. Preventing Default Behavior

Some elements have built-in behavior: a link opens a page and a form reloads the page when submitted. `event.preventDefault()` cancels it.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <form id="loginForm">
    <input id="username" type="text" placeholder="Username">
    <button type="submit">Log In</button>
  </form>
  <p id="status"></p>

  <script>
    document.getElementById("loginForm").addEventListener("submit", event => {
      event.preventDefault();   // stop the page from reloading

      const name = document.getElementById("username").value.trim();
      document.getElementById("status").textContent =
        name ? "Welcome, " + name + "!" : "Please enter a username.";
    });
  </script>
</body>
</html>
```

## 10. Removing an Event Listener

`removeEventListener()` needs the **same function reference** that was added. Anonymous functions cannot be removed, so use a named function.

```javascript
function onClick() {
  console.log("Clicked");
}

const button = document.querySelector("#btn");

button.addEventListener("click", onClick);
button.removeEventListener("click", onClick);
```

To run a handler only **once**, use the `once` option:

```javascript
button.addEventListener("click", () => {
  console.log("This runs only on the first click");
}, { once: true });
```

```output
This runs only on the first click
```

## 11. Event Listeners on Multiple Elements

`querySelectorAll()` returns several elements, so loop over them and attach a listener to each.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <button class="tab">HTML</button>
  <button class="tab">CSS</button>
  <button class="tab">JavaScript</button>
  <p id="selected">Selected: none</p>

  <script>
    const tabs = document.querySelectorAll(".tab");

    tabs.forEach(tab => {
      tab.addEventListener("click", () => {
        document.getElementById("selected").textContent =
          "Selected: " + tab.textContent;
      });
    });
  </script>
</body>
</html>
```

> **Tip:** Chapter 8 introduces **event delegation**, a technique that handles many elements with a single listener.

---

## 12. A Quick Look at Event Bubbling

When you click an element, the event first runs on that element and then **bubbles up** through its parents.

```text
Click on <button>
   → button handlers run
   → div handlers run
   → body handlers run
   → document handlers run
```

This is why `event.target` (the clicked element) and `event.currentTarget` (the element with the listener) can be different. You will study bubbling in detail in Chapter 8.

---

## 13. Why Avoid Inline Event Attributes?

You may see events written directly inside HTML:

```html
<button onclick="sayHi()">Click</button>
```

This works, but it mixes HTML with JavaScript and allows only one handler per event. Prefer `addEventListener()`, which keeps your code organized and lets you attach multiple handlers.

## Real-World Example

A counter with **+**, **−** and **Reset** buttons that never goes below zero:

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px; text-align:center;">
  <h2>Counter: <span id="value">0</span></h2>
  <button id="minus">−</button>
  <button id="reset">Reset</button>
  <button id="plus">+</button>

  <script>
    let count = 0;
    const value = document.getElementById("value");

    function render() {
      value.textContent = count;
    }

    document.getElementById("plus").addEventListener("click", () => {
      count++;
      render();
    });

    document.getElementById("minus").addEventListener("click", () => {
      if (count > 0) count--;
      render();
    });

    document.getElementById("reset").addEventListener("click", () => {
      count = 0;
      render();
    });
  </script>
</body>
</html>
```

## Common Mistakes

### Calling the Function Instead of Passing It

```javascript
button.addEventListener("click", showMessage());   // runs immediately, wrong
button.addEventListener("click", showMessage);     // runs on click, correct
```

### Using `on` in the Event Name

```javascript
button.addEventListener("onclick", handler);   // wrong
button.addEventListener("click", handler);     // correct
```

### Forgetting `preventDefault()` on Forms

Without it, the form submits and the page reloads, so your JavaScript result disappears.

### Trying to Remove an Anonymous Function

```javascript
button.addEventListener("click", () => console.log("Hi"));
button.removeEventListener("click", () => console.log("Hi"));   // does nothing
```

Use a named function stored in a variable.

### Adding a Listener to `null`

```javascript
document.querySelector("#missing").addEventListener("click", handler);   // TypeError
```

Check that the element exists, and make sure the script runs after the element is loaded.

### Confusing `change` and `input`

`input` fires on every keystroke. `change` fires only after the user finishes editing, such as when the field loses focus.

---

## Key Points

* An event is something that happens on the page, such as a click or key press.
* `addEventListener(type, handler)` is the standard way to respond to events.
* Pass the handler function without parentheses.
* The handler receives an **event object** with details such as `type`, `target` and `key`.
* `event.preventDefault()` stops default behavior, such as a form submitting.
* `keydown`, `input`, `submit`, `mouseover` and `DOMContentLoaded` are widely used events.
* Use `removeEventListener()` with a named function, or the `{ once: true }` option.
* Loop over `querySelectorAll()` results to add listeners to many elements.
* Events bubble up from the target element to its parents.
* Prefer `addEventListener()` over inline `onclick` attributes.

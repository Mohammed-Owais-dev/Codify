# Chapter 7: The Document Object Model (DOM)

## Section 2: Selecting HTML Elements

Before you can change an element, you must **select** it. JavaScript gives you several methods to find elements in the DOM. The most useful ones are `getElementById()`, `querySelector()` and `querySelectorAll()`.

---

## 1. Sample HTML

The examples in this section use this page structure:

```html
<h1 id="title">Codify</h1>
<p class="note">First note</p>
<p class="note">Second note</p>
<ul id="menu">
  <li>Home</li>
  <li class="active">Courses</li>
  <li>Contact</li>
</ul>
```

---

## 2. `getElementById()`

Finds **one** element using its `id`. The `id` is written without `#`.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <h1 id="title">Codify</h1>
  <p id="result"></p>

  <script>
    const title = document.getElementById("title");
    document.getElementById("result").textContent =
      "Found: " + title.textContent;
  </script>
</body>
</html>
```

If no element has that `id`, the method returns `null`.

---

## 3. `getElementsByClassName()` and `getElementsByTagName()`

These older methods return **several** elements as an `HTMLCollection`.

```javascript
const notes = document.getElementsByClassName("note");
const items = document.getElementsByTagName("li");

console.log(notes.length);
console.log(items.length);
console.log(notes[0].textContent);
```

```output
2
3
First note
```

* Items are accessed by index, starting from `0`.
* The result is **live**: if the page changes, the collection updates automatically.

---

## 4. `querySelector()`

Finds the **first** element that matches a **CSS selector**.

```javascript
const heading = document.querySelector("#title");
const firstNote = document.querySelector(".note");
const activeItem = document.querySelector("#menu .active");

console.log(heading.textContent);
console.log(firstNote.textContent);
console.log(activeItem.textContent);
```

```output
Codify
First note
Courses
```

If nothing matches, `querySelector()` returns `null`.

---

## 5. `querySelectorAll()`

Finds **all** elements that match a CSS selector and returns a `NodeList`.

```javascript
const notes = document.querySelectorAll(".note");
const items = document.querySelectorAll("#menu li");

console.log(notes.length);
console.log(items.length);

items.forEach(item => console.log(item.textContent));
```

```output
2
3
Home
Courses
Contact
```

If nothing matches, it returns an **empty** NodeList (never `null`).

---

## 6. CSS Selector Cheat Sheet

`querySelector()` and `querySelectorAll()` accept any CSS selector.

| Selector              | Selects                                         |
| --------------------- | ----------------------------------------------- |
| `"p"`                 | All `<p>` elements                              |
| `"#title"`            | The element with `id="title"`                   |
| `".note"`             | Elements with `class="note"`                    |
| `"ul li"`             | `<li>` elements inside a `<ul>`                 |
| `"ul > li"`           | `<li>` elements that are direct children of `<ul>` |
| `"li:first-child"`    | The first `<li>` of its parent                  |
| `"li:nth-child(2)"`   | The second `<li>` of its parent                 |
| `"input[type='text']"`| Inputs with `type="text"`                       |
| `"h1, h2"`            | All `<h1>` and `<h2>` elements                  |

---

## 7. Which Method Should You Use?

| Method                      | Returns            | Live? | Best For                   |
| --------------------------- | ------------------ | ----- | -------------------------- |
| `getElementById()`          | One element / `null` | –   | Elements with an `id`      |
| `getElementsByClassName()`  | HTMLCollection     | Yes   | Simple class lookups       |
| `getElementsByTagName()`    | HTMLCollection     | Yes   | Simple tag lookups         |
| `querySelector()`           | One element / `null` | –   | Any CSS selector, first match |
| `querySelectorAll()`        | NodeList           | No    | Any CSS selector, all matches |

> **Tip:** In modern JavaScript, `getElementById()` and `querySelector()` / `querySelectorAll()` cover almost every need.

## 8. Looping Over Selected Elements

A `NodeList` from `querySelectorAll()` supports `forEach()` and `for...of`.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <p class="note">First note</p>
  <p class="note">Second note</p>
  <p class="note">Third note</p>

  <script>
    const notes = document.querySelectorAll(".note");

    notes.forEach((note, index) => {
      note.textContent = `Note ${index + 1} (updated)`;
      note.style.color = "teal";
    });
  </script>
</body>
</html>
```

An `HTMLCollection` does **not** have `forEach()`. Convert it first:

```javascript
const items = document.getElementsByTagName("li");

Array.from(items).forEach(item => console.log(item.textContent));
[...items].map(item => item.textContent.toUpperCase());
```

---

## 9. Selecting Inside an Element

You can call `querySelector()` on any element to search only **inside** it.

```javascript
const menu = document.getElementById("menu");

const active = menu.querySelector(".active");
const links = menu.querySelectorAll("li");

console.log(active.textContent);
console.log(links.length);
```

```output
Courses
3
```

---

## 10. Checking Whether an Element Exists

Always check for `null` when an element might be missing.

```javascript
const banner = document.querySelector("#banner");

if (banner) {
  banner.textContent = "Welcome!";
} else {
  console.log("Banner not found");
}
```

```output
Banner not found
```

---

## 11. `closest()` and `matches()`

Two helpful methods for working with selectors on an element you already have:

```javascript
const item = document.querySelector("#menu .active");

console.log(item.closest("ul").id);
console.log(item.matches(".active"));
console.log(item.matches(".hidden"));
```

```output
menu
true
false
```

* `closest(selector)` goes **up** the tree and returns the nearest matching ancestor (or the element itself).
* `matches(selector)` returns `true` or `false`.

## Real-World Example

Highlight every course card whose level is "Beginner":

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <ul id="courses">
    <li data-level="Beginner">HTML Basics</li>
    <li data-level="Advanced">Node.js</li>
    <li data-level="Beginner">CSS Basics</li>
    <li data-level="Intermediate">JavaScript</li>
  </ul>

  <script>
    const beginnerCourses = document.querySelectorAll(
      "#courses li[data-level='Beginner']"
    );

    beginnerCourses.forEach(course => {
      course.style.background = "#d1fae5";
      course.style.padding = "4px";
    });
  </script>
</body>
</html>
```

## Common Mistakes

### Forgetting `#` or `.` in `querySelector()`

```javascript
document.querySelector("title");     // selects the <title> tag
document.querySelector("#title");    // selects id="title"
document.querySelector(".note");     // selects class="note"
```

### Adding `#` in `getElementById()`

```javascript
document.getElementById("#title");   // wrong, returns null
document.getElementById("title");    // correct
```

### Using `querySelector()` When You Need All Elements

```javascript
document.querySelector(".note");      // only the first match
document.querySelectorAll(".note");   // all matches
```

### Using an Element Without Checking for `null`

```javascript
const box = document.querySelector("#box");
box.textContent = "Hi";    // TypeError if #box does not exist
```

### Calling Array Methods on an HTMLCollection

`getElementsByClassName()` returns an HTMLCollection, so `map()` and `forEach()` are not available. Use `querySelectorAll()` or `Array.from()`.

---

## Key Points

* Selecting an element is the first step before changing it.
* `getElementById("id")` returns one element or `null`.
* `querySelector(selector)` returns the first match or `null`.
* `querySelectorAll(selector)` returns a NodeList of all matches.
* `getElementsByClassName()` and `getElementsByTagName()` return live HTMLCollections.
* NodeLists support `forEach()`; HTMLCollections do not.
* Use `Array.from()` or the spread operator to convert collections to arrays.
* You can call `querySelector()` on an element to search inside it.
* Always check for `null` before using a selected element.

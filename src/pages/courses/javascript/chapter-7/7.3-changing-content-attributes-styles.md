# Chapter 7: The Document Object Model (DOM)

## Section 3: Changing Content, Attributes and Styles

Once you have selected an element, you can change what it shows, how it is described and how it looks. This is what makes web pages interactive.

---

## 1. Changing Text with `textContent`

`textContent` reads or replaces the **text** inside an element.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <h2 id="heading">Old Title</h2>
  <button id="btn">Change Title</button>

  <script>
    const heading = document.getElementById("heading");

    document.getElementById("btn").addEventListener("click", () => {
      heading.textContent = "New Title";
    });
  </script>
</body>
</html>
```

You can also read the current text:

```javascript
const heading = document.querySelector("#heading");
console.log(heading.textContent);
```

```output
Old Title
```

---

## 2. Changing HTML with `innerHTML`

`innerHTML` reads or replaces the **HTML** inside an element, so tags are interpreted.

```javascript
const box = document.querySelector("#box");

box.innerHTML = "<strong>Bold</strong> and <em>italic</em> text";
console.log(box.innerHTML);
```

```output
<strong>Bold</strong> and <em>italic</em> text
```

### `textContent` vs `innerHTML`

```javascript
const box = document.querySelector("#box");

box.textContent = "<b>Hello</b>";   // shows the tags as plain text: <b>Hello</b>
box.innerHTML = "<b>Hello</b>";      // shows Hello in bold
```

| Property      | Treats the value as | Use it for                     |
| ------------- | ------------------- | ------------------------------ |
| `textContent` | Plain text          | Showing text safely            |
| `innerHTML`   | HTML code           | Inserting your own HTML markup |
| `innerText`   | Visible text only   | Reading text as the user sees it |

> **Warning:** Never put text typed by a user directly into `innerHTML`. An attacker could insert a `<script>` or an `onerror` attribute and run malicious code (an **XSS attack**). Use `textContent` for user-provided text.

## 3. Reading and Changing Attributes

Attributes are the values written inside a tag, such as `src`, `href` and `alt`.

| Method                           | Purpose                       |
| -------------------------------- | ----------------------------- |
| `getAttribute(name)`             | Reads an attribute            |
| `setAttribute(name, value)`      | Adds or changes an attribute  |
| `hasAttribute(name)`             | Checks whether it exists      |
| `removeAttribute(name)`          | Removes an attribute          |

```javascript
const link = document.querySelector("#docs");

console.log(link.getAttribute("href"));

link.setAttribute("href", "https://developer.mozilla.org");
link.setAttribute("target", "_blank");

console.log(link.getAttribute("href"));
console.log(link.hasAttribute("target"));

link.removeAttribute("target");
console.log(link.hasAttribute("target"));
```

```output
https://example.com
https://developer.mozilla.org
true
false
```

---

## 4. Attributes as Properties

Many attributes are also available directly as **properties** of the element.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <input id="nameInput" type="text" placeholder="Enter name">
  <button id="fillBtn">Fill and Disable</button>

  <script>
    const input = document.getElementById("nameInput");

    document.getElementById("fillBtn").addEventListener("click", () => {
      input.value = "Asha";
      input.disabled = true;
      input.placeholder = "Locked";
    });
  </script>
</body>
</html>
```

Common properties: `id`, `src`, `href`, `alt`, `title`, `value`, `checked`, `disabled`.

> **Tip:** Use properties such as `value`, `checked` and `disabled` for form controls. They reflect the **current** state, while attributes show the starting value in the HTML.

## 5. Working with CSS Classes: `classList`

The best way to change how an element looks is to add or remove **CSS classes**.

| Method                   | Purpose                                       |
| ------------------------ | --------------------------------------------- |
| `classList.add("a")`     | Adds a class                                  |
| `classList.remove("a")`  | Removes a class                               |
| `classList.toggle("a")`  | Adds the class if missing, removes it if present |
| `classList.contains("a")`| Checks whether the class exists               |
| `classList.replace("a","b")` | Replaces one class with another           |

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    .card { padding: 16px; border: 2px solid #94a3b8; border-radius: 8px; font-family: Arial, sans-serif; }
    .highlight { background: #fef08a; border-color: #ca8a04; }
  </style>
</head>
<body style="padding: 20px;">
  <div id="card" class="card">Click the button to toggle highlight.</div>
  <br>
  <button id="toggleBtn">Toggle Highlight</button>

  <script>
    const card = document.getElementById("card");

    document.getElementById("toggleBtn").addEventListener("click", () => {
      card.classList.toggle("highlight");
    });
  </script>
</body>
</html>
```

```javascript
const card = document.querySelector("#card");

card.classList.add("highlight");
console.log(card.classList.contains("highlight"));
console.log(card.className);

card.classList.remove("highlight");
console.log(card.classList.contains("highlight"));
```

```output
true
card highlight
false
```

## 6. Changing Styles with `style`

Every element has a `style` property for **inline** styles. CSS property names written with a hyphen become **camelCase**.

| CSS Property        | JavaScript Property        |
| ------------------- | -------------------------- |
| `background-color`  | `style.backgroundColor`    |
| `font-size`         | `style.fontSize`           |
| `border-radius`     | `style.borderRadius`       |
| `margin-top`        | `style.marginTop`          |

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <p id="text">Style me with JavaScript!</p>
  <button id="styleBtn">Apply Styles</button>

  <script>
    const text = document.getElementById("text");

    document.getElementById("styleBtn").addEventListener("click", () => {
      text.style.color = "white";
      text.style.backgroundColor = "#0f766e";
      text.style.padding = "12px";
      text.style.fontSize = "20px";
      text.style.borderRadius = "8px";
    });
  </script>
</body>
</html>
```

Values are always **strings** and need units: `"20px"`, not `20`.

---

## 7. Reading the Final Style: `getComputedStyle()`

`element.style` only shows **inline** styles. To read the style the browser actually applies (from CSS files too), use `getComputedStyle()`.

```javascript
const title = document.querySelector("h1");
const styles = getComputedStyle(title);

console.log(styles.color);
console.log(styles.fontSize);
```

```output
rgb(15, 23, 42)
32px
```

---

## 8. Custom Data with `dataset`

Attributes that start with `data-` store custom information. Read them through `dataset`.

```javascript
// <button id="buy" data-product-id="42" data-price="499">Buy</button>

const button = document.querySelector("#buy");

console.log(button.dataset.productId);
console.log(button.dataset.price);

button.dataset.price = "399";
console.log(button.getAttribute("data-price"));
```

```output
42
499
399
```

`data-product-id` becomes `dataset.productId` (hyphens turn into camelCase).

## 9. Showing and Hiding Elements

Two common ways to hide an element:

```javascript
const panel = document.querySelector("#panel");

panel.style.display = "none";     // hide
panel.style.display = "block";    // show

panel.hidden = true;              // hide using the hidden attribute
panel.hidden = false;             // show
```

A cleaner approach is to toggle a class such as `.hidden { display: none; }`.

## Real-World Example

A dark-mode switch that changes the page class and the button label:

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    body { font-family: Arial, sans-serif; padding: 20px; background: #ffffff; color: #0f172a; transition: 0.2s; }
    body.dark { background: #0f172a; color: #f8fafc; }
  </style>
</head>
<body>
  <h2>Codify Reader</h2>
  <p>Learn JavaScript one topic at a time.</p>
  <button id="themeBtn">Enable Dark Mode</button>

  <script>
    const btn = document.getElementById("themeBtn");

    btn.addEventListener("click", () => {
      document.body.classList.toggle("dark");

      const isDark = document.body.classList.contains("dark");
      btn.textContent = isDark ? "Enable Light Mode" : "Enable Dark Mode";
    });
  </script>
</body>
</html>
```

## Common Mistakes

### Using `innerHTML` with User Input

```javascript
output.innerHTML = userInput;       // risky
output.textContent = userInput;     // safe
```

### Writing CSS Property Names with Hyphens

```javascript
box.style.background-color = "red";    // SyntaxError
box.style.backgroundColor = "red";     // correct
```

### Forgetting Units in Styles

```javascript
box.style.width = 200;       // ignored
box.style.width = "200px";   // correct
```

### Using a Dot in `classList` Methods

```javascript
box.classList.add(".active");    // wrong, adds a class named ".active"
box.classList.add("active");     // correct
```

### Expecting `style` to Show CSS File Values

`element.style.color` is empty if the color was set in a stylesheet. Use `getComputedStyle()` instead.

---

## Key Points

* `textContent` changes plain text and is safe for user input.
* `innerHTML` changes HTML markup but is unsafe with untrusted input.
* Use `getAttribute()`, `setAttribute()`, `hasAttribute()` and `removeAttribute()` for attributes.
* Form properties such as `value`, `checked` and `disabled` can be set directly.
* `classList` with `add`, `remove`, `toggle` and `contains` is the best way to change appearance.
* `element.style` sets inline styles using camelCase names and string values with units.
* `getComputedStyle()` reads the styles that are actually applied.
* `dataset` reads and writes `data-*` attributes.
* Prefer toggling CSS classes over writing many inline styles.

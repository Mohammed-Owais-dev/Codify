# Chapter 8: Forms, Validation and Browser Storage

## Section 5: Timers and Browser Dialogs

JavaScript can run code **after a delay** or **repeatedly** using timers. It can also show simple pop-up boxes, called **dialogs**, to inform or ask the user something. This section covers both.

---

## 1. Timers

The browser provides two main timer functions.

| Function                       | Runs the callback                      |
| ------------------------------ | -------------------------------------- |
| `setTimeout(callback, delay)`  | **Once**, after `delay` milliseconds   |
| `setInterval(callback, delay)` | **Repeatedly**, every `delay` milliseconds |

Time is measured in **milliseconds**: `1000` ms = 1 second.

> **Tip:** Chapter 9 explores timers and asynchronous code in depth. Here you learn the essentials for building interactive pages.

---

## 2. `setTimeout()`

```javascript
console.log("Start");

setTimeout(() => {
  console.log("This runs after 2 seconds");
}, 2000);

console.log("End");
```

```output
Start
End
This runs after 2 seconds
```

JavaScript does not wait for the timer. It continues with the next line, and runs the callback when the time is up.

---

## 3. Passing Arguments to a Timer

Extra arguments after the delay are given to the callback.

```javascript
function greet(name, city) {
  console.log(`Hello ${name} from ${city}`);
}

setTimeout(greet, 1000, "Asha", "Hyderabad");
```

```output
Hello Asha from Hyderabad
```

You can also wrap the call in an arrow function: `setTimeout(() => greet("Asha", "Hyderabad"), 1000)`.

---

## 4. Cancelling with `clearTimeout()`

`setTimeout()` returns an **ID**. Pass it to `clearTimeout()` to cancel the timer before it runs.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <button id="startBtn">Show message in 3 seconds</button>
  <button id="cancelBtn">Cancel</button>
  <p id="msg"></p>

  <script>
    let timerId;
    const msg = document.getElementById("msg");

    document.getElementById("startBtn").addEventListener("click", () => {
      msg.textContent = "Waiting...";
      timerId = setTimeout(() => {
        msg.textContent = "Hello! 3 seconds have passed.";
      }, 3000);
    });

    document.getElementById("cancelBtn").addEventListener("click", () => {
      clearTimeout(timerId);
      msg.textContent = "Cancelled.";
    });
  </script>
</body>
</html>
```

---

## 5. `setInterval()`

`setInterval()` repeats the callback until you stop it.

```javascript
let count = 0;

const id = setInterval(() => {
  count++;
  console.log("Tick " + count);

  if (count === 3) {
    clearInterval(id);
    console.log("Stopped");
  }
}, 1000);
```

```output
Tick 1
Tick 2
Tick 3
Stopped
```

An interval keeps running **forever** unless you call `clearInterval()` with its ID.

---

## 6. A Live Clock

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px; text-align:center;">
  <h2 id="clock" style="font-size:40px;"></h2>

  <script>
    const clock = document.getElementById("clock");

    function showTime() {
      clock.textContent = new Date().toLocaleTimeString();
    }

    showTime();                   // show immediately, without waiting a second
    setInterval(showTime, 1000);  // then update every second
  </script>
</body>
</html>
```

## 7. `setTimeout` vs `setInterval`

| Feature        | `setTimeout`                | `setInterval`                |
| -------------- | --------------------------- | ---------------------------- |
| Runs           | Once                        | Repeatedly                   |
| Cancel with    | `clearTimeout(id)`          | `clearInterval(id)`          |
| Typical use    | Delayed messages, debounce  | Clocks, countdowns, slideshows |

## 8. Delaying a Search (Debounce)

Running a search on **every keystroke** is wasteful. **Debouncing** waits until the user stops typing for a moment.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <input id="search" type="text" placeholder="Type to search">
  <p id="result">Results will appear here</p>

  <script>
    let timer;
    const search = document.getElementById("search");

    search.addEventListener("input", () => {
      clearTimeout(timer);                 // cancel the previous timer

      timer = setTimeout(() => {
        document.getElementById("result").textContent =
          "Searching for: " + search.value;
      }, 500);                             // run only after 500 ms of silence
    });
  </script>
</body>
</html>
```

Each keystroke cancels the old timer and starts a new one, so the search runs only once the user pauses.

## 9. Browser Dialogs

JavaScript has three built-in dialog boxes. They are methods of the `window` object, so `window.alert()` and `alert()` are the same.

| Dialog      | Purpose                               | Returns                          |
| ----------- | ------------------------------------- | -------------------------------- |
| `alert()`   | Shows a message with an OK button     | Nothing (`undefined`)            |
| `confirm()` | Asks a yes/no question                | `true` (OK) or `false` (Cancel)  |
| `prompt()`  | Asks the user to type a value         | A string, or `null` if cancelled |

> **Warning:** Dialogs **block** the page until the user responds, and many embedded previews disable them. Run the examples in this section from your own HTML file or in the browser console.

---

## 10. `alert()`

```javascript
alert("Welcome to Codify!");
```

```output
(A pop-up appears showing: Welcome to Codify!)
```

Use `alert()` only for simple messages or quick debugging.

---

## 11. `confirm()`

`confirm()` lets the user choose **OK** or **Cancel**.

```javascript
const sure = confirm("Delete this file?");

if (sure) {
  console.log("File deleted");
} else {
  console.log("Deletion cancelled");
}
```

```output
File deleted
```

The output shown is for a click on **OK**. Clicking **Cancel** prints `Deletion cancelled`.

---

## 12. `prompt()`

`prompt(message, defaultValue)` asks for text.

```javascript
const name = prompt("What is your name?", "Guest");

if (name === null) {
  console.log("User cancelled");
} else if (name.trim() === "") {
  console.log("No name entered");
} else {
  console.log("Hello, " + name + "!");
}
```

```output
Hello, Asha!
```

This is the output when the user types `Asha` and clicks **OK**.

* **OK** with text → the text (a **string**).
* **OK** with an empty box → an empty string `""`.
* **Cancel** → `null`.

Since `prompt()` always returns a string, convert numbers with `Number()`.

## 13. The `<dialog>` Element: A Modern Alternative

The HTML `<dialog>` element creates a pop-up that you can **style yourself** and that does not freeze the page.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <button id="openBtn">Delete account</button>
  <p id="answer"></p>

  <dialog id="confirmDialog" style="border-radius:10px; padding:20px;">
    <p>Are you sure you want to delete your account?</p>
    <button id="yesBtn">Yes, delete</button>
    <button id="noBtn">Cancel</button>
  </dialog>

  <script>
    const dialog = document.getElementById("confirmDialog");
    const answer = document.getElementById("answer");

    document.getElementById("openBtn").addEventListener("click", () => dialog.showModal());

    document.getElementById("yesBtn").addEventListener("click", () => {
      answer.textContent = "Account deleted.";
      dialog.close();
    });

    document.getElementById("noBtn").addEventListener("click", () => {
      answer.textContent = "Cancelled.";
      dialog.close();
    });
  </script>
</body>
</html>
```

| Method / Event      | Purpose                                         |
| ------------------- | ----------------------------------------------- |
| `dialog.showModal()`| Opens the dialog and dims the rest of the page  |
| `dialog.close()`    | Closes the dialog                               |
| `close` event       | Fires when the dialog is closed                 |

The `Esc` key closes a modal dialog automatically.

## 14. Other Browser Window Features


These values depend on your browser and page.

* `window.innerWidth` / `innerHeight` give the size of the viewport.
* `window.location` describes the page address.
* `window.scrollTo()` scrolls the page.

## Real-World Example

A countdown timer that stops by itself and can be paused:

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px; text-align:center;">
  <h2>Quiz Timer</h2>
  <p id="time" style="font-size:48px; margin:10px;">10</p>
  <button id="startBtn">Start</button>
  <button id="pauseBtn">Pause</button>
  <button id="resetBtn">Reset</button>
  <p id="note"></p>

  <script>
    const START = 10;
    let secondsLeft = START;
    let intervalId = null;

    const timeEl = document.getElementById("time");
    const note = document.getElementById("note");

    function stop() {
      clearInterval(intervalId);
      intervalId = null;
    }

    document.getElementById("startBtn").addEventListener("click", () => {
      if (intervalId !== null || secondsLeft === 0) return;   // avoid duplicate timers

      note.textContent = "";
      intervalId = setInterval(() => {
        secondsLeft--;
        timeEl.textContent = secondsLeft;

        if (secondsLeft === 0) {
          stop();
          note.textContent = "Time's up!";
        }
      }, 1000);
    });

    document.getElementById("pauseBtn").addEventListener("click", stop);

    document.getElementById("resetBtn").addEventListener("click", () => {
      stop();
      secondsLeft = START;
      timeEl.textContent = START;
      note.textContent = "";
    });
  </script>
</body>
</html>
```

## Common Mistakes

### Calling the Function Instead of Passing It

```javascript
setTimeout(showMessage(), 1000);    // runs immediately
setTimeout(showMessage, 1000);      // runs after 1 second
```

### Forgetting That Time Is in Milliseconds

```javascript
setTimeout(done, 3);       // 3 milliseconds
setTimeout(done, 3000);    // 3 seconds
```

### Not Clearing an Interval

An interval keeps running (and using memory) forever. Save its ID and call `clearInterval()` when finished.

### Starting Multiple Intervals

Clicking a **Start** button three times creates three intervals running at once. Check whether one is already running before starting a new one.

### Expecting Code After a Timer to Wait

```javascript
let value;
setTimeout(() => { value = 42; }, 1000);
console.log(value);    // undefined, the timer has not run yet
```

### Treating `prompt()` Output as a Number

```javascript
const age = prompt("Age?");     // "25" (a string)
console.log(age + 1);           // "251"
console.log(Number(age) + 1);   // 26
```

### Overusing Dialogs

`alert()`, `confirm()` and `prompt()` freeze the page and look basic. For real projects, prefer the `<dialog>` element or messages shown on the page.

---

## Key Points

* `setTimeout(callback, delay)` runs code once after a delay in milliseconds.
* `setInterval(callback, delay)` runs code repeatedly.
* Both return an ID, which you pass to `clearTimeout()` or `clearInterval()` to cancel them.
* Timers do not pause the rest of your code.
* Debouncing uses `clearTimeout()` to wait until the user stops typing.
* `alert()` shows a message, `confirm()` returns `true` or `false`, and `prompt()` returns a string or `null`.
* Dialogs block the page until the user responds.
* The `<dialog>` element with `showModal()` and `close()` is a modern, stylable alternative.
* Always stop intervals that are no longer needed.

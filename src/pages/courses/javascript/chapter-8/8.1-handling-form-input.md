# Chapter 8: Forms, Validation and Browser Storage

## Section 1: Handling Form Input

Forms are how users send information to a web page: names, emails, passwords, choices and messages. JavaScript can read what the user typed, react to it and process it **without reloading the page**.

---

## 1. A Simple Form

Here is a basic HTML form. Every field has a `name` or `id` so that JavaScript can find it.

```html
<form id="contactForm">
  <input type="text" id="username" name="username" placeholder="Your name">
  <input type="email" id="email" name="email" placeholder="Your email">
  <button type="submit">Send</button>
</form>
```

The form fires a **`submit`** event when the user clicks the submit button or presses `Enter` in a field.

---

## 2. Reading Input Values

The `value` property holds what the user typed. It is **always a string**.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <input id="nameInput" type="text" placeholder="Enter your name">
  <button id="showBtn">Show</button>
  <p id="output"></p>

  <script>
    const nameInput = document.getElementById("nameInput");

    document.getElementById("showBtn").addEventListener("click", () => {
      document.getElementById("output").textContent =
        "Hello, " + nameInput.value + "!";
    });
  </script>
</body>
</html>
```

> **Tip:** Use `value.trim()` to remove extra spaces from the start and end of what the user typed.

---

## 3. Handling the `submit` Event

By default, submitting a form reloads the page. Call `event.preventDefault()` to stop that and handle the data yourself.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <form id="loginForm">
    <input id="user" type="text" placeholder="Username">
    <button type="submit">Log In</button>
  </form>
  <p id="msg"></p>

  <script>
    const form = document.getElementById("loginForm");

    form.addEventListener("submit", event => {
      event.preventDefault();

      const user = document.getElementById("user").value.trim();
      document.getElementById("msg").textContent =
        user ? "Welcome, " + user + "!" : "Please type a username.";
    });
  </script>
</body>
</html>
```

Always listen to the **form's** `submit` event, not the button's `click`. That way the `Enter` key works as well.

## 4. Different Input Types

Each kind of control stores its data in a slightly different way.

| Control              | Property to read         | Returns                    |
| -------------------- | ------------------------ | -------------------------- |
| Text, email, password| `value`                  | String                     |
| `<textarea>`         | `value`                  | String                     |
| `<select>`           | `value`                  | Value of the chosen option |
| Checkbox             | `checked`                | `true` or `false`          |
| Radio button         | `checked` (find the chosen one) | `true` or `false`   |
| Number input         | `value` or `valueAsNumber` | String / Number          |

---

## 5. Checkboxes

Use `checked` to know whether a checkbox is ticked.

```javascript
// <input type="checkbox" id="terms">
const terms = document.querySelector("#terms");

console.log(terms.checked);
terms.checked = true;
console.log(terms.checked);
```

```output
false
true
```

For a group of checkboxes, select them all and keep the ticked ones:

```javascript
// <input type="checkbox" name="hobby" value="Music"> ...
const ticked = [...document.querySelectorAll("input[name='hobby']:checked")]
  .map(box => box.value);

console.log(ticked);
```

```output
[ 'Music', 'Coding' ]
```

---

## 6. Radio Buttons

Radio buttons share the same `name`, and only one can be chosen. Select the checked one with `:checked`.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <form id="levelForm">
    <label><input type="radio" name="level" value="Beginner" checked> Beginner</label>
    <label><input type="radio" name="level" value="Intermediate"> Intermediate</label>
    <label><input type="radio" name="level" value="Advanced"> Advanced</label>
    <button type="submit">Choose</button>
  </form>
  <p id="chosen"></p>

  <script>
    document.getElementById("levelForm").addEventListener("submit", event => {
      event.preventDefault();

      const selected = document.querySelector("input[name='level']:checked");
      document.getElementById("chosen").textContent =
        "Your level: " + selected.value;
    });
  </script>
</body>
</html>
```

## 7. Dropdown Lists (`<select>`)

`select.value` gives the `value` of the chosen option. `selectedIndex` gives its position.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <select id="course">
    <option value="">Select a course</option>
    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="js">JavaScript</option>
  </select>
  <p id="picked"></p>

  <script>
    const select = document.getElementById("course");

    select.addEventListener("change", () => {
      const option = select.options[select.selectedIndex];
      document.getElementById("picked").textContent =
        "Value: " + select.value + " | Text: " + option.text;
    });
  </script>
</body>
</html>
```

## 8. `input` vs `change` Events

| Event    | Fires when                                              | Good for                        |
| -------- | ------------------------------------------------------- | ------------------------------- |
| `input`  | The value changes, on **every keystroke**               | Live preview, character counters |
| `change` | The value is **committed** (leaving the field or choosing an option) | Dropdowns, checkboxes |

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <input id="live" type="text" placeholder="Type something">
  <p>You typed: <strong id="preview"></strong></p>

  <script>
    document.getElementById("live").addEventListener("input", event => {
      document.getElementById("preview").textContent = event.target.value;
    });
  </script>
</body>
</html>
```

## 9. Numbers from Inputs

Even `<input type="number">` returns a **string**. Convert it before doing math.

```javascript
// <input type="number" id="qty" value="3">
const qty = document.querySelector("#qty");

console.log(qty.value + 2);
console.log(Number(qty.value) + 2);
console.log(qty.valueAsNumber + 2);
```

```output
32
5
5
```

The first line joins the **text** `"3"` and `2`, which is rarely what you want.

## 10. Using `FormData`

`FormData` collects **every field of a form at once**, using each field's `name` attribute.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <form id="signup">
    <input name="fullName" type="text" placeholder="Full name"><br><br>
    <input name="email" type="email" placeholder="Email"><br><br>
    <select name="country">
      <option value="India">India</option>
      <option value="USA">USA</option>
    </select><br><br>
    <label><input name="newsletter" type="checkbox"> Subscribe</label><br><br>
    <button type="submit">Register</button>
  </form>
  <pre id="data"></pre>

  <script>
    document.getElementById("signup").addEventListener("submit", event => {
      event.preventDefault();

      const formData = new FormData(event.target);
      const data = Object.fromEntries(formData);

      document.getElementById("data").textContent = JSON.stringify(data, null, 2);
    });
  </script>
</body>
</html>
```

> **Tip:** Unchecked checkboxes are **not included** in `FormData`. A checked checkbox without a `value` attribute is stored as `"on"`.

## 11. Accessing Form Fields Through the Form

A form gives you direct access to its fields through `elements`, using the field's `name` or `id`.

```javascript
// <form id="profile"> with fields named "username" and "age"
const form = document.querySelector("#profile");

console.log(form.elements.username.value);
console.log(form.elements["age"].value);
console.log(form.elements.length);
```

```output
asha
21
3
```

---

## 12. Resetting, Focusing and Disabling

```javascript
const form = document.querySelector("#signup");
const nameField = form.elements.fullName;
const submitBtn = form.querySelector("button");

form.reset();                    // clear all fields to their starting values
nameField.focus();               // put the cursor in the field
submitBtn.disabled = true;       // prevent clicking
nameField.readOnly = true;       // visible but not editable
```

## Real-World Example

A course registration form that reads every kind of input and shows a summary without reloading the page:

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px; max-width: 380px;">
  <h3>Course Registration</h3>
  <form id="regForm">
    <p><input name="student" type="text" placeholder="Student name" style="width:100%"></p>
    <p>
      <select name="course" style="width:100%">
        <option value="JavaScript">JavaScript</option>
        <option value="Python">Python</option>
        <option value="HTML">HTML</option>
      </select>
    </p>
    <p>
      <label><input type="radio" name="mode" value="Online" checked> Online</label>
      <label><input type="radio" name="mode" value="Offline"> Offline</label>
    </p>
    <p><label><input type="checkbox" name="certificate"> I want a certificate</label></p>
    <button type="submit">Register</button>
  </form>
  <p id="summary" style="background:#f1f5f9; padding:10px; border-radius:6px; display:none;"></p>

  <script>
    document.getElementById("regForm").addEventListener("submit", event => {
      event.preventDefault();

      const form = event.target;
      const name = form.elements.student.value.trim();
      const course = form.elements.course.value;
      const mode = form.querySelector("input[name='mode']:checked").value;
      const wantsCertificate = form.elements.certificate.checked;

      const summary = document.getElementById("summary");
      summary.style.display = "block";
      summary.textContent = name
        ? `${name} registered for ${course} (${mode}). Certificate: ${wantsCertificate ? "Yes" : "No"}`
        : "Please enter the student name.";
    });
  </script>
</body>
</html>
```

## Common Mistakes

### Forgetting `preventDefault()`

Without it, the form reloads the page and your JavaScript result disappears.

### Using `click` on the Submit Button

```javascript
button.addEventListener("click", handler);       // misses the Enter key
form.addEventListener("submit", handler);        // better
```

### Treating Input Values as Numbers

```javascript
const total = priceInput.value + taxInput.value;                // "10020" (text joined)
const total2 = Number(priceInput.value) + Number(taxInput.value);   // 120
```

### Reading `value` of a Checkbox Instead of `checked`

`checkbox.value` is just its label text (default `"on"`). Use `checkbox.checked` to see whether it is ticked.

### Missing `name` Attributes

`FormData` and `form.elements.name` rely on the `name` attribute. Fields without a `name` are skipped by `FormData`.

### Not Trimming Input

A name like `"  Asha  "` or just spaces `"   "` looks filled but is not useful. Use `.trim()`.

---

## Key Points

* Use the form's `submit` event and call `event.preventDefault()` to handle data with JavaScript.
* `input.value` always returns a string, even for number fields.
* Use `checked` for checkboxes and radio buttons.
* Select the chosen radio with `input[name='x']:checked`.
* `select.value` returns the chosen option's value.
* `input` fires on every keystroke; `change` fires when the value is committed.
* `FormData` and `Object.fromEntries()` collect all fields into one object.
* `form.elements` accesses fields by `name` or `id`.
* Use `trim()` to remove accidental spaces and `Number()` to convert numeric input.

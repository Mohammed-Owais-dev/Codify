# Chapter 2: JavaScript Fundamentals

## Section 3: Data Types

Every value in JavaScript has a **type**. The type decides what you can do with the value: you can add numbers, join strings, or check whether a Boolean is true. In this section you will learn all the basic data types.

---

## 1. Two Groups of Data Types

| Group | Types |
| --- | --- |
| **Primitive** (single, simple values) | `string`, `number`, `boolean`, `undefined`, `null`, `bigint`, `symbol` |
| **Non-primitive** (collections) | `object` (including arrays and functions) |

---

## 2. The `typeof` Operator

`typeof` returns the type of a value as text.

```javascript
console.log(typeof "Hello");
console.log(typeof 42);
console.log(typeof 3.14);
console.log(typeof true);
console.log(typeof undefined);
```

```output
string
number
number
boolean
undefined
```

---

## 3. Strings

A **string** is text inside quotes. Single quotes, double quotes and backticks all work.

```javascript
let first = "Asha";
let last = 'Reddy';
let full = `${first} ${last}`;

console.log(full);
console.log(full.length);
console.log(full[0]);
```

```output
Asha Reddy
10
A
```

* `length` gives the number of characters.
* `full[0]` gets the first character (counting starts at `0`).
* Strings cannot be changed in place, because they are **immutable**.

---

## 4. Numbers

JavaScript has one number type for both whole numbers and decimals.

```javascript
let age = 20;
let price = 99.99;
let negative = -5;

console.log(typeof age);
console.log(typeof price);
console.log(age + price);
```

```output
number
number
119.99
```

### Special Number Values

```javascript
console.log(10 / 0);
console.log(-10 / 0);
console.log("abc" * 2);
console.log(Number.MAX_SAFE_INTEGER);
```

```output
Infinity
-Infinity
NaN
9007199254740991
```

* `Infinity` appears when you divide by zero.
* `NaN` means **Not a Number**, the result of an invalid calculation.
* Whole numbers are accurate up to `Number.MAX_SAFE_INTEGER`.

### Decimal Precision

Computers store decimals in binary, so some results are slightly off.

```javascript
console.log(0.1 + 0.2);
console.log((0.1 + 0.2).toFixed(2));
```

```output
0.30000000000000004
0.30
```

> 💡 `toFixed(2)` rounds to 2 decimal places and returns a **string**.

### Working with `NaN`

```javascript
console.log(typeof NaN);
console.log(NaN === NaN);
console.log(Number.isNaN("abc"));
console.log(Number.isNaN(NaN));
```

```output
number
false
false
true
```

`NaN` is never equal to anything, even itself. Use `Number.isNaN()` to test for it.

---

## 5. Booleans

A **boolean** has only two values: `true` and `false`.

```javascript
let isStudent = true;
let hasPaid = false;

console.log(isStudent);
console.log(5 > 3);
console.log(5 === 3);
```

```output
true
true
false
```

### Truthy and Falsy

When JavaScript needs a boolean (for example in an `if`), other values are converted.

* **Falsy** values: `false`, `0`, `""` (empty string), `null`, `undefined`, `NaN`.
* **Truthy** values: everything else, including `"0"`, `"false"`, `[]` and `{}`.

```javascript
console.log(Boolean(0));
console.log(Boolean("Hello"));
console.log(Boolean(""));
console.log(Boolean([]));
```

```output
false
true
false
true
```

---

## 6. `undefined` and `null`

| Value | Meaning |
| --- | --- |
| `undefined` | A variable exists but has no value yet |
| `null` | An intentional "no value" that you assign yourself |

```javascript
let a;
let b = null;

console.log(a);
console.log(b);
console.log(typeof a);
console.log(typeof b);
```

```output
undefined
null
undefined
object
```

> 💡 `typeof null` returns `"object"`. This is a famous mistake in the early design of JavaScript that has been kept for compatibility. `null` is a primitive, not an object.

---

## 7. BigInt

`BigInt` stores integers larger than `Number.MAX_SAFE_INTEGER`. Add `n` at the end of the number.

```javascript
let big = 2n ** 64n;

console.log(big);
console.log(typeof big);
```

```output
18446744073709551616n
bigint
```

A `BigInt` cannot be mixed directly with a normal number in calculations.

---

## 8. Symbol

A `Symbol` creates a unique identifier. Every symbol is different, even with the same description.

```javascript
let id1 = Symbol("id");
let id2 = Symbol("id");

console.log(id1 === id2);
console.log(typeof id1);
```

```output
false
symbol
```

Symbols are rarely needed by beginners.

---

## 9. Objects, Arrays and Functions

Everything that is not a primitive is an **object**.

```javascript
let student = { name: "Asha", age: 20 };
let marks = [80, 90, 75];
function hello() {}

console.log(typeof student);
console.log(typeof marks);
console.log(Array.isArray(marks));
console.log(typeof hello);
```

```output
object
object
true
function
```

* Objects store `key: value` pairs.
* Arrays store ordered lists. Use `Array.isArray()` to check for an array.
* Functions are objects, and `typeof` reports them as `function`.

---

## 10. Primitive vs Reference Types

Primitives are copied by **value**. Objects are copied by **reference**, so two variables can point to the same object.

```javascript
let a = 10;
let b = a;
b = 20;
console.log(a, b);
```

```output
10 20
```

```javascript
let user1 = { score: 1 };
let user2 = user1;
user2.score = 99;
console.log(user1.score);
```

```output
99
```

Changing `user2` also changed `user1`, because both names refer to the same object.

---

## 11. Dynamic Typing

A variable can hold any type, and its type can change.

```javascript
let data = 100;
console.log(typeof data);

data = "one hundred";
console.log(typeof data);

data = false;
console.log(typeof data);
```

```output
number
string
boolean
```

## 12. Summary Table

| Type | Example | `typeof` result |
| --- | --- | --- |
| String | `"Hello"` | `"string"` |
| Number | `42`, `3.14` | `"number"` |
| Boolean | `true` | `"boolean"` |
| Undefined | `undefined` | `"undefined"` |
| Null | `null` | `"object"` (historical quirk) |
| BigInt | `10n` | `"bigint"` |
| Symbol | `Symbol("x")` | `"symbol"` |
| Object | `{ a: 1 }`, `[1, 2]` | `"object"` |
| Function | `function () {}` | `"function"` |

## Real-World Example

A user profile uses several data types together:

```javascript
const profile = {
  name: "Asha",
  age: 20,
  isStudent: true,
  address: null
};

console.log(typeof profile.name);
console.log(typeof profile.age);
console.log(typeof profile.isStudent);
console.log(profile.address);
```

```output
string
number
boolean
null
```

## Common Mistakes

### Trusting `typeof null`

```javascript
console.log(typeof null);    // "object", not "null"
```

Check for null with `value === null`.

### Comparing with `NaN`

```javascript
console.log(NaN === NaN);    // false
```

Use `Number.isNaN(value)`.

### Expecting Exact Decimal Math

`0.1 + 0.2` is not exactly `0.3`. For money, round with `toFixed()` or work in the smallest unit (such as paise or cents).

### Mixing Up `undefined` and `null`

`undefined` means "no value assigned yet". `null` is something you set on purpose.

### Using `typeof` to Detect Arrays

`typeof [1, 2]` is `"object"`. Use `Array.isArray()`.

---

## Key Points

* JavaScript has seven primitive types and the object type.
* `typeof` returns the type of a value as a string.
* There is a single `number` type for integers and decimals.
* `NaN` means "not a number" and is not equal to itself.
* Falsy values: `false`, `0`, `""`, `null`, `undefined`, `NaN`.
* `undefined` means no value yet; `null` means intentionally empty.
* Use `BigInt` for very large integers.
* Primitives are copied by value; objects are copied by reference.
* JavaScript is dynamically typed.

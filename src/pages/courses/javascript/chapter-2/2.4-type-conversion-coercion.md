# Chapter 2: JavaScript Fundamentals

## Section 4: Type Conversion and Coercion

Values often need to change from one type to another. For example, a number typed into a form arrives as text, and you must convert it before doing math. In this section you will learn both **explicit conversion** (you do it) and **implicit coercion** (JavaScript does it automatically).

---

## 1. Two Kinds of Conversion

| Kind | Who does it | Example |
| --- | --- | --- |
| **Type conversion** (explicit) | You, with functions such as `Number()` | `Number("42")` |
| **Type coercion** (implicit) | JavaScript, automatically | `"5" * 2` |

---

## 2. Converting to a Number

### `Number()`

```javascript
console.log(Number("42"));
console.log(Number("3.14"));
console.log(Number("  12  "));
console.log(Number(""));
console.log(Number("abc"));
console.log(Number(true));
console.log(Number(false));
console.log(Number(null));
console.log(Number(undefined));
```

```output
42
3.14
12
0
NaN
1
0
0
NaN
```

### `parseInt()` and `parseFloat()`

These read a number from the **start** of a string and ignore the rest.

```javascript
console.log(parseInt("42px"));
console.log(parseInt("px42"));
console.log(parseInt("3.99"));
console.log(parseFloat("3.14abc"));
console.log(parseInt("101", 2));
```

```output
42
NaN
3
3.14
5
```

* `parseInt("3.99")` drops the decimal part and gives `3`.
* The second argument of `parseInt` is the **base**. `parseInt("101", 2)` reads binary and gives `5`.

### The Unary Plus

A plus sign in front of a string is a short way to convert it.

```javascript
console.log(+"42");
console.log(+"abc");
```

```output
42
NaN
```

## 3. Converting to a String

```javascript
console.log(String(123));
console.log(String(true));
console.log(String(null));
console.log(String(undefined));
console.log(String([1, 2, 3]));
console.log((100).toString());
console.log(typeof String(123));
```

```output
123
true
null
undefined
1,2,3
100
string
```

## 4. Converting to a Boolean

```javascript
console.log(Boolean(1));
console.log(Boolean(0));
console.log(Boolean("hello"));
console.log(Boolean(""));
console.log(Boolean(null));
console.log(!!"text");
```

```output
true
false
true
false
false
true
```

`!!value` (double NOT) is a quick way to convert any value to a boolean.

---

## 5. Implicit Coercion with `+`

If **either** side of `+` is a string, JavaScript joins them as text.

```javascript
console.log("5" + 3);
console.log("Age: " + 20);
console.log(1 + 2 + "3");
console.log("1" + 2 + 3);
```

```output
53
Age: 20
33
123
```

Notice how the order matters. `1 + 2 + "3"` calculates `1 + 2` first (`3`), then joins `"3"`. In `"1" + 2 + 3`, everything after the string is joined as text.

---

## 6. Implicit Coercion with `-`, `*`, `/`

These operators always convert both sides to numbers.

```javascript
console.log("10" - 3);
console.log("5" * "2");
console.log("10" / 2);
console.log("abc" - 1);
console.log(true + 1);
console.log(null + 1);
console.log(undefined + 1);
```

```output
7
10
5
NaN
2
1
NaN
```

---

## 7. Loose vs Strict Equality

| Operator | Name | Behavior |
| --- | --- | --- |
| `==` | Loose equality | Converts types before comparing |
| `===` | Strict equality | Compares value **and** type, no conversion |

```javascript
console.log(5 == "5");
console.log(5 === "5");
console.log(0 == false);
console.log(0 === false);
console.log(null == undefined);
console.log(null === undefined);
console.log("" == 0);
```

```output
true
false
true
false
true
false
true
```

> 💡 Prefer `===` and `!==` in your programs. Loose equality produces surprising results.

## 8. Form Values are Strings

Values from `prompt()` and form fields always arrive as **strings**. Convert them before doing math.

```javascript
const a = "10";
const b = "20";

console.log(a + b);
console.log(Number(a) + Number(b));
```

```output
1020
30
```

---

## 9. Validating a Conversion

When the text is not a valid number, `Number()` returns `NaN`. Check for it before using the result.

```javascript
let value = Number("abc");

if (Number.isNaN(value)) {
  console.log("Invalid number");
} else {
  console.log("Valid number");
}
```

```output
Invalid number
```

## 10. Quick Reference

| Value | `Number()` | `String()` | `Boolean()` |
| --- | --- | --- | --- |
| `"42"` | `42` | `"42"` | `true` |
| `""` | `0` | `""` | `false` |
| `"abc"` | `NaN` | `"abc"` | `true` |
| `0` | `0` | `"0"` | `false` |
| `1` | `1` | `"1"` | `true` |
| `true` | `1` | `"true"` | `true` |
| `false` | `0` | `"false"` | `false` |
| `null` | `0` | `"null"` | `false` |
| `undefined` | `NaN` | `"undefined"` | `false` |

## Real-World Example

A small price calculator that receives text and converts it correctly:

```javascript
let price = prompt("Enter price:");
let quantity = prompt("Enter quantity:");

let total = Number(price) * Number(quantity);

if (Number.isNaN(total)) {
  console.log("Please enter valid numbers");
} else {
  console.log("Total: " + total);
}
```

If the user enters:

```text
250
3
```

The output will be:

```output
Total: 750
```

## Common Mistakes

### Adding Strings Instead of Numbers

```javascript
let a = prompt("First number:");     // "10"
let b = prompt("Second number:");    // "20"
console.log(a + b);                  // "1020"
```

Convert first: `Number(a) + Number(b)`.

### Using `parseInt` for Decimals

`parseInt("9.99")` gives `9`. Use `parseFloat()` or `Number()` for decimals.

### Assuming an Empty String Is Invalid

`Number("")` is `0`, not `NaN`. Check for an empty string yourself.

### Using `==` Out of Habit

`"" == 0` and `0 == false` are both `true`. Use `===`.

### Forgetting to Check for `NaN`

If a conversion fails, `NaN` spreads through later calculations. Use `Number.isNaN()`.

---

## Key Points

* Conversion is explicit (`Number()`, `String()`, `Boolean()`); coercion is automatic.
* `Number("abc")` gives `NaN`; `Number("")` gives `0`.
* `parseInt()` and `parseFloat()` read numbers from the start of a string.
* `+` joins text if either side is a string; `-`, `*` and `/` convert to numbers.
* `==` converts types; `===` does not. Prefer `===`.
* `prompt()` and form fields return strings.
* Use `Number.isNaN()` to validate converted values.

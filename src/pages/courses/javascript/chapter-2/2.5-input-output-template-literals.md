# Chapter 2: JavaScript Fundamentals

## Section 5: Input, Output and Template Literals

Programs become useful when they can **take input** from the user and **show output** in a clear way. In this section you will learn the common ways to read and display data in JavaScript, and how to build text easily using template literals.

---

## 1. Ways to Show Output

| Method | Where it appears | Typical use |
| --- | --- | --- |
| `console.log()` | Browser console / terminal | Testing and debugging |
| `alert()` | Pop-up dialog | Simple messages (browser only) |
| `textContent` / `innerHTML` | On the web page | Showing results to visitors |
| `document.write()` | On the web page | Avoid in real projects |

---

## 2. Output with `console.log()`

```javascript
console.log("Hello");
console.log("Total:", 250);
console.log(10 + 5);
```

```output
Hello
Total: 250
15
```

The console has other methods for different message levels.

```javascript
console.info("This is information");
console.warn("This is a warning");
console.error("This is an error");
```

```output
This is information
This is a warning
This is an error
```

In the browser console, warnings appear in yellow and errors in red.

---

## 3. Output with `alert()`

`alert()` shows a pop-up box with a message and an **OK** button. It works in a browser page and stops the page until the user clicks OK.

```javascript
alert("Welcome to Codify!");
```

> 💡 `alert()` does not exist in Node.js, and it is blocked inside the live previews on this site. Try it on your own page in a real browser.

---

## 4. Output on the Page

To show results to visitors, change the content of an HTML element. Press **Run**, type a name and click the button.

```html
<!DOCTYPE html>
<html>
<body style="font-family: Arial, sans-serif; padding: 20px;">
  <input id="nameInput" type="text" placeholder="Enter your name">
  <button id="greetBtn">Greet</button>
  <h3 id="result"></h3>

  <script>
    document.getElementById("greetBtn").addEventListener("click", function () {
      const name = document.getElementById("nameInput").value;
      document.getElementById("result").textContent = "Hello, " + name + "!";
    });
  </script>
</body>
</html>
```

* `.value` reads what the user typed into an input box.
* `.textContent` writes plain text into an element.

> 💡 Use `textContent` to display text that a user typed. `innerHTML` interprets text as HTML, which can be unsafe with user input.

---

## 5. Input with `prompt()`

`prompt()` shows a box with a text field. It **returns the text** the user typed as a string. If the user clicks Cancel, it returns `null`.

```javascript
let name = prompt("Enter your name:");
console.log("Hello, " + name);
```

If the user enters:

```text
Asha
```

The output will be:

```output
Hello, Asha
```

Remember that `prompt()` always returns a string. Convert it for math.

```javascript
let age = Number(prompt("Enter your age:"));
console.log("Next year you will be " + (age + 1));
```

If the user enters:

```text
20
```

The output will be:

```output
Next year you will be 21
```

---

## 6. Input with `confirm()`

`confirm()` shows a question with **OK** and **Cancel**. It returns `true` for OK and `false` for Cancel.

```javascript
let answer = confirm("Delete this item?");
console.log(answer);
```

```output
true
```

The output above is what appears when the user clicks **OK**.

---

## 7. Input from Forms

In real websites, input usually comes from form fields such as text boxes, checkboxes and drop-down lists. You read them with `.value`, as in the example in Section 4. Chapter 8 covers forms in detail.

## 8. Template Literals

A **template literal** is a string written with backticks `` ` ``. It makes it easy to put variables inside text.

**Syntax:**

```text
`text ${expression} more text`
```

```javascript
const name = "Asha";
const age = 20;

console.log(`My name is ${name} and I am ${age} years old.`);
```

```output
My name is Asha and I am 20 years old.
```

Compare with the old way of joining text:

```javascript
const name = "Asha";
const age = 20;

console.log("My name is " + name + " and I am " + age + " years old.");
```

```output
My name is Asha and I am 20 years old.
```

Template literals are shorter and easier to read.

---

## 9. Expressions Inside `${ }`

You can place any JavaScript expression inside `${ }`: calculations, function calls and conditions.

```javascript
const a = 5;
const b = 3;
const name = "asha";

console.log(`${a} + ${b} = ${a + b}`);
console.log(`Name in capitals: ${name.toUpperCase()}`);
console.log(`Status: ${a > b ? "a is bigger" : "b is bigger"}`);
```

```output
5 + 3 = 8
Name in capitals: ASHA
Status: a is bigger
```

---

## 10. Multi-Line Strings

Normal quotes cannot span lines, but template literals can.

```javascript
const message = `Dear Asha,
Welcome to Codify.
Happy learning!`;

console.log(message);
```

```output
Dear Asha,
Welcome to Codify.
Happy learning!
```

---

## 11. Escape Sequences

An escape sequence starts with a backslash `\` and has a special meaning inside a string.

| Sequence | Meaning |
| --- | --- |
| `\n` | New line |
| `\t` | Tab |
| `\\` | Backslash |
| `\"` | Double quote |
| `\'` | Single quote |

```javascript
console.log("Line 1\nLine 2");
console.log("She said \"Hi\"");
console.log("C:\\Users\\Asha");
```

```output
Line 1
Line 2
She said "Hi"
C:\Users\Asha
```

---

## 12. Formatting Numbers

`toFixed(n)` rounds a number to `n` decimal places and returns a string. It is handy for prices.

```javascript
const price = 19.5;
console.log(price.toFixed(2));
console.log(`Price: ₹${(250).toFixed(2)}`);
```

```output
19.50
Price: ₹250.00
```

---

## 13. Printing Objects

Joining an object to a string with `+` gives an unhelpful result. Use `JSON.stringify()` or print the object by itself.

```javascript
const user = { name: "Asha" };

console.log("User: " + user);
console.log("User: " + JSON.stringify(user));
console.log(user);
```

```output
User: [object Object]
User: {"name":"Asha"}
{ name: 'Asha' }
```

## Real-World Example 🌍

A bill splitter that reads the total and the number of people:

```javascript
const total = Number(prompt("Total bill:"));
const people = Number(prompt("Number of people:"));

const share = total / people;

console.log(`Each person pays ₹${share.toFixed(2)}`);
```

If the user enters:

```text
1200
5
```

The output will be:

```output
Each person pays ₹240.00
```

## Common Mistakes

### Using Quotes Instead of Backticks

```javascript
console.log("Hello ${name}");    // prints ${name} as plain text
```

Use backticks: ``console.log(`Hello ${name}`);``

### Forgetting the `$` or the Braces

```javascript
console.log(`Hello {name}`);    // prints {name} as plain text
```

### Forgetting That `prompt()` Returns a String

```javascript
let a = prompt("A:");    // "10"
let b = prompt("B:");    // "20"
console.log(a + b);      // "1020"
```

Convert with `Number()` first.

### Using `document.write()` After the Page Has Loaded

It can erase the whole page. Update elements with `textContent` instead.

### Using `innerHTML` with User Input

User-typed text can contain HTML tags. Prefer `textContent` for plain text.

### Expecting `alert()` and `prompt()` in Node.js

They exist only in browsers. In Node.js, use `console.log()` for output.

---

## Key Points

* `console.log()` is used for developer output.
* `alert()` shows a message box; `prompt()` reads text; `confirm()` asks OK or Cancel.
* `prompt()` returns a string (or `null` if cancelled).
* Show results on the page with `textContent`.
* Read form fields with `.value`.
* Template literals use backticks and `${ }` to insert values and expressions.
* Template literals can span several lines.
* `\n`, `\t`, `\\` and `\"` are escape sequences.
* `toFixed(2)` formats numbers with two decimal places.

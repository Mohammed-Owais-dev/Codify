# Chapter 2: JavaScript Fundamentals

## Section 2: Variables: let, const and var

A **variable** is a named container that stores a value. Variables let a program remember information such as a name, a score or a price. JavaScript has three keywords to create variables: `let`, `const` and `var`.

---

## 1. What is a Variable?

Think of a variable as a labeled box. The label is the **name**, and what is inside the box is the **value**.

```javascript
let name = "Asha";
console.log(name);
```

```output
Asha
```

Steps involved:

* **Declaration:** creating the variable (`let name`).
* **Assignment:** giving it a value (`= "Asha"`).
* **Initialization:** doing both together.

---

## 2. Declaring with `let`

Use `let` for values that **can change**.

```javascript
let city = "Hyderabad";
console.log(city);

city = "Pune";
console.log(city);
```

```output
Hyderabad
Pune
```

You can declare a variable first and assign a value later. Until then its value is `undefined`.

```javascript
let score;
console.log(score);

score = 90;
console.log(score);
```

```output
undefined
90
```

---

## 3. Declaring with `const`

Use `const` for values that **should not change**. A constant must be given a value when it is declared.

```javascript
const PI = 3.14159;
console.log(PI);
```

```output
3.14159
```

Trying to change a constant causes an error.

```javascript
const PI = 3.14159;
PI = 3;
```

```output
TypeError: Assignment to constant variable.
```

---

## 4. `const` with Arrays and Objects

`const` prevents you from **reassigning** the variable. It does not freeze the contents of an array or object.

```javascript
const fruits = ["apple", "banana"];
fruits.push("mango");
console.log(fruits);

const student = { name: "Asha", age: 20 };
student.age = 21;
console.log(student);
```

```output
[ 'apple', 'banana', 'mango' ]
{ name: 'Asha', age: 21 }
```

The array and object were **modified**, but the variables still point to the same array and object, so there is no error. You will learn more about arrays and objects in later chapters.

---

## 5. Declaring with `var`

`var` is the **old** way of creating variables, used before 2015. It still works, but it has confusing behavior, so modern code uses `let` and `const`.

```javascript
var city = "Hyderabad";
var city = "Pune";
console.log(city);
```

```output
Pune
```

Notice that `var` allows the same name to be declared twice without an error. This makes accidental mistakes easy to miss.

---

## 6. Comparing `let`, `const` and `var`

| Feature | `let` | `const` | `var` |
| --- | --- | --- | --- |
| Reassign value | Yes | No | Yes |
| Redeclare in same scope | No | No | Yes |
| Scope | Block | Block | Function |
| Must be initialized | No | Yes | No |
| Hoisted | Yes (but unusable until declared) | Yes (but unusable until declared) | Yes (value is `undefined`) |
| Recommended | Yes | Yes (first choice) | Avoid |

---

## 7. Block Scope

A **block** is the code inside `{ }`. Variables created with `let` and `const` exist only inside their block. Variables created with `var` ignore blocks.

```javascript
if (true) {
  let blockLet = "inside let";
  var blockVar = "inside var";
}

console.log(blockVar);
console.log(typeof blockLet);
```

```output
inside var
undefined
```

`blockLet` is not visible outside the block, so `typeof blockLet` reports `undefined`. Using `blockLet` directly outside would throw a `ReferenceError`.

---

## 8. Hoisting Preview

JavaScript moves declarations to the top of their scope before running the code. This is called **hoisting**.

```javascript
console.log(a);
var a = 5;
```

```output
undefined
```

With `var`, the declaration is hoisted but the value is not, so `a` is `undefined`. With `let` and `const`, the variable exists but cannot be used before its line.

```javascript
console.log(b);
let b = 5;
```

```output
ReferenceError: Cannot access 'b' before initialization
```

> 💡 Always declare variables at the top of their scope, before you use them. Hoisting is explained further in Chapter 4.

---

## 9. Declaring Several Variables

```javascript
let a = 1, b = 2, c = 3;
console.log(a, b, c);
```

```output
1 2 3
```

For readability, declaring one variable per line is usually better.

---

## 10. Which One Should I Use?

Follow this simple rule:

1. Use **`const`** by default.
2. Use **`let`** only when the value must change later.
3. Avoid **`var`** in new code.

---

## 11. Naming Variables Well

* Use descriptive `camelCase` names: `totalPrice`, `isLoggedIn`.
* Constants that never change can use `UPPER_SNAKE_CASE`: `MAX_USERS`.
* Booleans often start with `is`, `has` or `can`: `isActive`.
* Avoid single letters except in short loops.

---

## Real-World Example 🌍

A shopping cart where the price is fixed but the quantity can change:

```javascript
const price = 250;
let quantity = 2;

console.log("Total:", price * quantity);

quantity = 3;
console.log("Total:", price * quantity);
```

```output
Total: 500
Total: 750
```

## Common Mistakes

### Reassigning a `const`

```javascript
const age = 20;
age = 21;    // TypeError
```

Use `let` if the value needs to change.

### Declaring a `const` Without a Value

```javascript
const city;    // SyntaxError
```

### Redeclaring a `let` Variable

```javascript
let x = 1;
let x = 2;    // SyntaxError
```

Assign without `let`: `x = 2;`.

### Using a Variable Before Declaring It

```javascript
console.log(total);    // ReferenceError
let total = 10;
```

### Using `var` Out of Habit

`var` ignores block scope and can leak values outside `if` and `for` blocks. Prefer `let` and `const`.

---

## Key Points

* A variable stores a value under a name.
* `let` creates a variable that can be reassigned.
* `const` creates a variable that cannot be reassigned and must be initialized.
* `var` is the older keyword; avoid it in new code.
* `let` and `const` are block-scoped; `var` is function-scoped.
* A `const` array or object can still have its contents changed.
* An uninitialized variable has the value `undefined`.
* Use `const` by default and `let` when needed.

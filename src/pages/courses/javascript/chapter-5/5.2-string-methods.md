# Chapter 5: Arrays and Strings

## Section 2: Common String Methods

**String methods** are built-in functions that help you clean, search, cut, replace and transform text. Every string method returns a **new value** and leaves the original string unchanged.

---

## 1. Changing Case

`toUpperCase()` and `toLowerCase()` return the text in a different case.

```javascript
const lang = "JavaScript";

console.log(lang.toUpperCase());
console.log(lang.toLowerCase());
console.log(lang);
```

```output
JAVASCRIPT
javascript
JavaScript
```

The original variable `lang` is not modified.

---

## 2. Removing Extra Spaces

`trim()` removes spaces from both ends. `trimStart()` and `trimEnd()` remove them from one side only.

```javascript
const text = "  Hello, JavaScript!  ";

console.log(`[${text.trim()}]`);
console.log(`[${text.trimStart()}]`);
console.log(`[${text.trimEnd()}]`);
```

```output
[Hello, JavaScript!]
[Hello, JavaScript!  ]
[  Hello, JavaScript!]
```

`trim()` is very useful for cleaning form input before checking it.

---

## 3. Finding Text

These methods search for text inside a string.

```javascript
const sentence = "I love JavaScript and I love coding";

console.log(sentence.indexOf("love"));
console.log(sentence.lastIndexOf("love"));
console.log(sentence.indexOf("love", 5));
console.log(sentence.indexOf("Python"));
```

```output
2
24
24
-1
```

* `indexOf(text)` returns the position of the **first** match.
* `lastIndexOf(text)` returns the position of the **last** match.
* A second argument tells `indexOf` where to start searching.
* `-1` means the text was not found.

---

## 4. Checking Text with includes, startsWith and endsWith

These methods return `true` or `false`, which makes them ideal for conditions.

```javascript
const sentence = "I love JavaScript and I love coding";

console.log(sentence.includes("coding"));
console.log(sentence.startsWith("I love"));
console.log(sentence.endsWith("code"));
console.log(sentence.includes("java"));
```

```output
true
true
false
false
```

All three methods are **case-sensitive**, so `"java"` does not match `"Java"`.

---

## 5. Extracting Parts with slice and substring

Both methods cut a piece of text. The end position is **not included**.

```javascript
const str = "JavaScript";

console.log(str.slice(0, 4));
console.log(str.slice(4));
console.log(str.slice(-6));
console.log(str.slice(-6, -3));
console.log(str.substring(4, 0));
console.log(`[${str.slice(4, 0)}]`);
```

```output
Java
Script
Script
Scr
Java
[]
```

* `slice(start, end)` accepts **negative** numbers, which count from the end.
* `substring(start, end)` treats negative numbers as `0` and **swaps** the arguments if `start` is bigger than `end`.
* `slice(4, 0)` returns an empty string because the start is after the end.

> **Note:** The older `substr()` method is deprecated. Use `slice()` instead.

---

## 6. Replacing Text

`replace()` changes the **first** match only. `replaceAll()` changes every match.

```javascript
const msg = "cat and cat";

console.log(msg.replace("cat", "dog"));
console.log(msg.replaceAll("cat", "dog"));
console.log(msg.replace(/cat/g, "dog"));
console.log("Hello".replace("hello", "Hi"));
```

```output
dog and cat
dog and dog
dog and dog
Hello
```

* A regular expression with the `g` flag (global) also replaces every match.
* Matching is case-sensitive, so `"hello"` does not match `"Hello"`.

---

## 7. Splitting a String into an Array

`split(separator)` breaks a string into an array of smaller strings.

```javascript
console.log("apple,banana,cherry".split(","));
console.log("Hello".split(""));
console.log("one two  three".split(" "));
console.log("a-b-c".split("-", 2));
```

```output
[ 'apple', 'banana', 'cherry' ]
[ 'H', 'e', 'l', 'l', 'o' ]
[ 'one', 'two', '', 'three' ]
[ 'a', 'b' ]
```

* An empty separator `""` splits the text into single characters.
* Two spaces in a row create an empty string `''` in the result.
* The optional second argument limits how many pieces are returned.

---

## 8. Joining an Array into a String

`join(separator)` is an **array** method, but it is often used together with `split()`.

```javascript
console.log(["2026", "10", "19"].join("-"));
console.log("hello".split("").reverse().join(""));
```

```output
2026-10-19
olleh
```

Reversing a string works by splitting it into characters, reversing the array and joining it back.

---

## 9. Repeating and Padding

```javascript
console.log("ab".repeat(3));
console.log("-".repeat(10));
console.log("7".padStart(3, "0"));
console.log("Hi".padEnd(5, ".") + "|");
console.log("1234567812345678".slice(-4).padStart(16, "*"));
```

```output
ababab
----------
007
Hi...|
************5678
```

* `repeat(n)` repeats the string `n` times.
* `padStart(length, fill)` adds characters to the **left** until the string reaches the given length.
* `padEnd(length, fill)` adds characters to the **right**.
* Padding is handy for times such as `07:05` and for masking card numbers.

---

## 10. Joining with concat

`concat()` joins strings, but `+` and template literals are used more often.

```javascript
console.log("Hello".concat(" ", "World"));
```

```output
Hello World
```

---

## 11. Method Chaining

Because each method returns a string, you can call another method right away. This is called **chaining**.

```javascript
const input = "   JaVaScRiPt   ";

const clean = input.trim().toLowerCase();
const title = clean[0].toUpperCase() + clean.slice(1);

console.log(clean);
console.log(title);
```

```output
javascript
Javascript
```

Chained calls run from left to right. Keep chains short enough to stay readable.

---

## 12. Methods Do Not Change the Original

String methods never modify the original string. Store the result if you need it.

```javascript
const name = "asha";

name.toUpperCase();
console.log(name);

const upper = name.toUpperCase();
console.log(upper);
```

```output
asha
ASHA
```

---

## Real-World Example

Cleaning a sign-up form and creating a URL-friendly title:

```javascript
const rawEmail = "  Asha.Rao@Example.COM ";

const email = rawEmail.trim().toLowerCase();
const isValid = email.includes("@") && email.endsWith(".com");
const username = email.slice(0, email.indexOf("@"));

const slug = "  Learn JavaScript Fast  "
  .trim()
  .toLowerCase()
  .split(" ")
  .join("-");

console.log(email);
console.log(isValid);
console.log(username);
console.log(slug);
```

```output
asha.rao@example.com
true
asha.rao
learn-javascript-fast
```

## Common Mistakes

### Forgetting to Store the Result

```javascript
let name = "asha";
name.toUpperCase();          // result is thrown away
name = name.toUpperCase();   // correct
```

### Using indexOf Directly in a Condition

```javascript
const text = "apple";

if (text.indexOf("a")) { }        // wrong, index 0 is falsy
if (text.indexOf("a") !== -1) { } // correct
if (text.includes("a")) { }       // even better
```

### Expecting replace to Change Every Match

```javascript
"a-b-c".replace("-", "+");       // "a+b-c", only the first match
"a-b-c".replaceAll("-", "+");    // "a+b+c"
```

### Ignoring Case When Searching

```javascript
"JavaScript".includes("script");                      // false
"JavaScript".toLowerCase().includes("script");        // true
```

### Splitting on a Single Space When Spaces Repeat

```javascript
"a  b".split(" ");     // [ 'a', '', 'b' ]
"a  b".split(/\s+/);   // [ 'a', 'b' ], handles repeated spaces
```

---

## Key Points

* String methods return a **new** string; the original is never changed.
* `toUpperCase()` and `toLowerCase()` change the case.
* `trim()`, `trimStart()` and `trimEnd()` remove whitespace.
* `indexOf()` returns the position, or `-1` if the text is not found.
* `includes()`, `startsWith()` and `endsWith()` return `true` or `false`.
* `slice(start, end)` supports negative indexes; the end index is excluded.
* `replace()` changes the first match; `replaceAll()` changes all matches.
* `split()` turns a string into an array, and `join()` turns an array into a string.
* `repeat()`, `padStart()` and `padEnd()` help with formatting.
* Methods can be chained, such as `text.trim().toLowerCase()`.

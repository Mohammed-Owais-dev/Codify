# Chapter 5: Arrays and Strings

## Section 1: Working with Strings

A **string** is a sequence of characters used to store text such as names, messages, emails and passwords. Strings are one of the most used data types in JavaScript, and almost every program works with text in some way.

---

## 1. What Is a String?

A string is any text wrapped in quotes. JavaScript allows three kinds of quotes.

```javascript
const s1 = 'Hello';
const s2 = "World";
const s3 = `JavaScript`;

console.log(s1);
console.log(s2);
console.log(s3);
console.log(typeof s1);
```

```output
Hello
World
JavaScript
string
```

* Single quotes and double quotes work the same way. Pick one style and stay consistent.
* Backticks create a **template literal**, which has extra features (see Section 4).
* `typeof` confirms that the value is of type `"string"`.

---

## 2. Escape Characters

Sometimes you need a quote, a new line or a backslash **inside** a string. Use a backslash `\` to write these special characters.

| Escape | Meaning |
| ------ | ------- |
| `\"` | Double quote |
| `\'` | Single quote |
| `\\` | Backslash |
| `\n` | New line |
| `\t` | Tab |

```javascript
console.log("She said \"Hi\"");
console.log('It\'s a nice day');
console.log("Line 1\nLine 2");
console.log("C:\\Users\\Asha");
```

```output
She said "Hi"
It's a nice day
Line 1
Line 2
C:\Users\Asha
```

> **Tip:** You can also avoid escaping by choosing different outer quotes, such as `"It's a nice day"`.

---

## 3. String Length

The `length` property tells you how many characters a string contains. Spaces and punctuation are counted too.

```javascript
console.log("JavaScript".length);
console.log("Hi there".length);
console.log("".length);
```

```output
10
8
0
```

`length` is a **property**, so you write it without parentheses.

---

## 4. Template Literals

Template literals use backticks. They let you insert values with `${...}` and write text across multiple lines.

```javascript
const name = "Asha";
const age = 20;

console.log(`${name} is ${age} years old.`);
console.log(`Next year: ${age + 1}`);

console.log(`Line one
Line two`);
```

```output
Asha is 20 years old.
Next year: 21
Line one
Line two
```

* Anything inside `${ }` is evaluated as a JavaScript expression.
* Template literals are easier to read than long chains of `+`.

---

## 5. Accessing Characters

Every character has a position called an **index**. Indexes start at **0**.

```javascript
const word = "JavaScript";

console.log(word[0]);
console.log(word[4]);
console.log(word[word.length - 1]);
console.log(word.charAt(1));
console.log(word.at(-1));
console.log(word[20]);
console.log(`"${word.charAt(20)}"`);
```

```output
J
S
t
a
t
undefined
""
```

* `word[index]` returns `undefined` when the index is out of range.
* `charAt(index)` returns an **empty string** when the index is out of range.
* `at(-1)` counts from the end, so `-1` is the last character.

---

## 6. Strings Are Immutable

You cannot change a single character inside an existing string. To "change" a string, create a **new** one.

```javascript
let text = "Hello";

text[0] = "J";
console.log(text);

text = "J" + text.slice(1);
console.log(text);
```

```output
Hello
Jello
```

The assignment `text[0] = "J"` is ignored (in strict mode it throws a `TypeError`). Building a new string and storing it in the variable is the correct approach.

---

## 7. Joining Strings (Concatenation)

Use `+` to join strings. Use `+=` to add text to an existing variable.

```javascript
console.log("Hello" + " " + "World");

let msg = "Hi";
msg += ", there";
console.log(msg);

console.log("5" + 3);
console.log(5 + 3 + "2");
console.log("5" - 3);
```

```output
Hello World
Hi, there
53
82
2
```

* If one side of `+` is a string, the other side is converted to a string.
* `-` always works with numbers, so `"5" - 3` gives `2`.
* `5 + 3 + "2"` evaluates left to right: `8`, then `"82"`.

---

## 8. Comparing Strings

Strings are compared with `===`, `<` and `>`. The comparison is **case-sensitive** and uses character codes, not the dictionary.

```javascript
console.log("apple" === "apple");
console.log("apple" === "Apple");
console.log("apple" < "banana");
console.log("a" < "B");
console.log("10" < "9");
console.log("Hello".toLowerCase() === "hello".toLowerCase());
```

```output
true
false
true
false
true
true
```

* Uppercase letters have smaller codes than lowercase letters, so `"a" < "B"` is `false`.
* `"10" < "9"` is `true` because text is compared character by character: `"1"` comes before `"9"`.
* To ignore case, convert both strings to the same case first.

---

## 9. Looping Through a String

A string behaves like a list of characters, so you can loop over it.

```javascript
const word = "Hey";

for (let i = 0; i < word.length; i++) {
  console.log(`${i}: ${word[i]}`);
}

for (const ch of word) {
  console.log(ch);
}
```

```output
0: H
1: e
2: y
H
e
y
```

Use `for...of` when you only need the characters, and a normal `for` loop when you also need the index.

---

## 10. Strings and Emojis

JavaScript counts characters in units called UTF-16 code units. Some characters, such as emojis, use **two** units.

```javascript
console.log("😀".length);
console.log([..."😀"].length);
```

```output
2
1
```

Spreading a string with `[...text]` splits it into real characters, which is safer for emojis and special symbols.

## Real-World Example

Creating a welcome message and initials from a user's name:

```javascript
const firstName = "Asha";
const lastName = "Rao";

const initials = firstName[0] + lastName[0];
const letters = (firstName + lastName).length;

console.log(`Welcome, ${firstName} ${lastName}!`);
console.log(`Initials: ${initials}`);
console.log(`Letters in name: ${letters}`);
```

```output
Welcome, Asha Rao!
Initials: AR
Letters in name: 7
```

## Common Mistakes

### Trying to Change a Character Directly

```javascript
let word = "cat";
word[0] = "b";    // ignored, strings are immutable
word = "b" + word.slice(1);    // correct
```

### Using the Last Index Incorrectly

```javascript
const word = "Code";
console.log(word[word.length]);        // undefined
console.log(word[word.length - 1]);    // "e", correct
```

### Forgetting That + Can Join Text Instead of Adding

```javascript
const a = "10";
const b = 5;
console.log(a + b);            // "105"
console.log(Number(a) + b);    // 15, correct
```

### Mismatched Quotes

```javascript
const text = "Hello';    // SyntaxError, the quotes do not match
const ok = "Hello";      // correct
```

### Comparing Without Considering Case

```javascript
console.log("Yes" === "yes");                                    // false
console.log("Yes".toLowerCase() === "yes".toLowerCase());        // true
```

---

## Key Points

* A string is text written inside single quotes, double quotes or backticks.
* Use backslash escapes such as `\n`, `\t` and `\"` for special characters.
* `length` gives the number of characters and is a property, not a method.
* Template literals use backticks and `${expression}` to insert values.
* Indexes start at 0; use `at(-1)` to read from the end.
* Strings are immutable: operations return a new string instead of changing the old one.
* `+` joins strings, and mixing a string with a number produces a string.
* String comparison is case-sensitive.
* Use `for...of` or `[...text]` to work with individual characters.

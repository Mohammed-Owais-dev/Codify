# Chapter 5: Arrays and Strings

## Section 4: Array Methods: map, filter and reduce

`map()`, `filter()` and `reduce()` are three of the most important array methods in modern JavaScript. Each one takes a **callback function** (from Chapter 4) and processes every element of an array without needing a manual loop.

---

## 1. The Big Picture

| Method | Purpose | Returns |
| ------ | ------- | ------- |
| `map()` | Transform every element | New array, **same length** |
| `filter()` | Keep only matching elements | New array, **same or shorter** |
| `reduce()` | Combine all elements into one value | **Single value** |

None of these methods change the original array.

---

## 2. map: Transform Every Element

`map()` runs the callback for each element and collects the returned values into a new array.

```javascript
const nums = [1, 2, 3, 4];

const doubled = nums.map(n => n * 2);

console.log(doubled);
console.log(nums);
```

```output
[ 2, 4, 6, 8 ]
[ 1, 2, 3, 4 ]
```

```javascript
const names = ["asha", "ravi"];

console.log(names.map(n => n.toUpperCase()));
```

```output
[ 'ASHA', 'RAVI' ]
```

* The callback **must return** a value for each element.
* The result always has the same length as the original array.

---

## 3. map with Index and Objects

The callback receives up to three arguments: the element, its index and the whole array.

```javascript
const letters = ["a", "b", "c"];

console.log(letters.map((ch, i) => `${i}:${ch}`));

const people = ["Asha", "Ravi"].map((name, i) => ({ id: i + 1, name }));
console.log(people);
```

```output
[ '0:a', '1:b', '2:c' ]
[ { id: 1, name: 'Asha' }, { id: 2, name: 'Ravi' } ]
```

Wrap an object literal in parentheses `({ ... })` when returning it from an arrow function, otherwise JavaScript reads the braces as a function body.

---

## 4. filter: Keep Matching Elements

`filter()` keeps the elements for which the callback returns `true` (or any truthy value).

```javascript
const ages = [12, 18, 25, 9, 40];
const words = ["apple", "fig", "banana", "kiwi"];

console.log(ages.filter(a => a >= 18));
console.log(words.filter(w => w.length > 4));
console.log([1, 2].filter(n => n > 10));
```

```output
[ 18, 25, 40 ]
[ 'apple', 'banana' ]
[]
```

If nothing matches, `filter()` returns an **empty array**, not `undefined`.

### Removing an Item and Cleaning an Array

```javascript
console.log(["a", "b", "c"].filter(x => x !== "b"));
console.log([0, "hi", "", null, 5, undefined].filter(Boolean));
```

```output
[ 'a', 'c' ]
[ 'hi', 5 ]
```

`filter(Boolean)` removes falsy values such as `0`, `""`, `null` and `undefined`.

---

## 5. reduce: Combine into One Value

`reduce(callback, initialValue)` walks through the array and keeps a running result called the **accumulator**.

```javascript
const nums = [1, 2, 3, 4];

const sum = nums.reduce((acc, n) => acc + n, 0);

console.log(sum);
```

```output
10
```

How the accumulator changes step by step:

| Step | `acc` | `n` | Result |
| ---- | ----- | --- | ------ |
| 1 | `0` | `1` | `1` |
| 2 | `1` | `2` | `3` |
| 3 | `3` | `3` | `6` |
| 4 | `6` | `4` | `10` |

* The callback receives the accumulator first and the current element second.
* The value returned by the callback becomes the accumulator for the next step.
* The second argument of `reduce` (here `0`) is the **starting value**.

---

## 6. More reduce Examples

```javascript
console.log([3, 9, 4].reduce((max, n) => (n > max ? n : max)));
console.log([1, 2, 3, 4].reduce((total, n) => total * n, 1));

const votes = ["A", "B", "A", "C", "A", "B"];

const tally = votes.reduce((counts, v) => {
  counts[v] = (counts[v] || 0) + 1;
  return counts;
}, {});

console.log(tally);
```

```output
9
24
{ A: 3, B: 2, C: 1 }
```

* Without an initial value, `reduce` starts with the **first element** as the accumulator.
* The starting value can be any type: a number, a string, an array or an object.
* The vote counter uses an object as the accumulator.

---

## 7. Chaining map, filter and reduce

Each method returns a value that the next one can use, so you can build a data pipeline.

```javascript
const scores = [45, 82, 67, 90, 30];

const passed = scores.filter(s => s >= 50);
const total = passed
  .map(s => s + 5)
  .reduce((acc, s) => acc + s, 0);

console.log(passed);
console.log(total);
```

```output
[ 82, 67, 90 ]
254
```

Steps: `filter` keeps `[82, 67, 90]`, `map` adds 5 to get `[87, 72, 95]`, and `reduce` adds them up to `254`.

---

## 8. forEach vs map

`forEach()` runs a callback for each element but **returns nothing**. Use `map()` when you need a new array.

```javascript
const result = [1, 2].forEach(n => n * 2);
const mapped = [1, 2].map(n => n * 2);

console.log(result);
console.log(mapped);
```

```output
undefined
[ 2, 4 ]
```

Use `forEach` for side effects such as printing, and `map` for transforming data.

## Real-World Example 🌍

Working with a shopping cart of objects:

```javascript
const cart = [
  { name: "Pen", price: 10, qty: 5 },
  { name: "Notebook", price: 60, qty: 2 },
  { name: "Bag", price: 500, qty: 1 }
];

const names = cart.map(item => item.name);
const costly = cart
  .filter(item => item.price >= 50)
  .map(item => item.name);
const total = cart.reduce((sum, item) => sum + item.price * item.qty, 0);

console.log(names);
console.log(costly);
console.log(`Total: ₹${total}`);
```

```output
[ 'Pen', 'Notebook', 'Bag' ]
[ 'Notebook', 'Bag' ]
Total: ₹670
```

## Common Mistakes

### Forgetting to Return a Value

```javascript
const nums = [1, 2, 3];

nums.map(n => { n * 2; });           // [ undefined, undefined, undefined ]
nums.map(n => { return n * 2; });    // [ 2, 4, 6 ]
nums.map(n => n * 2);                // [ 2, 4, 6 ]
```

### Using map When You Do Not Need the New Array

```javascript
[1, 2, 3].map(n => console.log(n));        // creates an unused array
[1, 2, 3].forEach(n => console.log(n));    // better
```

### Calling reduce on an Empty Array Without an Initial Value

```javascript
[].reduce((a, b) => a + b);       // TypeError: Reduce of empty array with no initial value
[].reduce((a, b) => a + b, 0);    // 0, correct
```

### Forgetting to Return the Accumulator

```javascript
[1, 2, 3].reduce((acc, n) => { acc + n; }, 0);          // undefined after the first step
[1, 2, 3].reduce((acc, n) => { return acc + n; }, 0);   // 6, correct
```

### Passing parseInt Directly to map

```javascript
["1", "2", "3"].map(parseInt);                  // [ 1, NaN, NaN ]
["1", "2", "3"].map(s => parseInt(s, 10));      // [ 1, 2, 3 ]
["1", "2", "3"].map(Number);                    // [ 1, 2, 3 ]
```

`map` passes the index as a second argument, and `parseInt` reads it as the number base.

---

## Key Points

* `map()` transforms every element and returns a new array of the same length.
* `filter()` keeps the elements for which the callback returns a truthy value.
* `reduce()` combines all elements into a single value using an accumulator.
* Always give `reduce` an initial value, especially when the array might be empty.
* None of these methods modify the original array.
* The callback must `return` a value when you use braces `{ }`.
* `forEach()` returns `undefined`; use `map()` when you need results.
* Methods can be chained: `filter` first, then `map`, then `reduce`.

# Chapter 5: Arrays and Strings

## Section 5: Searching, Sorting and Iterating Arrays

Real programs constantly need to find an item, check a condition, put data in order and walk through every element. This section covers the array methods and loops that do exactly that.

---

## 1. Finding Values with indexOf and includes

`indexOf()` returns the position of a value, `lastIndexOf()` returns its last position, and `includes()` returns `true` or `false`.

```javascript
const colors = ["red", "green", "blue", "green"];

console.log(colors.indexOf("green"));
console.log(colors.lastIndexOf("green"));
console.log(colors.indexOf("pink"));
console.log(colors.includes("blue"));
```

```output
1
3
-1
true
```

* `indexOf()` returns `-1` when the value is not found.
* These methods compare values with strict equality, so they work well for primitives such as numbers and strings.

### The NaN Difference

```javascript
console.log([NaN].includes(NaN));
console.log([NaN].indexOf(NaN));
```

```output
true
-1
```

`includes()` can find `NaN`, but `indexOf()` cannot.

---

## 2. Finding Objects with find and findIndex

`indexOf` cannot search objects by a property. Use `find()` and `findIndex()` with a callback instead.

```javascript
const users = [
  { id: 1, name: "Asha", age: 17 },
  { id: 2, name: "Ravi", age: 22 },
  { id: 3, name: "Meena", age: 30 }
];

console.log(users.find(u => u.age >= 18));
console.log(users.find(u => u.age > 100));
console.log(users.findIndex(u => u.name === "Meena"));
console.log(users.findIndex(u => u.name === "Kiran"));
console.log(users.findLast(u => u.age >= 18));
```

```output
{ id: 2, name: 'Ravi', age: 22 }
undefined
2
-1
{ id: 3, name: 'Meena', age: 30 }
```

* `find()` returns the **first matching element**, or `undefined`.
* `findIndex()` returns the **index** of the first match, or `-1`.
* `findLast()` searches from the end of the array.
* `filter()` returns **all** matches in an array, while `find()` returns only the first one.

---

## 3. Checking Conditions with some and every

```javascript
const marks = [55, 72, 90];

console.log(marks.some(m => m >= 90));
console.log(marks.every(m => m >= 50));
console.log(marks.every(m => m >= 60));
console.log([].every(m => m > 0));
console.log([].some(m => m > 0));
```

```output
true
true
false
true
false
```

* `some()` is `true` if **at least one** element passes the test.
* `every()` is `true` only if **all** elements pass the test.
* On an empty array, `every()` returns `true` and `some()` returns `false`.

---

## 4. Sorting with sort()

`sort()` arranges the elements of an array. It **changes the original array** and also returns it.

```javascript
console.log(["banana", "apple", "cherry"].sort());

const nums = [3, 1, 2];
const sorted = nums.sort();

console.log(nums);
console.log(sorted === nums);
```

```output
[ 'apple', 'banana', 'cherry' ]
[ 1, 2, 3 ]
true
```

---

## 5. Sorting Numbers Correctly

By default, `sort()` converts elements to **text** and compares them as strings. This breaks number sorting.

```javascript
console.log([10, 9, 1, 100].sort());
console.log([10, 9, 1, 100].sort((a, b) => a - b));
console.log([10, 9, 1, 100].sort((a, b) => b - a));
```

```output
[ 1, 10, 100, 9 ]
[ 1, 9, 10, 100 ]
[ 100, 10, 9, 1 ]
```

How the compare function works:

* If it returns a **negative** number, `a` comes before `b`.
* If it returns a **positive** number, `b` comes before `a`.
* If it returns `0`, the order stays as it is.
* `a - b` gives ascending order and `b - a` gives descending order.

## 6. Sorting Strings and Objects

Uppercase letters sort before lowercase letters in the default order. Use `localeCompare()` for natural alphabetical order.

```javascript
const items = ["Banana", "apple", "Cherry"];

console.log([...items].sort());
console.log([...items].sort((a, b) => a.localeCompare(b)));
```

```output
[ 'Banana', 'Cherry', 'apple' ]
[ 'apple', 'Banana', 'Cherry' ]
```

Sorting objects by a property:

```javascript
const students = [
  { name: "Asha", marks: 85 },
  { name: "Ravi", marks: 92 },
  { name: "Meena", marks: 78 }
];

const byMarks = [...students]
  .sort((a, b) => b.marks - a.marks)
  .map(s => `${s.name} (${s.marks})`);

const byName = [...students]
  .sort((a, b) => a.name.localeCompare(b.name))
  .map(s => s.name);

console.log(byMarks);
console.log(byName);
```

```output
[ 'Ravi (92)', 'Asha (85)', 'Meena (78)' ]
[ 'Asha', 'Meena', 'Ravi' ]
```

## 7. Sorting Without Changing the Original

Since `sort()` modifies the array, copy it first with `[...array]`. Modern browsers also provide `toSorted()` and `toReversed()`, which return a new array.

```javascript
const original = [3, 1, 2];

const copySorted = [...original].sort((a, b) => a - b);
const newSorted = original.toSorted((a, b) => b - a);

console.log(original);
console.log(copySorted);
console.log(newSorted);
```

```output
[ 3, 1, 2 ]
[ 1, 2, 3 ]
[ 3, 2, 1 ]
```

---

## 8. Reversing an Array

```javascript
const list = [1, 2, 3];

console.log(list.toReversed());
console.log(list);

list.reverse();
console.log(list);
```

```output
[ 3, 2, 1 ]
[ 1, 2, 3 ]
[ 3, 2, 1 ]
```

`reverse()` changes the original array, while `toReversed()` returns a new one.

## 9. Iterating with Loops

JavaScript offers several ways to go through an array.

```javascript
const letters = ["a", "b", "c"];

for (let i = 0; i < letters.length; i++) {
  console.log(i, letters[i]);
}

for (const ch of letters) {
  console.log(ch);
}

letters.forEach((ch, i) => console.log(`${i}-${ch}`));
```

```output
0 a
1 b
2 c
a
b
c
0-a
1-b
2-c
```

| Style | Best for |
| ----- | -------- |
| `for` | Full control, custom steps, needing the index |
| `for...of` | Simple reading of every value, supports `break` and `continue` |
| `forEach` | Running a function on each element |

---

## 10. entries() and for...in

`entries()` gives both the index and the value. `for...in` loops over **property names**, which are strings, so it is not recommended for arrays.

```javascript
const letters = ["a", "b"];

for (const [i, ch] of letters.entries()) {
  console.log(i, ch);
}

for (const i in letters) {
  console.log(i, typeof i);
}
```

```output
0 a
1 b
0 string
1 string
```

The `[i, ch]` form is called destructuring, which you will study in Chapter 6.

---

## 11. break and continue

`for...of` supports `break` (stop the loop) and `continue` (skip to the next element). `forEach` does not.

```javascript
for (const n of [1, 2, 3, 4, 5]) {
  if (n === 4) break;
  if (n % 2 === 0) continue;
  console.log(n);
}
```

```output
1
3
```

The loop skips `2`, prints `1` and `3`, and stops completely when it reaches `4`.

## Real-World Example 🌍

Building a game leaderboard:

```javascript
const players = [
  { name: "Asha", score: 420 },
  { name: "Ravi", score: 560 },
  { name: "Meena", score: 380 },
  { name: "Kiran", score: 490 }
];

const ranked = [...players].sort((a, b) => b.score - a.score);

ranked.forEach((p, i) => {
  console.log(`${i + 1}. ${p.name} - ${p.score}`);
});

console.log(players.some(p => p.score >= 1000));
console.log(players.every(p => p.score > 0));
console.log(players.find(p => p.name === "Asha").score);
```

```output
1. Ravi - 560
2. Kiran - 490
3. Asha - 420
4. Meena - 380
false
true
420
```

## Common Mistakes

### Sorting Numbers Without a Compare Function

```javascript
[10, 9, 1].sort();                    // [ 1, 10, 9 ], sorted as text
[10, 9, 1].sort((a, b) => a - b);     // [ 1, 9, 10 ], correct
```

### Forgetting That sort Changes the Original

```javascript
const scores = [3, 1, 2];
scores.sort((a, b) => a - b);                  // scores is now changed
const safe = [...scores].sort((a, b) => b - a);  // original stays untouched
```

### Using indexOf to Find Objects

```javascript
const users = [{ id: 1 }];
users.indexOf({ id: 1 });                // -1, a different object in memory
users.findIndex(u => u.id === 1);        // 0, correct
```

### Treating find Like filter

```javascript
const nums = [5, 8, 12, 20];
nums.find(n => n > 10);      // 12, only the first match
nums.filter(n => n > 10);    // [ 12, 20 ], all matches
```

### Using for...in on Arrays

```javascript
for (const i in ["a", "b"]) { }    // i is the string "0", "1"
for (const v of ["a", "b"]) { }    // v is "a", "b", correct
```

## Key Points

* `indexOf()` returns a position or `-1`; `includes()` returns `true` or `false`.
* `find()` returns the first matching element and `findIndex()` returns its position.
* `some()` checks that at least one element passes; `every()` checks that all pass.
* `sort()` changes the original array and sorts as text by default.
* Use `(a, b) => a - b` for ascending numbers and `(a, b) => b - a` for descending.
* Use `localeCompare()` to sort strings alphabetically.
* Copy with `[...array]` or use `toSorted()` and `toReversed()` to keep the original safe.
* `for...of` is the cleanest loop for reading values and supports `break` and `continue`.
* `entries()` gives the index and value together; avoid `for...in` on arrays.

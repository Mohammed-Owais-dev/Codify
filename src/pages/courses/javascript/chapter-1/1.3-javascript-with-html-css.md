# Chapter 1: Introduction to JavaScript

## Section 3: JavaScript with HTML and CSS

A modern web page is built from three layers: HTML, CSS and JavaScript. In this section you will see how they work together and how to add JavaScript to a web page.

---

## 1. The Three Layers of a Web Page

| Layer | Language | Question it answers |
| --- | --- | --- |
| Structure | HTML | What is on the page? |
| Presentation | CSS | How does it look? |
| Behavior | JavaScript | What does it do? |

Think of a **button**: HTML creates it, CSS gives it color and size, and JavaScript decides what happens when you click it.

---

## 2. Step 1: HTML Only

HTML alone creates a plain page. Press **Run** to see it.

```html
<!DOCTYPE html>
<html>
<body>
  <h2 id="title">Welcome to Codify</h2>
  <button id="btn">Change title</button>
</body>
</html>
```

The button exists, but clicking it does nothing yet.

---

## 3. Step 2: Add CSS

CSS controls the appearance. It is usually written inside a `<style>` tag.

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    h2 { color: darkblue; font-family: Arial, sans-serif; }
    button { padding: 8px 16px; background: #4f46e5; color: white; border: none; border-radius: 6px; }
  </style>
</head>
<body>
  <h2 id="title">Welcome to Codify</h2>
  <button id="btn">Change title</button>
</body>
</html>
```

The page looks better, but it still does nothing when clicked.

---

## 4. Step 3: Add JavaScript

JavaScript is written inside a `<script>` tag. Now the button works.

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    h2 { color: darkblue; font-family: Arial, sans-serif; }
    button { padding: 8px 16px; background: #4f46e5; color: white; border: none; border-radius: 6px; }
  </style>
</head>
<body>
  <h2 id="title">Welcome to Codify</h2>
  <button id="btn">Change title</button>

  <script>
    document.getElementById("btn").addEventListener("click", function () {
      document.getElementById("title").textContent = "JavaScript is working!";
    });
  </script>
</body>
</html>
```

Here is what the script does:

1. `document.getElementById("btn")` finds the button on the page.
2. `addEventListener("click", ...)` waits for a click.
3. When clicked, the function changes the text of the heading.

> 💡 The part of JavaScript that talks to the page is called the **DOM** (Document Object Model). You will study it in Chapter 7.

---

## 5. Three Ways to Add JavaScript

### 1. Inline JavaScript

Written directly inside an HTML attribute.

```html
<!DOCTYPE html>
<html>
<body>
  <button onclick="this.textContent = 'Clicked!'">Click me</button>
</body>
</html>
```

Inline code is quick for demos but hard to maintain. Avoid it in real projects.

### 2. Internal JavaScript

Written inside a `<script>` tag in the same HTML file (as in Step 3 above). Good for small pages and practice.

### 3. External JavaScript

Written in a separate `.js` file and linked with the `src` attribute. This is the **recommended** way.

File `index.html`:

```text
<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
  <script src="script.js" defer></script>
</head>
<body>
  <h1 id="heading">Hello</h1>
</body>
</html>
```

File `script.js`:

```javascript
document.getElementById("heading").textContent = "Hello from script.js";
console.log("External file loaded");
```

```output
External file loaded
```

Benefits of external files:

* HTML, CSS and JavaScript stay separate and tidy.
* One `.js` file can be reused on many pages.
* The browser can cache the file, so pages load faster.

---

## 6. Where to Place the `<script>` Tag

A script runs as soon as the browser reaches it. If the script is placed **before** the elements it needs, it cannot find them.

| Placement | Result |
| --- | --- |
| End of `<body>` | Works: the elements already exist |
| In `<head>` with `defer` | Works: waits until the HTML is loaded |
| In `<head>` without `defer` | The script runs too early and may fail |

```text
<!-- Recommended -->
<script src="script.js" defer></script>
```

## 7. JavaScript and CSS Working Together

JavaScript can change CSS styles and classes. In this example the button adds and removes a highlight class.

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    .box { width: 160px; padding: 20px; background: #e5e7eb; text-align: center; font-family: Arial, sans-serif; }
    .active { background: #22c55e; color: white; }
  </style>
</head>
<body>
  <div id="box" class="box">Box</div>
  <br>
  <button id="toggle">Toggle highlight</button>

  <script>
    document.getElementById("toggle").addEventListener("click", function () {
      document.getElementById("box").classList.toggle("active");
    });
  </script>
</body>
</html>
```

CSS defines how `.active` looks, and JavaScript decides **when** to apply it.

---

## 8. The `<noscript>` Tag

Some users turn JavaScript off. Use `<noscript>` to show a message to them.

```html
<!DOCTYPE html>
<html>
<body>
  <noscript>Please enable JavaScript to use this page.</noscript>
  <p>Page content here.</p>
</body>
</html>
```

## Real-World Example

A greeting that changes with the time of day. Press **Run** to see your own greeting.

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    body { font-family: Arial, sans-serif; text-align: center; padding: 30px; }
    h2 { color: #4f46e5; }
  </style>
</head>
<body>
  <h2 id="greeting"></h2>

  <script>
    const hour = new Date().getHours();
    let greeting;

    if (hour < 12) {
      greeting = "Good Morning!";
    } else if (hour < 18) {
      greeting = "Good Afternoon!";
    } else {
      greeting = "Good Evening!";
    }

    document.getElementById("greeting").textContent = greeting;
  </script>
</body>
</html>
```

HTML provides the heading, CSS styles it, and JavaScript chooses the message. You will learn `if` and `else` in Chapter 3.

## Common Mistakes

### Placing the Script Before the Elements

```text
<script>
  document.getElementById("btn").textContent = "Hi";    // btn does not exist yet
</script>
<button id="btn">Click</button>
```

Move the script to the end of `<body>`, or use `defer`.

### Wrong File Path in `src`

```text
<script src="scripts/app.js"></script>    // file not found if the path is wrong
```

Check the file name, the folder and the capitalization.

### Putting Code Inside a Script That Has `src`

```text
<script src="app.js">
  console.log("This code is ignored");
</script>
```

A `<script>` tag with `src` ignores any code written inside it.

### Using the Wrong `id`

`getElementById("Btn")` will not find an element with `id="btn"`. IDs are case-sensitive.

### Forgetting the Closing `</script>` Tag

Every `<script>` needs a closing `</script>`.

---

## Key Points

* HTML gives structure, CSS gives style, JavaScript gives behavior.
* JavaScript is added with the `<script>` tag.
* You can write JavaScript inline, internally, or in an external `.js` file.
* External files are the recommended approach.
* Place scripts at the end of `<body>` or use `defer`.
* JavaScript can change content and CSS classes on a page.
* `<noscript>` shows a message when JavaScript is turned off.

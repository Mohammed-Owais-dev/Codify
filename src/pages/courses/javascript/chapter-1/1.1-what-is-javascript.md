# Chapter 1: Introduction to JavaScript

## Section 1: What is JavaScript?

JavaScript is the programming language of the web. Every time you click a button, see a menu slide open, or watch a page update without reloading, JavaScript is most likely at work. In this section you will learn what JavaScript is, where it came from, and where it runs.

---

## 1. What is JavaScript?

**JavaScript** (often shortened to **JS**) is a high-level programming language used to make web pages **interactive**.

A web page is built from three technologies that work together:

| Technology | Role | Real-life comparison |
| --- | --- | --- |
| **HTML** | Structure and content | The walls and rooms of a house |
| **CSS** | Design and layout | Paint, furniture and decoration |
| **JavaScript** | Behavior and logic | Electricity: lights, switches and appliances |

Without JavaScript a page is static. With JavaScript it can respond to the user.

---

## 2. A Short History

* JavaScript was created in **1995** by **Brendan Eich** while working at **Netscape**, to add interactivity to the Netscape Navigator browser.
* It is standardized as **ECMAScript** (ES) by an organization called Ecma International.
* A major update, **ES6 (ECMAScript 2015)**, added modern features such as `let`, `const`, arrow functions and classes. A new version is released every year.

> The names "JavaScript" and "ECMAScript" are used almost interchangeably. ECMAScript is the official specification; JavaScript is the language you write.

---

## 3. JavaScript is Not Java

Despite the similar name, they are two different languages.

| Feature | JavaScript | Java |
| --- | --- | --- |
| Main use | Web pages, web apps, servers | Enterprise apps, Android, large systems |
| Typing | Dynamic (types decided at run time) | Static (types declared in advance) |
| Execution | Run by a JavaScript engine | Compiled to bytecode, run on the JVM |
| Syntax | C-like | C-like |
| Relationship | None | None |

---

## 4. Where Does JavaScript Run?

JavaScript needs a **JavaScript engine** to run. Every browser has one.

| Engine | Used in |
| --- | --- |
| **V8** | Google Chrome, Microsoft Edge, Node.js |
| **SpiderMonkey** | Mozilla Firefox |
| **JavaScriptCore** | Apple Safari |

JavaScript runs in two main places:

* **In the browser (client side):** controls the web page the user sees.
* **On a server (server side) using Node.js:** builds websites, APIs and tools outside the browser.

---

## 5. Your First Taste of JavaScript

The `console.log()` function prints a message to the console, which is a developer tool.

```javascript
console.log("Hello from JavaScript!");
console.log(2 + 3);
```

```output
Hello from JavaScript!
5
```

JavaScript can also change a page when the user acts. Press **Run** to see a live example.

```html
<!DOCTYPE html>
<html>
<body>
  <h2 id="message">Hello!</h2>
  <button onclick="document.getElementById('message').textContent = 'You clicked the button!'">
    Click me
  </button>
</body>
</html>
```

You do not need to understand this code yet. It shows that JavaScript can change what is on the page after the user clicks.

---

## 6. How JavaScript Code Runs

JavaScript is an **interpreted** language: the engine reads and runs your code directly, line by line, without a separate compile step by you. Modern engines also use **just-in-time (JIT) compilation** behind the scenes to make it fast.

The flow:

1. The browser downloads the HTML page.
2. It finds your JavaScript code.
3. The JavaScript engine runs the code.
4. The page updates based on what the code does.

## 7. What Can You Build with JavaScript?

* Interactive websites: menus, sliders, pop-ups, image galleries.
* Web applications such as email clients, chat apps and online editors.
* Server programs and APIs using Node.js.
* Mobile apps and desktop apps using JavaScript-based tools.
* Browser games and animations.

You will explore these uses in the next section.

## Real-World Example

Every time you "like" a post and the counter changes instantly without the page reloading, JavaScript is doing the work. Here is a tiny version:

```html
<!DOCTYPE html>
<html>
<body>
  <button id="likeBtn">Like</button>
  <p id="count">Likes: 0</p>

  <script>
    let likes = 0;
    const button = document.getElementById("likeBtn");

    button.addEventListener("click", function () {
      likes = likes + 1;
      document.getElementById("count").textContent = "Likes: " + likes;
    });
  </script>
</body>
</html>
```

Each click increases the number. Learning how to build this is exactly what this course is about.

## Common Mistakes

### Confusing JavaScript with Java

They are different languages with different uses. Learning one does not teach you the other.

### Thinking JavaScript Only Works in the Browser

JavaScript also runs outside the browser with Node.js.

### Writing `Javascript` or `javascript` in Code

The language name is not used in code, but keywords are **case-sensitive**: `console.log` works, `Console.Log` does not.

### Expecting JavaScript to Replace HTML and CSS

JavaScript works together with HTML and CSS. It does not replace them.

---

## Key Points

* JavaScript makes web pages interactive.
* It was created in 1995 by Brendan Eich at Netscape.
* It follows the ECMAScript standard; ES6 (2015) was a major update.
* JavaScript and Java are completely different languages.
* HTML gives structure, CSS gives style, JavaScript gives behavior.
* Engines such as V8, SpiderMonkey and JavaScriptCore run JavaScript.
* JavaScript runs in browsers and on servers with Node.js.
* `console.log()` prints messages for developers.

# Chapter 1: Introduction to JavaScript

## Section 4: Setting Up JavaScript and VS Code

The good news: you already have almost everything you need to start. Every browser runs JavaScript. In this section you will set up a comfortable workspace with the browser console, Visual Studio Code and, optionally, Node.js.

---

## 1. What You Need

| Tool | Purpose | Required? |
| --- | --- | --- |
| Web browser (Chrome, Edge, Firefox) | Runs JavaScript and shows your pages | Yes |
| Code editor (VS Code) | Where you write code | Yes |
| Live Server extension | Auto-reloads your page when you save | Recommended |
| Node.js | Runs JavaScript outside the browser | Optional |

---

## 2. Option 1: The Browser Console

The quickest way to try JavaScript is the **developer console** that is built into every browser. No installation needed.

How to open it:

| Browser / System | Shortcut |
| --- | --- |
| Any browser, Windows/Linux | `F12` or `Ctrl + Shift + I` |
| Chrome / Edge, Windows/Linux (opens Console directly) | `Ctrl + Shift + J` |
| Chrome, Mac | `Cmd + Option + J` |
| Safari, Mac | Enable the Develop menu first, then `Cmd + Option + C` |

You can also right-click a page, choose **Inspect**, and open the **Console** tab.

Type this in the console and press **Enter**:

```javascript
console.log("Hello from the console!");
```

```output
Hello from the console!
```

The console is perfect for testing small ideas. For real projects, use a code editor.

---

## 3. Option 2: Install Visual Studio Code

**Visual Studio Code (VS Code)** is a free, popular code editor.

Steps:

1. Go to the official website `code.visualstudio.com`.
2. Download the installer for your operating system (Windows, macOS or Linux).
3. Run the installer and follow the steps.
4. Open VS Code after installation.

---

## 4. Useful VS Code Extensions

Open the **Extensions** panel (`Ctrl + Shift + X`), search by name and click **Install**.

| Extension | Why it helps |
| --- | --- |
| **Live Server** | Opens your page in the browser and reloads it automatically on save |
| **Prettier** | Formats your code neatly |
| **ESLint** (optional) | Warns about common mistakes |

---

## 5. Create Your First Project Folder

1. Create a new folder on your computer, for example `js-practice`.
2. In VS Code choose **File → Open Folder** and select it.
3. Create two files inside the folder: `index.html` and `script.js`.

Your project should look like this:

```text
js-practice/
├── index.html
└── script.js
```

---

## 6. Write the HTML File

In `index.html`, type `!` and press `Tab` (or `Enter`). VS Code creates the HTML boilerplate for you. Then add a heading and link your script.

```text
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>JS Practice</title>
  <script src="script.js" defer></script>
</head>
<body>
  <h1>My JavaScript Practice</h1>
</body>
</html>
```

---

## 7. Write the JavaScript File

In `script.js`, write:

```javascript
console.log("Setup complete!");
```

```output
Setup complete!
```

---

## 8. Run the Page with Live Server

1. Right-click `index.html` in VS Code.
2. Choose **Open with Live Server** (or click **Go Live** at the bottom right).
3. Your browser opens the page.
4. Press `F12` and open the **Console** tab to see `Setup complete!`.

Whenever you edit and save a file, the page refreshes automatically.

> 💡 You can also open `index.html` by double-clicking it. Live Server is simply more convenient because it reloads for you.

---

## 9. Optional: Install Node.js

**Node.js** lets you run JavaScript files from the terminal, without a browser.

1. Go to `nodejs.org`.
2. Download the **LTS** (Long Term Support) version and install it.
3. Open a terminal and check the installation:

```bash
node -v
```

```output
v22.12.0
```

Your version number will be different, and that is fine. Now run a file:

```bash
node script.js
```

```output
Setup complete!
```

In VS Code you can open the built-in terminal with ``Ctrl + ` `` (the backtick key).

> 💡 Node.js has no web page, so browser features such as `document` and `alert()` are not available there. You will use `console.log()` for output.

## Real-World Example

A small checklist for your first practice page. Create `script.js` with this code, link it in `index.html`, and open the page with Live Server:

```javascript
console.log("Editor: VS Code");
console.log("Browser: ready");
console.log("Project folder: js-practice");
console.log("Setup complete!");
```

```output
Editor: VS Code
Browser: ready
Project folder: js-practice
Setup complete!
```

If you can see these four lines in the browser console, your environment is ready.

## Common Mistakes

### Forgetting to Save the File

The browser shows old results if you do not save. Press `Ctrl + S` (or enable auto-save).

### Wrong File Name or Path in `src`

If `script.js` is spelled differently or is in another folder, the browser cannot find it. Check the **Network** or **Console** tab for a "404" error.

### Looking for Output in the Wrong Place

`console.log()` output appears in the **Console** tab of DevTools, not on the page itself.

### Using `node` for Browser Code

`document.getElementById()` works only in a browser. Node.js will report `document is not defined`.

### Editing a File Outside the Opened Folder

Always open the whole folder in VS Code so that all your project files stay together.

---

## Key Points

* A browser and a code editor are enough to start JavaScript.
* The browser console is great for quick experiments.
* VS Code is a free and popular editor.
* The Live Server extension reloads your page automatically.
* `!` + `Tab` creates an HTML boilerplate in VS Code.
* Node.js is optional and runs JavaScript from the terminal.
* Open the console with `F12` or `Ctrl + Shift + J`.

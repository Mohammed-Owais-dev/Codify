# Chapter 1: Introduction to JavaScript

## Section 2: Features and Uses of JavaScript

JavaScript is one of the most widely used programming languages in the world. In this section you will learn what makes it special and where it is used.

---

## 1. Key Features of JavaScript

| Feature | Meaning |
| --- | --- |
| Interpreted | Code is run directly by the engine, without a manual compile step |
| Dynamically typed | The type of a variable is decided while the program runs |
| Case-sensitive | `name` and `Name` are different |
| Object-based | Data and behavior are organized with objects |
| Multi-paradigm | Supports procedural, object-oriented and functional styles |
| Event-driven | Code can react to clicks, key presses and other events |
| Asynchronous | Can start slow tasks and continue without waiting |
| Cross-platform | Runs in any browser on any operating system |

---

## 2. Dynamic Typing

You do not declare the type of a variable. The same variable can hold different types of values over time.

```javascript
let value = 10;
console.log(typeof value);

value = "ten";
console.log(typeof value);
```

```output
number
string
```

`typeof` tells you the type of a value. First `value` held a number, then a string.

---

## 3. Case Sensitivity

JavaScript treats uppercase and lowercase letters as different.

```javascript
let name = "Asha";

console.log(name);
console.log(typeof Name);
```

```output
Asha
undefined
```

`Name` was never created, so `typeof Name` reports `undefined`.

---

## 4. Objects

An **object** groups related data together using `key: value` pairs.

```javascript
let student = {
  name: "Asha",
  age: 20
};

console.log(student.name);
console.log(student.age);
```

```output
Asha
20
```

You will study objects in detail in Chapter 6.

---

## 5. Asynchronous Behavior

JavaScript can start a slow task, such as a timer or a network request, and keep running other code in the meantime.

```javascript
console.log("First");

setTimeout(function () {
  console.log("Third (after 1 second)");
}, 1000);

console.log("Second");
```

```output
First
Second
Third (after 1 second)
```

The timer waits in the background, so `Second` prints before the delayed message.

---

## 6. Event-Driven Programming

JavaScript waits for **events** such as clicks and runs your code in response. Press **Run** and click the button.

```html
<!DOCTYPE html>
<html>
<body>
  <button id="btn">Click me</button>
  <p id="info">Clicks: 0</p>

  <script>
    let clicks = 0;

    document.getElementById("btn").addEventListener("click", function () {
      clicks = clicks + 1;
      document.getElementById("info").textContent = "Clicks: " + clicks;
    });
  </script>
</body>
</html>
```

## 7. Where is JavaScript Used?

| Area | What JavaScript does | Examples |
| --- | --- | --- |
| Web pages | Menus, sliders, form checks, animations | Interactive websites |
| Front-end apps | Builds rich user interfaces | Libraries and frameworks such as React, Vue, Angular |
| Back-end | Runs servers and APIs | Node.js |

---

## 8. Strengths and Limitations

### Strengths

* Easy to start: you only need a browser.
* Huge community and a very large package library (npm).
* One language for both front end and back end.
* Fast, thanks to modern engines.

### Limitations

* Browser JavaScript runs in a **sandbox**: it cannot freely read files on your computer, for safety.
* Dynamic typing can hide mistakes until the code runs.
* Different older browsers may support features differently.

## Real-World Example

A dark mode toggle, a feature found on many websites, takes only a few lines. Press **Run** and click the button.

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    body { font-family: Arial, sans-serif; padding: 20px; }
    .dark { background: #1e1e1e; color: #ffffff; }
  </style>
</head>
<body>
  <h3>Toggle the theme</h3>
  <button id="themeBtn">Switch theme</button>

  <script>
    document.getElementById("themeBtn").addEventListener("click", function () {
      document.body.classList.toggle("dark");
    });
  </script>
</body>
</html>
```

## Common Mistakes

### Assuming Types are Fixed

```javascript
let age = 20;
age = "twenty";    // allowed, but can cause bugs
```

Use clear variable names and keep one type per variable.

### Wrong Capitalization

```javascript
Console.log("Hi");    // ReferenceError
```

Use `console.log("Hi");`.

### Expecting Code to Wait for a Timer

```javascript
setTimeout(function () { console.log("Later"); }, 1000);
console.log("Now");
```

`Now` prints first. Asynchronous code does not block the rest of the program.

### Thinking JavaScript Can Access Any File in the Browser

Browsers block this for security. Server-side JavaScript (Node.js) can work with files.

---

## Key Points

* JavaScript is interpreted, dynamically typed and case-sensitive.
* It supports objects and several programming styles.
* It is event-driven and handles asynchronous tasks.
* It runs on every major browser and on servers through Node.js.
* It powers websites, web apps, servers, mobile apps, desktop apps and games.
* `typeof` shows the type of a value.
* Browser JavaScript is sandboxed for security.

# Chapter 1: Introduction to JavaScript

## Section 5: Your First JavaScript Program

Your environment is ready, so it is time to write and run your first JavaScript program.

---

## 1. Hello, World!

The traditional first program prints a message.

```javascript
console.log("Hello, World!");
```

```output
Hello, World!
```

That is the complete program. There is no `main` function and no extra setup.

---

## 2. Understanding `console.log()`

`console.log()` prints a value to the console.

```javascript
console.log("Welcome to JavaScript");
```

```output
Welcome to JavaScript
```

* `console` is a built-in object that gives access to the developer console.
* `log` is a **method** (a function that belongs to an object) that displays output.
* `()` holds what we want to display.
* `"Welcome to JavaScript"` is a **string**, which is text inside quotes.
* `;` ends the statement.

---

## 3. Three Kinds of Quotes

Strings can use single quotes, double quotes or backticks.

```javascript
console.log("Hello");
console.log('Hello');
console.log(`Hello`);
```

```output
Hello
Hello
Hello
```

Backticks (template literals) have a special power, which you will see shortly.

---

## 4. Printing Numbers

Numbers do not need quotes.

```javascript
console.log(100);
console.log(5 + 3);
```

```output
100
8
```

JavaScript calculates `5 + 3` and prints the result.

---

## 5. Printing Multiple Lines

Each `console.log()` prints on a new line.

```javascript
console.log("Line 1");
console.log("Line 2");
console.log("Line 3");
```

```output
Line 1
Line 2
Line 3
```

---

## 6. Printing Multiple Values

Separate values with commas.

```javascript
console.log("Age:", 20);
console.log("Name:", "Asha", "City:", "Hyderabad");
```

```output
Age: 20
Name: Asha City: Hyderabad
```

`console.log()` adds a space between the values automatically.

---

## 7. Joining Text with `+`

The `+` operator joins strings together. This is called **concatenation**.

```javascript
console.log("Hello, " + "Asha");
```

```output
Hello, Asha
```

---

## 8. Variables and Template Literals

A variable stores a value. You will study variables in Chapter 2, but here is a preview.

```javascript
let name = "Asha";
let city = "Hyderabad";

console.log(name);
console.log(`Hello, ${name} from ${city}!`);
```

```output
Asha
Hello, Asha from Hyderabad!
```

Inside backticks, `${...}` inserts the value of a variable or expression into the text.

---

## 9. Comments

Comments are notes for humans. JavaScript ignores them.

```javascript
// This is a single-line comment
console.log("Hello"); // a comment after code

/*
  This is a
  multi-line comment
*/
console.log("Done");
```

```output
Hello
Done
```

* `//` starts a single-line comment.
* `/* ... */` can span many lines.

---

## 10. Showing Output on the Web Page

`console.log()` is for developers. To show text to visitors, change an element on the page. Press **Run**.

```html
<!DOCTYPE html>
<html>
<body>
  <h2 id="output">Waiting...</h2>

  <script>
    document.getElementById("output").textContent = "Hello, World!";
  </script>
</body>
</html>
```

---

## 11. Getting Input in the Browser

In a browser, `prompt()` shows a box that asks the user to type something, and it returns the text.

```javascript
let name = prompt("Enter your name:");
console.log("Hello, " + name + "!");
```

If the user enters:

```text
Asha
```

The output will be:

```output
Hello, Asha!
```

> 💡 `prompt()` and `alert()` work in a real browser page. They do not work in Node.js and are blocked inside the live preview on this site.

---

## 12. Running Your Program

### In the Browser

1. Save your code in `script.js`.
2. Link it in `index.html` with `<script src="script.js" defer></script>`.
3. Open the page and view the Console tab (`F12`).

### With Node.js

```bash
node script.js
```

---

## 13. Understanding Errors

If you make a mistake, JavaScript shows an error message in the console.

```javascript
console.log(Hello);
```

```output
ReferenceError: Hello is not defined
```

Read the message and the line number carefully. Errors are a normal part of programming.

---

## Real-World Example 🌍

A simple greeting program that asks for a name and a city:

```javascript
let name = prompt("Enter your name:");
let city = prompt("Enter your city:");

console.log("Hello " + name + " from " + city);
```

If the user enters:

```text
Asha
Hyderabad
```

The output will be:

```output
Hello Asha from Hyderabad
```

## Common Mistakes

### Writing `Console.log` Instead of `console.log`

JavaScript is case-sensitive.

```javascript
Console.log("Hello");    // ReferenceError
```

Use:

```javascript
console.log("Hello");
```

### Forgetting the Quotes

```javascript
console.log(Hello);    // ReferenceError
```

Text must be inside quotes:

```javascript
console.log("Hello");
```

### Forgetting the Closing Bracket or Quote

```javascript
console.log("Hello";    // SyntaxError
console.log("Hello);    // SyntaxError
```

### Mixing Quote Types

```javascript
console.log("Hello');    // SyntaxError
```

Start and end a string with the same kind of quote.

### Using `print()` from Other Languages

```javascript
print("Hello");    // In a browser this opens the print dialog; it does not display text
```

Use `console.log()`.

---

## Key Points

* `console.log()` displays output in the console.
* Text must be written inside quotes; numbers do not need quotes.
* Each `console.log()` prints on a new line.
* Separate several values with commas.
* Use `+` or template literals to join text and variables.
* `//` starts a single-line comment and `/* */` a multi-line comment.
* `prompt()` reads input in the browser.
* JavaScript is case-sensitive.
* Run code in a browser console or with `node filename.js`.

# Chapter 4: Functions and Scope

## Section 3: Function Expressions and Arrow Functions

So far you have created functions with the `function` keyword. JavaScript offers two more ways: **function expressions** and **arrow functions**. Modern code uses them everywhere, so it is important to understand them.

---

## 1. Functions are Values

In JavaScript, a function is a **value**, just like a number or a string. It can be stored in a variable, passed to another function and returned from a function.

```javascript
function hello() {
  return "Hello!";
}

const greet = hello;
console.log(greet());
```

```output
Hello!
```

This idea makes function expressions and arrow functions possible.

---

## 2. Function Expressions

A **function expression** creates a function and stores it in a variable.

**Syntax:**

```text
const name = function (parameters) {
  // code
};
```

```javascript
const add = function (a, b) {
  return a + b;
};

console.log(add(2, 3));
```

```output
5
```

The function has no name of its own, so it is called an **anonymous function**. It is called through the variable `add`.

Note the semicolon at the end. The whole line is a variable declaration.

---

## 3. Named Function Expressions

A function expression can also have its own name. The name is available only **inside** the function, which is useful for recursion and for readable error messages.

```javascript
const factorial = function fact(n) {
  return n <= 1 ? 1 : n * fact(n - 1);
};

console.log(factorial(5));
```

```output
120
```

---

## 4. Declarations vs Expressions: Hoisting

A function **declaration** is hoisted, so you can call it before it is defined. A function **expression** is not usable before its line.

```javascript
console.log(square(4));

function square(n) {
  return n * n;
}
```

```output
16
```

```javascript
console.log(multiply(2, 3));

const multiply = function (a, b) {
  return a * b;
};
```

```output
ReferenceError: Cannot access 'multiply' before initialization
```

---

## 5. Arrow Functions

**Arrow functions** are a shorter way to write function expressions. They were added in ES6 (2015).

**Syntax:**

```text
const name = (parameters) => expression;
```

```javascript
const add = (a, b) => {
  return a + b;
};

console.log(add(2, 3));
```

```output
5
```

---

## 6. Shorter Arrow Function Forms

Arrow functions can be shortened in several steps.

### 1. Implicit Return

If the body is a single expression, remove `{ }` and `return`. The value is returned automatically.

```javascript
const add = (a, b) => a + b;

console.log(add(4, 6));
```

```output
10
```

### 2. One Parameter: Parentheses Are Optional

```javascript
const square = x => x * x;

console.log(square(5));
```

```output
25
```

### 3. No Parameters: Use Empty Parentheses

```javascript
const sayHello = () => "Hello!";

console.log(sayHello());
```

```output
Hello!
```

### 4. Several Statements: Use Braces and `return`

```javascript
const describe = (name, age) => {
  const status = age >= 18 ? "adult" : "minor";
  return `${name} is an ${status}`;
};

console.log(describe("Asha", 20));
```

```output
Asha is an adult
```

---

## 7. Returning an Object from an Arrow Function

Curly braces after `=>` start a function body. To return an object literal directly, wrap it in parentheses.

```javascript
const makeUser = name => ({ name: name, active: true });

console.log(makeUser("Asha"));
```

```output
{ name: 'Asha', active: true }
```

Without the parentheses, the braces would be treated as a function body and the function would return `undefined`.

---

## 8. Arrow Functions with Array Methods

Arrow functions are very popular with array methods, which you will study in Chapter 5.

```javascript
const numbers = [1, 2, 3, 4];

const doubled = numbers.map(n => n * 2);
const evens = numbers.filter(n => n % 2 === 0);

console.log(doubled);
console.log(evens);
```

```output
[ 2, 4, 6, 8 ]
[ 2, 4 ]
```

---

## 9. Functions Stored in Objects

```javascript
const calculator = {
  add: (a, b) => a + b,
  subtract: (a, b) => a - b
};

console.log(calculator.add(5, 3));
console.log(calculator.subtract(5, 3));
```

```output
8
2
```

---

## 10. Immediately Invoked Function Expressions (IIFE)

An **IIFE** is a function that runs as soon as it is defined. It creates a private scope.

```javascript
(function () {
  console.log("Runs immediately");
})();

(() => {
  console.log("Arrow IIFE");
})();
```

```output
Runs immediately
Arrow IIFE
```

---

## 11. Differences Between Regular and Arrow Functions

| Feature | Regular function | Arrow function |
| --- | --- | --- |
| Syntax | `function (a) { }` | `(a) => { }` |
| Hoisting (declaration form) | Yes | No (always a variable) |
| Own `this` | Yes | No, uses the surrounding `this` |
| `arguments` object | Yes | No |
| Can be used as a constructor with `new` | Yes | No |
| Best for | Methods and general functions | Short callbacks and simple helpers |

The `arguments` object holds all arguments of a regular function.

```javascript
function showCount() {
  console.log(arguments.length);
}

showCount(10, 20, 30);
```

```output
3
```

Arrow functions do not have `arguments`. Use rest parameters instead: `(...args) => args.length`.

> 💡 The `this` keyword is explained in Chapter 6. For now remember: use arrow functions for short callbacks, and regular functions for object methods.

---

## 12. Which Style Should I Use?

* **Function declaration:** named, top-level helper functions.
* **Arrow function:** short callbacks, array methods and small utilities.
* **Function expression:** when you need a function stored in a variable but prefer the regular syntax.

---

## Real-World Example 🌍

A price formatter applied to a list of prices:

```javascript
const formatPrice = amount => `₹${amount.toFixed(2)}`;

const prices = [250, 99.5, 1200];
const labels = prices.map(formatPrice);

console.log(labels);
```

```output
[ '₹250.00', '₹99.50', '₹1200.00' ]
```

## Common Mistakes

### Calling an Expression Before It Is Defined

```javascript
sayHi();                    // ReferenceError
const sayHi = () => "Hi";
```

Define the function first.

### Forgetting Parentheses Around a Returned Object

```javascript
const makeUser = name => { name: name };    // returns undefined
```

Use `name => ({ name: name })`.

### Forgetting `return` in a Block Body

```javascript
const add = (a, b) => { a + b };    // returns undefined
```

Either write `return a + b;` or remove the braces.

### Using an Arrow Function as an Object Method That Needs `this`

Arrow functions do not have their own `this`. Use a regular function for such methods.

### Reassigning a `const` Function

```javascript
const greet = () => "Hi";
greet = () => "Hello";    // TypeError
```

---

## Key Points

* Functions are values: they can be stored, passed and returned.
* A function expression stores a function in a variable.
* Function declarations are hoisted; expressions and arrow functions are not.
* Arrow functions use `=>` and can return values implicitly.
* Wrap a returned object literal in parentheses: `() => ({ ... })`.
* Arrow functions have no own `this` and no `arguments` object.
* An IIFE runs immediately and creates a private scope.
* Arrow functions are ideal for short callbacks.

# Chapter 4: Functions and Scope

## Section 2: Parameters, Arguments and Return Values

Functions become powerful when they can receive **inputs** and give back **results**. Inputs are passed through parameters and arguments, and results come back with `return`.

---

## 1. Parameters and Arguments

* A **parameter** is a variable listed in the function definition.
* An **argument** is the actual value you pass when calling the function.

```javascript
function greet(name) {
  console.log("Hello, " + name);
}

greet("Asha");
greet("Ravi");
```

```output
Hello, Asha
Hello, Ravi
```

Here `name` is the parameter, and `"Asha"` and `"Ravi"` are arguments.

---

## 2. Multiple Parameters

Separate parameters with commas. Arguments are matched **by position**.

```javascript
function introduce(name, age) {
  console.log(`${name} is ${age} years old`);
}

introduce("Asha", 20);
```

```output
Asha is 20 years old
```

The order matters:

```javascript
function subtract(a, b) {
  return a - b;
}

console.log(subtract(10, 3));
console.log(subtract(3, 10));
```

```output
7
-7
```

---

## 3. The `return` Statement

`return` sends a value back to the place where the function was called, and ends the function.

```javascript
function add(a, b) {
  return a + b;
}

const result = add(10, 20);
console.log(result);
console.log(add(5, 7) * 2);
```

```output
30
24
```

The returned value can be stored, printed or used inside another expression.

---

## 4. `console.log()` vs `return`

| `console.log()` | `return` |
| --- | --- |
| Shows a value on the screen | Sends a value back to the caller |
| The value cannot be reused | The value can be stored and reused |
| The function result is `undefined` | The function result is the returned value |

```javascript
function show(x) {
  console.log(x * 2);
}

function calc(x) {
  return x * 2;
}

const a = show(5);
console.log(a);

const b = calc(5);
console.log(b);
```

```output
10
undefined
10
```

---

## 5. `return` Ends the Function

Code after `return` never runs. A function can have several `return` statements.

```javascript
function check(n) {
  if (n < 0) {
    return "Negative";
  }
  return "Non-negative";
}

console.log(check(-5));
console.log(check(3));
```

```output
Negative
Non-negative
```

---

## 6. Returning Booleans

Functions that answer yes/no questions usually return `true` or `false`.

```javascript
function isEven(n) {
  return n % 2 === 0;
}

console.log(isEven(4));
console.log(isEven(7));
```

```output
true
false
```

---

## 7. Missing and Extra Arguments

JavaScript does not check the number of arguments.

* A **missing** argument becomes `undefined`.
* An **extra** argument is ignored.

```javascript
function show(a, b) {
  console.log(a, b);
}

show(1);
show(1, 2, 3);
```

```output
1 undefined
1 2
```

---

## 8. Default Parameters

Give a parameter a **default value** that is used when no argument is passed.

```javascript
function greet(name = "Guest", greeting = "Hello") {
  console.log(`${greeting}, ${name}!`);
}

greet();
greet("Asha");
greet("Ravi", "Good morning");
```

```output
Hello, Guest!
Hello, Asha!
Good morning, Ravi!
```

---

## 9. Rest Parameters

Use `...name` to accept any number of arguments. They are collected into an **array**.

```javascript
function sumAll(...numbers) {
  let total = 0;

  for (const n of numbers) {
    total += n;
  }

  return total;
}

console.log(sumAll(1, 2, 3));
console.log(sumAll(10, 20, 30, 40));
console.log(sumAll());
```

```output
6
100
0
```

The rest parameter must be the **last** parameter.

---

## 10. Returning Several Values

A function returns one value, but that value can be an array or an object holding several items.

```javascript
function minMax(numbers) {
  return [Math.min(...numbers), Math.max(...numbers)];
}

const [low, high] = minMax([4, 9, 1, 7]);
console.log(low, high);

function getStudent() {
  return { name: "Asha", marks: 85 };
}

const student = getStudent();
console.log(student.name, student.marks);
```

```output
1 9
Asha 85
```

---

## 11. Passing Arrays and Objects

Arrays and objects are passed by **reference**, so a function can change the original.

```javascript
function addItem(list) {
  list.push(99);
}

const data = [1, 2];
addItem(data);
console.log(data);
```

```output
[ 1, 2, 99 ]
```

Numbers, strings and booleans are copied, so the original does not change.

```javascript
function changeNumber(n) {
  n = 100;
}

let value = 5;
changeNumber(value);
console.log(value);
```

```output
5
```

## 12. Common Examples

### Area of a Rectangle

```javascript
function area(length, width) {
  return length * width;
}

console.log(area(5, 4));
```

```output
20
```

### Temperature Conversion

```javascript
function toFahrenheit(celsius) {
  return celsius * 9 / 5 + 32;
}

console.log(toFahrenheit(100));
console.log(toFahrenheit(0));
```

```output
212
32
```

## Real-World Example

A bill calculator:

```javascript
function calculateBill(price, quantity, discountPercent = 0) {
  const total = price * quantity;
  const discount = total * discountPercent / 100;
  return total - discount;
}

const price = Number(prompt("Enter price:"));
const quantity = Number(prompt("Enter quantity:"));

console.log("Total bill: " + calculateBill(price, quantity, 10));
```

If the user enters:

```text
250
3
```

The output will be:

```output
Total bill: 675
```

## Common Mistakes

### Using `console.log()` Instead of `return`

```javascript
function add(a, b) {
  console.log(a + b);
}

const total = add(2, 3) + 10;    // NaN, because add() returns undefined
```

### Forgetting to Store the Returned Value

```javascript
function square(x) { return x * x; }

square(4);    // the result is lost
```

Use `console.log(square(4))` or `const s = square(4);`.

### Starting the Returned Value on a New Line

```javascript
function f() {
  return
  5;    // never reached: return gives undefined
}
```

### Mixing Up the Argument Order

`subtract(3, 10)` is not the same as `subtract(10, 3)`.

### Using a Parameter Name That Hides Another Variable

Choose clear, different names to avoid confusion.

---

## Key Points

* Parameters are in the definition; arguments are in the call.
* Arguments are matched to parameters by position.
* `return` sends a value back and ends the function.
* A missing argument is `undefined`; extra arguments are ignored.
* Default parameters use `param = value`.
* Rest parameters `...args` collect extra arguments into an array.
* Return an array or object to give back several values.
* Arrays and objects are passed by reference; primitives are copied.

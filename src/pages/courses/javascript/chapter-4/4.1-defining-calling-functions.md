# Chapter 4: Functions and Scope

## Section 1: Defining and Calling Functions

A **function** is a named block of code that performs a specific task. You write it once and use it as many times as you like. Functions make programs shorter, cleaner and easier to fix.

---

## 1. Why Use Functions?

Imagine you need to print a welcome message in five places. Without a function you copy the same lines five times. With a function you write them once and **call** it whenever needed.

Functions give you:

* **Reusability:** write once, use many times.
* **Organization:** split big programs into small, clear parts.
* **Easy maintenance:** fix a bug in one place.
* **Readability:** a good name explains what the code does.

---

## 2. Built-in Functions

JavaScript already provides many functions.

| Function | Purpose | Example | Result |
| --- | --- | --- | --- |
| `console.log()` | Prints output | `console.log("Hi")` | `Hi` |
| `parseInt()` | Text to integer | `parseInt("42px")` | `42` |
| `Number()` | Converts to number | `Number("3.5")` | `3.5` |
| `Math.max()` | Largest value | `Math.max(4, 9, 2)` | `9` |
| `isNaN()` | Checks for NaN | `isNaN("abc")` | `true` |

```javascript
console.log(parseInt("42px"));
console.log(Math.max(4, 9, 2));
console.log(isNaN("abc"));
```

```output
42
9
true
```

Besides these, you can create your own functions.

---

## 3. Defining a Function

A function created with the `function` keyword is called a **function declaration**.

**Syntax:**

```text
function functionName() {
  // code to run
}
```

```javascript
function greet() {
  console.log("Hello, welcome to Codify!");
}
```

* `function` starts the definition.
* `greet` is the function name.
* `()` holds the parameters (empty for now).
* `{ }` holds the function body.

Defining a function does **not** run it. Nothing is printed yet.

---

## 4. Calling a Function

To run a function, write its name followed by parentheses.

```javascript
function greet() {
  console.log("Hello, welcome to Codify!");
}

greet();
greet();
```

```output
Hello, welcome to Codify!
Hello, welcome to Codify!
```

The same code ran twice because it was called twice.

---

## 5. Order of Execution

When JavaScript meets a function call, it jumps into the function, runs it, and then returns to the line after the call.

```javascript
function show() {
  console.log("Inside function");
}

console.log("Before");
show();
console.log("After");
```

```output
Before
Inside function
After
```

---

## 6. Calling a Function Before Defining It

Function **declarations** are hoisted, so they can be called before the line where they are written.

```javascript
sayHi();

function sayHi() {
  console.log("Hi!");
}
```

```output
Hi!
```

> 💡 This works only for function declarations. You will see the reason in Section 4.4 on hoisting.

---

## 7. Functions Calling Other Functions

```javascript
function line() {
  console.log("--------------------");
}

function title() {
  line();
  console.log("   CODIFY JAVASCRIPT");
  line();
}

title();
```

```output
--------------------
   CODIFY JAVASCRIPT
--------------------
```

---

## 8. A Function That Returns a Value

A function can send a value back with `return`. You will study this in detail in the next section.

```javascript
function getYear() {
  return 2026;
}

const year = getYear();
console.log(year);
console.log(getYear() + 1);
```

```output
2026
2027
```

A function with no `return` gives back `undefined`.

```javascript
function sayNothing() {
  console.log("Working...");
}

console.log(sayNothing());
```

```output
Working...
undefined
```

---

## 9. Function Naming Rules

Function names follow the same rules as variable names.

* Use `camelCase`: `calculateTotal`.
* Start with a letter, `_` or `$`, never a digit.
* Use a verb that explains the task: `printMenu`, `findLargest`, `isEven`.
* Do not use reserved words such as `function` or `if`.

---

## 10. Anatomy of a Function

| Part | Example | Meaning |
| --- | --- | --- |
| Keyword | `function` | Starts a function declaration |
| Name | `greet` | How you call it |
| Parentheses | `()` | Hold the inputs |
| Body | `{ ... }` | The code that runs |
| Call | `greet()` | Executes the function |

---

## Real-World Example 🌍

A menu printer that is reused every time the program needs it:

```javascript
function printMenu() {
  console.log("1. Start");
  console.log("2. Settings");
  console.log("3. Exit");
}

console.log("Main menu");
printMenu();

console.log("Back to menu");
printMenu();
```

```output
Main menu
1. Start
2. Settings
3. Exit
Back to menu
1. Start
2. Settings
3. Exit
```

## Common Mistakes

### Forgetting the Parentheses When Calling

```javascript
function greet() {
  console.log("Hello");
}

greet;    // nothing happens, it only refers to the function
```

Use `greet();`.

### Defining a Function but Never Calling It

A function runs only when it is called.

### Missing Braces or Parentheses

```javascript
function greet {      // SyntaxError: missing ()
  console.log("Hi");
}
```

### Misspelling the Name When Calling

```javascript
function greet() { }
Greet();    // ReferenceError: Greet is not defined
```

JavaScript is case-sensitive.

### Using the Same Name Twice

```javascript
function show() { console.log("A"); }
function show() { console.log("B"); }
show();    // prints B, the second one replaces the first
```

---

## Key Points

* A function is a reusable named block of code.
* Define it with `function name() { }` and call it with `name()`.
* Function declarations are hoisted and can be called before they are defined.
* A function without `return` gives back `undefined`.
* JavaScript has many built-in functions such as `parseInt()` and `Math.max()`.
* Use a clear `camelCase` verb as the function name.
* Functions can call other functions.

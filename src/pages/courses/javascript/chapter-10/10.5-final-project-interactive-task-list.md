## 3. Step 1: Plan the Data

Every task is an object with three properties.

```javascript
const task = {
  id: 1,
  text: "Buy milk",
  done: false
};

console.log(task);
```

```output
{ id: 1, text: 'Buy milk', done: false }
```

* `id` is a unique number used to find the task later.
* `text` is what the user typed.
* `done` tells whether the task is completed.

The app state is simply an **array of tasks** plus the current **filter**.

```javascript
let tasks = [];
let filter = "all";    // "all", "active" or "completed"
```

## 4. Step 2: Write the Data Functions

Start with plain functions that work with data only. They do not touch the page, so they are easy to test.

```javascript
let tasks = [];
let nextId = 1;

function addTask(text) {
  const task = { id: nextId++, text: text, done: false };
  tasks.push(task);
  return task;
}

function toggleTask(id) {
  tasks = tasks.map(task =>
    task.id === id ? { ...task, done: !task.done } : task
  );
}

function removeTask(id) {
  tasks = tasks.filter(task => task.id !== id);
}

addTask("Buy milk");
addTask("Study JavaScript");
addTask("Call mom");

toggleTask(2);
removeTask(3);

console.log(tasks);
```

```output
[
  { id: 1, text: 'Buy milk', done: false },
  { id: 2, text: 'Study JavaScript', done: true }
]
```

* `map` creates a new array with one task changed.
* `filter` creates a new array without the removed task.
* The spread `{ ...task }` copies the object instead of mutating it.

## 5. Step 3: Filtering and Counting

```javascript
const tasks = [
  { id: 1, text: "Buy milk", done: false },
  { id: 2, text: "Study JavaScript", done: true },
  { id: 3, text: "Walk the dog", done: false }
];

function getVisibleTasks(list, filter) {
  if (filter === "active") return list.filter(task => !task.done);
  if (filter === "completed") return list.filter(task => task.done);
  return list;
}

function countRemaining(list) {
  return list.filter(task => !task.done).length;
}

console.log(getVisibleTasks(tasks, "active").map(task => task.text));
console.log(getVisibleTasks(tasks, "completed").map(task => task.text));
console.log(countRemaining(tasks) + " tasks left");
```

```output
[ 'Buy milk', 'Walk the dog' ]
[ 'Study JavaScript' ]
2 tasks left
```

## 6. Step 4: Validate the Input

Never trust what the user types. Return an error message, or an empty string if the text is fine.

```javascript
const MAX_LENGTH = 60;

function validateTask(text, existingTasks) {
  const clean = text.trim();

  if (clean === "") return "Please type a task";
  if (clean.length > MAX_LENGTH) return `Keep it under ${MAX_LENGTH} characters`;

  const duplicate = existingTasks.some(
    task => task.text.toLowerCase() === clean.toLowerCase()
  );
  if (duplicate) return "That task is already on your list";

  return "";
}

const existing = [{ id: 1, text: "Buy milk", done: false }];

console.log(validateTask("   ", existing));
console.log(validateTask("buy MILK", existing));
console.log(validateTask("Read a book", existing) === "");
```

```output
Please type a task
That task is already on your list
true
```

## 7. Step 5: Save and Load Safely

`localStorage` stores **text only**, so convert with JSON. Both reading and writing can fail (storage blocked, full, or broken saved data), so wrap them in `try...catch`.

```javascript
const STORAGE_KEY = "codify-tasks";
const memory = {};    // stands in for localStorage in this demo

function saveTasks(tasks) {
  try {
    memory[STORAGE_KEY] = JSON.stringify(tasks);
  } catch (error) {
    console.log("Could not save:", error.name);
  }
}

function loadTasks() {
  try {
    const saved = memory[STORAGE_KEY];
    const parsed = saved ? JSON.parse(saved) : [];
    return Array.isArray(parsed) ? parsed : [];
  } catch (error) {
    console.log("Saved data was broken, starting fresh");
    return [];
  }
}

saveTasks([{ id: 1, text: "Buy milk", done: false }]);
console.log(loadTasks());

memory[STORAGE_KEY] = "{ broken json";
console.log(loadTasks());
```

```output
[ { id: 1, text: 'Buy milk', done: false } ]
Saved data was broken, starting fresh
[]
```

## 9. Step 7: Render the List

The `render` function rebuilds the list from the current state. It builds elements with `createElement` and `textContent`, which is **safe** even if the user types HTML.

```javascript
function render() {
  list.innerHTML = "";
  const visible = getVisibleTasks();

  if (visible.length === 0) {
    const empty = document.createElement("li");
    empty.className = "empty";
    empty.textContent = "No tasks to show";
    list.appendChild(empty);
  }

  visible.forEach(task => {
    const item = document.createElement("li");
    item.className = "task" + (task.done ? " done" : "");
    item.dataset.id = task.id;

    const label = document.createElement("label");
    const box = document.createElement("input");
    box.type = "checkbox";
    box.checked = task.done;

    const text = document.createElement("span");
    text.textContent = task.text;

    label.append(box, text);

    const deleteBtn = document.createElement("button");
    deleteBtn.type = "button";
    deleteBtn.dataset.action = "delete";
    deleteBtn.textContent = "Delete";
    deleteBtn.setAttribute("aria-label", "Delete task: " + task.text);

    item.append(label, deleteBtn);
    list.appendChild(item);
  });

  updateFooter();
}
```

## 10. Step 8: Handle Events with Delegation

Instead of adding a listener to every checkbox and delete button, add **one** listener to the list. It also works for tasks created later.

```javascript
list.addEventListener("change", event => {
  if (event.target.type !== "checkbox") return;

  const id = Number(event.target.closest("li").dataset.id);
  toggleTask(id);
  saveTasks();
  render();

  const box = list.querySelector(`li[data-id="${id}"] input`);
  if (box) box.focus();    // keep keyboard focus after redraw
});

list.addEventListener("click", event => {
  if (event.target.dataset.action !== "delete") return;

  const id = Number(event.target.closest("li").dataset.id);
  removeTask(id);
  saveTasks();
  render();
  input.focus();           // send focus somewhere sensible
});
```

Redrawing the list destroys the old elements, so the code restores focus afterwards. Without it, keyboard users would lose their place.

```html
    // ---------- Settings ----------
    const STORAGE_KEY = "codify-tasks";
    const MAX_LENGTH = 60;

    // ---------- State ----------
    let tasks = loadTasks();
    let filter = "all";
    let nextId = tasks.reduce((max, task) => Math.max(max, task.id), 0) + 1;

    // ---------- Elements ----------
    const form = document.getElementById("taskForm");
    const input = document.getElementById("taskInput");
    const errorMsg = document.getElementById("errorMsg");
    const list = document.getElementById("taskList");
    const countEl = document.getElementById("count");
    const statusEl = document.getElementById("status");
    const clearBtn = document.getElementById("clearBtn");
    const filterButtons = document.querySelectorAll("[data-filter]");

    // ---------- Storage (safe, even when storage is blocked) ----------
    function loadTasks() {
      try {
        const saved = localStorage.getItem(STORAGE_KEY);
        const parsed = saved ? JSON.parse(saved) : [];
        return Array.isArray(parsed) ? parsed : [];
      } catch (error) {
        return [];
      }
    }

    function saveTasks() {
      try {
        localStorage.setItem(STORAGE_KEY, JSON.stringify(tasks));
      } catch (error) {
        console.warn("Tasks could not be saved:", error.name);
      }
    }

    // ---------- Data functions ----------
    function validateTask(text) {
      const clean = text.trim();
      if (clean === "") return "Please type a task";
      if (clean.length > MAX_LENGTH) return "Keep it under " + MAX_LENGTH + " characters";

      const duplicate = tasks.some(task => task.text.toLowerCase() === clean.toLowerCase());
      if (duplicate) return "That task is already on your list";

      return "";

    function getVisibleTasks() {
      if (filter === "active") return tasks.filter(task => !task.done);
      if (filter === "completed") return tasks.filter(task => task.done);
      return tasks;
    }

    // ---------- Helpers ----------
    function announce(message) {
      statusEl.textContent = "";
      setTimeout(() => { statusEl.textContent = message; }, 50);
    }

    function showError(message) {
      errorMsg.textContent = message;
      input.setAttribute("aria-invalid", message ? "true" : "false");
    }

    // ---------- Rendering ----------
    function render() {
      list.innerHTML = "";
      const visible = getVisibleTasks();

      if (visible.length === 0) {
        const empty = document.createElement("li");
        empty.className = "empty";
        empty.textContent = "No tasks to show";
        list.appendChild(empty);
      }

      visible.forEach(task => {
        const item = document.createElement("li");
        item.className = "task" + (task.done ? " done" : "");
        item.dataset.id = task.id;

        const label = document.createElement("label");
        const box = document.createElement("input");
        box.type = "checkbox";
        box.checked = task.done;

        const text = document.createElement("span");
        text.textContent = task.text;
        label.append(box, text);

        const deleteBtn = document.createElement("button");
        deleteBtn.type = "button";
        deleteBtn.dataset.action = "delete";
        deleteBtn.textContent = "Delete";
        deleteBtn.setAttribute("aria-label", "Delete task: " + task.text);

        item.append(label, deleteBtn);
        list.appendChild(item);
      });

      const remaining = tasks.filter(task => !task.done).length;
      countEl.textContent = remaining + (remaining === 1 ? " task left" : " tasks left");
      clearBtn.disabled = !tasks.some(task => task.done);

      filterButtons.forEach(button => {
        button.setAttribute("aria-pressed", String(button.dataset.filter === filter));
      });
    }

    // ---------- Events ----------
    form.addEventListener("submit", event => {
      event.preventDefault();

      const error = validateTask(input.value);
      if (error) {
        showError(error);
        input.focus();
        return;
      }

      const text = input.value.trim();
      tasks.push({ id: nextId++, text: text, done: false });
      saveTasks();

      showError("");
      input.value = "";
      render();
      announce("Added task: " + text);
      input.focus();
    });

    input.addEventListener("input", () => showError(""));

    list.addEventListener("change", event => {
      if (event.target.type !== "checkbox") return;

      const id = Number(event.target.closest("li").dataset.id);
      tasks = tasks.map(task => task.id === id ? { ...task, done: !task.done } : task);
      saveTasks();
      render();

      const box = list.querySelector('li[data-id="' + id + '"] input');
      if (box) box.focus();
    });

    list.addEventListener("click", event => {
      if (event.target.dataset.action !== "delete") return;

      const item = event.target.closest("li");
      const id = Number(item.dataset.id);
      const removed = tasks.find(task => task.id === id);

      tasks = tasks.filter(task => task.id !== id);
      saveTasks();
      render();
      announce("Deleted task: " + removed.text);
      input.focus();
    });

    filterButtons.forEach(button => {
      button.addEventListener("click", () => {
        filter = button.dataset.filter;
        render();
        announce("Showing " + filter + " tasks");
      });
    });

    clearBtn.addEventListener("click", () => {
      const count = tasks.filter(task => task.done).length;
      tasks = tasks.filter(task => !task.done);
      saveTasks();
      render();
      announce("Cleared " + count + " completed tasks");
      input.focus();
    });

    // ---------- Start ----------
    render();
  </script>
</body>
</html>
```

## 12. How the Pieces Work Together

```text
User action ──▶ Event handler ──▶ Update tasks array ──▶ saveTasks() ──▶ render()
                    │                                                       │
                    └── validate first                        rebuilds the list from the data
```

* The **array** is the single source of truth.
* Every change updates the array first, then saves, then redraws.
* `render()` never changes the data; it only reads it.

This "data first, then draw" pattern is the basis of modern front-end frameworks.

## Real-World Example 🌍

The same ideas power the apps you use every day. A to-do app, a shopping cart, a notes app and an email inbox all follow the same cycle:

```javascript
let cart = [];

function addItem(name, price) {
  cart = [...cart, { name, price }];
}

function cartTotal() {
  return cart.reduce((sum, item) => sum + item.price, 0);
}

function render() {
  console.log("--- Cart ---");
  cart.forEach(item => console.log(`${item.name}: ₹${item.price}`));
  console.log(`Total: ₹${cartTotal()}`);
}

addItem("Notebook", 120);
addItem("Pen", 20);
render();
```

```output
--- Cart ---
Notebook: ₹120
Pen: ₹20
Total: ₹140
```

Change the data, then render. Once you understand this loop, you can build almost any interactive page.

## Common Mistakes

### Rendering Without Updating the Data First

Changing only the page, not the array, means the next `render()` brings the old state back. Update the data, then redraw.

### Using innerHTML with Task Text

```javascript
item.innerHTML = task.text;       // user input can inject HTML
item.textContent = task.text;     // safe
```

### Forgetting to Save After Every Change

If you save only when adding, toggles and deletes are lost on refresh. Call `saveTasks()` after each change.

### Trusting Saved Data

```javascript
const tasks = JSON.parse(localStorage.getItem("tasks"));    // can throw or return null
```

Wrap it in `try...catch` and check with `Array.isArray`.

### Adding a Listener to Every Item

Adding listeners inside `render()` creates many listeners and misses new items. Use event delegation on the list.

### Using the Index as the ID

Indexes change when items are deleted or filtered. Use a stable `id`.

### Forgetting Number() for dataset Values

```javascript
const id = event.target.closest("li").dataset.id;     // a string "2"
tasks.find(task => task.id === id);                   // undefined, 2 !== "2"
```

Convert with `Number(...)` before comparing.

### Losing Keyboard Focus After a Redraw

Rebuilding the list removes the focused element. Restore focus to a sensible place.

### Not Handling the Empty State

Show a friendly message such as "No tasks to show" so the page never looks broken.

## Key Points

* The project combines arrays, objects, the DOM, events, forms, validation, storage, error handling and accessibility.
* Store tasks as an array of objects with a stable `id`, `text` and `done` property.
* Keep **data functions** separate from **rendering** so each is easy to understand and test.
* Follow the loop: handle event, update data, save, render.
* Validate input before using it, and show clear error messages.
* Use `map`, `filter`, `find` and `some` instead of manual loops.
* Use `createElement` and `textContent` to display user text safely.
* Use one delegated listener on the list for toggling and deleting.
* Wrap `localStorage` and `JSON.parse` in `try...catch`.
* Support keyboard users and screen readers with labels, `aria-pressed`, `aria-live` and managed focus.
* Test the app with the mouse, the keyboard and tricky input.
* You can now plan, build, debug and polish a complete JavaScript application.

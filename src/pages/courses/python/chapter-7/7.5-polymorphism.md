# Chapter 7: Object-Oriented Programming

## Section 7.5: Polymorphism & Abstraction

Polymorphism lets different objects respond to the same operation. Abstraction exposes essential behavior while hiding implementation details.

## Real-World Example

Checkout code calls pay() on different payment options.

## Example

```python
class CardPayment:
    def pay(self, amount): return f"Card: {amount}"
class CashPayment:
    def pay(self, amount): return f"Cash: {amount}"
for method in (CardPayment(), CashPayment()):
    print(method.pay(250))
```

```output
Card: 250
Cash: 250
```

## Common Mistakes

* Confusing the purpose of the concept with the exact syntax used in the example.
* Assuming one successful run proves the program works for every input.

## Key Points

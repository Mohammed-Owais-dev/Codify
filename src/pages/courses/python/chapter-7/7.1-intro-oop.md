# Chapter 7: Object-Oriented Programming

## Section 1: Introduction to OOP, Classes & Objects

Until now we wrote programs using variables and functions. **Object-Oriented Programming (OOP)** is a way of organizing code around **objects**, which bundle data and the actions that work on that data.

---

## 1. What is OOP?

In OOP, a program is built from objects that model real-world things such as a student, a car or a bank account.

Every real-world object has:

* **Properties** (what it has): a car has a color, brand and speed.
* **Behaviors** (what it does): a car can start, accelerate and stop.

In Python, properties are called **attributes** and behaviors are called **methods**.

---

## 2. Why Use OOP?

* **Organization**: related data and functions stay together.
* **Reusability**: write a class once and create many objects from it.
* **Easy maintenance**: changes are made in one place.
* **Real-world modeling**: code looks like the problem it solves.

Python supports both procedural and object-oriented styles. In fact, everything in Python (numbers, strings, lists) is already an object.

---

## 3. Class and Object

* A **class** is a blueprint or template.
* An **object** is a real item created from that blueprint. It is also called an **instance**.

Example: `Car` is a class. Your red Honda and a neighbor's blue Toyota are two objects of that class.

---

## 4. Creating a Class

Use the `class` keyword. By convention, class names start with a **capital letter**.

```python
class Dog:
    pass

print(Dog)
```

```output
<class '__main__.Dog'>
```

`pass` means the class is empty for now.

---

## 5. Creating an Object

Call the class like a function to create an object.

```python
class Dog:
    pass

d1 = Dog()
d2 = Dog()

print(type(d1))
print(d1 == d2)
```

```output
<class '__main__.Dog'>
False
```

`d1` and `d2` are two separate objects made from the same class.

---

## 6. Class Attributes

Variables written inside a class are **attributes**. Access them with a dot.

```python
class Dog:
    species = "Canine"
    sound = "Woof"

d = Dog()

print(d.species)
print(d.sound)
print(Dog.species)
```

```output
Canine
Woof
Canine
```

---

## 7. Methods

A **method** is a function written inside a class. Its first parameter is always `self`, which refers to the current object.

```python
class Dog:
    def bark(self):
        print("Woof! Woof!")

d = Dog()
d.bark()
```

```output
Woof! Woof!
```

You write `d.bark()` without passing `self`. Python passes it automatically.

---

## 8. Methods That Use Attributes

Inside a method, use `self.attribute` to reach the object's data.

```python
class Dog:
    def set_name(self, name):
        self.name = name

    def introduce(self):
        print("My name is", self.name)

d = Dog()
d.set_name("Tommy")
d.introduce()
```

```output
My name is Tommy
```

---

## 9. Many Objects, Separate Data

Each object keeps its **own** data.

```python
class Dog:
    def set_name(self, name):
        self.name = name

d1 = Dog()
d2 = Dog()

d1.set_name("Tommy")
d2.set_name("Bruno")

print(d1.name)
print(d2.name)
```

```output
Tommy
Bruno
```

---

## 10. Adding, Changing and Deleting Attributes

Attributes can be created or changed directly through the object.

```python
class Car:
    pass

car = Car()

car.color = "Red"
car.speed = 60
print(car.color, car.speed)

car.speed = 80
print(car.speed)

del car.color
print(hasattr(car, "color"))
```

```output
Red 60
80
False
```

Helpful built-in functions for attributes:

| Function | Purpose |
|----------|---------|
| `hasattr(obj, "x")` | Checks if the attribute exists |
| `getattr(obj, "x")` | Reads the attribute |
| `setattr(obj, "x", value)` | Sets the attribute |
| `delattr(obj, "x")` | Deletes the attribute |

```python
class Car:
    pass

car = Car()
setattr(car, "brand", "Honda")
print(getattr(car, "brand"))
```

```output
Honda
```

---

## 11. Checking an Object's Type

`isinstance()` tells whether an object belongs to a class.

```python
class Dog:
    pass

class Cat:
    pass

d = Dog()

print(isinstance(d, Dog))
print(isinstance(d, Cat))
print(isinstance(10, int))
```

```output
True
False
True
```

## 12. A Complete Simple Class

```python
class Rectangle:
    def set_size(self, length, width):
        self.length = length
        self.width = width

    def area(self):
        return self.length * self.width

    def perimeter(self):
        return 2 * (self.length + self.width)

r = Rectangle()
r.set_size(6, 4)

print("Area:", r.area())
print("Perimeter:", r.perimeter())
```

```output
Area: 24
Perimeter: 20
```

## 13. Procedural vs Object-Oriented

| Feature | Procedural | Object-Oriented |
|---------|------------|-----------------|
| Focus | Functions and steps | Objects and classes |
| Data and functions | Kept separate | Bundled together |
| Reuse | Copy or call functions | Create many objects, use inheritance |
| Best for | Small scripts | Large, growing programs |

## Real-World Example

A simple **Student** class that stores marks and decides pass or fail:

```python
class Student:
    def set_details(self, name, marks):
        self.name = name
        self.marks = marks

    def result(self):
        if self.marks >= 40:
            return self.name + " passed"
        return self.name + " failed"

s1 = Student()
s2 = Student()

s1.set_details("Asha", 85)
s2.set_details("Ravi", 32)

print(s1.result())
print(s2.result())
```

```output
Asha passed
Ravi failed
```

## Common Mistakes

### Forgetting `self` in a Method

```python
class Dog:
    def bark():        # missing self
        print("Woof")

Dog().bark()           # TypeError
```

Write `def bark(self):`.

### Forgetting the Brackets When Creating an Object

```python
d = Dog        # This is the class, not an object
d = Dog()      # Correct
```

### Using an Attribute Without `self`

```python
class Dog:
    def set_name(self, name):
        name = name        # Not saved in the object
```

Use `self.name = name`.

### Calling a Method on the Class Directly

```python
Dog.bark()     # TypeError: missing self
```

Create an object first: `Dog().bark()`.

### Using a Lowercase Class Name

It works, but the convention is `Dog`, not `dog`.

---

## Key Points

* OOP organizes code using classes and objects.
* A class is a blueprint; an object is an instance of the class.
* Attributes store data; methods define behavior.
* `self` refers to the current object and is the first parameter of every method.
* Create an object by calling the class: `obj = ClassName()`.
* Each object keeps its own attribute values.
* Access members with the dot operator: `obj.attribute` and `obj.method()`.
* `isinstance()` checks whether an object belongs to a class.
* Class names usually start with a capital letter.

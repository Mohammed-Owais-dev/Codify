# Chapter 7: Object-Oriented Programming

## Section 7.1: Introduction to OOP, Classes & Objects

A class defines a type; an object is an instance. Objects can combine attributes and methods that represent data and behavior.

## Real-World Example

A college system models a course enrollment as an object.

## Example

```python
class Course:
    def __init__(self, name):
        self.name = name
course = Course("Python")
print(course.name)
```

```output
Python
```

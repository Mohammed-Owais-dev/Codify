# Chapter 7: Object-Oriented Programming

## Section 7.3: Encapsulation & Access Control

Classes define objects that combine data and behaviour. Inheritance can reuse behaviour, while encapsulation and polymorphism help organise larger programs.

This lesson focuses on **Encapsulation & Access Control**. Learn its purpose, how Python expresses it, and when it is useful. Start with the example, then modify it to see how the program behaves.

## Example

```python
class Student:
    def __init__(self, name):
        self.name = name
student = Student("Asha")
print(student.name)
```

```output
Asha
```

## How to Practise

1. Run the example in your Python environment.
2. Predict the output before running it again.
3. Change one value or statement and observe the result.
4. Explain each line in your own words.
5. Test different inputs where appropriate.

## Common Mistakes

* Forgetting Python's spelling, punctuation, or indentation rules.
* Using a value before assigning it.
* Assuming input always has the expected format.
* Copying code without understanding the steps.
* Testing only one example.

## Key Points

* **Encapsulation & Access Control** is part of the Python learning path.
* Understand the purpose before memorising syntax.
* Small runnable examples make new ideas easier to understand.
* Meaningful names, clear structure, and testing improve code quality.

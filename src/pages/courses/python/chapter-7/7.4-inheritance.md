# Chapter 7: Object-Oriented Programming

## Section 7.4: Inheritance & Method Overriding

Inheritance lets a child reuse parent behavior. Overriding provides a specialized method implementation; super() can access parent behavior.

## Real-World Example

Email and SMS notifications share a common interface.

## Example

```python
class Notification:
    def send(self):
        return "Sending notification"
class EmailNotification(Notification):
    def send(self):
        return "Sending email"
print(EmailNotification().send())
```

```output
Sending email
```

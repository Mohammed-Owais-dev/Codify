# Chapter 7: Object-Oriented Programming

## Section 4: Inheritance & Method Overriding

**Inheritance** lets one class **reuse** the attributes and methods of another class. It avoids repeating code and models "is-a" relationships, such as "a Dog **is an** Animal".

---

## 1. What is Inheritance?

* The class being inherited from is the **parent** (also called **base** or **super**) class.
* The class that inherits is the **child** (also called **derived** or **sub**) class.

The child automatically gets everything from the parent and can add its own features.

---

## 2. Basic Syntax

Write the parent class name in brackets after the child class name.

```python
class Animal:
    def eat(self):
        print("This animal eats food")

class Dog(Animal):
    def bark(self):
        print("Woof!")

d = Dog()
d.eat()
d.bark()
```

```output
This animal eats food
Woof!
```

`Dog` never defined `eat()`, but it inherited it from `Animal`.

---

## 3. Types of Inheritance

| Type | Structure |
|------|-----------|
| **Single** | One child inherits from one parent |
| **Multilevel** | A chain: grandparent → parent → child |
| **Hierarchical** | Many children inherit from one parent |
| **Multiple** | One child inherits from many parents |
| **Hybrid** | A mix of the above |

---

## 4. Single Inheritance

```python
class Vehicle:
    def __init__(self, brand):
        self.brand = brand

    def info(self):
        print("Brand:", self.brand)

class Car(Vehicle):
    def wheels(self):
        print("A car has 4 wheels")

c = Car("Honda")
c.info()
c.wheels()
```

```output
Brand: Honda
A car has 4 wheels
```

Since `Car` has no `__init__`, it uses the parent's constructor.

---

## 5. Method Overriding

A child can **redefine** a method that exists in the parent. The child's version is used for child objects.

```python
class Animal:
    def sound(self):
        print("Some generic sound")

class Dog(Animal):
    def sound(self):
        print("Woof!")

class Cat(Animal):
    def sound(self):
        print("Meow!")

Animal().sound()
Dog().sound()
Cat().sound()
```

```output
Some generic sound
Woof!
Meow!
```

---

## 6. Using `super()`

`super()` gives access to the **parent class**. It is mostly used to call the parent's constructor or an overridden method.

```python
class Person:
    def __init__(self, name):
        self.name = name

class Student(Person):
    def __init__(self, name, marks):
        super().__init__(name)
        self.marks = marks

s = Student("Asha", 85)
print(s.name, s.marks)
```

```output
Asha 85
```

If the child defines its own `__init__`, the parent's `__init__` is **not** called automatically. You must call it with `super().__init__(...)`.

---

## 7. Extending a Parent Method with `super()`

Call the parent's version, then add more behavior.

```python
class Employee:
    def show(self):
        print("I am an employee")

class Manager(Employee):
    def show(self):
        super().show()
        print("I also manage a team")

Manager().show()
```

```output
I am an employee
I also manage a team
```

## 8. Multilevel Inheritance

```python
class Grandparent:
    def home(self):
        print("Family home")

class Parent(Grandparent):
    def car(self):
        print("Family car")

class Child(Parent):
    def bike(self):
        print("My bike")

c = Child()
c.home()
c.car()
c.bike()
```

```output
Family home
Family car
My bike
```

## 9. Hierarchical Inheritance

Several classes inherit from the same parent.

```python
class Shape:
    def display(self):
        print("This is a shape")

class Circle(Shape):
    pass

class Square(Shape):
    pass

Circle().display()
Square().display()
```

```output
This is a shape
This is a shape
```

---

## 10. Multiple Inheritance

A class can inherit from more than one parent. Python supports this directly.

```python
class Father:
    def skill1(self):
        print("Driving")

class Mother:
    def skill2(self):
        print("Cooking")

class Child(Father, Mother):
    pass

c = Child()
c.skill1()
c.skill2()
```

```output
Driving
Cooking
```

---

## 11. Method Resolution Order (MRO)

When several parents have the same method name, Python follows the **MRO** to decide which one to use. It searches the class first, then its parents from left to right.

```python
class A:
    def show(self):
        print("A")

class B(A):
    def show(self):
        print("B")

class C(A):
    def show(self):
        print("C")

class D(B, C):
    pass

D().show()
print([cls.__name__ for cls in D.__mro__])
```

```output
B
['D', 'B', 'C', 'A', 'object']
```

Every class ultimately inherits from the built-in `object` class.

---

## 12. Checking Relationships

`isinstance()` checks an object's class (including parents) and `issubclass()` checks a class's relationship.

```python
class Animal:
    pass

class Dog(Animal):
    pass

d = Dog()

print(isinstance(d, Dog))
print(isinstance(d, Animal))
print(issubclass(Dog, Animal))
print(issubclass(Animal, Dog))
```

```output
True
True
True
False
```

---

## 13. Inheritance vs Composition

Inheritance models **"is-a"** (a Dog is an Animal). Composition models **"has-a"** (a Car has an Engine).

```python
class Engine:
    def start(self):
        print("Engine started")

class Car:
    def __init__(self):
        self.engine = Engine()

    def drive(self):
        self.engine.start()
        print("Car is moving")

Car().drive()
```

```output
Engine started
Car is moving
```

Use inheritance only when the "is-a" relationship is true.

## Real-World Example 🌍

An **Employee** hierarchy with shared data and a different bonus rule for managers:

```python
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def annual_pay(self):
        return self.salary * 12

    def details(self):
        print(self.name, "earns", self.annual_pay(), "per year")

class Manager(Employee):
    def __init__(self, name, salary, bonus):
        super().__init__(name, salary)
        self.bonus = bonus

    def annual_pay(self):
        return super().annual_pay() + self.bonus

e = Employee("Ravi", 30000)
m = Manager("Asha", 50000, 20000)

e.details()
m.details()
```

```output
Ravi earns 360000 per year
Asha earns 620000 per year
```

`details()` is written once but uses the correct `annual_pay()` for each class.

## Common Mistakes

### Forgetting to Call `super().__init__()`

```python
class Student(Person):
    def __init__(self, name, marks):
        self.marks = marks      # self.name is never set
```

Call `super().__init__(name)` first.

### Forgetting the Parent in Brackets

```python
class Dog:          # Not inheriting from Animal
```

Write `class Dog(Animal):`.

### Writing `super.__init__()` Without Brackets

`super` must be called: `super().__init__()`.

### Using Inheritance for a "has-a" Relationship

A `Car` is not an `Engine`. Use composition instead.

### Expecting a Child's New Attributes in the Parent

Inheritance works **downward**. A parent object cannot use the child's methods.

---

## Key Points

* Inheritance lets a child class reuse the members of a parent class.
* Syntax: `class Child(Parent):`.
* Types: single, multilevel, hierarchical, multiple and hybrid.
* Method overriding redefines a parent's method in the child.
* `super()` calls the parent's constructor or methods.
* If the child defines `__init__`, call `super().__init__()` to initialize the parent.
* MRO decides which method runs in multiple inheritance; view it with `__mro__`.
* `isinstance()` and `issubclass()` check class relationships.
* Use inheritance for "is-a" and composition for "has-a".

# Chapter 7: Object-Oriented Programming

## Section 2: Constructors, self & Class Members

In the last section we set attributes with separate methods. A **constructor** does this automatically the moment an object is created. In this section we also learn how `self` works and the different kinds of members a class can have.

---

## 1. What is a Constructor?

A **constructor** is a special method that runs **automatically** when an object is created. In Python it is named `__init__` (two underscores on each side).

```python
class Dog:
    def __init__(self):
        print("A new dog is created")

d1 = Dog()
d2 = Dog()
```

```output
A new dog is created
A new dog is created
```

It ran once for every object, with no extra call.

---

## 2. Constructor with Parameters

Pass values when creating the object, and store them in attributes using `self`.

```python
class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

s1 = Student("Asha", 85)
s2 = Student("Ravi", 72)

print(s1.name, s1.marks)
print(s2.name, s2.marks)
```

```output
Asha 85
Ravi 72
```

---

## 3. Understanding `self`

`self` is a reference to **the object that is calling the method**.

```python
class Demo:
    def show(self):
        print(self)

d = Demo()
print(d is d)
d.show()
print(d)
```

```output
True
<__main__.Demo object at 0x7f3a1c2b5d90>
<__main__.Demo object at 0x7f3a1c2b5d90>
```

Both lines print the same object (the memory address will differ on your computer).

Key facts about `self`:

* It is automatically passed by Python when you call a method.
* `self.name = name` stores data **inside the object**.
* `self` is only a convention. You could use another name, but you should not.

---

## 4. Default Values in the Constructor

Give parameters default values to make them optional.

```python
class Student:
    def __init__(self, name, city="Hyderabad"):
        self.name = name
        self.city = city

s1 = Student("Asha")
s2 = Student("Ravi", "Chennai")

print(s1.name, "-", s1.city)
print(s2.name, "-", s2.city)
```

```output
Asha - Hyderabad
Ravi - Chennai
```

Python does **not** allow two constructors, so default values or `*args` are used for flexibility.

---

## 5. Instance Methods

Methods that use `self` are called **instance methods**. They work with one object's data.

```python
class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def grade(self):
        if self.marks >= 80:
            return "A"
        elif self.marks >= 60:
            return "B"
        return "C"

s = Student("Asha", 85)
print(s.name, "got grade", s.grade())
```

```output
Asha got grade A
```

---

## 6. Instance Variables vs Class Variables

| Type | Defined | Shared? |
|------|---------|---------|
| **Instance variable** | Inside methods using `self.x` | Each object has its own copy |
| **Class variable** | Directly inside the class | Shared by **all** objects |

```python
class Student:
    school = "Codify School"        # class variable

    def __init__(self, name):
        self.name = name            # instance variable

s1 = Student("Asha")
s2 = Student("Ravi")

print(s1.name, s1.school)
print(s2.name, s2.school)
```

```output
Asha Codify School
Ravi Codify School
```

Changing the class variable through the class updates it for every object:

```python
class Student:
    school = "Codify School"

s1 = Student()
s2 = Student()

Student.school = "New Academy"

print(s1.school)
print(s2.school)
```

```output
New Academy
New Academy
```

## 7. Counting Objects with a Class Variable

A class variable is a good way to keep a shared counter.

```python
class Student:
    count = 0

    def __init__(self, name):
        self.name = name
        Student.count += 1

Student("Asha")
Student("Ravi")
Student("Meena")

print("Total students:", Student.count)
```

```output
Total students: 3
```

## 8. The `__str__` Method

By default, printing an object shows an unhelpful address. Define `__str__` to control what `print()` shows.

```python
class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def __str__(self):
        return self.name + " scored " + str(self.marks)

s = Student("Asha", 85)
print(s)
```

```output
Asha scored 85
```

`__str__` must **return** a string. It should not print.

---

## 9. Class Methods

A **class method** works with the class instead of one object. Use `@classmethod` and the first parameter `cls`.

```python
class Student:
    count = 0

    def __init__(self, name, marks):
        self.name = name
        self.marks = marks
        Student.count += 1

    @classmethod
    def from_string(cls, text):
        name, marks = text.split("-")
        return cls(name, int(marks))

s = Student.from_string("Ravi-72")
print(s.name, s.marks)
print(Student.count)
```

```output
Ravi 72
1
```

This is a popular way to create objects in alternate ways.

---

## 10. Static Methods

A **static method** uses neither `self` nor `cls`. It is a plain utility function placed inside the class. Use `@staticmethod`.

```python
class Student:
    @staticmethod
    def is_pass(marks):
        return marks >= 40

print(Student.is_pass(55))
print(Student.is_pass(30))
```

```output
True
False
```

---

## 11. Comparing the Three Method Types

| Type | Decorator | First parameter | Can access |
|------|-----------|-----------------|------------|
| Instance method | none | `self` | Object data and class data |
| Class method | `@classmethod` | `cls` | Class data only |
| Static method | `@staticmethod` | none | Neither (utility only) |

---

## 12. The Destructor `__del__`

`__del__` runs when an object is destroyed. It is rarely needed because Python cleans memory automatically.

```python
class Demo:
    def __init__(self):
        print("Object created")

    def __del__(self):
        print("Object destroyed")

d = Demo()
del d
print("End")
```

```output
Object created
Object destroyed
End
```

## Real-World Example

A **BankAccount** class with a constructor, methods and a shared class variable:

```python
class BankAccount:
    bank_name = "Codify Bank"

    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

    def withdraw(self, amount):
        if amount > self.balance:
            print("Insufficient balance")
        else:
            self.balance -= amount

    def __str__(self):
        return self.owner + " has Rs." + str(self.balance)

acc = BankAccount("Asha", 1000)
acc.deposit(500)
acc.withdraw(300)
acc.withdraw(5000)

print(acc)
print(BankAccount.bank_name)
```

```output
Insufficient balance
Asha has Rs.1200
Codify Bank
```

## Common Mistakes

### Writing `_init_` Instead of `__init__`

```python
def _init_(self, name):     # Wrong, never runs automatically
```

Use **two** underscores on each side: `__init__`.

### Forgetting `self.` Before Attributes

```python
def __init__(self, name):
    name = name             # Not saved in the object
```

Write `self.name = name`.

### Returning a Value from `__init__`

`__init__` must not return anything other than `None`.

### Missing Arguments

```python
s = Student("Asha")         # TypeError: missing argument 'marks'
```

Provide every required value or set defaults.

### Changing a Class Variable Through an Object

`s1.school = "X"` creates a new instance variable on `s1` only. Use `Student.school = "X"` to change it for all.

---

## Key Points

* `__init__` is the constructor and runs automatically when an object is created.
* The constructor usually stores values in attributes using `self`.
* `self` refers to the current object.
* Instance variables belong to each object; class variables are shared.
* `__str__` controls what `print(object)` displays.
* `@classmethod` uses `cls` and works with the class.
* `@staticmethod` is a utility function with no `self` or `cls`.
* Python allows only one `__init__`, so use default arguments for flexibility.
* `__del__` runs when an object is destroyed.

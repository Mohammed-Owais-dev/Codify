# Chapter 7: Object-Oriented Programming

## Section 7.2: Constructors, self & Class Members

__init__ initializes an instance and self refers to it. Instance attributes belong to one object; class attributes can be shared.

## Real-World Example

Each book has a title, while books share a library name.

## Example

```python
class Book:
    library = "Central Library"
    def __init__(self, title):
        self.title = title
book = Book("Python Basics")
print(book.title)
print(book.library)
```

```output
Python Basics
Central Library
```

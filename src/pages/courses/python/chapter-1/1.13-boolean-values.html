1.13 Boolean Values – The Ultimate Digital Yes or No

Previous Topic Next Topic

Welcome back to Codify’s Masterclass Notes! So far, you’ve learned how to store numbers, letters, and massive lists. But let’s pause and look at how human brains make decisions every single day.

  • "Is it raining outside?" Yes or No.
  • "Did I pass my math exam?" True or False.
  • "Should I eat another slice of pizza?" Always True!

Computers might look like magical glowing boxes capable of launching rockets and rendering 3D video games, but deep down inside their hardware, they are actually just hyper-speed toddlers that only understand two things: Yes or No, On or Off, 1 or 0.

In programming, this binary decision-making system is handled by a data type named after the brilliant 19th-century mathematician George Boole: The Boolean (bool).

In this massive, fun, and easy-to-understand guide, we will unpack every single corner of Booleans in Python!

1. Who is George Boole? (The Man Behind the Name)

Before we write any code, let's give credit where credit is due. In the mid-1800s, a self-taught English mathematician named George Boole wrote a revolutionary book arguing that logical thoughts and complex arguments could be written down using simple mathematical formulas involving just two values: true and false.

People laughed at him at the time, calling it useless "pure math." Fast forward a century later, and George Boole's math became the absolute foundation of every computer, smartphone, and smart toaster on planet Earth. Without Boole, you wouldn't be reading this website right now!

2. The Two Faces of Booleans (True and False)

In Python, the Boolean data type has only two possible values:

  • True
  • False
🚨
CRITICAL RULE FOR CODIFY STUDENTS: Python is case-sensitive! You must capitalize the first letter. Writing true or false in lowercase will cause Python to throw a NameError because it thinks you are trying to call a regular variable. It has to be True and False.
is_coding_fun = True is_broccoli_tasty = False print(type(is_coding_fun)) # Output: <class 'bool'> print(type(is_broccoli_tasty)) # Output: <class 'bool'>
<class 'bool'> <class 'bool'>

3. The Secret Truth: Booleans are Actually Numbers!

Here is a fun piece of trivia that will blow your friends' minds: In Python, Booleans are actually a sub-class of Integers!

Under the hood of the Python Virtual Machine (PVM):

  • True has an underlying numerical value of 1
  • False has an underlying numerical value of 0

Don't believe us? Let's prove it with math!

print(True + True) # Output: 2 (1 + 1) print(True * 50) # Output: 50 (1 * 50) print(False * 999) # Output: 0 (0 * 999) print(True + False) # Output: 1 (1 + 0)
2 50 0 1

Can you use this in real software? Please don't write True + True to mean 2 in a production app—your coworkers will cry. But it proves how Python handles data internally!

4. How Do We Get Booleans? (Expressions)

You rarely type x = True manually in a real program. Instead, your code calculates Booleans automatically using Comparison Operators (which we learned in Topic 1.12):

score = 85 passing_grade = 50 # Python evaluates this expression and assigns a Boolean result has_passed = score >= passing_grade print(has_passed) # Output: True

5. The Concept of "Truthy" and "Falsy" Values

This is a classic interview trap question! In Python, any value can be evaluated in a Boolean context (like inside an if statement). You don't have to give it an explicit True or False.

Python automatically categorizes everything in the universe into two camps: Truthy (acts like True) or Falsy (acts like False).

The Official List of Falsy Values in Python

Believe it or not, Python considers all of the following things to be strictly False:

  • The number 0 (integer) or 0.0 (float)
  • None (the absence of value)
  • False itself
  • Empty sequences and collections:
    • Empty string: ""
    • Empty list: []
    • Empty tuple: ()
    • Empty dictionary: {}
    • Empty set: set()

Everything else in the entire universe is automatically considered Truthy!

Real-World "Truthy/Falsy" Check:

Imagine you are building a signup form and want to check if a user actually typed their name:

username = input("Enter your username: ") # Instead of writing: if username != "": if username: print(f"Welcome, {username}!") else: print("Hey! You forgot to type your name!")

Why does this work? If the user types nothing and hits Enter, username is an empty string "" (which is Falsy), so Python drops into the else block. If they type something, it becomes Truthy!

6. The bool() Function Casting

You can explicitly force any data type to convert into a Boolean using the built-in bool() constructor function, just like we use int() or str().

age = 18 is_adult = bool(age) print(is_adult) # Output: True (because 18 is not zero)

7. Short-Circuit Evaluation (Python is Lazy!)

When Python evaluates complex logical statements using and or or, it practices Short-Circuit Evaluation.

💤
Translation: Python is extremely lazy and stops calculating the moment it already knows the final answer.

How 'and' laziness works:

In an and statement, both sides must be true. If the left side is already False, Python doesn't even bother looking at the right side because the overall result is doomed anyway!

# If the first condition is False, Python stops and returns False immediately result = False and (10 / 0 == 1) print(result) # Output: False (Notice it didn't crash with a ZeroDivisionError!)

(If Python had bothered to evaluate 10 / 0, it would have crashed. But because the left side was False, it short-circuited and saved the day!)

How 'or' laziness works:

In an or statement, only one side needs to be true. If the left side is already True, Python stops and says, "Good enough!" without checking the right side.

result = True or (10 / 0 == 1) print(result) # Output: True (Ignored the math error completely!)

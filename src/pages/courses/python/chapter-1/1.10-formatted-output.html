1.10 Formatted Output (Making Your Data Look Good)

Previous Topic Next Topic

Welcome back to Codify’s Masterclass Notes! In Topic 1.9, we learned how to print() data to the screen. But let's be honest: just throwing raw numbers and text onto a screen is like serving a 5-star meal on a paper plate. It works, but it looks terrible.

Imagine building an e-commerce app. You don't want to show a price as Total: 1459.3958372. You want it to look like Total: $1,459.40.

In this ultimate guide, we are going to learn how to "dress up" your data using String Formatting. We will travel through time to see how Python formatting evolved, from the cranky old methods of the 1990s to the shiny, ultra-fast superpowers of modern Python!

1. The Dark Ages: String Concatenation (The Ugly Way)

Before we learn the cool tricks, let's look at how beginners usually try to combine text and variables. They use the + operator (concatenation).

name = "Alex" age = 18 balance = 150.5 # The Ugly Way (Concatenation) print("User " + name + " is " + str(age) + " years old and has $" + str(balance) + ".")

Why is this terrible?

  • You have to type + everywhere. It's exhausting.
  • You have to cast everything. If you forget str(age), Python throws a TypeError and crashes!
  • Space Management: You constantly have to remember to type spaces inside your strings "User " so the words don't squash together like "UserAlex".

Let's look at the three professional ways Python solves this.

2. The Grandparent: Modulo % Formatting (Old School)

Back in the 1990s (Python 1 and 2), Python borrowed its formatting style from the C programming language. It uses the % symbol as a placeholder.

  • %s = String (Text)
  • %d = Decimal (Integer/Whole Number)
  • %f = Float (Decimal Number)
name = "Batman" enemies_defeated = 45 # The old-school % way print("I am %s and I have defeated %d enemies!" % (name, enemies_defeated))
⚠️
The Verdict: You will still see this in very old Python codebases. It is clunky, hard to read if you have 10 variables, and prone to crashing if you pass the wrong data type. Do not use this for new projects! Let grandpa rest.

3. The Parent: The .format() Method (Python 3.0+)

When Python 3 was released, the developers wanted a cleaner way to format strings. They introduced the .format() method.

Instead of weird %s symbols, you use empty curly braces {} as placeholders in your text. At the end of the string, you call .format() and pass in your variables.

A. Default Order

The variables fill the curly braces in the exact order you provide them.

item = "Laptop" price = 899.99 print("I bought a {} for ${}.".format(item, price)) # Output: I bought a Laptop for $899.99.

B. Positional Indexing

What if you want to reuse a variable multiple times? You can put index numbers inside the braces!

print("Eat {0}, Sleep {0}, Code {1}, Repeat {0}!".format("Pizza", "Python")) # Output: Eat Pizza, Sleep Pizza, Code Python, Repeat Pizza!

C. Keyword Arguments

You can even name the placeholders to make your code super readable.

print("My name is {name} and I play {game}.".format(name="Sarah", game="Minecraft"))
⚖️
The Verdict: The .format() method is excellent, very safe, and highly readable. However, it requires a lot of extra typing at the end of the string.

4. The Cool Teenager: F-Strings (Python 3.6+)

In 2016, Python 3.6 introduced Formatted String Literals, affectionately known as F-Strings.

F-strings completely revolutionized Python. They are incredibly fast to type, incredibly fast for the computer to run, and ridiculously easy to read.

To use an f-string, you simply type a lowercase f (or uppercase F) directly in front of the quotation marks, and inject your variables straight into the curly braces!

hero = "Iron Man" power_level = 9000 # The glorious F-String: print(f"{hero} has a power level over {power_level}!")

(No commas, no .format(), no type casting. Just pure, beautiful code.)

5. F-String Superpowers (Codify Ninja Tricks)

F-strings don't just hold variables; they can actively compute logic, do math, and format numbers like a spreadsheet wizard.

Interactive F-String Simulator
f" { value : modifier } "
Raw Value
Modifier (:, | :.2f | :.1%)
...

Superpower 1: Math Inside the Braces!

You don't need to do math before printing. You can do it inside the f-string!

price = 50 tax = 0.05 print(f"Total cost: ${price + (price * tax)}") # Output: Total cost: $52.5

Superpower 2: Number Formatting (Decimals)

Let's fix the ugly decimal problem. You can format numbers by adding a colon : after the variable, followed by .2f (which means "Float with 2 decimal places").

pi = 3.14159265359 print(f"Pi rounded to two decimals is {pi:.2f}") # Output: Pi rounded to two decimals is 3.14 print(f"Pi rounded to four decimals is {pi:.4f}") # Output: Pi rounded to four decimals is 3.1416

Superpower 3: Comma Separators for Big Numbers

Reading 1000000000 is hard. Reading 1,000,000,000 is easy. F-strings can add commas for you automatically!

lottery_win = 25000000 # Just add a colon and a comma! print(f"I won ${lottery_win:,} in the lottery!") # Output: I won $25,000,000 in the lottery!

Superpower 4: Formatting as Percentages

Want to turn a decimal into a clean percentage? Use the % symbol after the colon!

success_rate = 0.875 # .1% means "Convert to percentage and give me 1 decimal place" print(f"Mission Success Rate: {success_rate:.1%}") # Output: Mission Success Rate: 87.5%

Superpower 5: Text Alignment and Padding

If you are building a text-based menu or receipt, you want things to line up nicely. You can tell an f-string to reserve a specific amount of space and align the text!

  • < means Left Align
  • > means Right Align
  • ^ means Center Align
word = "Codify" # Reserve 15 spaces, align left print(f"|{word:<15}|") # Output: |Codify | # Reserve 15 spaces, align right print(f"|{word:>15}|") # Output: | Codify| # Reserve 15 spaces, center it! print(f"|{word:^15}|") # Output: | Codify |

Superpower 6: The Ultimate Debugging Trick (Python 3.8+)

If your code is broken and you want to quickly print a variable to see what its value is, just add an = sign after the variable name in the f-string!

health_points = 85 # The Debug Trick: print(f"{health_points=}") # Output: health_points=85

(This saves you from typing print("health_points =", health_points) every single time you hunt for a bug!)

6. Codify Master Summary Table

Method Name Syntax Example Era / Version Pros & Cons
Concatenation (+) "Age: " + str(age) Forever ❌ Ugly, requires manual str() conversion.
Modulo % "Age: %d" % age Python 1 & 2 ❌ Outdated, hard to read with many variables.
.format() Method "Age: {}".format(age) Python 3.0+ ✅ Very safe, great for passing dictionaries. A bit wordy.
F-Strings f"Age: {age}" Python 3.6+ 👑 The absolute best. Fast, readable, supports inline math.

F-String Formatting Cheat Sheet:

{value:.2f} 👉 2 decimal places (5.67)
{value:,} 👉 Add commas (1,000,000)
{value:.1%} 👉 Percentage (85.5%)
{value:>10} 👉 Right-align in 10 spaces

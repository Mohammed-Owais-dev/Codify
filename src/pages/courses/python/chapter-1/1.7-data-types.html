1.7 Master Guide to Python Data Types

Previous Topic Next Topic

Welcome back to Codify’s Masterclass Notes! You’ve mastered how to write Python code, execute scripts, and follow basic syntax rules. Now, it’s time to learn about the actual raw materials you’ll use to build software: Data Types.

Every time you type a number, a piece of text, a list of items, or a simple True/False into your code, Python needs to store that information in your computer’s RAM memory. A Data Type tells Python what kind of value a variable is holding and what operations can be performed on it.

1. What is a Data Type? (And Why Should You Care?)

Think of variables as storage boxes in a warehouse.

📦
You wouldn’t store a liquid drink, a heavy metal dumbbell, and a fragile glass vase in the exact same container shape without labeling them first, right? Similarly, Python classifies data into specific categories so it knows how much memory space to allocate and what actions are legal.

For instance:

  • Adding two numbers: 10 + 20 results in 30 (Mathematical addition).
  • "Adding" two text strings: "10" + "20" results in "1020" (Text concatenation).

Understanding data types prevents weird bugs and helps you choose the right data structure for your applications.

3. Numeric Types: Working with Math

Numeric types represent numerical values. Python automatically assigns numeric data types based on how you write the numbers.

A. Integers (int)

An integer is a whole number (positive, negative, or zero) without decimals.

age = 21 temperature = -5 count = 0 print(type(age)) # Output: <class 'int'>

Python Superpower!

In languages like C++ or Java, integers have a maximum limit (e.g., up to 2,147,483,647). In Python 3, integers have arbitrary precision. That means an integer can be as large as your computer's memory allows!

# Unbelievably huge number? Python handles it effortlessly! huge_number = 99999999999999999999999999999999999999999 print(huge_number * huge_number)
Terminal Output: 999999999999999999999999999999999999999980000000000000000000000000000000000000001

B. Floating-Point Numbers (float)

A float is a real number that contains a decimal point or fractional part.

price = 99.99 pi = 3.14159 negative_val = -0.005 print(type(price)) # Output: <class 'float'>
  • Scientific Notation: Floats can also be written using the character e or E to represent powers of 10.
    distance_to_sun = 1.496e8 # 1.496 * 10^8 = 149,600,000.0

C. Complex Numbers (complex)

Complex numbers are used in advanced physics, electrical engineering, and mathematical calculations. They consist of a real part and an imaginary part, denoted by j.

# Structure: real + imaginary 'j' z = 3 + 5j print(type(z)) # Output: <class 'complex'> print(z.real) # Output: 3.0 print(z.imag) # Output: 5.0

4. Sequence Types: Ordered Collections

Sequences are ordered collections of items. "Ordered" means every element stays in the exact position where you placed it, and you can access items using numerical index positions starting at 0.

A. Strings (str)

A string is a sequence of Unicode characters used to represent text. You can create strings using single quotes '...', double quotes "...", or triple quotes '''...''' (for multi-line text).

single_q = 'Hello' double_q = "Codify" multi_line = '''This is a multi-line string in Python.''' print(type(double_q)) # Output: <class 'str'>
  • Ordered: You can access characters via indexing (double_q[0] gives 'C').
  • Immutable: You cannot change characters inside an existing string.

B. Lists (list)

A list is an ordered, changeable (mutable) collection that allows duplicate elements and can store mixed data types. Lists are defined using square brackets [...].

# Heterogeneous list (contains strings, ints, floats, and booleans) student_info = ["Alex", 20, 88.5, True] print(student_info[0]) # Output: Alex student_info[1] = 21 # Changing value (Lists are MUTABLE!) print(student_info) # Output: ['Alex', 21, 88.5, True]
Terminal Output: Alex ['Alex', 21, 88.5, True]

C. Tuples (tuple)

A tuple is an ordered collection just like a list, but with one massive difference: tuples are immutable (read-only). Once created, you cannot change, add, or remove elements. Tuples are defined using parentheses (...).

coordinates = (12.9716, 77.5946) # Accessing elements works fine: print(coordinates[0]) # Output: 12.9716 # Trying to change an element throws an error! # coordinates[0] = 15.0000 ❌ TypeError: 'tuple' object does not support item assignment
  • Speed: Tuples are faster and consume less memory than lists.
  • Data Security: Use tuples for data that should never be altered (e.g., GPS coordinates, database credentials).

5. Boolean Type: Truth Values (bool)

The Boolean data type represents one of two values: True or False. (Note the required capital letters T and F).

is_logged_in = True has_paid = False print(type(is_logged_in)) # Output: <class 'bool'>

Under the Hood

Booleans in Python are actually a sub-class of integers!
True evaluates to 1
False evaluates to 0

print(True + True) # Output: 2
print(True * 5) # Output: 5
print(False == 0) # Output: True

6. Set Types: Unordered Unique Collections

A. Sets (set)

A set is an unordered, unindexed collection of unique elements. Sets do not allow duplicate items and are defined using curly braces {...}.

# Duplicate items are automatically removed! unique_ids = {101, 102, 103, 101, 102} print(unique_ids) # Output: {101, 102, 103} print(type(unique_ids)) # Output: <class 'set'>
{101, 102, 103} <class 'set'>
  • Fast membership testing (if item in my_set).
  • Supports mathematical set operations like Union (|), Intersection (&), and Difference (-).

B. Frozenset (frozenset)

A frozenset is simply an immutable version of a standard set. Once created, elements cannot be added or removed.

immutable_set = frozenset([1, 2, 3, 4]) # immutable_set.add(5) ❌ AttributeError: 'frozenset' object has no attribute 'add'

7. Mapping Type: Key-Value Pairs (dict)

A Dictionary (dict) is an ordered collection of key-value pairs. Think of it like a physical dictionary: you look up a word (the Key) to find its definition (the Value).

Dictionaries are defined using curly braces with colons {key: value}.

user_profile = { "name": "Sarah", "age": 22, "course": "Computer Science", "is_enrolled": True } # Accessing value by key print(user_profile["name"]) # Output: Sarah # Updating values user_profile["age"] = 23 print(user_profile["age"]) # Output: 23
Sarah 23
  • Keys must be unique and immutable (strings, numbers, or tuples).
  • Values can be of any data type, including duplicate values or nested dictionaries.

8. Binary Types & None Type

A. Binary Types (bytes, bytearray, memoryview)

These advanced types are used to work directly with raw binary data streams, such as audio files, images, or network sockets:

  • bytes: Immutable sequence of integers in the range 0≤x<256.
  • bytearray: Mutable sequence of bytes.
  • memoryview: Allows code to access the internal buffer of an object without making a copy (extremely memory-efficient).
raw_bytes = b"Hello" # The prefix 'b' creates a bytes object print(type(raw_bytes)) # Output: <class 'bytes'>

B. The None Type (NoneType)

None is a special constant in Python that represents the absence of a value or a null state. It is not equivalent to 0, False, or an empty string "".

result = None print(type(result)) # Output: <class 'NoneType'> def my_function(): print("Function called!") # Functions without a 'return' statement return None by default output = my_function() print(output) # Output: None

9. Crucial Concept: Mutability vs. Immutability

One of the most popular technical interview questions is: "What is the difference between mutable and immutable data types in Python?"

  • Mutable Types: Objects whose internal contents can be modified in-place without changing their memory address ID.
  • Immutable Types: Objects whose internal contents cannot be modified after creation. Any attempt to modify them creates a brand new object at a new memory address.

10. Type Checking & Type Casting (Conversion)

Checking Data Types

You can check the type of any variable using two built-in functions:

val = 42 # Method 1: type() print(type(val)) # Output: <class 'int'> # Method 2: isinstance() - Recommended for clean code logic print(isinstance(val, int)) # Output: True

Type Casting (Converting Types)

Python allows you to explicitly convert values from one data type to another using constructor functions:

# Converting String to Int str_num = "100" int_num = int(str_num) # 100 as integer # Converting Int to Float float_num = float(int_num) # 100.0 # Converting List to Set (Removes duplicates!) my_list = [1, 2, 2, 3, 4, 4] my_set = set(my_list) # {1, 2, 3, 4} # Converting List to Tuple my_tuple = tuple(my_list) # (1, 2, 2, 3, 4, 4)

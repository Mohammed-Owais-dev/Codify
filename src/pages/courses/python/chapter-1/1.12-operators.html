1.12 Python Operators – The Math & Logic Superpowers

Previous Topic Next Topic

Welcome back to Codify’s Masterclass Notes! So far, you know how to store data in variables (Topic 1.8), talk to the user using input() and print() (Topic 1.9), and format your text like a pro (Topic 1.10). But right now, your variables are just sitting there doing nothing. They are lazy.

To make your program actually do something—like calculate a game score, check if a password is correct, or split a pizza bill—you need Operators.

Think of operators as the verbs and mathematical tools of programming. In this massive, fun, and corner-to-corner guide, we will break down every single operator Python has to offer!

1. What is an Operator?

Before we dive into the math, let's learn two quick vocabulary words that interviewers love to throw around:

  • Operand: The data (values or variables) being operated on.
  • Operator: The special symbol or keyword that tells Python what action to perform on those operands.
# In this equation: # 10 and 5 are the OPERANDS # + is the OPERATOR result = 10 + 5

Python divides its operators into 7 major categories. Let's examine them one by one!

2. Category 1: Arithmetic Operators (The Math Class)

These are the classic mathematical symbols you learned in elementary school, plus a few sneaky programming bonuses!

Deep Dive into Python's Secret Math Weapons:

  • Floor Division (//): Imagine you have 10 pieces of candy and 4 friends. If you divide them equally, everyone gets 2 pieces, and 2 pieces are left over. 10 // 4 gives you 2. It chops off the decimal entirely.
  • Modulus (%): This is the ultimate "Even or Odd" checker. If a number divided by 2 has a remainder of 0 (num % 2 == 0), it is an even number!
  • Exponentiation (**): Instead of writing long multiplication code, 2 ** 10 instantly calculates 210.

3. Category 2: Comparison (Relational) Operators

Comparison operators are used to compare two values. They always return a Boolean value: either True or False.

THE BIGGEST BEGINNER TRAP: Never confuse assignment (=) with equality (==).
  • x = 10 means "Store 10 inside x."
  • x == 10 means "Ask Python: Is x currently equal to 10? Give me True or False."

4. Category 3: Logical Operators (The Matchmaker)

What if you need to check two conditions at the same time? For example: "Can the user enter the club? They must be over 18 AND have a VIP ticket."

Python uses three English keywords for logical operations: and, or, and not.

A. The and Operator

Returns True ONLY IF BOTH conditions are true. If even one side is false, the whole thing crashes into False.

age = 20 has_vip = True # Both must be true print(age >= 18 and has_vip) # Output: True

B. The or Operator

Returns True if AT LEAST ONE condition is true.

is_weekend = True is_holiday = False # Only one needs to be true print(is_weekend or is_holiday) # Output: True

C. The not Operator (The Sarcasm Operator)

Flips a Boolean value upside down. If something is True, not makes it False. If it's False, it makes it True.

is_raining = False # Flips False to True print(not is_raining) # Output: True

5. Category 4: Assignment Operators (The Lazy Typists)

Assignment operators are shortcuts used to update the value of a variable without repeating yourself.

score = 10 score += 5 # Adds 5 to score print(score) # Output: 15

6. Category 5: Bitwise Operators (The Deep Hacker Level)

Computers don't see numbers like 5 or 10. Deep down inside the hardware, they see binary 0s and 1s. Bitwise operators let you manipulate the individual bits of a number.

(Don't panic! Beginners rarely use these, but knowing them makes you look like a cybersecurity hacker.)

  • & (Bitwise AND): Compares each bit; returns 1 if both bits are 1.
  • | (Bitwise OR): Returns 1 if at least one bit is 1.
  • ^ (Bitwise XOR): Returns 1 if the bits are different.
  • ~ (Bitwise NOT): Inverts all the bits.
  • << (Zero fill left shift): Shifts bits to the left, multiplying the number by powers of 2.
  • >> (Signed right shift): Shifts bits to the right, dividing the number by powers of 2.
# Quick example of a bitwise shift: print(3 << 1) # Output: 6 (Shifts binary 11 to 110)

7. Category 6: Membership Operators (The VIP Guest List)

Membership operators check if a specific value is inside a sequence (like a list, string, or tuple). They return True or False.

  • in: Returns True if the item is present in the sequence.
  • not in: Returns True if the item is NOT present in the sequence.
my_fruits = ["Apple", "Banana", "Cherry"] print("Banana" in my_fruits) # Output: True print("Mango" not in my_fruits) # Output: True print("Grape" in my_fruits) # Output: False
Terminal Output: True True False

8. Category 7: Identity Operators (The Twin Detector)

Do not confuse Identity operators with Equality operators (==).

  • == checks if two variables have the same value.
  • is checks if two variables point to the exact same object in computer memory (sharing the same id()).
  • is not: Returns True if they are different objects.

9. Operator Precedence: Who Goes First?

If you write a crazy math equation like result = 10 + 2 * 5 ** 2, which part does Python calculate first? Does it add first? Multiply? Power?

Python follows a strict order of operations, very similar to school algebra (PEMDAS), expanded for programming:

Order Operator(s) Description
1 (Highest) () Parentheses (Always wins! Group things here first)
2 ** Exponentiation (Powers)
3 +x, -x, ~x Unary plus, minus, and bitwise NOT
4 *, /, //, % Multiplication, Division, Floor Div, Modulus
5 +, - Addition and Subtraction
6 <<, >> Bitwise Shifts (Left and Right)
7 & Bitwise AND
8 ^ Bitwise XOR
9 | Bitwise OR
10 ==, !=, >, <, >=, <= Comparisons
11 (Lowest) not, and, or Logical Operators
💡
Pro Tip: When in doubt, always use parentheses (). They make your code easier to read and guarantee Python evaluates your math in the exact order you want!

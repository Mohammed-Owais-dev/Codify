1.6 Python Syntax Basics: Identifiers, Keywords, and Indentation

Previous Topic Next Topic

Welcome back to Codify's Masterclass Notes! Every spoken language has grammar rules—English requires capital letters at the start of sentences and periods at the end. Programming languages have grammar rules too, and we call this Syntax.

To write a successful Python program, you must understand the three foundational pillars of its syntax: how to name things (Identifiers), what words are forbidden to use (Keywords), and how to structure your code visually (Indentation). Let's dive in!

1. Identifiers (Naming Your Code)

An Identifier is simply a name. Whenever you create a variable, a function, a class, or a module in Python, you have to give it a name so the computer can find it later in memory.

🏷️
Rule of Thumb: You have a lot of freedom when naming things in Python, but you cannot just type random symbols. The Python compiler enforces strict rules on what makes a "legal" identifier.
✅

Allowed Characters

Identifiers can contain letters (A-Z, a-z), numbers (0-9), and underscores (_). Nothing else is allowed!

🚫

No Leading Numbers

An identifier cannot start with a number. player1 is legal, but 1player will crash your code.

🔠

Case Sensitivity

Python is case-sensitive. The variable Score is completely different from score or SCORE.

Examples of Identifiers:

identifiers.py
# Valid Identifiers: user_age = 25 TotalScore = 100 _hidden_value = "secret" player_2_name = "Alex" # INVALID Identifiers (These will cause a SyntaxError): # 2nd_player = "Bob" (Starts with a number) # user-age = 25 (Contains a hyphen instead of an underscore) # total score = 100 (Contains a space)

2. Keywords (The Forbidden Words)

Keywords are special reserved words in Python that have built-in meaning. Because Python already uses these words for its core logic (like loops and conditions), you are not allowed to use them as identifiers.

Python 3 has exactly 35 keywords. You don't need to memorize them all right now, but you should recognize the most common ones. Notice that almost all of them are completely lowercase, except for three!

Category Common Keywords
Boolean Values True, False, None (Note: These are the ONLY three that start with a capital letter!)
Conditionals if, elif, else
Loops for, while, break, continue
Functions & Classes def, return, class, lambda
Logic and, or, not, is, in
Why we can't use keywords as names:
# If you try to name a variable 'False', Python gets confused! False = 10 # SyntaxError: cannot assign to False # If you try to name a variable 'for': for = "Alex" # SyntaxError: invalid syntax

3. Indentation (Python's Unique Visual Structure)

In languages like C++, Java, or JavaScript, developers use curly braces { } to group blocks of code together. Python threw away the curly braces completely. Instead, Python uses Indentation (empty spaces at the beginning of a line) to determine which lines of code belong together.

📏
The Golden Rule of Indentation: In Python, spacing is not just for making the code look pretty. Indentation is mandatory grammar. If your spacing is wrong, your program will crash with an IndentationError.

How it works: Whenever you end a line with a colon (:), you are telling Python, "The lines below this belong to a new block." The standard practice is to use 4 spaces (or 1 Tab) for each level of indentation.

indentation_example.py
temperature = 85 if temperature > 80: # This block is indented by 4 spaces. It belongs to the 'if' statement! print("It is very hot outside.") print("Turn on the AC.") # This code is NOT indented. It runs independently after the 'if' is done. print("Program complete.")

If we forgot the spaces inside the if statement, Python wouldn't know which lines belong to the condition, and it would throw a fatal error!

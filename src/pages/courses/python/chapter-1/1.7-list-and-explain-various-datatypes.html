1.7 List and Explain Various Datatypes

Previous Next

In Python, variables act as named storage containers holding structural details in system memory. Because Python is a **dynamically-typed language**, you do not need to explicitly declare data types when instantiating values; the interpreter auto-detects structural categories based on assignment.

Core Characteristic: Mutability vs Immutability

• **Mutable Data Types:** Objects whose internal values can be modified in place after allocation (e.g., Lists, Dictionaries, Sets).
• **Immutable Data Types:** Value matrices that cannot be mutated post-creation. Any modification constructs a distinct address location pointer (e.g., Integers, Floats, Strings, Tuples).

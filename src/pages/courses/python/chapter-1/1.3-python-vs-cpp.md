# Chapter 1: Introduction to Python

## Section 3: Python vs C++

Python and C++ are both powerful languages, but they are designed with different goals.

Understanding the differences helps you choose the right language for the right job.

---

## 1. Overview

| Language | Main Idea                                  |
| -------- | ------------------------------------------ |
| Python   | Easy to read and fast to write             |
| C++      | Very fast with fine control over hardware  |

---

## 2. Syntax Comparison

Let's print `Hello, World!` in both languages.

**Python**

```python
print("Hello, World!")
```

**C++**

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "Hello, World!";
    return 0;
}
```

```output
Hello, World!
```

Python needs one line. C++ needs a header, a `main` function and a return statement.

---

## 3. Variables and Types

**Python**

```python
age = 20
price = 99.5
name = "Asha"
```

**C++**

```cpp
int age = 20;
float price = 99.5;
string name = "Asha";
```

C++ requires you to declare the type. Python figures it out automatically.

---

## 4. Code Blocks

Python uses **indentation**. C++ uses **curly braces** and **semicolons**.

**Python**

```python
age = 20

if age >= 18:
    print("Adult")
```

**C++**

```cpp
int age = 20;

if (age >= 18)
{
    cout << "Adult";
}
```

---

## 5. Compiled vs Interpreted

| Python                  | C++                        |
| ----------------------- | -------------------------- |
| Interpreted             | Compiled                   |
| Runs line by line       | Converted to machine code first |
| Slower execution        | Faster execution           |

```text
Python:  Code → Interpreter → Output
C++:     Code → Compiler → Executable → Output
```

---

## 6. Typing

| Python             | C++                  |
| ------------------ | -------------------- |
| Dynamically typed  | Statically typed     |
| `x = 10`           | `int x = 10;`        |

---

## 7. Memory Management

* **Python** manages memory automatically using garbage collection.
* **C++** gives you manual control with `new` and `delete`, which is powerful but easier to get wrong.

---

## 8. Speed and Use Cases

| Python                              | C++                                    |
| ----------------------------------- | -------------------------------------- |
| Web apps, data science, AI, scripts | Games, operating systems, embedded     |
| Faster development                  | Faster execution                       |

---

## 9. Summary Table

| Feature          | Python         | C++            |
| ---------------- | -------------- | -------------- |
| Syntax           | Simple         | More complex   |
| Execution        | Interpreted    | Compiled       |
| Typing           | Dynamic        | Static         |
| Speed            | Slower         | Faster         |
| Memory           | Automatic      | Manual         |
| Learning curve   | Easy           | Steeper        |

---

## Real-World Example

A video game engine needs maximum speed, so it is often written in C++.

A tool that analyzes sales data and draws charts is much quicker to build in Python.

Many projects use both: Python for the easy parts and C++ for the performance-critical parts.

---

## Common Mistakes

### Thinking One Language is Always Better

Each language is best for different situations.

### Forgetting Indentation in Python

```python
if True:
print("Hello")    # IndentationError
```

### Forgetting Semicolons in C++

```cpp
cout << "Hello"    // Error: missing ;
```

---

## Key Points

* Python is interpreted, while C++ is compiled.
* Python is dynamically typed, while C++ is statically typed.
* Python uses indentation, while C++ uses braces and semicolons.
* Python is easier to learn and write.
* C++ is faster and gives more control over hardware.
* Python manages memory automatically.

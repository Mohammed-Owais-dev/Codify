1.9 Input and Output (Talking to Your Code)

Previous Topic Next Topic

Welcome back to Codify’s Masterclass Notes! So far, our code has been a bit... lonely. We write instructions, the computer calculates them, and maybe it prints a result. But real software is a two-way street! A game needs to know what button you pressed. A login screen needs your password. A calculator needs your numbers.

In this module, we will learn how to make our Python programs interactive. We will master the art of Output (the computer talking to you) and Input (you talking to the computer). Let’s dive in and give your programs a voice!

1. Output: The print() Function

You have already seen print() in our earlier examples, but you haven't seen its true power yet. In Python, print() is a built-in function used to display information to the standard output device (usually your monitor).

The Basics

You can print strings, numbers, variables, or the results of mathematical equations directly.

print("Hello, Codify!") # Printing a String print(100) # Printing an Integer print(10 + 5) # Printing a calculation (Output: 15)

Printing Multiple Items

You can print multiple items in a single print() statement by separating them with commas. Python will automatically insert a space between them.

name = "Alex" age = 20 print("User", name, "is", age, "years old.") # Output: User Alex is 20 years old.
User Alex is 20 years old.

2. Advanced print() Parameters: sep and end

This is where beginners turn into pros. The print() function actually has hidden parameters that control how it displays text!

Interactive print() Configurator

Change the sep (separator) and end parameters to see how Python formats the text output dynamically.

print( , , ,
sep= , end= )
Apple Banana Cherry

A. The sep Parameter (Separator)

When you print multiple items separated by commas, Python inserts a space between them by default. You can change this using the sep parameter!

# Default behavior (Space) print("Apple", "Banana", "Cherry") # Output: Apple Banana Cherry # Changing the separator to a hyphen print("Apple", "Banana", "Cherry", sep="-") # Output: Apple-Banana-Cherry # Changing the separator to a newline character (\n) print("Apple", "Banana", "Cherry", sep="\n") # Output: # Apple # Banana # Cherry

B. The end Parameter

Have you ever noticed that every time you use print(), the next print() starts on a brand new line? That is because, by default, the print() function ends with an invisible newline character (\n). You can override this using the end parameter!

# Default behavior print("Hello") print("World") # Output: # Hello # World # Changing the end character to a space print("Hello", end=" ") print("World") # Output: Hello World

3. The Art of String Formatting

When you want to mix text and variables together, using commas gets really messy and annoying. Python gives us elegant ways to format strings.

Method 1: F-Strings (The Modern, Best Way)

Introduced in Python 3.6, f-strings (Formatted String Literals) are the absolute industry standard today. You just put an f before the string, and you can inject variables directly inside curly braces {}!

item = "Pizza" price = 12.50 # The F-String magic! print(f"I bought a {item} for ${price}.") # Output: I bought a Pizza for $12.50. # You can even do math inside the braces! print(f"Ten pizzas will cost ${price * 10}.") # Output: Ten pizzas will cost $125.0.
I bought a Pizza for $12.50. Ten pizzas will cost $125.0.

Method 2: The .format() Method (The Older Way)

Before f-strings, developers used the .format() method. You place empty curly braces {} as placeholders, and fill them at the end of the string.

name = "Sarah" score = 95 print("Student {} scored {} points!".format(name, score)) # Output: Student Sarah scored 95 points!

4. Input: The input() Function

Now, let's learn how to listen to the user. The input() function pauses your program and waits for the user to type something on their keyboard and press Enter.

# The string inside the parentheses is the prompt the user will see. user_name = input("Please enter your name: ") print(f"Welcome to the system, {user_name}!")
🚨
THE GOLDEN RULE OF input()
Write this on a sticky note and put it on your monitor: The input() function ALWAYS returns a String (str), no matter what the user types!

If the user types the number 5, Python reads it as the text "5". This leads to the most common beginner bug in Python:

# THE BUG: age = input("Enter your age: ") # User types 20 print(age + 5) # CRASH! TypeError! You cannot add an Integer to a String!

The Solution: Type Casting

To fix this, you must Type Cast (convert) the input into the data type you actually need (like an int or float) the moment you receive it!

# Wrap the input() function inside int() age = int(input("Enter your age: ")) print(f"In 5 years, you will be {age + 5} years old.") # Works perfectly!

Note: If you expect a decimal number, use float(input()) instead.

❌ Without Type Casting

5. Python Ninja Moves: Taking Multiple Inputs in One Line

If you are a student planning to use Python for competitive programming (like LeetCode, HackerRank, or GeeksforGeeks), this is the most important trick you will ever learn.

Often, coding platforms will feed your program two numbers separated by a space on the same line (e.g., 10 20). If you use two standard input() calls, your code will fail. You need to use the .split() method!

Trick 1: Splitting Strings

The .split() method takes a string and chops it into a list of strings based on spaces.

# User types: "Alex Bob" first, second = input("Enter two names separated by a space: ").split() print(f"First name: {first}") # Output: Alex print(f"Last name: {second}") # Output: Bob

Trick 2: Splitting Integers using map()

What if the user types two numbers, like 5 10, and you want them to be integers, not strings? You can use the powerful map() function to apply int() to both inputs instantly!

# User types: "5 10" x, y = map(int, input("Enter two numbers: ").split()) print(f"The sum is: {x + y}") # Output: The sum is: 15

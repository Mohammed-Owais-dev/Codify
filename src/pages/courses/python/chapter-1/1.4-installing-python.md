# Chapter 1: Introduction to Python

## Section 4: Installing Python and Setting Up the Environment

Before writing Python programs, you need a Python interpreter and a place to write your code. On a Windows computer, you can install Python and use an editor such as Visual Studio Code.

Download Python from the official website: [python.org](https://www.python.org/). Avoid installers from unfamiliar websites.

---

## 1. Install Python on Windows

1. Open the official Python downloads page.
2. Download a current stable Python 3 release that supports your version of Windows.
3. Run the installer and follow its instructions.
4. If the installer offers **Add Python to PATH**, select it when appropriate.
5. Complete the installation.
6. Open a new Command Prompt or terminal window.

The exact installer screens can change between versions. Follow the official instructions for the version you download.

---

## 2. Check the Installation

In Command Prompt or the VS Code terminal, try:

```bash
python --version
```

A successful installation displays a version similar to:

```output
Python 3.x.x
```

The `x` characters represent version numbers; they are placeholders, not literal output.

On Windows, this command may also work:

```bash
py --version
```

If neither command is recognized, Python may not be installed correctly or its command may not be available in PATH. Reopen the terminal after installation and check the installer settings before reinstalling.

---

## 3. Set Up Visual Studio Code

Visual Studio Code is a code editor. Python itself is the interpreter that runs your program.

1. Install Visual Studio Code from [code.visualstudio.com](https://code.visualstudio.com/).
2. Open VS Code.
3. Open the Extensions view.
4. Install the official **Python** extension published by Microsoft.
5. Create or open a folder for your Python practice files.
6. Create a file named `hello.py`.
7. Use **Python: Select Interpreter** from the Command Palette to choose your installed Python interpreter.

The extension provides editor support such as syntax highlighting, code completion, and convenient ways to run Python files. The interpreter must still be installed separately.

---

## 4. Run a Small Test

Enter this code in `hello.py`:

```python
print("Python is ready!")
```

Save the file, then run it using the Run Python File control or from the terminal:

```bash
python hello.py
```

Expected output:

```output
Python is ready!
```

Run the command from the directory containing `hello.py`, or provide the correct path to the file.

---

## 5. Python Setup in the Real World 🌍

Imagine you are building a college attendance report. Before writing the full program, you install Python, open the project folder in VS Code, and run a small test file.

This confirms that the interpreter and editor are working before you start debugging the actual application. Keeping project files in a dedicated folder also makes it easier to locate scripts and supporting data.

---

## ⚠️ Common Problems

### 1. The `python` Command Is Not Recognized

Try `py --version` on Windows. If that works, you can run a script with `py hello.py`. Otherwise, check the installation and PATH settings.

### 2. VS Code Uses the Wrong Interpreter

Select the correct interpreter using **Python: Select Interpreter**. Different installations can have different packages, so choosing the intended one matters.

### 3. The File Does Not Run

Check that the file is saved as `hello.py`, that the terminal is in the correct folder, and that the command uses the correct filename.

### 4. Confusing the Editor with Python

VS Code helps you write and manage code. The Python interpreter executes the program.

---

## 🔑 Key Points

* Download Python from the official Python website.
* Use `python --version` or `py --version` to check the installation on Windows.
* VS Code is an editor; the Python interpreter is a separate requirement.
* Install the Microsoft Python extension for Python editing support.
* Select the intended interpreter and save your file with the `.py` extension.
* Test the setup with a small program before building a larger project.

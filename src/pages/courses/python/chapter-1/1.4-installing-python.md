# Chapter 1: Introduction to Python

## Section 4: Installing Python & Setting Up the Environment

Before writing Python programs, we need to install Python on our computer and choose a place to write code.

---

## 1. What Do We Need?

To write and run Python programs, we need:

* The **Python interpreter**
* A **code editor** or **IDE**

---

## 2. Downloading Python

1. Open the official website: `python.org`
2. Go to the **Downloads** section.
3. Download the latest **Python 3** version for your operating system.

---

## 3. Installing on Windows

1. Run the downloaded installer.
2. **Tick the box** `Add Python to PATH`.
3. Click **Install Now**.
4. Wait for the installation to finish.

> ⚠️ If you forget to tick **Add Python to PATH**, the `python` command may not work in the terminal.

---

## 4. Installing on macOS

1. Open the downloaded `.pkg` file.
2. Follow the installation steps.
3. Open **Terminal** to verify.

---

## 5. Installing on Linux

Most Linux systems already include Python. To install or update it on Ubuntu or Debian:

```bash
sudo apt update
sudo apt install python3
```

---

## 6. Checking the Installation

Open a terminal (or Command Prompt) and run:

```bash
python --version
```

```output
Python 3.12.0
```

On macOS and Linux you may need:

```bash
python3 --version
```

The version number on your computer may be different.

---

## 7. Using the Python Shell (REPL)

Type `python` in the terminal to open the interactive shell.

```python
>>> print("Hello")
Hello
>>> 5 + 3
8
```

To leave the shell, type:

```python
exit()
```

---

## 8. Choosing a Code Editor

| Editor / IDE     | Best For                         |
| ---------------- | -------------------------------- |
| IDLE             | Comes with Python, very simple   |
| VS Code          | Lightweight and popular          |
| PyCharm          | Full-featured Python IDE         |
| Jupyter Notebook | Data science and experiments     |

For beginners, **IDLE** or **VS Code** is a good choice.

---

## 9. Setting Up VS Code

1. Install **VS Code**.
2. Open the **Extensions** panel.
3. Search for **Python** and install the extension.
4. Create a new file with the `.py` extension.

---

## 10. Running a Python File

Save this as `hello.py`:

```python
print("Setup complete!")
```

Run it from the terminal:

```bash
python hello.py
```

```output
Setup complete!
```

---

## Real-World Example 🌍

Professional developers keep a separate setup for every project so that different projects do not interfere with each other. This is done using **virtual environments**, which you will meet later in the course.

---

## Common Mistakes

### Forgetting to Add Python to PATH

The terminal shows:

```text
'python' is not recognized as an internal or external command
```

Reinstall Python and tick **Add Python to PATH**.

### Saving the File Without `.py`

Python files must end with `.py`, for example `hello.py`.

### Running the Command in the Wrong Folder

Make sure the terminal is in the folder where your file is saved.

---

## Key Points

* Python is downloaded from `python.org`.
* Always install Python 3.
* On Windows, tick **Add Python to PATH**.
* Use `python --version` to check the installation.
* The Python shell lets you test code instantly.
* VS Code, IDLE and PyCharm are popular editors.
* Python files use the `.py` extension.
* Run a file with `python filename.py`.

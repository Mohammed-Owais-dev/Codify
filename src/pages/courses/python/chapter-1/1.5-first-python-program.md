# Chapter 1: Introduction to Python

## Section 1.5: Your First Python Program

Python runs statements in order. print() displays values, and commas separate printed values with spaces by default. Save scripts with a .py extension.

## Real-World Example

A first script can welcome a student to a programming course.

## Example

```python
name = "Asha"
print("Hello,", name)
print("Welcome to Python!")
```

```output
Hello, Asha
Welcome to Python!
```

## How It Works

Python runs statements in order. print() displays values, and commas separate printed values with spaces by default. Save scripts with a .py extension. Read the code line by line, predict the result, and then run it to confirm your understanding. Change one value at a time to see how the behavior changes.

## Common Mistakes

* Confusing the purpose of the concept with the exact syntax used in the example.
* Assuming one successful run proves the program works for every input.
* Ignoring invalid input, boundary values, or readability when they matter.

## Key Points

* Python runs statements in order.
* print() displays values, and commas separate printed values with spaces by default.
* Save scripts with a.
* Use meaningful names and test examples before relying on a program.

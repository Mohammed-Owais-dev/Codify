# Chapter 1: Introduction to Python

## Section 5: Your First Python Program

Your first Python program will display a message on the screen. This small example introduces the structure of a Python script and shows how to run code and check its output.

---

## 1. Write Your First Program

Create a file named `hello.py` and type:

```python
print("Hello, World!")
```

Output:

```output
Hello, World!
```

The function `print()` displays the value given to it. In this example, the text is surrounded by quotation marks, so Python treats it as a string.

---

## 2. Understand Each Part

| Code | Meaning |
| --- | --- |
| `print` | The built-in function used to display values |
| `(` and `)` | Enclose the value passed to the function |
| `"Hello, World!"` | A string containing the message |
| `"` | Marks the beginning and end of this string |
| `hello.py` | The filename; `.py` is the usual Python file extension |

Python is case-sensitive, so `print` must be written in lowercase. The statement does not need a semicolon at the end.

---

## 3. Display More Than One Line

A Python program can contain multiple statements. They normally run from top to bottom:

```python
print("Welcome to Codify")
print("Learn Python step by step")
print("Practice every day")
```

```output
Welcome to Codify
Learn Python step by step
Practice every day
```

By default, `print()` ends with a newline, so each call displays its output on a new line.

---

## 4. Display Values and Simple Calculations

`print()` can display numbers and the results of expressions as well as text:

```python
print(10 + 5)
print("Total:", 10 + 5)
```

```output
15
Total: 15
```

The expression `10 + 5` is calculated before its result is displayed. When multiple values are passed to `print()` separated by commas, Python places a space between them by default.

---

## 5. Run the Program

If you are using VS Code:

1. Save the file as `hello.py`.
2. Open the integrated terminal.
3. Make sure the terminal is in the folder containing the file.
4. Run `python hello.py` on systems where the `python` command is configured. On Windows, `py hello.py` may also work.
5. Compare the terminal output with the expected output.

If the command fails, check the Python installation, filename, and current folder.

---

## 6. A First Program in the Real World 🌍

Imagine a college department creating a simple welcome script for new students. The program can display the department name, course name, and a short message.

```python
print("Welcome, students!")
print("Department: Computer Engineering")
print("Course: Python Programming")
```

```output
Welcome, students!
Department: Computer Engineering
Course: Python Programming
```

This program only displays text, but the same basic idea of giving instructions in order is used in larger programs. Later, variables and input will let a program display information that changes for each student.

---

## 7. Common Errors

### 1. Incorrect Capitalization

Incorrect:

```python
Print("Hello")
```

Correct:

```python
print("Hello")
```

Python treats `Print` and `print` as different names.

### 2. Missing Quotation Marks

Incorrect:

```python
print(Hello)
```

Unless `Hello` is a defined name, Python raises a `NameError`. To display the word as text, use quotation marks:

```python
print("Hello")
```

### 3. Missing Parentheses

In Python 3, use `print("Hello")`. Writing `print "Hello"` is not valid Python 3 syntax.

### 4. Running the Wrong File

Check the file name and current folder if Python reports that it cannot find `hello.py`.

---

## 🔑 Key Points

* A Python script is commonly saved with the `.py` extension.
* `print()` displays text, numbers, and calculated values.
* Text is written as a string inside matching quotation marks.
* Python is case-sensitive.
* Statements normally run from top to bottom.
* Save your file and run it with the installed Python interpreter.

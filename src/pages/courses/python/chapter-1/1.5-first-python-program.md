# Chapter 1: Introduction to Python

## Section 5: Your First Python Program

Now that Python is installed, it is time to write and run your first program.

---

## 1. Hello, World!

The traditional first program prints a message on the screen.

```python
print("Hello, World!")
```

```output
Hello, World!
```

That is the complete program. There is no `main` function, no header and no semicolon.

---

## 2. Understanding `print()`

`print()` is a **built-in function** that displays output.

```python
print("Welcome to Python")
```

```output
Welcome to Python
```

* `print` is the function name.
* `()` holds what we want to display.
* `"Welcome to Python"` is a **string**, which is text inside quotes.

---

## 3. Single and Double Quotes

Both quote styles work:

```python
print("Hello")
print('Hello')
```

```output
Hello
Hello
```

---

## 4. Printing Numbers

Numbers do not need quotes.

```python
print(100)
print(5 + 3)
```

```output
100
8
```

Python calculates `5 + 3` and prints the result.

---

## 5. Printing Multiple Lines

Each `print()` starts on a new line.

```python
print("Line 1")
print("Line 2")
print("Line 3")
```

```output
Line 1
Line 2
Line 3
```

---

## 6. Printing Multiple Values

Separate values with commas.

```python
print("Age:", 20)
```

```output
Age: 20
```

Python adds a space between the values automatically.

---

## 7. Comments

Comments are notes for humans. Python ignores them.

```python
# This line prints a greeting
print("Hello")
```

```output
Hello
```

Anything after `#` on a line is a comment.

---

## 8. Taking Input

The `input()` function reads text typed by the user.

```python
name = input("Enter your name: ")

print("Hello,", name)
```

If the user enters:

```text
Asha
```

The output will be:

```output
Enter your name: Asha
Hello, Asha
```

---

## 9. Saving and Running the Program

1. Create a file named `first.py`.
2. Type your code and save it.
3. Open a terminal in that folder.
4. Run:

```bash
python first.py
```

---

## 10. Understanding Errors

If you make a mistake, Python shows an error message.

```python
print("Hello)
```

```output
SyntaxError: unterminated string literal
```

Read the message and line number carefully. Errors are a normal part of programming.

---

## Real-World Example

A simple greeting program that asks for a name and a city:

```python
name = input("Enter your name: ")
city = input("Enter your city: ")

print("Hello", name, "from", city)
```

If the user enters `Asha` and `Hyderabad`:

```output
Enter your name: Asha
Enter your city: Hyderabad
Hello Asha from Hyderabad
```

---

## Common Mistakes

### Writing `Print` Instead of `print`

Python is case-sensitive.

```python
Print("Hello")    # NameError
```

Use:

```python
print("Hello")
```

### Forgetting the Quotes

```python
print(Hello)    # NameError
```

Text must be inside quotes:

```python
print("Hello")
```

### Forgetting the Closing Bracket

```python
print("Hello"    # SyntaxError
```

### Using Python 2 Syntax

```python
print "Hello"    # Wrong in Python 3
```

---

## Key Points

* `print()` displays output on the screen.
* Text must be written inside quotes.
* Numbers do not need quotes.
* Each `print()` starts a new line.
* `#` starts a comment.
* `input()` reads text from the user.
* Python is case-sensitive.
* Run a program with `python filename.py`.

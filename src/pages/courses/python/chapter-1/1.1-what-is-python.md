# Chapter 1: Introduction to Python

## Section 1: What is Python?

Python is a **high-level, general-purpose programming language**. It lets people write instructions that a computer can execute. Python code is designed to be readable, so beginners can focus on solving problems instead of learning complicated syntax first.

Python was created by **Guido van Rossum** and was first released in **1991**. It is developed as an open-source language, so people can use it for learning and for building real software.

In simple words:

> **Python is a programming language used to tell a computer how to perform a task.**

---

## 1. What Can We Do with Python?

Python is used in many areas of software development:

* **Web development:** build server-side features for websites.
* **Automation:** perform repeated tasks such as renaming files or organizing folders.
* **Data analysis:** process tables, calculate totals, and create reports.
* **Artificial intelligence and machine learning:** work with data and build models using specialized libraries.
* **Testing:** automate checks to help find software problems.
* **Desktop tools:** create small utilities and applications.

Python is a general-purpose language, so it is not limited to one type of application.

---

## 2. Why Is Python Called a High-Level Language?

A high-level language uses instructions that are easier for people to read than raw machine instructions.

For example:

```python
price = 120
quantity = 3
total = price * quantity
print(total)
```

```output
360
```

This program calculates the cost of three items. You can understand its purpose from the variable names and arithmetic expression.

Python still needs a Python interpreter to execute the program. “High-level” does not mean the computer understands Python source code directly as machine code.

---

## 3. Python in the Real World 🌍

Imagine a college office that needs to calculate the total marks of hundreds of students. Doing each calculation manually takes time and can lead to mistakes.

A Python program can read the marks, calculate totals or averages, and prepare a report. The same basic idea can be used for shop bills, attendance summaries, and organizing files.

Python does not automatically know the rules of a task. A programmer must describe the steps correctly and check the result.

---

## 4. A Small Look at Python Code

```python
student_name = "Asha"
print("Welcome,", student_name)
```

```output
Welcome, Asha
```

* `student_name` is a variable name that refers to the text `"Asha"`.
* `print()` displays information on the screen.
* Text values are written inside quotation marks.
* Python executes these statements from top to bottom.

You will learn variables, strings, and output in more detail in the next chapter.

## 5. Important Python Terms

| Term | Simple Meaning |
| --- | --- |
| Programming language | A language used to write computer instructions |
| Program | A set of instructions that performs a task |
| Source code | Instructions written by a programmer |
| Interpreter | Software that runs Python code |
| Library | Reusable code that provides useful features |
| Application | Software built to help users perform tasks |

---

## ⚠️ Common Mistakes

### 1. Thinking Python Is Only for Beginners

Python is beginner-friendly, but it is also used in professional applications, automation, data processing, and many other fields.

### 2. Assuming Python Does Every Task Automatically

A program only performs the steps written by the programmer. Incorrect instructions can produce incorrect results.

### 3. Confusing Python with an Application

Python is a programming language. An application is a program or group of programs built to perform a task.

---

## 🔑 Key Points

* Python is a high-level, general-purpose programming language.
* Guido van Rossum created Python; its first release was in 1991.
* Python is designed to have readable syntax.
* It is used for web development, automation, data analysis, testing, and more.
* Python code needs a Python interpreter to run.
* Learning to program means practising how to break a task into clear steps.

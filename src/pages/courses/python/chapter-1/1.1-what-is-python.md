# Chapter 1: Introduction to Python

## Section 1.1: What is Python?

Python is a high-level, general-purpose language designed to make code readable. It is used in automation, web development, data analysis, testing, and scripting.

## Real-World Example

A shop can automate a bill or rename many files.

## Common Mistakes

* Confusing the purpose of the concept with the exact syntax used in the example.
* Assuming one successful run proves the program works for every input.
* Ignoring invalid input, boundary values, or readability when they matter.

## Key Points

* Python is a high-level, general-purpose language designed to make code readable.
* It is used in automation, web development, data analysis, testing, and scripting.
* Test the result with different inputs.
* Use meaningful names and test examples before relying on a program.

## How to Practise

1. Run the example in a Python environment.
2. Predict the output before running it.
3. Change one input or value and explain the result.
4. Test a boundary case or invalid input where relevant.

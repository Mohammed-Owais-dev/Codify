# Chapter 1: Introduction to Python

## Section 1: What is Python?

**Python** is a high-level, general-purpose programming language known for its simple and readable syntax.

It is used to build websites, automate tasks, analyze data, create games and develop artificial intelligence applications.

---

## 1. What is a Programming Language?

A programming language is a way to give instructions to a computer.

Computers only understand `0` and `1`, so programming languages let us write instructions in a human-friendly form, which are then translated into something the computer can run.

---

## 2. Introduction to Python

Python was created by **Guido van Rossum** and first released in **1991**.

The name comes from the comedy show *Monty Python's Flying Circus*, not from the snake.

Python was designed with one main goal: **code should be easy to read and write**.

---

## 3. A First Look at Python Code

Here is a simple Python program:

```python
print("Hello, World!")
```

```output
Hello, World!
```

The `print()` function displays text on the screen.

---

## 4. Why is Python Called High-Level?

A **high-level** language is closer to human language and hides complex details such as memory management.

Compare how easy it is to add two numbers in Python:

```python
a = 10
b = 5

print(a + b)
```

```output
15
```

There are no type declarations, no semicolons and no curly braces.

---

## 5. Python is Interpreted

Python is an **interpreted** language.

This means Python reads and runs your code **line by line**, using a program called the **Python interpreter**.

```text
Your Code (.py)  →  Python Interpreter  →  Output
```

You do not need a separate compile step before running your program.

---

## 6. Python is Dynamically Typed

In Python, you do not need to declare the type of a variable.

```python
x = 10
print(x)

x = "Python"
print(x)
```

```output
10
Python
```

The same variable `x` first holds a number and then a string.

## Common Mistakes

### Thinking Python is Only for Beginners

Python is easy to learn, but it is also used by large companies for serious, large-scale projects.

### Confusing Python 2 and Python 3

Older tutorials may use Python 2 syntax such as:

```python
print "Hello"
```

In Python 3, use:

```python
print("Hello")
```

### Confusing the Language with the Snake

Python is a programming language. It is named after a comedy show.

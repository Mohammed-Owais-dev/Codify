1.15 Modules & Imports – Legally Stealing Other People's Code

Previous Topic Next Topic

Welcome back to Codify’s Masterclass Notes! So far, you’ve been writing all your Python code entirely from scratch. That is awesome for learning, but in the real world? Programmers are incredibly, beautifully lazy.

If someone else has already spent 500 hours writing the perfect mathematical formula to calculate the square root of a circle's radius, we do not want to re-write it. We want to borrow it.

In Python, this concept is called using Modules. Think of modules like downloading DLC (Downloadable Content) or an expansion pack for a video game. Python comes with a base game, but you can load up extra superpowers whenever you need them. Let’s unpack how to expand your Python toolkit without doing any of the hard work yourself!

1. What Exactly is a Module?

At its core, a module is literally just a file containing Python code (a .py file) written by someone else.

If you write a really cool function that calculates pizza taxes, and you save it as pizza_tax.py, congratulations! You just created a module. Other developers can now plug your file into their programs and use your math without having to copy and paste the actual code.

When you use a module, you are basically saying to the computer: "Hey, go look at that other file, grab the tools inside it, and bring them over here so I can use them."

2. The import Statement (The Magic Word)

To get access to a module, you have to use the import keyword. You put this at the absolute top of your code, like a grocery list for the Python interpreter.

Let's look at one of the most famous built-in modules: math.

import math # Now we can use any tool inside the math toolkit! result = math.sqrt(64) print(result) # Output: 8.0
Terminal Output: 8.0
🧰
Funny Note / Vibe: Using import math is like carrying an entire IKEA toolbox into your living room just to use one specific screwdriver. It gets the job done, but you have to carry the whole box around. Notice how we had to write math.sqrt? That dot . tells Python, "Open the math toolbox, and pull out the square root tool."

3. The Sniper Approach (from ... import)

What if you don't want to carry the entire toolbox? What if you only want the screwdriver?

Instead of importing the whole module, you can surgically extract exactly what you need. This makes your code cleaner and saves you from typing the module name over and over.

# We are ONLY grabbing the sqrt (square root) and pi tools from math import sqrt, pi # Now we don't need to type "math." anymore! circle_area = pi * (5 ** 2) print(sqrt(100)) # Output: 10.0
Terminal Output: 10.0

Funny Note / Vibe: This is like picking just the pepperonis off a pizza instead of buying the whole pie. It’s highly efficient and straight to the point.

4. Aliasing: Nicknames for Lazy Typists (import ... as)

Sometimes, module names are way too long. If you are importing a module called super_advanced_quantum_mechanics, you do not want to type that out every time you use a function.

You can give modules a nickname using the as keyword.

import random as rng # rng stands for Random Number Generator # Now we call our nickname instead of "random" dice_roll = rng.randint(1, 6) print(f"You rolled a {dice_roll}!")
🤫
The Reality Check: In the data science world, there are legendary, unspoken rules about nicknames. If you use the pandas module, you must alias it as pd. If you use numpy, you must alias it as np. If you don't, other programmers will look at you like you just put ketchup on a steak.

5. "Batteries Included" (The Standard Library)

When you install Python, it comes with a massive collection of free modules already installed. This is known as the Python Standard Library (often praised as Python's "batteries included" philosophy). Here are the VIPs you will use constantly:

Module Name What it does Real-World Example
random Generates random numbers and picks random items. Simulating dice rolls or shuffling a deck of cards.
math Advanced math (trigonometry, logarithms, constants). Calculating the trajectory of a rocket.
datetime Handles dates, times, and timezones. Figuring out exactly how many days until your birthday.
time Controls the flow of time in your code. Adding a time.sleep(2) to make your program pause for 2 seconds.
os Interacts with your operating system (Mac/Windows). Creating new folders or deleting files on your computer via code.

6. The "Wild West" (Third-Party Modules & PIP)

What if the tool you need isn't in the Standard Library? What if you want to build a 2D video game, scrape data off Twitter, or build an AI?

You go to the outside world. There are millions of third-party modules written by developers globally. To get them, you use a tool that comes with Python called pip (Python Package Installer). It is basically the App Store for Python.

You type a command into your terminal (not your Python script, but your computer's command line):

bash ~ terminal

Once the download finishes, you just jump back into your Python file and type:

import pygame

Boom. You just gave your program the ability to render 60-frames-per-second video game graphics. Programming is basically magic.

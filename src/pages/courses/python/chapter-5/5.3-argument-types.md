# Chapter 5: Functions

## Section 3: Default, Keyword & Variable-Length Arguments

Python offers flexible ways to pass arguments to functions. You can set default values, pass arguments by name, and even accept any number of arguments.

---

## 1. Positional Arguments (Recap)

Positional arguments are matched to parameters **in order**.

```python
def student_info(name, age, city):
    print(name, age, city)

student_info("Asha", 20, "Hyderabad")
```

```output
Asha 20 Hyderabad
```

---

## 2. Default Arguments

A parameter can have a **default value**. If the caller does not supply that argument, the default is used.

```python
def greet(name, msg="Welcome"):
    print(msg + ",", name)

greet("Asha")
greet("Ravi", "Good morning")
```

```output
Welcome, Asha
Good morning, Ravi
```

> 💡 Parameters with defaults must come **after** parameters without defaults. `def f(a=1, b):` is a `SyntaxError`.

```python
def power(base, exponent=2):
    return base ** exponent

print(power(5))
print(power(2, 3))
```

```output
25
8
```

---

## 3. Keyword Arguments

With **keyword arguments**, you pass `name=value`, so the order does not matter.

```python
def student_info(name, age, city):
    print(name, age, city)

student_info(age=20, city="Hyderabad", name="Asha")
```

```output
Asha 20 Hyderabad
```

Keyword arguments make calls easier to read, especially when there are many parameters.

---

## 4. Mixing Positional and Keyword Arguments

Positional arguments must come **first**.

```python
student_info("Asha", city="Hyderabad", age=20)
```

```output
Asha 20 Hyderabad
```

---

## 5. Variable-Length Arguments: `*args`

Use `*args` when you do not know how many positional arguments will be passed. Python collects them into a **tuple**.

```python
def add_all(*numbers):
    total = 0
    for n in numbers:
        total = total + n
    return total

print(add_all(1, 2, 3))
print(add_all(10, 20, 30, 40))
print(add_all())
```

```output
6
100
0
```

Inside the function, `numbers` is a tuple:

```python
def show(*items):
    print(items)
    print(type(items))

show("a", "b", "c")
```

```output
('a', 'b', 'c')
<class 'tuple'>
```

> 💡 The name `args` is only a convention. The `*` is what matters.

---

## 6. Variable-Length Keyword Arguments: `**kwargs`

Use `**kwargs` to accept any number of keyword arguments. Python collects them into a **dictionary**.

```python
def show_profile(**details):
    for key, value in details.items():
        print(key, ":", value)

show_profile(name="Asha", age=20)
```

```output
name : Asha
age : 20
```

---

## 7. Combining All Argument Types

When combining, follow this order:

| Order | Type | Example |
| --- | --- | --- |
| 1 | Normal parameters | `a` |
| 2 | Default parameters | `b=2` |
| 3 | `*args` | `*args` |
| 4 | `**kwargs` | `**kwargs` |

```python
def demo(a, b=2, *args, **kwargs):
    print(a, b, args, kwargs)

demo(1)
demo(1, 5, 7, 8, x=9)
```

```output
1 2 () {}
1 5 (7, 8) {'x': 9}
```

---

## 8. Unpacking Arguments When Calling

Use `*` to unpack a list or tuple, and `**` to unpack a dictionary, into arguments.

```python
def multiply(a, b):
    return a * b

nums = [3, 4]
values = {"a": 2, "b": 5}

print(multiply(*nums))
print(multiply(**values))
```

```output
12
10
```

---

## 9. Summary of Argument Types

| Type | Syntax | Use |
| --- | --- | --- |
| Positional | `f(1, 2)` | Order decides the match |
| Default | `def f(a, b=5)` | Optional arguments |
| Keyword | `f(b=2, a=1)` | Match by name |
| Variable positional | `def f(*args)` | Any number of values |
| Variable keyword | `def f(**kwargs)` | Any number of `name=value` pairs |

## Real-World Example

A user-registration function with a default role and optional extra details:

```python
def create_user(username, role="student", **extra):
    print("User:", username)
    print("Role:", role)
    for key, value in extra.items():
        print(key, "=", value)

create_user("asha", city="Hyderabad", age=20)
```

```output
User: asha
Role: student
city = Hyderabad
age = 20
```

## Common Mistakes

### Non-Default Parameter After a Default One

```python
def f(a=1, b):    # SyntaxError
    pass
```

Write `def f(b, a=1):`.

### Positional Argument After a Keyword Argument

```python
student_info(name="Asha", 20, "Hyderabad")    # SyntaxError
```

### Giving the Same Argument Twice

```python
def greet(name):
    print(name)

greet("Asha", name="Ravi")    # TypeError
```

### Using a Mutable Default Value

```python
def add_item(item, items=[]):
    items.append(item)
    return items
```

The same list is reused on every call, which leads to surprising results. Use `items=None` and create a new list inside the function.

### Forgetting the `*` or `**`

`def f(args)` takes exactly one value. Use `def f(*args)` to accept many.

---

## Key Points

* Default arguments give a parameter a value when none is passed.
* Default parameters must come after normal parameters.
* Keyword arguments use `name=value`, so order does not matter.
* Positional arguments must come before keyword arguments.
* `*args` collects extra positional arguments into a tuple.
* `**kwargs` collects extra keyword arguments into a dictionary.
* Use `*` and `**` when calling to unpack lists and dictionaries.

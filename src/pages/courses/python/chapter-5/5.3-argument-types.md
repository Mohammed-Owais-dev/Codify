# Chapter 5: Functions

## Section 5.3: Default, Keyword & Variable-Length Arguments

Default arguments supply values when omitted; keyword arguments name parameters. *args collects extra positional arguments and **kwargs collects keyword arguments.

## Real-World Example

A notification service uses email by default but allows another channel.

## Example

```python
def notify(message, channel="email"):
    print(channel, message)
notify("Assignment due")
notify("Lab moved", channel="SMS")
```

```output
email Assignment due
SMS Lab moved
```

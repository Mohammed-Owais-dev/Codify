# Chapter 5: Functions

## Section 1: Introduction to Functions

A **function** is a named block of code that performs a specific task. You write it once and use it as many times as you like. Functions make programs shorter, cleaner and easier to fix.

---

## 1. Why Use Functions?

Imagine you need to print a welcome message in five different places. Without a function you would copy the same lines five times. With a function you write them once and **call** the function whenever needed.

Functions give you:

* **Reusability:** write once, use many times.
* **Organization:** large programs are split into small, clear parts.
* **Easy maintenance:** fix a bug in one place instead of many.
* **Readability:** a good function name explains what the code does.

---

## 2. Built-in Functions

Python already provides many ready-made functions.

| Function | Purpose | Example | Result |
| --- | --- | --- | --- |
| `print()` | Displays output | `print("Hi")` | `Hi` |
| `len()` | Length of a sequence | `len("Python")` | `6` |
| `type()` | Type of a value | `type(5)` | `<class 'int'>` |
| `abs()` | Absolute value | `abs(-5)` | `5` |
| `round()` | Rounds a number | `round(3.14159, 2)` | `3.14` |
| `max()` / `min()` | Largest / smallest | `max(4, 9, 2)` | `9` |
| `sum()` | Total of a list | `sum([1, 2, 3])` | `6` |

```python
print(abs(-5))
print(round(3.14159, 2))
print(max(4, 9, 2))
```

```output
5
3.14
9
```

Besides these, you can create your own functions. These are called **user-defined functions**.

---

## 3. Defining a Function

Use the `def` keyword to define a function.

**Syntax:**

```text
def function_name():
    statement(s)
```

```python
def greet():
    print("Hello, welcome to Codify!")
```

* `def` starts the definition.
* `greet` is the function name.
* `()` holds parameters (empty for now).
* The colon `:` and the **indented** block form the function body.

Defining a function does **not** run it. Nothing is printed yet.

---

## 4. Calling a Function

To run a function, write its name followed by parentheses.

```python
def greet():
    print("Hello, welcome to Codify!")

greet()
greet()
```

```output
Hello, welcome to Codify!
Hello, welcome to Codify!
```

The same code ran twice from two calls.

---

## 5. Order of Execution

Python reads the program from top to bottom. When it meets a function call, it jumps into the function, runs it, and then returns to the line after the call.

```python
def show():
    print("Inside function")

print("Before")
show()
print("After")
```

```output
Before
Inside function
After
```

> 💡 A function must be **defined before** it is called. Calling it earlier causes a `NameError`.

---

## 6. Functions Calling Other Functions

```python
def line():
    print("-" * 20)

def title():
    line()
    print("   CODIFY PYTHON")
    line()

title()
```

```output
--------------------
   CODIFY PYTHON
--------------------
```

---

## 7. Docstrings

A **docstring** is a string written as the first line of a function to describe it.

```python
def add_numbers():
    """Prints the sum of 10 and 20."""
    print(10 + 20)

add_numbers()
print(add_numbers.__doc__)
```

```output
30
Prints the sum of 10 and 20.
```

---

## 8. Function Naming Rules

Function names follow the same rules as variable names.

* Use lowercase letters and underscores: `calculate_total`.
* Start with a letter or underscore, never a digit.
* Use a clear verb that explains the task: `print_menu`, `find_largest`.
* Do not use Python keywords such as `if` or `for`.

---

## 9. Empty Functions with `pass`

If you want to define a function now and write the code later, use `pass`.

```python
def future_feature():
    pass

future_feature()
print("No error")
```

```output
No error
```

---

## 10. Function Anatomy

| Part | Example | Meaning |
| --- | --- | --- |
| Keyword | `def` | Starts a function |
| Name | `greet` | How you call it |
| Parentheses | `()` | Hold the inputs |
| Colon | `:` | Starts the body |
| Body | indented lines | The code that runs |
| Call | `greet()` | Executes the function |

## Real-World Example 🌍

A welcome banner reused in a program:

```python
def banner():
    print("=" * 22)
    print("  Welcome to Codify")
    print("=" * 22)

banner()
name = input("Enter your name: ")
print("Happy learning,", name)
```

If the user enters:

```text
Asha
```

The output will be:

```output
======================
  Welcome to Codify
======================
Enter your name: Asha
Happy learning, Asha
```

## Common Mistakes

### Forgetting the Parentheses When Calling

```python
def greet():
    print("Hello")

greet    # nothing happens
```

Use `greet()`.

### Calling Before Defining

```python
greet()    # NameError

def greet():
    print("Hello")
```

### Missing Colon or Indentation

```python
def greet()    # SyntaxError
print("Hello")    # IndentationError
```

Use:

```python
def greet():
    print("Hello")
```

### Writing `Def` Instead of `def`

Python is case-sensitive, so the keyword must be lowercase.

### Defining a Function but Never Calling It

A function runs only when it is called.

---

## Key Points

* A function is a reusable named block of code.
* Define it with `def name():` and an indented body.
* Call it with `name()`.
* A function must be defined before it is called.
* Python has built-in functions such as `print()`, `len()` and `max()`.
* A docstring describes what a function does.
* `pass` is a placeholder for an empty function body.

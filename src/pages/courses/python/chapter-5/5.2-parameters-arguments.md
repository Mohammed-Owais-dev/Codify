# Chapter 5: Functions

## Section 5.2: Parameters, Arguments & Return Values

Parameters are names in a function definition; arguments are values passed to it. return sends a result back, while print() only displays it.

## Real-World Example

A delivery app calculates a fee from the order amount.

## Example

```python
def delivery_fee(amount):
    if amount >= 500:
        return 0
    return 40
print(delivery_fee(350))
```

```output
40
```

## Common Mistakes

* Confusing the purpose of the concept with the exact syntax used in the example.
* Assuming one successful run proves the program works for every input.
* Ignoring invalid input, boundary values, or readability when they matter.

## Key Points

* Parameters are names in a function definition.
* arguments are values passed to it.
* return sends a result back, while print() only displays it.
* Use meaningful names and test examples before relying on a program.

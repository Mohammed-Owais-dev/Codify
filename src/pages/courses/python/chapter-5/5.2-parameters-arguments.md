# Chapter 5: Functions

## Section 2: Parameters, Arguments & Return Values

Functions become powerful when they can receive **inputs** and give back **results**. Inputs are passed through parameters and arguments, and results come back through `return`.

---

## 1. Parameters and Arguments

* A **parameter** is a variable listed in the function definition.
* An **argument** is the actual value you pass when calling the function.

```python
def greet(name):
    print("Hello,", name)

greet("Asha")
greet("Ravi")
```

```output
Hello, Asha
Hello, Ravi
```

Here `name` is the parameter, and `"Asha"` and `"Ravi"` are arguments.

---

## 2. Multiple Parameters

Separate parameters with commas. Arguments are matched **by position**.

```python
def introduce(name, age):
    print(name, "is", age, "years old")

introduce("Asha", 20)
```

```output
Asha is 20 years old
```

Position matters:

```python
def subtract(a, b):
    return a - b

print(subtract(10, 3))
print(subtract(3, 10))
```

```output
7
-7
```

---

## 3. The `return` Statement

`return` sends a value back to the place where the function was called.

```python
def add(a, b):
    return a + b

result = add(10, 20)
print(result)
print(add(5, 7))
```

```output
30
12
```

The returned value can be stored in a variable, printed, or used inside another expression.

```python
print(add(2, 3) * 10)
```

```output
50
```

---

## 4. `print()` vs `return`

| `print()` | `return` |
| --- | --- |
| Shows a value on the screen | Sends a value back to the caller |
| The value cannot be reused | The value can be stored and reused |
| Function result becomes `None` | Function result is the returned value |

```python
def show(x):
    print(x * 2)

def calc(x):
    return x * 2

a = show(5)
print(a)

b = calc(5)
print(b)
```

```output
10
None
10
```

`show()` printed `10` but returned nothing, so `a` is `None`. `calc()` returned `10`, so `b` holds it.

---

## 5. A Function Without `return`

If there is no `return`, the function returns `None` automatically.

```python
def say_hi():
    print("Hi")

value = say_hi()
print(value)
```

```output
Hi
None
```

---

## 6. `return` Ends the Function

Code after `return` is never executed.

```python
def check(n):
    if n < 0:
        return "Negative"
    return "Non-negative"

print(check(-5))
print(check(3))
```

```output
Negative
Non-negative
```

---

## 7. Returning Multiple Values

A function can return several values separated by commas. Python packs them into a **tuple**.

```python
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([4, 9, 1, 7])
print(low, high)
print(min_max([4, 9, 1, 7]))
```

```output
1 9
(1, 9)
```

---

## 8. Returning Booleans

Functions that answer yes/no questions usually return `True` or `False`.

```python
def is_even(n):
    return n % 2 == 0

print(is_even(4))
print(is_even(7))
```

```output
True
False
```

---

## 9. Passing Lists to Functions

You can pass any type of data, including lists and strings.

```python
def total(numbers):
    s = 0
    for n in numbers:
        s = s + n
    return s

print(total([10, 20, 30]))
```

```output
60
```

Lists are **mutable**, so a function can change the original list.

```python
def add_item(items):
    items.append(99)

data = [1, 2]
add_item(data)
print(data)
```

```output
[1, 2, 99]
```

## 10. Common Examples

### Temperature Conversion

```python
def to_fahrenheit(c):
    return c * 9 / 5 + 32

print(to_fahrenheit(100))
print(to_fahrenheit(0))
```

```output
212.0
32.0
```

### Area of a Rectangle

```python
def area(length, width):
    return length * width

print(area(5, 4))
```

```output
20
```

## Real-World Example 🌍

A bill calculator:

```python
def calculate_bill(price, quantity):
    return price * quantity

price = float(input("Enter price: "))
quantity = int(input("Enter quantity: "))

total = calculate_bill(price, quantity)
print("Total bill:", total)
```

If the user enters:

```text
250
3
```

The output will be:

```output
Enter price: 250
Enter quantity: 3
Total bill: 750.0
```

## Common Mistakes

### Wrong Number of Arguments

```python
def add(a, b):
    return a + b

add(5)    # TypeError: missing 1 required argument
```

### Using `print()` Instead of `return`

```python
def add(a, b):
    print(a + b)

result = add(2, 3) + 10    # TypeError, because add() returns None
```

Use `return a + b`.

### Writing Code After `return`

```python
def f():
    return 5
    print("Never runs")
```

### Forgetting to Store or Print the Returned Value

```python
def square(x):
    return x * x

square(4)    # value is returned but lost
```

Use `print(square(4))` or `r = square(4)`.

### Mixing Up the Argument Order

`subtract(3, 10)` is different from `subtract(10, 3)`.

---

## Key Points

* Parameters are in the definition; arguments are in the call.
* Arguments are matched to parameters by position.
* `return` sends a value back and ends the function.
* A function without `return` gives back `None`.
* Several values can be returned as a tuple.
* `print()` only displays; `return` lets you reuse the value.
* Passing a list lets the function change the original list.

## Section 5.4: Scope, Lambda & Higher-Order Functions

Scope controls name visibility. lambda creates a small function expression; sorted() accepts a key function, a simple higher-order-function example.

## Real-World Example

A report sorts products by price.

## Example

```python
prices = [("Pen", 10), ("Book", 80), ("Bag", 500)]
print(sorted(prices, key=lambda item: item[1]))
```

```output
[('Pen', 10), ('Book', 80), ('Bag', 500)]
```

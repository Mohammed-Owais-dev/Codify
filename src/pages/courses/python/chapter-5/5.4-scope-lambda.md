# Chapter 5: Functions

## Section 4: Scope, Lambda & Higher-Order Functions

In this section you will learn where variables can be used (scope), how to write tiny one-line functions (lambda), and how functions can be passed around like any other value (higher-order functions).

---

## 1. What is Scope?

**Scope** is the part of a program where a variable can be accessed.

* A **local variable** is created inside a function and exists only there.
* A **global variable** is created outside all functions and can be used anywhere.

---

## 2. Local Variables

```python
def show():
    message = "Hello from inside"
    print(message)

show()
```

```output
Hello from inside
```

Trying to use `message` outside the function causes an error.

```python
def show():
    message = "Hello"

show()
print(message)    # NameError: name 'message' is not defined
```

---

## 3. Global Variables

A function can **read** a global variable.

```python
course = "Python"

def show():
    print("Course:", course)

show()
print(course)
```

```output
Course: Python
Python
```

---

## 4. Local vs Global with the Same Name

If a function assigns to a name, Python creates a **new local variable**, and the global one stays unchanged.

```python
x = 10

def show():
    x = 5
    print("Inside:", x)

show()
print("Outside:", x)
```

```output
Inside: 5
Outside: 10
```

---

## 5. The `global` Keyword

To **change** a global variable from inside a function, declare it with `global`.

```python
counter = 0

def increment():
    global counter
    counter = counter + 1

increment()
increment()
print(counter)
```

```output
2
```

> 💡 Without `global`, the line `counter = counter + 1` raises an `UnboundLocalError`. Use `global` sparingly. Passing values as arguments and returning results is cleaner.

---

## 6. Nested Functions and `nonlocal`

A function can be defined inside another function. The inner function can read the outer function's variables.

```python
def outer():
    msg = "Hello"

    def inner():
        print(msg)

    inner()

outer()
```

```output
Hello
```

To **change** an outer function's variable, use `nonlocal`.

```python
def make_counter():
    count = 0

    def increment():
        nonlocal count
        count = count + 1
        return count

    return increment

counter = make_counter()
print(counter())
print(counter())
print(counter())
```

```output
1
2
3
```

---

## 7. The LEGB Rule

When Python looks for a variable name, it searches in this order:

| Level | Meaning |
| --- | --- |
| **L**ocal | Inside the current function |
| **E**nclosing | Inside any outer function |
| **G**lobal | At the top level of the file |
| **B**uilt-in | Names Python provides, such as `len` and `print` |

---

## 8. Lambda Functions

A **lambda** is a small anonymous function written in one line.

**Syntax:**

```text
lambda parameters: expression
```

The expression is calculated and returned automatically.

```python
square = lambda x: x * x
add = lambda a, b: a + b

print(square(5))
print(add(3, 4))
print((lambda x: x + 1)(9))
```

```output
25
7
10
```

A lambda can include a conditional expression.

```python
check = lambda n: "Even" if n % 2 == 0 else "Odd"

print(check(7))
print(check(10))
```

```output
Odd
Even
```

| Normal function | Lambda |
| --- | --- |
| Uses `def` and a name | Uses `lambda`, usually no name |
| Can have many statements | Only one expression |
| Needs `return` | Returns automatically |

---

## 9. Lambda with `sorted()`

Lambdas are most useful as short helper functions. The `key` argument of `sorted()` decides how items are compared.

```python
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=lambda w: len(w)))

students = [("Asha", 82), ("Ravi", 45), ("Meena", 91)]
print(sorted(students, key=lambda s: s[1], reverse=True))
```

```output
['kiwi', 'apple', 'banana']
[('Meena', 91), ('Asha', 82), ('Ravi', 45)]
```

---

## 10. Functions are Values

In Python, a function can be stored in a variable, passed as an argument and returned from another function.

```python
def hello():
    print("Hello")

greet = hello
greet()
```

```output
Hello
```

---

## 11. Higher-Order Functions

A **higher-order function** takes another function as an argument, or returns a function.

```python
def apply(func, value):
    return func(value)

print(apply(len, "Python"))
print(apply(lambda x: x * x, 4))
```

```output
6
16
```

A function that returns a function:

```python
def make_multiplier(n):
    return lambda x: x * n

double = make_multiplier(2)
triple = make_multiplier(3)

print(double(5))
print(triple(5))
```

```output
10
15
```

---

## 12. `map()` and `filter()` Preview

These built-in higher-order functions work well with lambda. You will study them in detail in Chapter 8.

```python
nums = [1, 2, 3, 4, 5]

print(list(map(lambda x: x * 2, nums)))
print(list(filter(lambda x: x % 2 == 0, nums)))
```

```output
[2, 4, 6, 8, 10]
[2, 4]
```

* `map(func, items)` applies `func` to every item.
* `filter(func, items)` keeps items for which `func` returns `True`.

---

## Real-World Example 🌍

Sorting products by price using a lambda:

```python
products = [("Pen", 10), ("Book", 150), ("Bag", 500), ("Eraser", 5)]

sorted_products = sorted(products, key=lambda p: p[1])

for name, price in sorted_products:
    print(name, "-", price)
```

```output
Eraser - 5
Pen - 10
Book - 150
Bag - 500
```

## Common Mistakes

### Using a Local Variable Outside Its Function

```python
def f():
    result = 10

f()
print(result)    # NameError
```

Return the value instead: `return result`.

### Changing a Global Without `global`

```python
total = 0

def add(n):
    total = total + n    # UnboundLocalError
```

### Writing Statements Inside a Lambda

```python
f = lambda x: print(x); return x    # SyntaxError
```

A lambda can contain only a single expression.

### Overusing Lambdas

If a lambda becomes long or hard to read, write a normal function with a clear name.

### Calling a Function When You Meant to Pass It

```python
apply(len(), "Python")    # TypeError
apply(len, "Python")      # correct
```

Pass the function **name** without parentheses.

---

## Key Points

* Local variables exist only inside their function.
* Global variables are defined outside functions and can be read anywhere.
* Use `global` to change a global variable and `nonlocal` for an enclosing function's variable.
* Python searches names in the LEGB order.
* `lambda params: expression` creates a small one-line function.
* Lambdas are handy with `sorted()`, `map()` and `filter()`.
* Functions are values: they can be stored, passed and returned.
* A higher-order function accepts or returns another function.

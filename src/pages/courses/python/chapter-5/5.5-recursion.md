# Chapter 5: Functions

## Section 5.5: Recursion & Common Function Programs

Recursion occurs when a function calls itself on a smaller problem. A base case stops calls; each recursive step should move toward it.

## Real-World Example

Factorial demonstrates a recursively defined calculation.

## Example

```python
def factorial(n):
    if n < 0:
        raise ValueError("n must be non-negative")
    if n <= 1:
        return 1
    return n * factorial(n - 1)
print(factorial(5))
```

```output
120
```

## Common Mistakes

* Recursive calls must reach a base case.
* Assuming one successful run proves the program works for every input.
* Ignoring invalid input, boundary values, or readability when they matter.

## Key Points

* Recursion occurs when a function calls itself on a smaller problem.

* Use meaningful names and test examples before relying on a program.

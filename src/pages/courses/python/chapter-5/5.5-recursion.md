# Chapter 5: Functions

## Section 5: Recursion & Common Function Programs

**Recursion** is a technique where a function calls **itself** to solve a problem. It breaks a big problem into smaller copies of the same problem. At the end of this section you will also practice several common programs written as functions.

---

## 1. What is Recursion?

Think of standing between two mirrors: each mirror shows a smaller copy of the same image. A recursive function works the same way: each call works on a smaller version of the problem until it becomes simple enough to answer directly.

Every recursive function needs two parts:

| Part | Meaning |
| --- | --- |
| **Base case** | The simple case that stops the recursion |
| **Recursive case** | The part where the function calls itself with a smaller input |

> 💡 Without a base case, the function calls itself forever and Python raises a `RecursionError`.

---

## 2. A Simple Example: Countdown

```python
def countdown(n):
    if n == 0:
        print("Liftoff!")
    else:
        print(n)
        countdown(n - 1)

countdown(3)
```

```output
3
2
1
Liftoff!
```

* Base case: `n == 0` prints `Liftoff!` and stops.
* Recursive case: print `n`, then call `countdown(n - 1)`.

## 3. Factorial

The factorial of `n` (written `n!`) is `n x (n-1) x ... x 1`. For example, `5! = 5 x 4 x 3 x 2 x 1 = 120`.

The recursive idea is `n! = n x (n-1)!`, and `0! = 1`.

```python
def factorial(n):
    if n == 0 or n == 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))
print(factorial(0))
```

```output
120
1
```

### How it Works

```text
factorial(3)
= 3 * factorial(2)
= 3 * (2 * factorial(1))
= 3 * (2 * 1)
= 6
```

Each call waits for the next call to finish. Python keeps these waiting calls on the **call stack**.

## 4. Sum of the First `n` Numbers

```python
def sum_n(n):
    if n == 0:
        return 0
    return n + sum_n(n - 1)

print(sum_n(5))
```

```output
15
```

Here `5 + 4 + 3 + 2 + 1 + 0 = 15`.

## 5. Fibonacci Series

In the Fibonacci series, each number is the sum of the previous two: `0, 1, 1, 2, 3, 5, 8, 13, ...`

```python
def fib(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    return fib(n - 1) + fib(n - 2)

print([fib(i) for i in range(8)])
```

```output
[0, 1, 1, 2, 3, 5, 8, 13]
```

## 6. Power of a Number

```python
def power(base, exp):
    if exp == 0:
        return 1
    return base * power(base, exp - 1)

print(power(2, 5))
```

```output
32
```

## 7. Reversing a String

```python
def reverse(s):
    if len(s) <= 1:
        return s
    return reverse(s[1:]) + s[0]

print(reverse("code"))
```

```output
edoc
```

## 8. GCD Using Recursion

The **GCD** (greatest common divisor) can be found with Euclid's method: `gcd(a, b) = gcd(b, a % b)`, and `gcd(a, 0) = a`.

```python
def gcd(a, b):
    if b == 0:
        return a
    return gcd(b, a % b)

print(gcd(48, 18))
```

```output
6
```

## 9. Recursion vs Iteration

| Feature | Recursion | Iteration (loops) |
| --- | --- | --- |
| Idea | Function calls itself | Loop repeats a block |
| Stopping | Base case | Loop condition |
| Memory | Uses call stack | Uses less memory |
| Speed | Usually slower | Usually faster |
| Best for | Naturally nested problems | Simple repetition |

Python limits recursion depth (about 1000 calls by default). For very large inputs, prefer a loop.

## 10. Common Function Programs

### Check for a Prime Number

```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, n):
        if n % i == 0:
            return False
    return True

print([n for n in range(1, 21) if is_prime(n)])
```

```output
[2, 3, 5, 7, 11, 13, 17, 19]
```

### Count Vowels

```python
def count_vowels(text):
    count = 0
    for ch in text.lower():
        if ch in "aeiou":
            count = count + 1
    return count

print(count_vowels("Programming"))
```

```output
3
```

### Palindrome Check

```python
def is_palindrome(text):
    return text == text[::-1]

print(is_palindrome("level"))
print(is_palindrome("python"))
```

```output
True
False
```

### Find the Largest in a List

```python
def largest(numbers):
    big = numbers[0]
    for n in numbers:
        if n > big:
            big = n
    return big

print(largest([12, 45, 7, 32]))
```

```output
45
```

### Factorial Using a Loop

```python
def factorial_loop(n):
    result = 1
    for i in range(1, n + 1):
        result = result * i
    return result

print(factorial_loop(5))
```

```output
120
```

## Real-World Example

A program that finds the sum of the digits of a number using recursion:

```python
def sum_digits(n):
    if n < 10:
        return n
    return n % 10 + sum_digits(n // 10)

number = int(input("Enter a number: "))
print("Sum of digits:", sum_digits(number))
```

If the user enters:

```text
2345
```

The output will be:

```output
Enter a number: 2345
Sum of digits: 14
```

## Common Mistakes

### Forgetting the Base Case

```python
def countdown(n):
    print(n)
    countdown(n - 1)    # RecursionError
```

Always add a condition that stops the recursion.

### Not Moving Toward the Base Case

```python
def f(n):
    if n == 0:
        return 0
    return f(n)    # n never changes, infinite recursion
```

Each call must use a smaller or simpler input.

### Forgetting to `return` the Recursive Call

```python
def factorial(n):
    if n == 1:
        return 1
    n * factorial(n - 1)    # returns None
```

Write `return n * factorial(n - 1)`.

### Using Recursion for Very Large Inputs

Deep recursion can exceed Python's limit. Use a loop instead.

### Inefficient Fibonacci

The simple recursive `fib()` repeats the same calculations many times and becomes very slow for large `n`. Use a loop for big values.

---

## Key Points

* Recursion means a function calls itself.
* Every recursive function needs a base case and a recursive case.
* Each recursive call should work on a smaller problem.
* Python stores waiting calls on the call stack and stops at about 1000 levels.
* Classic recursive programs: factorial, sum, Fibonacci, power, GCD, string reverse.
* Loops are usually faster and use less memory than recursion.
* Write small, focused functions that each do one job and `return` a result.

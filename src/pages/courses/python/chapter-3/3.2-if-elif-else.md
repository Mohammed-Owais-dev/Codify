# Chapter 3: Conditional Statements & Loops

## Section 2: if, elif & else

The `if`, `elif` and `else` statements let your program choose one path out of several. They are the most important decision-making tools in Python.

---

## 1. The `if` Statement

The `if` block runs only when the condition is `True`.

**Syntax:**

```text
if condition:
    statement(s)
```

```python
temperature = 35

if temperature > 30:
    print("It is a hot day.")
```

```output
It is a hot day.
```

If the condition is `False`, Python skips the block and nothing is printed.

---

## 2. Indentation Matters

Python uses **indentation** (spaces at the start of a line) to mark the block that belongs to the `if`.

```python
number = 10

if number > 5:
    print("Number is greater than 5")
    print("This line is also inside the if block")

print("This line is outside the if block")
```

```output
Number is greater than 5
This line is also inside the if block
This line is outside the if block
```

> 💡 Use 4 spaces for each level of indentation, and use the same amount for every line in a block.

---

## 3. The `if-else` Statement

`else` runs when the `if` condition is `False`. It has no condition of its own.

**Syntax:**

```text
if condition:
    statement(s)
else:
    statement(s)
```

```python
age = 15

if age >= 18:
    print("Eligible to vote")
else:
    print("Not eligible to vote")
```

```output
Not eligible to vote
```

Exactly one of the two blocks always runs.

---

## 4. Even or Odd Program

The remainder operator `%` gives the remainder of a division. A number is even when the remainder after dividing by 2 is `0`.

```python
number = 7

if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")
```

```output
Odd number
```

---

## 5. The `if-elif-else` Ladder

Use `elif` (short for "else if") to test more than two conditions. Python checks them from top to bottom and runs the **first** block whose condition is true.

**Syntax:**

```text
if condition1:
    statement(s)
elif condition2:
    statement(s)
elif condition3:
    statement(s)
else:
    statement(s)
```

```python
marks = 72

if marks >= 90:
    print("Grade A+")
elif marks >= 75:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
elif marks >= 40:
    print("Grade C")
else:
    print("Fail")
```

```output
Grade B
```

Here `72 >= 90` and `72 >= 75` are false, `72 >= 60` is true, so `Grade B` is printed and the rest of the ladder is skipped.

* You can use as many `elif` blocks as you need.
* `else` is optional and must come last.

---

## 6. Multiple `if` vs `elif`

Separate `if` statements are all checked independently. An `elif` chain stops at the first match.

```python
x = 15

if x > 10:
    print("Greater than 10")
if x > 5:
    print("Greater than 5")
```

```output
Greater than 10
Greater than 5
```

```python
x = 15

if x > 10:
    print("Greater than 10")
elif x > 5:
    print("Greater than 5")
```

```output
Greater than 10
```

Use `elif` when only one of the choices should run.

---

## 7. Using Logical Operators in Conditions

Combine conditions with `and`, `or` and `not`.

```python
year = 2024

if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print("Leap year")
else:
    print("Not a leap year")
```

```output
Leap year
```

---

## 8. Checking Membership with `in`

The `in` operator checks whether a value exists inside a string or a collection.

```python
vowels = "aeiou"
letter = "e"

if letter in vowels:
    print("Vowel")
else:
    print("Consonant")
```

```output
Vowel
```

---

## 9. Checking Strings and Empty Values

```python
username = ""

if username:
    print("Welcome,", username)
else:
    print("Username cannot be empty")
```

```output
Username cannot be empty
```

An empty string is falsy, so the `else` block runs.

## Real-World Example 🌍

A grade calculator that reads marks from the user:

```python
marks = int(input("Enter your marks: "))

if marks >= 90:
    grade = "A+"
elif marks >= 75:
    grade = "A"
elif marks >= 60:
    grade = "B"
elif marks >= 40:
    grade = "C"
else:
    grade = "Fail"

print("Your grade is", grade)
```

If the user enters:

```text
82
```

The output will be:

```output
Enter your marks: 82
Your grade is A
```

## Common Mistakes

### Forgetting the Colon

```python
if marks >= 40    # SyntaxError
    print("Pass")
```

Use:

```python
if marks >= 40:
    print("Pass")
```

### Wrong Indentation

```python
if marks >= 40:
print("Pass")    # IndentationError
```

### Writing `else if`

Python does not use `else if`.

```python
else if marks > 50:    # SyntaxError
```

Use `elif marks > 50:`.

### Wrong Order of Conditions

```python
marks = 95

if marks >= 40:
    print("Grade C")    # runs first!
elif marks >= 90:
    print("Grade A+")
```

Always test the **most specific** (highest) condition first.

### Adding a Condition to `else`

```python
else marks < 40:    # SyntaxError
```

`else` never takes a condition. Use `elif` instead.

---

## Key Points

* `if` runs a block when its condition is true.
* `else` runs when the `if` condition is false.
* `elif` checks extra conditions, one after another.
* Only the first true block in an `if-elif-else` chain runs.
* Indentation defines the block, and each header ends with a colon `:`.
* Use `%` to test even/odd and divisibility.
* Place the most specific condition first in an `elif` ladder.

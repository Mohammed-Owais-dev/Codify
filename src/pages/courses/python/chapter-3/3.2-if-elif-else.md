# Chapter 3: Conditional Statements & Loops

## Section 3.2: if, elif & else

if checks the first condition, elif checks alternatives, and else handles remaining cases. Conditions are evaluated from top to bottom.

## Real-World Example

A marks application assigns a grade from score ranges.

## Example

```python
score = 76
if score >= 90:
    grade = "A"
elif score >= 70:
    grade = "B"
else:
    grade = "C"
print(grade)
```

```output
B
```

## How It Works

if checks the first condition, elif checks alternatives, and else handles remaining cases. Conditions are evaluated from top to bottom. Read the code line by line, predict the result, and then run it to confirm your understanding. Change one value at a time to see how the behavior changes.

## Common Mistakes

* Confusing the purpose of the concept with the exact syntax used in the example.
* Assuming one successful run proves the program works for every input.
* Ignoring invalid input, boundary values, or readability when they matter.

## Key Points

* if checks the first condition, elif checks alternatives, and else handles remaining cases.
* Conditions are evaluated from top to bottom.
* Test the result with different inputs.
* Use meaningful names and test examples before relying on a program.

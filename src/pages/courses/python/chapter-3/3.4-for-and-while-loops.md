# Chapter 3: Conditional Statements & Loops

## Section 3.4: for & while Loops

for iterates over an iterable; while repeats while a condition is true. range(1, 4) excludes the stop value 4.

## Real-World Example

A teacher totals marks or loops through a timetable.

## Example

```python
marks = [70, 85, 90]
total = 0
for mark in marks:
    total += mark
print(total)
for n in range(1, 4):
    print(n)
```

```output
245
1
2
3
```

## Common Mistakes

* Forgetting to update a while-loop condition can create an infinite loop.
* Assuming one successful run proves the program works for every input.
* Ignoring invalid input, boundary values, or readability when they matter.

## Key Points

* for iterates over an iterable.
* while repeats while a condition is true.
* range(1, 4) excludes the stop value 4.
* Use meaningful names and test examples before relying on a program.

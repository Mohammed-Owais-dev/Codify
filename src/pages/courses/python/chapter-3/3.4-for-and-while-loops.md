# Chapter 3: Conditional Statements & Loops

## Section 4: for & while Loops

A **loop** repeats a block of code many times, so you do not have to write the same lines again and again. Python has two loops: `for` and `while`.

---

## 1. Why Do We Need Loops?

Without a loop, printing a message 5 times needs 5 lines:

```python
print("Hello")
print("Hello")
print("Hello")
print("Hello")
print("Hello")
```

With a loop, it takes only 2 lines:

```python
for i in range(5):
    print("Hello")
```

```output
Hello
Hello
Hello
Hello
Hello
```

---

## 2. The `for` Loop

A `for` loop goes through a sequence (such as a range, string or list) one item at a time.

**Syntax:**

```text
for variable in sequence:
    statement(s)
```

```python
for letter in "Python":
    print(letter)
```

```output
P
y
t
h
o
n
```

* `letter` is the loop variable. It takes a new value in every round.
* Each round of the loop is called an **iteration**.

---

## 3. The `range()` Function

`range()` creates a sequence of numbers. It has three forms:

| Form | Meaning | Example | Numbers produced |
| --- | --- | --- | --- |
| `range(stop)` | 0 up to stop - 1 | `range(5)` | 0, 1, 2, 3, 4 |
| `range(start, stop)` | start up to stop - 1 | `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(start, stop, step)` | jump by step | `range(1, 10, 2)` | 1, 3, 5, 7, 9 |

> 💡 The `stop` value is **never included** in the range.

```python
for i in range(1, 6):
    print(i)
```

```output
1
2
3
4
5
```

---

## 4. Counting Backwards

Use a negative step to count down.

```python
for i in range(5, 0, -1):
    print(i)
```

```output
5
4
3
2
1
```

---

## 5. Looping Over a List

```python
fruits = ["apple", "banana", "mango"]

for fruit in fruits:
    print("I like", fruit)
```

```output
I like apple
I like banana
I like mango
```

---

## 6. Sum of Numbers Using `for`

A running total is stored in a variable that starts at `0`.

```python
total = 0

for i in range(1, 6):
    total = total + i

print("Sum =", total)
```

```output
Sum = 15
```

---

## 7. Multiplication Table

```python
n = 5

for i in range(1, 6):
    print(n, "x", i, "=", n * i)
```

```output
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
```

---

## 8. Printing on the Same Line

By default `print()` ends with a new line. Use `end` to change this.

```python
for i in range(1, 6):
    print(i, end=" ")
```

```output
1 2 3 4 5
```

---

## 9. The `while` Loop

A `while` loop repeats **as long as its condition is true**. Use it when you do not know in advance how many times to repeat.

**Syntax:**

```text
while condition:
    statement(s)
```

```python
count = 1

while count <= 5:
    print(count)
    count = count + 1
```

```output
1
2
3
4
5
```

A `while` loop needs three things:

1. A **starting value** (`count = 1`).
2. A **condition** (`count <= 5`).
3. An **update** that moves toward ending the loop (`count = count + 1`).

---

## 10. Infinite Loops

If the condition never becomes false, the loop runs forever.

```python
count = 1

while count <= 5:
    print(count)
    # count is never updated, so this never stops
```

> 💡 If a program gets stuck in an infinite loop, press `Ctrl + C` in the terminal to stop it.

---

## 11. Sum of Digits Using `while`

Here the number of repetitions depends on the number of digits, so `while` is a good choice.

```python
n = 1234
total = 0

while n > 0:
    total = total + n % 10
    n = n // 10

print("Sum of digits =", total)
```

```output
Sum of digits = 10
```

* `n % 10` gives the last digit.
* `n // 10` removes the last digit.

---

## 12. `for` vs `while`

| Feature | `for` loop | `while` loop |
| --- | --- | --- |
| Best when | Number of repeats is known | Number of repeats is not known |
| Works with | Sequences and `range()` | Any condition |
| Update step | Handled automatically | You must write it yourself |
| Risk of infinite loop | Very low | Higher |

---

## Real-World Example

A password check that keeps asking until the user enters the right password:

```python
password = ""

while password != "python123":
    password = input("Enter password: ")

print("Access granted")
```

If the user enters:

```text
hello
python123
```

The output will be:

```output
Enter password: hello
Enter password: python123
Access granted
```

## Common Mistakes

### Forgetting to Update the Counter

```python
i = 1
while i <= 5:
    print(i)    # infinite loop
```

Add `i = i + 1` inside the loop.

### Off-by-One Errors with `range()`

```python
for i in range(1, 5):
    print(i)    # prints 1 to 4, not 5
```

Use `range(1, 6)` to include `5`.

### Missing Colon or Indentation

```python
for i in range(3)    # SyntaxError
print(i)             # IndentationError
```

Use:

```python
for i in range(3):
    print(i)
```

### Changing the Loop Variable Expecting It to Affect the Loop

```python
for i in range(3):
    i = 10    # next round i is still the next value from range
```

The `for` loop assigns a fresh value to `i` in every iteration.

---

## Key Points

* A loop repeats a block of code.
* `for` is used to go through a sequence or a `range()`.
* `range(start, stop, step)` never includes `stop`.
* `while` repeats as long as its condition is `True`.
* A `while` loop needs a starting value, a condition and an update.
* Forgetting the update creates an infinite loop.
* `print(..., end=" ")` keeps output on the same line.

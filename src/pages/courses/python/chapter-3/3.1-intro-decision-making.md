# Chapter 3: Conditional Statements & Loops

## Section 1: Introduction to Decision Making

So far, our programs ran line by line from top to bottom. Real programs must also **make decisions**: check a condition and choose what to do next. In this section you will learn the building blocks of decision making in Python.

---

## 1. What is Decision Making?

Decision making means running a block of code **only when a condition is true**.

Think of everyday life:

* If it is raining, take an umbrella.
* If your marks are above 40, you pass.
* If the password is correct, log in.

Python programs do the same using **conditions** and **conditional statements**.

---

## 2. Flow of Control

The order in which Python executes statements is called the **flow of control**. There are three kinds:

| Type | Description | Example |
| --- | --- | --- |
| Sequential | Statements run one after another | `print()` lines in order |
| Selection | Python chooses which block to run | `if`, `elif`, `else` |
| Iteration | A block is repeated | `for`, `while` |

This chapter covers selection first, then iteration.

---

## 3. Boolean Values

A **Boolean** has only two possible values: `True` and `False`. Both start with a capital letter.

```python
is_raining = True
is_sunday = False

print(is_raining)
print(is_sunday)
print(type(is_raining))
```

```output
True
False
<class 'bool'>
```

Every condition in Python finally becomes either `True` or `False`.

---

## 4. Comparison Operators

Comparison operators compare two values and return a Boolean result.

| Operator | Meaning | Example (`a = 10`, `b = 20`) | Result |
| --- | --- | --- | --- |
| `==` | Equal to | `a == b` | `False` |
| `!=` | Not equal to | `a != b` | `True` |
| `>` | Greater than | `a > b` | `False` |
| `<` | Less than | `a < b` | `True` |
| `>=` | Greater than or equal to | `a >= b` | `False` |
| `<=` | Less than or equal to | `a <= b` | `True` |

```python
a = 10
b = 20

print(a == b)
print(a != b)
print(a < b)
print(a >= b)
```

```output
False
True
True
False
```

> 💡 `=` assigns a value, while `==` compares two values. Mixing them up is one of the most common beginner errors.

---

## 5. Chained Comparisons

Python lets you write a range check in a natural way.

```python
x = 7

print(1 < x < 10)
print(10 < x < 20)
```

```output
True
False
```

`1 < x < 10` means "x is greater than 1 **and** less than 10".

---

## 6. Logical Operators

Logical operators combine more than one condition.

| Operator | Meaning | Result |
| --- | --- | --- |
| `and` | True only if **both** conditions are true | `True and False` is `False` |
| `or` | True if **at least one** condition is true | `True or False` is `True` |
| `not` | Reverses the result | `not True` is `False` |

```python
age = 20
has_id = True

print(age >= 18 and has_id)
print(age < 18 or has_id)
print(not has_id)
```

```output
True
True
False
```

### Truth Table

| A | B | `A and B` | `A or B` |
| --- | --- | --- | --- |
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

Order of evaluation: `not` runs first, then `and`, then `or`.

```python
print(True or False and False)
```

```output
True
```

Python evaluates `False and False` first, which gives `False`, and then `True or False` gives `True`.

---

## 7. Truthy and Falsy Values

Python can treat any value as a condition.

* **Falsy** values act like `False`: `0`, `0.0`, `""` (empty string), `[]` (empty list), `None`.
* **Truthy** values act like `True`: every other value.

```python
print(bool(0))
print(bool(5))
print(bool(""))
print(bool("Hi"))
```

```output
False
True
False
True
```

---

## 8. Your First Decision: A Quick Preview

The `if` statement runs its block only when the condition is `True`.

```python
age = 20

if age >= 18:
    print("You can vote.")

print("Program ended.")
```

```output
You can vote.
Program ended.
```

* The condition is followed by a colon `:`.
* The block under `if` is **indented** (4 spaces is the standard).
* `"Program ended."` is not indented, so it always runs.

If `age` were `15`, only `Program ended.` would be printed. The next section explains `if`, `elif` and `else` in detail.

---

## 9. Types of Conditional Statements

| Statement | Use |
| --- | --- |
| `if` | Run a block if a condition is true |
| `if-else` | Choose between two blocks |
| `if-elif-else` | Choose between many blocks |
| Nested `if` | An `if` inside another `if` |
| Conditional expression | A one-line `if-else` |

## Real-World Example 🌍

A program that checks whether a person can apply for a driving licence (age 18 or above and has completed the training):

```python
age = int(input("Enter your age: "))
trained = input("Completed training? (yes/no): ")

if age >= 18 and trained == "yes":
    print("You can apply for a licence.")
```

If the user enters:

```text
21
yes
```

The output will be:

```output
Enter your age: 21
Completed training? (yes/no): yes
You can apply for a licence.
```

## Common Mistakes

### Using `=` Instead of `==`

```python
age = 18
if age = 18:    # SyntaxError
    print("Adult")
```

Use:

```python
if age == 18:
    print("Adult")
```

### Writing `true` Instead of `True`

Python is case-sensitive.

```python
is_ready = true    # NameError
```

Use:

```python
is_ready = True
```

### Forgetting the Colon

```python
if age >= 18    # SyntaxError
    print("Adult")
```

### Comparing Input Without Converting It

`input()` returns text, so convert it before comparing numbers.

```python
age = input("Age: ")
if age >= 18:    # TypeError
    print("Adult")
```

Use `age = int(input("Age: "))`.

---

## Key Points

* Decision making lets a program choose which code to run.
* A condition always results in `True` or `False`.
* Comparison operators: `==`, `!=`, `>`, `<`, `>=`, `<=`.
* Logical operators: `and`, `or`, `not`.
* `0`, `""`, `[]` and `None` are falsy; most other values are truthy.
* A colon `:` and indentation are required after `if`.
* `=` assigns, `==` compares.

# Chapter 3: Conditional Statements & Loops

## Section 3.1: Introduction to Decision Making

Decision-making uses conditions to choose which block runs. Comparisons such as <, ==, and >= produce True or False.

## Real-World Example

A ticket system selects a fare based on passenger age.

## Example

```python
age = 17
if age < 18:
    print("Student fare")
else:
    print("Regular fare")
```

```output
Student fare
```

# Chapter 3: Conditional Statements & Loops

## Section 3.3: Nested Conditions & Conditional Expressions

Conditions select statements to run, while loops repeat statements. Use if, elif, and else for decisions, and for or while for repetition.

This lesson focuses on **Nested Conditions & Conditional Expressions**. Learn its purpose, how Python expresses it, and when it is useful. Start with the example, then modify it to see how the program behaves.

## Example

```python
marks = 82
if marks >= 75:
    print("Passed")
else:
    print("Keep practising")
for number in range(1, 4):
    print(number)
```

```output
Passed
1
2
3
```

## How to Practise

1. Run the example in your Python environment.
2. Predict the output before running it again.
3. Change one value or statement and observe the result.
4. Explain each line in your own words.
5. Test different inputs where appropriate.

## Common Mistakes

* Forgetting Python's spelling, punctuation, or indentation rules.
* Using a value before assigning it.
* Assuming input always has the expected format.
* Copying code without understanding the steps.
* Testing only one example.

## Key Points

* **Nested Conditions & Conditional Expressions** is part of the Python learning path.
* Understand the purpose before memorising syntax.
* Small runnable examples make new ideas easier to understand.
* Meaningful names, clear structure, and testing improve code quality.

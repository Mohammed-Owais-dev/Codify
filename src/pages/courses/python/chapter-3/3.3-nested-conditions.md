# Chapter 3: Conditional Statements & Loops

## Section 3: Nested Conditions & Conditional Expressions

Sometimes one decision depends on another. Python lets you place an `if` inside another `if`, and also gives a short one-line form for simple choices.

---

## 1. What is a Nested `if`?

A **nested if** is an `if` statement written inside another `if` (or `else`) block. The inner condition is checked only when the outer condition is true.

**Syntax:**

```text
if outer_condition:
    if inner_condition:
        statement(s)
    else:
        statement(s)
else:
    statement(s)
```

---

## 2. A Simple Nested Example

```python
age = 25
has_ticket = True

if age >= 18:
    if has_ticket:
        print("Entry allowed")
    else:
        print("Please buy a ticket")
else:
    print("Adults only")
```

```output
Entry allowed
```

Python first checks the age. Only then does it check the ticket.

---

## 3. Nested `if` with `elif`

Inner blocks can use `elif` and `else` too.

```python
marks = 85
attendance = 70

if marks >= 40:
    if attendance >= 75:
        print("Passed")
    elif attendance >= 60:
        print("Passed with warning (low attendance)")
    else:
        print("Detained")
else:
    print("Failed")
```

```output
Passed with warning (low attendance)
```

---

## 4. Largest of Three Numbers

A classic program that uses nested conditions.

```python
a = 12
b = 45
c = 30

if a >= b:
    if a >= c:
        print(a, "is the largest")
    else:
        print(c, "is the largest")
else:
    if b >= c:
        print(b, "is the largest")
    else:
        print(c, "is the largest")
```

```output
45 is the largest
```

---

## 5. Replacing Nesting with `and`

Many nested conditions can be written flatter with `and`. This is shorter and easier to read.

```python
age = 25
has_ticket = True

if age >= 18 and has_ticket:
    print("Entry allowed")
else:
    print("Entry denied")
```

```output
Entry allowed
```

> 💡 Use nesting when each level needs its **own different message**. Use `and` when you only need one combined result. Avoid going deeper than 3 levels, because the code becomes hard to read.

---

## 6. Conditional Expressions (Ternary Operator)

A **conditional expression** writes a simple `if-else` in a single line.

**Syntax:**

```text
value_if_true if condition else value_if_false
```

```python
age = 17

status = "Adult" if age >= 18 else "Minor"
print(status)
```

```output
Minor
```

The same logic in the normal form:

```python
if age >= 18:
    status = "Adult"
else:
    status = "Minor"
```

---

## 7. Conditional Expression Inside `print()`

You can place the expression directly inside a function call.

```python
number = 7

print("Even" if number % 2 == 0 else "Odd")
```

```output
Odd
```

---

## 8. Finding the Maximum of Two Numbers

```python
a = 10
b = 25

largest = a if a > b else b
print("Largest:", largest)
```

```output
Largest: 25
```

---

## 9. Chained Conditional Expressions

You can chain more than one expression, but keep it short.

```python
marks = 68

result = "Distinction" if marks >= 75 else "First Class" if marks >= 60 else "Pass"
print(result)
```

```output
First Class
```

> 💡 If a conditional expression becomes hard to read, switch to a regular `if-elif-else`. Clear code is better than short code.

---

## 10. Comparison: Normal `if` vs Conditional Expression

| Feature | Normal `if-else` | Conditional expression |
| --- | --- | --- |
| Lines | Multiple | One |
| Can run many statements | Yes | No, it only gives a value |
| Best for | Complex logic | Simple two-way choices |

## Real-World Example 🌍

An ATM withdrawal check that uses nested conditions:

```python
balance = 5000
amount = int(input("Enter amount to withdraw: "))

if amount > 0:
    if amount <= balance:
        balance = balance - amount
        print("Withdrawal successful")
        print("Remaining balance:", balance)
    else:
        print("Insufficient balance")
else:
    print("Enter a valid amount")
```

If the user enters:

```text
2000
```

The output will be:

```output
Enter amount to withdraw: 2000
Withdrawal successful
Remaining balance: 3000
```

## Common Mistakes

### Wrong Indentation in Nested Blocks

```python
if age >= 18:
if has_ticket:    # IndentationError
    print("Allowed")
```

Each inner block must be indented one more level.

### Mismatched `else`

An `else` belongs to the `if` at the **same indentation level**.

```python
if a > 0:
    if b > 0:
        print("Both positive")
else:
    print("a is not positive")    # belongs to the outer if
```

### Missing `else` in a Conditional Expression

```python
status = "Adult" if age >= 18    # SyntaxError
```

A conditional expression always needs both `if` and `else`.

### Too Many Nested Levels

Deep nesting is hard to read. Combine conditions with `and` / `or` where possible.

---

## Key Points

* A nested `if` is an `if` inside another `if`.
* The inner condition runs only when the outer condition is true.
* Indentation decides which `else` belongs to which `if`.
* Flat conditions with `and` are often simpler than nested ones.
* Conditional expression: `value1 if condition else value2`.
* It is best for short, simple choices.
* Keep nesting to about 3 levels.

## Section 3.3: Nested Conditions & Conditional Expressions

Nested conditions place a decision inside another block. A conditional expression chooses one of two values; use regular blocks for complex logic.

## Real-World Example

A website checks account status and email verification.

## Example

```python
active = True
verified = False
if active:
    if verified:
        print("Access granted")
    else:
        print("Verify email")
status = "Open" if active else "Closed"
print(status)
```

```output
Verify email
Open
```

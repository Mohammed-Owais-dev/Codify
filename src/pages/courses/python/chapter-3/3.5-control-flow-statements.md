## Section 3.5: break, continue, pass & Nested Loops

break exits the nearest loop, continue skips to the next iteration, and pass is a placeholder. Nested loops run one loop inside another.

## Real-World Example

A timetable generator skips lunch periods for each day.

## Example

```python
for day in range(1, 3):
    for period in range(1, 4):
        if period == 2:
            continue
        print(day, period)
```

```output
1 1
1 3
2 1
2 3
```

# Chapter 3: Conditional Statements & Loops

## Section 5: break, continue, pass & Nested Loops

Loops normally run until their condition ends. The statements `break`, `continue` and `pass` let you control exactly how a loop behaves. You will also learn to place one loop inside another.

---

## 1. The `break` Statement

`break` **stops the loop immediately** and moves to the code after it.

```python
for i in range(1, 10):
    if i == 5:
        break
    print(i)

print("Loop ended")
```

```output
1
2
3
4
Loop ended
```

When `i` becomes `5`, `break` exits the loop, so `5` and the numbers after it are never printed.

---

## 2. `break` in a `while` Loop

```python
while True:
    text = input("Type 'exit' to stop: ")
    if text == "exit":
        break
    print("You typed:", text)
```

If the user enters:

```text
hi
exit
```

The output will be:

```output
Type 'exit' to stop: hi
You typed: hi
Type 'exit' to stop: exit
```

`while True` creates a loop that runs forever, and `break` is the way out.

---

## 3. The `continue` Statement

`continue` **skips the rest of the current iteration** and jumps to the next one.

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```

```output
1
2
4
5
```

The number `3` is skipped, but the loop keeps running.

---

## 4. `break` vs `continue`

| Statement | What it does |
| --- | --- |
| `break` | Ends the whole loop |
| `continue` | Skips only the current iteration |

---

## 5. The `pass` Statement

`pass` does **nothing**. It is a placeholder used where Python needs a statement but you have no code yet.

```python
age = 20

if age >= 18:
    pass    # code will be added later
else:
    print("Minor")

print("Done")
```

```output
Done
```

Without `pass`, an empty block causes an `IndentationError`.

```python
for i in range(3):
    pass

print("Loop finished")
```

```output
Loop finished
```

---

## 6. The `else` Block with Loops

A loop can have an `else` block. It runs **only when the loop ends normally**, that is, without a `break`.

```python
for i in range(1, 4):
    print(i)
else:
    print("Loop finished")
```

```output
1
2
3
Loop finished
```

With `break`, the `else` block is skipped:

```python
numbers = [3, 7, 9]

for n in numbers:
    if n == 7:
        print("Found")
        break
else:
    print("Not found")
```

```output
Found
```

---

## 7. Nested Loops

A **nested loop** is a loop inside another loop. For every single iteration of the outer loop, the inner loop runs completely.

**Syntax:**

```text
for i in range(...):
    for j in range(...):
        statement(s)
```

```python
for i in range(1, 4):
    for j in range(1, 3):
        print("i =", i, "j =", j)
```

```output
i = 1 j = 1
i = 1 j = 2
i = 2 j = 1
i = 2 j = 2
i = 3 j = 1
i = 3 j = 2
```

The outer loop runs 3 times and the inner loop runs 2 times for each, giving 3 x 2 = 6 lines.

---

## 8. `break` in Nested Loops

`break` only exits the **innermost** loop that contains it.

```python
for i in range(1, 4):
    for j in range(1, 4):
        if j == 2:
            break
        print(i, j)
```

```output
1 1
2 1
3 1
```

---

## 9. Star Pattern

Nested loops are often used to print patterns. The outer loop controls the rows, and the inner loop controls the columns.

```python
for i in range(1, 5):
    for j in range(i):
        print("*", end="")
    print()
```

```output
*
**
***
****
```

* `end=""` keeps the stars on the same line.
* The empty `print()` moves to the next line after each row.

---

## 10. Number Pattern

```python
for i in range(1, 4):
    for j in range(1, i + 1):
        print(j, end="")
    print()
```

```output
1
12
123
```

---

## 11. Prime Number Check

This program combines `for`, `break` and `else`.

```python
n = 29

for i in range(2, n):
    if n % i == 0:
        print(n, "is not prime")
        break
else:
    print(n, "is prime")
```

```output
29 is prime
```

---

## Real-World Example

A prime number checker that reads a number from the user:

```python
n = int(input("Enter a number: "))

if n < 2:
    print(n, "is not a prime number")
else:
    for i in range(2, n):
        if n % i == 0:
            print(n, "is not a prime number")
            break
    else:
        print(n, "is a prime number")
```

If the user enters:

```text
29
```

The output will be:

```output
Enter a number: 29
29 is a prime number
```

## Common Mistakes

### Using `break` Outside a Loop

```python
x = 5
if x > 3:
    break    # SyntaxError
```

`break` and `continue` can be used only inside loops.

### Skipping the Counter Update with `continue`

```python
i = 0
while i < 5:
    if i == 2:
        continue    # i is never updated, infinite loop
    i = i + 1
```

Update `i` **before** `continue`.

### Expecting `break` to Exit All Nested Loops

`break` exits only the inner loop. The outer loop keeps running.

### Forgetting `print()` After the Inner Loop

Without an empty `print()`, the whole pattern appears on one line.

### Leaving a Block Empty

```python
if x > 5:
# nothing here    # IndentationError
```

Write `pass` inside the block.

---

## Key Points

* `break` ends the loop immediately.
* `continue` skips the current iteration only.
* `pass` does nothing and acts as a placeholder.
* A loop's `else` block runs only if the loop was not stopped by `break`.
* In nested loops, the inner loop completes for every outer iteration.
* `break` affects only the innermost loop.
* Use `print(..., end="")` and an empty `print()` to build patterns.

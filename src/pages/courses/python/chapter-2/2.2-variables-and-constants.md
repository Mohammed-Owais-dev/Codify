## Section 2.2: Variables & Constants

Assignment binds a name to a value. Uppercase names are a convention for constants, not enforced by Python; descriptive names improve readability.

## Real-World Example

A bill calculator stores price and tax rate.

## Example

```python
price = 500
tax_rate = 0.05
print(price + price * tax_rate)
```

```output
525.0
```

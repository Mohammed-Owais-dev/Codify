# Chapter 2: Python Basics

## Section 2: Variables & Constants

Programs need to remember information while they work. A bill calculator stores prices, a student record stores a name and marks, and a game stores a player's score. In Python, **variables** give names to values so that a program can use and update that information.

Python uses assignment to bind a name to an object. You do not need to declare a variable's type in advance. The value assigned determines the object's type, and a name can later be assigned a value of another type.

---

## 1. Creating a Variable

Use an assignment statement with a name, the assignment operator (`=`), and a value.

```python
student_name = "Asha"
marks = 86
average = 86.5

print(student_name)
print(marks)
print(average)
```

```output
Asha
86
86.5
```

The equal sign in an assignment does not mean “is equal to” in the same way it is used in mathematics. It tells Python to assign the value on the right to the name on the left.

A variable name can refer to a value that the program will use later. The name `marks` is more descriptive than a name such as `x`, especially when the program becomes larger.

## 2. Updating a Variable

A variable can be assigned a new value during program execution.

```python
score = 10
print(score)

score = 15
print(score)
```

```output
10
15
```

The second assignment changes what the name `score` refers to. The first printed value is already displayed, so it remains in the output.

You can also use the current value when calculating a new one:

```python
score = 10
score = score + 5
print(score)
```

```output
15
```

Python first evaluates `score + 5`, then assigns the result back to `score`. The shorter form `score += 5` performs the same kind of update.

## 3. Rules for Naming Variables

Python names must follow specific rules.

* A name may contain letters, digits, and underscores.
* A name cannot begin with a digit.
* Spaces are not allowed inside a variable name.
* Names are case-sensitive.
* Python keywords, such as `if`, `for`, and `class`, cannot be used as ordinary variable names.
* Choose names that describe the stored information.

Examples:

| Valid name | Invalid name | Reason |
| --- | --- | --- |
| `student_name` | `student name` | A name cannot contain a space |
| `marks2` | `2marks` | A name cannot start with a digit |
| `total_price` | `total-price` | A hyphen is not allowed in a normal identifier |
| `_count` | `class` | `class` is a reserved keyword |

Python programmers commonly use **snake_case** for variable names: lowercase words separated by underscores. For example, `total_amount`, `student_age`, and `is_registered`.

## 4. Multiple Assignment

Python can assign values to multiple names in one statement.

```python
name, age, city = "Asha", 17, "Nandyal"

print(name)
print(age)
print(city)
```

```output
Asha
17
Nandyal
```

The number of names and values should match when using this form. Python also allows one value to be assigned to several names:

```python
first = second = third = 0
print(first, second, third)
```

```output
0 0 0
```

This is convenient for simple immutable values such as integers. Remember that assigning one mutable object, such as a list, to multiple names makes those names refer to the same list object.

## 5. Variables Refer to Objects

A useful way to understand Python variables is to think of a name as a label referring to an object. Assignment does not permanently lock a name to one type.

```python
value = 25
print(value, type(value).__name__)

value = "twenty-five"
print(value, type(value).__name__)
```

```output
25 int
twenty-five str
```

The name `value` first refers to an integer and later refers to a string. This is allowed in Python. However, changing types without a clear reason can make a program harder to understand, so use names consistently.

## 6. What Are Constants?

A **constant** is a value that a program is intended not to change. Python does not enforce ordinary constants as a separate language feature. Instead, programmers commonly write constant names in uppercase letters with underscores.

```python
GST_RATE = 0.18
MAX_ATTEMPTS = 3
COLLEGE_NAME = "Codify College"

price = 1000
final_price = price + price * GST_RATE

print(final_price)
print(MAX_ATTEMPTS)
print(COLLEGE_NAME)
```

```output
1180.0
3
Codify College
```

Uppercase names communicate intent to other programmers. They do not prevent reassignment: Python will still allow `GST_RATE = 0.20`. The convention is a reminder that the value should be treated as fixed.

Use constants for values that are shared or meaningful across a program, such as a tax rate, maximum retry count, or application setting. Avoid using a constant for every small value when a clear explanation is not needed.

## 7. Real-World Example: Calculating a Shopping Bill

A shop bill needs the price of an item, the quantity purchased, and the delivery charge. These are stored in variables so the program can calculate a total.

```python
item_price = 120
quantity = 3
delivery_charge = 30

subtotal = item_price * quantity
total = subtotal + delivery_charge

print("Subtotal:", subtotal)
print("Delivery:", delivery_charge)
print("Total:", total)
```

```output
Subtotal: 360
Delivery: 30
Total: 390
```

Each name describes one piece of information. If the quantity changes from 3 to 4, the program recalculates the subtotal and total automatically. This is the practical benefit of storing values rather than repeating numbers throughout the code.

## 8. Assignment Operators

Assignment operators make common updates shorter.

| Operator | Example | Equivalent idea |
| --- | --- | --- |
| `=` | `score = 10` | Assign 10 |
| `+=` | `score += 2` | Add 2 and assign the result |
| `-=` | `score -= 2` | Subtract 2 and assign the result |
| `*=` | `price *= 2` | Multiply by 2 and assign the result |
| `/=` | `total /= 2` | Divide by 2 and assign the result |
| `%=` | `value %= 3` | Assign the remainder after division |

Example:

```python
wallet = 500
wallet -= 120
wallet += 50
print(wallet)
```

```output
430
```

The wallet starts at 500, decreases by 120, and then increases by 50. The final value is 430.

## 9. Choosing Good Names

Good names reduce the amount of explanation needed to understand a program.

Less clear:

```python
a = 250
b = 4
c = a * b
```

Clearer:

```python
item_price = 250
quantity = 4
total_cost = item_price * quantity
```

Both versions calculate the same result, but the second version communicates the purpose of each value. Avoid names that are too long without a reason, and do not use misleading names such as `student_age` to store a price.

## ⚠️ Common Mistakes

### 1. Using an invalid name

names cannot start with a digit or contain spaces.

### 2. Confusing `=` and `==`

`=` assigns a value; `==` compares two values.

### 3. Assuming uppercase makes a true constant

uppercase is a convention, not a restriction enforced by Python.

### 4. Using unclear names

names such as `a1` or `temp2` can be confusing when their purpose is not obvious.

### 5. Expecting a variable to keep its original value

a later assignment can change what the name refers to.

### 6. Repeating important values everywhere

a named constant can make shared settings easier to update consistently.

---

## 🔑 Key Points

* A variable is a name that refers to a value or object.
* Assignment uses the `=` operator.
* Python determines a value's type at runtime; a name is not permanently tied to one type.
* Variable names are case-sensitive and must follow naming rules.
* Snake_case is a common style for variable names.
* Assignment operators such as `+=` and `-=` update values.
* Uppercase names are the common convention for constants, but Python does not enforce them as immutable.
* Descriptive names make programs easier to read and maintain.

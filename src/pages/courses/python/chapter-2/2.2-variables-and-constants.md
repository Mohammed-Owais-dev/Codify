# Chapter 2: Python Basics

## Section 2: Variables & Constants

A program needs to remember information such as a name, an age or a price. We store this information in **variables**. In this topic you will learn how to create and use them.

---

## 1. What is a Variable?

A **variable** is a name that refers to a value stored in the computer's memory. Think of it as a labeled box that holds something.

```python
age = 20
print(age)
```

```output
20
```

Here `age` is the variable and `20` is the value stored in it.

---

## 2. Creating a Variable

In Python, we create a variable by assigning a value with the `=` sign. There is no need to write a type like `int` or `string` first.

```python
name = "Asha"
age = 20
height = 5.4

print(name)
print(age)
print(height)
```

```output
Asha
20
5.4
```

The `=` sign here means **assign**, not "equal to". It puts the value on the right into the name on the left.

---

## 3. Using Variables with print()

You can print many variables together.

```python
name = "Ravi"
age = 22

print("Name:", name)
print("Age:", age)
```

```output
Name: Ravi
Age: 22
```

---

## 4. Changing the Value of a Variable

The value of a variable can change at any time. That is why it is called a *variable*.

```python
score = 10
print(score)

score = 25
print(score)
```

```output
10
25
```

You can also use the old value to make a new value:

```python
score = 10
score = score + 5

print(score)
```

```output
15
```

---

## 5. Rules for Naming Variables

* A name can contain letters, digits and underscores `_`.
* A name must **start** with a letter or an underscore.
* A name cannot start with a digit.
* A name cannot contain spaces or special symbols like `@`, `#`, `-` or `$`.
* A name cannot be a Python keyword such as `if`, `for`, `while` or `class`.
* Names are case-sensitive.

---

## 6. Valid and Invalid Names

**Valid names:**

```python
student_name = "Asha"
age2 = 20
_count = 5
totalMarks = 480
```

**Invalid names:**

```python
2age = 20           # starts with a digit
student-name = "A"  # contains a hyphen
my age = 20         # contains a space
class = "Python"    # keyword
```

Each of these lines gives a `SyntaxError`.

---

## 7. Naming Style (Conventions)

Python programmers use **snake_case** for variable names. All letters are small, and words are joined with an underscore.

```python
first_name = "Asha"
total_marks = 480
number_of_students = 30

print(first_name, total_marks, number_of_students)
```

```output
Asha 480 30
```

Choose meaningful names. `total_marks` is much clearer than `tm` or `x`.

---

## 8. Assigning Multiple Variables

You can assign many variables in one line.

```python
a, b, c = 10, 20, 30

print(a)
print(b)
print(c)
```

```output
10
20
30
```

You can also give the same value to many variables:

```python
x = y = z = 0

print(x, y, z)
```

```output
0 0 0
```

---

## 9. Swapping Two Variables

In many languages you need a third variable to swap two values. Python makes it easy.

```python
a = 5
b = 9

a, b = b, a

print("a =", a)
print("b =", b)
```

```output
a = 9
b = 5
```

---

## 10. Variables Can Hold Any Type

Python is **dynamically typed**. The same variable can hold different types of values at different times. We can check the type using `type()`.

```python
data = 100
print(type(data))

data = "Hello"
print(type(data))
```

```output
<class 'int'>
<class 'str'>
```

---

## 11. Deleting a Variable

The `del` keyword removes a variable.

```python
city = "Hyderabad"
del city

print(city)
```

```output
NameError: name 'city' is not defined
```

---

## 12. What are Constants?

A **constant** is a value that should never change while the program runs, such as the value of PI or the number of days in a week.

Python does **not** have a real constant type. By convention, programmers write the name in **UPPERCASE** letters to tell others "do not change this value".

```python
PI = 3.14159
DAYS_IN_WEEK = 7
MAX_USERS = 100

print(PI)
print(DAYS_IN_WEEK)
```

```output
3.14159
7
```

Python will not stop you from changing a constant, so it is a rule we follow by agreement.

```python
PI = 3.14159
PI = 3        # allowed by Python, but a bad practice

print(PI)
```

```output
3
```

## Real-World Example

A program that calculates the area of a circle using a constant and variables:

```python
PI = 3.14159

radius = 5
area = PI * radius * radius

print("Radius:", radius)
print("Area:", area)
```

```output
Radius: 5
Area: 78.53975
```

## Common Mistakes

### Using a Variable Before Creating It

```python
print(total)    # NameError
total = 100
```

Create the variable first:

```python
total = 100
print(total)
```

### Starting a Name with a Digit

```python
1st_name = "Asha"    # SyntaxError
```

Use:

```python
first_name = "Asha"
```

### Using a Keyword as a Name

```python
if = 10    # SyntaxError
```

### Wrong Case

```python
name = "Asha"
print(Name)    # NameError
```

`name` and `Name` are different. Keep the same spelling and case.

---

## Key Points

* A variable stores a value in memory.
* Use `=` to assign a value to a variable.
* No need to declare the type. Python decides it from the value.
* Names can have letters, digits and `_`, but cannot start with a digit.
* Variable names are case-sensitive.
* Use `snake_case` and meaningful names.
* Constants are written in UPPERCASE by convention.
* Use `type()` to check the type of a variable.

## Section 2.3: Data Types

Common built-in types include int, float, str, and bool. Lists, tuples, sets, and dictionaries store collections; type() inspects a value.

## Real-World Example

A student record holds a name, marks, and enrollment status.

## Example

```python
age = 16
average = 86.5
name = "Asha"
enrolled = True
print(type(age).__name__, type(average).__name__)
print(type(name).__name__, type(enrolled).__name__)
```

```output
int float
str bool
```

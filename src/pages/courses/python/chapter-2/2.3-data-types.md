# Chapter 2: Python Basics

## Section 3: Data Types

Every value in Python has a **type**. The type tells Python what kind of data it is and what we can do with it. In this topic you will learn the basic data types.

---

## 1. What is a Data Type?

A **data type** describes the kind of value. For example, `25` is a number, `"Asha"` is text and `True` is a yes/no value.

```python
print(type(25))
print(type("Asha"))
print(type(True))
```

```output
<class 'int'>
<class 'str'>
<class 'bool'>
```

The `type()` function tells us the type of any value.

---

## 2. Main Built-in Data Types

| Category | Type | Example |
|----------|------|---------|
| Whole numbers | `int` | `10`, `-5`, `0` |
| Decimal numbers | `float` | `3.14`, `-0.5` |
| Complex numbers | `complex` | `2 + 3j` |
| Text | `str` | `"Hello"` |
| True / False | `bool` | `True`, `False` |
| Nothing | `NoneType` | `None` |
| Collections | `list`, `tuple`, `set`, `dict` | `[1, 2]`, `(1, 2)` |

---

## 3. Integer (`int`)

An `int` is a whole number without a decimal point. It can be positive, negative or zero.

```python
a = 100
b = -25
c = 0

print(a, b, c)
print(type(a))
```

```output
100 -25 0
<class 'int'>
```

Python integers can be very large. There is no fixed limit.

```python
big = 123456789012345678901234567890
print(big)
```

```output
123456789012345678901234567890
```

---

## 4. Float (`float`)

A `float` is a number with a decimal point.

```python
price = 99.99
temperature = -4.5

print(price)
print(type(temperature))
```

```output
99.99
<class 'float'>
```

Note that `5` is an `int`, but `5.0` is a `float`.

```python
print(type(5))
print(type(5.0))
```

```output
<class 'int'>
<class 'float'>
```

---

## 5. String (`str`)

A `str` is text. It is written inside single, double or triple quotes.

```python
name = "Asha"
city = 'Hyderabad'
message = """This is
a multi-line string"""

print(name)
print(city)
print(message)
```

```output
Asha
Hyderabad
This is
a multi-line string
```

Even digits inside quotes are text, not numbers.

```python
value = "100"
print(type(value))
```

```output
<class 'str'>
```

---

## 6. Boolean (`bool`)

A `bool` has only two values: `True` and `False`. The first letter must be capital.

```python
is_student = True
is_raining = False

print(is_student)
print(type(is_raining))
```

```output
True
<class 'bool'>
```

Comparisons give boolean results:

```python
print(10 > 5)
print(10 == 20)
```

```output
True
False
```

---

## 7. None (`NoneType`)

`None` means "no value". It is used when a variable exists but does not hold any useful data yet.

```python
result = None

print(result)
print(type(result))
```

```output
None
<class 'NoneType'>
```

---

## 8. Complex Numbers (`complex`)

A complex number has a real part and an imaginary part. The imaginary part uses the letter `j`. Beginners rarely need this type, but it is good to know it exists.

```python
z = 2 + 3j

print(z)
print(type(z))
```

```output
(2+3j)
<class 'complex'>
```

---

## 9. Collection Types (A Quick Look)

Python has four main types that hold many values. We will study them in detail in Chapter 4.

```python
fruits = ["apple", "banana", "mango"]   # list
point = (10, 20)                        # tuple
unique = {1, 2, 3}                      # set
student = {"name": "Asha", "age": 20}   # dict

print(type(fruits))
print(type(point))
print(type(unique))
print(type(student))
```

```output
<class 'list'>
<class 'tuple'>
<class 'set'>
<class 'dict'>
```

---

## 10. Checking Types with isinstance()

The `isinstance()` function checks if a value is of a given type. It returns `True` or `False`.

```python
age = 20

print(isinstance(age, int))
print(isinstance(age, str))
```

```output
True
False
```

---

## 11. Dynamic Typing

We do not declare the type of a variable. Python finds the type from the value, and the type can change when we assign a new value.

```python
x = 10
print(type(x))

x = 10.5
print(type(x))

x = "ten"
print(type(x))
```

```output
<class 'int'>
<class 'float'>
<class 'str'>
```

---

## 12. Mutable and Immutable (Simple Idea)

* **Immutable** types cannot be changed after creation: `int`, `float`, `str`, `bool`, `tuple`.
* **Mutable** types can be changed: `list`, `set`, `dict`.

```python
numbers = [1, 2, 3]
numbers[0] = 100

print(numbers)
```

```output
[100, 2, 3]
```

A string cannot be changed like this:

```python
word = "cat"
word[0] = "b"
```

```output
TypeError: 'str' object does not support item assignment
```

## Real-World Example 🌍

A student record that uses many data types together:

```python
name = "Asha"            # str
age = 20                 # int
marks = 87.5             # float
is_passed = True         # bool
backlog = None           # NoneType

print("Name:", name)
print("Age:", age)
print("Marks:", marks)
print("Passed:", is_passed)
print("Backlog:", backlog)
```

```output
Name: Asha
Age: 20
Marks: 87.5
Passed: True
Backlog: None
```

## Common Mistakes

### Writing `true` or `false` in Lowercase

```python
is_ok = true    # NameError
```

Use:

```python
is_ok = True
```

### Thinking Quoted Numbers Are Numbers

```python
a = "10"
b = "20"

print(a + b)
```

```output
1020
```

Because they are strings, Python joins them instead of adding them.

### Forgetting That Division Gives a Float

```python
print(10 / 2)
```

```output
5.0
```

The result is `5.0` (a `float`), not `5`.

---

## Key Points

* Every value has a data type.
* Basic types are `int`, `float`, `str`, `bool`, `complex` and `NoneType`.
* Collection types are `list`, `tuple`, `set` and `dict`.
* `type()` shows the type of a value.
* `isinstance()` checks whether a value has a given type.
* `True` and `False` must start with a capital letter.
* `None` means "no value".
* Python is dynamically typed, so the type comes from the value.

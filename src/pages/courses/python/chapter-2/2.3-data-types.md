# Chapter 2: Python Basics

## Section 2.3: Data Types

A program works with different kinds of information. A student's age is usually a whole number, an average mark may contain a decimal, a name is text, and a registration status may be either true or false. Python represents these kinds of values using **data types**.

A data type helps determine which operations make sense for a value. For example, numbers can be added mathematically, while strings can be joined together. Understanding types helps you choose suitable operations and avoid unexpected results.

---

## 1. Checking a Value's Type

Python provides the built-in \`type()\` function to inspect the type of an object.

\`\`\`python
age = 17
average = 88.5
student_name = "Asha"
is_registered = True

print(type(age))
print(type(average))
print(type(student_name))
print(type(is_registered))
\`\`\`

\`\`\`output
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
\`\`\`

The values have the types \`int\`, \`float\`, \`str\`, and \`bool\). Python's interactive output displays type information in this form. To print just the type name, you can use \`type(age).__name__\`.

## 2. Integer: \`int\`

An integer represents a whole number without a fractional part. Examples include \`0\`, \`17\`, \`-5\`, and \`1200\`.

\`\`\`python
students = 45
absent = 3
present = students - absent

print(present)
print(type(present).__name__)
\`\`\`

\`\`\`output
42
int
\`\`\`

Python integers can represent very large whole numbers, limited in practice by available memory. They are useful for counts, indexes, quantities, and values that should be whole numbers.

A number written as \`17\` is an integer, while \`17.0\` is a floating-point value. They may compare as numerically equal, but they have different types.

## 3. Floating-Point: \`float\`

A float represents a number with a fractional part or a decimal-point notation.

\`\`\`python
item_price = 49.50
quantity = 3
total = item_price * quantity

print(total)
print(type(total).__name__)
\`\`\`

\`\`\`output
148.5
float
\`\`\`

Floats are useful for measurements, averages, and many calculations involving decimal values. However, floating-point numbers are stored using a binary representation, so some decimal fractions cannot be represented exactly.

For example:

\`\`\`python
print(0.1 + 0.2)
\`\`\`

The displayed result is commonly:

\`\`\`output
0.30000000000000004
\`\`\`

This is a normal floating-point precision effect, not necessarily a mistake in your program. For applications that require exact decimal money calculations, the \`decimal\` module may be more suitable than ordinary floats.

## 4. String: \`str\`

A string represents text. Strings can be written with single or double quotation marks.

\`\`\`python
first_name = "Asha"
city = 'Nandyal'
message = "Welcome to Python"

print(first_name)
print(city)
print(message)
\`\`\`

\`\`\`output
Asha
Nandyal
Welcome to Python
\`\`\`

Use quotation marks around text. Without them, Python usually treats the word as a variable name.

Strings can be joined using \`+\` and repeated using \`*\`:

\`\`\`python
first = "Code"
second = "ify"

print(first + second)
print("Hi! " * 3)
\`\`\`

\`\`\`output
Codify
Hi! Hi! Hi!
\`\`\`

The plus operator joins two strings; it does not automatically convert a number into text. For example, \`"Age: " + 17\` raises a \`TypeError\`. Convert the number with \`str(17)\` or use an f-string.

## 5. Boolean: \`bool\`

A Boolean value represents one of two logical states: \`True\` or \`False\`. The first letters are capitalized.

\`\`\`python
attendance = 82
minimum_attendance = 75
eligible = attendance >= minimum_attendance

print(eligible)
print(type(eligible).__name__)
\`\`\`

\`\`\`output
True
bool
\`\`\`

The comparison produces a Boolean value. Booleans are commonly used for conditions, flags, and status checks. Examples include \`is_logged_in\`, \`has_permission\`, and \`is_available\`.

## 6. None: No Value Yet

Python has a special value called \`None\), often used to represent the absence of a value or a result that has not been set.

\`\`\`python
selected_course = None
print(selected_course)
print(type(selected_course).__name__)
\`\`\`

\`\`\`output
None
NoneType
\`\`\`

\`None\` is not the same as zero, an empty string, or \`False\`. Those values each have their own meanings and types. To check whether a value is \`None\`, use \`is None\`:

\`\`\`python
if selected_course is None:
    print("No course selected")
\`\`\`

\`\`\`output
No course selected
\`\`\`

## 7. Collection Types: Store Multiple Values

Python also provides collection types for storing groups of values.

| Type | Example | Main idea |
| --- | --- | --- |
| \`list\` | \`[10, 20, 30]\` | Ordered and changeable collection |
| \`tuple\` | \`(10, 20, 30)\` | Ordered collection that cannot be reassigned item by item |
| \`set\` | \`{10, 20, 30}\` | Collection of unique elements |
| \`dict\` | \`{"name": "Asha", "marks": 90}\` | Stores key-value pairs |

Example:

\`\`\`python
marks = [78, 84, 91]
student = {"name": "Asha", "marks": 84}

print(marks[0])
print(student["name"])
\`\`\`

\`\`\`output
78
Asha
\`\`\`

Lists, tuples, sets, and dictionaries have different rules and uses. You will study them in detail in Chapter 4. For now, remember that the type tells you what kind of data is stored and which operations are available.

## 8. Mutable and Immutable Objects

Some Python objects can be changed after they are created; these are called **mutable**. Lists and dictionaries are examples. Other objects, including integers, floats, strings, and tuples, are generally **immutable**: their contents cannot be changed in place.

\`\`\`python
colors = ["blue", "black"]
colors.append("white")
print(colors)

course = "Python"
course = course + " Basics"
print(course)
\`\`\`

\`\`\`output
['blue', 'black', 'white']
Python Basics
\`\`\`

The list is modified by \`append()\`. With the string, the expression creates a new string value and the name \`course\` is assigned to it. The original string itself was not changed.

This difference becomes important when multiple variables refer to the same mutable object.

## 9. Converting Between Types

Built-in functions can convert compatible values to other types.

\`\`\`python
age_text = "17"
age_number = int(age_text)

price_text = "45.75"
price = float(price_text)

print(age_number + 1)
print(price + 5)
\`\`\`

\`\`\`output
18
50.75
\`\`\`

Conversion only works when the input has a valid form. For example, \`int("seventeen")\` raises a \`ValueError\`. Also, \`int(4.9)\` produces \`4\), because conversion from a float to an integer truncates the fractional part rather than rounding it.

You will practise input and conversion in the next lesson.

## 10. Real-World Example: A Student Record

A student record often combines several data types:

\`\`\`python
student_name = "Asha"
roll_number = 24
average_mark = 86.75
is_present = True
subjects = ["Python", "Maths", "English"]

print("Name:", student_name)
print("Roll number:", roll_number)
print("Average:", average_mark)
print("Present:", is_present)
print("First subject:", subjects[0])
\`\`\`

\`\`\`output
Name: Asha
Roll number: 24
Average: 86.75
Present: True
First subject: Python
\`\`\`

Each value is represented by a suitable type. Choosing appropriate types makes calculations and checks easier to write and understand.

## Common Mistakes

* **Forgetting quotation marks:** \`"Asha"\` is text, while \`Asha\` is interpreted as a name.
* **Mixing strings and numbers:** convert values or use formatted strings before combining them.
* **Treating \`True\` as text:** the Boolean value is \`True\`; the string is \`"True"\`.
* **Assuming floats are always exact:** binary floating-point has precision limits.
* **Confusing \`None\` with zero:** \`None\` represents the absence of a value, not a numeric quantity.
* **Expecting every conversion to succeed:** invalid text may raise \`ValueError\`.
* **Assuming every object can be modified in place:** strings are immutable, while lists are mutable.

---

## Key Points

* Common basic types are \`int\`, \`float\`, \`str\`, and \`bool\`.
* \`type()\` can inspect an object's type.
* \`None\` represents the absence of a value.
* Lists, tuples, sets, and dictionaries store collections.
* Strings must be placed inside quotation marks.
* Type conversion can fail if the input is not compatible.
* Mutable and immutable objects behave differently.
* Select a data type that matches the meaning of the information.

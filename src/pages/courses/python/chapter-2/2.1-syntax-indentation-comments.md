# Chapter 2: Python Basics

## Section 2.1: Python Syntax, Indentation & Comments

Python syntax defines valid code. Indentation groups block statements, a colon starts a block, and # begins a single-line comment.

## Real-World Example

A clearly indented grade checker is easier to maintain.

## Example

```python
score = 82
if score >= 40:
    print("Pass")  # passed
else:
    print("Try again")
```

```output
Pass
```

## How It Works

Python syntax defines valid code. Indentation groups block statements, a colon starts a block, and # begins a single-line comment. Read the code line by line, predict the result, and then run it to confirm your understanding. Change one value at a time to see how the behavior changes.

## Common Mistakes

* Confusing the purpose of the concept with the exact syntax used in the example.
* Assuming one successful run proves the program works for every input.
* Ignoring invalid input, boundary values, or readability when they matter.

## Key Points

* Python syntax defines valid code.
* Indentation groups block statements, a colon starts a block, and # begins a single-line comment.
* Test the result with different inputs.
* Use meaningful names and test examples before relying on a program.

# Chapter 2: Python Basics

## Section 1: Python Syntax, Indentation & Comments

Every language has rules. In this topic you will learn the basic rules of Python: how to write statements, why indentation matters, and how to add comments to your code.

---

## 1. What is Syntax?

**Syntax** is the set of rules that tells us how to write a program correctly. If we break the rules, Python shows an error and stops.

```python
print("Python is easy")
```

```output
Python is easy
```

Python syntax is simple and close to normal English. That is why it is a good first language.

---

## 2. Python Statements

A **statement** is one instruction that Python can run. Usually, we write one statement on one line.

```python
print("Statement 1")
print("Statement 2")
```

```output
Statement 1
Statement 2
```

There is no need to end a line with a semicolon `;`.

---

## 3. Python is Case-Sensitive

Uppercase and lowercase letters are different in Python.

```python
name = "Asha"
Name = "Ravi"

print(name)
print(Name)
```

```output
Asha
Ravi
```

Here `name` and `Name` are two different variables.

---

## 4. What is Indentation?

**Indentation** means the empty space at the start of a line. Many languages use curly braces `{ }` to make a block of code. Python uses indentation instead.

```python
age = 20

if age >= 18:
    print("You are an adult")
    print("You can vote")
```

```output
You are an adult
You can vote
```

Both `print()` lines belong to the `if` block because they have the same indentation.

---

## 5. Indentation Rules

* Use **4 spaces** for each level. This is the standard style.
* All lines in the same block must have the same indentation.
* Do not mix tabs and spaces in one file.
* A line that ends with a colon `:` expects an indented block below it.

```python
age = 15

if age >= 18:
    print("Adult")
else:
    print("Minor")
```

```output
Minor
```

---

## 6. Indentation Errors

If you forget to indent, Python shows an `IndentationError`.

```python
age = 18
if age >= 18:
print("Adult")
```

```output
IndentationError: expected an indented block after 'if' statement on line 2
```

If you add extra spaces where they are not needed, you also get an error:

```python
print("Hello")
    print("World")
```

```output
IndentationError: unexpected indent
```

---

## 7. Multiple Statements on One Line

You can write more than one statement on a line by using a semicolon. This is allowed, but it is not a good habit.

```python
a = 5; b = 10; print(a + b)
```

```output
15
```

It is better to write each statement on its own line.

---

## 8. Long Statements (Line Continuation)

Sometimes a statement is too long for one line. There are two ways to continue it.

**Using a backslash `\`:**

```python
total = 10 + 20 + 30 + \
        40 + 50

print(total)
```

```output
150
```

**Using brackets `( )`, which is the cleaner way:**

```python
total = (10 + 20 + 30 +
         40 + 50)

print(total)
```

```output
150
```

---

## 9. Single-Line Comments

A **comment** is a note written for humans. Python ignores it completely. A comment starts with `#`.

```python
# This program prints a welcome message
print("Welcome")
```

```output
Welcome
```

---

## 10. Inline Comments

A comment can also come at the end of a code line.

```python
price = 250    # price of one book
qty = 3        # number of books

print(price * qty)
```

```output
750
```

Leave at least two spaces before the `#` so the code is easy to read.

---

## 11. Multi-Line Comments

Python has no special multi-line comment symbol. The simple way is to put `#` at the start of each line.

```python
# This program calculates
# the total price of items
# including tax

print("Done")
```

```output
Done
```

Some programmers also use triple quotes `""" """` for long notes. Technically this is a string, not a comment, but Python does nothing with it when it is not stored in a variable.

```python
"""
This is a long note.
It can have many lines.
"""

print("Hello")
```

```output
Hello
```

---

## 12. Why Write Comments?

* They explain **why** the code does something.
* They help other people understand your program.
* They help you when you come back to your code after many days.
* You can use `#` to temporarily switch off a line while testing.

```python
print("Line 1")
# print("Line 2")
print("Line 3")
```

```output
Line 1
Line 3
```

> Good comments explain the reason, not the obvious. `# add 1 to count` is not helpful for `count = count + 1`.

---

## Real-World Example

A small program that calculates the final bill of a shop, with proper indentation and comments:

```python
# Shop bill calculator

price = 1200        # price of the item
discount = 200      # discount in rupees

if price > 1000:
    # discount applies only above 1000
    final_price = price - discount
else:
    final_price = price

print("Final price:", final_price)
```

```output
Final price: 1000
```

## Common Mistakes

### Forgetting the Colon

```python
if 5 > 3
    print("Yes")    # SyntaxError
```

Use:

```python
if 5 > 3:
    print("Yes")
```

### Mixing Tabs and Spaces

Python may show a `TabError`. Choose spaces and use 4 spaces everywhere.

### Wrong Indentation Inside a Block

```python
if True:
    print("A")
  print("B")    # IndentationError
```

All lines in a block must line up exactly.

### Using `//` for Comments

```python
// This is a comment    # SyntaxError
```

Use:

```python
# This is a comment
```

---

## Key Points

* Syntax is the set of rules for writing Python code.
* Usually one statement is written on one line.
* Python is case-sensitive.
* Python uses indentation to make blocks of code.
* Use 4 spaces for each indentation level.
* A line ending with `:` needs an indented block below it.
* `#` starts a comment, and Python ignores comments.
* Use brackets or `\` to continue a long statement on the next line.

## Section 2.5: Operators & Expressions

Arithmetic operators include +, -, *, /, //, %, and **. Comparisons return booleans; and, or, and not combine conditions.

## Real-World Example

An online store checks whether a cart qualifies for free delivery.

## Example

```python
total = 650
free_delivery = total >= 500
print(free_delivery)
print(total if free_delivery else total + 40)
```

```output
True
650
```

# Chapter 2: Python Basics

## Section 2.5: Operators & Expressions

An **operator** is a symbol or keyword that performs an operation on one or more values. An **expression** combines values, names, and operators to produce a result.

For example, in \`total = price * quantity\`, the \`*\` operator multiplies the values of \`price\` and \`quantity\`. The expression on the right is evaluated, and its result is assigned to \`total\`.

Operators are used in calculations, comparisons, decision-making, text processing, and many everyday programs. This lesson covers the main operator groups and how Python evaluates expressions.

---

## 1. Arithmetic Operators

Arithmetic operators perform mathematical calculations.

| Operator | Meaning | Example | Result |
| --- | --- | --- | --- |
| \`+\` | Addition | \`8 + 3\` | \`11\` |
| \`-\` | Subtraction | \`8 - 3\` | \`5\` |
| \`*\` | Multiplication | \`8 * 3\` | \`24\` |
| \`/\` | Division | \`8 / 3\` | \`2.666...\` |
| \`//\` | Floor division | \`8 // 3\` | \`2\` |
| \`%\` | Remainder (modulo) | \`8 % 3\` | \`2\` |
| \`**\` | Exponentiation | \`2 ** 3\` | \`8\` |

Example:

\`\`\`python
a = 17
b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(2 ** 3)
\`\`\`

\`\`\`output
22
12
85
3.4
3
2
8
\`\`\`

Division with \`/\` produces a floating-point result. Floor division with \`//\` rounds the quotient down toward negative infinity. For positive values this looks like dropping the fractional part, but negative values show the difference: \`-7 // 2\` is \`-4\`, while \`int(-7 / 2)\` is \`-3\`.

The modulo operator gives the remainder according to Python's division rules. It is often used to test whether a number is divisible by another number.

\`\`\`python
number = 24
print(number % 2 == 0)
print(number % 5)
\`\`\`

\`\`\`output
True
4
\`\`\`

## 2. Comparison Operators

Comparison operators compare values and return a Boolean: \`True\` or \`False\`.

| Operator | Meaning | Example |
| --- | --- | --- |
| \`==\` | Equal to | \`5 == 5\` gives \`True\` |
| \`!=\` | Not equal to | \`5 != 3\` gives \`True\` |
| \`>\` | Greater than | \`8 > 3\` gives \`True\` |
| \`<\` | Less than | \`2 < 7\` gives \`True\` |
| \`>=\` | Greater than or equal to | \`75 >= 75\` gives \`True\` |
| \`<=\` | Less than or equal to | \`4 <= 9\` gives \`True\` |

\`\`\`python
marks = 82

print(marks >= 40)
print(marks == 100)
print(marks < 0)
\`\`\`

\`\`\`output
True
False
False
\`\`\`

Do not confuse assignment (\`=\`) with comparison (\`==\`). Assignment stores a value in a name; comparison checks whether two values are equal.

## 3. Logical Operators

Logical operators combine or reverse Boolean conditions.

* \`and\` is true only when both conditions are true.
* \`or\` is true when at least one condition is true.
* \`not\` reverses a Boolean result.

\`\`\`python
age = 19
has_id = True

print(age >= 18 and has_id)
print(age >= 18 or has_id)
print(not has_id)
\`\`\`

\`\`\`output
True
True
False
\`\`\`

Logical operators are useful when a decision depends on multiple rules. For example, a website may allow access only if a user is logged in and has permission.

Python's \`and\` and \`or\` operators use **short-circuit evaluation**. For \`A and B\`, Python does not need to evaluate \`B\` if \`A\` is already false. For \`A or B\`, Python does not need to evaluate \`B\` if \`A\` is already true. In many beginner conditions, the most important point is that the final decision follows the truth of the combined conditions.

## 4. Assignment and Augmented Assignment Operators

The assignment operator \`=\` assigns a value to a name. Augmented assignment combines an operation with assignment.

\`\`\`python
balance = 500
balance -= 120
balance += 50
balance *= 2

print(balance)
\`\`\`

\`\`\`output
860
\`\`\`

The balance becomes 380 after subtraction, 430 after addition, and 860 after multiplication.

Common augmented assignments include \`+=\`, \`-=\`, \`*=\`, \`/=\`, \`//=\`, \`%=\`, and \`**=\`. They are often useful for updating totals and counters in loops.

## 5. Membership Operators

The \`in\` and \`not in\` operators check whether a value is present in a collection or sequence.

\`\`\`python
course = "Python Programming"
subjects = ["Python", "Maths", "English"]

print("Python" in course)
print("Science" in subjects)
print("Java" not in subjects)
\`\`\`

\`\`\`output
True
False
True
\`\`\`

For strings, membership checks whether a substring is present. For lists and other collections, it checks whether an item is a member. In a dictionary, \`in\` checks keys by default, not values.

Membership checks are useful for validating choices, checking allowed commands, and determining whether an item has already been entered.

## 6. Identity Operators

The identity operators are \`is\` and \`is not\`. They check whether two names refer to the same object, not simply whether their values compare equal.

\`\`\`python
first = [1, 2, 3]
second = [1, 2, 3]
third = first

print(first == second)
print(first is second)
print(first is third)
\`\`\`

\`\`\`output
True
False
True
\`\`\`

The two lists \`first\` and \`second\` contain equal values, so \`==\` returns \`True\`. They are separate list objects, so \`is\` returns \`False\). The name \`third\` refers to the same list as \`first\`, so \`first is third\` returns \`True\`.

For normal value comparisons, use \`==\`. Use identity checks for cases where object identity matters, especially checking for \`None\`:

\`\`\`python
result = None
print(result is None)
\`\`\`

\`\`\`output
True
\`\`\`

## 7. Bitwise Operators: A Brief Introduction

Bitwise operators work on the binary bits of integers. They are used in some low-level programming, permissions, flags, and performance-sensitive tasks. Beginners do not need them for most everyday calculations, but it is useful to recognize the symbols.

| Operator | Meaning |
| --- | --- |
| \`&\` | Bitwise AND |
| \`|\` | Bitwise OR |
| \`^\` | Bitwise XOR |
| \`~\` | Bitwise NOT |
| \`<<\` | Left shift |
| \`>>\` | Right shift |

For example, \`5 & 3\` returns \`1\` because the binary representations of 5 and 3 share only the lowest set bit. You can study binary representation before using these operators in more complex code.

Do not confuse bitwise \`&\` and \`|\` with logical \`and\` and \`or\`. They serve different purposes.

## 8. Operator Precedence

When an expression contains several operators, Python follows precedence rules to determine the order of evaluation. Parentheses can make the intended order explicit.

\`\`\`python
answer = 2 + 3 * 4
print(answer)

answer_with_parentheses = (2 + 3) * 4
print(answer_with_parentheses)
\`\`\`

\`\`\`output
14
20
\`\`\`

Multiplication is evaluated before addition in the first expression. Parentheses make the addition happen first in the second expression.

A useful simplified order for common beginner expressions is:

1. Parentheses
2. Exponentiation
3. Multiplication, division, floor division, and modulo
4. Addition and subtraction
5. Comparisons
6. \`not\`
7. \`and\`
8. \`or\`

This is a simplified learning guide, not the complete precedence table. Some operators in the same group associate differently, and exponentiation has special behavior with unary operators. When an expression looks complicated, use parentheses instead of relying on memory.

## 9. Expressions and Mixed Types

The result of an expression depends on the operators and the types involved.

\`\`\`python
quantity = 4
price = 25.5
subtotal = quantity * price

print(subtotal)
print(type(subtotal).__name__)
\`\`\`

\`\`\`output
102.0
float
\`\`\`

Python allows many useful operations between compatible types, but not every combination is valid. For example, adding a string directly to an integer raises a \`TypeError\`. Convert the value or use an f-string when you want to display mixed information.

## 10. Real-World Example: Free Delivery Rule

An online shop offers free delivery when the cart total is at least Rs. 500 and the customer has selected an eligible delivery location.

\`\`\`python
cart_total = 650
eligible_location = True
delivery_charge = 40

free_delivery = cart_total >= 500 and eligible_location

if free_delivery:
    final_total = cart_total
else:
    final_total = cart_total + delivery_charge

print("Free delivery:", free_delivery)
print("Final total:", final_total)
\`\`\`

\`\`\`output
Free delivery: True
Final total: 650
\`\`\`

The comparison \`cart_total >= 500\` produces a Boolean. The \`and\` operator combines that condition with the location flag. The result determines whether the delivery charge is added.

This example shows how arithmetic, comparisons, logical operators, and variables work together in a small practical rule.

## Common Mistakes

* **Confusing \`=\` with \`==\`:** one assigns; the other compares.
* **Confusing \`/\` and \`//\`:** ordinary division returns a float; floor division rounds down.
* **Assuming modulo always means a positive remainder:** negative operands follow Python's division rules.
* **Using \`is\` for value equality:** use \`==\` for ordinary value comparisons.
* **Mixing strings and numbers without conversion:** Python does not automatically concatenate an integer with a string.
* **Forgetting precedence:** use parentheses to make complex expressions clear.
* **Confusing logical and bitwise operators:** \`and\` and \`or\` are not the same as \`&\` and \`|\`.

---

## Key Points

* Operators perform calculations, comparisons, membership checks, and other operations.
* Arithmetic operators include \`+\`, \`-\`, \`*\`, \`/\`, \`//\`, \`%\`, and \`**\`.
* Comparison expressions return Boolean results.
* \`and\`, \`or\`, and \`not\` combine or reverse logical conditions.
* \`in\` and \`not in\` check membership.
* \`is\` and \`is not\` check object identity.
* Parentheses help control evaluation order and improve readability.
* Use the operator that matches the intention of the program.

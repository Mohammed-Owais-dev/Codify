# Chapter 2: Python Basics

## Section 5: Operators & Expressions

Operators are symbols that perform actions on values, such as adding two numbers or comparing them. In this topic you will learn the main operators in Python and how expressions are calculated.

---

## 1. What is an Operator?

An **operator** is a symbol that performs an operation. The values it works on are called **operands**.

```python
print(10 + 5)
```

```output
15
```

Here `+` is the operator, and `10` and `5` are the operands.

---

## 2. What is an Expression?

An **expression** is a combination of values, variables and operators that Python can calculate to produce a result.

```python
a = 10
b = 3

result = a * b + 2
print(result)
```

```output
32
```

`a * b + 2` is an expression. Its result is `32`.

---

## 3. Types of Operators

Python has these groups of operators:

* Arithmetic operators
* Assignment operators
* Comparison operators
* Logical operators
* Membership operators
* Identity operators
* Bitwise operators

---

## 4. Arithmetic Operators

These are used for mathematical calculations.

| Operator | Name | Example | Result |
|----------|------|---------|--------|
| `+` | Addition | `7 + 2` | `9` |
| `-` | Subtraction | `7 - 2` | `5` |
| `*` | Multiplication | `7 * 2` | `14` |
| `/` | Division | `7 / 2` | `3.5` |
| `//` | Floor division | `7 // 2` | `3` |
| `%` | Modulus (remainder) | `7 % 2` | `1` |
| `**` | Power | `7 ** 2` | `49` |

```python
a = 7
b = 2

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
```

```output
9
5
14
3.5
3
1
49
```

---

## 5. Division, Floor Division and Modulus

* `/` always gives a **float**, even when the numbers divide exactly.
* `//` gives only the whole-number part of the answer (rounded **down**).
* `%` gives the **remainder**.

```python
print(10 / 2)
print(10 // 3)
print(10 % 3)
print(-7 // 2)
```

```output
5.0
3
1
-4
```

Note that `-7 // 2` is `-4`, because floor division rounds down to the smaller number.

A common use of `%` is to check if a number is even or odd:

```python
number = 8

print(number % 2)
```

```output
0
```

If the remainder is `0`, the number is even.

---

## 6. Assignment Operators

These store a value in a variable. Short forms like `+=` update the variable using its old value.

| Operator | Example | Same as |
|----------|---------|---------|
| `=` | `x = 5` | Assign 5 to x |
| `+=` | `x += 3` | `x = x + 3` |
| `-=` | `x -= 3` | `x = x - 3` |
| `*=` | `x *= 3` | `x = x * 3` |
| `/=` | `x /= 3` | `x = x / 3` |
| `//=` | `x //= 3` | `x = x // 3` |
| `%=` | `x %= 3` | `x = x % 3` |
| `**=` | `x **= 3` | `x = x ** 3` |

```python
x = 10

x += 5
print(x)

x -= 3
print(x)

x *= 2
print(x)
```

```output
15
12
24
```

> Python does not have `++` or `--`. Use `x += 1` and `x -= 1` instead.

---

## 7. Comparison Operators

These compare two values and give `True` or `False`.

| Operator | Meaning | Example | Result |
|----------|---------|---------|--------|
| `==` | Equal to | `5 == 5` | `True` |
| `!=` | Not equal to | `5 != 3` | `True` |
| `>` | Greater than | `5 > 8` | `False` |
| `<` | Less than | `5 < 8` | `True` |
| `>=` | Greater than or equal | `5 >= 5` | `True` |
| `<=` | Less than or equal | `5 <= 3` | `False` |

```python
a = 10
b = 20

print(a == b)
print(a != b)
print(a > b)
print(a < b)
```

```output
False
True
False
True
```

Remember: `=` assigns a value, but `==` compares two values.

---

## 8. Logical Operators

These combine conditions. Python uses the words `and`, `or` and `not`.

| Operator | Meaning |
|----------|---------|
| `and` | `True` only if **both** conditions are true |
| `or` | `True` if **at least one** condition is true |
| `not` | Reverses the result |

```python
age = 22
has_id = True

print(age >= 18 and has_id)
print(age < 18 or has_id)
print(not has_id)
```

```output
True
True
False
```

---

## 9. Membership Operators

These check if a value is present inside a sequence such as a string or list.

| Operator | Meaning |
|----------|---------|
| `in` | `True` if the value is found |
| `not in` | `True` if the value is not found |

```python
fruits = ["apple", "banana", "mango"]

print("apple" in fruits)
print("grape" in fruits)
print("grape" not in fruits)
print("a" in "Python")
```

```output
True
False
True
False
```

---

## 10. Identity Operators

These check if two names refer to the **same object** in memory.

| Operator | Meaning |
|----------|---------|
| `is` | `True` if both are the same object |
| `is not` | `True` if they are not the same object |

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)
print(a is b)
print(a is c)
```

```output
True
False
True
```

`a == b` is `True` because the values are equal. `a is b` is `False` because they are two different lists in memory.

## 11. Bitwise Operators (A Quick Look)

Bitwise operators work on the binary form of numbers. Beginners use them rarely, but you may see them in interviews.

| Operator | Name |
|----------|------|
| `&` | AND |
| `\|` | OR |
| `^` | XOR |
| `~` | NOT |
| `<<` | Left shift |
| `>>` | Right shift |

```python
a = 5      # binary 101
b = 3      # binary 011

print(a & b)
print(a | b)
print(a ^ b)
print(a << 1)
print(a >> 1)
```

```output
1
7
6
10
2
```

## 12. Operator Precedence

When an expression has many operators, Python follows an order called **precedence**. Higher rows are done first.

| Priority | Operators |
|----------|-----------|
| 1 (highest) | `( )` Brackets |
| 2 | `**` |
| 3 | `*`, `/`, `//`, `%` |
| 4 | `+`, `-` |
| 5 | Comparison: `==`, `!=`, `>`, `<`, `>=`, `<=` |
| 6 | `not` |
| 7 | `and` |
| 8 (lowest) | `or` |

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 ** 3 ** 2)
```

```output
14
20
512
```

`3 * 4` is done before `+`. Brackets change the order. The `**` operator works from right to left, so `2 ** 3 ** 2` is `2 ** 9`.

When you are not sure, use brackets. They also make the code easier to read.

## 13. Operators on Strings

Some operators also work with text.

```python
first = "Hello"
second = "World"

print(first + " " + second)
print("Ha" * 3)
```

```output
Hello World
HaHaHa
```

* `+` joins two strings (concatenation).
* `*` repeats a string.

## Real-World Example 🌍

A program that calculates the total bill with tax and checks if the customer gets free delivery:

```python
price = 450
quantity = 3
tax_rate = 0.05

subtotal = price * quantity
tax = subtotal * tax_rate
total = subtotal + tax

free_delivery = total >= 1000

print("Subtotal:", subtotal)
print("Tax:", tax)
print("Total:", total)
print("Free delivery:", free_delivery)
```

```output
Subtotal: 1350
Tax: 67.5
Total: 1417.5
Free delivery: True
```

## Common Mistakes

### Using `=` Instead of `==`

```python
if x = 5:    # SyntaxError
    print("Five")
```

Use `==` to compare:

```python
if x == 5:
    print("Five")
```

### Using `++` Like in C or Java

```python
count = 0
count++    # SyntaxError
```

Use:

```python
count += 1
```

### Using `&&` and `||`

```python
print(True && False)    # SyntaxError
```

Python uses words:

```python
print(True and False)
```

### Forgetting That `/` Gives a Float

```python
print(8 / 2)
```

```output
4.0
```

Use `//` if you need a whole number.

---

## Key Points

* An operator performs an action on operands.
* An expression is a combination of values, variables and operators.
* Arithmetic operators: `+`, `-`, `*`, `/`, `//`, `%`, `**`.
* `/` gives a float, `//` gives the floor value, `%` gives the remainder.
* Use `+=`, `-=` and similar for short updates. There is no `++` or `--`.
* Comparison operators return `True` or `False`.
* Logical operators are `and`, `or` and `not`.
* `in` checks membership, and `is` checks identity.
* Use brackets to control the order of calculation.

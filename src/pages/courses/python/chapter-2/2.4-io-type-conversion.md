# Chapter 2: Python Basics

## Section 2: Input, Output & Type Conversion

Most programs need to communicate with people. They display instructions, receive information, process it, and show a result. Python provides simple built-in functions for this: \`print()\` displays output, while \`input()\` reads text entered by a user.

The value received from \`input()\` is a string, even if the person types digits. When you want to perform calculations, you often need to convert that text into an integer or a floating-point number.

---

## 1. Displaying Output with \`print()\`

The \`print()\` function displays values in the output area.

\`\`\`python
print("Welcome to Codify")
print(100)
print(12 + 8)
\`\`\`

\`\`\`output
Welcome to Codify
100
20
\`\`\`

Python evaluates an expression before displaying its result. That is why \`print(12 + 8)\` displays \`20\), not the text \`12 + 8\`.

### Printing multiple values

You can pass multiple values to \`print()\), separated by commas:

\`\`\`python
name = "Asha"
marks = 92

print("Student:", name, "Marks:", marks)
\`\`\`

\`\`\`output
Student: Asha Marks: 92
\`\`\`

By default, \`print()\` places a space between separate values and ends with a newline. The \`sep\` argument changes the separator, and \`end\` changes what is printed at the end.

\`\`\`python
print("2026", "10", "17", sep="-")
print("Loading", end="...")
print("Done")
\`\`\`

\`\`\`output
2026-10-17
Loading...Done
\`\`\`

Use these options when they make the output clearer. Most beginner programs can use the default behavior.

## 2. Receiving Input with \`input()\`

The \`input()\` function displays an optional prompt and waits for the user to enter text. The program continues when the user submits the input.

\`\`\`python
name = input("Enter your name: ")
print("Hello,", name)
\`\`\`

If the user types \`Asha\`, the output is:

\`\`\`output
Enter your name: Asha
Hello, Asha
\`\`\`

The prompt is displayed by \`input()\`; the entered text is supplied by the user. In an online lesson or automated test, the exact interaction may be represented differently, but the program logic is the same.

## 3. Why Input Is a String

Even if the user types digits, \`input()\` returns text.

\`\`\`python
age = input("Enter your age: ")
print(type(age).__name__)
\`\`\`

If the user enters \`17\`, the program displays:

\`\`\`output
str
\`\`\`

That result matters because \`"17"\` is not the same type as \`17\). For example, \`"17" + "3"\` joins text and produces \`"173"\`, while \`17 + 3\` performs arithmetic and produces \`20\`.

## 4. Converting Text to Numbers

Use \`int()\` when you need a whole number, and \`float()\` when you need a number that may contain a fractional part.

\`\`\`python
age = int(input("Enter your age: "))
height = float(input("Enter your height in metres: "))

print("Age next year:", age + 1)
print("Height:", height)
\`\`\`

For inputs \`17\` and \`1.65\`, the calculated output is:

\`\`\`output
Age next year: 18
Height: 1.65
\`\`\`

The conversion functions turn valid numeric text into numeric values. If the user enters text such as \`seventeen\` where an integer is expected, \`int()\` raises a \`ValueError\`. Real applications should validate input and handle errors rather than assuming everyone enters valid data.

## 5. Other Common Type Conversions

Python provides several built-in conversion functions.

| Function | Purpose | Example |
| --- | --- | --- |
| \`int(value)\` | Convert a compatible value to an integer | \`int("25")\` gives \`25\` |
| \`float(value)\` | Convert a compatible value to a float | \`float("4.5")\` gives \`4.5\` |
| \`str(value)\` | Produce a string representation | \`str(25)\` gives \`"25"\` |
| \`bool(value)\` | Convert a value to a Boolean | \`bool(0)\` gives \`False\` |

Examples:

\`\`\`python
number = int("25")
price = float("49.50")
label = str(number)

print(number + 5)
print(price + 0.5)
print("Number: " + label)
\`\`\`

\`\`\`output
30
50.0
Number: 25
\`\`\`

Be careful with \`bool()\`: many values are considered true, while values such as \`0\`, \`0.0\`, \`""\`, \`[]\`, and \`None\` are false. It does not interpret arbitrary text as a human might. For example, \`bool("False")\` is \`True\` because the string is not empty.

## 6. Converting a Float to an Integer

Converting a float with \`int()\` removes the fractional part; it does not round to the nearest integer.

\`\`\`python
print(int(7.9))
print(int(7.1))
print(int(-7.9))
\`\`\`

\`\`\`output
7
7
-7
\`\`\`

For negative numbers, truncation moves toward zero. If your program needs rounding, use \`round()\` and understand its rounding behavior rather than assuming \`int()\` will round.

## 7. Formatted Output with F-Strings

An **f-string** lets you place variable values or expressions inside a string. Write the letter \`f\` before the opening quotation mark and put expressions inside curly braces.

\`\`\`python
name = "Asha"
marks = 91
print(f"{name} scored {marks} marks.")
print(f"After bonus: {marks + 2}")
\`\`\`

\`\`\`output
Asha scored 91 marks.
After bonus: 93
\`\`\`

F-strings are useful when output needs to read naturally. They also support formatting numbers:

\`\`\`python
price = 49.5
print(f"Price: Rs. {price:.2f}")
\`\`\`

\`\`\`output
Price: Rs. 49.50
\`\`\`

The format specifier \`:.2f\` displays a number with two digits after the decimal point. It changes how the number is displayed; it does not change the original variable into a string or permanently round the stored value.

## 8. Real-World Example: Canteen Bill Calculator

A canteen needs the quantity and price of an item to calculate the bill. The input is converted before multiplication.

\`\`\`python
quantity = int(input("Enter quantity: "))
price = float(input("Enter price per item: "))

total = quantity * price

print(f"Total bill: Rs. {total:.2f}")
\`\`\`

For quantity \`3\` and price \`25.5\`, the output is:

\`\`\`output
Enter quantity: 3
Enter price per item: 25.5
Total bill: Rs. 76.50
\`\`\`

The quantity is converted to an integer and the price to a float. The multiplication produces the total, and the f-string formats the displayed amount to two decimal places. A production billing system may use \`decimal.Decimal\` for exact decimal calculations.

## 9. Basic Input Validation

Input should not be trusted to always match the expected format. A beginner-friendly way to handle invalid numeric text is to use \`try\` and \`except\`. You will learn exception handling in more detail later.

\`\`\`python
text = input("Enter a whole number: ")

try:
    number = int(text)
    print("Double:", number * 2)
except ValueError:
    print("Please enter a valid whole number.")
\`\`\`

If the user enters \`12\`, the program displays \`Double: 24\`. If the user enters \`hello\`, the conversion fails and the error-handling block displays a helpful message instead of stopping with an unhandled exception.

Validation should match the task. For example, a quantity may need to be a positive integer, while a temperature may allow negative decimal values.

## ⚠️ Common Mistakes

### 1. Forgetting that \`input()\` returns a string

convert the value before numeric calculations.

### 2. Joining numbers and strings directly

use \`str()\`, commas in \`print()\`, or an f-string.

### 3. Using \`int()\` when decimals matter

\`int(4.8)\` produces \`4\`, not \`5\`.

### 4. Assuming \`bool("False")\` is false

any non-empty string is truthy.

### 5. Ignoring invalid input

text that cannot be converted may raise \`ValueError\`.

### 6. Confusing display formatting with stored data

\`:.2f\` affects how a number is shown.

### 7. Using unclear prompts

tell the user what kind of value is expected.

---

## 🔑 Key Points

* \`print()\` displays values and supports options such as \`sep\` and \`end\`.
* \`input()\` reads text and returns a string.
* Convert valid input with \`int()\` or \`float()\` before arithmetic.
* \`str()\` creates a string representation of a value.
* \`int()\` truncates a float's fractional part instead of rounding it.
* F-strings make formatted output readable.
* Validate input and handle conversion errors when needed.
* Display formatting does not necessarily change the stored value.

# Chapter 2: Python Basics

## Section 4: Input, Output & Type Conversion

Programs become useful when they talk to the user. They take input, process it and show output. In this topic you will learn how to read input, format output and change one data type into another.

---

## 1. Output with print()

We already use `print()` to show output. It can print text, numbers and variables.

```python
name = "Asha"
age = 20

print("Name:", name)
print("Age:", age)
```

```output
Name: Asha
Age: 20
```

---

## 2. The `sep` Parameter

By default, `print()` puts a space between values. The `sep` parameter changes this separator.

```python
print("2026", "10", "18", sep="-")
print("A", "B", "C", sep="")
```

```output
2026-10-18
ABC
```

---

## 3. The `end` Parameter

By default, `print()` moves to a new line at the end. The `end` parameter changes this.

```python
print("Hello", end=" ")
print("World")
```

```output
Hello World
```

```python
print("Loading", end="...")
print("Done")
```

```output
Loading...Done
```

---

## 4. Escape Characters

An **escape character** starts with a backslash `\` and gives a special meaning.

| Escape | Meaning |
|--------|---------|
| `\n` | New line |
| `\t` | Tab space |
| `\\` | A backslash |
| `\"` | A double quote |
| `\'` | A single quote |

```python
print("Hello\nWorld")
print("Name:\tAsha")
print("She said \"Hi\"")
```

```output
Hello
World
Name:	Asha
She said "Hi"
```

---

## 5. Formatted Output with f-strings

An **f-string** lets you put variables directly inside text. Write `f` before the quotes and put variables inside `{ }`.

```python
name = "Asha"
age = 20

print(f"{name} is {age} years old.")
```

```output
Asha is 20 years old.
```

You can also do calculations inside the braces:

```python
price = 250
qty = 3

print(f"Total = {price * qty}")
```

```output
Total = 750
```

---

## 6. Formatting Decimal Numbers

Use `:.2f` inside the braces to show 2 digits after the decimal point.

```python
pi = 3.14159265

print(f"PI = {pi:.2f}")
print(f"PI = {pi:.4f}")
```

```output
PI = 3.14
PI = 3.1416
```

---

## 7. Taking Input with input()

The `input()` function reads what the user types. You can give it a message (called a **prompt**).

```python
name = input("Enter your name: ")

print("Hello,", name)
```

If the user enters:

```text
Ravi
```

The output will be:

```output
Enter your name: Ravi
Hello, Ravi
```

---

## 8. Input is Always a String

This is very important. `input()` always returns **text**, even if the user types a number.

```python
age = input("Enter your age: ")

print(age)
print(type(age))
```

If the user enters:

```text
20
```

The output will be:

```output
Enter your age: 20
20
<class 'str'>
```

So we cannot do maths with it directly. We must first **convert** it.

---

## 9. What is Type Conversion?

**Type conversion** (also called **type casting**) means changing a value from one type to another. Python gives us these functions:

| Function | Converts to |
|----------|-------------|
| `int()` | Integer |
| `float()` | Decimal number |
| `str()` | Text |
| `bool()` | True / False |

---

## 10. Converting to int and float

```python
a = int("25")
b = float("2.5")

print(a + 5)
print(b + 1)
```

```output
30
3.5
```

When `float` is converted to `int`, the decimal part is **cut off**, not rounded.

```python
print(int(3.9))
print(int(-3.9))
```

```output
3
-3
```

---

## 11. Converting to str

```python
age = 20
message = "I am " + str(age) + " years old"

print(message)
```

```output
I am 20 years old
```

We cannot join a string and a number with `+` directly. We must convert the number with `str()` first, or use an f-string.

---

## 12. Converting to bool

`bool()` gives `False` for "empty" values and `True` for everything else.

```python
print(bool(0))
print(bool(5))
print(bool(""))
print(bool("Hello"))
```

```output
False
True
False
True
```

Values that give `False`: `0`, `0.0`, `""` (empty string), `None` and empty collections.

---

## 13. Reading Numbers from the User

We combine `input()` with `int()` or `float()`.

```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

print("Sum =", a + b)
```

If the user enters `10` and `20`:

```output
Enter first number: 10
Enter second number: 20
Sum = 30
```

---

## 14. Reading Many Values in One Line

Use `split()` to separate values typed on one line.

```python
a, b = input("Enter two numbers: ").split()

print(int(a) + int(b))
```

If the user enters:

```text
10 20
```

The output will be:

```output
Enter two numbers: 10 20
30
```

---

## 15. Conversion Errors

If the text cannot be converted, Python shows a `ValueError`.

```python
number = int("abc")
```

```output
ValueError: invalid literal for int() with base 10: 'abc'
```

A decimal string also cannot go directly to `int()`:

```python
number = int("3.5")
```

```output
ValueError: invalid literal for int() with base 10: '3.5'
```

Use `int(float("3.5"))` in that case. We will learn to handle such errors safely in Chapter 6.

## Real-World Example

A program that calculates the area of a rectangle from user input:

```python
length = float(input("Enter length: "))
width = float(input("Enter width: "))

area = length * width

print(f"Area of the rectangle = {area:.2f}")
```

If the user enters `5.5` and `4`:

```output
Enter length: 5.5
Enter width: 4
Area of the rectangle = 22.00
```

## Common Mistakes

### Forgetting to Convert Input

```python
a = input("Enter a number: ")
b = input("Enter another number: ")

print(a + b)
```

If the user enters `10` and `20`:

```output
Enter a number: 10
Enter another number: 20
1020
```

The values are strings, so Python joins them. Use `int(input(...))`.

### Joining Text and a Number

```python
age = 20
print("Age: " + age)    # TypeError
```

Use:

```python
print("Age: " + str(age))
```

or:

```python
print(f"Age: {age}")
```

### Forgetting the `f` in an f-string

```python
name = "Asha"
print("Hello {name}")
```

```output
Hello {name}
```

Write `f"Hello {name}"` to get `Hello Asha`.

---

## Key Points

* `print()` shows output. Use `sep` and `end` to control the format.
* `\n` makes a new line and `\t` makes a tab space.
* f-strings put variables inside text: `f"{name}"`.
* `:.2f` shows 2 digits after the decimal point.
* `input()` always returns a string.
* Use `int()`, `float()`, `str()` and `bool()` to convert types.
* `int()` cuts off the decimal part and does not round.
* Bad conversions cause a `ValueError`.

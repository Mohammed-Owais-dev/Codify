# Chapter 2: Python Basics

## Section 2.4: Input, Output & Type Conversion

input() returns text. Convert it to int or float before numeric calculations; invalid text raises ValueError.

## Real-World Example

A canteen program calculates the total from quantity and price.

## Example

```python
quantity = int(input("Quantity: "))
price = float(input("Price: "))
print("Total:", quantity * price)
```

```output
For input 3 and 25.5: Total: 76.5
```

## Common Mistakes

* Confusing the purpose of the concept with the exact syntax used in the example.
* Assuming one successful run proves the program works for every input.
* Ignoring invalid input, boundary values, or readability when they matter.

## Key Points

* input() returns text.
* Convert it to int or float before numeric calculations.
* invalid text raises ValueError.
* Use meaningful names and test examples before relying on a program.

## Section 10.1: Calculator & Number Guessing Game

A calculator selects an operation and validates cases such as division by zero. A guessing game similarly needs a defined range, input checks, and a stopping rule.

## Real-World Example

A student builds a command-line calculator for arithmetic practice.

## Example

```python
def calculate(a, op, b):
    if op == "+": return a + b
    if op == "-": return a - b
    if op == "*": return a * b
    if op == "/" and b != 0: return a / b
    raise ValueError("Unsupported operation")
print(calculate(12, "+", 8))
```

```output
20
```

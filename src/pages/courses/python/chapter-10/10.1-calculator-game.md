# Chapter 10: Python Mini Projects

## Section 1: Calculator & Number Guessing Game

Time to build real programs! In this section we create two classic beginner projects: a **menu-driven calculator** and a **number guessing game**. Along the way we combine functions, loops, conditions, exceptions and the `random` module.

## 1. Project Overview

| Project | What it does |
|---------|--------------|
| **Calculator** | Adds, subtracts, multiplies and divides two numbers from a menu |
| **Guessing Game** | The computer picks a secret number and the player tries to guess it |

Concepts used:

| Concept | Where |
|---------|-------|
| Functions | One function for each calculator operation |
| `while` loop | Keeps the menu running until the user exits |

# Part A: Calculator

## 3. Step 1: The Operations

Each operation gets its own function. This keeps the code clean and easy to test.

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    return a / b

print(add(10, 5))
print(subtract(10, 5))
print(multiply(10, 5))
print(divide(10, 5))
```

```output

5
50
2.0
```

Dividing by zero raises an error, which we will handle in the main program:

```python
try:
    print(divide(5, 0))
except ZeroDivisionError:
    print("Cannot divide by zero")
```

```output

```

## 4. Step 2: Safe Number Input

If the user types text instead of a number, `float()` raises a `ValueError`. We keep asking until a valid number arrives.

```python
def get_number(prompt):
    while True:
        try:
            return float(input(prompt))
        except ValueError:
            print("Invalid number. Try again.")

number = get_number("Enter a number: ")
print("You entered", number)
```

```output
Enter a number: abc
Invalid number. Try again.
Enter a number: 7
You entered 7.0
```

## 5. Step 3: The Menu Loop

An infinite `while True` loop shows the menu repeatedly. The `break` statement ends it when the user chooses Exit, and `continue` jumps back to the top after a bad choice.

```python
while True:
    choice = input("Choose 1 to continue or 2 to exit: ")

    if choice == "2":
        print("Goodbye!")
        break

    if choice != "1":
        print("Invalid choice.")
        continue

    print("Working...")
```

```output
Choose 1 to continue or 2 to exit: 1
Working...
Choose 1 to continue or 2 to exit: 9
Invalid choice.
Choose 1 to continue or 2 to exit: 2
Goodbye!
```

## 6. Complete Calculator Program

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    return a / b

def get_number(prompt):
    while True:
        try:
            return float(input(prompt))
        except ValueError:
            print("Invalid number. Try again.")

def show_menu():
    print("-" * 40)
    print("1. Add  2. Subtract  3. Multiply  4. Divide  5. Exit")

print("=== Simple Calculator ===")

while True:
    show_menu()
    choice = input("Choose an option (1-5): ")

    if choice == "5":
        print("Goodbye!")
        break

    if choice not in ("1", "2", "3", "4"):
        print("Invalid choice. Please select 1-5.")
        continue

    a = get_number("Enter first number: ")
    b = get_number("Enter second number: ")

    try:
        if choice == "1":
            result = add(a, b)
        elif choice == "2":
            result = subtract(a, b)
        elif choice == "3":
            result = multiply(a, b)
        else:
            result = divide(a, b)
    except ZeroDivisionError:
        print("Error: Cannot divide by zero")
    else:
        print("Result:", result)
```

# Part B: Number Guessing Game

## 7. The Game Rules

* The computer picks a secret number between 1 and 100.
* The player has 7 attempts.
* After each guess, the program says **Too low** or **Too high**.
* The game ends when the player guesses correctly or runs out of attempts.

---

## 8. Step 1: Picking a Random Number

`random.randint(1, 100)` picks an integer from 1 to 100, **including both ends**.

```python
import random

secret = random.randint(1, 100)

print(1 <= secret <= 100)
```

```output
True
```

---

## 9. Step 2: Checking a Guess

Put the comparison inside a function so it is easy to test.

```python
def check_guess(secret, guess):
    if guess < secret:
        return "Too low!"
    elif guess > secret:
        return "Too high!"
    return "Correct!"

print(check_guess(37, 50))
print(check_guess(37, 25))
print(check_guess(37, 37))
```

```output
Too high!
Too low!
Correct!
```

---

## 10. Complete Guessing Game

The attempt counter only increases for **valid** guesses, so a typing mistake does not cost an attempt.

```python
import random

def play_game(max_number=100, max_attempts=7):
    secret = random.randint(1, max_number)
    attempts = 0

    print("I am thinking of a number between 1 and", max_number)
    print("You have", max_attempts, "attempts.")

    while attempts < max_attempts:
        try:
            guess = int(input("Your guess: "))
        except ValueError:
            print("Please enter a whole number.")
            continue

        attempts += 1

        if guess < secret:
            print("Too low!")
        elif guess > secret:
            print("Too high!")
        else:
            print("Correct! You guessed it in", attempts, "attempts.")
            return True

        print("Attempts left:", max_attempts - attempts)

    print("Game over! The number was", secret)
    return False

while True:
    play_game()
    again = input("Play again? (y/n): ").lower()
    if again != "y":
        print("Thanks for playing!")
        break
```

Sample run (in this run, the computer happened to pick **37**; the secret number is different each time):

```output
I am thinking of a number between 1 and 100
You have 7 attempts.
Your guess: 50
Too high!
Attempts left: 6
Your guess: abc
Please enter a whole number.
Your guess: 25
Too low!
Attempts left: 5
Your guess: 37
Correct! You guessed it in 3 attempts.
Play again? (y/n): n
Thanks for playing!
```

---

## 11. Winning Strategy: Binary Search

Always guess the **middle** of the remaining range. Each guess cuts the possibilities in half, so any number from 1 to 100 can be found in at most **7 guesses**. This is exactly the binary search idea from Chapter 9.

## Real-World Example 🌍

A **bill splitter** that reuses the calculator functions to split a restaurant bill with a tip:

```python
def multiply(a, b):
    return a * b

def divide(a, b):
    return a / b

bill = 1250
tip_percent = 10
people = 4

total = multiply(bill, 1 + tip_percent / 100)
per_person = divide(total, people)

print("Total with tip:", total)
print("Each person pays:", per_person)
```

```output
Total with tip: 1375.0
Each person pays: 343.75
```

Writing small, reusable functions lets you use them in many different programs.

## Common Mistakes

### Comparing a String with a Number

```python
guess = input("Your guess: ")
if guess < secret:         # TypeError: str and int
```

Convert first: `guess = int(input(...))`.

### Forgetting `break` in an Infinite Loop

Without `break` (or `return`), a `while True` loop never ends.

### Counting Invalid Guesses as Attempts

Use `continue` in the `except` block **before** increasing the attempt counter.

### Dividing Without Handling Zero

Always wrap division in `try / except ZeroDivisionError`.

### Calling `random.randint(1, 99)` for 1 to 100

`randint` includes both ends, so use `randint(1, 100)`.

### Defining the Menu but Never Calling It

Functions do nothing until you call them, such as `show_menu()`.

---

## Key Points

* Split a program into small functions that each do one job.
* `while True` with `break` is a common pattern for menu-driven programs.
* `continue` skips the rest of the loop body and starts the next round.
* Use `try / except ValueError` to validate user input.
* Use `try / except ZeroDivisionError` for division.
* `random.randint(a, b)` includes both `a` and `b`.
* Test small functions separately before joining them.
* Guessing the middle of the range finds a number in the fewest attempts.
* Good projects handle wrong input without crashing.

## Section 10.2: Quiz Application

A quiz stores question-answer pairs, compares normalized input, and updates the score once per correct answer. Keep content separate from scoring logic.

## Real-World Example

A revision tool asks short questions and reports a final score.

## Example

```python
questions = [{"q": "2 + 3?", "a": "5"}, {"q": "Capital of India?", "a": "New Delhi"}]
score = 0
for item in questions:
    answer = input(item["q"] + " ").strip()
    if answer.casefold() == item["a"].casefold():
        score += 1
print(f"Score: {score}/{len(questions)}")
```

```output
With answers 5 and New Delhi: Score: 2/2
```

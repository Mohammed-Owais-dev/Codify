## Section 2: Quiz Application

In this project we build a **multiple-choice quiz application** that asks questions, checks answers, calculates the score and saves results to a leaderboard file.

---

## 1. Project Overview

**Features:**

* Asks a list of multiple-choice questions.
* Accepts only valid options (a, b, c or d).
* Tells the user instantly whether each answer is correct.
* Shows the final score, percentage and a message.
* Saves scores to a JSON file and displays a leaderboard.

| Concept | Where |
|---------|-------|
| Lists and dictionaries | Storing the question bank |
| Functions | Asking one question; running the whole quiz |
| Loops with `enumerate` and `zip` | Numbering questions and options |
| Input validation | Rejecting invalid answers |
| Files and JSON | Saving the leaderboard |

---

## 2. Step 1: Designing the Question Bank

Each question is a **dictionary** with the question text, a list of options and the correct answer letter. All questions go in a **list**.

```python
questions = [
    {
        "question": "Which keyword defines a function in Python?",
        "options": ["func", "def", "function", "define"],
        "answer": "b"
    },
    {
        "question": 'What is the output of len("Python")?',
        "options": ["5", "6", "7", "Error"],
        "answer": "b"
    }
]

print(len(questions))
print(questions[0]["question"])
print(questions[1]["options"][1])
```

```output
2
Which keyword defines a function in Python?
6
```

Adding a new question later only means adding another dictionary to the list. The program logic stays the same.

## 4. Step 3: Validating the Answer

Keep asking until the user types a valid letter. `.strip().lower()` accepts answers like `" B "`.

while True:

## 5. Step 4: One Question at a Time

The function `ask_question()` shows one question, validates the answer and **returns `True` or `False`**. The main program only needs to count the `True` values.

```python
def ask_question(number, q):
    print("\nQ" + str(number) + ". " + q["question"])
    for letter, option in zip("abcd", q["options"]):
        print("  " + letter + ")", option)

    while True:
        choice = input("Your answer (a/b/c/d): ").strip().lower()
        if choice in ("a", "b", "c", "d"):
            break
        print("Invalid choice. Please enter a, b, c or d.")

    if choice == q["answer"]:
        print("Correct!")
        return True

    correct_index = "abcd".index(q["answer"])
    print("Wrong! The correct answer is", q["answer"] + ") " + q["options"][correct_index])
    return False
```

`"abcd".index("b")` gives `1`, which is the position of the correct option in the list.

## 6. Step 5: Running the Quiz and Scoring

```python
def run_quiz():
    name = input("Enter your name: ")
    score = 0

    for i, q in enumerate(questions, start=1):
        if ask_question(i, q):
            score += 1

    percent = score / len(questions) * 100

    print("\n--- Result ---")
    print(name, "scored", score, "out of", len(questions))
    print("Percentage: " + str(round(percent, 1)) + "%")

    if percent == 100:
        print("Excellent!")
    elif percent >= 60:
        print("Good job!")
    else:
        print("Keep practicing!")

    return name, score
```

## Real-World Example 🌍

A **leaderboard** that saves every player's score in a JSON file and shows the best players first. The functions below use the file `scores.json`.

```python
import json
import os

def save_score(name, score, filename="scores.json"):
    scores = []
    if os.path.exists(filename):
        with open(filename, "r") as file:
            scores = json.load(file)

    scores.append({"name": name, "score": score})

    with open(filename, "w") as file:
        json.dump(scores, file, indent=4)

def show_leaderboard(filename="scores.json"):
    with open(filename, "r") as file:
        scores = json.load(file)

    ranked = sorted(scores, key=lambda s: s["score"], reverse=True)

    print("--- Leaderboard ---")
    for position, entry in enumerate(ranked, start=1):
        print(position, entry["name"], entry["score"])

save_score("Asha", 3)
save_score("Ravi", 4)
save_score("Meena", 2)
show_leaderboard()
```

On the **first run** (when `scores.json` does not exist yet), the output is:

```output
--- Leaderboard ---
1 Ravi 4
2 Asha 3
3 Meena 2
```

Running it again adds the same three scores once more, because the file keeps old data. To connect it with the quiz, replace the last line of the quiz with:

```python
name, score = run_quiz()
save_score(name, score)
show_leaderboard()
```

## Common Mistakes

### Wrong Answer Letter in the Question Bank

If `"answer"` is `"B"` (capital) but the user's input is converted to lowercase `"b"`, no answer will ever match. Keep them in the same case.

### Forgetting to Convert the Input

Use `.strip().lower()` so `" B"` and `"b"` both work.

### Dividing by the Wrong Count

Use `len(questions)`, not a fixed number, so the percentage stays correct when you add questions.

### Quotes Inside Quotes

```python
"question": "What is len("Python")?"       # SyntaxError
```

Wrap the text in single quotes: `'What is len("Python")?'`.

### Overwriting the Leaderboard

Opening the file with `"w"` and writing only the new score erases old scores. Read the existing list first, then add to it.

### Returning Nothing from `ask_question()`

Without `return True` / `return False`, the score never increases because the function returns `None`.

## Key Points

* A list of dictionaries is an easy and flexible way to store questions.
* `zip("abcd", options)` pairs letters with options; `enumerate(..., start=1)` numbers the questions.
* Always validate user input in a loop.
* Functions that return `True` or `False` make counting scores simple.
* `"abcd".index(letter)` converts a letter into a list position.
* Percentage = `score / total * 100`.
* Save results using JSON: read the old data, add the new entry, write it back.
* `sorted(..., key=..., reverse=True)` builds a leaderboard.
* Keep data (questions) separate from logic (functions) so the program is easy to extend.

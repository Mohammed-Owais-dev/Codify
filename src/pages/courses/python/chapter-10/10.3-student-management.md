# Chapter 10: Python Mini Projects

## Section 3: Student Management System

In this project we build a **Student Management System** that stores student records, lets users search and update them, calculates statistics and **saves everything to a file** so data is not lost when the program closes.

---

## 1. Project Overview

**Features:**

1. Add a student with roll number, name and marks.
2. View all students in a neat table.
3. Search a student by roll number.
4. Update a student's marks.
5. Delete a student.
6. Show statistics: total, average, highest, lowest and topper.
7. Save to a JSON file and load it again at the next start.

| Concept | Where |
|---------|-------|
| Dictionaries | Storing all students, keyed by roll number |
| Functions | One function for each feature |
| Dictionary of functions | Menu dispatch table |
| `try / except` | Validating marks |
| Files and JSON | Saving and loading data |
| String methods | `ljust()` for aligned columns |

## 2. Step 1: Choosing the Data Structure

A **dictionary** works well. The **roll number** is the key (unique), and each value is another dictionary with the student's details.

```python
students = {
    "101": {"name": "Asha", "marks": 85},
    "102": {"name": "Ravi", "marks": 72}
}

print(students["101"]["name"])
print(students["102"]["marks"])
print("103" in students)
```

```output
Asha
72
False
```

Using `in` on a dictionary checks the **keys**, which makes duplicate roll numbers easy to detect.

## 4. Step 3: Reading Valid Marks

Marks must be a whole number from 0 to 100. We repeat the question until the input is valid.

```python
def get_marks():
    while True:
        try:
            marks = int(input("Enter marks (0-100): "))
            if 0 <= marks <= 100:
                return marks
        except ValueError:
            pass
        print("Marks must be a number between 0 and 100.")

print("Marks:", get_marks())
```

```output
Enter marks (0-100): abc
Marks must be a number between 0 and 100.
Enter marks (0-100): 150
Marks must be a number between 0 and 100.
Enter marks (0-100): 72
Marks: 72
```

`"abc"` fails inside `int()`. `150` converts correctly but is out of range. In both cases the loop prints the message and asks again.

## 6. Step 5: Saving and Loading with JSON

```python
import json
import os

FILE_NAME = "students.json"

def load_students():
    if os.path.exists(FILE_NAME):
        with open(FILE_NAME, "r") as file:
            return json.load(file)
    return {}

def save_students():
    with open(FILE_NAME, "w") as file:
        json.dump(students, file, indent=4)
```

* `load_students()` returns the saved data, or an empty dictionary on the first run.
* `save_students()` writes the current `students` dictionary to the file.

JSON keys are always text, which is why roll numbers are stored as strings.

## 7. Complete Program

```python
import json
import os

FILE_NAME = "students.json"

def load_students():
    if os.path.exists(FILE_NAME):
        with open(FILE_NAME, "r") as file:
            return json.load(file)
    return {}

def save_students():
    with open(FILE_NAME, "w") as file:
        json.dump(students, file, indent=4)

def get_grade(marks):
    if marks >= 80:
        return "A"
    elif marks >= 60:
        return "B"
    elif marks >= 40:
        return "C"
    return "F"

def get_marks():
    while True:
        try:
            marks = int(input("Enter marks (0-100): "))
            if 0 <= marks <= 100:
                return marks
        except ValueError:
            pass
        print("Marks must be a number between 0 and 100.")

def add_student():
    roll = input("Enter roll number: ").strip()
    if roll in students:
        print("Roll number already exists.")
        return
    name = input("Enter name: ").strip()
    marks = get_marks()
    students[roll] = {"name": name, "marks": marks}
    print("Student added.")

def view_students():
    if not students:
        print("No students found.")
        return
    print("Roll".ljust(6) + "Name".ljust(10) + "Marks".ljust(6) + "Grade")
    print("-" * 27)
    for roll in sorted(students):
        info = students[roll]
        print(roll.ljust(6) + info["name"].ljust(10) + str(info["marks"]).ljust(6) + get_grade(info["marks"]))

def search_student():
    roll = input("Enter roll number to search: ").strip()
    if roll not in students:
        print("Student not found.")
        return
    info = students[roll]
    print("Name:", info["name"])
    print("Marks:", info["marks"])
    print("Grade:", get_grade(info["marks"]))

def update_marks():
    roll = input("Enter roll number to update: ").strip()
    if roll not in students:
        print("Student not found.")
        return
    students[roll]["marks"] = get_marks()
    print("Marks updated.")

def delete_student():
    roll = input("Enter roll number to delete: ").strip()
    if roll in students:
        del students[roll]
        print("Student deleted.")
    else:
        print("Student not found.")

def show_statistics():
    if not students:
        print("No students found.")
        return
    all_marks = [info["marks"] for info in students.values()]
    topper = max(students, key=lambda r: students[r]["marks"])
    print("Total students:", len(students))
    print("Average marks:", round(sum(all_marks) / len(all_marks), 2))
    print("Highest marks:", max(all_marks))
    print("Lowest marks:", min(all_marks))
    print("Topper:", students[topper]["name"])

students = load_students()

actions = {
    "1": add_student,
    "2": view_students,
    "3": search_student,
    "4": update_marks,
    "5": delete_student,
    "6": show_statistics
}

while True:
    print()
    print("1. Add  2. View  3. Search  4. Update  5. Delete  6. Statistics  7. Save & Exit")
    choice = input("Enter your choice: ")

    if choice == "7":
        save_students()
        print("Data saved. Goodbye!")
        break
    elif choice in actions:
        actions[choice]()
    else:
        print("Invalid choice.")
```

## 8. Understanding the Dispatch Table

Instead of a long `if / elif` chain, we store the functions in a dictionary:

```python
actions = {"1": add_student, "2": view_students}
actions["2"]()
```

* `actions["2"]` fetches the function.
* The brackets `()` call it.

To add a new feature, write the function and add one line to the dictionary.

## Real-World Example

**Exporting a report to CSV** so the data can be opened in Excel:

```python
import csv

students = {
    "101": {"name": "Asha", "marks": 85},
    "102": {"name": "Ravi", "marks": 72}
}

with open("report.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["roll", "name", "marks"])
    for roll in sorted(students):
        info = students[roll]
        writer.writerow([roll, info["name"], info["marks"]])

with open("report.csv", "r") as file:
    print(file.read())
```

```output
roll,name,marks
101,Asha,85
102,Ravi,72
```

## Common Mistakes

### Using the Same Roll Number Twice

Without the `if roll in students` check, a new student would silently **overwrite** an old one.

### Forgetting to Save

Data is lost when the program ends unless `save_students()` runs before exit.

### Storing Marks as Text

`input()` returns a string. Convert with `int()` or comparisons and averages will fail.

### Using `students = {}` Inside a Function

That creates a **new local** variable. To change the shared dictionary, modify it (`students[roll] = ...`) instead of reassigning it.

### Forgetting That JSON Keys are Strings

A roll number saved as `101` (int) comes back as `"101"` (string). Use strings from the start.

### Calling `max()` on an Empty Dictionary

This raises `ValueError`. Check `if not students:` first.

---

## Key Points

* A dictionary of dictionaries represents a table of records.
* Use a unique key, such as the roll number, to find records quickly.
* Validate every input, especially numbers.
* Keep each feature in its own function.
* A dictionary of functions replaces a long `if / elif` menu chain.
* `ljust()` aligns text into columns.
* `json.dump()` and `json.load()` save and restore data between runs.
* Check `os.path.exists()` before loading a file.
* Handle empty data before using `max()`, `min()` or division.

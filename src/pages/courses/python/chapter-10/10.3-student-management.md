## Section 10.3: Student Management System

A student management program can add, search, view, and update records. A dictionary maps unique IDs to values; in-memory data disappears when the program ends unless saved.

## Real-World Example

A lab instructor maintains a small student register.

## Example

```python
students = {"C101": "Asha", "C102": "Rahul"}
students["C103"] = "Mina"
print(students.get("C102", "Not found"))
print(len(students))
```

```output
Rahul
3
```

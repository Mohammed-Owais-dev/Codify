## 4. Step 2: The `Expense` Class

```python
class Expense:
    def __init__(self, title, amount, category, date):
        self.title = title
        self.amount = amount
        self.category = category
        self.date = date

    def to_dict(self):
        return {
            "title": self.title,
            "amount": self.amount,
            "category": self.category,
            "date": self.date
        }

    def __str__(self):
        return (self.date + "  " + self.title.ljust(12) + self.category.ljust(10)
                + format(self.amount, ".2f").rjust(8))
```

* `to_dict()` converts the object into a dictionary so it can be saved as JSON.
* `__str__()` controls how the expense prints as one aligned row.
* `format(amount, ".2f")` shows the amount with exactly 2 decimal places.
* `rjust(8)` right-aligns the amount.

Testing the class on its own:

```python
e = Expense("Tea", 20, "Food", "2026-10-01")

print(e)
print(e.to_dict())
```

```output

{'title': 'Tea', 'amount': 20, 'category': 'Food', 'date': '2026-10-01'}
```

## 5. Step 3: The `ExpenseTracker` Class

This class owns the list of expenses and knows how to save, load and analyze them.

```python
import json
import os

class ExpenseTracker:
    def __init__(self, filename):
        self.filename = filename
        self.expenses = []
        self.load()

    def add(self, expense):
        self.expenses.append(expense)

    def sorted_expenses(self, month=None):
        items = self.expenses
        if month:
            items = [e for e in items if e.date.startswith(month)]
        return sorted(items, key=lambda e: e.date)

    def by_category(self):
        totals = {}
        for e in self.expenses:
            totals[e.category] = totals.get(e.category, 0) + e.amount
        return totals

    def delete(self, title):
        for e in self.expenses:
            if e.title.lower() == title.lower():
                self.expenses.remove(e)
                return True
        return False

    def save(self):
        with open(self.filename, "w") as file:
            json.dump([e.to_dict() for e in self.expenses], file, indent=4)

    def load(self):
        if not os.path.exists(self.filename):
            return
        try:
            with open(self.filename, "r") as file:
                data = json.load(file)
            self.expenses = [Expense(**item) for item in data]
        except (json.JSONDecodeError, TypeError):
            print("Could not read saved data. Starting fresh.")
```

Important ideas:

* Dates are stored as `"YYYY-MM-DD"` text, so sorting by date text also sorts them in time order.
* `e.date.startswith("2026-10")` is a quick month filter.
* `Expense(**item)` unpacks a dictionary into keyword arguments.
* `load()` is called inside `__init__`, so saved data returns automatically.
* The `try / except` protects the program from a damaged file.

## 6. Step 4: Input Helper Functions

Each helper returns `None` when the input is invalid, so the caller decides what message to show.

```python
from datetime import datetime

def read_amount():
    try:
        amount = float(input("Amount: "))
    except ValueError:
        return None
    return amount if amount > 0 else None

def read_date():
    text = input("Date (YYYY-MM-DD): ").strip()
    try:
        datetime.strptime(text, "%Y-%m-%d")
    except ValueError:
        return None
    return text
```

`datetime.strptime()` raises `ValueError` for impossible dates, such as `2026-13-40` or `09-10-2026`.

## 7. Step 5: Display and Menu Functions

```python
def add_expense(tracker):
    title = input("Title: ").strip()
    amount = read_amount()
    if amount is None:
        print("Amount must be a positive number.")
        return
    category = input("Category: ").strip()
    date = read_date()
    if date is None:
        print("Invalid date. Use YYYY-MM-DD.")
        return
    tracker.add(Expense(title, amount, category, date))
    print("Expense added.")

def show_table(items):
    if not items:
        print("No expenses found.")
        return
    print("Date".ljust(12) + "Title".ljust(12) + "Category".ljust(10) + "Amount".rjust(8))
    print("-" * 42)
    for e in items:
        print(e)
    print("-" * 42)
    print("Total:", format(sum(e.amount for e in items), ".2f"))

def show_summary(tracker):
    totals = tracker.by_category()
    if not totals:
        print("No expenses found.")
        return
    print("Spending by category")
    print("-" * 19)
    for category, amount in sorted(totals.items(), key=lambda item: item[1], reverse=True):
        print(category.ljust(10), format(amount, ".2f").rjust(8))
    print("-" * 19)
    print("Total".ljust(10), format(sum(totals.values()), ".2f").rjust(8))

def monthly_report(tracker):
    month = input("Enter month (YYYY-MM): ").strip()
    show_table(tracker.sorted_expenses(month))

def delete_expense(tracker):
    title = input("Enter title to delete: ").strip()
    if tracker.delete(title):
        print("Deleted:", title)
    else:
        print("Expense not found.")
```

## 8. Step 6: The Main Program

```python
def main():
    tracker = ExpenseTracker(DATA_FILE)
    print("=== Personal Expense Tracker ===")

    while True:
        print()
        print("1. Add  2. View  3. Summary  4. Monthly report  5. Delete  6. Save & Exit")
        choice = input("Enter your choice: ")

        if choice == "1":
            add_expense(tracker)
        elif choice == "2":
            show_table(tracker.sorted_expenses())
        elif choice == "3":
            show_summary(tracker)
        elif choice == "4":
            monthly_report(tracker)
        elif choice == "5":
            delete_expense(tracker)
        elif choice == "6":
            tracker.save()
            print("Data saved. Goodbye!")
            break
        else:
            print("Invalid choice.")

if __name__ == "__main__":
    main()
```

The `if __name__ == "__main__":` line (from Chapter 6) lets other files import this code without starting the menu.

## Common Mistakes

### Putting Everything in One Giant Function

Split the program into classes and small functions. Each should do one job.

### Forgetting to Validate Input

Always check amounts and dates. Bad data stored once causes errors every time it is loaded.

### Saving Dates in Different Formats

Use one format (`YYYY-MM-DD`) everywhere. It also sorts correctly as text.

### Forgetting to Call `save()` Before Exiting

Unsaved changes are lost when the program ends.

### Modifying a List While Looping Over It

In `delete()`, we `return` immediately after `remove()`, so the loop does not continue on a changed list.

### Forgetting `if __name__ == "__main__":`

Without it, importing the file would start the menu immediately.

### Not Handling a Damaged Data File

Wrap file loading in `try / except` so a broken JSON file does not crash the program.

---

## Key Points

* Plan the design first: separate **data**, **logic** and **user interface**.
* Use a class for each real-world thing (`Expense`, `ExpenseTracker`).
* `to_dict()` and `Expense(**item)` convert between objects and JSON data.
* Store dates as `YYYY-MM-DD` text so they sort correctly and are easy to filter.
* `datetime.strptime()` validates dates.
* `format(value, ".2f")`, `ljust()` and `rjust()` create clean aligned output.
* Group and total data with a dictionary and `get()`.
* Test classes directly, without the menu.
* Use `if __name__ == "__main__":` to make files reusable.
* Real projects combine many small ideas: variables, loops, functions, collections, files, exceptions, classes and modules.

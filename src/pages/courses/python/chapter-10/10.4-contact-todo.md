## Section 10.4: Contact Book & To-Do List

A to-do list stores a title and completion status. A contact book can use similar records for names and details; persistent storage is needed across runs.

## Real-World Example

A student marks a task complete after submitting it.

## Example

```python
tasks = [{"title": "Revise functions", "done": False}, {"title": "Submit lab", "done": True}]
for task in tasks:
    status = "Done" if task["done"] else "Pending"
    print(task["title"], "-", status)
```

```output
Revise functions - Pending
Submit lab - Done
```

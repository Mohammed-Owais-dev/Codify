# Part A: Contact Book

## 2. Step 1: Storing Contacts

A dictionary maps each **name** to a **phone number**.

```python
contacts = {"Asha": "9876543210", "Ravi": "9123456780"}

contacts["Meena"] = "9988776655"
```

```output

```

`sorted(contacts)` gives the names in alphabetical order.

## 3. Step 2: Validating a Phone Number

A valid phone number has **exactly 10 digits**.

```python
def is_valid_phone(phone):
    return phone.isdigit() and len(phone) == 10

print(is_valid_phone("9876543210"))
print(is_valid_phone("12345"))
print(is_valid_phone("98765abcde"))
```

```output
True
False
False
```

## 4. Step 3: Searching by Part of a Name

Convert both texts to lowercase and use the `in` operator to find partial matches.

```python
contacts = {"Asha": "9876543210", "Ravi": "9123456780", "Meena": "9988776655"}
term = "EE"

for name, phone in contacts.items():
    if term.lower() in name.lower():
        print(name, "-", phone)
```

```output
Meena - 9988776655
```

## 5. Complete Contact Book Program

```python
import json
import os

FILE_NAME = "contacts.json"

def load_contacts():
    if os.path.exists(FILE_NAME):
        with open(FILE_NAME, "r") as file:
            return json.load(file)
    return {}

def save_contacts():
    with open(FILE_NAME, "w") as file:
        json.dump(contacts, file, indent=4)

def add_contact():
    name = input("Enter name: ").strip()
    phone = input("Enter phone: ").strip()

    if not phone.isdigit() or len(phone) != 10:
        print("Phone must be exactly 10 digits.")
        return

    contacts[name] = phone
    print("Contact saved.")

def view_contacts():
    if not contacts:
        print("Contact book is empty.")
        return
    for name in sorted(contacts):
        print(name, "-", contacts[name])

def search_contact():
    term = input("Search for: ").strip().lower()
    found = False

    for name, phone in contacts.items():
        if term in name.lower():
            print(name, "-", phone)
            found = True

    if not found:
        print("No matching contacts.")

def delete_contact():
    name = input("Enter name to delete: ").strip()
    if name in contacts:
        del contacts[name]
        print("Contact deleted.")
    else:
        print("Contact not found.")

contacts = load_contacts()

actions = {
    "1": add_contact,
    "2": view_contacts,
    "3": search_contact,
    "4": delete_contact
}

while True:
    print()
    print("1. Add  2. View  3. Search  4. Delete  5. Save & Exit")
    choice = input("Enter your choice: ")

    if choice == "5":
        save_contacts()
        print("Contacts saved. Goodbye!")
        break
    elif choice in actions:
        actions[choice]()
    else:
        print("Invalid choice.")
```

# Part B: To-Do List

## 6. Step 1: Storing Tasks

Each task is a **dictionary** with the task text and a `done` flag. All tasks live in a **list**, so their order is kept and each task has a position number.

```python
tasks = []

tasks.append({"task": "Buy milk", "done": False})
tasks.append({"task": "Study Python", "done": True})

print(len(tasks))
print(tasks[1]["task"], tasks[1]["done"])
```

```output
2
Study Python True
```

---

## 7. Step 2: Displaying Tasks with Check Marks

```python
tasks = [
    {"task": "Buy milk", "done": False},
    {"task": "Study Python", "done": True}
]

for i, t in enumerate(tasks, start=1):
    mark = "x" if t["done"] else " "
    print(str(i) + ". [" + mark + "] " + t["task"])
```

```output
1. [ ] Buy milk
2. [x] Study Python
```

The expression `"x" if t["done"] else " "` is a **conditional expression** that picks one of two values.

## 8. Step 3: Reading a Valid Task Number

A helper function asks for a task number and returns the **list index** (number minus 1), or `None` if the input is wrong.

```python
def get_task_index(tasks):
    try:
        number = int(input("Enter task number: "))
    except ValueError:
        print("Please enter a number.")
        return None

    if 1 <= number <= len(tasks):
        return number - 1

    print("No such task.")
    return None
```

Using this helper in both "complete" and "delete" avoids repeating the same validation code.

## 9. Complete To-Do List Program

```python
import json
import os

FILE_NAME = "tasks.json"

def load_tasks():
    if os.path.exists(FILE_NAME):
        with open(FILE_NAME, "r") as file:
            return json.load(file)
    return []

def save_tasks():
    with open(FILE_NAME, "w") as file:
        json.dump(tasks, file, indent=4)

def get_task_index():
    try:
        number = int(input("Enter task number: "))
    except ValueError:
        print("Please enter a number.")
        return None

    if 1 <= number <= len(tasks):
        return number - 1

    print("No such task.")
    return None

def add_task():
    text = input("Enter task: ").strip()
    if text == "":
        print("Task cannot be empty.")
        return
    tasks.append({"task": text, "done": False})
    print("Task added.")

def view_tasks():
    if not tasks:
        print("No tasks yet.")
        return
    for i, t in enumerate(tasks, start=1):
        mark = "x" if t["done"] else " "
        print(str(i) + ". [" + mark + "] " + t["task"])

def complete_task():
    index = get_task_index()
    if index is not None:
        tasks[index]["done"] = True
        print("Task marked as done.")

def delete_task():
    index = get_task_index()
    if index is not None:
        removed = tasks.pop(index)
        print("Task deleted:", removed["task"])

tasks = load_tasks()

actions = {
    "1": add_task,
    "2": view_tasks,
    "3": complete_task,
    "4": delete_task
}

while True:
    print()
    print("1. Add  2. View  3. Complete  4. Delete  5. Save & Exit")
    choice = input("Enter your choice: ")

    if choice == "5":
        save_tasks()
        print("Tasks saved. Goodbye!")
        break
    elif choice in actions:
        actions[choice]()
    else:
        print("Invalid choice.")
```

## 10. Contact Book vs To-Do List

| Feature | Contact Book | To-Do List |
|---------|--------------|------------|
| Structure | Dictionary | List of dictionaries |
| Lookup | By name (key) | By position (index) |
| Duplicates | Name must be unique | Same text allowed |
| Order | Sorted when displayed | Order of entry |
| Delete using | `del contacts[name]` | `tasks.pop(index)` |

Choose a **dictionary** when you look things up by a unique key, and a **list** when order and position matter.

## Real-World Example 🌍

A **daily progress summary** for the to-do list:

```python
tasks = [
    {"task": "Buy milk", "done": True},
    {"task": "Study Python", "done": False},
    {"task": "Call mom", "done": False}
]

done = sum(1 for t in tasks if t["done"])
total = len(tasks)
percent = int(done / total * 100)

print("Completed:", done, "of", total, "(" + str(percent) + "%)")

print("Pending:")
for t in tasks:
    if not t["done"]:
        print("-", t["task"])
```

```output
Completed: 1 of 3 (33%)
Pending:
- Study Python
- Call mom
```

## Common Mistakes

### Using Task Numbers as List Indexes Directly

Users see numbers starting from 1, but lists start at 0. Subtract 1 before using the index.

### Not Checking for Empty Input

Without a check, empty tasks and blank names get saved.

### Deleting While Looping

Removing items from a list inside a `for` loop over the same list skips items. Remove by index instead.

### Forgetting `is not None`

```python
if index:               # False for index 0, the first task!
```

Write `if index is not None:`.

### Overwriting a Contact by Accident

Adding a name that already exists replaces the old number. Check `if name in contacts` first if you want to warn the user.

### Leaving Out the Save Step

Data is lost unless it is written to the file before the program exits.

---

## Key Points

* A dictionary suits lookup by unique name; a list of dictionaries suits ordered records.
* `isdigit()` and `len()` validate phone numbers.
* Use lowercase comparison with `in` for partial, case-insensitive search.
* `enumerate(list, start=1)` creates numbered displays.
* Convert user-facing numbers (starting at 1) to list indexes (starting at 0).
* `list.pop(index)` removes an item and returns it.
* Compare with `is not None` when `0` is a valid value.
* A helper function removes repeated validation code.
* Use JSON files to keep data between runs.

# Chapter 4: Strings & Collections

## Section 4.1: Strings & String Operations

Strings are immutable sequences of Unicode characters. Indexing starts at zero; slices include the start and exclude the stop. Methods such as strip() and lower() return new strings.

## Real-World Example

A form normalizes a username before comparing it.

## Example

```python
raw = "  Codify Student  "
name = raw.strip().lower()
print(name)
print(name[0:6])
```

```output
codify student
codify
```

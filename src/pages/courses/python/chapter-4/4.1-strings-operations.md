# Chapter 4: Strings & Collections

## Section 1: Strings & String Operations

A **string** is a sequence of characters such as letters, digits and symbols. Strings are used everywhere: names, messages, passwords, file paths and more. In this section you will learn how to create strings and work with them.

---

## 1. Creating Strings

A string is written inside single quotes, double quotes or triple quotes.

```python
name = "Asha"
city = 'Hyderabad'

print(name)
print(city)
print(type(name))
```

```output
Asha
Hyderabad
<class 'str'>
```

Triple quotes create a **multi-line string**.

```python
poem = """Roses are red,
Violets are blue,
Python is fun."""

print(poem)
```

```output
Roses are red,
Violets are blue,
Python is fun.
```

---

## 2. String Length

`len()` returns the number of characters, including spaces.

```python
text = "Python"
print(len(text))
print(len("Hello World"))
```

```output
6
11
```

---

## 3. Indexing

Every character has a position called an **index**. Counting starts from `0`. Negative indexes count from the end.

| Character | P | y | t | h | o | n |
| --- | --- | --- | --- | --- | --- | --- |
| Index | 0 | 1 | 2 | 3 | 4 | 5 |
| Negative index | -6 | -5 | -4 | -3 | -2 | -1 |

```python
text = "Python"

print(text[0])
print(text[2])
print(text[-1])
```

```output
P
t
n
```

> 💡 Using an index that does not exist, such as `text[10]`, causes an `IndexError`.

---

## 4. Slicing

Slicing extracts a part of a string.

**Syntax:**

```text
string[start:stop:step]
```

`start` is included, `stop` is **not** included.

```python
text = "Python"

print(text[0:3])
print(text[2:])
print(text[:4])
print(text[::2])
print(text[::-1])
```

```output
Pyt
thon
Pyth
Pto
nohtyP
```

* `text[2:]` goes from index 2 to the end.
* `text[:4]` goes from the start up to index 3.
* `text[::-1]` reverses the string.

## 5. Concatenation and Repetition

Use `+` to join strings and `*` to repeat them.

```python
first = "Hello"
second = "World"

print(first + " " + second)
print("Ha" * 3)
print("-" * 20)
```

```output
Hello World
HaHaHa
--------------------
```

---

## 6. Strings are Immutable

You cannot change a character inside an existing string. You must create a new string.

```python
word = "Python"
# word[0] = "J"    # TypeError

word = "J" + word[1:]
print(word)
```

```output
Jython
```

## 9. Common String Methods

Strings have many built-in methods. Each method returns a **new** string and leaves the original unchanged.

| Method | Purpose |
| --- | --- |
| `upper()` | Converts to uppercase |
| `lower()` | Converts to lowercase |
| `title()` | Capitalizes every word |
| `capitalize()` | Capitalizes the first letter only |
| `strip()` | Removes spaces from both ends |
| `replace(old, new)` | Replaces text |
| `find(sub)` | Returns the first index, or `-1` if not found |
| `count(sub)` | Counts occurrences |
| `startswith(x)` / `endswith(x)` | Checks the start / end |
| `split(sep)` | Splits into a list |
| `join(list)` | Joins a list into a string |
| `isdigit()` / `isalpha()` | Checks digits / letters |

```python
msg = "python programming"

print(msg.upper())
print(msg.title())
print(msg.capitalize())
print(msg.replace("python", "java"))
```

```output
PYTHON PROGRAMMING
Python Programming
Python programming
java programming
```

```python
msg = "python programming"

print(msg.find("pro"))
print(msg.find("z"))
print(msg.count("g"))
print(msg.startswith("py"))
print(msg.endswith("ing"))
```

```output
7
-1
2
True
True
```

```python
text = "   Hello World   "
print(text.strip())

print("123".isdigit())
print("abc".isalpha())
print("abc123".isalpha())
```

```output
Hello World
True
True
False
```

## 10. `split()` and `join()`

```python
data = "apple,banana,mango"
fruits = data.split(",")
print(fruits)

print("-".join(["a", "b", "c"]))
```

```output
['apple', 'banana', 'mango']
a-b-c
```

## 11. Escape Characters

An escape character starts with a backslash `\` and has a special meaning.

| Escape | Meaning |
| --- | --- |
| `\n` | New line |
| `\t` | Tab |
| `\\` | Backslash |
| `\"` | Double quote |
| `\'` | Single quote |

```python
print("Hello\nWorld")
print("She said \"Hi\"")
print("C:\\Users")
```

```output
Hello
World
She said "Hi"
C:\Users
```

---

## 12. f-Strings (Formatted Strings)

Put `f` before the quotes and write variables inside `{}`.

```python
name = "Asha"
age = 20

print(f"{name} is {age} years old")
print(f"Next year: {age + 1}")
```

```output
Asha is 20 years old
Next year: 21
```

---

## 13. Palindrome Check

A palindrome reads the same forwards and backwards.

```python
word = "madam"

if word == word[::-1]:
    print("Palindrome")
else:
    print("Not a palindrome")
```

```output
Palindrome
```

## Real-World Example

A program that counts the vowels in a word:

```python
word = input("Enter a word: ")
count = 0

for ch in word.lower():
    if ch in "aeiou":
        count = count + 1

print("Number of vowels:", count)
```

If the user enters:

```text
Education
```

The output will be:

```output
Enter a word: Education
Number of vowels: 5
```

## Common Mistakes

### Changing a Character Directly

```python
name = "Asha"
name[0] = "E"    # TypeError
```

Strings are immutable. Build a new string instead.

### Mixing Strings and Numbers with `+`

```python
age = 20
print("Age: " + age)    # TypeError
```

Use:

```python
print("Age: " + str(age))
```

### Index Out of Range

```python
text = "Hi"
print(text[5])    # IndexError
```

### Forgetting That Methods Return a New String

```python
name = "asha"
name.upper()
print(name)    # still asha
```

Use `name = name.upper()`.

### Forgetting the `f` in an f-String

```python
print("Hello {name}")    # prints the braces as text
```

---

## Key Points

* Strings are written in single, double or triple quotes.
* Indexing starts at `0`; negative indexes count from the end.
* Slicing uses `string[start:stop:step]`, and `[::-1]` reverses a string.
* Strings are immutable.
* Methods such as `upper()`, `strip()`, `replace()` and `split()` return new values.
* `+` joins strings and `*` repeats them.
* `in` checks whether text exists inside a string.
* f-strings make formatting easy: `f"{name}"`.

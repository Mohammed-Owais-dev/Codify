# Chapter 4: Strings & Collections

## Section 3: Tuples & Sets

Lists are not the only collections in Python. A **tuple** is like a list that cannot be changed, and a **set** stores only unique values. Each has its own use.

---

## 1. What is a Tuple?

A tuple is an **ordered** collection that is **immutable**, which means it cannot be changed after it is created. Tuples are written inside round brackets.

```python
point = (10, 20)
colors = ("red", "green", "blue")
mixed = ("Asha", 20, True)

print(point)
print(type(colors))
```

```output
(10, 20)
<class 'tuple'>
```

---

## 2. Accessing Tuple Items

Indexing and slicing work exactly as in lists.

```python
days = ("Mon", "Tue", "Wed", "Thu", "Fri")

print(days[0])
print(days[-1])
print(days[1:4])
print(len(days))
```

```output
Mon
Fri
('Tue', 'Wed', 'Thu')
5
```

---

## 3. Tuples are Immutable

```python
t = (1, 2, 3)
# t[0] = 10    # TypeError

print(t)
```

```output
(1, 2, 3)
```

To "change" a tuple, create a new one:

```python
t = (1, 2, 3)
t = t + (4, 5)
print(t)
```

```output
(1, 2, 3, 4, 5)
```

---

## 4. Single-Item Tuple

A tuple with one item needs a trailing comma.

```python
a = (5)
b = (5,)

print(type(a))
print(type(b))
```

```output
<class 'int'>
<class 'tuple'>
```

---

## 5. Tuple Methods

Tuples have only two methods because they cannot change.

```python
t = (1, 2, 3, 2, 2)

print(t.count(2))
print(t.index(3))
```

```output
3
2
```

---

## 6. Tuple Packing and Unpacking

Several values can be packed into a tuple and unpacked into separate variables.

```python
student = ("Asha", 20, "Hyderabad")

name, age, city = student

print(name)
print(age)
print(city)
```

```output
Asha
20
Hyderabad
```

Unpacking is also a neat way to swap two variables.

```python
a = 5
b = 10

a, b = b, a
print(a, b)
```

```output
10 5
```

---

## 7. Looping Through a Tuple

```python
for color in ("red", "green", "blue"):
    print(color)
```

```output
red
green
blue
```

---

## 8. List vs Tuple

| Feature | List | Tuple |
| --- | --- | --- |
| Brackets | `[ ]` | `( )` |
| Mutable | Yes | No |
| Methods | Many | `count()`, `index()` |
| Speed | Slightly slower | Slightly faster |
| Use for | Data that changes | Fixed data (coordinates, dates) |

---

## 9. What is a Set?

A set is an **unordered** collection of **unique** items. Sets are written inside curly braces.

```python
numbers = {1, 2, 2, 3, 3, 3}

print(numbers)
print(len(numbers))
```

```output
{1, 2, 3}
3
```

* Duplicates are removed automatically.
* Items have no fixed order, so sets cannot be indexed.
* An empty set must be created with `set()`, because `{}` creates an empty dictionary.

```python
empty = set()
print(type(empty))
print(type({}))
```

```output
<class 'set'>
<class 'dict'>
```

---

## 10. Adding and Removing Items

| Method | Purpose |
| --- | --- |
| `add(x)` | Adds one item |
| `update(iterable)` | Adds many items |
| `remove(x)` | Removes `x`; error if missing |
| `discard(x)` | Removes `x`; no error if missing |
| `pop()` | Removes a random item |
| `clear()` | Removes all items |

```python
s = {1, 2}

s.add(3)
s.add(2)
print(s)

s.update([4, 5])
print(s)

s.remove(1)
s.discard(100)
print(s)
```

```output
{1, 2, 3}
{1, 2, 3, 4, 5}
{2, 3, 4, 5}
```

---

## 11. Set Operations

Sets support mathematical operations.

| Operation | Symbol | Method | Meaning |
| --- | --- | --- | --- |
| Union | `a \| b` | `a.union(b)` | All items from both |
| Intersection | `a & b` | `a.intersection(b)` | Items in both |
| Difference | `a - b` | `a.difference(b)` | Items only in `a` |
| Symmetric difference | `a ^ b` | `a.symmetric_difference(b)` | Items in only one set |

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)
print(a & b)
print(a - b)
print(a ^ b)
```

```output
{1, 2, 3, 4, 5, 6}
{3, 4}
{1, 2}
{1, 2, 5, 6}
```

---

## 12. Membership and Subsets

```python
a = {1, 2}
b = {1, 2, 3, 4}

print(2 in b)
print(a.issubset(b))
print(b.issuperset(a))
```

```output
True
True
True
```

---

## 13. Removing Duplicates from a List

```python
data = [1, 2, 2, 3, 3, 3, 4]

unique = list(set(data))
print(unique)
```

```output
[1, 2, 3, 4]
```

> A set does not guarantee order. If the original order matters, use a loop with a list instead (see Section 4.5).

---

## Real-World Example

A program that counts how many different numbers a user entered:

```python
nums = input("Enter numbers separated by spaces: ").split()

unique = set(nums)

print("Total entered:", len(nums))
print("Unique numbers:", len(unique))
```

If the user enters:

```text
4 7 4 9 7
```

The output will be:

```output
Enter numbers separated by spaces: 4 7 4 9 7
Total entered: 5
Unique numbers: 3
```

## Common Mistakes

### Trying to Change a Tuple

```python
t = (1, 2, 3)
t[0] = 5    # TypeError
```

### Forgetting the Comma in a Single-Item Tuple

```python
t = (5)    # this is an int, not a tuple
```

Use `t = (5,)`.

### Creating an Empty Set with `{}`

```python
s = {}    # this is a dictionary
```

Use `s = set()`.

### Indexing a Set

```python
s = {1, 2, 3}
print(s[0])    # TypeError
```

Sets are unordered and do not support indexes.

### Using `remove()` on a Missing Item

```python
s = {1, 2}
s.remove(10)    # KeyError
```

Use `discard()` when the item may not exist.

---

## Key Points

* A tuple is ordered and immutable; it uses `( )`.
* A single-item tuple needs a trailing comma: `(5,)`.
* Tuples support indexing, slicing, `count()` and `index()`.
* Unpacking assigns tuple items to variables.
* A set is unordered and stores unique items; it uses `{ }`.
* Create an empty set with `set()`.
* Sets support union `|`, intersection `&`, difference `-` and symmetric difference `^`.
* `list(set(data))` removes duplicates.

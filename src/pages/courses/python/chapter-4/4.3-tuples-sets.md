# Chapter 4: Strings & Collections

## Section 4.3: Tuples & Sets

Tuples are ordered and immutable. Sets contain unique hashable values and do not provide positional indexing; sorted() returns a sorted list.

## Real-World Example

Coordinates can be a tuple; a set can remove duplicate course codes.

## Example

```python
location = (16.5, 80.6)
courses = {"C", "Python", "C", "Java"}
print(location)
print(sorted(courses))
```

```output
(16.5, 80.6)
['C', 'Java', 'Python']
```

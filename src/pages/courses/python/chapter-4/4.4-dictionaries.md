# Chapter 4: Strings & Collections

## Section 4: Dictionaries & Dictionary Methods

A **dictionary** stores data as **key-value pairs**. Instead of finding an item by its position, you find it by its **key**, just like looking up a word in a real dictionary.

---

## 1. Creating a Dictionary

A dictionary is written inside curly braces, with `key: value` pairs separated by commas.

```python
student = {
    "name": "Asha",
    "age": 20,
    "city": "Hyderabad"
}

print(student)
print(type(student))
```

```output
{'name': 'Asha', 'age': 20, 'city': 'Hyderabad'}
<class 'dict'>
```

Rules for dictionaries:

* Keys must be **unique** and **immutable** (strings, numbers or tuples).
* Values can be of any type and can repeat.
* Items keep the order in which they were added.

---

## 2. Accessing Values

Use the key inside square brackets, or the `get()` method.

```python
student = {"name": "Asha", "age": 20, "city": "Hyderabad"}

print(student["name"])
print(student.get("age"))
print(student.get("phone"))
print(student.get("phone", "Not available"))
```

```output
Asha
20
None
Not available
```

`student["phone"]` would raise a `KeyError`, but `get()` returns `None` (or a default value) instead.

---

## 3. Adding and Updating Items

Assigning to a key adds it if it is new, or updates it if it already exists.

```python
student = {"name": "Asha", "age": 20}

student["age"] = 21
student["course"] = "Python"

print(student)
```

```output
{'name': 'Asha', 'age': 21, 'course': 'Python'}
```

`update()` changes many items at once.

```python
d = {"a": 1}

d.update({"b": 2, "c": 3})
print(d)
```

```output
{'a': 1, 'b': 2, 'c': 3}
```

---

## 4. Removing Items

| Method | Purpose |
| --- | --- |
| `pop(key)` | Removes the key and returns its value |
| `popitem()` | Removes and returns the last added pair |
| `del d[key]` | Deletes the key |
| `clear()` | Removes everything |

```python
student = {"name": "Asha", "age": 21, "city": "Hyderabad", "course": "Python"}

city = student.pop("city")
print(city)

del student["course"]
print(student)
```

```output
Hyderabad
{'name': 'Asha', 'age': 21}
```

---

## 5. Keys, Values and Items

```python
student = {"name": "Asha", "age": 21}

print(list(student.keys()))
print(list(student.values()))
print(list(student.items()))
```

```output
['name', 'age']
['Asha', 21]
[('name', 'Asha'), ('age', 21)]
```

---

## 6. Looping Through a Dictionary

Looping directly gives the keys. Use `items()` to get both key and value.

```python
student = {"name": "Asha", "age": 21}

for key in student:
    print(key)

for key, value in student.items():
    print(key, ":", value)
```

```output
name
age
name : Asha
age : 21
```

---

## 7. Checking for a Key

The `in` operator checks **keys**, not values.

```python
student = {"name": "Asha", "age": 21}

print("name" in student)
print("Asha" in student)
print("Asha" in student.values())
```

```output
True
False
True
```

## 8. Length of a Dictionary

```python
student = {"name": "Asha", "age": 21, "city": "Hyderabad"}

print(len(student))
```

```output
3
```

## 9. Nested Dictionaries

A dictionary can hold other dictionaries as values.

```python
students = {
    "s1": {"name": "Asha", "marks": 85},
    "s2": {"name": "Ravi", "marks": 78}
}

print(students["s2"]["name"])
print(students["s1"]["marks"])
```

```output
Ravi
85
```

---

## 10. Copying a Dictionary

```python
a = {"x": 1}
b = a.copy()

b["x"] = 100
print(a)
print(b)
```

```output
{'x': 1}
{'x': 100}
```

---

## 11. Common Dictionary Methods

| Method | Purpose |
| --- | --- |
| `get(key, default)` | Safe access to a value |
| `keys()` | All keys |
| `values()` | All values |
| `items()` | All key-value pairs |
| `update(other)` | Adds or updates many pairs |
| `pop(key)` | Removes a key and returns its value |
| `setdefault(key, value)` | Adds the key only if it is missing |
| `copy()` | Creates a copy |
| `clear()` | Empties the dictionary |

---

## 12. Counting with a Dictionary

Dictionaries are perfect for counting how often something appears.

```python
sentence = "the cat and the hat"
words = sentence.split()
freq = {}

for w in words:
    if w in freq:
        freq[w] = freq[w] + 1
    else:
        freq[w] = 1

print(freq)
```

```output
{'the': 2, 'cat': 1, 'and': 1, 'hat': 1}
```

## Real-World Example 🌍

A simple phone book that looks up a contact:

```python
contacts = {
    "Asha": "9876543210",
    "Ravi": "9123456780",
    "Meena": "9988776655"
}

name = input("Enter name to search: ")

if name in contacts:
    print("Phone number:", contacts[name])
else:
    print("Contact not found")
```

If the user enters:

```text
Ravi
```

The output will be:

```output
Enter name to search: Ravi
Phone number: 9123456780
```

## Common Mistakes

### Accessing a Missing Key

```python
d = {"a": 1}
print(d["b"])    # KeyError
```

Use `d.get("b")` or check `"b" in d` first.

### Using a List as a Key

```python
d = {[1, 2]: "x"}    # TypeError
```

Keys must be immutable. Use a tuple `(1, 2)` instead.

### Duplicate Keys

```python
d = {"a": 1, "a": 2}
print(d)    # {'a': 2}
```

The last value silently replaces the earlier one.

### Checking Values with `in`

`"Asha" in student` checks keys. Use `student.values()` to check values.

### Changing a Dictionary While Looping

Adding or deleting keys during a loop raises a `RuntimeError`. Loop over `list(d.keys())` or build a new dictionary.

---

## Key Points

* A dictionary stores `key: value` pairs inside `{ }`.
* Keys are unique and immutable; values can be anything.
* Access with `d[key]` or the safer `d.get(key, default)`.
* Assigning to a key adds or updates a pair.
* Remove with `pop()`, `del` or `clear()`.
* `keys()`, `values()` and `items()` return the parts of a dictionary.
* `for key, value in d.items()` loops over pairs.
* `in` checks keys.
* Dictionaries can be nested.

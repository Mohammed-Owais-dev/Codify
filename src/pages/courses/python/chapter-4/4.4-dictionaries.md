## Section 4.4: Dictionaries & Dictionary Methods

A dictionary maps unique keys to values. get() can provide a fallback for a missing key; bracket access raises KeyError when the key is absent.

## Real-World Example

A student record maps field names to values.

## Example

```python
student = {"name": "Asha", "marks": 91}
student["marks"] = 94
print(student.get("name"))
print(student["marks"])
```

```output
Asha
94
```

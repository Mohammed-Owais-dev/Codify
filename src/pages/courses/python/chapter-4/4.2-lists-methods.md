## Section 4.2: Lists & List Methods

Lists are ordered and mutable. append() adds an item, remove() removes the first matching value, and len() returns the item count.

## Real-World Example

A shopping cart adds and removes products.

## Example

```python
cart = ["book", "pen"]
cart.append("notebook")
cart.remove("pen")
print(cart)
print(len(cart))
```

```output
['book', 'notebook']
2
```

# Chapter 4: Strings & Collections

## Section 5: Comprehensions & Common Collection Programs

A **comprehension** is a short, readable way to build a list, set or dictionary in a single line. In this section you will also practice common programs that combine everything you learned in this chapter.

---

## 1. Why Comprehensions?

Suppose we want a list of squares of the numbers 1 to 5. With a normal loop:

```python
squares = []

for x in range(1, 6):
    squares.append(x * x)

print(squares)
```

```output
[1, 4, 9, 16, 25]
```

With a **list comprehension**, the same result takes one line:

```python
squares = [x * x for x in range(1, 6)]
print(squares)
```

```output
[1, 4, 9, 16, 25]
```

---

## 2. List Comprehension Syntax

**Syntax:**

```text
[expression for item in iterable]
```

Read it as: "give me `expression` for every `item` in `iterable`".

```python
words = ["python", "java", "c"]

lengths = [len(w) for w in words]
upper = [w.upper() for w in words]

print(lengths)
print(upper)
```

```output
[6, 4, 1]
['PYTHON', 'JAVA', 'C']
```

---

## 3. Comprehension with a Condition

Add `if` at the end to filter items.

**Syntax:**

```text
[expression for item in iterable if condition]
```

```python
evens = [x for x in range(1, 11) if x % 2 == 0]
print(evens)

long_words = [w for w in ["hi", "python", "go", "coding"] if len(w) > 2]
print(long_words)
```

```output
[2, 4, 6, 8, 10]
['python', 'coding']
```

---

## 4. Comprehension with `if-else`

When you want to **change** the value instead of filtering, put `if-else` **before** the `for`.

**Syntax:**

```text
[value_if_true if condition else value_if_false for item in iterable]
```

```python
labels = ["Even" if x % 2 == 0 else "Odd" for x in range(1, 5)]
print(labels)
```

```output
['Odd', 'Even', 'Odd', 'Even']
```

> Filtering uses `if` **after** the loop. Choosing between two values uses `if-else` **before** the loop.

## 5. Comprehension on Strings

```python
vowels = [c for c in "education" if c in "aeiou"]
print(vowels)
```

```output
['e', 'u', 'a', 'i', 'o']
```

---

## 6. Nested Loops in a Comprehension

```python
pairs = [(x, y) for x in range(1, 3) for y in range(1, 3)]
print(pairs)
```

```output
[(1, 1), (1, 2), (2, 1), (2, 2)]
```

This is the same as:

```python
pairs = []
for x in range(1, 3):
    for y in range(1, 3):
        pairs.append((x, y))
```

---

## 7. Dictionary Comprehension

**Syntax:**

```text
{key_expression: value_expression for item in iterable}
```

```python
cubes = {x: x ** 3 for x in range(1, 4)}
print(cubes)

marks = {"Asha": 82, "Ravi": 45, "Meena": 91, "John": 38}
passed = {name: m for name, m in marks.items() if m >= 40}
print(passed)
```

```output
{1: 1, 2: 8, 3: 27}
{'Asha': 82, 'Ravi': 45, 'Meena': 91}
```

---

## 8. Set Comprehension

```python
remainders = {x % 3 for x in range(10)}
print(remainders)
```

```output
{0, 1, 2}
```

---

## 9. When Not to Use a Comprehension

Comprehensions are great for simple tasks. If the logic needs several statements or becomes long, use a normal loop. **Readable code is better than short code.**

## 10. Common Collection Programs

### Largest and Smallest

```python
nums = [10, 45, 32, 45, 8]

print("Largest:", max(nums))
print("Smallest:", min(nums))
```

```output
Largest: 45
Smallest: 8
```

### Second Largest

```python
nums = [10, 45, 32, 45, 8]

unique = sorted(set(nums))
print(unique)
print("Second largest:", unique[-2])
```

```output
[8, 10, 32, 45]
Second largest: 32
```

### Reverse a List

```python
nums = [1, 2, 3, 4]
print(nums[::-1])
```

```output
[4, 3, 2, 1]
```

### Sum of Even Numbers

```python
nums = [1, 2, 3, 4, 5, 6]

total = sum([x for x in nums if x % 2 == 0])
print(total)
```

```output
12
```

### Remove Duplicates and Keep the Order

```python
data = [3, 1, 3, 2, 1]
result = []

for x in data:
    if x not in result:
        result.append(x)

print(result)
```

```output
[3, 1, 2]
```

### Count Character Frequency

`get(key, 0)` returns `0` when the key is missing, which keeps the code short.

```python
freq = {}

for ch in "banana":
    freq[ch] = freq.get(ch, 0) + 1

print(freq)
```

```output
{'b': 1, 'a': 3, 'n': 2}
```

### Swap Keys and Values

```python
d = {"a": 1, "b": 2}

swapped = {v: k for k, v in d.items()}
print(swapped)
```

```output
{1: 'a', 2: 'b'}
```

### Merge Two Lists

```python
a = [1, 2]
b = [3, 4]

print(a + b)
```

```output
[1, 2, 3, 4]
```

## Real-World Example

A report on student results using a dictionary and comprehensions:

```python
marks = {"Asha": 82, "Ravi": 45, "Meena": 91, "John": 38}

passed = [name for name, m in marks.items() if m >= 40]
toppers = [name for name, m in marks.items() if m >= 80]
average = sum(marks.values()) / len(marks)

print("Passed:", passed)
print("Toppers:", toppers)
print("Class average:", average)
```

```output
Passed: ['Asha', 'Ravi', 'Meena']
Toppers: ['Asha', 'Meena']
Class average: 64.0
```

## Common Mistakes

### Putting the Filter in the Wrong Place

```python
[x for x in range(5) if x > 2 else 0]    # SyntaxError
```

For `if-else`, write it before the `for`:

```python
[x if x > 2 else 0 for x in range(5)]
```

### Forgetting That a Dictionary Comprehension Needs `key: value`

```python
{x for x in range(3)}    # this is a set, not a dictionary
```

Use `{x: x * 2 for x in range(3)}`.

### Writing Very Long Comprehensions

If a comprehension does not fit comfortably on one line, use a regular loop.

### Using a Comprehension Only for Side Effects

```python
[print(x) for x in range(3)]    # works, but is bad style
```

Use a normal `for` loop when you only need to run an action.

### Confusing the Output Brackets

* `[ ]` creates a list.
* `{ }` with `key: value` creates a dictionary.
* `{ }` with single values creates a set.

---

## Key Points

* A comprehension builds a collection in one readable line.
* List: `[expr for item in iterable]`.
* Filter with `if` at the end; choose values with `if-else` before the `for`.
* Dictionary: `{k: v for ...}`; set: `{expr for ...}`.
* Use `sorted(set(data))` to find unique or second-largest values.
* `freq.get(key, 0) + 1` is a clean way to count items.
* Use a normal loop when the logic is complex.

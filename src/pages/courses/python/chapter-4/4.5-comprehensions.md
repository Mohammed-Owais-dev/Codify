# Chapter 4: Strings & Collections

## Section 4.5: Comprehensions & Common Collection Programs

Strings store text; lists are ordered and mutable; tuples are ordered and fixed; sets store unique values; dictionaries map keys to values.

This lesson focuses on **Comprehensions & Common Collection Programs**. Learn its purpose, how Python expresses it, and when it is useful. Start with the example, then modify it to see how the program behaves.

## Example

```python
word = "python"
numbers = [2, 4, 6]
student = {"name": "Asha"}
print(word.upper())
print(numbers[1])
print(student["name"])
```

```output
PYTHON
4
Asha
```

## How to Practise

1. Run the example in your Python environment.
2. Predict the output before running it again.
3. Change one value or statement and observe the result.
4. Explain each line in your own words.
5. Test different inputs where appropriate.

## Common Mistakes

* Forgetting Python's spelling, punctuation, or indentation rules.
* Using a value before assigning it.
* Assuming input always has the expected format.
* Copying code without understanding the steps.
* Testing only one example.

## Key Points

* **Comprehensions & Common Collection Programs** is part of the Python learning path.
* Understand the purpose before memorising syntax.
* Small runnable examples make new ideas easier to understand.
* Meaningful names, clear structure, and testing improve code quality.

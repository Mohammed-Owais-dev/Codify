## Section 9.4: Searching, Sorting & Frequency Problems

Searching locates an item, sorting arranges values, and counting tracks frequency. sorted() returns a new list; list.sort() sorts in place.

## Real-World Example

A shop sorts product prices and checks if a price exists.

## Example

```python
prices = [350, 120, 500, 120]
print(sorted(prices))
print(120 in prices)
print(prices.count(120))
```

```output
[120, 120, 350, 500]
True
2
```

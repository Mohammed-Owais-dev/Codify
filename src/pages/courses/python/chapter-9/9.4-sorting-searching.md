# Chapter 9: Python Problem Solving

## Section 4: Searching, Sorting & Frequency Problems

Finding data and arranging it in order are among the most common tasks in programming. In this section we write **searching** and **sorting** algorithms from scratch, learn Python's built-in tools, and solve **frequency-counting** problems.

---

## 1. What is an Algorithm?

An **algorithm** is a step-by-step method for solving a problem. Two algorithms can give the same answer, but one may be much **faster** than the other.

| Notation | Name | Meaning |
|----------|------|---------|
| O(1) | Constant | Time does not grow with input |
| O(log n) | Logarithmic | Very fast; halves the work each step |
| O(n) | Linear | Time grows in step with input |
| O(n log n) | Linearithmic | Good sorting speed |
| O(n²) | Quadratic | Slow for large inputs |

---

## 2. Linear Search

**Logic:** Check every item one by one until the target is found. It works on **any** list.

```python
def linear_search(items, target):
    for index, value in enumerate(items):
        if value == target:
            return index
    return -1

data = [4, 9, 2, 7]

print(linear_search(data, 2))
print(linear_search(data, 5))
```

```output
2
-1
```

Returning `-1` means "not found". Time: **O(n)**.

---

## 3. Binary Search

**Logic:** On a **sorted** list, compare the target with the middle item and discard half of the list each time.

```python
def binary_search(items, target):
    low = 0
    high = len(items) - 1

    while low <= high:
        mid = (low + high) // 2
        if items[mid] == target:
            return mid
        elif items[mid] < target:
            low = mid + 1
        else:
            high = mid - 1

    return -1

data = [2, 5, 8, 12, 16, 23, 38, 56]

print(binary_search(data, 23))
print(binary_search(data, 10))
```

```output
5
-1
```

Time: **O(log n)**. A list of 1,000,000 items needs only about 20 steps. The list **must be sorted**.

## 4. Binary Search with `bisect`

Python's `bisect` module does the same job using ready-made code.

```python
import bisect

data = [2, 5, 8, 12, 16, 23, 38, 56]

print(bisect.bisect_left(data, 23))
print(bisect.bisect_left(data, 10))
```

```output
5
3
```

For a missing value, `bisect_left` returns the position where it **would be inserted**.

## 5. Bubble Sort

**Logic:** Compare neighbouring items and swap them if they are in the wrong order. After each pass, the largest remaining item "bubbles" to the end.

```python
def bubble_sort(items):
    arr = items[:]
    n = len(arr)

    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break

    return arr

print(bubble_sort([64, 34, 25, 12, 22, 11, 90]))
```

```output
[11, 12, 22, 25, 34, 64, 90]
```

The `swapped` flag stops early when the list is already sorted. Time: **O(n²)**.

## 6. Selection Sort

**Logic:** Find the smallest item in the unsorted part and place it at the front.

```python
def selection_sort(items):
    arr = items[:]
    n = len(arr)

    for i in range(n - 1):
        smallest = i
        for j in range(i + 1, n):
            if arr[j] < arr[smallest]:
                smallest = j
        arr[i], arr[smallest] = arr[smallest], arr[i]

    return arr

print(selection_sort([64, 34, 25, 12, 22, 11, 90]))
```

```output
[11, 12, 22, 25, 34, 64, 90]
```

Time: **O(n²)**.

---

## 7. Insertion Sort

**Logic:** Take one item at a time and insert it into its correct place among the already sorted items, like sorting playing cards in your hand.

```python
def insertion_sort(items):
    arr = items[:]

    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key

    return arr

print(insertion_sort([64, 34, 25, 12, 22, 11, 90]))
```

```output
[11, 12, 22, 25, 34, 64, 90]
```

Time: **O(n²)**, but very fast on lists that are almost sorted.

## 8. Merge Sort

**Logic:** **Divide** the list into halves, sort each half, then **merge** the sorted halves.

```python
def merge_sort(items):
    if len(items) <= 1:
        return items

    mid = len(items) // 2
    left = merge_sort(items[:mid])
    right = merge_sort(items[mid:])

    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1

    result.extend(left[i:])
    result.extend(right[j:])
    return result

print(merge_sort([38, 27, 43, 3, 9, 82, 10]))
```

```output
[3, 9, 10, 27, 38, 43, 82]
```

## 9. Python's Built-in Sorting

In real programs, use the built-in tools. Python's sorting algorithm (**Timsort**) runs in **O(n log n)**.

```python
nums = [5, 2, 9, 1]

print(sorted(nums))
print(sorted(nums, reverse=True))
print(nums)

nums.sort()
print(nums)
```

```output
[1, 2, 5, 9]
[9, 5, 2, 1]
[5, 2, 9, 1]
[1, 2, 5, 9]
```

* `sorted()` returns a **new** list.
* `list.sort()` sorts **in place** and returns `None`.

## 10. Sorting with a `key`

The `key` parameter decides **what to compare**.

```python
words = ["banana", "kiwi", "apple", "fig"]

print(sorted(words, key=len))
print(sorted(words))
```

```output
['fig', 'kiwi', 'apple', 'banana']
['apple', 'banana', 'fig', 'kiwi']
```

Sorting records by several rules, here marks **descending**, then name **ascending**:

```python
students = [("Asha", 85), ("Ravi", 72), ("Meena", 85)]

result = sorted(students, key=lambda s: (-s[1], s[0]))

print(result)
```

```output
[('Asha', 85), ('Meena', 85), ('Ravi', 72)]
```

## 12. Frequency Counting with a Dictionary

```python
data = [1, 2, 2, 3, 3, 3, 4]
freq = {}

for n in data:
    freq[n] = freq.get(n, 0) + 1

print(freq)
```

```output
{1: 1, 2: 2, 3: 3, 4: 1}
```

## 13. Frequency Counting with `Counter`

```python
from collections import Counter

data = [1, 2, 2, 3, 3, 3, 4]
count = Counter(data)

print(count)
print(count.most_common(1))
print(count.most_common(2))
print(count[3])
```

```output
Counter({3: 3, 2: 2, 1: 1, 4: 1})
[(3, 3)]
[(3, 3), (2, 2)]
3
```

`most_common(n)` returns the `n` most frequent items with their counts.

## 15. Find Duplicate Items

**Logic:** Keep a `seen` set. If an item is already in it, it is a duplicate.

```python
nums = [1, 2, 3, 2, 4, 3, 5]

seen = set()
duplicates = []

for n in nums:
    if n in seen and n not in duplicates:
        duplicates.append(n)
    seen.add(n)

print(duplicates)
```

```output
[2, 3]
```

## 16. Find the Missing Number

**Logic:** The sum of numbers from 1 to n is `n(n+1)/2`. Subtract the actual sum to find the missing one.

```python
nums = [1, 2, 4, 5, 6]
n = 6

expected = n * (n + 1) // 2
missing = expected - sum(nums)

print(missing)
```

```output
3
```

## 17. Two Sum Problem

**Problem:** Find two positions whose values add up to the target.

**Logic:** For each number, check whether its **partner** (`target - number`) was already seen. A dictionary makes this fast, in O(n).

```python
def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        partner = target - n
        if partner in seen:
            return (seen[partner], i)
        seen[n] = i
    return None

print(two_sum([2, 7, 11, 15], 9))
print(two_sum([1, 2, 3], 10))
```

```output
(0, 1)
None
```

## 18. Comparing the Algorithms

| Algorithm | Best Case | Worst Case | Needs Sorted Data? |
|-----------|-----------|------------|--------------------|
| Linear search | O(1) | O(n) | No |
| Binary search | O(1) | O(log n) | **Yes** |
| Bubble sort | O(n) | O(n²) | – |
| Selection sort | O(n²) | O(n²) | – |
| Insertion sort | O(n) | O(n²) | – |
| Merge sort | O(n log n) | O(n log n) | – |
| Python `sorted()` | O(n) | O(n log n) | – |

## Real-World Example

A **shopping cart** that sorts products by price and searches for a product by name:

```python
products = [
    {"name": "Pen", "price": 10},
    {"name": "Bag", "price": 500},
    {"name": "Book", "price": 100}
]

by_price = sorted(products, key=lambda p: p["price"])

for p in by_price:
    print(p["name"], p["price"])

def find_product(name):
    for p in products:
        if p["name"] == name:
            return p
    return None

item = find_product("Book")
print(item["name"], "costs", item["price"])
```

```output
Pen 10
Book 100
Bag 500
Book costs 100
```

## Common Mistakes

### Using Binary Search on an Unsorted List

Binary search gives wrong answers unless the list is sorted first.

### Assigning the Result of `sort()`

```python
nums = nums.sort()      # nums becomes None
```

Use `nums.sort()` alone, or `new = sorted(nums)`.

### Infinite Loop in Binary Search

Always update `low = mid + 1` or `high = mid - 1`, never `low = mid`.

### Forgetting the "Not Found" Case

Return `-1` or `None` when the item is missing, and check for it when you use the result.

### Sorting the Original When You Need It Unchanged

Copy the list first (`items[:]`) or use `sorted()`.

### Confusing `Counter` Order

`most_common()` sorts by count. Items with equal counts keep the order in which they first appeared.

---

## Key Points

* Linear search checks every item; binary search needs a sorted list but is much faster.
* Return `-1` (or `None`) when a search finds nothing.
* Bubble, selection and insertion sort are simple but O(n²).
* Merge sort is O(n log n) using divide and conquer.
* Prefer `sorted()` and `list.sort()` in real programs.
* `sorted()` returns a new list; `sort()` changes the list and returns `None`.
* The `key` parameter customizes the sort order.
* `Counter` and dictionaries count frequencies; `most_common()` finds the top items.
* A `seen` set or dictionary makes duplicate and two-sum problems fast.

## Section 9.3: List, Tuple & Dictionary Problems

Collection problems include totals, extrema, duplicates, grouping, and frequencies. get(key, 0) starts a count at zero for a new key; max() needs non-empty input.

## Real-World Example

A class report finds the highest score and counts repeated marks.

## Example

```python
marks = [70, 85, 70, 90, 85, 70]
frequency = {}
for mark in marks:
    frequency[mark] = frequency.get(mark, 0) + 1
print(max(marks))
print(frequency)
```

```output
90
{70: 3, 85: 2, 90: 1}
```

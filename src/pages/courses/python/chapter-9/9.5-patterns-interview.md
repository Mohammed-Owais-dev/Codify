## Section 9.5: Pattern, Recursion & Interview Problems

Pattern and interview problems test loop logic, edge cases, and clear reasoning. String multiplication repeats a character; remainder can test evenness.

## Real-World Example

A practice app prints a pattern and tests a number.

## Example

```python
for row in range(1, 5):
    print("*" * row)
def is_even(number):
    return number % 2 == 0
print(is_even(12))
```

```output
*
**
***
****
True
```

## How It Works

Pattern and interview problems test loop logic, edge cases, and clear reasoning. String multiplication repeats a character; remainder can test evenness. Read the code line by line, predict the result, and then run it to confirm your understanding. Change one value at a time to see how the behavior changes.

## Common Mistakes

* Confusing the purpose of the concept with the exact syntax used in the example.
* Assuming one successful run proves the program works for every input.
* Ignoring invalid input, boundary values, or readability when they matter.

## Key Points

* Pattern and interview problems test loop logic, edge cases, and clear reasoning.
* String multiplication repeats a character.
* remainder can test evenness.
* Use meaningful names and test examples before relying on a program.

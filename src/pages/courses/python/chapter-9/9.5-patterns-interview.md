## 1. Pattern Printing: The Idea

Patterns are built with **nested loops**:

* The **outer loop** controls the rows.
* The **inner loop** controls what is printed in each row.
* `print(..., end="")` stays on the same line; a plain `print()` moves to the next line.

A useful shortcut is string multiplication: `"*" * 3` gives `***`.

## 4. Pyramid

**Logic:** In row `i`, print `n - i` spaces and then `2i - 1` stars.

```python
n = 4

for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))
```

```output
   *
  ***
 *****
*******
```

## 5. Diamond

**Logic:** Print the pyramid, then print it again upside down without repeating the middle row.

```python

for i in range(1, n + 1):

for i in range(n - 1, 0, -1):
```

## 9. What is Recursion?

**Recursion** means a function **calls itself** to solve a smaller version of the same problem.

Every recursive function needs:

1. A **base case**: the condition where it stops.
2. A **recursive case**: the call that moves toward the base case.

Without a base case, the function calls itself forever and Python raises `RecursionError`.

---

## 10. Sum of First N Numbers (Recursive)

```python
def sum_n(n):
    if n == 0:
        return 0
    return n + sum_n(n - 1)

print(sum_n(5))
```

```output
15
```

How it works: `sum_n(5) = 5 + 4 + 3 + 2 + 1 + 0`.

## 11. Factorial and Power (Recursive)

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

def power(base, exp):
    if exp == 0:
        return 1
    return base * power(base, exp - 1)

print(factorial(5))
print(power(2, 5))
```

```output
120
32
```

## 12. Fibonacci (Recursive)

```python
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print([fib(i) for i in range(8)])
```

```output
[0, 1, 1, 2, 3, 5, 8, 13]
```

This version repeats the same work many times. Use **memoization** to remember earlier answers:

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(40))
```

```output
102334155
```

## 13. String Problems with Recursion

```python
def reverse(s):
    if len(s) <= 1:
        return s
    return reverse(s[1:]) + s[0]

def is_palindrome(s):
    if len(s) <= 1:
        return True
    if s[0] != s[-1]:
        return False
    return is_palindrome(s[1:-1])

def sum_digits(n):
    if n < 10:
        return n
    return n % 10 + sum_digits(n // 10)

print(reverse("hello"))
print(is_palindrome("level"))
print(sum_digits(1234))
```

```output
olleh
True
10
```

## 14. Tower of Hanoi

**Problem:** Move `n` disks from peg A to peg C using peg B, moving one disk at a time and never placing a larger disk on a smaller one.

**Logic:** Move `n-1` disks to the helper peg, move the largest disk, then move the `n-1` disks onto it.

```python
def hanoi(n, source, target, helper):
    if n == 0:
        return
    hanoi(n - 1, source, helper, target)
    print("Move disk", n, "from", source, "to", target)
    hanoi(n - 1, helper, target, source)

hanoi(3, "A", "C", "B")
```

```output
Move disk 1 from A to C
Move disk 2 from A to B
Move disk 1 from C to B
Move disk 3 from A to C
Move disk 1 from B to A
Move disk 2 from B to C
Move disk 1 from A to C
```

For `n` disks, the number of moves is `2ⁿ - 1`. Here, 3 disks need 7 moves.

## 15. Recursion vs Loops

| Feature | Recursion | Loop |
|---------|-----------|------|
| Code | Often shorter and elegant | Often longer |
| Speed and memory | Slower; uses the call stack | Faster |
| Risk | `RecursionError` if too deep | Infinite loop if wrong |
| Best for | Trees, divide and conquer, naturally recursive problems | Simple repetition |

Python's default recursion limit is about 1000 calls.

## 17. Interview Problem: Balanced Brackets

**Logic:** Use a **stack** (a list). Push opening brackets; when a closing bracket appears, the top of the stack must be its matching opening bracket.

```python
def is_balanced(s):
    stack = []
    pairs = {")": "(", "]": "[", "}": "{"}

    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False

    return not stack

print(is_balanced("{[()]}"))
print(is_balanced("{[(])}"))
print(is_balanced("(("))
```

```output
True
False
False
```

## 18. Interview Problem: Maximum Subarray (Kadane's Algorithm)

**Problem:** Find the largest sum of any continuous part of a list.

**Logic:** At each number, decide whether to **extend** the current sum or **start fresh**.

```python
def max_subarray(nums):
    best = current = nums[0]
    for n in nums[1:]:
        current = max(n, current + n)
        best = max(best, current)
    return best

print(max_subarray([-2, 1, -3, 4, -1, 2, 1, -5, 4]))
```

```output
6
```

The best part is `[4, -1, 2, 1]`. Time: **O(n)**.

## Common Mistakes

### Missing the Base Case

```python
def count(n):
    return count(n - 1)       # never stops, RecursionError
```

Always add a condition that stops the recursion.

### Not Moving Toward the Base Case

Calling `factorial(n)` again with the same `n` also never ends. Reduce the problem each time.

### Wrong Number of Spaces in Patterns

Count rows from 1 and use `n - i` spaces for centered shapes.

### Forgetting `print()` After an Inner Loop

When you use `end=" "`, add a plain `print()` after the inner loop to start a new line.

### Testing `i % 3` Before `i % 15` in FizzBuzz

Multiples of 15 would print only `Fizz`.

### Using Recursion for Very Deep Problems

Python limits recursion depth. Use loops or memoization for large inputs.

---

## Key Points

* Pattern programs use an outer loop for rows and an inner loop (or string multiplication) for columns.
* `" " * (n - i) + "*" * (2 * i - 1)` prints a centered pyramid row.
* Recursion needs a base case and a recursive case that moves toward it.
* Use `lru_cache` to speed up repeated recursive calls.
* Tower of Hanoi with `n` disks needs `2ⁿ - 1` moves.
* A stack solves balanced-bracket problems.
* Kadane's algorithm finds the maximum subarray sum in O(n).
* In FizzBuzz, check the combined case first.
* In interviews, explain your thinking, test with examples and state the complexity.

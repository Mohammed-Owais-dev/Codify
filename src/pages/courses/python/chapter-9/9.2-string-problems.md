## Section 9.2: String & Character Problems

String problems include reversing, counting, palindrome checks, and searching. lower() makes this vowel count case-insensitive; the example counts English vowels only.

## Real-World Example

A text tool counts vowels in a student's paragraph.

## Example

```python
def count_vowels(text):
    vowels = set("aeiou")
    return sum(1 for ch in text.lower() if ch in vowels)
print(count_vowels("Codify Learning"))
```

```output
5
```

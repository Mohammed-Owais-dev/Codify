# Chapter 9: Python Problem Solving

## Section 2: String & Character Problems

Strings appear in almost every program: names, messages, passwords, search text. In this section we solve the most common **string problems** using loops, string methods and a few helpful modules.

---

## 1. Quick Reminder of Useful String Tools

| Tool | Purpose |
|------|---------|
| `s[::-1]` | Reverse a string |
| `s.lower()`, `s.upper()` | Change case |
| `s.split()` | Break into a list of words |
| `"".join(list)` | Join items into a string |
| `s.isalpha()`, `s.isdigit()`, `s.isalnum()` | Check character types |
| `s.count(x)` | Count occurrences |
| `s.replace(a, b)` | Replace text |

Strings are **immutable**, so every change creates a new string.

## 2. Reverse a String

**Logic:** Use slicing with a step of `-1`, or build the reverse using a loop.

```python
text = "Python"

print(text[::-1])

rev = ""
for ch in text:
    rev = ch + rev

print(rev)
```

```output
nohtyP
nohtyP
```

## 3. Palindrome String

**Logic:** A palindrome reads the same in both directions. Ignore spaces and letter case for sentences.

```python
def is_palindrome(s):
    cleaned = "".join(ch.lower() for ch in s if ch.isalnum())
    return cleaned == cleaned[::-1]

print(is_palindrome("Madam"))
print(is_palindrome("A man a plan a canal Panama"))
print(is_palindrome("Python"))
```

```output
True
True
False
```

## 4. Count Vowels and Consonants

**Logic:** Check only alphabet letters; a letter in `"aeiou"` is a vowel.

```python
text = "Hello World"

vowels = 0
consonants = 0

for ch in text.lower():
    if ch.isalpha():
        if ch in "aeiou":
            vowels += 1
        else:
            consonants += 1

print("Vowels:", vowels)
print("Consonants:", consonants)
```

```output
Vowels: 3
Consonants: 7
```

## 6. Character Frequency

**Logic:** Store each character as a dictionary key and its count as the value.

```python
text = "banana"
freq = {}

for ch in text:
    freq[ch] = freq.get(ch, 0) + 1

print(freq)
```

```output
{'b': 1, 'a': 3, 'n': 2}
```

The `Counter` class from `collections` does this in one line:

```python
from collections import Counter

print(Counter("banana"))
```

```output
Counter({'a': 3, 'n': 2, 'b': 1})
```

## 10. Anagram Check

**Logic:** Two words are anagrams if their sorted letters are the same.

```python
def is_anagram(a, b):
    a = a.replace(" ", "").lower()
    b = b.replace(" ", "").lower()
    return sorted(a) == sorted(b)

print(is_anagram("listen", "silent"))
print(is_anagram("hello", "world"))
```

```output
True
False
```

## 14. String Compression

**Logic:** Replace repeated characters with the character and its count.

```python
text = "aaabbc"

result = ""
count = 1

for i in range(1, len(text) + 1):
    if i < len(text) and text[i] == text[i - 1]:
        count += 1
    else:
        result += text[i - 1] + str(count)
        count = 1

print(result)
```

```output
a3b2c1
```

## 15. Caesar Cipher

**Logic:** Shift each letter by a fixed number of positions, wrapping around after `z`.

```python
def caesar(text, shift):
    result = ""
    for ch in text:
        if ch.isalpha():
            base = ord("a") if ch.islower() else ord("A")
            result += chr((ord(ch) - base + shift) % 26 + base)
        else:
            result += ch
    return result

secret = caesar("Hello, World!", 3)

print(secret)
print(caesar(secret, -3))
```

```output
Khoor, Zruog!
Hello, World!
```

`ord()` gives a character's number and `chr()` converts a number back to a character.

## 16. Check String Rotation

**Logic:** A string is a rotation of another if it appears inside the **doubled** original.

```python
def is_rotation(a, b):
    return len(a) == len(b) and b in a + a

print(is_rotation("abcd", "cdab"))
print(is_rotation("abcd", "acbd"))
```

```output
True
False
```

## 17. Pangram Check

A **pangram** contains every letter of the alphabet.

```python
import string

def is_pangram(text):
    return set(string.ascii_lowercase) <= set(text.lower())

print(is_pangram("The quick brown fox jumps over the lazy dog"))
print(is_pangram("Hello World"))
```

```output
True
False
```

## 19. Counting Substrings

```python
print("banana".count("an"))
print("banana".count("a"))
print("aaaa".count("aa"))
```

```output

```

`count()` counts **non-overlapping** matches, so `"aaaa".count("aa")` is 2, not 3.

## Real-World Example

A **password strength checker**:

```python
import string

def check_password(pw):
    score = 0

    if len(pw) >= 8:
        score += 1
    if any(ch.isupper() for ch in pw):
        score += 1
    if any(ch.islower() for ch in pw):
        score += 1
    if any(ch.isdigit() for ch in pw):
        score += 1
    if any(ch in string.punctuation for ch in pw):
        score += 1

    if score >= 4:
        level = "Strong"
    elif score >= 3:
        level = "Medium"
    else:
        level = "Weak"

    return pw + " -> " + level + " (" + str(score) + "/5)"

print(check_password("Codify@2026"))
print(check_password("python123"))
print(check_password("python"))
```

```output
Codify@2026 -> Strong (5/5)
python123 -> Medium (3/5)
python -> Weak (1/5)
```

## Common Mistakes

### Trying to Change a String in Place

```python
s = "hello"
s[0] = "H"        # TypeError
```

Create a new string: `s = "H" + s[1:]`.

### Forgetting to Ignore Case

`"Madam"` is not equal to its reverse `"madaM"` unless you use `.lower()` first.

### Counting Spaces and Symbols as Letters

Use `ch.isalpha()` before counting vowels or consonants.

### Forgetting That Methods Return New Strings

```python
text.upper()          # Result is lost
text = text.upper()   # Correct
```

### Using `+=` in Huge Loops

Building very large strings with `+=` is slow. Collect pieces in a list and use `"".join(list)`.

### Index Errors in Compression Programs

Check `i < len(text)` before reading `text[i]`.

---

## Key Points

* Strings are immutable; every change creates a new string.
* Slicing `[::-1]` reverses a string.
* Clean the text with `lower()` and `isalnum()` before palindrome checks.
* Use dictionaries or `Counter` for character and word frequency.
* Sorted letters can compare anagrams.
* `split()` breaks text into words; `"".join()` combines them.
* `ord()` and `chr()` convert between characters and numbers.
* `string.punctuation` and `string.ascii_lowercase` are handy constants.
* `str.count()` counts non-overlapping occurrences.

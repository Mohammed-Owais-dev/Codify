## Section 9.1: Number & Mathematical Programs

Number problems use arithmetic, conditions, and loops. % extracts the last digit and // removes it; abs() lets this example use the magnitude of negative input.

## Real-World Example

A learning app provides digit-sum practice.

## Example

```python
def digit_sum(number):
    number = abs(number)
    total = 0
    while number:
        total += number % 10
        number //= 10
    return total
print(digit_sum(482))
```

```output
14
```

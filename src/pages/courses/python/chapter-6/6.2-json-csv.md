# Chapter 6: Files, Exceptions & Modules

## Section 2: Working with JSON & CSV

Plain text files are simple, but real data is often **structured**. Two very popular formats are **CSV** (tables) and **JSON** (nested data). Python can read and write both easily.

---

## 1. What is CSV?

**CSV** stands for **Comma-Separated Values**. Each line is a row, and commas separate the columns. It opens in Excel and Google Sheets.

```text
name,marks
Asha,85
Ravi,72
Meena,90
```

---

## 2. Writing a CSV File

Import the built-in `csv` module and use `csv.writer()`.

```python
import csv

with open("students.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["name", "marks"])
    writer.writerow(["Asha", 85])
    writer.writerow(["Ravi", 72])
    writer.writerow(["Meena", 90])

print("CSV saved")
```

```output
CSV saved
```

* `writerow()` writes one row from a list.
* `newline=""` prevents blank lines between rows on Windows.

---

## 3. Reading a CSV File

`csv.reader()` gives each row as a **list of strings**.

```python
import csv

with open("students.csv", "r") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
```

```output
['name', 'marks']
['Asha', '85']
['Ravi', '72']
['Meena', '90']
```

Notice that `85` is read as the **string** `'85'`. Convert it with `int()` when you need to calculate.

---

## 4. Writing Many Rows at Once

`writerows()` writes a list of rows in a single call.

```python
import csv

data = [
    ["item", "price"],
    ["Pen", 10],
    ["Book", 50]
]

with open("items.csv", "w", newline="") as file:
    csv.writer(file).writerows(data)

with open("items.csv", "r") as file:
    print(file.read())
```

```output
item,price
Pen,10
Book,50
```

---

## 5. Reading CSV as Dictionaries

`csv.DictReader()` uses the first row as keys, so you can access columns **by name**.

```python
import csv

with open("students.csv", "r") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row["name"], "scored", row["marks"])
```

```output
Asha scored 85
Ravi scored 72
Meena scored 90
```

---

## 6. Writing CSV from Dictionaries

`csv.DictWriter()` writes dictionaries and needs the column names.

```python
import csv

people = [
    {"name": "Asha", "city": "Hyderabad"},
    {"name": "Ravi", "city": "Chennai"}
]

with open("people.csv", "w", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "city"])
    writer.writeheader()
    writer.writerows(people)

with open("people.csv", "r") as file:
    print(file.read())
```

```output
name,city
Asha,Hyderabad
Ravi,Chennai
```

---

## 7. Calculating with CSV Data

```python
import csv

total = 0
count = 0

with open("students.csv", "r") as file:
    reader = csv.DictReader(file)
    for row in reader:
        total += int(row["marks"])
        count += 1

print("Total:", total)
print("Average:", total / count)
```

```output
Total: 247
Average: 82.33333333333333
```

## 8. What is JSON?

**JSON** stands for **JavaScript Object Notation**. It is a text format used by websites, apps and APIs to exchange data. It looks very similar to a Python dictionary.

```text
{
  "name": "Asha",
  "age": 20,
  "skills": ["Python", "SQL"],
  "student": true
}
```

| Python | JSON |
|--------|------|
| `dict` | object `{}` |
| `list`, `tuple` | array `[]` |
| `str` | string |
| `int`, `float` | number |
| `True` / `False` | `true` / `false` |
| `None` | `null` |

---

## 9. Converting Python to a JSON String

`json.dumps()` turns a Python object into a JSON **string**.

```python
import json

person = {"name": "Asha", "age": 20, "student": True, "phone": None}

text = json.dumps(person)
print(text)
print(type(text))
```

```output
{"name": "Asha", "age": 20, "student": true, "phone": null}
<class 'str'>
```

Use `indent` to make it easy to read:

```python
import json

person = {"name": "Asha", "skills": ["Python", "SQL"]}
print(json.dumps(person, indent=2))
```

```output
{
  "name": "Asha",
  "skills": [
    "Python",
    "SQL"
  ]
}
```

---

## 10. Converting a JSON String to Python

`json.loads()` turns a JSON string back into a Python object.

```python
import json

text = '{"name": "Ravi", "age": 22, "skills": ["C", "Python"]}'

data = json.loads(text)
print(data["name"])
print(data["skills"][1])
print(type(data))
```

```output
Ravi
Python
<class 'dict'>
```

> Remember: `dumps` and `loads` have an **s** for **string**.

---

## 11. Saving JSON to a File

`json.dump()` writes JSON straight into a file.

```python
import json

student = {"name": "Meena", "marks": [90, 88, 95]}

with open("student.json", "w") as file:
    json.dump(student, file, indent=4)

print("JSON saved")
```

```output
JSON saved
```

---

## 12. Loading JSON from a File

`json.load()` reads JSON from a file.

```python
import json

with open("student.json", "r") as file:
    data = json.load(file)

print(data["name"])
print("Highest:", max(data["marks"]))
```

```output
Meena
Highest: 95
```

---

## 13. Updating a JSON File

Load the data, change it, then save it again.

```python
import json

with open("student.json", "r") as file:
    data = json.load(file)

data["marks"].append(100)
data["city"] = "Delhi"

with open("student.json", "w") as file:
    json.dump(data, file, indent=4)

print(data)
```

```output
{'name': 'Meena', 'marks': [90, 88, 95, 100], 'city': 'Delhi'}
```

## Quick Comparison

| Feature | CSV | JSON |
|---------|-----|------|
| Shape | Flat table (rows and columns) | Nested data (objects, lists) |
| Best for | Spreadsheets, reports | APIs, settings, complex data |
| Module | `csv` | `json` |
| Data types | Everything is text | Numbers, booleans, null supported |

## Real-World Example

A tiny **contact saver** that stores contacts in JSON and prints them:

```python
import json

contacts = [
    {"name": "Asha", "phone": "9876543210"},
    {"name": "Ravi", "phone": "9123456780"}
]

with open("contacts.json", "w") as file:
    json.dump(contacts, file, indent=2)

with open("contacts.json", "r") as file:
    saved = json.load(file)

for person in saved:
    print(person["name"], "-", person["phone"])
```

```output
Asha - 9876543210
Ravi - 9123456780
```

## Common Mistakes

### Forgetting `newline=""` When Writing CSV

```python
open("data.csv", "w")    # May create blank lines on Windows
```

Use `open("data.csv", "w", newline="")`.

### Treating CSV Numbers as Numbers

```python
print(row[1] + 10)    # TypeError, because row[1] is the string "85"
```

Convert first: `int(row[1]) + 10`.

### Mixing Up `dump` and `dumps`

* `dumps` and `loads` work with **strings**.
* `dump` and `load` work with **files**.

### Using Single Quotes in JSON Text

```python
json.loads("{'name': 'Asha'}")    # JSONDecodeError
```

JSON requires **double quotes**:

```python
json.loads('{"name": "Asha"}')
```

### Forgetting to Import the Module

```python
json.dumps({"a": 1})    # NameError: name 'json' is not defined
```

Add `import json` at the top.

---

## Key Points

* CSV stores table data; use the `csv` module.
* `csv.writer` and `csv.reader` work with lists; `DictWriter` and `DictReader` work with dictionaries.
* CSV values are always read as strings.
* JSON stores nested data and is the standard format for APIs.
* `json.dumps()` and `json.loads()` convert to and from strings.
* `json.dump()` and `json.load()` write to and read from files.
* Use `indent` to format JSON neatly.
* JSON needs double quotes, and Python `True`, `False` and `None` become `true`, `false` and `null`.

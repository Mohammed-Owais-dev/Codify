## Section 6.2: Working with JSON & CSV

JSON represents structured data; CSV represents tabular rows. dumps() serializes an object to JSON text, and loads() parses JSON text.

## Real-World Example

A class register can use CSV and application settings can use JSON.

## Example

```python
import json
student = {"name": "Asha", "marks": 91}
text = json.dumps(student)
restored = json.loads(text)
print(restored["name"], restored["marks"])
```

```output
Asha 91
```

# Chapter 6: Files, Exceptions & Modules

## Section 4: Modules, Packages & import

As programs grow, keeping everything in one file becomes messy. Python lets you split code into **modules** and group modules into **packages**, so you can reuse code and stay organized.

---

## 1. What is a Module?

A **module** is simply a Python file (`.py`) that contains functions, variables or classes you can use in other programs.

Benefits of modules:

* **Reusability**: write once, use in many programs.
* **Organization**: related code stays together.
* **Easy maintenance**: fix a problem in one place.

Python ships with many ready-made modules called the **standard library**, such as `math`, `os`, `random` and `datetime`.

---

## 2. Importing a Module

Use the `import` keyword, then access items with `module.name`.

```python
import math

print(math.sqrt(16))
print(math.pi)
```

```output
4.0
3.141592653589793
```

---

## 3. Useful Functions of the `math` Module

```python
import math

print(math.ceil(4.2))
print(math.floor(4.8))
print(math.pow(2, 3))
print(math.factorial(5))
print(math.gcd(12, 18))
```

```output
5
4
8.0
120
6
```

---

## 4. Importing with an Alias

Use `as` to give a module a shorter name.

```python
import math as m

print(m.sqrt(25))
```

```output
5.0
```

---

## 5. Importing Specific Items

Use `from ... import ...` to bring in only what you need. You can then use the name directly.

```python
from math import sqrt, pi

print(sqrt(49))
print(pi)
```

```output
7.0
3.141592653589793
```

You can also rename an item:

```python
from math import factorial as fact

print(fact(4))
```

```output
24
```

---

## 6. Importing Everything with `*`

```python
from math import *

print(sqrt(9))
print(floor(2.9))
```

```output
3.0
2
```

This is **not recommended** because it can overwrite your own names and makes it unclear where a function came from.

---

## 7. Ways to Import – Comparison

| Style | Example | How to use |
|-------|---------|------------|
| Whole module | `import math` | `math.sqrt(4)` |
| With alias | `import math as m` | `m.sqrt(4)` |
| Specific item | `from math import sqrt` | `sqrt(4)` |
| Everything | `from math import *` | `sqrt(4)` (avoid) |

## 8. Creating Your Own Module

Create a file named `calculator.py`:

```python
# calculator.py

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

PI = 3.14
```

Now create another file in the **same folder** and import it:

```python
# main.py
import calculator

print(calculator.add(10, 5))
print(calculator.subtract(10, 5))
print(calculator.PI)
```

```output
15
5
3.14
```

The module name is the file name **without** `.py`.

## 9. Exploring a Module with `dir()` and `help()`

`dir()` lists everything inside a module.

```python
import math

names = dir(math)
print("sqrt" in names)
print("pi" in names)
```

```output
True
True
```

`help(math.sqrt)` shows documentation for a function.

## 10. The `__name__` Variable

Every module has a built-in variable `__name__`.

* When a file is **run directly**, `__name__` is `"__main__"`.
* When a file is **imported**, `__name__` is the module name.

```python
# greet.py

def hello():
    print("Hello from greet")

if __name__ == "__main__":
    print("Running greet.py directly")
    hello()
```

Running `python greet.py` prints:

```output
Running greet.py directly
Hello from greet
```

If another file does `import greet`, the code inside the `if` block does **not** run. This is why you often see this pattern in Python programs.

---

## 11. Where Does Python Look for Modules?

When you write `import something`, Python searches in this order:

1. The folder of the current program.
2. Folders listed in the `PYTHONPATH` setting.
3. The standard library and installed packages.

You can see the search list with `sys.path`:

```python
import sys

print(type(sys.path))
```

```output
<class 'list'>
```

---

## 12. What is a Package?

A **package** is a **folder** that contains modules. It groups related modules together.

```text
shop/
    __init__.py
    billing.py
    stock.py
```

* `shop` is the package.
* `billing.py` and `stock.py` are modules inside it.
* `__init__.py` marks the folder as a package. It can be empty.

---

## 13. Importing from a Package

```python
# Import a whole module from the package
import shop.billing

# Import a module using from
from shop import stock

# Import one function from a module
from shop.billing import calculate_total
```

Use a dot `.` to go inside a package, as in `package.module.function`.




## 15. Reloading and Avoiding Name Clashes

Never name your own file the same as a standard module. If you create `math.py`, Python imports **your** file instead of the real `math` module and your program breaks. Choose unique names such as `my_math.py`.

## Real-World Example 🌍

A small **utilities module** for a billing program.

First file, `billing.py`:

```python
# billing.py

def add_gst(price, rate=18):
    return price + price * rate / 100

def apply_discount(price, percent):
    return price - price * percent / 100
```

Second file, `main.py`:

```python
from billing import add_gst, apply_discount

price = 1000
discounted = apply_discount(price, 10)
final = add_gst(discounted)

print("After discount:", discounted)
print("Final price:", final)
```

```output
After discount: 900.0
Final price: 1062.0
```

## Common Mistakes

### Forgetting the Module Name

```python
import math
print(sqrt(16))    # NameError
```

Use `math.sqrt(16)`, or `from math import sqrt`.

### Naming Your File Like a Standard Module

A file called `random.py` or `math.py` will hide the real module. Rename it.

### Typing `.py` in the Import

```python
import calculator.py    # Wrong
```

Write `import calculator`.

### Module Not in the Same Folder

If `calculator.py` is in another folder, Python raises `ModuleNotFoundError`. Keep it in the same folder or place it in a package.

### Missing `__init__.py` in Old Packages

Older Python code expects `__init__.py` inside a package folder. Add one to be safe.

---

## Key Points

* A module is a `.py` file; a package is a folder of modules.
* Use `import module` and access items as `module.name`.
* `import ... as ...` creates a shorter alias.
* `from module import name` imports specific items.
* Avoid `from module import *`.
* Create your own module by saving functions in a `.py` file.
* `if __name__ == "__main__":` runs code only when the file is run directly.
* `dir()` lists the contents of a module.
* Python's standard library offers modules like `math`, `os`, `random` and `datetime`.
* Do not name your files the same as standard modules.

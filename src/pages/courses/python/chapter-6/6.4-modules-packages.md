# Chapter 6: Files, Exceptions & Modules

## Section 6.4: Modules, Packages & import

A module is a Python file or importable unit; a package groups modules. import provides access to reusable names, including standard-library modules.

## Real-World Example

A project imports shared calculations rather than copying code.

## Example

```python
import math
print(math.ceil(4.2))
```

```output
5
```

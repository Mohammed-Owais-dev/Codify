## Section 5: pip & Using Python Libraries

Python's standard library is large, but the real power of Python comes from **third-party libraries**, which are packages written by other developers that you can install in seconds using **pip**.

---

## 1. What is a Library?

A **library** is a collection of ready-made modules that solve a specific kind of problem, so you do not have to write everything yourself.

Examples of popular libraries:

| Library | Used for |
|---------|----------|
| `requests` | Calling websites and APIs |
| `numpy` | Fast numerical calculations and arrays |
| `pandas` | Working with tables and data analysis |
| `matplotlib` | Drawing charts and graphs |
| `flask` / `django` | Building websites |
| `pillow` | Editing images |
| `pytest` | Testing code |

---

## 2. What is pip?

**pip** stands for **Pip Installs Packages**. It is Python's package manager. It downloads libraries from the **PyPI** (Python Package Index) website at `pypi.org` and installs them on your computer.

pip comes with Python 3. Check that it works by running these commands in a **terminal** (not inside Python):

```bash
pip --version
```

If `pip` is not recognized, try:

```bash
python -m pip --version
```

On macOS and Linux you may need `pip3` or `python3 -m pip`.

---

## 3. Installing a Library

```bash
pip install requests
```

pip downloads `requests` and any other libraries it depends on.

Install a specific version:

```bash
pip install requests==2.31.0
```

Install several libraries at once:

```bash
pip install numpy pandas matplotlib
```

---

## 4. Other Useful pip Commands

| Command | What it does |
|---------|--------------|
| `pip install name` | Installs a library |
| `pip install --upgrade name` | Updates a library to the latest version |
| `pip uninstall name` | Removes a library |
| `pip list` | Shows all installed libraries |
| `pip show name` | Shows details about one library |
| `pip freeze` | Lists installed libraries with exact versions |
| `pip search` | Not available anymore. Search on `pypi.org` instead |

```bash
pip list
pip show numpy
pip uninstall requests
```

---

## 5. Using an Installed Library

After installation, use `import` just like any other module.

```python
import numpy as np

numbers = np.array([1, 2, 3, 4])

print(numbers)
print(numbers * 2)
print(numbers.mean())
```

```output
[1 2 3 4]
[2 4 6 8]
2.5
```

* `import numpy as np` uses the standard short alias `np`.
* A NumPy array applies the operation to **every element** at once.

## 6. A Quick Look at Other Libraries

### `pandas` – working with tables

```python
import pandas as pd

data = {"name": ["Asha", "Ravi"], "marks": [85, 72]}
table = pd.DataFrame(data)

print(table)
print(table["marks"].mean())
```

```output
   name  marks
0  Asha     85
1  Ravi     72
78.5
```

### `requests` – calling a website

```python
import requests

response = requests.get("https://example.com")
print(response.status_code)
```

```output
200
```

A status code of `200` means the request was successful. This example needs an internet connection.

---

## 7. Installing a Library That is Missing

If you import a library that is not installed, Python shows an error:

```python
import pandas    # if pandas is not installed
```

```output
ModuleNotFoundError: No module named 'pandas'
```

The fix is to install it in the terminal with `pip install pandas`.

---

## 8. Virtual Environments

Different projects may need **different versions** of the same library. A **virtual environment** (venv) is an isolated space for each project, so libraries do not clash.

Create one:

```bash
python -m venv myenv
```

Activate it:

```bash
# Windows
myenv\Scripts\activate

# macOS / Linux
source myenv/bin/activate
```

When active, your terminal shows `(myenv)` and `pip install` adds libraries **only to this environment**.

Leave the environment:

```bash
deactivate
```

---

## 9. Saving Dependencies with `requirements.txt`

A `requirements.txt` file lists all libraries a project needs, so others can install them easily.

Create the file:

```bash
pip freeze > requirements.txt
```

The file looks like this:

```text
numpy==1.26.4
pandas==2.2.1
requests==2.31.0
```

Install everything from the file:

```bash
pip install -r requirements.txt
```

This is how teams share the exact setup of a project.

---

## 10. Choosing a Good Library

Before installing a library, check on PyPI or GitHub:

* It is **actively maintained** (recent updates).
* It has **good documentation**.
* It has many **downloads or stars**.
* Its **name is spelled correctly**. Fake packages with look-alike names exist.

Only install libraries from trusted sources.

---

## 11. Checking an Installed Version in Code

Most libraries store their version in `__version__`.

```python
import numpy as np

print(type(np.__version__))
```

```output
<class 'str'>
```

## Real-World Example 🌍

A small **sales summary** using `pandas` to find total and best-selling product:

```python
import pandas as pd

sales = pd.DataFrame({
    "product": ["Pen", "Book", "Bag"],
    "units": [50, 30, 20],
    "price": [10, 100, 500]
})

sales["revenue"] = sales["units"] * sales["price"]

print(sales)
print("Total revenue:", sales["revenue"].sum())
print("Top product:", sales.loc[sales["revenue"].idxmax(), "product"])
```

```output
  product  units  price  revenue
0     Pen     50     10      500
1    Book     30    100     3000
2     Bag     20    500    10000
Total revenue: 13500
Top product: Bag
```

## Common Mistakes

### Running `pip install` Inside the Python Shell

```python
>>> pip install numpy    # SyntaxError
```

`pip` is a **terminal command**. Run it in the command prompt or terminal, not inside Python.

### Installing into the Wrong Python

If you have several Python versions, `pip` may install to a different one. Use:

```bash
python -m pip install numpy
```

### Wrong Package Name

The install name and import name can differ. For example, `pip install pillow` but `import PIL`, and `pip install scikit-learn` but `import sklearn`.

### Naming Your File Like the Library

A file called `numpy.py` or `requests.py` will hide the real library and cause strange errors. Rename it.

### Skipping Virtual Environments

Installing everything globally leads to version conflicts between projects. Use a venv for each project.

---

## Key Points

* A library is a collection of ready-made modules.
* pip installs libraries from PyPI.
* Run pip commands in the **terminal**, not in Python code.
* `pip install`, `pip uninstall`, `pip list`, `pip show` and `pip freeze` are the main commands.
* After installing, use `import` to access the library.
* A `ModuleNotFoundError` means the library is not installed.
* Virtual environments keep each project's libraries separate.
* `requirements.txt` records dependencies; install them with `pip install -r requirements.txt`.
* Popular libraries include `numpy`, `pandas`, `requests` and `matplotlib`.

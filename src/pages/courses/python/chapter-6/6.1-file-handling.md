# Chapter 6: Files, Exceptions & Modules

## Section 6.1: File Handling

File handling reads or writes persistent data. with open() closes the file automatically; w overwrites, while r reads an existing file.

## Real-World Example

A study tracker saves a note for later.

## Example

```python
with open("study-note.txt", "w", encoding="utf-8") as f:
    f.write("Revise Python loops\n")
with open("study-note.txt", "r", encoding="utf-8") as f:
    print(f.read().strip())
```

```output
Revise Python loops
```

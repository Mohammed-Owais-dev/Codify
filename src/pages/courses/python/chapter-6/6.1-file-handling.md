# Chapter 6: Files, Exceptions & Modules

## Section 1: File Handling

So far, our programs lose all their data when they finish. Files let a program **save** data permanently and **read** it back later.

---

## 1. Why Do We Need Files?

Variables live in memory and disappear when the program ends. A file lives on the disk, so the data stays.

Files are used for:

* Saving user data such as scores, notes and settings.
* Reading large amounts of text without typing it again.
* Sharing data between programs.

---

## 2. Opening a File with `open()`

The built-in `open()` function connects your program to a file.

```python
file = open("notes.txt", "w")
print(type(file))
file.close()
```

```output
<class '_io.TextIOWrapper'>
```

* `"notes.txt"` is the **file name**.
* `"w"` is the **mode**, which tells Python what you want to do.
* `open()` returns a **file object** that you use to read or write.
* `close()` releases the file when you are done.

---

## 3. File Modes

| Mode | Name | Meaning |
|------|------|---------|
| `"r"` | Read | Reads a file. Gives an error if the file does not exist. This is the default. |
| `"w"` | Write | Creates a file or **erases** an existing one, then writes. |
| `"a"` | Append | Adds text at the end without erasing. Creates the file if needed. |
| `"x"` | Create | Creates a new file. Gives an error if it already exists. |
| `"r+"` | Read and write | Opens an existing file for both reading and writing. |

Add `b` for binary files, for example `"rb"` or `"wb"` (used for images and PDFs).

---

## 4. Writing to a File

`write()` puts text into the file.

```python
file = open("notes.txt", "w")
file.write("Hello, Python!\n")
file.write("File handling is easy.\n")
file.close()

print("File written")
```

```output
File written
```

`\n` is the **newline character**. `write()` does not add a new line by itself, so you must add `\n`.

The file `notes.txt` now contains:

```text
Hello, Python!
File handling is easy.
```

---

## 5. Reading the Whole File

`read()` returns the entire file as one string.

```python
file = open("notes.txt", "r")
content = file.read()
print(content)
file.close()
```

```output
Hello, Python!
File handling is easy.
```

You can also read only a few characters:

```python
file = open("notes.txt", "r")
print(file.read(5))
file.close()
```

```output
Hello
```

---

## 6. Reading Line by Line

`readline()` reads **one line** each time it is called.

```python
file = open("notes.txt", "r")
print(file.readline())
print(file.readline())
file.close()
```

```output
Hello, Python!

File handling is easy.
```

The blank line appears because each line already ends with `\n` and `print()` adds another. Use `.strip()` to remove it:

```python
file = open("notes.txt", "r")
print(file.readline().strip())
file.close()
```

```output
Hello, Python!
```

---

## 7. Reading All Lines as a List

`readlines()` returns a **list** where each item is one line.

```python
file = open("notes.txt", "r")
lines = file.readlines()
print(lines)
print(len(lines))
file.close()
```

```output
['Hello, Python!\n', 'File handling is easy.\n']
2
```

---

## 8. Looping Through a File

The best way to read a large file is to loop over the file object directly.

```python
file = open("notes.txt", "r")

for line in file:
    print(line.strip())

file.close()
```

```output
Hello, Python!
File handling is easy.
```

This reads one line at a time, so it uses very little memory.

---

## 9. Appending to a File

Mode `"a"` adds new text at the end and keeps the old content.

```python
file = open("notes.txt", "a")
file.write("This line was appended.\n")
file.close()

file = open("notes.txt", "r")
print(file.read())
file.close()
```

```output
Hello, Python!
File handling is easy.
This line was appended.
```

---

## 10. The `with` Statement (Best Practice)

If your program crashes before `close()`, the file may stay open. The `with` statement **closes the file automatically**, even if an error happens.

```python
with open("notes.txt", "r") as file:
    content = file.read()

print(content)
print("Closed:", file.closed)
```

```output
Hello, Python!
File handling is easy.
This line was appended.

Closed: True
```

Always prefer `with` when working with files.

---

## 11. Writing Many Lines at Once

`writelines()` writes every item of a list. It does **not** add newlines, so include `\n` yourself.

```python
fruits = ["Apple\n", "Banana\n", "Mango\n"]

with open("fruits.txt", "w") as file:
    file.writelines(fruits)

with open("fruits.txt", "r") as file:
    print(file.read())
```

```output
Apple
Banana
Mango
```

---

## 12. Checking Whether a File Exists

Use the `os` module to avoid errors when a file is missing.

```python
import os

if os.path.exists("fruits.txt"):
    print("File found")
else:
    print("File not found")

print(os.path.exists("missing.txt"))
```

```output
File found
False
```

You can also delete a file with `os.remove("fruits.txt")`.

---

## 13. Counting Lines, Words and Characters

```python
lines = 0
words = 0
chars = 0

with open("notes.txt", "r") as file:
    for line in file:
        lines += 1
        words += len(line.split())
        chars += len(line)

print("Lines:", lines)
print("Words:", words)
print("Characters:", chars)
```

```output
Lines: 3
Words: 10
Characters: 62
```

## Real-World Example

A simple **to-do saver** that writes tasks to a file and reads them back with numbers:

```python
tasks = ["Buy milk", "Study Python", "Call mom"]

with open("todo.txt", "w") as file:
    for task in tasks:
        file.write(task + "\n")

with open("todo.txt", "r") as file:
    number = 1
    for line in file:
        print(number, "-", line.strip())
        number += 1
```

```output
1 - Buy milk
2 - Study Python
3 - Call mom
```

Even after the program ends, `todo.txt` still holds the tasks.

## Common Mistakes

### Forgetting to Close the File

```python
file = open("notes.txt", "w")
file.write("Hello")
# file.close() is missing
```

The data may not be saved properly. Use `with`:

```python
with open("notes.txt", "w") as file:
    file.write("Hello")
```

### Using `"w"` When You Wanted to Add Text

Mode `"w"` **erases** the old content. Use `"a"` to add to the end.

### Opening a File That Does Not Exist

```python
file = open("missing.txt", "r")    # FileNotFoundError
```

Check with `os.path.exists()` first, or handle the error (see Section 3).

### Forgetting `\n`

```python
with open("data.txt", "w") as file:
    file.write("One")
    file.write("Two")    # File contains: OneTwo
```

Write `"One\n"` and `"Two\n"` instead.

### Writing a Number Directly

```python
file.write(100)    # TypeError
```

Convert it first: `file.write(str(100))`.

---

## Key Points

* Files store data permanently on the disk.
* `open(name, mode)` returns a file object.
* Modes: `"r"` read, `"w"` write, `"a"` append, `"x"` create.
* `"w"` erases the existing content.
* `read()`, `readline()` and `readlines()` read text in different ways.
* Looping over the file object is the best way to read large files.
* `write()` accepts only strings and does not add a newline.
* Use `with open(...) as file:` so the file closes automatically.
* `os.path.exists()` checks whether a file exists.

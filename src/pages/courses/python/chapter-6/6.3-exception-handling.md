# Chapter 6: Files, Exceptions & Modules

## Section 6.3: Exception Handling

Exceptions report runtime errors. Catch expected exception types with try/except instead of silently hiding unrelated errors.

## Real-World Example

A marks tool handles invalid numeric input.

## Example

```python
try:
    marks = int("eighty")
except ValueError:
    print("Enter marks as a number")
```

```output
Enter marks as a number
```

## Common Mistakes

* Confusing the purpose of the concept with the exact syntax used in the example.
* Assuming one successful run proves the program works for every input.
* Ignoring invalid input, boundary values, or readability when they matter.

## Key Points

* Exceptions report runtime errors.
* Catch expected exception types with try/except instead of silently hiding unrelated errors.
* Test the result with different inputs.
* Use meaningful names and test examples before relying on a program.

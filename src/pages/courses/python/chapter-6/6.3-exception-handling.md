# Chapter 6: Files, Exceptions & Modules

## Section 3: Exception Handling

Even correct programs can fail at run time: a user types text instead of a number, a file is missing, or a number is divided by zero. **Exception handling** lets your program deal with these problems without crashing.

---

## 1. What is an Exception?

An **exception** is an error that happens **while the program is running**. If it is not handled, Python stops the program and shows an error message.

```python
print("Start")
print(10 / 0)
print("End")
```

```output
Start
ZeroDivisionError: division by zero
```

`"End"` is never printed because the program crashed.

---

## 2. Syntax Errors vs Exceptions

| Type | When it happens | Example |
|------|-----------------|---------|
| **Syntax error** | Before the program runs, because the code is written wrongly | `print("Hi"` |
| **Exception** | While the program runs, even if the syntax is correct | `10 / 0` |

Exceptions can be handled. Syntax errors must be fixed in the code.

---

## 3. The `try` and `except` Block

Put risky code in `try`. If an error occurs, Python jumps to `except`.

```python
try:
    print(10 / 0)
except:
    print("Something went wrong")

print("Program continues")
```

```output
Something went wrong
Program continues
```

The program no longer crashes.

---

## 4. Catching a Specific Exception

It is better to catch a **specific** error so you know what went wrong.

```python
try:
    number = int("abc")
except ValueError:
    print("Please enter a valid number")
```

```output
Please enter a valid number
```

---

## 5. Getting the Error Message

Use `as` to store the exception object and print its message.

```python
try:
    print(10 / 0)
except ZeroDivisionError as e:
    print("Error:", e)
```

```output
Error: division by zero
```

---

## 6. Handling Multiple Exceptions

Use several `except` blocks for different errors.

```python
try:
    numbers = [1, 2, 3]
    print(numbers[5])
except ValueError:
    print("Value problem")
except IndexError:
    print("Index is out of range")
```

```output
Index is out of range
```

You can also group errors in a tuple:

```python
try:
    print(int("xyz"))
except (ValueError, TypeError) as e:
    print("Caught:", e)
```

```output
Caught: invalid literal for int() with base 10: 'xyz'
```

---

## 7. Common Built-in Exceptions

| Exception | Cause |
|-----------|-------|
| `ZeroDivisionError` | Dividing by zero |
| `ValueError` | Right type but wrong value, such as `int("abc")` |
| `TypeError` | Wrong type, such as `5 + "a"` |
| `IndexError` | List index out of range |
| `KeyError` | Dictionary key not found |
| `NameError` | Variable is not defined |
| `FileNotFoundError` | File does not exist |
| `AttributeError` | Object has no such attribute or method |
| `ImportError` | Module could not be imported |

## 8. Examples of Common Errors

```python
try:
    student = {"name": "Asha"}
    print(student["age"])
except KeyError as e:
    print("Missing key:", e)
```

```output
Missing key: 'age'
```

```python
try:
    print(5 + "5")
except TypeError as e:
    print("Error:", e)
```

```output
Error: unsupported operand type(s) for +: 'int' and 'str'
```

```python
try:
    with open("missing.txt", "r") as file:
        print(file.read())
except FileNotFoundError as e:
    print("Error:", e)
```

```output
Error: [Errno 2] No such file or directory: 'missing.txt'
```

---

## 9. The `else` Block

The `else` block runs **only if no exception** happened.

```python
try:
    result = 10 / 2
except ZeroDivisionError:
    print("Cannot divide by zero")
else:
    print("Result:", result)
```

```output
Result: 5.0
```

---

## 10. The `finally` Block

The `finally` block runs **always**, whether an error happened or not. It is used for cleanup such as closing files.

```python
try:
    print(10 / 0)
except ZeroDivisionError:
    print("Error caught")
finally:
    print("This always runs")
```

```output
Error caught
This always runs
```

Full structure:

```python
try:
    # risky code
    pass
except SomeError:
    # runs if that error occurs
    pass
else:
    # runs if no error occurs
    pass
finally:
    # always runs
    pass
```

---

## 11. Asking Until the Input is Valid

Combine a loop with `try` and `except` to keep asking.

```python
while True:
    try:
        age = int(input("Enter your age: "))
        break
    except ValueError:
        print("Invalid input. Try again.")

print("Your age is", age)
```

```output
Enter your age: abc
Invalid input. Try again.
Enter your age: 20
Your age is 20
```

---

## 12. Raising Your Own Exception

Use `raise` to create an error yourself when something is wrong.

```python
def check_age(age):
    if age < 18:
        raise ValueError("Age must be 18 or above")
    return "Access granted"

try:
    print(check_age(20))
    print(check_age(15))
except ValueError as e:
    print("Error:", e)
```

```output
Access granted
Error: Age must be 18 or above
```

---

## 13. Custom Exceptions

You can create your own exception class by inheriting from `Exception`.

```python
class LowBalanceError(Exception):
    pass

def withdraw(balance, amount):
    if amount > balance:
        raise LowBalanceError("Not enough balance")
    return balance - amount

try:
    print(withdraw(500, 200))
    print(withdraw(500, 800))
except LowBalanceError as e:
    print("Error:", e)
```

```output
300
Error: Not enough balance
```

---

## 14. Using `assert`

`assert` checks a condition and raises `AssertionError` if it is false. It is helpful while testing.

```python
try:
    marks = -5
    assert marks >= 0, "Marks cannot be negative"
except AssertionError as e:
    print("Error:", e)
```

```output
Error: Marks cannot be negative
```

## Real-World Example 🌍

A **safe calculator** that handles bad input and division by zero:

```python
def divide(a, b):
    try:
        result = a / b
    except ZeroDivisionError:
        return "Cannot divide by zero"
    except TypeError:
        return "Please use numbers only"
    else:
        return result
    finally:
        print("Calculation attempted")

print(divide(10, 2))
print(divide(10, 0))
print(divide(10, "a"))
```

```output
Calculation attempted
5.0
Calculation attempted
Cannot divide by zero
Calculation attempted
Please use numbers only
```

## Common Mistakes

### Using a Bare `except` for Everything

```python
try:
    risky()
except:
    pass    # hides every error, even real bugs
```

Catch specific exceptions and report them.

### Wrong Order of `except` Blocks

```python
try:
    print(10 / 0)
except Exception:
    print("General")
except ZeroDivisionError:    # never reached
    print("Zero")
```

Put **specific** exceptions first and general ones like `Exception` last.

### Putting Too Much Code in `try`

Keep only the risky lines inside `try`, so you know which line caused the error.

### Missing the Colon or Indentation

```python
try
    print("Hi")    # SyntaxError
```

Write `try:` and indent the block.

### Forgetting That `finally` Always Runs

Do not put a `return` inside `finally` unless you intend to override earlier results.

---

## Key Points

* An exception is an error that occurs while the program runs.
* `try` holds risky code and `except` handles the error.
* Catch specific exceptions such as `ValueError` and `ZeroDivisionError`.
* Use `as e` to read the error message.
* `else` runs if no exception happened.
* `finally` runs every time, for cleanup.
* `raise` creates an exception manually.
* Custom exceptions inherit from `Exception`.
* Put specific `except` blocks before general ones.

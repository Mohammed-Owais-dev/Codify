## Section 8.1: Iterators & Generators

An iterator produces values one at a time. A generator uses yield and can reduce memory use by producing values lazily; list() consumes the generator here.

## Real-World Example

A log processor reads records as needed instead of storing everything.

## Example

```python
def even_numbers(limit):
    for n in range(0, limit + 1, 2):
        yield n
print(list(even_numbers(6)))
```

```output
[0, 2, 4, 6]
```

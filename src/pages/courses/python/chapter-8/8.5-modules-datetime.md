## Section 8.5: Dates, Time, Math & Random Modules

datetime handles calendar values, math provides numeric functions, and random provides pseudo-random choices. ceil() rounds upward; isoformat() formats the date.

## Real-World Example

A study planner displays dates and rounds calculated values.

## Example

```python
from datetime import date
import math
print(date(2026, 10, 17).isoformat())
print(math.ceil(4.2))
```

```output
2026-10-17
5
```

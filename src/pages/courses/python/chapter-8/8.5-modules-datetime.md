# Chapter 8: Advanced Python

## Section 5: Dates, Time, Math & Random Modules

Python's standard library includes modules for working with **dates and times**, doing **mathematics** and generating **random values**. These are used in almost every real project, from booking systems to games.

---

## 1. The `datetime` Module

The `datetime` module provides these main classes:

| Class | Stores |
|-------|--------|
| `date` | Year, month, day |
| `time` | Hour, minute, second |
| `datetime` | Date and time together |
| `timedelta` | A **difference** between two dates or times |

---

## 2. Getting the Current Date and Time

```python
from datetime import date, datetime

today = date.today()
now = datetime.now()

print(type(today))
print(type(now))
```

```output
<class 'datetime.date'>
<class 'datetime.datetime'>
```

Printing them shows your actual current date and time, for example `2026-10-18` and `2026-10-18 14:30:45.123456`. To keep outputs predictable, the examples below use fixed dates.

## 5. Day of the Week

`weekday()` returns 0 for Monday up to 6 for Sunday. `isoweekday()` returns 1 for Monday up to 7 for Sunday.

```python
from datetime import date

d = date(2026, 10, 18)

print(d.weekday())
print(d.isoweekday())
print(d.strftime("%A"))
```

```output
6
7
Sunday
```

## 6. Formatting Dates with `strftime()`

`strftime()` converts a date into a **formatted string**.

| Code | Meaning | Example |
|------|---------|---------|
| `%Y` | Year (4 digits) | 2026 |
| `%y` | Year (2 digits) | 26 |
| `%m` | Month number | 10 |
| `%B` | Month name | October |
| `%b` | Short month name | Oct |
| `%d` | Day of the month | 18 |
| `%A` | Weekday name | Sunday |
| `%a` | Short weekday | Sun |
| `%H` | Hour (24-hour) | 14 |
| `%I` | Hour (12-hour) | 02 |
| `%M` | Minute | 30 |
| `%S` | Second | 45 |
| `%p` | AM or PM | PM |

```python
from datetime import datetime

dt = datetime(2026, 10, 18, 14, 30, 45)

print(dt.strftime("%d-%m-%Y"))
print(dt.strftime("%A, %B %d, %Y"))
print(dt.strftime("%I:%M %p"))
```

```output
18-10-2026
Sunday, October 18, 2026
02:30 PM
```

## 7. Converting Text to a Date with `strptime()`

`strptime()` reads a string and builds a `datetime`. You must give the **format** of the text.

```python
from datetime import datetime

text = "25-12-2026"
dt = datetime.strptime(text, "%d-%m-%Y")

print(dt)
print(dt.strftime("%B"))
```

```output
2026-12-25 00:00:00
December
```

Remember: `strftime` = **f**ormat (date to text), `strptime` = **p**arse (text to date).

## 8. Date Arithmetic with `timedelta`

A `timedelta` represents a length of time. Add or subtract it from dates.

```python
from datetime import date, timedelta

d = date(2026, 10, 18)

print(d + timedelta(days=30))
print(d - timedelta(days=18))
print(d + timedelta(weeks=2))
```

```output
2026-11-17
2026-09-30
2026-11-01
```

Subtracting two dates gives a `timedelta`:

```python
from datetime import date

start = date(2026, 10, 18)
end = date(2026, 12, 25)

diff = end - start

print(diff)
print(diff.days)
```

```output
68 days, 0:00:00
68
```

Working with hours and seconds:

```python
from datetime import datetime, timedelta

dt = datetime(2026, 10, 18, 9, 0)

print(dt + timedelta(hours=30))
print(timedelta(hours=2).total_seconds())
```

```output
2026-10-19 15:00:00
7200.0
```

## 11. The `time` Module

The `time` module handles seconds and delays.

```python
import time

print(type(time.time()))

start = time.perf_counter()
time.sleep(0.1)
end = time.perf_counter()

print(end - start >= 0.05)
```

```output
<class 'float'>
True
```

* `time.time()` returns the seconds since January 1, 1970 (the Unix epoch).
* `time.sleep(n)` pauses the program for n seconds.
* `time.perf_counter()` is a precise clock for measuring how long code takes.

## 14. The `random` Module

The `random` module generates pseudo-random values. Outputs differ every run, so the examples below print results that are always the same.

```python
import random

x = random.random()
print(0 <= x < 1)

n = random.randint(1, 6)
print(1 <= n <= 6)

u = random.uniform(1.5, 2.5)
print(1.5 <= u <= 2.5)

r = random.randrange(0, 10, 2)
print(r in [0, 2, 4, 6, 8])
```

```output
True
True
True
True
```

| Function | Purpose |
|----------|---------|
| `random.random()` | Float from 0.0 up to (not including) 1.0 |
| `random.randint(a, b)` | Integer from a to b, **both included** |
| `random.randrange(a, b, step)` | Integer from a up to (not including) b |
| `random.uniform(a, b)` | Random float between a and b |
| `random.choice(seq)` | One random item |
| `random.sample(seq, k)` | k different random items |
| `random.shuffle(list)` | Shuffles a list in place |
| `random.seed(n)` | Makes results repeatable |

---

## 15. Choosing, Sampling and Shuffling

```python
import random

colors = ["red", "green", "blue", "yellow"]

pick = random.choice(colors)
print(pick in colors)

group = random.sample(colors, 2)
print(len(group))
print(len(set(group)))

cards = [1, 2, 3, 4, 5]
random.shuffle(cards)
print(sorted(cards))
```

```output
True
2
2
[1, 2, 3, 4, 5]
```

`shuffle()` changes the list itself and returns nothing. `sample()` never repeats an item.

## 16. Repeatable Results with `seed()`

Setting the same **seed** gives the same sequence every time. This is useful for testing.

```python
import random

random.seed(10)
first = [random.randint(1, 100) for _ in range(3)]

random.seed(10)
second = [random.randint(1, 100) for _ in range(3)]

print(first == second)
```

```output
True
```

## Real-World Example

An **age and countdown calculator** using fixed dates, plus a simple OTP generator:

```python
from datetime import date
import random

today = date(2026, 10, 18)
birthday = date(2000, 5, 15)
event = date(2026, 12, 25)

age = today.year - birthday.year
if (today.month, today.day) < (birthday.month, birthday.day):
    age -= 1

days_left = (event - today).days

print("Age:", age)
print("Days until Christmas:", days_left)
print("Today is", today.strftime("%A"))

otp = "".join(str(random.randint(0, 9)) for _ in range(6))
print("OTP length:", len(otp))
print("All digits:", otp.isdigit())
```

```output
Age: 26
Days until Christmas: 68
Today is Sunday
OTP length: 6
All digits: True
```

In a real program, replace the fixed `today` with `date.today()`.

## Common Mistakes

### Mixing Up `strftime` and `strptime`

* `strftime` turns a date into text.
* `strptime` turns text into a date.

### Wrong Format Code

```python
datetime.strptime("18-10-2026", "%Y-%m-%d")    # ValueError
```

The format must match the text exactly: `"%d-%m-%Y"`.

### Naming Your File `random.py` or `datetime.py`

It hides the real module and causes confusing import errors. Choose a different file name.

### Forgetting That `randint` Includes Both Ends

`random.randint(1, 6)` can return 6, but `random.randrange(1, 6)` cannot.

### Expecting `shuffle()` to Return a List

```python
cards = random.shuffle(cards)    # cards becomes None
```

Call `random.shuffle(cards)` without assigning it.

### Adding a Number Directly to a Date

```python
date(2026, 10, 18) + 5    # TypeError
```

Use `timedelta(days=5)`.

## Key Points

* `datetime` provides `date`, `time`, `datetime` and `timedelta`.
* `date.today()` and `datetime.now()` give the current date and time.
* `strftime()` formats a date as text; `strptime()` parses text into a date.
* Subtracting two dates gives a `timedelta`; use `.days` for the number of days.
* Use `timedelta` to add or subtract time from dates.
* `calendar` helps with leap years and month details.
* `time.sleep()` pauses a program; `time.perf_counter()` measures execution time.
* `math` offers functions such as `sqrt`, `log`, `sin`, `hypot` and constants like `pi` and `e`.
* `random` offers `randint`, `choice`, `sample`, `shuffle`, `uniform` and `seed`.
* `random.seed()` makes random results repeatable.

## Section 8.4: Regular Expressions

Regular expressions describe text patterns. Here [A-Z] matches one uppercase ASCII letter and \d+ matches one or more digits; re.search finds a match within the text.

## Real-World Example

An order tool extracts an identifier from a message.

## Example

```python
import re
text = "Order ID: A123"
match = re.search(r"[A-Z]\d+", text)
print(match.group() if match else "No ID")
```

```output
A123
```

# Chapter 8: Advanced Python

## Section 4: Regular Expressions

A **regular expression** (regex) is a pattern used to search, match, extract or replace text. With one short pattern you can find every email address in a document, validate a phone number or clean messy data.

---

## 1. Why Use Regular Expressions?

Normal string methods like `find()` and `replace()` search for **exact** text. Regex searches for **patterns**, such as "any 10 digits" or "any word that starts with a capital letter".

Python provides regex through the built-in `re` module.

```python
import re

text = "My number is 9876543210"

print(re.search(r"\d+", text).group())
```

```output
9876543210
```

---

## 2. Raw Strings

Always write patterns as **raw strings** by placing `r` before the quotes. This stops Python from treating backslashes as escape characters.

```python
print("a\nb")
print(r"a\nb")
```

```output
a
b
a\nb
```

In a normal string, `\n` becomes a new line. In a raw string, it stays as the two characters `\` and `n`. Patterns such as `\b` also change meaning in a normal string, so use `r"..."` every time.

---

## 3. Basic Pattern Characters

| Pattern | Meaning |
|---------|---------|
| `.` | Any single character except newline |
| `^` | Start of the string |
| `$` | End of the string |
| `*` | Zero or more of the previous item |
| `+` | One or more of the previous item |
| `?` | Zero or one of the previous item |
| `{n}` | Exactly n times |
| `{n,m}` | Between n and m times |
| `[abc]` | Any one of a, b or c |
| `[a-z]` | Any lowercase letter |
| `[^abc]` | Any character **except** a, b, c |
| `a\|b` | Either a or b |
| `( )` | Group |

---

## 4. Special Sequences

| Pattern | Meaning |
|---------|---------|
| `\d` | A digit (0-9) |
| `\D` | A non-digit |
| `\w` | A letter, digit or underscore |
| `\W` | A non-word character |
| `\s` | A whitespace (space, tab, newline) |
| `\S` | A non-whitespace |
| `\b` | A word boundary |

## 5. `re.search()`

`re.search()` looks for the **first match anywhere** in the string. It returns a match object or `None`.

```python
import re

m = re.search(r"\d+", "Order 123 shipped")

print(m)
print(m.group())
print(m.start())
print(m.end())
print(m.span())
```

```output
<re.Match object; span=(6, 9), match='123'>
123
6
9
(6, 9)
```

If nothing matches, the result is `None`:

```python
import re

print(re.search(r"\d+", "No numbers here"))
```

```output
None
```

---

## 6. `re.match()` and `re.fullmatch()`

* `re.match()` checks only the **beginning** of the string.
* `re.fullmatch()` requires the **entire** string to match.

```python
import re

print(bool(re.match(r"Hello", "Hello World")))
print(bool(re.match(r"World", "Hello World")))
print(bool(re.search(r"World", "Hello World")))
print(bool(re.fullmatch(r"\d{3}", "123")))
print(bool(re.fullmatch(r"\d{3}", "1234")))
```

```output
True
False
True
True
False
```

---

## 7. `re.findall()`

`re.findall()` returns **all matches** as a list of strings.

```python
import re

text = "a1 b22 c333"

print(re.findall(r"\d+", text))
print(re.findall(r"[a-z]", text))
```

```output
['1', '22', '333']
['a', 'b', 'c']
```

Extracting hashtags:

```python
import re

post = "Learning #python and #coding today"

print(re.findall(r"#\w+", post))
```

```output
['#python', '#coding']
```

---

## 8. `re.finditer()`

`re.finditer()` gives match objects, so you also get **positions**.

```python
import re

for m in re.finditer(r"\d+", "a1b22"):
    print(m.group(), m.span())
```

```output
1 (1, 2)
22 (3, 5)
```

---

## 9. `re.sub()` – Search and Replace

`re.sub(pattern, replacement, text)` replaces every match.

```python
import re

print(re.sub(r"\d", "#", "a1b2c3"))
print(re.sub(r"\s+", " ", "Too    many     spaces"))
```

```output
a#b#c#
Too many spaces
```

Hiding the digits of a phone number:

```python
import re

print(re.sub(r"\d{6}$", "XXXXXX", "9876543210"))
```

```output
9876XXXXXX
```

---

## 10. `re.split()`

`re.split()` splits a string at every match.

```python
import re

print(re.split(r"[,;]", "a,b;c"))
print(re.split(r"\s+", "Python   is    fun"))
```

```output
['a', 'b', 'c']
['Python', 'is', 'fun']
```

## 11. Quantifiers in Action

```python
import re

print(re.findall(r"ab*", "a ab abb abbb"))
print(re.findall(r"ab+", "a ab abb abbb"))
print(re.findall(r"colou?r", "color colour"))
print(re.findall(r"\d{2,3}", "1 22 333 4444"))
```

```output
['a', 'ab', 'abb', 'abbb']
['ab', 'abb', 'abbb']
['color', 'colour']
['22', '333', '444']
```

The last result shows that `\d{2,3}` takes at most 3 digits, so `4444` gives `444`.

## 12. Character Sets and Anchors

```python
import re

print(re.findall(r"[aeiou]", "education"))

```

```output
['e', 'u', 'a', 'i', 'o']
True
True
['a', 'b']
```

## 13. Groups

Round brackets **capture** parts of a match.

```python
import re

m = re.search(r"(\d{2})-(\d{2})-(\d{4})", "Date: 18-10-2026")

print(m.group())
print(m.group(1))
print(m.group(2))
print(m.group(3))
print(m.groups())
```

```output
18-10-2026
18
10
2026
('18', '10', '2026')
```

Give groups **names** for readability:

```python
import re

m = re.search(r"(?P<day>\d{2})-(?P<month>\d{2})-(?P<year>\d{4})", "18-10-2026")

print(m.group("day"))
print(m.groupdict())
```

```output
18
{'day': '18', 'month': '10', 'year': '2026'}
```

With groups, `findall()` returns **tuples** of the groups:

```python
import re

text = "asha@gmail.com ravi@yahoo.com"

print(re.findall(r"(\w+)@(\w+)\.com", text))
```

```output
[('asha', 'gmail'), ('ravi', 'yahoo')]
```

## 14. Greedy vs Non-Greedy Matching

By default, quantifiers are **greedy**: they match as much as possible. Add `?` to make them **non-greedy**.

```python
import re

html = "<a><b>"

print(re.findall(r"<.+>", html))
print(re.findall(r"<.+?>", html))
```

```output
['<a><b>']
['<a>', '<b>']
```

---

## 15. Flags

Flags change how the pattern behaves.

| Flag | Meaning |
|------|---------|
| `re.IGNORECASE` or `re.I` | Ignore upper and lower case |
| `re.MULTILINE` or `re.M` | `^` and `$` match at each line |
| `re.DOTALL` or `re.S` | `.` also matches a newline |

```python
import re

print(re.findall(r"python", "Python PYTHON python", re.IGNORECASE))
```

```output
['Python', 'PYTHON', 'python']
```

---

## 16. Compiling a Pattern

If you use a pattern many times, compile it once with `re.compile()`.

```python
import re

pattern = re.compile(r"\d+")

print(pattern.findall("1 and 22 and 333"))
print(pattern.sub("N", "Room 5 and Room 12"))
```

```output
['1', '22', '333']
Room N and Room N
```

## 17. Validating Input

```python
import re

def is_valid_phone(number):
    return bool(re.fullmatch(r"\d{10}", number))

def is_valid_email(email):
    return bool(re.fullmatch(r"[\w.]+@\w+\.[a-z]{2,}", email))

print(is_valid_phone("9876543210"))
print(is_valid_phone("98765"))
print(is_valid_email("asha@gmail.com"))
print(is_valid_email("asha@gmail"))
```

```output
True
False
True
False
```

This email pattern is simple. Real email rules are more complex.

## Real-World Example

**Extracting contact details** from a block of text:

```python
import re

text = "Contact: asha@mail.com, ravi@site.org or call 9876543210."

emails = re.findall(r"[\w.]+@[\w.]+\.\w+", text)
phones = re.findall(r"\b\d{10}\b", text)

print("Emails:", emails)
print("Phones:", phones)
```

```output
Emails: ['asha@mail.com', 'ravi@site.org']
Phones: ['9876543210']
```

## Common Mistakes

### Forgetting the Raw String

```python
re.findall("\bword\b", text)    # \b becomes a backspace character
```

Write `r"\bword\b"`.

### Using `match()` When You Meant `search()`

`match()` only checks the **start** of the string. Use `search()` to look anywhere.

### Calling `.group()` on `None`

```python
re.search(r"\d", "abc").group()    # AttributeError
```

Check first:

```python
m = re.search(r"\d", "abc")
if m:
    print(m.group())
```

### Forgetting to Escape Special Characters

To match a literal dot, write `\.`. A plain `.` matches **any** character.

### Surprise from Groups in `findall()`

With groups, `findall()` returns the groups, not the whole match. Use non-capturing groups `(?:...)` when you only need grouping.

---

## Key Points

* Regex is a pattern language for searching and editing text; use the `re` module.
* Write patterns as raw strings: `r"..."`.
* `search()` finds the first match anywhere; `match()` checks the start; `fullmatch()` checks the whole string.
* `findall()` returns all matches; `finditer()` returns match objects with positions.
* `sub()` replaces matches; `split()` splits at matches.
* Important symbols: `\d`, `\w`, `\s`, `.`, `^`, `$`, `*`, `+`, `?`, `{n,m}`, `[ ]`.
* Parentheses create groups; use `group()` and `groups()` to read them.
* Add `?` after a quantifier for non-greedy matching.
* Flags like `re.IGNORECASE` change matching behavior.
* `re.compile()` saves time when a pattern is reused.

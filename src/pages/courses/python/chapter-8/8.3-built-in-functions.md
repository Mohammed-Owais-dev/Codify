## Section 8.3: map(), filter(), reduce(), zip() & enumerate()

map transforms values; filter keeps matching values; reduce combines values. zip pairs iterables and enumerate adds indexes. In Python 3, map/filter return iterators.

## Real-World Example

A score report transforms, filters, and totals marks.

## Example

```python
from functools import reduce
marks = [30, 60, 90]
print(list(map(lambda n: n + 5, marks)))
print(list(filter(lambda n: n >= 40, marks)))
print(reduce(lambda a, b: a + b, marks))
```

```output
[35, 65, 95]
[60, 90]
180
```

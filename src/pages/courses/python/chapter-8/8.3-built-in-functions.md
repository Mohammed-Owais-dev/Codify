# Chapter 8: Advanced Python

## Section 3: map(), filter(), reduce(), zip() & enumerate()

Python has powerful built-in functions that process whole collections without writing explicit loops. They make code shorter and often easier to read. In this section we learn five of the most useful ones.

---

## 1. Quick Overview

| Function | Purpose |
|----------|---------|
| `map()` | Applies a function to **every** item |
| `filter()` | Keeps only items that **pass a test** |
| `reduce()` | Combines all items into **one value** |
| `zip()` | Pairs items from **several** collections |
| `enumerate()` | Gives each item along with its **index** |

---

## 2. Quick Reminder: `lambda`

A **lambda** is a small, nameless function written in one line. It is often used with `map()` and `filter()`.

```python
square = lambda x: x * x

print(square(5))
```

```output
25
```

---

## 3. The `map()` Function

`map(function, iterable)` applies the function to **each item** and returns a map object (an iterator). Convert it with `list()` to see the values.

```python
numbers = [1, 2, 3, 4]

result = map(lambda x: x * 2, numbers)

print(type(result))
print(list(result))
```

```output
<class 'map'>
[2, 4, 6, 8]
```

---

## 4. `map()` with a Normal Function

```python
def to_celsius(f):
    return round((f - 32) * 5 / 9, 1)

fahrenheit = [32, 50, 98.6, 212]

print(list(map(to_celsius, fahrenheit)))
```

```output
[0.0, 10.0, 37.0, 100.0]
```

A very common use is converting types:

```python
text = ["10", "20", "30"]

numbers = list(map(int, text))
print(numbers)
print(sum(numbers))
```

```output
[10, 20, 30]
60
```

---

## 5. `map()` with Multiple Iterables

If the function takes two parameters, give `map()` two iterables.

```python
a = [1, 2, 3]
b = [10, 20, 30]

print(list(map(lambda x, y: x + y, a, b)))
```

```output
[11, 22, 33]
```

---

## 6. The `filter()` Function

`filter(function, iterable)` keeps only items for which the function returns `True`.

```python
numbers = [1, 2, 3, 4, 5, 6, 7, 8]

evens = filter(lambda x: x % 2 == 0, numbers)

print(list(evens))
```

```output
[2, 4, 6, 8]
```

Filtering words by length:

```python
words = ["cat", "elephant", "dog", "giraffe"]

long_words = list(filter(lambda w: len(w) > 3, words))
print(long_words)
```

```output
['elephant', 'giraffe']
```

If the function is `None`, `filter()` removes all **falsy** values (0, empty strings, `None`):

```python
data = [0, 1, "", "Hi", None, 5]

print(list(filter(None, data)))
```

```output
[1, 'Hi', 5]
```

---

## 7. The `reduce()` Function

`reduce()` repeatedly combines items into a **single result**. It lives in the `functools` module, so import it first.

`reduce(function, iterable)` works like this for `[1, 2, 3, 4]` with addition:

```text
(((1 + 2) + 3) + 4) = 10
```

```python
from functools import reduce

numbers = [1, 2, 3, 4]

total = reduce(lambda a, b: a + b, numbers)
print(total)
```

```output
10
```

---

## 8. More `reduce()` Examples

Finding the product and the largest number:

```python
from functools import reduce

numbers = [2, 3, 4, 5]

print(reduce(lambda a, b: a * b, numbers))
print(reduce(lambda a, b: a if a > b else b, numbers))
```

```output
120
5
```

You can pass a starting value as the third argument:

```python
from functools import reduce

print(reduce(lambda a, b: a + b, [1, 2, 3], 100))
```

```output
106
```

For simple sums, the built-in `sum()` is clearer. Use `reduce()` for custom combinations.

## 9. The `zip()` Function

`zip()` pairs up items from two or more iterables, position by position.

```python
names = ["Asha", "Ravi", "Meena"]
marks = [85, 72, 90]

pairs = zip(names, marks)

print(list(pairs))
```

```output
[('Asha', 85), ('Ravi', 72), ('Meena', 90)]
```

Looping through zipped data is very common:

```python
names = ["Asha", "Ravi", "Meena"]
marks = [85, 72, 90]

for name, mark in zip(names, marks):
    print(name, "scored", mark)
```

```output
Asha scored 85
Ravi scored 72
Meena scored 90
```

---

## 10. `zip()` with Different Lengths

`zip()` stops at the **shortest** collection.

```python
a = [1, 2, 3, 4]
b = ["x", "y"]

print(list(zip(a, b)))
```

```output
[(1, 'x'), (2, 'y')]
```

---

## 11. Creating Dictionaries and Unzipping

```python
keys = ["name", "age", "city"]
values = ["Asha", 20, "Hyderabad"]

person = dict(zip(keys, values))
print(person)
```

```output
{'name': 'Asha', 'age': 20, 'city': 'Hyderabad'}
```

Use `*` to **unzip** pairs back into separate groups:

```python
pairs = [(1, "a"), (2, "b"), (3, "c")]

numbers, letters = zip(*pairs)

print(numbers)
print(letters)
```

```output
(1, 2, 3)
('a', 'b', 'c')
```

## 12. The `enumerate()` Function

`enumerate()` gives both the **index** and the **value** while looping. It replaces the old `range(len(list))` pattern.

```python
fruits = ["Apple", "Banana", "Mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
```

```output
0 Apple
1 Banana
2 Mango
```

Use `start` to begin counting from another number:

```python
fruits = ["Apple", "Banana", "Mango"]

for number, fruit in enumerate(fruits, start=1):
    print(number, "-", fruit)
```

```output
1 - Apple
2 - Banana
3 - Mango
```

---

## 13. Finding Positions with `enumerate()`

```python
marks = [45, 82, 67, 91, 30]

for i, m in enumerate(marks):
    if m > 80:
        print("Index", i, "has", m)
```

```output
Index 1 has 82
Index 3 has 91
```

Converting to a list shows the pairs:

```python
print(list(enumerate(["a", "b"])))
```

```output
[(0, 'a'), (1, 'b')]
```

---

## 14. Combining These Functions

These tools work well together. Here we take the squares of only the even numbers and then add them:

```python
from functools import reduce

numbers = [1, 2, 3, 4, 5, 6]

evens = filter(lambda x: x % 2 == 0, numbers)
squares = map(lambda x: x * x, evens)
total = reduce(lambda a, b: a + b, squares)

print(total)
```

```output
56
```

That is `4 + 16 + 36 = 56`.

A list comprehension can do the same job and is often preferred:

```python
numbers = [1, 2, 3, 4, 5, 6]

print(sum(x * x for x in numbers if x % 2 == 0))
```

```output
56
```

## 15. Related Helpers: `sorted()`, `any()` and `all()`

```python
marks = [45, 82, 67, 91]

print(sorted(marks, reverse=True))
print(any(m > 90 for m in marks))
print(all(m >= 40 for m in marks))
```

```output
[91, 82, 67, 45]
True
True
```

* `any()` is `True` if **at least one** item is true.
* `all()` is `True` only if **every** item is true.

## Real-World Example 🌍

A **result report** that uses `zip`, `enumerate`, `map` and `filter` together:

```python
names = ["Asha", "Ravi", "Meena", "Kiran"]
marks = [85, 32, 90, 55]

print("Rank list:")
data = sorted(zip(names, marks), key=lambda p: p[1], reverse=True)

for rank, (name, mark) in enumerate(data, start=1):
    print(rank, name, mark)

passed = list(filter(lambda p: p[1] >= 40, zip(names, marks)))
print("Passed:", [p[0] for p in passed])

grades = list(map(lambda m: "A" if m >= 80 else "B", marks))
print("Grades:", grades)
```

```output
Rank list:
1 Meena 90
2 Asha 85
3 Kiran 55
4 Ravi 32
Passed: ['Asha', 'Meena', 'Kiran']
Grades: ['A', 'B', 'A', 'B']
```

## Common Mistakes

### Printing a `map` or `filter` Object Directly

```python
print(map(str, [1, 2]))     # <map object at 0x...>
```

Wrap it with `list()` to see the values.

### Forgetting to Import `reduce`

```python
reduce(lambda a, b: a + b, [1, 2])    # NameError
```

Add `from functools import reduce`.

### Using the Result Twice

A `map`, `filter` or `zip` object is an iterator, so it is used up after one pass.

```python
z = zip([1, 2], [3, 4])
print(list(z))
print(list(z))      # []
```

### Expecting `zip()` to Keep Extra Items

Extra items in the longer list are dropped silently.

### Using `filter()` with a Function That Returns the Item

`filter()` checks truthiness. A function returning the item itself keeps or drops items depending on whether they are truthy.

---

## Key Points

* `map(func, iterable)` applies a function to every item.
* `filter(func, iterable)` keeps items where the function returns `True`.
* `reduce(func, iterable)` combines items into one value; import it from `functools`.
* `zip()` pairs items from multiple iterables and stops at the shortest.
* `enumerate()` gives index and value; use `start=` to change the first index.
* `map`, `filter`, `zip` and `enumerate` return iterators; use `list()` to see them.
* `lambda` functions pair naturally with `map`, `filter` and `reduce`.
* List comprehensions and generator expressions are often an alternative.

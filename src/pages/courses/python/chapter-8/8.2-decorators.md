# Chapter 8: Advanced Python

## Section 2: Decorators

A **decorator** adds new behavior to an existing function **without changing its code**. Decorators are used everywhere in real Python projects, from web frameworks to logging and security checks.

---

## 1. Functions are First-Class Objects

In Python, functions are objects. You can store them in variables, pass them as arguments and return them from other functions. Decorators depend on this idea.

```python
def greet():
    return "Hello"

say = greet

print(say())
print(say == greet)
```

```output
Hello
True
```

Note that `greet` (no brackets) is the function itself, while `greet()` calls it.

---

## 2. Passing a Function as an Argument

```python
def shout(func):
    return func().upper()

def hello():
    return "hello"

print(shout(hello))
```

```output
HELLO
```

---

## 3. Functions Inside Functions

A function can be defined **inside** another function and even be returned.

```python
def outer():
    def inner():
        return "Inside inner"
    return inner

f = outer()
print(f())
```

```output
Inside inner
```

`outer()` returns the `inner` function, which we then call.

---

## 4. Closures

An inner function can remember variables from the outer function, even after the outer function has finished. This is called a **closure**.

```python
def multiplier(n):
    def multiply(x):
        return x * n
    return multiply

double = multiplier(2)
triple = multiplier(3)

print(double(10))
print(triple(10))
```

```output
20
30
```

---

## 5. Writing Your First Decorator

A decorator is a function that:

1. Takes a function as input.
2. Defines a **wrapper** function that adds behavior.
3. Returns the wrapper.

```python
def my_decorator(func):
    def wrapper():
        print("Before the function")
        func()
        print("After the function")
    return wrapper

def say_hello():
    print("Hello!")

say_hello = my_decorator(say_hello)
say_hello()
```

```output
Before the function
Hello!
After the function
```

---

## 6. The `@` Syntax

Python provides the `@` symbol as a shortcut. `@my_decorator` above a function means `func = my_decorator(func)`.

```python
def my_decorator(func):
    def wrapper():
        print("Before the function")
        func()
        print("After the function")
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")

say_hello()
```

```output
Before the function
Hello!
After the function
```

---

## 7. Decorating Functions with Arguments

Use `*args` and `**kwargs` in the wrapper so it works with any function.

```python
def log_call(func):
    def wrapper(*args, **kwargs):
        print("Calling", func.__name__, "with", args)
        return func(*args, **kwargs)
    return wrapper

@log_call
def add(a, b):
    return a + b

print(add(3, 4))
```

```output
Calling add with (3, 4)
7
```

Always **return** the result of the original function inside the wrapper.

## 8. Preserving Function Details with `functools.wraps`

Without help, the decorated function loses its original name and documentation.

```python
def my_decorator(func):
    def wrapper():
        return func()
    return wrapper

@my_decorator
def hello():
    return "Hi"

print(hello.__name__)
```

```output
wrapper
```

Use `@wraps(func)` to fix this:

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)
    def wrapper():
        return func()
    return wrapper

@my_decorator
def hello():
    return "Hi"

print(hello.__name__)
```

```output
hello
```

Good practice: always use `@wraps` inside your decorators.

## 9. A Practical Decorator – Checking Input

```python
from functools import wraps

def positive_only(func):
    @wraps(func)
    def wrapper(n):
        if n < 0:
            return "Negative numbers not allowed"
        return func(n)
    return wrapper

@positive_only
def square_root(n):
    return n ** 0.5

print(square_root(25))
print(square_root(-4))
```

```output
5.0
Negative numbers not allowed
```

## 10. A Practical Decorator – Counting Calls

```python
from functools import wraps

def count_calls(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        wrapper.calls += 1
        print("Call number", wrapper.calls)
        return func(*args, **kwargs)
    wrapper.calls = 0
    return wrapper

@count_calls
def greet(name):
    return "Hello " + name

print(greet("Asha"))
print(greet("Ravi"))
```

```output
Call number 1
Hello Asha
Call number 2
Hello Ravi
```

## 11. A Practical Decorator – Measuring Time

```python
import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        end = time.perf_counter()
        print(func.__name__, "finished")
        return result
    return wrapper

@timer
def total(n):
    return sum(range(n))

print(total(1000))
```

```output
total finished
499500
```

A real timer would print `end - start`. The number changes every run, so it is left out here.

## 12. Decorators with Arguments

To give a decorator its own settings, add **one more outer function**.

```python
from functools import wraps

def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(3)
def hello():
    print("Hello!")

hello()
```

```output
Hello!
Hello!
Hello!
```

Order of work: `repeat(3)` returns `decorator`, which is then applied to `hello`.

## 13. Using Multiple Decorators

Decorators are applied from the **bottom up** (the one closest to the function runs first).

```python
def bold(func):
    def wrapper():
        return "<b>" + func() + "</b>"
    return wrapper

def italic(func):
    def wrapper():
        return "<i>" + func() + "</i>"
    return wrapper

@bold
@italic
def text():
    return "Hello"

print(text())
```

```output
<b><i>Hello</i></b>
```

`italic` wraps the function first, then `bold` wraps the result.

## 14. Built-in Decorators You Already Know

| Decorator | Purpose |
|-----------|---------|
| `@staticmethod` | A method with no `self` or `cls` |
| `@classmethod` | A method that receives `cls` |
| `@property` | Use a method like an attribute |
| `@abstractmethod` | Forces child classes to implement a method |
| `@functools.lru_cache` | Remembers results of earlier calls |

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(30))
```

```output
832040
```

`lru_cache` stores earlier answers, so this runs very fast.

## Real-World Example 🌍

A **login check** decorator that protects functions from users who are not logged in:

```python
from functools import wraps

def login_required(func):
    @wraps(func)
    def wrapper(user, *args, **kwargs):
        if not user.get("logged_in"):
            return "Access denied. Please log in."
        return func(user, *args, **kwargs)
    return wrapper

@login_required
def view_profile(user):
    return "Welcome, " + user["name"]

asha = {"name": "Asha", "logged_in": True}
guest = {"name": "Guest", "logged_in": False}

print(view_profile(asha))
print(view_profile(guest))
```

```output
Welcome, Asha
Access denied. Please log in.
```

The same decorator can protect any number of functions with one line each.

## Common Mistakes

### Calling the Function Inside the Decorator

```python
@my_decorator()      # Wrong for a simple decorator
def hello(): ...
```

Write `@my_decorator` without brackets, unless the decorator takes arguments.

### Forgetting to Return the Wrapper

```python
def my_decorator(func):
    def wrapper():
        func()
    # missing: return wrapper
```

Without `return wrapper`, the decorated name becomes `None`.

### Forgetting to Return the Result

```python
def wrapper(*args, **kwargs):
    func(*args, **kwargs)       # result is lost
```

Use `return func(*args, **kwargs)`.

### Not Accepting Arguments

If the wrapper has no `*args, **kwargs`, decorating a function with parameters causes a `TypeError`.

### Forgetting `@wraps`

The function name and docstring change to those of `wrapper`, which confuses debugging.

---

## Key Points

* Functions are objects: they can be assigned, passed and returned.
* An inner function can remember outer variables (closure).
* A decorator takes a function, wraps it and returns a new function.
* `@decorator` is shortcut for `func = decorator(func)`.
* Use `*args` and `**kwargs` so the wrapper accepts any arguments.
* Use `@wraps(func)` to keep the original name and docs.
* A decorator with arguments needs an extra outer function.
* Multiple decorators are applied from the bottom up.
* Common uses: logging, timing, access control and caching.

# Chapter 8: Advanced Python

## Section 8.2: Decorators

A decorator takes a function and returns a callable with added behavior. Reusable decorators often use *args, **kwargs, and functools.wraps.

## Real-World Example

A report function logs when it starts.

## Example

```python
def announce(func):
    def wrapper():
        print("Starting")
        return func()
    return wrapper
@announce
def report():
    print("Report ready")
report()
```

```output
Starting
Report ready
```

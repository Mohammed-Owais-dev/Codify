# Chapter 4: The CSS Box Model

## Section 2: Width, Height and Sizing

Now that you know the parts of a box, let us control its **size**. CSS has several properties for width and height. Some set exact sizes, and some let the box grow or shrink with the screen. In this lesson you will learn how to size boxes properly for both small phones and big monitors.

---

## 1. The width and height Properties

`width` sets the width of the **content area**, and `height` sets its height.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    width: 280px;
    height: 100px;
    background-color: #bae6fd;
    border: 3px solid #0284c7;
  }
</style>

<div class="box">A box 280px wide and 100px tall</div>
```

Values can be lengths (`px`, `rem`), percentages (`%`), or the keyword `auto`.

---

## 2. The Default: auto

If you do not set a size, the browser uses `auto`.

| Element | `width: auto` | `height: auto` |
| ------- | ------------- | -------------- |
| Block element (`div`, `p`) | Fills the full width of its parent | Grows to fit its content |
| Inline element (`span`, `a`) | Width of its content | Height of its content |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .auto {
    background-color: #fde68a;
    padding: 10px;
  }
</style>

<div class="auto">I have no width or height, so I fill the page width and are only as tall as my text.</div>
```

Most of the time, **letting the height be auto is best**, because the box then adapts to its content.

---

## 3. Percentage Sizes

A percentage width is based on the width of the **parent** element.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .parent {
    width: 400px;
    background-color: #e2e8f0;
    padding: 10px;
  }
  .half {
    width: 50%;
    background-color: #fb923c;
    color: white;
    padding: 6px 0;
    margin-bottom: 6px;
    text-align: center;
  }
  .full {
    width: 100%;
    background-color: #0ea5e9;
    color: white;
    padding: 6px 0;
    text-align: center;
  }
</style>

<div class="parent">
  <div class="half">50% of the parent</div>
  <div class="full">100% of the parent</div>
</div>
```

The `parent` content area is 400px, so `50%` is 200px. If the parent changes size, the child follows. This is the basis of flexible layouts.

**Note:** A percentage `height` only works if the parent has a **fixed height**. If the parent's height is `auto`, the percentage has nothing to measure.

---

## 4. Viewport Units: vw and vh

The **viewport** is the visible area of the browser window.

| Unit | Meaning |
| ---- | ------- |
| `1vw` | 1% of the viewport width |
| `1vh` | 1% of the viewport height |
| `100vw` | The full viewport width |
| `100vh` | The full viewport height |

```css
.hero {
  height: 100vh;        /* as tall as the screen */
  width: 100%;
}
```

Full-screen sections use `100vh`. Be careful with `100vw`, because it includes the width of the scroll bar and can cause a small horizontal scroll. For widths, `100%` is usually safer.

---

## 5. min-width and max-width

Sometimes you want a box to be flexible but within **limits**.

| Property | Meaning |
| -------- | ------- |
| `min-width` | The box can never be narrower than this |
| `max-width` | The box can never be wider than this |
| `min-height` | The box can never be shorter than this |
| `max-height` | The box can never be taller than this |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .container {
    max-width: 420px;
    background-color: #dcfce7;
    border: 2px solid #16a34a;
    padding: 14px;
    margin: 0 auto;
  }
</style>

<div class="container">
  This container is as wide as the screen allows, but never wider than 420px. Resize the preview and see how it behaves on small screens.
</div>
```

`max-width` is better than `width` for content boxes. On a wide screen the box stops at the limit, and on a small screen it shrinks to fit instead of causing a horizontal scroll bar.

---

## 6. min-height for Flexible Boxes

A fixed `height` can cause text to spill out of a box when the content gets longer. Use `min-height` so the box has a minimum size but can still grow.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .fixed {
    height: 40px;
    background-color: #fecaca;
    width: 220px;
    margin-bottom: 40px;
  }
  .flexible {
    min-height: 40px;
    background-color: #bbf7d0;
    width: 220px;
  }
</style>

<div class="fixed">Fixed height: this long text overflows the red box.</div>
<div class="flexible">Min height: this long text makes the green box grow.</div>
```

---

## 7. Making Images Responsive

Images have a natural size. A big image can be wider than a phone screen. This short rule keeps an image inside its container:

```css
img {
  max-width: 100%;
  height: auto;
}
```

* `max-width: 100%` stops the image from growing bigger than its parent.
* `height: auto` keeps the correct shape (aspect ratio) when the width shrinks.

```html
<style>
  .holder {
    width: 240px;
    border: 2px dashed #94a3b8;
    padding: 6px;
  }
  .holder svg {
    max-width: 100%;
    height: auto;
  }
</style>

<div class="holder">
  <svg width="600" height="300" viewBox="0 0 600 300">
    <rect width="600" height="300" fill="#7c3aed"/>
    <text x="300" y="165" font-size="60" text-anchor="middle" fill="white" font-family="Arial">600 x 300</text>
  </svg>
</div>
```

The graphic is 600px wide, but it shrinks to fit the 240px container and keeps its shape.

---

## 8. The aspect-ratio Property

`aspect-ratio` keeps a box in a fixed shape, such as a video (16:9) or a square (1:1), while the width changes.

```html
<style>
  .video {
    width: 100%;
    max-width: 320px;
    aspect-ratio: 16 / 9;
    background-color: #0f172a;
    color: white;
    font-family: Arial, sans-serif;
    display: flex;
    align-items: center;
    justify-content: center;
  }
  .square {
    width: 120px;
    aspect-ratio: 1 / 1;
    background-color: #f97316;
    margin-top: 12px;
  }
</style>

<div class="video">16 : 9</div>
<div class="square"></div>
```

You only set the width, and the browser calculates the height.

---

## 9. Content-Based Sizes

Special keywords let a box size itself from its content.

| Value | Meaning |
| ----- | ------- |
| `fit-content` | As wide as the content, but not more than the available space |
| `max-content` | As wide as the content needs on one line |
| `min-content` | As narrow as possible, such as the longest word |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .tag {
    width: fit-content;
    background-color: #fde68a;
    padding: 8px 16px;
    border-radius: 6px;
  }
</style>

<div class="tag">I only take the width I need</div>
<p>A normal div would have filled the whole line.</p>
```

## 10. Using calc() for Mixed Units

The `calc()` function lets you do math with different units.

```html
<style>
  body {
    font-family: Arial, sans-serif;
    margin: 0;
  }
  .sidebar {
    width: 200px;
    background-color: #1e293b;
    color: white;
    padding: 10px 0;
    text-align: center;
  }
  .main {
    width: calc(100% - 200px);
    background-color: #bae6fd;
    padding: 10px 0;
    text-align: center;
  }
</style>

<div class="sidebar">Sidebar: 200px</div>
<div class="main">Main: 100% minus 200px</div>
```

Spaces are required around `+` and `-` inside `calc()`.

## Real-World Example

A flexible page container and responsive cards that use sizing rules together:

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
    padding: 16px;
  }
  .page {
    width: 100%;
    max-width: 500px;
    margin: 0 auto;
  }
  .banner {
    width: 100%;
    aspect-ratio: 16 / 6;
    background-color: #0ea5e9;
    color: white;
    display: flex;
    align-items: center;
    justify-content: center;
    font-size: 22px;
    border-radius: 10px;
  }
  .card {
    width: 100%;
    min-height: 80px;
    background-color: white;
    border-radius: 10px;
    padding: 14px;
    margin-top: 12px;
    box-shadow: 0 2px 6px rgba(0, 0, 0, 0.1);
  }
</style>

<div class="page">
  <div class="banner">Welcome back!</div>
  <div class="card">Card one. The card grows if I get more text.</div>
  <div class="card">Card two</div>
</div>
```

The `.page` never gets wider than 500px, but shrinks on a small screen. The banner keeps its shape with `aspect-ratio`, and the cards use `min-height` so they can grow.

## Common Mistakes

### Fixing the Height of Text Boxes

```css
.card { height: 100px; }       /* text may spill out when it grows */
.card { min-height: 100px; }   /* safer */
```

### Using a Fixed width Where max-width Is Better

```css
.container { width: 1000px; }      /* sideways scroll on phones */
.container { max-width: 1000px; }  /* shrinks on small screens */
```

### Percentage Height Without a Parent Height

```css
.parent { }                       /* height: auto */
.child { height: 50%; }           /* has no effect */
```

### Forgetting height: auto on Images

```css
img { width: 300px; height: 300px; }   /* may stretch or squash the picture */
img { max-width: 100%; height: auto; } /* keeps its shape */
```

### Missing Spaces in calc()

```text
width: calc(100%-200px);     /* invalid */
width: calc(100% - 200px);   /* correct */
```

### Setting Width and Height on Inline Elements

```css
span { width: 200px; }      /* ignored, spans are inline by default */
```

---

## Key Points

* `width` and `height` set the size of the **content area** by default.
* `auto` is the default: block elements fill the width, and height grows with the content.
* **Percentage** widths are based on the parent's width. A percentage height needs a parent with a set height.
* `vw` and `vh` are percentages of the viewport width and height.
* Use `max-width` and `min-height` to keep boxes flexible but within limits.
* `img { max-width: 100%; height: auto; }` keeps images responsive.
* `aspect-ratio` keeps a box in a fixed shape.
* `fit-content` makes a box only as wide as it needs to be.
* `calc()` mixes different units, and needs spaces around `+` and `-`.

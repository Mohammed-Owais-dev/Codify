# Chapter 4: The CSS Box Model

## Section 1: Understanding the Box Model

Here is one of the most important ideas in CSS: **every element on a webpage is a rectangular box**. Headings, paragraphs, images, buttons and even the page itself are all boxes. If you understand how these boxes are built, you can control spacing and size with confidence. This lesson introduces the **box model**.

---

## 1. Everything Is a Box

Even a round button or a circular photo is a rectangle underneath. Look at this page where we draw a visible border around each element.

```html
<style>
  * {
    border: 2px solid #3b82f6;
    margin: 6px;
    padding: 4px;
  }
  body {
    font-family: Arial, sans-serif;
  }
</style>

<h2>A heading</h2>
<p>A paragraph with a <em>word in italics</em> and a <strong>bold word</strong>.</p>
<button>A button</button>
```

Every element, including the inline words `em` and `strong`, is shown inside a rectangle. CSS places and sizes these boxes.

---

## 2. The Four Layers of a Box

Every box is made of **four layers**, from the inside to the outside:

| Layer | What it is |
| ----- | ---------- |
| **Content** | The text, image or other content itself |
| **Padding** | The space **between the content and the border**, inside the box |
| **Border** | A line around the padding and content |
| **Margin** | The space **outside** the border that separates this box from others |

```text
+---------------------------------------------+
|                  MARGIN                     |
|   +-------------------------------------+   |
|   |              BORDER                 |   |
|   |   +-----------------------------+   |   |
|   |   |          PADDING            |   |   |
|   |   |   +---------------------+   |   |   |
|   |   |   |       CONTENT       |   |   |   |
|   |   |   +---------------------+   |   |   |
|   |   +-----------------------------+   |   |
|   +-------------------------------------+   |
+---------------------------------------------+
```

Think of a framed photo on a wall. The **photo** is the content, the **mat** around it is the padding, the **frame** is the border, and the **empty wall space** to the next picture is the margin.

---

## 3. Seeing the Layers

This example gives each layer a different look so you can spot them.

```html
<style>
  body {
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  .box {
    width: 200px;
    padding: 24px;
    border: 8px solid #1e3a8a;
    margin: 30px;
    background-color: #bfdbfe;
  }
</style>

<div class="box">Content area</div>
```

* The light blue color fills the **content and padding** (the background reaches under the padding).
* The dark blue band around it is the **border**.
* The gray space outside the border is the **margin**. It is always transparent, so the page background shows through.

---

## 4. Content

The content area is where your text or image sits. Its size is set by `width` and `height`, or by the content itself when you do not set them. You will learn more about sizing in the next lesson.

---

## 5. Padding

**Padding** is the breathing room inside the box around the content. The element's background color or image extends into the padding.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .no-padding {
    background-color: #fde68a;
    margin-bottom: 14px;
  }
  .with-padding {
    background-color: #fde68a;
    padding: 20px;
  }
</style>

<p class="no-padding">No padding: the text touches the edge of the colored box.</p>
<p class="with-padding">With padding: the text has room inside the colored box.</p>
```

---

## 6. Border

The **border** goes around the padding. It has a width, a style and a color.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .framed {
    border: 4px solid #be123c;
    padding: 16px;
    width: 260px;
  }
</style>

<div class="framed">This box has a 4px solid red border.</div>
```

---

## 7. Margin

**Margin** is the empty space **outside** the border. It pushes other boxes away. Margin has no background color, because it is outside the box.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .card {
    background-color: #bbf7d0;
    padding: 12px;
    margin-bottom: 30px;
    width: 240px;
  }
</style>

<div class="card">First card</div>
<div class="card">Second card, 30px below the first</div>
```

---

## 8. How Big Is a Box? (Total Size)

By default, `width` and `height` set only the **content** size. Padding and border are **added** on top.

```text
Total width  = content width + left padding + right padding
               + left border + right border

Example:
  width: 200px
  padding: 20px  (left and right: 40px)
  border: 5px    (left and right: 10px)

  Total width = 200 + 40 + 10 = 250px
```

Margin is not included in the box's own size, but it adds to the space the box takes on the page: 250px + the left and right margins.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .a {
    width: 200px;
    padding: 20px;
    border: 5px solid #7c3aed;
    background-color: #ede9fe;
    margin-bottom: 14px;
  }
  .b {
    width: 250px;
    background-color: #fde68a;
    padding: 4px 0;
    text-align: center;
  }
</style>

<div class="a">Content width 200px, total width 250px</div>
<div class="b">A 250px reference bar</div>
```

The purple box and the yellow bar have the same width on the screen, because 200 + 40 + 10 = 250. In Lesson 4.5 you will learn a property, `box-sizing`, that makes this easier.

## 9. Block Boxes and Inline Boxes

Boxes behave in two main ways:

| | Block boxes | Inline boxes |
| - | ----------- | ------------ |
| Starts on a new line | **Yes** | No, flows with the text |
| Width | Fills the available width by default | Only as wide as its content |
| Width and height properties | Work | **Ignored** |
| Top and bottom margin | Work | Do not push other lines |
| Examples | `div`, `p`, `h1`, `ul`, `section` | `span`, `a`, `strong`, `em` |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  div {
    background-color: #bfdbfe;
    margin-bottom: 8px;
  }
  span {
    background-color: #fecaca;
    width: 300px;
    margin: 20px;
    padding: 8px;
  }
</style>

<div>A block box fills the full width of the page.</div>
<div>Another block starts on a new line.</div>
<p>Some text with <span>an inline span</span> inside the line. The span ignores its width, and its top and bottom margin do nothing.</p>
```

The `display` property can change how a box behaves. You will study it in Chapter 6.

## 10. Inspecting the Box Model in DevTools

Every browser can show the box model of any element.

1. Right-click an element and choose **Inspect**.
2. Look at the **Computed** panel (or the **Layout** tab).
3. You will see a diagram with colored layers for margin, border, padding and content, and the exact numbers.
4. Hover over the diagram and the layer is highlighted on the page.

This is the fastest way to find out why spacing is not what you expected.

## Real-World Example 🌍

A pricing card showing all four box layers in a real design:

```html
<style>
  body {
    font-family: Arial, sans-serif;
    background-color: #e2e8f0;
  }
  .plan {
    width: 240px;
    background-color: white;
    padding: 24px;
    border: 2px solid #38bdf8;
    margin: 20px;
  }
  .plan h2 {
    margin: 0 0 8px;
    color: #0f172a;
  }
  .plan .price {
    font-size: 32px;
    font-weight: bold;
    color: #0284c7;
    margin: 0 0 12px;
  }
  .plan ul {
    margin: 0 0 16px;
    padding-left: 20px;
    color: #475569;
  }
  .plan button {
    background-color: #0284c7;
    color: white;
    border: none;
    padding: 10px 20px;
  }
</style>

<div class="plan">
  <h2>Starter</h2>
  <p class="price">$9</p>
  <ul>
    <li>5 courses</li>
    <li>Quizzes</li>
    <li>Certificate</li>
  </ul>
  <button>Choose plan</button>
</div>
```

The card has 24px of **padding** inside, a 2px blue **border**, and 20px of **margin** around it. The `h2`, price and list also have their own margins to control the spacing between them.

## Common Mistakes

### Confusing Margin and Padding

```text
Padding = space INSIDE the border (the background color shows here)
Margin  = space OUTSIDE the border (always transparent)
```

### Forgetting That Padding and Border Add to the Width

```text
.box {
  width: 100%;
  padding: 20px;       /* the box becomes 100% + 40px wide and sticks out */
}
```

You will see how `box-sizing` fixes this in Lesson 4.5.

### Expecting Width and Height to Work on Inline Elements

```text
span { width: 200px; height: 50px; }    /* ignored */
```

### Expecting Margin to Have a Background Color

```text
.box { margin: 20px; background-color: yellow; }
```

The yellow color fills the content, padding and border, but never the margin.

### Not Using DevTools

```text
When spacing looks wrong, inspect the element and read its box model diagram.
It shows exactly which layer causes the problem.
```

---

## Key Points

* Every element is a **rectangular box**.
* A box has four layers: **content**, **padding**, **border** and **margin**.
* **Padding** is inside the border, and the background color extends into it.
* **Margin** is outside the border, and it is always transparent.
* By default, total width = content width + padding + border.
* **Block** boxes start on a new line and fill the width. **Inline** boxes flow within text and ignore width and height.
* Use browser **DevTools** to see the box model of any element.

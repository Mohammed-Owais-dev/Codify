# Chapter 4: The CSS Box Model

## Section 3: Margin and Padding

Every box has space **inside** it and space **outside** it. **Padding** is the space inside the box, between the content and the border. **Margin** is the space outside the box, between the box and other boxes. In this lesson you will learn how to use both to make clean and comfortable layouts.

---

## 1. Padding: Space Inside the Box

`padding` adds space between the content and the border. The background color of the box also fills the padding area.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    background-color: #bae6fd;
    border: 3px solid #0284c7;
    padding: 20px;
  }
</style>

<div class="box">This text has 20px of padding on all four sides.</div>
```

You can also set padding for one side at a time.

| Property | Meaning |
| -------- | ------- |
| `padding-top` | Space above the content |
| `padding-right` | Space on the right of the content |
| `padding-bottom` | Space below the content |
| `padding-left` | Space on the left of the content |

---

## 2. Margin: Space Outside the Box

`margin` adds space outside the border. Margin is always transparent, so the background color does not fill it.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    background-color: #fde68a;
    border: 3px solid #d97706;
    padding: 10px;
    margin-bottom: 30px;
  }
</style>

<div class="box">First box</div>
<div class="box">Second box, 30px below the first</div>
```

Margin also has four side properties: `margin-top`, `margin-right`, `margin-bottom` and `margin-left`.

---

## 3. The Shorthand Rules

You can write all four sides in one line. The order is always **clockwise**: top, right, bottom, left.

| Shorthand | Meaning |
| --------- | ------- |
| `padding: 10px;` | All four sides are 10px |
| `padding: 10px 20px;` | Top and bottom 10px, left and right 20px |
| `padding: 10px 20px 30px;` | Top 10px, left and right 20px, bottom 30px |
| `padding: 10px 20px 30px 40px;` | Top, right, bottom, left |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .one {
    padding: 10px 40px;
    background-color: #dcfce7;
    border: 2px solid #16a34a;
    margin-bottom: 14px;
  }
  .two {
    padding: 5px 10px 25px 60px;
    background-color: #fce7f3;
    border: 2px solid #db2777;
  }
</style>

<div class="one">Two values: vertical 10px, horizontal 40px</div>
<div class="two">Four values: top, right, bottom, left</div>
```

The same shorthand works for `margin`.

---

## 4. Centering a Box with margin: auto

When a block box has a set width, `margin: 0 auto` centers it horizontally. The browser shares the free space equally between the left and right margins.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .centered {
    width: 260px;
    margin: 0 auto;
    background-color: #e9d5ff;
    border: 3px solid #7c3aed;
    padding: 12px;
    text-align: center;
  }
</style>

<div class="centered">I am in the center</div>
```

This only works if the box has a `width` (or `max-width`). A block box with `width: auto` already fills the line, so there is nothing to center.

---

## 5. Negative Margins

Margins can be negative. A negative margin pulls the box in the opposite direction.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .a {
    background-color: #bae6fd;
    padding: 12px;
  }
  .b {
    background-color: #fb923c;
    color: white;
    padding: 12px;
    margin-top: -10px;
    margin-left: 30px;
  }
</style>

<div class="a">Box A</div>
<div class="b">Box B moves up and overlaps A</div>
```

Use negative margins carefully. They can make boxes overlap and are harder to understand later.

---

## 6. Margin Collapse

When the **top and bottom margins of two blocks touch**, they do not add up. They **collapse** into one margin, and the larger one wins.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .top {
    background-color: #fecaca;
    margin-bottom: 40px;
    padding: 8px;
  }
  .bottom {
    background-color: #bbf7d0;
    margin-top: 20px;
    padding: 8px;
  }
</style>

<div class="top">Bottom margin: 40px</div>
<div class="bottom">Top margin: 20px</div>
```

The gap between the boxes is **40px**, not 60px. Remember:

* Margin collapse happens only **vertically** (top and bottom).
* It does not happen with left and right margins.
* It does not happen inside flex or grid containers.

---

## 7. Margin vs Padding: Which One to Use?

| Question | Use |
| -------- | --- |
| Do I want space between two boxes? | `margin` |
| Do I want space between the text and the border? | `padding` |
| Do I want the background color to cover the space? | `padding` |
| Do I want to center a box? | `margin: 0 auto` |

---

## 8. Padding and Box Size

By default, padding is **added** to the width and height. A box with `width: 200px` and `padding: 20px` is really 240px wide (200 + 20 + 20), not counting the border.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .plain {
    width: 200px;
    background-color: #bae6fd;
    margin-bottom: 10px;
  }
  .padded {
    width: 200px;
    padding: 20px;
    background-color: #fde68a;
  }
</style>

<div class="plain">Width 200px, no padding</div>
<div class="padded">Width 200px, padding 20px, so it looks 240px wide</div>
```

You will learn how to control this with `box-sizing` in lesson 4.5.

## Real-World Example

A simple card with comfortable spacing:

```html
<style>
  body {
    margin: 0;
    padding: 16px;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  .card {
    max-width: 320px;
    margin: 0 auto 16px auto;
    padding: 18px 20px;
    background-color: white;
    border-radius: 10px;
    box-shadow: 0 2px 6px rgba(0, 0, 0, 0.1);
  }
  .card h3 {
    margin: 0 0 8px 0;
  }
  .card p {
    margin: 0;
    color: #475569;
  }
</style>

<div class="card">
  <h3>Welcome</h3>
  <p>Padding gives the text room, and margin keeps the cards apart.</p>
</div>
<div class="card">
  <h3>Second Card</h3>
  <p>The cards are centered with margin auto.</p>
</div>
```

## Common Mistakes

### Using Margin When You Need Padding

```css
.button { margin: 10px; }    /* the button does not get bigger inside */
.button { padding: 10px; }   /* more space around the button text */
```

### Centering Without a Width

```css
.box { margin: 0 auto; }                 /* nothing to center */
.box { width: 300px; margin: 0 auto; }   /* centered */
```

### Wrong Shorthand Order

```text
padding: 10px 20px 30px 40px;   /* top right bottom left, clockwise */
```

### Expecting Margins to Add Up

```css
.a { margin-bottom: 40px; }
.b { margin-top: 20px; }     /* the gap is 40px, not 60px */
```

### Adding Padding Without Checking the Width

```css
.box { width: 100%; padding: 20px; }   /* wider than the parent */
```

---

## Key Points

* **Padding** is space inside the box. **Margin** is space outside the box.
* The background color fills the padding but not the margin.
* Shorthand order is clockwise: **top, right, bottom, left**.
* `margin: 0 auto` centers a block box that has a width.
* Vertical margins between blocks can **collapse** into the larger one.
* Margins can be negative, but use them carefully.
* Padding is added to the width and height by default.

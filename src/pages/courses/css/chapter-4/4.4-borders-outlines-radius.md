# Chapter 4: The CSS Box Model

## Section 4: Borders, Outlines and Border Radius

The **border** is the line that goes around the padding and content of a box. In this lesson you will learn how to style borders, use outlines for focus effects, and round the corners of a box with `border-radius`.

---

## 1. The border Shorthand

A border needs three things: a **width**, a **style** and a **color**. You can write all three in one line.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    border: 4px solid #0284c7;
    background-color: #e0f2fe;
    padding: 14px;
  }
</style>

<div class="box">A box with a 4px solid blue border</div>
```

The order is `width style color`. If you forget the **style**, no border appears, because the default style is `none`.

---

## 2. Border Styles

The `border-style` property changes the look of the line.

| Value | Look |
| ----- | ---- |
| `solid` | A single line |
| `dashed` | A line made of dashes |
| `dotted` | A line made of dots |
| `double` | Two lines |
| `groove`, `ridge` | 3D-looking lines |
| `none` | No border |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  div {
    padding: 8px;
    margin-bottom: 10px;
    border-width: 4px;
    border-color: #7c3aed;
  }
  .s1 { border-style: solid; }
  .s2 { border-style: dashed; }
  .s3 { border-style: dotted; }
  .s4 { border-style: double; }
</style>

<div class="s1">solid</div>
<div class="s2">dashed</div>
<div class="s3">dotted</div>
<div class="s4">double</div>
```

---

## 3. Borders on One Side

You can style each side on its own.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .note {
    border-left: 6px solid #f97316;
    background-color: #fff7ed;
    padding: 12px 16px;
    margin-bottom: 14px;
  }
  .title {
    border-bottom: 3px solid #0ea5e9;
    padding-bottom: 6px;
    width: fit-content;
  }
</style>

<div class="note">A note with an orange left border</div>
<div class="title">Heading with an underline</div>
```

The side properties are `border-top`, `border-right`, `border-bottom` and `border-left`. You can also use `border-width`, `border-style` and `border-color` with up to four values, in the same clockwise order as padding.

---

## 4. border-radius: Rounded Corners

`border-radius` rounds the corners of a box.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    width: 140px;
    padding: 20px 10px;
    text-align: center;
    color: white;
    margin-bottom: 12px;
  }
  .small {
    background-color: #0ea5e9;
    border-radius: 6px;
  }
  .big {
    background-color: #16a34a;
    border-radius: 24px;
  }
</style>

<div class="box small">6px</div>
<div class="box big">24px</div>
```

You can set each corner on its own with up to four values: top-left, top-right, bottom-right, bottom-left.

```text
.shape { border-radius: 20px 0 20px 0; }
```

---

## 5. Circles and Pills

* A **circle** needs a square box and `border-radius: 50%`.
* A **pill** (a rounded button) uses a very large radius such as `999px`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .circle {
    width: 90px;
    height: 90px;
    background-color: #f43f5e;
    border-radius: 50%;
    margin-bottom: 14px;
  }
  .pill {
    display: inline-block;
    background-color: #1e293b;
    color: white;
    padding: 8px 22px;
    border-radius: 999px;
  }
</style>

<div class="circle"></div>
<span class="pill">Pill button</span>
```

---

## 6. Outlines

An **outline** looks like a border, but it is drawn **outside** the border and takes **no space** in the layout. It does not change the size of the box.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    border: 2px solid #94a3b8;
    padding: 14px;
    outline: 4px solid #fbbf24;
    outline-offset: 6px;
    width: 240px;
    margin: 12px;
  }
</style>

<div class="box">A box with an outline</div>
```

* `outline-offset` sets the gap between the border and the outline.
* Outlines are mostly used for **focus** states, so keyboard users can see which element is active.

| Feature | `border` | `outline` |
| ------- | -------- | --------- |
| Takes space in the layout | Yes | No |
| Can be set per side | Yes | No |
| Follows `border-radius` | Yes | Yes (in modern browsers) |
| Main use | Design | Focus and highlight |

---

## 7. Do Not Remove the Focus Outline

Some beginners write `outline: none` to remove the focus ring. This makes a page hard to use with a keyboard. If you remove it, always add a clear replacement.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  input {
    padding: 8px 10px;
    border: 2px solid #94a3b8;
    border-radius: 6px;
    outline: none;
  }
  input:focus {
    border-color: #0284c7;
    box-shadow: 0 0 0 3px rgba(2, 132, 199, 0.3);
  }
</style>

<input type="text" placeholder="Click here">
```

## Common Mistakes

### Forgetting the Border Style

```text
.box { border: 3px #0284c7; }          /* no border appears */
.box { border: 3px solid #0284c7; }    /* correct */
```

### Using border-radius on a Non-Square Box for a Circle

```text
.dot { width: 100px; height: 50px; border-radius: 50%; }   /* an oval */
.dot { width: 100px; height: 100px; border-radius: 50%; }  /* a circle */
```

### Removing the Focus Outline Without a Replacement

```text
button:focus { outline: none; }    /* keyboard users get lost */
```

### Thinking an Outline Changes the Box Size

```text
.box { outline: 10px solid red; }  /* the layout does not move */
```

---

## Key Points

* A border needs **width, style and color**. Without a style there is no border.
* Use `border-top`, `border-right`, `border-bottom` and `border-left` for single sides.
* `border-radius` rounds corners. Use `50%` on a square for a circle.
* An **outline** is drawn outside the border and takes no space.
* `outline-offset` moves the outline away from the border.
* Never remove the focus outline without adding a clear replacement.

- [ ] An outline can only be red
- [ ] A border cannot have a color
- [x] An outline takes no space in the layout

- [ ] `outline-gap`
- [x] `outline-offset`
- [ ] `border-spacing`
- [ ] `margin`

5. Why is `outline: none` a bad idea without a replacement?

- [ ] It makes the page load slower
- [ ] It removes the border

# Chapter 4: The CSS Box Model

## Section 5: box-sizing and Overflow

Two small details of the box model cause many layout problems for beginners: how the browser **calculates the size** of a box, and what happens when the content is **too big** for its box. In this lesson you will learn `box-sizing` and the `overflow` property.

---

## 1. The Problem with the Default Size

By default, `width` and `height` set only the **content area**. Padding and border are added **on top**.

```text
total width = width + padding-left + padding-right + border-left + border-right
```

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .parent {
    width: 300px;
    background-color: #e2e8f0;
    padding: 6px 0;
  }
  .child {
    width: 100%;
    padding: 20px;
    border: 5px solid #0284c7;
    background-color: #bae6fd;
  }
</style>

<div class="parent">
  <div class="child">I am 100% wide, but I stick out of my parent.</div>
</div>
```

The child is 300px for the content, plus 40px of padding, plus 10px of border. It is **350px** wide and goes outside the parent.

---

## 2. The box-sizing Property

`box-sizing` tells the browser how to calculate the size.

| Value | Meaning |
| ----- | ------- |
| `content-box` | Default. `width` is the content only. Padding and border are added. |
| `border-box` | `width` includes the content, padding and border. |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .parent {
    width: 300px;
    background-color: #e2e8f0;
    padding: 6px 0;
  }
  .child {
    box-sizing: border-box;
    width: 100%;
    padding: 20px;
    border: 5px solid #16a34a;
    background-color: #bbf7d0;
  }
</style>

<div class="parent">
  <div class="child">Now I fit inside my parent.</div>
</div>
```

With `border-box`, the box stays exactly 300px wide. The content area shrinks to make room for the padding and border.

---

## 3. The Universal border-box Reset

Most developers use `border-box` for every element. Put this at the top of your CSS file:

```text
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

Now a `width: 200px` box is always 200px wide, no matter how much padding or border you add. This makes layouts much easier to plan.

---

## 4. What Is Overflow?

**Overflow** happens when the content is bigger than its box. This usually happens when the box has a fixed `height`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    width: 240px;
    height: 60px;
    border: 3px solid #dc2626;
    background-color: #fef2f2;
    padding: 6px;
  }
</style>

<div class="box">This text is too long for the box, so it spills out of the bottom edge of the red border.</div>
```

By default, the extra content is **visible** and flows outside the box.

---

## 5. The overflow Property

The `overflow` property decides what to do with the extra content.

| Value | What happens |
| ----- | ------------ |
| `visible` | Default. Extra content is shown outside the box. |
| `hidden` | Extra content is cut off and cannot be seen. |
| `scroll` | Scroll bars are always shown. |
| `auto` | Scroll bars appear only when needed. |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    width: 200px;
    height: 70px;
    border: 2px solid #475569;
    padding: 6px;
    margin-bottom: 14px;
    background-color: #f8fafc;
  }
  .hidden { overflow: hidden; }
  .auto { overflow: auto; }
</style>

<div class="box hidden">hidden: the extra text of this long paragraph is cut off and cannot be seen at all.</div>
<div class="box auto">auto: the extra text of this long paragraph can be reached with a scroll bar when needed.</div>
```

**Tip:** `overflow: auto` is usually the best choice for content areas, because the user can still reach all of the content.

---

## 6. overflow-x and overflow-y

You can control each direction on its own.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .strip {
    width: 260px;
    overflow-x: auto;
    overflow-y: hidden;
    white-space: nowrap;
    border: 2px solid #7c3aed;
    padding: 10px;
    background-color: #f5f3ff;
  }
</style>

<div class="strip">This single line of text is very long, so you can scroll sideways to read it all.</div>
```

* `overflow-x` controls the horizontal direction.
* `overflow-y` controls the vertical direction.

---

## 7. Cutting Long Text with an Ellipsis

Three properties together show `...` at the end of one long line of text.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .title {
    width: 220px;
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
    border: 2px solid #0ea5e9;
    padding: 8px;
  }
</style>

<div class="title">This is a very long title that will not fit in the box</div>
```

* `white-space: nowrap` keeps the text on one line.
* `overflow: hidden` hides the extra text.
* `text-overflow: ellipsis` adds the `...`.

---

## 8. Overflow and Layout Helpers

`overflow: hidden` also clips children with rounded corners, so images and colored areas do not poke out of a card.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .card {
    width: 240px;
    border-radius: 16px;
    overflow: hidden;
    border: 2px solid #cbd5e1;
  }
  .card .top {
    height: 70px;
    background-color: #f97316;
  }
  .card .text {
    padding: 12px;
  }
</style>

<div class="card">
  <div class="top"></div>
  <div class="text">The orange top follows the rounded corners.</div>
</div>
```

## Real-World Example 🌍

A chat box with a fixed height that scrolls, and a border-box reset:

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 16px;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  .chat {
    width: 100%;
    max-width: 320px;
    height: 180px;
    margin: 0 auto;
    padding: 12px;
    overflow-y: auto;
    background-color: white;
    border: 2px solid #0ea5e9;
    border-radius: 12px;
  }
  .msg {
    background-color: #e0f2fe;
    padding: 8px 12px;
    border-radius: 8px;
    margin-bottom: 8px;
  }
</style>

<div class="chat">
  <div class="msg">Hi there!</div>
  <div class="msg">Welcome to the class.</div>
  <div class="msg">Today we learn about overflow.</div>
  <div class="msg">The box scrolls when messages grow.</div>
  <div class="msg">Try scrolling this box.</div>
</div>
```

## Common Mistakes

### Forgetting That Padding Adds to the Width

```text
.box { width: 100%; padding: 20px; }                          /* too wide */
.box { box-sizing: border-box; width: 100%; padding: 20px; }  /* fits */
```

### Using overflow: hidden Without Thinking

```text
.content { overflow: hidden; }   /* important content may be cut off */
.content { overflow: auto; }     /* the user can still scroll to it */
```

### Forgetting white-space: nowrap in the Ellipsis Trick

```text
.title { overflow: hidden; text-overflow: ellipsis; }   /* text wraps, no ellipsis */
```

### Using a Fixed Height Everywhere

```text
.card { height: 100px; overflow: hidden; }    /* text can be lost */
.card { min-height: 100px; }                  /* the card can grow */
```

---

## Key Points

* By default (`content-box`), padding and border are **added** to the width and height.
* `box-sizing: border-box` includes padding and border inside the width and height.
* Use `*, *::before, *::after { box-sizing: border-box; }` on almost every project.
* **Overflow** happens when content is bigger than its box.
* `overflow` can be `visible`, `hidden`, `scroll` or `auto`.
* `overflow-x` and `overflow-y` control each direction.
* `white-space: nowrap`, `overflow: hidden` and `text-overflow: ellipsis` make a one-line ellipsis.

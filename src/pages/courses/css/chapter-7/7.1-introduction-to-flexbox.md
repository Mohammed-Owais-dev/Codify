# Chapter 7: Flexbox and CSS Grid

## Section 1: Introduction to Flexbox

**Flexbox** (Flexible Box Layout) is a modern way to arrange items in a row or a column. It makes it easy to align, space and size boxes without floats or tricky margins. In this lesson you will learn the basic idea, the two main parts of a flex layout and your first flex properties.

---

## 1. Why Flexbox?

Before Flexbox, even simple tasks were hard: centering a box, making equal-height columns, or spacing items evenly. Flexbox solves these problems with a few lines of CSS.

Flexbox is best for **one-dimensional** layouts, which means a single row **or** a single column at a time. Examples: navigation bars, button groups, card rows and form lines.

---

## 2. Flex Container and Flex Items

A flex layout has two parts.

| Part | Meaning |
| ---- | ------- |
| **Flex container** | The parent element. It has `display: flex`. |
| **Flex items** | The direct children of the container. |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .container {
    display: flex;
    background-color: #e2e8f0;
    border: 2px solid #64748b;
    padding: 8px;
  }
  .item {
    background-color: #38bdf8;
    color: white;
    padding: 16px 24px;
    margin: 4px;
    border-radius: 6px;
  }
</style>

<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

Just adding `display: flex` puts the three block items **side by side** in a row. Only the **direct children** become flex items. Grandchildren are not affected.

---

## 3. The Two Axes

Flexbox works with two axes.

| Axis | Meaning |
| ---- | ------- |
| **Main axis** | The direction in which items are placed. By default it goes left to right. |
| **Cross axis** | The direction across the main axis. By default it goes top to bottom. |

Keep these two axes in mind. Almost every flex property works along one of them.

---

## 4. display: flex vs inline-flex

| Value | Behavior |
| ----- | -------- |
| `display: flex` | The container is a block and fills the width |
| `display: inline-flex` | The container is inline and is only as wide as its content |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    background-color: #fde68a;
    border: 2px solid #d97706;
    padding: 6px;
    margin-bottom: 8px;
  }
  .box span {
    background-color: #f97316;
    color: white;
    padding: 6px 12px;
    margin: 2px;
  }
  .a { display: flex; }
  .b { display: inline-flex; }
</style>

<div class="box a"><span>flex</span><span>block-level</span></div>
<div class="box b"><span>inline-flex</span><span>only as wide as needed</span></div>
```

---

## 5. Default Flex Behavior

When you use `display: flex`, these defaults apply:

* Items go in a **row** (main axis is horizontal).
* Items **do not wrap**. They try to fit on one line.
* Items are only as wide as their content.
* Items stretch to the same **height** (the tallest item).
* Items start at the left (the start of the main axis).

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    background-color: #e2e8f0;
  }
  .row div {
    padding: 10px 16px;
    margin: 4px;
    color: white;
  }
  .short { background-color: #0ea5e9; }
  .tall { background-color: #f97316; }
</style>

<div class="row">
  <div class="short">Short</div>
  <div class="tall">This item has more text so it is taller than the first one</div>
</div>
```

The "Short" item stretches to match the tall one. This is how Flexbox makes equal-height columns easily.

## 6. flex-direction (First Look)

`flex-direction` sets the main axis.

| Value | Result |
| ----- | ------ |
| `row` | Left to right (default) |
| `row-reverse` | Right to left |
| `column` | Top to bottom |
| `column-reverse` | Bottom to top |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .col {
    display: flex;
    flex-direction: column;
    width: 200px;
    background-color: #e2e8f0;
    padding: 6px;
  }
  .col div {
    background-color: #16a34a;
    color: white;
    padding: 10px;
    margin: 4px;
  }
</style>

<div class="col">
  <div>One</div>
  <div>Two</div>
  <div>Three</div>
</div>
```

You will learn more about direction in lesson 7.2.

## 7. Centering with Flexbox

Centering both ways is one of the best uses of Flexbox.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .center {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 160px;
    background-color: #1e293b;
  }
  .center div {
    background-color: #38bdf8;
    padding: 14px 24px;
    border-radius: 8px;
    color: white;
  }
</style>

<div class="center">
  <div>Perfectly centered</div>
</div>
```

* `justify-content` aligns items along the **main axis**.
* `align-items` aligns items along the **cross axis**.

## 8. The gap Property

`gap` adds space **between** flex items, without extra margins on the outside.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .gapped {
    display: flex;
    gap: 16px;
    padding: 10px;
    background-color: #e2e8f0;
  }
  .gapped div {
    background-color: #7c3aed;
    color: white;
    padding: 12px 20px;
    border-radius: 6px;
  }
</style>

<div class="gapped">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</div>
```

You can also use `row-gap` and `column-gap`.

## Real-World Example

A simple navigation bar with a logo on the left and links on the right:

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    font-family: Arial, sans-serif;
  }
  .navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 12px 20px;
    background-color: #0f172a;
    color: white;
  }
  .logo {
    font-weight: bold;
    font-size: 20px;
  }
  .links {
    display: flex;
    gap: 18px;
  }
  .links a {
    color: #cbd5e1;
    text-decoration: none;
  }
</style>

<nav class="navbar">
  <div class="logo">Codify</div>
  <div class="links">
    <a href="#">Home</a>
    <a href="#">Courses</a>
    <a href="#">About</a>
  </div>
</nav>
```

Notice that the `.links` element is a flex item of the navbar, and also a flex container for the links. Flex containers can be nested.

## Common Mistakes

### Applying Flex to the Wrong Element

```css
.item { display: flex; }        /* the items inside .item are affected, not .item itself */
.container { display: flex; }   /* put it on the parent */
```

### Expecting Grandchildren to Be Flex Items

```css
/* Only direct children become flex items. */
```

### Using Margins Instead of gap

```css
.item { margin-right: 16px; }     /* extra space after the last item */
.container { gap: 16px; }         /* only between items */
```

### Mixing Up the Axes

```text
justify-content: center;   /* main axis */
align-items: center;       /* cross axis */
```

---

## Key Points

* Flexbox arranges items in one direction: a row **or** a column.
* `display: flex` makes a **flex container**. Its direct children are **flex items**.
* The **main axis** is the item direction, and the **cross axis** crosses it.
* By default items are in a row, do not wrap, and stretch to equal height.
* `justify-content` works on the main axis. `align-items` works on the cross axis.
* `gap` adds clean spacing between items.
* Flex containers can be nested inside other flex containers.

# Chapter 7: Flexbox and CSS Grid

## Section 2: Flex Direction, Alignment and Spacing

Now that you know what a flex container is, let us control **where** the items go. In this lesson you will learn `flex-direction`, `justify-content`, `align-items`, `align-self` and `gap`, which together control almost every flex layout.

---

## 1. flex-direction

`flex-direction` chooses the main axis.

| Value | Main axis | Items start from |
| ----- | --------- | ---------------- |
| `row` | Horizontal | Left |
| `row-reverse` | Horizontal | Right |
| `column` | Vertical | Top |
| `column-reverse` | Vertical | Bottom |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .flex {
    display: flex;
    gap: 6px;
    padding: 8px;
    margin-bottom: 10px;
    background-color: #e2e8f0;
  }
  .flex div {
    width: 60px;
    padding: 10px;
    text-align: center;
    color: white;
    background-color: #0ea5e9;
  }
  .rev { flex-direction: row-reverse; }
  .col { flex-direction: column; width: 100px; }
</style>

<div class="flex rev"><div>1</div><div>2</div><div>3</div></div>
<div class="flex col"><div>1</div><div>2</div><div>3</div></div>
```

When the direction changes to `column`, the **main axis** becomes vertical and the **cross axis** becomes horizontal. This also switches what `justify-content` and `align-items` do.

---

## 2. justify-content (Main Axis)

`justify-content` places items along the **main axis** and decides how extra space is shared.

| Value | Result |
| ----- | ------ |
| `flex-start` | Items at the start (default) |
| `flex-end` | Items at the end |
| `center` | Items in the center |
| `space-between` | First and last at the edges, equal space between |
| `space-around` | Equal space around each item |
| `space-evenly` | Exactly equal space everywhere |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    margin-bottom: 8px;
    background-color: #e2e8f0;
    padding: 6px;
  }
  .row div {
    width: 50px;
    padding: 8px;
    text-align: center;
    background-color: #7c3aed;
    color: white;
  }
  .j1 { justify-content: flex-start; }
  .j2 { justify-content: center; }
  .j3 { justify-content: flex-end; }
  .j4 { justify-content: space-between; }
  .j5 { justify-content: space-around; }
  .j6 { justify-content: space-evenly; }
</style>

<div class="row j1"><div>A</div><div>B</div><div>C</div></div>
<div class="row j2"><div>A</div><div>B</div><div>C</div></div>
<div class="row j3"><div>A</div><div>B</div><div>C</div></div>
<div class="row j4"><div>A</div><div>B</div><div>C</div></div>
<div class="row j5"><div>A</div><div>B</div><div>C</div></div>
<div class="row j6"><div>A</div><div>B</div><div>C</div></div>
```

---

## 3. align-items (Cross Axis)

`align-items` places items along the **cross axis**. In a row, that means vertically.

| Value | Result |
| ----- | ------ |
| `stretch` | Items stretch to fill the container height (default) |
| `flex-start` | Items at the top |
| `flex-end` | Items at the bottom |
| `center` | Items vertically centered |
| `baseline` | Text baselines line up |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    height: 90px;
    margin-bottom: 8px;
    background-color: #e2e8f0;
  }
  .row div {
    width: 70px;
    padding: 8px;
    text-align: center;
    background-color: #f97316;
    color: white;
  }
  .a1 { align-items: flex-start; }
  .a2 { align-items: center; }
  .a3 { align-items: flex-end; }
  .a4 { align-items: stretch; }
</style>

<div class="row a1"><div>top</div><div>top</div></div>
<div class="row a2"><div>mid</div><div>mid</div></div>
<div class="row a3"><div>end</div><div>end</div></div>
<div class="row a4"><div>stretch</div><div>stretch</div></div>
```

The `stretch` items only fill the height if they do not have a fixed height of their own.

---

## 4. align-self

`align-self` lets **one item** use a different cross-axis alignment than the others.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    align-items: flex-start;
    height: 120px;
    background-color: #e2e8f0;
    gap: 8px;
    padding: 6px;
  }
  .row div {
    width: 70px;
    padding: 10px;
    background-color: #16a34a;
    color: white;
    text-align: center;
  }
  .row .special {
    align-self: flex-end;
    background-color: #dc2626;
  }
</style>

<div class="row">
  <div>1</div>
  <div class="special">2</div>
  <div>3</div>
</div>
```

## 5. Using margin: auto in Flexbox

An `auto` margin on a flex item takes all the free space on that side. It is great for pushing one item away from the others.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .bar {
    display: flex;
    align-items: center;
    gap: 10px;
    padding: 10px 14px;
    background-color: #0f172a;
    color: white;
  }
  .bar .push {
    margin-left: auto;
    background-color: #0ea5e9;
    padding: 6px 14px;
    border-radius: 6px;
  }
</style>

<div class="bar">
  <span>Home</span>
  <span>Courses</span>
  <span class="push">Log In</span>
</div>
```

## 6. gap, row-gap and column-gap

`gap` is the clean way to put space between items.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .g {
    display: flex;
    flex-wrap: wrap;
    width: 260px;
    row-gap: 20px;
    column-gap: 6px;
    padding: 8px;
    background-color: #e2e8f0;
  }
  .g div {
    width: 70px;
    padding: 10px;
    background-color: #db2777;
    color: white;
    text-align: center;
  }
</style>

<div class="g">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div><div>6</div>
</div>
```

`gap: 20px 6px` is the shorthand: row gap first, then column gap.

## 7. How Direction Changes the Axes

| | `flex-direction: row` | `flex-direction: column` |
| - | --------------------- | ------------------------ |
| Main axis | Horizontal | Vertical |
| `justify-content` moves items | Left and right | Up and down |
| `align-items` moves items | Up and down | Left and right |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .stack {
    display: flex;
    flex-direction: column;
    justify-content: center;
    align-items: center;
    height: 180px;
    gap: 8px;
    background-color: #1e293b;
  }
  .stack div {
    width: 120px;
    padding: 10px;
    text-align: center;
    background-color: #38bdf8;
    color: #0f172a;
    border-radius: 6px;
  }
</style>

<div class="stack">
  <div>First</div>
  <div>Second</div>
</div>
```

## Common Mistakes

### Mixing Up justify-content and align-items

```text
justify-content   /* main axis */
align-items       /* cross axis */
```

### align-items Does Nothing Because the Container Has No Height

```css
.row { display: flex; align-items: center; }                 /* the container is only as tall as its items */
.row { display: flex; align-items: center; height: 200px; }  /* now centering is visible */
```

### Forgetting That Direction Switches the Axes

```css
.col { flex-direction: column; justify-content: center; }   /* now centers vertically */
```

### Using Margins for Spacing Instead of gap

```css
.item { margin-right: 10px; }   /* extra space at the end */
.row { gap: 10px; }             /* only between items */
```

---

## Key Points

* `flex-direction` sets the main axis: `row`, `row-reverse`, `column` or `column-reverse`.
* `justify-content` aligns items along the **main axis**, with values like `center`, `space-between` and `space-evenly`.
* `align-items` aligns items along the **cross axis**, with values like `center`, `flex-start` and `stretch`.
* `align-self` changes the cross-axis alignment of one single item.
* An `auto` margin on a flex item pushes it away and takes the free space.
* `gap`, `row-gap` and `column-gap` add space between items.
* In `column` direction, the roles of `justify-content` and `align-items` switch.

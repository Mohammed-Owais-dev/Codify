# Chapter 7: Flexbox and CSS Grid

## Section 3: Flex Wrapping, Order and Sizing

In this lesson you will learn how flex items **wrap** onto new lines, how to change their **order**, and how to control their **size** with `flex-grow`, `flex-shrink` and `flex-basis`. These tools let you build flexible cards, columns and responsive rows.

---

## 1. flex-wrap

By default, flex items stay on **one line** and shrink to fit. `flex-wrap` lets them move to the next line when there is no room.

| Value | Meaning |
| ----- | ------- |
| `nowrap` | One line only (default) |
| `wrap` | Items wrap onto new lines |
| `wrap-reverse` | Items wrap, and new lines go above |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    gap: 8px;
    width: 280px;
    margin-bottom: 14px;
    padding: 6px;
    background-color: #e2e8f0;
  }
  .row div {
    width: 100px;
    padding: 10px;
    text-align: center;
    background-color: #0ea5e9;
    color: white;
  }
  .wrap { flex-wrap: wrap; }
</style>

<div class="row">
  <div>1</div><div>2</div><div>3</div><div>4</div>
</div>
<div class="row wrap">
  <div>1</div><div>2</div><div>3</div><div>4</div>
</div>
```

In the first row, the items are squeezed into one line. In the second row, they wrap to a new line.

The shorthand `flex-flow` combines direction and wrap: `flex-flow: row wrap;`.

---

## 2. order

`order` changes the **visual order** of flex items without changing the HTML. The default is `0`. Items are sorted from the lowest number to the highest.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    gap: 8px;
    padding: 8px;
    background-color: #e2e8f0;
  }
  .row div {
    padding: 14px 20px;
    color: white;
    background-color: #7c3aed;
  }
  .first {
    order: -1;
    background-color: #f97316;
  }
</style>

<div class="row">
  <div>A</div>
  <div>B</div>
  <div class="first">C (order -1)</div>
</div>
```

Item C comes first visually. Use `order` carefully: screen readers and keyboard users still follow the **HTML order**, so a big visual change can confuse them.

---

## 3. flex-grow

`flex-grow` decides how items share **extra space**. The default is `0`, which means do not grow.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    gap: 8px;
    padding: 8px;
    background-color: #e2e8f0;
  }
  .row div {
    padding: 12px;
    color: white;
    text-align: center;
  }
  .a { background-color: #0ea5e9; }
  .b { background-color: #16a34a; flex-grow: 1; }
  .c { background-color: #f97316; flex-grow: 2; }
</style>

<div class="row">
  <div class="a">No grow</div>
  <div class="b">Grow 1</div>
  <div class="c">Grow 2</div>
</div>
```

The free space is split in the ratio of the grow numbers. Item C (grow 2) gets twice as much extra space as item B (grow 1).

---

## 4. flex-shrink

`flex-shrink` decides how items **shrink** when there is not enough space. The default is `1`, so all items shrink equally. Set it to `0` to stop an item from shrinking.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    width: 300px;
    background-color: #e2e8f0;
    padding: 6px;
  }
  .row div {
    width: 160px;
    padding: 12px;
    color: white;
    text-align: center;
  }
  .a { background-color: #0ea5e9; }
  .b { background-color: #dc2626; flex-shrink: 0; }
</style>

<div class="row">
  <div class="a">Can shrink</div>
  <div class="b">Never shrinks</div>
</div>
```

Together the two items want 320px, but the container is only about 288px wide inside its padding. Item A shrinks, and item B keeps its 160px.

---

## 5. flex-basis

`flex-basis` sets the **starting size** of an item along the main axis, before growing or shrinking. It is like `width` in a row, or `height` in a column.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    gap: 8px;
    padding: 8px;
    background-color: #e2e8f0;
  }
  .row div {
    padding: 12px;
    color: white;
    text-align: center;
    background-color: #db2777;
  }
  .small { flex-basis: 80px; }
  .large { flex-basis: 200px; }
</style>

<div class="row">
  <div class="small">80px</div>
  <div class="large">200px</div>
</div>
```

If `flex-basis` and `width` are both set, `flex-basis` wins on the main axis. The value `auto` means "use my width".

---

## 6. The flex Shorthand

The `flex` property combines the three values: `flex: grow shrink basis`.

| Shorthand | Meaning |
| --------- | ------- |
| `flex: 1` | `1 1 0%`. Share space equally. Very common. |
| `flex: auto` | `1 1 auto`. Grow and shrink from the content size. |
| `flex: none` | `0 0 auto`. Fixed size, no grow, no shrink. |
| `flex: 0 0 200px` | A fixed 200px item |
| `flex: 2` | Takes twice the space of `flex: 1` items |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .layout {
    display: flex;
    gap: 8px;
    height: 100px;
  }
  .layout div {
    padding: 10px;
    color: white;
    text-align: center;
  }
  .side {
    flex: 0 0 90px;
    background-color: #1e293b;
  }
  .main {
    flex: 1;
    background-color: #0ea5e9;
  }
  .extra {
    flex: 0 0 60px;
    background-color: #f97316;
  }
</style>

<div class="layout">
  <div class="side">Fixed 90px</div>
  <div class="main">flex: 1 (takes the rest)</div>
  <div class="extra">60px</div>
</div>
```

## 7. Equal-Width Columns

`flex: 1` on every item is the easiest way to get equal columns.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .cols {
    display: flex;
    gap: 10px;
  }
  .cols div {
    flex: 1;
    padding: 16px;
    text-align: center;
    color: white;
    border-radius: 8px;
  }
  .c1 { background-color: #0ea5e9; }
  .c2 { background-color: #16a34a; }
  .c3 { background-color: #7c3aed; }
</style>

<div class="cols">
  <div class="c1">Short</div>
  <div class="c2">A column with much longer text inside it</div>
  <div class="c3">Mid</div>
</div>
```

## 8. A Responsive Card Row with Wrap

Mix `flex-wrap`, `flex` and a minimum size to make cards that wrap on small screens.

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    font-family: Arial, sans-serif;
  }
  .cards {
    display: flex;
    flex-wrap: wrap;
    gap: 12px;
  }
  .card {
    flex: 1 1 140px;
    padding: 16px;
    background-color: #f0f9ff;
    border: 2px solid #0ea5e9;
    border-radius: 10px;
    text-align: center;
  }
</style>

<div class="cards">
  <div class="card">Card 1</div>
  <div class="card">Card 2</div>
  <div class="card">Card 3</div>
  <div class="card">Card 4</div>
</div>
```

Each card wants at least 140px (`flex-basis`). When there is not enough room, cards wrap, and the ones on each line grow to fill the row.

## Real-World Example 🌍

A page layout with a fixed sidebar, a flexible main area and wrapping stat cards:

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 12px;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  .page {
    display: flex;
    flex-wrap: wrap;
    gap: 12px;
  }
  .sidebar {
    flex: 0 0 160px;
    padding: 14px;
    background-color: #0f172a;
    color: white;
    border-radius: 10px;
  }
  .main {
    flex: 1 1 240px;
    display: flex;
    flex-wrap: wrap;
    gap: 10px;
  }
  .stat {
    flex: 1 1 100px;
    padding: 14px;
    background-color: white;
    border-radius: 10px;
    box-shadow: 0 1px 4px rgba(0, 0, 0, 0.1);
    text-align: center;
  }
  .stat strong {
    display: block;
    font-size: 22px;
    color: #0ea5e9;
  }
</style>

<div class="page">
  <div class="sidebar">Menu</div>
  <div class="main">
    <div class="stat"><strong>12</strong>Lessons</div>
    <div class="stat"><strong>5</strong>Quizzes</div>
    <div class="stat"><strong>92%</strong>Score</div>
  </div>
</div>
```

## Common Mistakes

### Forgetting flex-wrap

```text
.row { display: flex; }                        /* items squeeze into one line */
.row { display: flex; flex-wrap: wrap; }       /* items wrap */
```

### Using flex: 1 When You Need a Fixed Size

```text
.sidebar { flex: 1; }            /* shares space, size changes */
.sidebar { flex: 0 0 200px; }    /* always 200px */
```

### Changing order and Breaking Keyboard Flow

```text
.item { order: 5; }    /* visual order differs from tab order */
```

### Text Overflowing a Shrinking Item

```text
.item { min-width: 0; }   /* lets a long text item shrink below its content size */
```

### Confusing width with flex-basis

```text
.item { width: 200px; flex-basis: 100px; }   /* flex-basis wins on the main axis */
```

---

## Key Points

* `flex-wrap: wrap` lets items move to new lines. The default is `nowrap`.
* `flex-flow` is the shorthand for `flex-direction` and `flex-wrap`.
* `order` changes the visual order. The default is `0`, and lower numbers come first.
* `flex-grow` shares extra space. `flex-shrink` controls shrinking. `flex-basis` sets the starting size.
* The `flex` shorthand is `grow shrink basis`.
* `flex: 1` makes equal-size items, and `flex: none` makes a fixed-size item.
* `flex: 1 1 140px` plus `flex-wrap: wrap` makes a responsive card row.

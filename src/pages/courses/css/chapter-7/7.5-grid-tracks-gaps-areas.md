# Chapter 7: Flexbox and CSS Grid

## Section 5: Grid Tracks, Gaps and Areas

You already know how to make columns and rows with Grid. In this lesson you will go deeper: how **tracks** are sized, how **gaps** work, and how to draw a whole page layout with **grid areas**. Grid areas make page layouts very easy to read.

---

## 1. What Is a Track?

A **track** is a single row or a single column of the grid. The space between two grid lines is a track.

* `grid-template-columns` defines column tracks.
* `grid-template-rows` defines row tracks.

---

## 2. Ways to Size Tracks

| Value | Meaning |
| ----- | ------- |
| `200px` | A fixed size |
| `30%` | A percent of the grid container |
| `1fr` | A share of the free space |
| `auto` | Sized by the content (and can stretch if there is free space) |
| `min-content` | As narrow as the content can be |
| `max-content` | As wide as the content needs |
| `minmax(100px, 1fr)` | At least 100px, at most 1fr |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: 90px auto 1fr;
    gap: 8px;
  }
  .grid div {
    padding: 12px;
    color: white;
    background-color: #0ea5e9;
    border-radius: 6px;
  }
  .grid div:nth-child(2) { background-color: #f97316; }
  .grid div:nth-child(3) { background-color: #16a34a; }
</style>

<div class="grid">
  <div>90px</div>
  <div>auto</div>
  <div>1fr takes what is left</div>
</div>
```

## 3. minmax()

`minmax(min, max)` gives a track a size **range**. It is great for rows that should grow with their content.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    grid-auto-rows: minmax(60px, auto);
    gap: 8px;
  }
  .grid div {
    padding: 10px;
    color: white;
    background-color: #7c3aed;
    border-radius: 6px;
  }
</style>

<div class="grid">
  <div>Short</div>
  <div>This cell has a lot more text, so its row becomes taller than 60px to fit it all.</div>
  <div>Short</div>
  <div>Short</div>
</div>
```

Rows are at least 60px, but grow when the content needs more space. This stops text from overflowing.

---

## 4. gap, row-gap and column-gap

`gap` adds space **between** tracks only. It does not add space at the outer edges.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    row-gap: 24px;
    column-gap: 6px;
    padding: 8px;
    background-color: #e2e8f0;
  }
  .grid div {
    padding: 12px;
    text-align: center;
    color: white;
    background-color: #db2777;
    border-radius: 6px;
  }
</style>

<div class="grid">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div><div>6</div>
</div>
```

The shorthand `gap: 24px 6px` means row gap first, then column gap. `gap: 16px` sets both.

---

## 5. Named Grid Lines

You can give names to grid lines to make placement easier to read.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: [start] 80px [content-start] 1fr [content-end] 80px [end];
    gap: 6px;
  }
  .grid div {
    padding: 10px;
    color: white;
    background-color: #0ea5e9;
    border-radius: 6px;
  }
  .main {
    grid-column: content-start / content-end;
    background-color: #16a34a;
  }
</style>

<div class="grid">
  <div>Left</div>
  <div class="main">Main between named lines</div>
  <div>Right</div>
</div>
```

## 6. grid-template-areas

Grid areas let you **draw** your layout with names. First you name the items with `grid-area`. Then you draw the layout with `grid-template-areas`.

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    font-family: Arial, sans-serif;
  }
  .page {
    display: grid;
    grid-template-columns: 110px 1fr;
    grid-template-rows: 50px 120px 40px;
    grid-template-areas:
      "header header"
      "sidebar main"
      "footer footer";
    gap: 6px;
    min-height: 220px;
  }
  .page > div {
    padding: 10px;
    color: white;
    border-radius: 6px;
  }
  .header  { grid-area: header;  background-color: #0f172a; }
  .sidebar { grid-area: sidebar; background-color: #7c3aed; }
  .main    { grid-area: main;    background-color: #0ea5e9; }
  .footer  { grid-area: footer;  background-color: #475569; }
</style>

<div class="page">
  <div class="header">Header</div>
  <div class="sidebar">Sidebar</div>
  <div class="main">Main</div>
  <div class="footer">Footer</div>
</div>
```

Each text string is one **row**. Each word is one **column** cell. Repeating a name makes the area span those cells. Rules for areas:

* Every row must have the same number of cells.
* A named area must form a **rectangle**.
* Use a dot (`.`) for an empty cell.

## 7. Changing the Layout for Small Screens

Because areas are drawn as text, changing the layout is easy. You only redraw the picture inside a media query. (Media queries are covered in chapter 8.)

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    font-family: Arial, sans-serif;
  }
  .page {
    display: grid;
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "main"
      "sidebar"
      "footer";
    gap: 6px;
  }
  .page > div {
    padding: 12px;
    color: white;
    border-radius: 6px;
  }
  .header  { grid-area: header;  background-color: #0f172a; }
  .sidebar { grid-area: sidebar; background-color: #7c3aed; }
  .main    { grid-area: main;    background-color: #0ea5e9; }
  .footer  { grid-area: footer;  background-color: #475569; }

  @media (min-width: 600px) {
    .page {
      grid-template-columns: 140px 1fr;
      grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
    }
  }
</style>

<div class="page">
  <div class="header">Header</div>
  <div class="sidebar">Sidebar</div>
  <div class="main">Main</div>
  <div class="footer">Footer</div>
</div>
```

On a small screen, everything stacks. On a wider screen, the sidebar moves next to the main area.

## 8. Implicit Tracks and grid-auto-flow

When there are more items than defined cells, Grid makes extra tracks by itself. These are **implicit** tracks.

* `grid-auto-rows` and `grid-auto-columns` size the extra tracks.
* `grid-auto-flow` decides the direction of auto-placement: `row` (default), `column`, or `dense`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    grid-auto-flow: dense;
    grid-auto-rows: 50px;
    gap: 6px;
  }
  .grid div {
    padding: 8px;
    color: white;
    background-color: #0ea5e9;
    border-radius: 6px;
  }
  .wide {
    grid-column: span 3;
    background-color: #f97316;
  }
</style>

<div class="grid">
  <div>1</div>
  <div class="wide">Wide (3)</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
</div>
```

`dense` fills the holes left by wide items with later, smaller items. The visual order may differ from the HTML order, so use it carefully.

## 9. Centering Everything with Grid

Grid has the shortest way to center something.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .center {
    display: grid;
    place-items: center;
    height: 150px;
    background-color: #1e293b;
  }
  .center div {
    padding: 14px 26px;
    background-color: #38bdf8;
    border-radius: 8px;
  }
</style>

<div class="center">
  <div>Centered with two lines of CSS</div>
</div>
```

## Real-World Example 🌍

A dashboard layout drawn with grid areas:

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 12px;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  .dashboard {
    display: grid;
    grid-template-columns: 130px repeat(2, 1fr);
    grid-template-rows: 50px minmax(80px, auto) minmax(80px, auto);
    grid-template-areas:
      "nav top top"
      "nav stats chart"
      "nav table table";
    gap: 10px;
  }
  .dashboard > div {
    padding: 12px;
    background-color: white;
    border-radius: 10px;
    box-shadow: 0 1px 4px rgba(0, 0, 0, 0.1);
  }
  .nav   { grid-area: nav;   background-color: #0f172a !important; color: white; }
  .top   { grid-area: top; }
  .stats { grid-area: stats; }
  .chart { grid-area: chart; }
  .table { grid-area: table; }
</style>

<div class="dashboard">
  <div class="nav">Menu</div>
  <div class="top">Top bar</div>
  <div class="stats">Stats</div>
  <div class="chart">Chart</div>
  <div class="table">Table</div>
</div>
```

## Common Mistakes

### Rows with a Different Number of Cells

```text
grid-template-areas:
  "header header"
  "sidebar";            /* invalid, each row needs the same number of cells */
```

### Area That Is Not a Rectangle

```text
grid-template-areas:
  "a b"
  "a a";                /* "a" makes an L-shape, which is invalid */
```

### Forgetting grid-area on the Items

```text
.header { }                       /* the item is not placed in the "header" area */
.header { grid-area: header; }
```

### Fixed Row Heights for Text

```text
grid-auto-rows: 60px;                  /* long text overflows */
grid-auto-rows: minmax(60px, auto);    /* rows grow with the text */
```

### Expecting gap on the Outer Edges

```text
/* gap adds space between tracks only. Use padding on the container for outer space. */
```

## Key Points

* A **track** is a grid row or column.
* Track sizes can be `px`, `%`, `fr`, `auto`, `min-content`, `max-content` or `minmax()`.
* `minmax(60px, auto)` lets tracks grow with their content.
* `gap`, `row-gap` and `column-gap` add space **between** tracks only.
* `grid-template-areas` lets you draw the layout with names. Items are placed with `grid-area`.
* Named areas must be **rectangles**, and each row needs the same number of cells.
* You can redraw the areas inside a media query for responsive layouts.
* `grid-auto-rows` sizes extra rows, and `grid-auto-flow: dense` fills holes.
* `display: grid; place-items: center;` is the shortest way to center content.

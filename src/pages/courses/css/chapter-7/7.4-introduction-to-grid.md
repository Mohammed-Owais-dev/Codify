# Chapter 7: Flexbox and CSS Grid

## Section 4: Introduction to CSS Grid

**CSS Grid** is a layout system for **two dimensions** at the same time: rows **and** columns. Flexbox is great for a single row or column, and Grid is great for whole page layouts, galleries and dashboards. In this lesson you will learn the basics of Grid and build your first grids.

---

## 1. Flexbox vs Grid

| | Flexbox | Grid |
| - | ------- | ---- |
| Dimensions | One (row **or** column) | Two (rows **and** columns) |
| Starts from | The content | The layout |
| Best for | Menus, button groups, small components | Page layouts, galleries, dashboards |

You will often use **both** together: Grid for the page structure, and Flexbox inside the pieces.

---

## 2. Grid Container and Grid Items

Just like Flexbox, Grid has a parent and children.

| Part | Meaning |
| ---- | ------- |
| **Grid container** | The parent, with `display: grid` |
| **Grid items** | The direct children |
| **Grid lines** | The lines that divide the grid |
| **Grid cell** | One single space between two rows and two columns |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    background-color: #e2e8f0;
    padding: 8px;
  }
  .grid div {
    background-color: #0ea5e9;
    color: white;
    padding: 14px;
    margin: 4px;
    border-radius: 6px;
  }
</style>

<div class="grid">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>
```

With only `display: grid`, the items stack in **one column**, one per row. To make more columns, you need to define them.

---

## 3. grid-template-columns

`grid-template-columns` defines the **columns**. You list the width of each column.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: 100px 100px 100px;
    gap: 8px;
    padding: 8px;
    background-color: #e2e8f0;
  }
  .grid div {
    padding: 14px;
    text-align: center;
    color: white;
    background-color: #7c3aed;
    border-radius: 6px;
  }
</style>

<div class="grid">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div><div>6</div>
</div>
```

Three column sizes mean three columns. The items fill the first row, then **automatically** continue on the next row.

---

## 4. The fr Unit

`fr` means a **fraction** of the free space. It is the most useful unit in Grid.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;
    gap: 8px;
    padding: 8px;
    background-color: #e2e8f0;
  }
  .grid div {
    padding: 14px;
    text-align: center;
    color: white;
    background-color: #16a34a;
    border-radius: 6px;
  }
</style>

<div class="grid">
  <div>1fr</div>
  <div>2fr</div>
  <div>1fr</div>
</div>
```

The total is 4 parts. The middle column gets 2 of 4 parts (half), and the others get 1 of 4 parts each.

You can mix units: `grid-template-columns: 200px 1fr;` makes a fixed sidebar and a flexible main column.

---

## 5. The repeat() Function

`repeat()` saves you from writing the same value again and again.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 8px;
  }
  .grid div {
    padding: 16px;
    text-align: center;
    color: white;
    background-color: #f97316;
    border-radius: 6px;
  }
</style>

<div class="grid">
  <div>1</div><div>2</div><div>3</div><div>4</div>
  <div>5</div><div>6</div><div>7</div><div>8</div>
</div>
```

`repeat(4, 1fr)` is the same as `1fr 1fr 1fr 1fr`: four equal columns.

---

## 6. grid-template-rows and grid-auto-rows

`grid-template-rows` defines the **rows** in the same way.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: 60px 100px;
    grid-auto-rows: 50px;
    gap: 8px;
  }
  .grid div {
    padding: 8px;
    color: white;
    background-color: #db2777;
    border-radius: 6px;
  }
</style>

<div class="grid">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div><div>6</div>
  <div>7</div><div>8</div><div>9</div>
</div>
```

* The first two rows are 60px and 100px.
* Any extra rows use `grid-auto-rows`, which is 50px here.

By default, rows are sized by their content.

---

## 7. Placing Items by Line Number

Grid lines are numbered, starting at **1**. You can place an item with `grid-column` and `grid-row`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    grid-auto-rows: 50px;
    gap: 6px;
  }
  .grid div {
    padding: 8px;
    color: white;
    background-color: #0ea5e9;
    border-radius: 6px;
  }
  .wide {
    grid-column: 1 / 4;
    background-color: #f97316;
  }
  .tall {
    grid-row: span 2;
    background-color: #7c3aed;
  }
</style>

<div class="grid">
  <div class="wide">Spans columns 1 to 3</div>
  <div class="tall">Spans 2 rows</div>
  <div>A</div><div>B</div><div>C</div>
</div>
```

* `grid-column: 1 / 4` starts at line 1 and ends at line 4, so it covers three columns.
* `span 2` means "cover two tracks".

---

## 8. Aligning Items in Grid

The alignment properties are similar to Flexbox.

| Property | On | Meaning |
| -------- | -- | ------- |
| `justify-items` | Container | Aligns items **horizontally** inside their cells |
| `align-items` | Container | Aligns items **vertically** inside their cells |
| `place-items` | Container | Shorthand for both |
| `justify-self`, `align-self` | One item | Aligns a single item |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-auto-rows: 80px;
    gap: 8px;
    place-items: center;
    background-color: #e2e8f0;
    padding: 6px;
  }
  .grid div {
    padding: 8px 14px;
    background-color: #16a34a;
    color: white;
    border-radius: 6px;
  }
</style>

<div class="grid">
  <div>1</div><div>2</div><div>3</div>
</div>
```

## 9. Auto-Fit Responsive Grid

A very powerful line of CSS makes a responsive grid with **no media queries**.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(110px, 1fr));
    gap: 10px;
  }
  .gallery div {
    padding: 28px 10px;
    text-align: center;
    color: white;
    background-color: #0ea5e9;
    border-radius: 8px;
  }
</style>

<div class="gallery">
  <div>1</div><div>2</div><div>3</div><div>4</div><div>5</div>
</div>
```

* `minmax(110px, 1fr)` means each column is at least 110px, and can grow to share the space.
* `auto-fit` creates as many columns as fit. When the screen gets smaller, the columns drop to fewer per row.

## Real-World Example

A photo-style gallery with one featured, wide item:

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 14px;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  .gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));
    grid-auto-rows: 90px;
    gap: 10px;
    max-width: 460px;
    margin: 0 auto;
  }
  .tile {
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    font-weight: bold;
    border-radius: 10px;
  }
  .t1 { background-color: #0ea5e9; grid-column: span 2; grid-row: span 2; }
  .t2 { background-color: #f97316; }
  .t3 { background-color: #16a34a; }
  .t4 { background-color: #7c3aed; }
  .t5 { background-color: #db2777; }
</style>

<div class="gallery">
  <div class="tile t1">Featured</div>
  <div class="tile t2">2</div>
  <div class="tile t3">3</div>
  <div class="tile t4">4</div>
  <div class="tile t5">5</div>
</div>
```

## Common Mistakes

### Forgetting to Define Columns

```css
.grid { display: grid; }                                      /* one column only */
.grid { display: grid; grid-template-columns: repeat(3, 1fr); }
```

### Mixing Up Line Numbers and Column Numbers

```text
grid-column: 1 / 3;   /* from line 1 to line 3, which is 2 columns */
```

### Applying Grid Properties to the Items

```css
.item { grid-template-columns: 1fr 1fr; }   /* belongs on the container */
```

### Using Percent Widths Plus gap

```text
grid-template-columns: 50% 50%;   /* plus a gap, causes overflow */
grid-template-columns: 1fr 1fr;   /* fr includes the gap correctly */
```

---

## Key Points

* Grid is a **two-dimensional** layout system. Use `display: grid` on the container.
* `grid-template-columns` and `grid-template-rows` define the tracks.
* The **fr** unit shares free space in fractions.
* `repeat(3, 1fr)` creates three equal columns.
* `gap` adds space between rows and columns.
* `grid-column` and `grid-row` place or span items using line numbers or `span`.
* `place-items: center` centers items inside their cells.
* `repeat(auto-fit, minmax(110px, 1fr))` makes a responsive grid without media queries.

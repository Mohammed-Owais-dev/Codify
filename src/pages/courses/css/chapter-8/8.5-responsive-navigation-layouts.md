# Chapter 8: Responsive Web Design

## Section 5: Responsive Navigation and Layouts

A navigation menu with many links fits well on a desktop, but it can be too wide for a phone. In this lesson you will build responsive navigation bars, a hamburger menu that works with CSS only, and several common page layouts that adapt to screen size.

---

## 1. The Problem

A row of links like **Home, Courses, Blog, About, Contact** is easy to read on a laptop. On a narrow phone, the links either overflow the screen or become too small. We have several options:

* Let the links **wrap** onto more lines.
* Make the menu **stack** vertically on small screens.
* Hide the links behind a **menu button** (the "hamburger" button).
* Make the menu **scroll sideways**.

---

## 2. A Wrapping Navigation Bar

The simplest responsive menu uses Flexbox with `flex-wrap`.

```html
<style>
  body {
    margin: 0;
    font-family: Arial, sans-serif;
  }
  .nav {
    display: flex;
    flex-wrap: wrap;
    gap: 6px;
    padding: 10px;
    background-color: #0f172a;
  }
  .nav a {
    padding: 10px 14px;
    color: white;
    text-decoration: none;
    border-radius: 6px;
    background-color: #1e293b;
  }
</style>

<nav class="nav">
  <a href="#">Home</a>
  <a href="#">Courses</a>
  <a href="#">Blog</a>
  <a href="#">About</a>
  <a href="#">Contact</a>
</nav>
```

Make the preview narrow, and the links move to a new line instead of overflowing.

## 3. Stacked on Phones, Row on Desktop

This is the mobile-first pattern: a vertical menu first, and a horizontal row for wider screens.

```html
<style>
  body {
    margin: 0;
    font-family: Arial, sans-serif;
  }
  .nav {
    display: flex;
    flex-direction: column;
    background-color: #0f172a;
  }
  .nav a {
    padding: 14px 16px;
    color: white;
    text-decoration: none;
    border-bottom: 1px solid #334155;
  }

  @media (min-width: 600px) {
    .nav {
      flex-direction: row;
      justify-content: center;
      gap: 6px;
    }
    .nav a {
      border-bottom: none;
    }
  }
</style>

<nav class="nav">
  <a href="#">Home</a>
  <a href="#">Courses</a>
  <a href="#">About</a>
  <a href="#">Contact</a>
</nav>
```

## 5. A CSS-Only Hamburger Menu

On small screens, you can hide the links behind a button. This version uses a hidden checkbox and the `:checked` pseudo-class, so no JavaScript is needed.

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    font-family: Arial, sans-serif;
  }
  .bar {
    background-color: #0f172a;
    color: white;
  }
  .top {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 12px 16px;
  }
  .toggle {
    position: absolute;
    opacity: 0;
    pointer-events: none;
  }
  .burger {
    display: inline-block;
    padding: 6px 12px;
    border: 1px solid #475569;
    border-radius: 6px;
    cursor: pointer;
    font-size: 20px;
  }
  .menu {
    display: none;
    flex-direction: column;
  }
  .menu a {
    padding: 12px 16px;
    color: white;
    text-decoration: none;
    border-top: 1px solid #334155;
  }
  .toggle:checked ~ .menu {
    display: flex;
  }
  .toggle:focus-visible ~ .top .burger {
    outline: 3px solid #38bdf8;
  }

  @media (min-width: 640px) {
    .burger {
      display: none;
    }
    .menu {
      display: flex;
      flex-direction: row;
      gap: 6px;
      padding: 0 16px 12px;
    }
    .menu a {
      border-top: none;
    }
  }
</style>

<header class="bar">
  <input type="checkbox" id="menu-toggle" class="toggle" aria-label="Toggle menu">
  <div class="top">
    <strong>Codify</strong>
    <label for="menu-toggle" class="burger">&#9776;</label>
  </div>
  <nav class="menu">
    <a href="#">Home</a>
    <a href="#">Courses</a>
    <a href="#">About</a>
  </nav>
</header>
```

How it works:

* The checkbox stores the "open" or "closed" state.
* The `<label>` is the button. Clicking it toggles the checkbox.
* `.toggle:checked ~ .menu` shows the menu when the checkbox is checked.
* On wide screens, the button is hidden and the menu is always visible.

Many real sites use a few lines of JavaScript instead, because it gives you more control, such as `aria-expanded` for screen readers.

## 6. A Horizontally Scrolling Menu

A menu with many items can scroll sideways, like the tabs in many apps.

```html
<style>
  body {
    margin: 0;
    font-family: Arial, sans-serif;
  }
  .tabs {
    display: flex;
    gap: 8px;
    padding: 10px;
    overflow-x: auto;
    background-color: #e2e8f0;
  }
  .tabs a {
    flex: 0 0 auto;
    padding: 8px 16px;
    color: #0f172a;
    text-decoration: none;
    background-color: white;
    border-radius: 999px;
    white-space: nowrap;
  }
</style>

<nav class="tabs">
  <a href="#">All</a>
  <a href="#">HTML</a>
  <a href="#">CSS</a>
  <a href="#">JavaScript</a>
  <a href="#">Python</a>
  <a href="#">Java</a>
  <a href="#">C++</a>
</nav>
```

## 7. A Sticky Header

Keep the navigation visible while the user scrolls.

```text
.header {
  position: sticky;
  top: 0;
  z-index: 100;
}
```

Use `sticky` for a normal header that stays in the flow, or `fixed` if you want it always at the top (and then add padding to the page).

## 8. Common Responsive Page Layouts

Here are four layouts used again and again.

| Layout | Phone | Desktop |
| ------ | ----- | ------- |
| **Stacked to columns** | One column | Two or three columns |
| **Sidebar** | Sidebar below or above the content | Sidebar beside the content |
| **Holy grail** | Header, content, sidebars, footer stacked | Header, three columns, footer |
| **Card grid** | One card per row | Many cards per row |

---

## 9. The Holy Grail Layout with Grid

A page with a header, a footer, a main area and two sidebars.

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 10px;
    font-family: Arial, sans-serif;
  }
  .page {
    display: grid;
    gap: 8px;
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "main"
      "left"
      "right"
      "footer";
  }
  .page > * {
    padding: 14px;
    color: white;
    border-radius: 8px;
  }
  .header { grid-area: header; background-color: #0f172a; }
  .main   { grid-area: main;   background-color: #0ea5e9; min-height: 80px; }
  .left   { grid-area: left;   background-color: #7c3aed; }
  .right  { grid-area: right;  background-color: #f97316; }
  .footer { grid-area: footer; background-color: #475569; }

  @media (min-width: 700px) {
    .page {
      grid-template-columns: 120px 1fr 120px;
      grid-template-areas:
        "header header header"
        "left   main   right"
        "footer footer footer";
    }
  }
</style>

<div class="page">
  <header class="header">Header</header>
  <main class="main">Main</main>
  <aside class="left">Left</aside>
  <aside class="right">Right</aside>
  <footer class="footer">Footer</footer>
</div>
```

## 10. Accessibility Tips for Navigation

* Use the `<nav>` element, and give it an `aria-label` if you have more than one.
* Use real `<a>` links and `<button>` elements. They work with the keyboard.
* Keep a visible focus style. Never remove the outline without a replacement.
* Make sure the menu button has a text label or `aria-label`.
* Keep tap targets big enough (44px).

## Real-World Example 🌍

A complete responsive header with a logo, a wrapping menu and a call-to-action button:

```html
<style>

    box-sizing: border-box;
  }
  body {
    margin: 0;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  .site-header {
    position: sticky;
    top: 0;
    z-index: 50;
    display: flex;
    flex-wrap: wrap;
    align-items: center;
    gap: 10px 16px;
    padding: 10px 16px;
    background-color: #0f172a;
  }
  .brand {
    margin-right: auto;
    color: white;
    font-size: 20px;
    font-weight: bold;
  }
  .site-nav {
    display: flex;
```

## Common Mistakes

### A Menu Wider Than the Screen

```text
.nav { display: flex; }                        /* links may overflow */
.nav { display: flex; flex-wrap: wrap; }       /* links wrap */
```

### A Hamburger Button with No Label

```text
<button>☰</button>                                  /* unclear for screen readers */
<button aria-label="Open menu">☰</button>
```

### Hover-Only Dropdowns

```text
.menu li:hover .sub { display: block; }   /* touch devices cannot use it */
```

### Sticky Header Covering Content

```text
.header { position: fixed; top: 0; }     /* content hides under the header */
.header { position: sticky; top: 0; }    /* it stays in the flow */
```

### Removing the Focus Outline

```text
a:focus { outline: none; }    /* keyboard users cannot see where they are */
```

---

## Key Points

* Navigation must be usable on small screens: wrap, stack, scroll or hide behind a button.
* `flex-wrap: wrap` is the easiest responsive menu.
* The mobile-first menu is a column, and it becomes a row with a `min-width` query.
* A CSS-only hamburger menu uses a hidden checkbox, a label and the `:checked` selector.
* `position: sticky; top: 0;` keeps a header visible while scrolling.
* Grid areas make layouts such as the holy grail easy to rearrange for each screen size.
* Use `<nav>`, real links, visible focus styles and large tap targets.

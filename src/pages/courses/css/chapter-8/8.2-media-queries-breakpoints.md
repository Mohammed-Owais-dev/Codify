# Chapter 8: Responsive Web Design

## Section 2: Media Queries and Breakpoints

Flexible layouts do a lot, but sometimes you need to change the design itself on certain screen sizes, such as turning a three-column layout into one column. **Media queries** let you do that. In this lesson you will learn how to write them and how to choose good breakpoints.

---

## 1. What Is a Media Query?

A media query is a CSS rule that applies **only when a condition is true**, for example "when the screen is at least 600px wide".

```text
@media (min-width: 600px) {
  .box {
    background-color: lightblue;
  }
}
```

The CSS inside the curly braces is used only if the condition matches. Otherwise, the browser ignores it.

---

## 2. A First Example

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    padding: 16px;
    color: white;
    background-color: #dc2626;
  }
  .box::after {
    content: " (small screen)";
  }

  @media (min-width: 500px) {
    .box {
      background-color: #16a34a;
    }
    .box::after {
      content: " (500px or wider)";
    }
  }
</style>

<div class="box">Resize the preview</div>
```

The box is red on narrow screens, and turns green when the width is 500px or more.

---

## 3. min-width and max-width

| Query | Applies when |
| ----- | ------------ |
| `(min-width: 768px)` | The screen is **768px or wider** |
| `(max-width: 767px)` | The screen is **767px or narrower** |
| `(min-width: 600px) and (max-width: 900px)` | The screen is **between** 600px and 900px |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .label {
    padding: 14px;
    color: white;
    background-color: #475569;
  }
  .label::after { content: " Phone"; }

  @media (min-width: 480px) {
    .label { background-color: #0ea5e9; }
    .label::after { content: " Tablet"; }
  }
  @media (min-width: 800px) {
    .label { background-color: #7c3aed; }
    .label::after { content: " Desktop"; }
  }
</style>

<div class="label">Layout:</div>
```

---

## 4. Common Breakpoints

A **breakpoint** is a screen width where your design changes. These values are common starting points:

| Name | Width | Typical device |
| ---- | ----- | -------------- |
| Small | 480px | Large phones |
| Medium | 768px | Tablets |
| Large | 1024px | Small laptops |
| Extra large | 1200px | Desktops |

Do not choose breakpoints by devices alone, because there are too many devices. A better method is to make the page narrow, then widen it slowly. **Add a breakpoint where the layout starts to look bad.**

---

## 5. Changing a Layout

The most common use is changing the number of columns.

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    font-family: Arial, sans-serif;
  }
  .grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: 10px;
  }
  .grid div {
    padding: 20px;
    text-align: center;
    color: white;
    background-color: #0ea5e9;
    border-radius: 8px;
  }

  @media (min-width: 500px) {
    .grid {
      grid-template-columns: repeat(2, 1fr);
    }
  }
  @media (min-width: 800px) {
    .grid {
      grid-template-columns: repeat(4, 1fr);
    }
  }
</style>

<div class="grid">
  <div>1</div><div>2</div><div>3</div><div>4</div>
</div>
```

One column on small screens, two on medium and four on large screens.

---

## 6. Hiding and Showing Elements

Media queries can show or hide parts of the page.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .mobile-only {
    padding: 10px;
    background-color: #fde68a;
  }
  .desktop-only {
    display: none;
    padding: 10px;
    background-color: #bbf7d0;
  }

  @media (min-width: 600px) {
    .mobile-only { display: none; }
    .desktop-only { display: block; }
  }
</style>

<div class="mobile-only">Shown on small screens</div>
<div class="desktop-only">Shown on screens 600px or wider</div>
```

Do not hide important content on mobile. Use hiding for extras only.

---

## 7. Combining Conditions: and, comma, not

| Keyword | Meaning |
| ------- | ------- |
| `and` | All conditions must be true |
| `,` (comma) | Works like "or": any condition can be true |
| `not` | Reverses the whole query |

```text
@media (min-width: 600px) and (orientation: landscape) {
  /* wide screens in landscape */
}

@media (max-width: 400px), (orientation: portrait) {
  /* small screens OR portrait screens */
}
```

---

## 8. Other Media Features

Media queries can check more than width.

| Feature | Example | Meaning |
| ------- | ------- | ------- |
| `orientation` | `(orientation: landscape)` | Wider than tall |
| `prefers-color-scheme` | `(prefers-color-scheme: dark)` | The user likes dark mode |
| `prefers-reduced-motion` | `(prefers-reduced-motion: reduce)` | The user wants less animation |
| `hover` | `(hover: hover)` | The device can really hover |
| `print` | `@media print` | When the page is printed |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .theme {
    padding: 16px;
    background-color: #f8fafc;
    color: #0f172a;
    border: 2px solid #94a3b8;
  }

  @media (prefers-color-scheme: dark) {
    .theme {
      background-color: #0f172a;
      color: #f8fafc;
    }
  }
</style>

<div class="theme">This box follows your device theme</div>
```

---

## 9. Range Syntax

Modern CSS lets you write width queries like math.

```text
@media (width >= 768px) {
  /* 768px or wider */
}

@media (500px <= width <= 900px) {
  /* between 500px and 900px */
}
```

It is easier to read than `min-width` and `max-width`. It is supported in modern browsers, but older projects still use `min-width`.

---

## 10. Where to Write Media Queries

* Put media queries **after** the normal rules for the same element, because later rules win when specificity is equal.
* You can keep them near the component, or group them at the bottom of the file.
* Use the same breakpoints across the whole project.

---

## Real-World Example 🌍

A page layout that changes from one column to a sidebar layout:

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 12px;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  .layout {
    display: grid;
    gap: 10px;
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "main"
      "aside";
  }
  .layout > * {
    padding: 14px;
    color: white;
    border-radius: 8px;
  }
  .header { grid-area: header; background-color: #0f172a; }
  .main   { grid-area: main;   background-color: #0ea5e9; min-height: 90px; }
  .aside  { grid-area: aside;  background-color: #7c3aed; }

  @media (min-width: 640px) {
    .layout {
      grid-template-columns: 2fr 1fr;
      grid-template-areas:
        "header header"
        "main aside";
    }
  }
</style>

<div class="layout">
  <div class="header">Header</div>
  <div class="main">Main content</div>
  <div class="aside">Sidebar</div>
</div>
```

## Common Mistakes

### Forgetting the Parentheses

```text
@media min-width: 600px { }       /* invalid */
@media (min-width: 600px) { }     /* correct */
```

### Media Query Placed Before the Normal Rule

```text
@media (min-width: 600px) { .box { color: red; } }
.box { color: blue; }     /* this comes later and overrides the media query */
```

### Mixing min-width and max-width Without a Plan

```text
/* Pick one main direction for the whole project, as shown in lesson 8.4. */
```

### Overlapping Breakpoints

```text
@media (max-width: 600px) { }
@media (min-width: 600px) { }    /* both are true at exactly 600px */
```

### Using Too Many Breakpoints

```text
/* Add a breakpoint only when the design really needs one. */
```

---

## Key Points

* A **media query** applies CSS only when a condition is true.
* `min-width` means "this wide or wider". `max-width` means "this narrow or narrower".
* A **breakpoint** is a width where the layout changes. Choose it where your design breaks.
* Common values are 480px, 768px, 1024px and 1200px.
* Use `and`, a comma and `not` to combine conditions.
* You can test other features, such as `orientation`, `prefers-color-scheme` and `prefers-reduced-motion`.
* Write media queries **after** the normal rules.
* Modern range syntax such as `(width >= 768px)` is easier to read.

# Chapter 8: Responsive Web Design

## Section 3: Responsive Images and Containers

Images are often the biggest cause of broken mobile layouts. A large image can push the page wider than the screen, and it can also slow the page down. In this lesson you will learn how to make images, videos and containers adapt to any screen.

---

## 1. The Basic Responsive Image Rule

The first rule you should add to every project:

```text
img {
  max-width: 100%;
  height: auto;
}
```

* `max-width: 100%` stops the image from becoming wider than its container.
* `height: auto` keeps the correct shape (aspect ratio) when the image shrinks.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .holder {
    width: 220px;
    padding: 6px;
    border: 2px dashed #94a3b8;
  }
  .holder svg {
    max-width: 100%;
    height: auto;
  }
</style>

<div class="holder">
  <svg width="600" height="300" viewBox="0 0 600 300">
    <rect width="600" height="300" fill="#0ea5e9"/>
    <text x="300" y="165" font-size="56" text-anchor="middle" fill="white" font-family="Arial">600 x 300</text>
  </svg>
</div>
```

The graphic is 600px wide, but it fits the 220px holder.

---

## 2. The width and height Attributes

Always write `width` and `height` in the HTML `<img>` tag. The browser uses them to reserve the right space **before** the image loads, so the page does not jump.

```text
<img src="photo.jpg" alt="A mountain lake" width="800" height="450">
```

With `max-width: 100%; height: auto;` in your CSS, the image still scales down properly.

---

## 3. Controlling the Shape with object-fit

When an image is placed in a box of a fixed shape, it may stretch. `object-fit` decides how the image fills the box, just like `background-size`.

| Value | Result |
| ----- | ------ |
| `fill` | Stretches the image (default) |
| `contain` | Shows the whole image, with empty space if needed |
| `cover` | Fills the box and crops the edges |
| `none` | Keeps the natural size |
| `scale-down` | The smaller result of `none` or `contain` |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .frame {
    display: flex;
    gap: 10px;
  }
  .frame svg {
    width: 120px;
    height: 120px;
    border: 2px solid #475569;
    background-color: #f1f5f9;
  }
  .contain { object-fit: contain; }
</style>

<div class="frame">
  <svg viewBox="0 0 200 100" preserveAspectRatio="xMidYMid meet">
    <rect width="200" height="100" fill="#f97316"/>
    <circle cx="100" cy="50" r="30" fill="white"/>
  </svg>
  <svg viewBox="0 0 200 100" preserveAspectRatio="xMidYMid slice">
    <rect width="200" height="100" fill="#f97316"/>
    <circle cx="100" cy="50" r="30" fill="white"/>
  </svg>
</div>
```

The left graphic shows the whole picture (like `contain`), and the right one fills the box and crops the sides (like `cover`). For real `<img>` tags, you write `object-fit: cover` or `object-fit: contain` in CSS.

```text
.thumb {
  width: 100%;
  height: 200px;
  object-fit: cover;
}
```

---

## 4. object-position

`object-position` chooses which part of the image stays visible when it is cropped.

```text
.thumb {
  object-fit: cover;
  object-position: center top;   /* keep the top of the photo, like a face */
}
```

---

## 5. Keeping a Shape with aspect-ratio

`aspect-ratio` keeps a box at a fixed shape while its width changes. This is perfect for image cards and videos.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .thumb {
    width: 100%;
    max-width: 300px;
    aspect-ratio: 16 / 9;
    display: flex;
    align-items: center;
    justify-content: center;
    background-color: #0ea5e9;
    color: white;
    border-radius: 10px;
  }
</style>

<div class="thumb">16 : 9</div>
```

---

## 6. Responsive Video and Embeds

A video or an embedded map (an `iframe`) has a fixed size by default. Use `aspect-ratio` to make it fluid.

```text
iframe,
video {
  width: 100%;
  height: auto;
  aspect-ratio: 16 / 9;
}
```

---

## 7. srcset and sizes: Different Images for Different Screens

A phone does not need a huge desktop image. The `srcset` attribute gives the browser **several versions** of one image, and the browser picks the best one.

```text
<img
  src="photo-800.jpg"
  srcset="photo-400.jpg 400w,
          photo-800.jpg 800w,
          photo-1600.jpg 1600w"
  sizes="(min-width: 800px) 800px, 100vw"
  alt="A mountain lake"
  width="800" height="450">
```

* `srcset` lists the files, with their real width in pixels (`400w`).
* `sizes` tells the browser how wide the image will be on the page.
* The browser picks a file that is sharp enough, and saves data on small screens.

---

## 8. The picture Element: Art Direction

With `<picture>`, you can show a **different image** on different screens, such as a wide photo on desktop and a cropped one on phones.

```text
<picture>
  <source media="(min-width: 800px)" srcset="hero-wide.jpg">
  <source media="(min-width: 480px)" srcset="hero-medium.jpg">
  <img src="hero-small.jpg" alt="A runner at sunrise">
</picture>
```

The browser uses the first `<source>` that matches. The `<img>` is the fallback and is **required**.

## 9. Responsive Containers

A **container** keeps your content in a comfortable width and centers it.

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    font-family: Arial, sans-serif;
    background-color: #e2e8f0;
  }
  .container {
    width: 100%;
    max-width: 700px;
    margin: 0 auto;
    padding: 0 16px;
    background-color: white;
  }
  .container p {
    margin: 0;
    padding: 16px 0;
  }
</style>

<div class="container">
  <p>This content never gets wider than 700px, stays centered, and keeps side space on small screens.</p>
</div>
```

## 10. Container Queries

Media queries look at the **screen** size. **Container queries** look at the size of a **parent box**. This lets a card change its layout depending on the space it has, no matter where it is placed.

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    font-family: Arial, sans-serif;
  }
  .wrapper {
    container-type: inline-size;
    border: 2px dashed #94a3b8;
    padding: 8px;
    margin-bottom: 12px;
  }
  .card {
    display: grid;
    gap: 8px;
    padding: 10px;
    background-color: #f0f9ff;
    border-radius: 8px;
  }
  .pic {
    height: 50px;
    background-color: #0ea5e9;
    border-radius: 6px;
  }

  @container (min-width: 300px) {
    .card {
      grid-template-columns: 80px 1fr;
      align-items: center;
    }
  }
</style>

<div class="wrapper" style="width: 200px">
  <div class="card"><div class="pic"></div><div>Narrow box: stacked</div></div>
</div>
<div class="wrapper">
  <div class="card"><div class="pic"></div><div>Wide box: side by side</div></div>
</div>
```

The same card is stacked in the narrow wrapper, and side by side in the wide wrapper.

## Real-World Example 🌍

A responsive blog card list with fluid images:

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 14px;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  .posts {
    width: 100%;
    max-width: 760px;
    margin: 0 auto;
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 14px;
  }
  .post {
    overflow: hidden;
    background-color: white;
    border-radius: 12px;
    box-shadow: 0 1px 5px rgba(0, 0, 0, 0.1);
  }
  .post .cover {
    width: 100%;
    aspect-ratio: 16 / 9;
    background-color: #0ea5e9;
  }
  .post:nth-child(2) .cover { background-color: #f97316; }
  .post:nth-child(3) .cover { background-color: #16a34a; }
  .post h3 {
    margin: 0;
    padding: 12px 14px 4px;
    font-size: 17px;
  }
  .post p {
    margin: 0;
    padding: 0 14px 14px;
    color: #475569;
    font-size: 14px;
  }
</style>

<div class="posts">
  <article class="post"><div class="cover"></div><h3>Flexbox Tips</h3><p>Five quick layout tricks.</p></article>
  <article class="post"><div class="cover"></div><h3>Grid Guide</h3><p>Rows and columns made easy.</p></article>
  <article class="post"><div class="cover"></div><h3>Fluid Images</h3><p>Pictures that fit every screen.</p></article>
</div>
```

## Common Mistakes

### No max-width on Images

```text
img { }                                  /* a big image breaks the layout */
img { max-width: 100%; height: auto; }
```

### Setting Both Width and Height in CSS

```text
img { width: 100%; height: 200px; }                    /* the image may stretch */
img { width: 100%; height: 200px; object-fit: cover; }
```

### Missing the alt Text

```text
<img src="photo.jpg">                       /* not accessible */
<img src="photo.jpg" alt="A mountain lake">
```

### Forgetting the img Inside picture

```text
<picture><source ...></picture>      /* nothing is shown */
```

### Loading One Huge Image for Everyone

```text
/* Use srcset so phones download smaller files. */
```

---

## Key Points

* Use `img { max-width: 100%; height: auto; }` on every project.
* Add `width` and `height` attributes in the HTML so the page does not jump while loading.
* `object-fit` (`cover` or `contain`) and `object-position` control how an image fills a box.
* `aspect-ratio` keeps boxes, videos and embeds in a fixed shape.
* `srcset` and `sizes` let the browser pick the best image file for the screen.
* `<picture>` shows different images on different screens.
* A container uses `max-width`, `margin: 0 auto` and side padding.
* **Container queries** (`@container`) react to the parent box size, not the screen size.

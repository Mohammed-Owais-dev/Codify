# Chapter 2: Selectors and the Cascade

## Section 4: Pseudo-Classes and Pseudo-Elements

Some styles depend on what the user is doing, such as hovering over a button, or on a special part of an element, such as its first letter. You cannot add a class for these cases. CSS solves this with **pseudo-classes** and **pseudo-elements**. In this lesson you will learn both.

---

## 1. Pseudo-Classes vs Pseudo-Elements

| | Pseudo-class | Pseudo-element |
| - | ------------ | -------------- |
| Symbol | One colon `:` | Two colons `::` |
| Selects | An element in a certain **state** or position | A certain **part** of an element, or new content |
| Example | `a:hover` | `p::first-letter` |
| Meaning | "When the mouse is over the link" | "The first letter of the paragraph" |

---

## 2. The :hover Pseudo-Class

`:hover` applies when the mouse pointer is over an element. It is used for buttons, links, cards and menus. Move your mouse over the button below after running the example.

```html
<style>
  button {
    background-color: #2563eb;
    color: white;
    border: none;
    padding: 12px 24px;
    border-radius: 8px;
    font-size: 16px;
    cursor: pointer;
  }
  button:hover {
    background-color: #1e40af;
  }
</style>

<button>Hover over me</button>
```

---

## 3. Link Pseudo-Classes

Links have several states, and each has its own pseudo-class.

| Pseudo-class | When it applies |
| ------------ | --------------- |
| `a:link` | A link that has not been visited yet |
| `a:visited` | A link the user has already visited |
| `a:hover` | The mouse is over the link |
| `a:active` | The moment the link is being clicked |

```html
<style>
  a:link {
    color: #2563eb;
  }
  a:visited {
    color: #7c3aed;
  }
  a:hover {
    color: #dc2626;
    text-decoration: none;
  }
  a:active {
    color: #f97316;
  }
</style>

<a href="https://example.com">Hover and click this link</a>
```

Write them in this order: **link, visited, hover, active** (remember "LoVe HAte"). If the order changes, some states may not work because of the cascade rules.

---

## 4. :focus and Keyboard Users

`:focus` applies to the element that is currently selected, such as a text box you are typing in, or a button reached with the Tab key. Good focus styles are very important for people who use a keyboard.

```html
<style>
  input {
    padding: 10px;
    border: 2px solid #cbd5e1;
    border-radius: 6px;
    font-size: 16px;
    outline: none;
  }
  input:focus {
    border-color: #2563eb;
    box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.25);
  }
</style>

<input type="text" placeholder="Click here to focus">
```

Never remove the focus outline unless you give a clear replacement, as this example does with a blue border and glow.

## 5. Structural Pseudo-Classes

These select elements by their **position** among their siblings.

| Selector | Selects |
| -------- | ------- |
| `:first-child` | An element that is the first child of its parent |
| `:last-child` | An element that is the last child |
| `:nth-child(n)` | The element at position `n` |
| `:nth-child(odd)` | Elements 1, 3, 5, ... |
| `:nth-child(even)` | Elements 2, 4, 6, ... |
| `:only-child` | An element with no siblings |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  ul {
    list-style: none;
    padding: 0;
    width: 220px;
  }
  li {
    padding: 8px 12px;
  }
  li:first-child {
    font-weight: bold;
    border-radius: 6px 6px 0 0;
  }
  li:nth-child(odd) {
    background-color: #e0f2fe;
  }
  li:nth-child(even) {
    background-color: #f1f5f9;
  }
  li:last-child {
    border-radius: 0 0 6px 6px;
  }
</style>

<ul>
  <li>Item 1 (first)</li>
  <li>Item 2</li>
  <li>Item 3</li>
  <li>Item 4</li>
  <li>Item 5 (last)</li>
</ul>
```

This "striped list" look is one of the most common uses of `:nth-child`.

---

## 6. The nth-child Formula

Inside `:nth-child()` you can write a formula `an + b`.

| Formula | Selects |
| ------- | ------- |
| `3` | Only the 3rd element |
| `2n` | Every 2nd element (2, 4, 6, ...) |
| `3n` | Every 3rd element (3, 6, 9, ...) |
| `2n + 1` | Same as `odd` (1, 3, 5, ...) |
| `n + 3` | The 3rd element and all after it |

---

## 7. The :not() Pseudo-Class

`:not()` selects elements that do **not** match the selector inside the brackets.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  p:not(.skip) {
    color: #0f766e;
    font-weight: bold;
  }
</style>

<p>This paragraph is styled.</p>
<p class="skip">This one has the skip class, so it is not styled.</p>
<p>This paragraph is styled too.</p>
```

---

## 8. Form State Pseudo-Classes

CSS can style form controls based on their state.

| Pseudo-class | When it applies |
| ------------ | --------------- |
| `:checked` | A checkbox or radio button that is selected |
| `:disabled` | A control that cannot be used |
| `:required` | A field marked with the `required` attribute |
| `:valid` / `:invalid` | A field whose value passes or fails validation |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  input:checked + label {
    color: #16a34a;
    font-weight: bold;
  }
  input:disabled {
    opacity: 0.5;
  }
  input:required {
    border: 2px solid #f97316;
  }
</style>

<p><input type="checkbox" id="agree"><label for="agree"> I agree to the terms</label></p>
<p><input type="text" placeholder="Disabled field" disabled></p>
<p><input type="text" placeholder="Required field" required></p>
```

Tick the checkbox and the label turns green. This uses `:checked` together with the `+` combinator from the last lesson.

## 9. Pseudo-Elements: ::first-letter and ::first-line

A pseudo-element styles a **part** of an element. These two are used in magazine-style text.

```html
<style>
  body {
    font-family: Georgia, serif;
    width: 360px;
    line-height: 1.6;
  }
  p::first-letter {
    font-size: 42px;
    font-weight: bold;
    color: #be123c;
    float: left;
    margin-right: 6px;
  }
  p::first-line {
    font-weight: bold;
    color: #1e3a8a;
  }
</style>

<p>CSS lets you style the first letter and the first line of a paragraph without adding any extra HTML tags. This makes text look more like a printed magazine.</p>
```

---

## 10. ::before and ::after

`::before` and `::after` create **new content** before or after an element's real content. They need the `content` property, even if the content is empty (`content: ""`).

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .tip::before {
    content: "💡 Tip: ";
    font-weight: bold;
    color: #f59e0b;
  }
  .required-label::after {
    content: " *";
    color: #dc2626;
  }
</style>

<p class="tip">Save your work often.</p>
<p class="required-label">Email address</p>
```

The icon and the red star are added by CSS only. They are not in the HTML, so they are decoration and screen readers may not treat them as real content. Do not use them for important information.

---

## 11. Other Useful Pseudo-Elements

| Pseudo-element | What it styles |
| -------------- | -------------- |
| `::selection` | The text a user highlights with the mouse |
| `::placeholder` | The hint text inside an empty input |
| `::marker` | The bullet or number of a list item |

```html
<style>
  ::selection {
    background-color: #fde047;
    color: #1e293b;
  }
  input::placeholder {
    color: #94a3b8;
    font-style: italic;
  }
  li::marker {
    color: #dc2626;
  }
  body {
    font-family: Arial, sans-serif;
  }
</style>

<p>Select this text with your mouse to see the yellow highlight.</p>
<input type="text" placeholder="Styled placeholder text">
<ul>
  <li>Red bullet one</li>
  <li>Red bullet two</li>
</ul>
```

## Real-World Example 🌍

A hover card and a striped table using pseudo-classes and pseudo-elements:

```html
<style>
  body {
    font-family: Arial, sans-serif;
    padding: 16px;
    background-color: #f1f5f9;
  }
  .course {
    width: 260px;
    background-color: white;
    padding: 16px;
    border-radius: 12px;
    border: 1px solid #e2e8f0;
    transition: transform 0.2s, box-shadow 0.2s;
  }
  .course:hover {
    transform: translateY(-4px);
    box-shadow: 0 10px 20px rgba(0, 0, 0, 0.15);
  }
  .course h3 {
    margin: 0 0 6px;
  }
  .course h3::after {
    content: " NEW";
    background-color: #16a34a;
    color: white;
    font-size: 11px;
    padding: 2px 6px;
    border-radius: 4px;
    vertical-align: middle;
  }
  table {
    border-collapse: collapse;
    margin-top: 16px;
    background-color: white;
  }
  th, td {
    padding: 8px 16px;
    text-align: left;
  }
  tr:nth-child(even) {
    background-color: #e0f2fe;
  }
  tr:hover {
    background-color: #fef9c3;
  }
</style>

<div class="course">
  <h3>CSS Basics</h3>
  <p>Learn selectors, colors and layout.</p>
</div>

<table>
  <tr><th>Chapter</th><th>Topic</th></tr>
  <tr><td>1</td><td>Introduction</td></tr>
  <tr><td>2</td><td>Selectors</td></tr>
  <tr><td>3</td><td>Typography</td></tr>
  <tr><td>4</td><td>Box Model</td></tr>
</table>
```

Hover over the card and the table rows to see the effects. The "NEW" badge is added with `::after`, so the HTML stays clean.

## Common Mistakes

### Using the Wrong Number of Colons

```css
a:hover { }          /* pseudo-class: one colon */
p::first-line { }    /* pseudo-element: two colons */
```

### Forgetting the content Property

```css
.tip::before {
  color: red;        /* nothing appears, content is missing */
}

.tip::before {
  content: "";       /* now the element exists */
}
```

### Wrong Order of Link States

```css
a:hover { color: red; }
a:link { color: blue; }     /* this one overrides hover! */
```

Always keep the order **link, visited, hover, active**.

### Adding a Space Before the Colon

```css
a :hover { }     /* any hovered element INSIDE an a */
a:hover { }      /* a link that is hovered */
```

### Relying on Hover for Important Actions

```text
Phones and tablets have no mouse pointer.
Make sure important information is available without hovering.
```

## Key Points

* A **pseudo-class** (one colon) selects an element in a certain **state** or **position**.
* A **pseudo-element** (two colons) styles a **part** of an element or adds generated content.
* `:hover`, `:focus` and `:active` respond to user actions.
* Link states must be written in the order **link, visited, hover, active**.
* `:first-child`, `:last-child` and `:nth-child()` select elements by position.
* `:not()` excludes elements, and `:checked`, `:disabled` and `:required` style form controls.
* `::before` and `::after` add content with the `content` property.
* `::first-letter`, `::first-line`, `::selection`, `::placeholder` and `::marker` style special parts.
* Do not put important information in generated content, and do not remove focus styles.

# Chapter 2: Selectors and the Cascade

## Section 2: Grouping and Universal Selectors

Sometimes many different elements need the same style. Writing the same declarations again and again is slow and makes mistakes more likely. In this lesson you will learn to **group** selectors with commas, and to use the **universal selector** `*` to target every element at once.

---

## 1. The Problem: Repeating Yourself

Look at this CSS. Three rules have exactly the same declarations.

```css
h1 {
  color: #1e3a8a;
  font-family: Georgia, serif;
}
h2 {
  color: #1e3a8a;
  font-family: Georgia, serif;
}
h3 {
  color: #1e3a8a;
  font-family: Georgia, serif;
}
```

This works, but if you want to change the color you must edit it in three places. CSS has a better way.

---

## 2. Grouping Selectors

To apply one set of declarations to several selectors, write the selectors in one list, **separated by commas**.

```html
<style>
  h1, h2, h3 {
    color: #1e3a8a;
    font-family: Georgia, serif;
  }
</style>

<h1>Main Heading</h1>
<h2>Second Heading</h2>
<h3>Third Heading</h3>
<p>This paragraph is not in the group, so it keeps the default style.</p>
```

The comma means "and". The rule reads: "h1 **and** h2 **and** h3 should be dark blue and use Georgia."

---

## 3. Writing Group Lists Neatly

For long lists, put each selector on its own line. It is easier to read and to edit.

```css
h1,
h2,
h3,
h4 {
  font-family: Georgia, serif;
  line-height: 1.3;
}
```

Remember that the comma goes after each selector except the last one. The `{` comes after the final selector.

---

## 4. Grouping Different Kinds of Selectors

You can mix element, class and id selectors in the same group.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  h1, .title, #special {
    color: #be123c;
    text-decoration: underline;
  }
</style>

<h1>Element selector</h1>
<p class="title">Class selector</p>
<p id="special">ID selector</p>
<p>Not selected</p>
```

---

## 5. Group Rule Plus Individual Rules

A common pattern is to put the shared style in a group rule, then add extra rules for each selector.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  h1, h2 {
    color: #0f172a;
    margin-bottom: 4px;
  }
  h1 {
    font-size: 34px;
  }
  h2 {
    font-size: 22px;
    color: #2563eb;
  }
</style>

<h1>Big Title</h1>
<h2>Smaller Subtitle</h2>
```

Both headings share the `margin-bottom`. Each then has its own size, and `h2` also changes its color. The later `h2` rule wins for the color because it comes after.

---

## 6. One Wrong Selector Breaks the Whole Group

If **one** selector in the list is invalid, the browser ignores the **entire** rule, even the good selectors.

```html
<style>
  h1, h2, ..broken, h3 {
    color: crimson;
  }
</style>

<h1>I am not crimson</h1>
<h2>I am not crimson</h2>
<h3>I am not crimson</h3>
```

Because of `..broken`, none of the headings are styled. If a group rule is not working, look for a typo in the selector list.

---

## 7. The Universal Selector

The **universal selector** is written as an asterisk `*`. It selects **every element** on the page.

```html
<style>
  * {
    font-family: Arial, sans-serif;
    color: #334155;
  }
</style>

<h2>Universal Selector</h2>
<p>Every element uses the same font and color.</p>
<button>Even the button</button>
```

Notice how the button, which normally uses a system font, now uses Arial too. The `*` reaches everything.

---

## 8. A Simple CSS Reset

Browsers add default margins and padding to many elements. Developers often use `*` to remove these defaults, so they can start with a clean page.

```html
<style>
  * {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
  }
  body {
    font-family: Arial, sans-serif;
    padding: 20px;
  }
  h2 {
    color: #0f766e;
  }
</style>

<h2>Clean start</h2>
<p>The default spacing between the heading and paragraph is gone.</p>
```

You will learn what `box-sizing: border-box` does in Chapter 4. For now, know that this three-line reset is used in thousands of real websites.

---

## 9. Universal Selector Inside Another Selector

The `*` can be combined with other selectors to mean "everything inside".

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .panel * {
    color: #7c3aed;
  }
</style>

<div class="panel">
  <h3>Inside the panel</h3>
  <p>Every element inside .panel turns purple.</p>
</div>
<p>Outside the panel, the text keeps its normal color.</p>
```

`.panel *` means "every element that is **inside** an element with the class `panel`". (The space between them is a combinator, which you will study in the next lesson.)

---

## 10. A Modern Shortcut: :is()

Newer CSS has a shorter way to group parts of a selector, using `:is()`.

```css
/* Long version */
nav a, header a, footer a {
  color: #0369a1;
}

/* Shorter version with :is() */
:is(nav, header, footer) a {
  color: #0369a1;
}
```

Both do the same thing. Another benefit of `:is()` is that if one item in the list is invalid, the others still work. All modern browsers support it.

---

## Real-World Example

A stylesheet that uses grouping and a universal reset to build a clean article page:

```html
<style>
  * {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
  }
  body {
    font-family: Arial, sans-serif;
    background-color: #f8fafc;
    color: #334155;
    padding: 24px;
    line-height: 1.6;
  }
  h1, h2, h3 {
    font-family: Georgia, serif;
    color: #0f172a;
    margin-bottom: 10px;
  }
  p, li {
    font-size: 17px;
    margin-bottom: 10px;
  }
  ul {
    padding-left: 24px;
  }
</style>

<h1>Why Learn CSS?</h1>
<p>CSS lets you control the look of every website you build.</p>
<h2>Benefits</h2>
<ul>
  <li>Clean, consistent designs</li>
  <li>Easy updates in one place</li>
  <li>Works on every device</li>
</ul>
```

The universal selector resets the page, and grouped rules keep the headings and text styles short.

## Common Mistakes

### Forgetting the Comma

```css
h1 h2 { color: red; }      /* means an h2 INSIDE an h1 */
h1, h2 { color: red; }     /* correct: both headings */
```

Without the comma, the selector has a completely different meaning.

### Putting a Comma Before the Brace

```css
h1,
h2, {
  color: red;
}
```

A trailing comma makes the selector list invalid, so the whole rule is ignored.

### Overusing the Universal Selector

```css
* {
  color: red;
  border: 1px solid blue;
}
```

This styles **every** element, including ones you did not think about, and can make a page hard to control. Use `*` only for resets and basic settings.

### Expecting * to Be Strong

```css
* { color: red; }
p { color: blue; }
```

The universal selector is the **weakest** selector, so `p` wins and paragraphs are blue. You will learn why in Lesson 2.5.

---

## Key Points

* **Grouping** lets one rule style many selectors. Separate them with commas.
* A group can mix element, class and id selectors.
* One invalid selector in a group makes the browser ignore the whole rule.
* The **universal selector** `*` matches every element on the page.
* `*` is often used for a CSS reset such as `margin: 0; padding: 0; box-sizing: border-box;`.
* `.panel *` selects everything inside an element with the class `panel`.
* `:is()` is a modern shortcut for grouping parts of a selector.
* The universal selector has the lowest strength, so other selectors can override it.

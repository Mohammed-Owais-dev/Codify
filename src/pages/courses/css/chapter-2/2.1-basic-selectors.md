# Chapter 2: Selectors and the Cascade

## Section 1: Element, Class and ID Selectors

To style a webpage, you must first tell the browser **which elements** you want to style. This is the job of a **selector**. In this lesson you will learn the three most important basic selectors: the element selector, the class selector and the id selector.

---

## 1. What Is a Selector?

A selector is the first part of a CSS rule. It points to the HTML elements that the declarations should be applied to.

```text
selector {
  property: value;
}
```

Think of a selector as an address. If you say "all paragraphs", "everything with the class `card`" or "the element with the id `logo`", the browser knows exactly where to apply your styles.

---

## 2. Element Selector

An **element selector** (also called a **type selector**) uses the name of an HTML tag. It selects **every** element of that type on the page.

```html
<style>
  h2 {
    color: #7c3aed;
    font-family: Arial, sans-serif;
  }
  p {
    color: #475569;
    font-family: Arial, sans-serif;
    font-size: 18px;
  }
</style>

<h2>Element Selectors</h2>
<p>Every paragraph gets this style.</p>
<p>This paragraph is styled too.</p>
```

Use element selectors for **general** styles that should apply everywhere, such as the font of all paragraphs.

---

## 3. Class Selector

A **class selector** starts with a dot `.` followed by the class name. It selects every element that has that class in its `class` attribute.

```html
<style>
  .highlight {
    background-color: #fef08a;
    padding: 4px 8px;
  }
  body {
    font-family: Arial, sans-serif;
  }
</style>

<p>This is a normal paragraph.</p>
<p class="highlight">This paragraph is highlighted.</p>
<h3 class="highlight">This heading is highlighted too.</h3>
```

The same class can be used on **many** elements, and the elements can be of different types. Classes are the most useful and most common selector in CSS.

---

## 4. Using More Than One Class

An element can have several classes. Write them in one `class` attribute, separated by spaces.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .badge {
    padding: 6px 14px;
    border-radius: 20px;
    color: white;
    display: inline-block;
  }
  .green {
    background-color: #16a34a;
  }
  .red {
    background-color: #dc2626;
  }
</style>

<span class="badge green">Passed</span>
<span class="badge red">Failed</span>
```

The shared shape comes from `badge`, and the color comes from `green` or `red`. Combining small classes is a clean way to build designs.

---

## 5. ID Selector

An **id selector** starts with a hash `#` followed by the id name. It selects the one element that has that `id` attribute.

```html
<style>
  #page-title {
    color: #be123c;
    font-family: Georgia, serif;
    border-bottom: 3px solid #be123c;
    padding-bottom: 6px;
  }
</style>

<h1 id="page-title">Welcome to My Site</h1>
<p>Only the heading has the page-title id.</p>
```

An id must be **unique**. The same id should never be used on two elements in one page.

---

## 6. Class vs ID

| | Class | ID |
| - | ----- | -- |
| CSS symbol | `.` (dot) | `#` (hash) |
| HTML attribute | `class="name"` | `id="name"` |
| Use on many elements | **Yes** | No, must be unique |
| Many on one element | Yes, separated by spaces | No, only one id |
| Strength (specificity) | Medium | High |
| Best for | Reusable styles | One special element, links and JavaScript |

In everyday styling, prefer **classes**. Ids are strong and hard to override, so they can cause problems later.

---

## 7. Combining Element and Class

You can write an element name and a class together, **with no space**, to select only that type of element with that class.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  p.note {
    background-color: #dbeafe;
    padding: 10px;
    border-left: 4px solid #2563eb;
  }
</style>

<p class="note">This paragraph has the note class, so it is styled.</p>
<div class="note">This div has the same class, but is not styled because the rule is p.note.</div>
```

`p.note` means "a `<p>` element that also has the class `note`". If you add a space (`p .note`) the meaning changes completely, as you will see in Lesson 2.3.

---

## 8. Naming Rules for Classes and IDs

* Use letters, numbers, hyphens `-` and underscores `_`.
* Do not start a name with a number. `.1box` is invalid, `.box1` is fine.
* Names are **case-sensitive**: `.Card` and `.card` are different.
* Do not use spaces inside one name. Use hyphens instead: `main-title`.
* Choose names that describe the **purpose**, not the look. `.warning` is better than `.red-text`, because the color may change later.

---

## 9. Reusing a Class Everywhere

One class can style a group of different elements. This keeps your CSS short.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .card {
    background-color: #f8fafc;
    border: 1px solid #cbd5e1;
    border-radius: 10px;
    padding: 14px;
    margin-bottom: 12px;
    width: 260px;
  }
</style>

<div class="card">A card made from a div</div>
<section class="card">A card made from a section</section>
<article class="card">A card made from an article</article>
```

---

## 10. Which Selector Should I Use?

| Situation | Best selector |
| --------- | ------------- |
| Style every paragraph or heading the same way | Element selector: `p` |
| Style a group of similar things, or reuse a design | Class selector: `.card` |
| Style one unique element on the page | Class, or id if it is truly unique |
| Make a style that JavaScript or a page link will also use | ID: `#contact` |

## Real-World Example 🌍

A small product list built with element and class selectors:

```html
<style>
  body {
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
    padding: 20px;
  }
  h2 {
    color: #0f172a;
  }
  .product {
    background-color: white;
    border-radius: 10px;
    padding: 14px;
    margin-bottom: 12px;
    width: 280px;
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.12);
  }
  .product h3 {
    margin: 0 0 6px;
  }
  .price {
    color: #16a34a;
    font-weight: bold;
  }
  .sale {
    background-color: #fff7ed;
    border-left: 5px solid #f97316;
  }
</style>

<h2>Our Products</h2>

<div class="product">
  <h3>Wireless Mouse</h3>
  <p class="price">$18</p>
</div>

<div class="product sale">
  <h3>Keyboard (On Sale)</h3>
  <p class="price">$25</p>
</div>
```

Both products share the `product` class. The second one adds the `sale` class for a special look.

## Common Mistakes

### Forgetting the Dot or Hash

```text
highlight { color: red; }      /* looks for a <highlight> tag */
.highlight { color: red; }     /* correct for class="highlight" */
#logo { color: red; }          /* correct for id="logo" */
```

### Using the Dot in the HTML

```text
<p class=".note">Wrong</p>
<p class="note">Correct</p>
```

The dot belongs only in the CSS selector, never in the HTML attribute.

### Repeating an ID

```text
<p id="intro">First</p>
<p id="intro">Second</p>     <!-- wrong: ids must be unique -->
```

Use a class when you need the same style on more than one element.

### Adding an Accidental Space

```text
p.note { }     /* a <p> that has the class note */
p .note { }    /* any .note element INSIDE a <p> */
```

### Mismatched Names

```text
CSS:  .Card { }
HTML: <div class="card">      <!-- no match, case is different -->
```

---

## Key Points

* A **selector** chooses which HTML elements a rule styles.
* An **element selector** uses a tag name, such as `p`, and matches all elements of that type.
* A **class selector** uses a dot, such as `.card`, and can be reused on many elements.
* An **id selector** uses a hash, such as `#logo`, and must be unique on the page.
* One element can have several classes, separated by spaces.
* `p.note` (no space) means a paragraph that also has the class `note`.
* Class and id names are case-sensitive and should describe the purpose.
* Prefer classes for most styling, because ids are strong and harder to override.

# Chapter 10: Practical CSS and Best Practices

## Section 1: CSS Variables and Custom Properties

When you build a real website, the same values appear again and again: the brand color, the main font, the spacing, the border radius. If you type them everywhere and later want to change one, you must find and edit every place. **CSS variables** (also called **custom properties**) solve this. You write a value once, and use it many times.

---

## 1. Declaring and Using a Variable

A custom property name **starts with two dashes** (`--`). You read its value with the `var()` function.

```html
<style>
  :root {
    --main-color: #0ea5e9;
  }
  body {
    font-family: Arial, sans-serif;
  }
  .btn {
    padding: 10px 22px;
    color: white;
    background-color: var(--main-color);
    border: 3px solid var(--main-color);
    border-radius: 8px;
  }
  .note {
    margin-top: 12px;
    padding: 10px;
    color: var(--main-color);
    border-left: 5px solid var(--main-color);
  }
</style>

<button class="btn">Button</button>
<div class="note">The same color is used three times from one variable.</div>
```

Change `--main-color` in one place, and every use changes with it.

---

## 2. Why Use :root?

`:root` selects the top element of the page (`<html>`). Variables declared there are **global**: you can use them anywhere on the page.

```text
:root {
  --brand: #0ea5e9;
  --text: #0f172a;
  --space: 16px;
}
```

---

## 3. Scope: Local Variables

A variable is available inside the element where it is declared, and in all of that element's **children**. This is called its **scope**.

```html
<style>
  :root {
    --accent: #0ea5e9;
  }
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    padding: 12px;
    margin-bottom: 8px;
    color: white;
    background-color: var(--accent);
    border-radius: 8px;
  }
  .danger {
    --accent: #dc2626;
  }
  .success {
    --accent: #16a34a;
  }
</style>

<div class="box">Default (global accent)</div>
<div class="box danger">Danger (local accent)</div>
<div class="box success">Success (local accent)</div>
```

The `.box` rule is written only once. Each element changes the variable it uses, and gets a different color.

---

## 4. Fallback Values

`var()` can take a second value that is used if the variable is **not defined**.

```text
.title {
  color: var(--title-color, #0f172a);
}
```

If `--title-color` is missing, the color becomes `#0f172a`. A fallback can also be another variable: `var(--a, var(--b, red))`.

---

## 5. What Can a Variable Hold?

A variable can hold almost any piece of CSS value.

```html
<style>
  :root {
    --radius: 12px;
    --shadow: 0 4px 12px rgba(0, 0, 0, 0.18);
    --font-main: Arial, sans-serif;
    --gap: 14px;
    --border: 2px solid #cbd5e1;
  }
  body {
    margin: 0;
    padding: var(--gap);
    font-family: var(--font-main);
    background-color: #f1f5f9;
  }
  .card {
    padding: var(--gap);
    margin-bottom: var(--gap);
    background-color: white;
    border: var(--border);
    border-radius: var(--radius);
    box-shadow: var(--shadow);
  }
</style>

<div class="card">Card one</div>
<div class="card">Card two</div>
```

Colors, lengths, fonts, shadows, whole borders, and even numbers can all be stored.

---

## 6. Variables with calc()

Combine variables with `calc()` to make scales.

```html
<style>
  :root {
    --space: 8px;
  }
  body {
    font-family: Arial, sans-serif;
  }
  .step {
    margin-bottom: var(--space);
    padding: calc(var(--space) * 2);
    color: white;
    background-color: #7c3aed;
    border-radius: 8px;
  }
  .big {
    padding: calc(var(--space) * 4);
    background-color: #db2777;
  }
</style>

<div class="step">Padding: 2 x space</div>
<div class="step big">Padding: 4 x space</div>
```

If you want to pass a plain number, store it without a unit and multiply: `--size: 4;` then `width: calc(var(--size) * 10px)`.

---

## 7. Dark Mode with Variables

Variables make theme switching easy. You redefine the same variables inside a media query or under a class.

```html
<style>
  :root {
    --bg: #f8fafc;
    --text: #0f172a;
    --card: #ffffff;
    --accent: #0ea5e9;
  }
  @media (prefers-color-scheme: dark) {
    :root {
      --bg: #0f172a;
      --text: #e2e8f0;
      --card: #1e293b;
      --accent: #38bdf8;
    }
  }
  body {
    margin: 0;
    padding: 16px;
    font-family: Arial, sans-serif;
    color: var(--text);
    background-color: var(--bg);
  }
  .card {
    padding: 16px;
    background-color: var(--card);
    border-left: 5px solid var(--accent);
    border-radius: 10px;
  }
</style>

<div class="card">This card follows your device theme (light or dark).</div>
```

No rule needs to be written twice. Only the variable values change.

---

## 8. Changing Variables with a Class

You can also switch themes by adding a class to the `<html>` or `<body>` element (for example with a button and JavaScript).

```text
:root {
  --bg: white;
  --text: black;
}
.dark {
  --bg: #0f172a;
  --text: white;
}
```

When `<body class="dark">` is set, every use of `var(--bg)` and `var(--text)` below it updates at once.

---

## 9. Variables Are Live

Unlike variables in preprocessors (like Sass), CSS variables stay **alive in the browser**. They can be changed by media queries, by `:hover`, and by JavaScript while the page is open.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .btn {
    --bg: #0ea5e9;
    padding: 12px 26px;
    color: white;
    border: none;
    border-radius: 8px;
    background-color: var(--bg);
    cursor: pointer;
    transition: background-color 0.2s ease;
  }
  .btn:hover {
    --bg: #7c3aed;
  }
</style>

<button class="btn">Hover me</button>
```

With JavaScript you can also change a variable, like this:

```text
document.documentElement.style.setProperty("--accent", "#16a34a");
```

---

## 10. Naming Tips

* Use clear lowercase names with dashes: `--color-primary`, `--space-md`, `--radius-lg`.
* Name by **purpose**, not by value: `--color-primary` is better than `--blue`, because the color might change later.
* Group variables by type: colors, spacing, fonts, shadows.
* Variable names are **case sensitive**. `--Main` and `--main` are different.
* Keep the global list in one place at the top of your CSS.

A small design system with tokens, a button style with variants, and a card:

```html
<style>

    --color-primary: #0ea5e9;

    --font: Arial, sans-serif;

  * {
    box-sizing: border-box;
  }

    margin: 0;

  }
  .card h3 {
    margin: 0 0 var(--space-sm) 0;
  }
  .card p {
    margin: 0 0 var(--space-md) 0;
    color: var(--color-muted);
  }

    --btn-bg: var(--color-primary);

```

## Common Mistakes

### Forgetting the Two Dashes

```text
:root { main-color: red; }       /* not a variable */
:root { --main-color: red; }
```

### Using the Variable Without var()

```text
.box { background-color: --main-color; }            /* invalid */
.box { background-color: var(--main-color); }
```

### Using a Variable Outside Its Scope

```text
.card { --accent: red; }
.footer { color: var(--accent); }      /* undefined here, since .footer is not inside .card */
```

### Naming by Value

```text
--blue: #0ea5e9;               /* breaks when the brand color changes */
--color-primary: #0ea5e9;      /* stays meaningful */
```

### Variables in Media Query Conditions

```text
@media (min-width: var(--bp)) { }    /* does not work, var() is not allowed here */
```

---

## Key Points

* A CSS **variable** (custom property) starts with `--` and is read with `var()`.
* Declare global variables on `:root`.
* A variable is available inside the element where it is declared, and in its children.
* `var(--name, fallback)` gives a backup value.
* Variables can hold colors, lengths, fonts, shadows and more, and they work with `calc()`.
* Change a variable inside a class, media query or `:hover` to update everything that uses it.
* Variables make themes and dark mode simple.
* Name variables by their **purpose**, such as `--color-primary`.
* Variables stay alive in the browser, and JavaScript can change them.

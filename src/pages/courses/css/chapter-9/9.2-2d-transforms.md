# Chapter 9: Transitions, Transforms and Animations

## Section 2: 2D Transforms

The `transform` property lets you **move, rotate, resize and tilt** an element without changing the layout around it. It is one of the most useful tools for hover effects, icons and animations. In this lesson you will learn the four main 2D transform functions.

---

## 1. What Does transform Do?

`transform` changes how an element is **drawn**, not where it sits in the layout. Other elements act as if the transformed element is still in its original place and size. That is why transforms are smooth and fast.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    gap: 14px;
    padding: 20px;
  }
  .box {
    width: 80px;
    height: 60px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    background-color: #0ea5e9;
    border-radius: 8px;
  }
  .rotated {
    transform: rotate(20deg);
    background-color: #f97316;
  }
</style>

<div class="row">
  <div class="box">Normal</div>
  <div class="box rotated">Rotated</div>
  <div class="box">Normal</div>
</div>
```

The rotated box turns, but its neighbors do not move.

---

## 2. translate(): Move

`translate()` moves an element sideways, up or down.

| Function | Meaning |
| -------- | ------- |
| `translate(50px, 20px)` | 50px right and 20px down |
| `translateX(50px)` | 50px to the right |
| `translateY(-20px)` | 20px up (negative moves up) |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .stage {
    height: 130px;
    padding: 10px;
    background-color: #e2e8f0;
  }
  .ghost {
    width: 80px;
    height: 50px;
    border: 2px dashed #64748b;
    position: absolute;
  }
  .box {
    width: 80px;
    height: 50px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    background-color: #7c3aed;
    border-radius: 8px;
    transform: translate(120px, 40px);
  }
</style>

<div class="stage">
  <div class="ghost"></div>
  <div class="box">Moved</div>
</div>
```

**Percentages** in `translate()` are based on the **element's own size**, not the parent. `translateX(100%)` moves the element by its own width. This is the key to centering tricks.

```css
.center {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

---

## 3. rotate(): Turn

`rotate()` turns an element around its center. The angle uses `deg` (degrees), `turn` or `rad`. Positive values turn **clockwise**.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    gap: 26px;
    padding: 24px;
  }
  .sq {
    width: 60px;
    height: 60px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    font-size: 13px;
    background-color: #16a34a;
    border-radius: 8px;
  }
  .a { transform: rotate(15deg); }
  .b { transform: rotate(45deg); }
  .c { transform: rotate(-30deg); }
</style>

<div class="row">
  <div class="sq a">15deg</div>
  <div class="sq b">45deg</div>
  <div class="sq c">-30deg</div>
</div>
```

`rotate(0.5turn)` is the same as `rotate(180deg)`, and `1turn` is a full circle.

---

## 4. scale(): Resize

`scale()` makes an element bigger or smaller. A value of `1` is the normal size.

| Function | Meaning |
| -------- | ------- |
| `scale(1.5)` | 150% size, in both directions |
| `scale(0.5)` | 50% size |
| `scale(2, 0.5)` | Twice as wide, half as tall |
| `scaleX(2)` | Only the width |
| `scaleY(0.5)` | Only the height |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    align-items: center;
    gap: 34px;
    padding: 30px;
  }
  .sq {
    width: 60px;
    height: 60px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    font-size: 13px;
    background-color: #db2777;
    border-radius: 8px;
  }
  .big { transform: scale(1.5); }
  .small { transform: scale(0.6); }
</style>

<div class="row">
  <div class="sq small">0.6</div>
  <div class="sq">1</div>
  <div class="sq big">1.5</div>
</div>
```

`scale()` also scales the content inside, including text and borders, unlike `width` and `height`.

---

## 5. skew(): Tilt

`skew()` slants an element along the x or y axis.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    gap: 26px;
    padding: 24px;
  }
  .sq {
    width: 80px;
    height: 50px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    background-color: #0ea5e9;
  }
  .a { transform: skewX(20deg); }
  .b { transform: skewY(15deg); }
  .c { transform: skew(20deg, 10deg); }
</style>

<div class="row">
  <div class="sq a">skewX</div>
  <div class="sq b">skewY</div>
  <div class="sq c">skew</div>
</div>
```

Skew is used for slanted banners and decorative shapes. To keep the text straight, skew a background layer, not the text itself.

## 6. Combining Transforms

You can put several functions into one `transform`. Separate them with **spaces**.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    width: 90px;
    height: 60px;
    margin: 40px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    background-color: #f97316;
    border-radius: 8px;
    transform: translateX(40px) rotate(20deg) scale(1.2);
  }
</style>

<div class="box">Combined</div>
```

**The order matters.** The functions run from **right to left** in terms of the coordinate system, so `translateX(40px) rotate(20deg)` is not the same as `rotate(20deg) translateX(40px)`. When you rotate first, the move goes along the rotated direction.

Also, a second `transform` rule **replaces** the first one. It does not add to it.

```css
.box { transform: rotate(20deg); }
.box { transform: scale(1.2); }      /* the rotation is gone */
```

## 7. transform-origin

By default, transforms happen around the **center** of the element. `transform-origin` changes the pivot point.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    gap: 50px;
    padding: 40px;
  }
  .pad {
    width: 80px;
    height: 50px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    background-color: #7c3aed;
    border-radius: 6px;
    transform: rotate(25deg);
  }
  .top-left { transform-origin: top left; background-color: #16a34a; }
  .center { transform-origin: center; }
</style>

<div class="row">
  <div class="pad center">center</div>
  <div class="pad top-left">top left</div>
</div>
```

Values can be keywords (`top left`, `bottom right`), lengths (`10px 20px`) or percentages (`0% 100%`).

## 8. Transform and Transition Together

Transforms and transitions work very well together for hover effects.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flex;
    gap: 20px;
    padding: 30px;
  }
  .icon {
    width: 70px;
    height: 70px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    font-size: 26px;
    background-color: #0ea5e9;
    border-radius: 16px;
    transition: transform 0.3s ease;
  }
  .spin:hover { transform: rotate(180deg); }
  .grow:hover { transform: scale(1.25); }
  .hop:hover { transform: translateY(-12px); }
</style>

<div class="row">
  <div class="icon spin">&#9733;</div>
  <div class="icon grow">&#9829;</div>
  <div class="icon hop">&#9650;</div>
</div>
```

## 9. Individual Transform Properties

Modern CSS also has separate properties: `translate`, `rotate` and `scale`. They are easier to combine and animate on their own.

```css
.box {
  translate: 40px 0;
  rotate: 20deg;
  scale: 1.2;
}
```

They are supported in current browsers, but `transform` is still the most common and works in older ones too.

---

## 10. A Quick Look at 3D

2D transforms work on the x and y axes. Adding a **perspective** allows 3D effects such as `rotateY()` and `rotateX()`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .scene {
    padding: 30px;
    perspective: 400px;
  }
  .flip {
    width: 140px;
    height: 70px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    background-color: #db2777;
    border-radius: 10px;
    transition: transform 0.6s ease;
  }
  .flip:hover {
    transform: rotateY(180deg);
  }
</style>

<div class="scene">
  <div class="flip">Hover to flip</div>
</div>
```

## Common Mistakes

### Thinking transform Moves the Layout

```css
.box { transform: translateX(100px); }   /* other elements do not move, the space stays */
```

### Overwriting a Transform

```css
.box { transform: rotate(20deg); }
.box:hover { transform: scale(1.2); }                  /* the rotation disappears */
.box:hover { transform: rotate(20deg) scale(1.2); }    /* keep both */
```

### Commas Between Transform Functions

```text
transform: rotate(20deg), scale(1.2);    /* invalid */
transform: rotate(20deg) scale(1.2);     /* correct, use spaces */
```

### Forgetting the Unit on Angles and Lengths

```text
transform: rotate(45);        /* invalid */
transform: rotate(45deg);
```

### Transforming an Inline Element

```css
span { transform: rotate(10deg); }                          /* inline elements ignore it */
span { display: inline-block; transform: rotate(10deg); }
```

---

## Key Points

* `transform` changes how an element is drawn. It does **not** change the layout around it.
* `translate()` moves, `rotate()` turns, `scale()` resizes and `skew()` tilts.
* Percentages in `translate()` use the element's own size.
* Combine several functions with spaces. Their **order matters**.
* A new `transform` replaces the old one, so rewrite all the functions you need.
* `transform-origin` changes the pivot point. The default is the center.
* Transforms and transitions are a great pair for hover effects.
* Transforms work on block and inline-block elements, not on plain inline elements.
* `perspective` with `rotateX()` or `rotateY()` gives simple 3D effects.

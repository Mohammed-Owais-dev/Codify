# Chapter 9: Transitions, Transforms and Animations

## Section 3: Keyframe Animations

A transition goes from one state to another, and it needs a trigger such as `:hover`. A **keyframe animation** can have **many steps**, can start by itself, and can repeat forever. In this lesson you will learn how to write `@keyframes` and use the `animation` property.

---

## 1. Two Parts of an Animation

Every CSS animation has two parts.

| Part | Job |
| ---- | --- |
| `@keyframes` | Describes **what** happens: the steps of the animation |
| `animation` | Applies the keyframes to an element and sets **how** it runs |

---

## 2. Your First Animation

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes slide {
    from {
      transform: translateX(0);
    }
    to {
      transform: translateX(200px);
    }
  }
  .box {
    width: 70px;
    padding: 14px 0;
    text-align: center;
    color: white;
    background-color: #0ea5e9;
    border-radius: 8px;
    animation-name: slide;
    animation-duration: 2s;
  }
</style>

<div class="box">Slide</div>
```

The box slides to the right in 2 seconds, then jumps back to its starting place. You will fix that jump with `animation-fill-mode` in lesson 9.4.

* `@keyframes slide` gives the animation a name and its steps.
* `from` is the start (0%) and `to` is the end (100%).
* `animation-name` connects the element to the keyframes.
* `animation-duration` is required. Without it, nothing is seen.

---

## 3. Percentage Keyframes

Use percentages for more than two steps.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes colors {
    0% {
      background-color: #ef4444;
    }
    33% {
      background-color: #f59e0b;
    }
    66% {
      background-color: #22c55e;
    }
    100% {
      background-color: #3b82f6;
    }
  }
  .box {
    width: 140px;
    padding: 20px 0;
    text-align: center;
    color: white;
    border-radius: 10px;
    animation: colors 4s linear infinite;
  }
</style>

<div class="box">Changing colors</div>
```

The browser calculates all the smooth steps **between** the keyframes by itself.

---

## 4. The animation Shorthand

The shorthand puts the main settings in one line.

```text
animation: name duration timing-function delay iteration-count direction fill-mode;
```

```css
.box {
  animation: slide 2s ease-in-out 0.5s infinite alternate;
}
```

| Part | Example | Meaning |
| ---- | ------- | ------- |
| name | `slide` | The `@keyframes` name |
| duration | `2s` | Length of one cycle |
| timing function | `ease-in-out` | The speed curve |
| delay | `0.5s` | Wait before starting |
| iteration count | `infinite` | How many times it runs |
| direction | `alternate` | Forward then backward |

You will see all of these in more detail in lesson 9.4.

---

## 5. Repeating with infinite

`animation-iteration-count` sets how many times the animation runs. Use a number or `infinite`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes spin {
    from {
      transform: rotate(0deg);
    }
    to {
      transform: rotate(360deg);
    }
  }
  .spinner {
    width: 50px;
    height: 50px;
    margin: 20px;
    border: 6px solid #bae6fd;
    border-top-color: #0284c7;
    border-radius: 50%;
    animation: spin 1s linear infinite;
  }
</style>

<div class="spinner"></div>
```

This is a loading spinner. It uses `linear` timing so the spin has a steady speed.

## 6. A Pulsing Effect

Keyframes can go from one state, to another, and back, in a single cycle.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes pulse {
    0% {
      transform: scale(1);
      box-shadow: 0 0 0 0 rgba(239, 68, 68, 0.6);
    }
    70% {
      transform: scale(1.08);
      box-shadow: 0 0 0 16px rgba(239, 68, 68, 0);
    }
    100% {
      transform: scale(1);
      box-shadow: 0 0 0 0 rgba(239, 68, 68, 0);
    }
  }
  .live {
    display: inline-block;
    margin: 20px;
    padding: 10px 22px;
    color: white;
    font-weight: bold;
    background-color: #ef4444;
    border-radius: 999px;
    animation: pulse 1.8s ease-out infinite;
  }
</style>

<div class="live">LIVE</div>
```

## 7. Animating Several Properties

In each keyframe, you can change many properties at once.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes bounce {
    0%, 100% {
      transform: translateY(0);
      background-color: #f97316;
    }
    50% {
      transform: translateY(-50px);
      background-color: #facc15;
    }
  }
  .ball {
    width: 50px;
    height: 50px;
    margin: 60px 30px 10px;
    border-radius: 50%;
    animation: bounce 1s ease-in-out infinite;
  }
</style>

<div class="ball"></div>
```

`0%, 100%` is a quick way to give the same style to the first and last steps, so the animation loops without a jump.

## 8. Reusing Keyframes

One `@keyframes` rule can be used by many elements, each with different timing.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes fade-up {
    from {
      opacity: 0;
      transform: translateY(20px);
    }
    to {
      opacity: 1;
      transform: translateY(0);
    }
  }
  .item {
    margin-bottom: 8px;
    padding: 12px;
    color: white;
    background-color: #7c3aed;
    border-radius: 8px;
    animation: fade-up 0.6s ease both;
  }
  .item:nth-child(2) { animation-delay: 0.2s; }
  .item:nth-child(3) { animation-delay: 0.4s; }
</style>

<div class="item">First item</div>
<div class="item">Second item</div>
<div class="item">Third item</div>
```

The items appear one after the other, because each has a different delay. `both` is a fill mode that holds the first keyframe during the delay.

## 9. Animating Text and Backgrounds

You can animate gradients and shadows too. Here is a moving stripe background.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes move-stripes {
    from {
      background-position: 0 0;
    }
    to {
      background-position: 40px 0;
    }
  }
  .progress {
    width: 260px;
    height: 24px;
    border-radius: 12px;
    background-color: #0ea5e9;
    background-image: repeating-linear-gradient(
      45deg,
      rgba(255, 255, 255, 0.3) 0,
      rgba(255, 255, 255, 0.3) 10px,
      transparent 10px,
      transparent 20px
    );
    background-size: 40px 40px;
    animation: move-stripes 1s linear infinite;
  }
</style>

<div class="progress"></div>
```

## 10. Transition vs Animation

| | Transition | Animation |
| - | ---------- | --------- |
| Needs a trigger (like hover) | Yes | No, it can start by itself |
| Number of steps | Two (start and end) | Any number of keyframes |
| Can repeat | No | Yes (`infinite`) |
| Complexity | Simple | More powerful |
| Best for | Hover and focus effects | Loaders, attention effects, intros |

## Real-World Example 🌍

A loading screen with a spinner, a pulsing dot row and a text that fades in:

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 20px;
    font-family: Arial, sans-serif;
    background-color: #0f172a;
    color: white;
    text-align: center;

  @keyframes spin {
    to {
      transform: rotate(360deg);
    }
  }
  @keyframes blink {
    0%, 80%, 100% {
      opacity: 0.2;
      transform: scale(0.8);
    }
    40% {
      opacity: 1;
      transform: scale(1);
    }
  }
  @keyframes fade-in {

      opacity: 0;
```

## Common Mistakes

### Forgetting the Duration

```css
.box { animation-name: slide; }                      /* the default duration is 0s */
.box { animation-name: slide; animation-duration: 2s; }
```

### A Mismatch Between the Names

```css
@keyframes slide-in { }
.box { animation: slide 1s; }       /* the names do not match, nothing runs */
```

### The Animation Jumps Back at the End

```css
.box { animation: slide 2s; }              /* returns to the start */
.box { animation: slide 2s forwards; }     /* stays at the end state */
```

### Loops That Jump at the Restart

```css
@keyframes loop { from { opacity: 0; } to { opacity: 1; } }    /* jumps at each restart */
@keyframes loop { 0%, 100% { opacity: 0; } 50% { opacity: 1; } }
```

### Animating Layout Properties

```css
@keyframes move { to { left: 200px; } }              /* can be janky */
@keyframes move { to { transform: translateX(200px); } }   /* smoother */
```

## Key Points

* A keyframe animation has two parts: `@keyframes` (the steps) and `animation` (applies and controls it).
* Use `from` and `to`, or percentages, to describe the steps.
* `animation-duration` is required to see anything.
* `animation-iteration-count: infinite` repeats forever.
* Use `0%, 100%` together for smooth looping animations.
* The `animation` shorthand sets the name, duration, timing, delay, count, direction and fill mode.
* One `@keyframes` rule can be reused by many elements, with different delays.
* Animations can start by themselves, while transitions need a trigger.
* Animate `transform` and `opacity` for the best performance.

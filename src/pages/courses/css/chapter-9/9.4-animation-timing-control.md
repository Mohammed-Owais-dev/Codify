# Chapter 9: Transitions, Transforms and Animations

## Section 4: Animation Timing and Control

You already know how to write `@keyframes` and start an animation. Now you will learn how to **control** it: its speed curve, its delay, how many times it plays, its direction, what happens before and after it, and how to pause it. These controls turn a basic animation into a polished one.

---

## 1. The Animation Properties

| Property | What it controls |
| -------- | ---------------- |
| `animation-name` | Which `@keyframes` to use |
| `animation-duration` | The length of one cycle |
| `animation-timing-function` | The speed curve |
| `animation-delay` | The wait before starting |
| `animation-iteration-count` | How many times it plays |
| `animation-direction` | Forward, backward or both |
| `animation-fill-mode` | The style before and after the animation |
| `animation-play-state` | Running or paused |

---

## 2. animation-timing-function

The timing function controls how the speed changes **between each pair of keyframes**.

| Value | Speed |
| ----- | ----- |
| `ease` | Slow, fast, slow (default) |
| `linear` | Constant speed |
| `ease-in` | Starts slow |
| `ease-out` | Ends slow |
| `ease-in-out` | Slow at both ends |
| `steps(n)` | Jumps in `n` steps |
| `cubic-bezier(a, b, c, d)` | A custom curve |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes run {
    from {
      margin-left: 0;
    }
    to {
      margin-left: 220px;
    }
  }
  .track {
    width: 290px;
    margin-bottom: 6px;
    background-color: #e2e8f0;
    border-radius: 6px;
  }
  .dot {
    width: 70px;
    padding: 6px 0;
    text-align: center;
    color: white;
    font-size: 12px;
    background-color: #0ea5e9;
    border-radius: 6px;
    animation: run 2.5s infinite alternate;
  }
  .l .dot { animation-timing-function: linear; }
  .e .dot { animation-timing-function: ease-in-out; }
  .s .dot { animation-timing-function: steps(5); }
</style>

<div class="track l"><div class="dot">linear</div></div>
<div class="track e"><div class="dot">ease-in-out</div></div>
<div class="track s"><div class="dot">steps(5)</div></div>
```

The `steps()` function is great for sprite animations and typing effects.

## 3. animation-delay

`animation-delay` makes the animation wait before it starts.

* A **positive** value waits.
* A **negative** value starts the animation **already in progress**, as if it began earlier. This is a nice trick for making items look random.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes jump {
    0%, 100% {
      transform: translateY(0);
    }
    50% {
      transform: translateY(-34px);
    }
  }
  .row {
    display: flex;
    gap: 10px;
    padding: 40px 10px 10px;
  }
  .ball {
    width: 30px;
    height: 30px;
    background-color: #db2777;
    border-radius: 50%;
    animation: jump 1s ease-in-out infinite;
  }
  .ball:nth-child(2) { animation-delay: 0.15s; }
  .ball:nth-child(3) { animation-delay: 0.3s; }
  .ball:nth-child(4) { animation-delay: 0.45s; }
</style>

<div class="row">
  <div class="ball"></div>
  <div class="ball"></div>
  <div class="ball"></div>
  <div class="ball"></div>
</div>
```

## 4. animation-iteration-count

This sets how many times the animation plays. Use whole numbers, decimals or `infinite`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes shake {
    0%, 100% {
      transform: translateX(0);
    }
    25% {
      transform: translateX(-8px);
    }
    75% {
      transform: translateX(8px);
    }
  }
  .alert {
    display: inline-block;
    margin: 16px;
    padding: 12px 20px;
    color: white;
    background-color: #dc2626;
    border-radius: 8px;
    animation: shake 0.4s ease-in-out 3;
  }
</style>

<div class="alert">Wrong password! (shakes 3 times)</div>
```

## 5. animation-direction

`animation-direction` decides which way the keyframes are played.

| Value | Meaning |
| ----- | ------- |
| `normal` | Start to end, then restart (default) |
| `reverse` | End to start |
| `alternate` | Forward, then backward, then forward... |
| `alternate-reverse` | Backward first, then forward... |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes slide {
    from {
      margin-left: 0;
    }
    to {
      margin-left: 200px;
    }
  }
  .track {
    width: 280px;
    margin-bottom: 6px;
    background-color: #e2e8f0;
    border-radius: 6px;
  }
  .dot {
    width: 70px;
    padding: 6px 0;
    text-align: center;
    color: white;
    font-size: 12px;
    background-color: #7c3aed;
    border-radius: 6px;
    animation: slide 2s ease-in-out infinite;
  }
  .n .dot { animation-direction: normal; }
  .a .dot { animation-direction: alternate; }
</style>

<div class="track n"><div class="dot">normal</div></div>
<div class="track a"><div class="dot">alternate</div></div>
```

`normal` jumps back to the start at the end of each cycle. `alternate` moves back smoothly, which looks better for most loops.

## 6. animation-fill-mode

By default, an animation has **no effect** before it starts (during a delay) or after it ends. The element goes back to its normal style. `animation-fill-mode` changes that.

| Value | Meaning |
| ----- | ------- |
| `none` | No styles outside the animation (default) |
| `forwards` | Keeps the **last keyframe** after the animation ends |
| `backwards` | Applies the **first keyframe** during the delay |
| `both` | Both `forwards` and `backwards` |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes appear {
    from {
      opacity: 0;
      transform: translateY(20px);
    }
    to {
      opacity: 1;
      transform: translateY(0);
    }
  }
  .box {
    margin: 8px 0;
    padding: 12px;
    color: white;
    background-color: #16a34a;
    border-radius: 8px;
    animation: appear 0.8s ease 1s;
  }
  .keep {
    animation-fill-mode: both;
    background-color: #0ea5e9;
  }
</style>

<div class="box">Without fill-mode: visible, then it jumps in after 1s</div>
<div class="box keep">With "both": hidden during the delay, stays at the end</div>
```

The first box is visible during its delay and then flashes. The second box waits invisibly, animates in and stays in place. For entrance animations with a delay, `both` is the best choice.

## 7. animation-play-state

`animation-play-state` can be `running` or `paused`. A common use is to pause an animation on hover.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes spin {
    to {
      transform: rotate(360deg);
    }
  }
  .wheel {
    width: 80px;
    height: 80px;
    margin: 20px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    font-size: 12px;
    text-align: center;
    background-color: #f97316;
    border-radius: 50%;
    animation: spin 4s linear infinite;
  }
  .wheel:hover {
    animation-play-state: paused;
  }
</style>

<div class="wheel">Hover to pause</div>
```

## 8. Multiple Animations

An element can run several animations at once. Separate them with commas.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  @keyframes float {
    0%, 100% {
      transform: translateY(0);
    }
    50% {
      transform: translateY(-20px);
    }
  }
  @keyframes glow {
    0%, 100% {
      box-shadow: 0 0 6px #38bdf8;
    }
    50% {
      box-shadow: 0 0 26px #38bdf8;
    }
  }
  .orb {
    width: 70px;
    height: 70px;
    margin: 40px;
    background-color: #0ea5e9;
    border-radius: 50%;
    animation: float 2.4s ease-in-out infinite, glow 1.2s ease-in-out infinite;
  }
</style>

<div class="orb"></div>
```

## 9. A Typing Effect with steps()

`steps()` can make a typewriter effect with just CSS.

```html
<style>
  body {
    font-family: monospace;
    font-size: 18px;
  }
  @keyframes typing {
    from {
      width: 0;
    }
    to {
      width: 17ch;
    }
  }
  @keyframes caret {
    50% {
      border-color: transparent;
    }
  }
  .typing {
    width: 17ch;
    overflow: hidden;
    white-space: nowrap;
    border-right: 3px solid #0f172a;
    animation: typing 3s steps(17) 1s both, caret 0.7s step-end infinite;
  }
</style>

<div class="typing">Hello, Codify web!</div>
```

The text has 17 characters, so `steps(17)` shows one new letter per step. The width uses `ch` units, which match the width of a character in a monospace font.

## 10. Respecting Motion Preferences

Some people feel sick or distracted by moving content. They can turn on **reduce motion** in their device settings. Your CSS can respect it:

```text
@media (prefers-reduced-motion: reduce) {
  .spinner,
  .ball {
    animation: none;
  }
}
```

You will see this in more detail in lesson 9.5.

## Real-World Example 🌍

A notification toast that slides in after a delay, stays, and a progress bar that counts down:

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 20px;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  @keyframes toast-in {
    from {
      opacity: 0;
      transform: translateY(-20px);
    }
    to {
      opacity: 1;
      transform: translateY(0);
    }
  }
  @keyframes countdown {
    from {
      transform: scaleX(1);
    }
    to {
      transform: scaleX(0);
    }
  }
  .toast {
    position: relative;
    max-width: 300px;
    margin: 0 auto;
    overflow: hidden;
    padding: 14px 16px;
    color: white;
    background-color: #0f172a;
    border-radius: 10px;
    box-shadow: 0 8px 20px rgba(0, 0, 0, 0.25);
    animation: toast-in 0.5s ease 0.5s both;
  }
  .toast .bar {
    position: absolute;
    left: 0;
    bottom: 0;
    width: 100%;
    height: 4px;
    background-color: #38bdf8;
    transform-origin: left;
    animation: countdown 5s linear 1s forwards;
  }
  .toast:hover .bar {
    animation-play-state: paused;
  }
</style>

<div class="toast">
  Lesson saved successfully
  <div class="bar"></div>
</div>
```

## Common Mistakes

### Elements Flash Before a Delayed Animation

```text
.box { animation: appear 1s ease 2s; }         /* visible for 2s, then it jumps */
.box { animation: appear 1s ease 2s both; }    /* hidden during the delay */
```

### The Element Resets After the Animation

```text
.box { animation: grow 1s; }              /* goes back to its normal size */
.box { animation: grow 1s forwards; }     /* stays grown */
```

### A Jump in an Infinite Loop

```text
.box { animation: slide 2s infinite; }                   /* snaps back at the end */
.box { animation: slide 2s infinite alternate; }         /* moves back smoothly */
```

### Using a Comma Wrongly with Many Animations

```text
animation: a 1s b 2s;         /* invalid, no comma */
animation: a 1s, b 2s;        /* correct */
```

### Ignoring Reduced-Motion Preferences

```text
/* Large or constant motion can bother some users. Always offer a reduced option. */
```

## Key Points

* `animation-timing-function` sets the speed curve. Use `linear` for spinners and `ease-in-out` for natural motion.
* `animation-delay` waits before starting. Negative delays start the animation part-way through.
* `animation-iteration-count` can be a number or `infinite`.
* `animation-direction: alternate` plays forward and backward for smooth loops.
* `animation-fill-mode` controls styles before and after: use `forwards` to keep the end state, and `both` for delayed entrances.
* `animation-play-state: paused` pauses the animation, for example on hover.
* You can run many animations on one element by separating them with commas.
* `steps()` creates jumpy, frame-by-frame effects such as typing.
* Always consider users who prefer reduced motion.

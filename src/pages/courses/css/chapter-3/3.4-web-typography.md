# Chapter 3: Colors, Text and Typography

## Section 4: Google Fonts and Web Typography

So far you used fonts that already exist on most computers. But a designer's favorite font may not be installed on a visitor's phone. **Web fonts** solve this problem by sending the font file together with your page. In this lesson you will learn how to add Google Fonts, how to self-host fonts, and the basics of good typography on the web.

---

## 1. System Fonts vs Web Fonts

| | System (web-safe) fonts | Web fonts |
| - | ----------------------- | --------- |
| Where the font lives | Already on the user's device | Downloaded from a server when the page loads |
| Examples | Arial, Georgia, Courier New | Poppins, Roboto, Playfair Display |
| Speed | Instant, nothing to download | Small download needed |
| Choice | Limited | Thousands of fonts |
| Same look everywhere | Not always | Yes |

---

## 2. What Is Google Fonts?

**Google Fonts** (fonts.google.com) is a free library of hundreds of open-source fonts. You choose a font, copy a small piece of code into your page, and the font works for every visitor. It is the most popular way to use web fonts.

---

## 3. Steps to Add a Google Font

1. Go to **fonts.google.com** and find a font you like.
2. Open the font and select the **weights** you need (for example Regular 400 and Bold 700).
3. Copy the `<link>` code that Google gives you.
4. Paste it inside the `<head>` of your HTML page, **before** your own stylesheet.
5. Use the font name in your CSS `font-family`.

```html
<head>
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap" rel="stylesheet">
  <link rel="stylesheet" href="css/style.css">
</head>
```

The two `preconnect` lines tell the browser to connect to Google early, so the font loads faster.

---

## 4. Using the Font in CSS

After adding the link, use the font like any other. Always keep fallback fonts in the stack, in case the font fails to load.

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap" rel="stylesheet">

<style>
  body {
    font-family: "Poppins", Arial, sans-serif;
    padding: 16px;
  }
  .normal {
    font-weight: 400;
  }
  .bold {
    font-weight: 700;
  }
</style>

<h2 class="bold">Poppins from Google Fonts</h2>
<p class="normal">This paragraph uses the regular weight of Poppins.</p>
<p class="bold">This paragraph uses the bold weight.</p>
```

You need an internet connection for the preview to show the Google font. Without it, the browser shows the next font in your stack.

---

## 5. Choosing Only the Weights You Need

Every weight and style is a separate file download. More files make the page slower.

```text
family=Poppins:wght@400            one weight (fast)
family=Poppins:wght@400;700        two weights (common)
family=Poppins:ital,wght@0,400;1,400   regular and italic
```

A good rule: **use one or two fonts, and only two or three weights** for a whole website.

---

## 6. Loading Several Fonts

To use two fonts, join them with `&family=` in one link.

```text
https://fonts.googleapis.com/css2?family=Playfair+Display:wght@700&family=Lato:wght@400;700&display=swap
```

Spaces in font names become a plus sign (`Playfair+Display`).

---

## 7. Font Pairing

Pairing means using **two fonts** that look good together, usually one for headings and one for body text. Easy ways to pair fonts:

* **Contrast:** a serif heading with a sans-serif body (or the opposite).
* **Keep it simple:** two fonts are enough for most sites. More than three looks messy.
* **Use weight and size** for variety instead of adding more fonts.

```html
<link href="https://fonts.googleapis.com/css2?family=Playfair+Display:wght@700&family=Lato:wght@400;700&display=swap" rel="stylesheet">

<style>
  body {
    font-family: "Lato", Arial, sans-serif;
    font-size: 17px;
    line-height: 1.7;
    color: #334155;
    padding: 16px;
    max-width: 460px;
  }
  h1 {
    font-family: "Playfair Display", Georgia, serif;
    font-size: 34px;
    color: #0f172a;
    line-height: 1.2;
  }
</style>

<h1>The Art of Reading Online</h1>
<p>A strong serif heading paired with a clean sans-serif body gives the page character, and keeps long text comfortable to read.</p>
```

---

## 8. The display=swap Setting

While a web font is downloading, the browser must decide what to show. The `display=swap` part of the Google Fonts link tells the browser: "Show the text immediately in a fallback font, then **swap** to the web font when it arrives."

This avoids a blank space where text should be. When you write your own `@font-face`, the same idea is `font-display: swap;`.

---

## 9. Using the @import Method

Google also gives an `@import` option. It goes at the top of your CSS file.

```css
@import url("https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap");

body {
  font-family: "Poppins", sans-serif;
}
```

This works, but the `<link>` method is usually faster because the browser can start downloading the font earlier.

---

## 10. Self-Hosting Fonts with @font-face

You can also keep the font files in your own project and load them with `@font-face`. This works offline and does not depend on another company's server.

```text
my-site/
  fonts/
    myfont-regular.woff2
    myfont-bold.woff2
  css/
    style.css
```

```css
@font-face {
  font-family: "My Font";
  src: url("../fonts/myfont-regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: "My Font";
  src: url("../fonts/myfont-bold.woff2") format("woff2");
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}

body {
  font-family: "My Font", Arial, sans-serif;
}
```

Use the **WOFF2** format. It is small and works in all modern browsers. Only use fonts you have a license to use. Google Fonts are free for personal and commercial use.

## 11. Rules of Good Web Typography

* **Readable size:** body text at 16px or more.
* **Good line height:** about 1.5 to 1.7 for paragraphs.
* **Comfortable line length:** 45 to 75 characters per line. In CSS you can use the `ch` unit (about the width of the character 0), such as `max-width: 65ch;`.
* **Clear hierarchy:** headings should be clearly larger or bolder than body text.
* **Strong contrast:** dark text on a light background, or the opposite.
* **Consistency:** use the same fonts, sizes and spacing across all pages.

```html
<style>
  body {
    font-family: Georgia, serif;
    font-size: 18px;
    line-height: 1.7;
    color: #1e293b;
    padding: 16px;
  }
  .article {
    max-width: 40ch;
    background-color: #f8fafc;
    padding: 16px;
    border-radius: 8px;
  }
</style>

<div class="article">
  <p>This paragraph is limited to about 40 characters per line by using max-width in the ch unit. Short lines like these are easy for the eyes to follow from one line to the next.</p>
</div>
```

## Real-World Example

A landing section that uses a Google font pair, consistent sizes and good spacing:

```html
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;600;700&family=Merriweather:wght@400&display=swap" rel="stylesheet">

<style>
  body {
    margin: 0;
    font-family: "Merriweather", Georgia, serif;
    color: #334155;
    line-height: 1.8;
  }
  .hero {
    background-color: #0f172a;
    color: #f1f5f9;
    padding: 40px 24px;
    text-align: center;
  }
  .hero h1 {
    font-family: "Poppins", Arial, sans-serif;
    font-size: 36px;
    font-weight: 700;
    margin: 0 0 10px;
  }
  .hero p {
    font-size: 16px;
    max-width: 44ch;
    margin: 0 auto 20px;
    color: #cbd5e1;
  }
  .hero a {
    font-family: "Poppins", Arial, sans-serif;
    font-weight: 600;
    background-color: #38bdf8;
    color: #0f172a;
    padding: 10px 24px;
    border-radius: 24px;
    text-decoration: none;
    display: inline-block;
  }
</style>

<section class="hero">
  <h1>Learn Web Design</h1>
  <p>Build beautiful websites step by step, with clear lessons and simple examples for every beginner.</p>
  <a href="#">Start Learning</a>
</section>
```

Poppins is used for the heading and the button. Merriweather is used for the paragraph. Two fonts and three weights are enough for a polished page.

## Common Mistakes

### Using a Font Without Loading It

```text
font-family: "Poppins", sans-serif;   /* but no link or @font-face was added */
```

The browser cannot find Poppins on the user's device, so it uses the fallback. Always load web fonts first.

### Wrong Font Name in CSS

```text
Loaded:  Playfair Display
CSS:     font-family: "Playfair", serif;     /* wrong name */
CSS:     font-family: "Playfair Display", serif;    /* correct */
```

### Loading Too Many Fonts and Weights

```text
Five fonts with six weights each can add a lot of download time.
Choose one or two fonts and only the weights you use.
```

### Putting the Font Link After Your Own CSS

```text
Place the Google Fonts <link> before your own stylesheet link
so the font is requested as early as possible.
```

### No Fallback Fonts

```text
font-family: "Poppins";                       /* risky */
font-family: "Poppins", Arial, sans-serif;    /* safe */
```

### Using a Weight That Was Not Loaded

```text
Loaded: wght@400
CSS:    font-weight: 700;     /* the browser fakes bold, which can look poor */
```

---

## Key Points

* **Web fonts** are downloaded with the page, so every visitor sees the same typeface.
* **Google Fonts** is a free library. You copy a `<link>` into `<head>` and use the name in `font-family`.
* Add `preconnect` links and `display=swap` for faster, smoother loading.
* Load only the **fonts and weights** you really use. Fewer files mean a faster page.
* Always give **fallback fonts** in the font stack.
* **Font pairing** works best with two fonts: often a serif heading and a sans-serif body.
* You can **self-host** fonts using `@font-face` and the **WOFF2** format.
* Good typography means readable size, comfortable line height, a line length of 45 to 75 characters, clear hierarchy and strong contrast.

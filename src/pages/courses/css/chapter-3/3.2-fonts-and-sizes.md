# Chapter 3: Colors, Text and Typography

## Section 2: Font Families and Font Sizes

The font you choose changes the personality of your page. A school website, a news site and a gaming site all use different fonts to create a different feeling. In this lesson you will learn how to choose fonts, set their size, weight and style, and control the space between lines.

---

## 1. The font-family Property

`font-family` sets which font the text uses. You write a **list** of fonts, separated by commas. The browser tries them from left to right and uses the first one it finds on the user's device.

```html
<style>
  .demo {
    font-family: "Trebuchet MS", Arial, sans-serif;
    font-size: 20px;
  }
</style>

<p class="demo">This text tries Trebuchet MS first, then Arial, then any sans-serif font.</p>
```

This list is called a **font stack**. The last item in the stack should always be a **generic family**, as a safe backup.

---

## 2. Generic Font Families

Generic families are groups of similar fonts. Every device has at least one font for each group.

| Generic family | Look | Typical use |
| -------------- | ---- | ----------- |
| `serif` | Small strokes (feet) on the letters | Books, news, formal text |
| `sans-serif` | Clean letters without feet | Websites and apps |
| `monospace` | Every letter has the same width | Code and terminals |
| `cursive` | Handwriting style | Decoration (use rarely) |
| `system-ui` | The default font of the user's operating system | Apps that should feel native |

```html
<style>
  p {
    font-size: 22px;
    margin: 8px 0;
  }
  .serif { font-family: Georgia, serif; }
  .sans { font-family: Arial, sans-serif; }
  .mono { font-family: "Courier New", monospace; }
</style>

<p class="serif">Serif: Georgia</p>
<p class="sans">Sans-serif: Arial</p>
<p class="mono">Monospace: Courier New</p>
```

---

## 3. Font Names With Spaces

If a font name contains **spaces**, write it inside quotes. Single-word names such as Arial and Georgia do not need quotes.

```text
font-family: "Times New Roman", serif;       /* quotes needed */
font-family: "Open Sans", Arial, sans-serif; /* quotes needed */
font-family: Verdana, sans-serif;            /* no quotes needed */
```

---

## 4. Safe Fonts and Fallbacks

Fonts only work if they are **installed on the visitor's device**. A font that exists on your laptop may be missing on someone else's phone. This is why you always add fallbacks.

| Font stack | Looks like |
| ---------- | ---------- |
| `Arial, Helvetica, sans-serif` | Clean and neutral |
| `Georgia, "Times New Roman", serif` | Classic and readable |
| `"Courier New", Courier, monospace` | Typewriter or code |
| `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` | Modern native look on every device |

In Lesson 3.4 you will learn how to use **web fonts** that load from the internet, so every visitor sees the same font.

---

## 5. The font-size Property

`font-size` sets how big the text is. The default size in most browsers is **16px**.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .small { font-size: 12px; }
  .normal { font-size: 16px; }
  .large { font-size: 24px; }
  .huge { font-size: 40px; }
</style>

<p class="small">12 pixels</p>
<p class="normal">16 pixels</p>
<p class="large">24 pixels</p>
<p class="huge">40 pixels</p>
```

---

## 6. Font Size Units

| Unit | Meaning | Example |
| ---- | ------- | ------- |
| `px` | Fixed pixels | `16px` |
| `em` | Relative to the **parent's** font size | `1.5em` is 1.5 times the parent |
| `rem` | Relative to the **root (html)** font size | `1.5rem` is 1.5 times 16px = 24px |
| `%` | Percent of the parent's font size | `150%` |
| `vw` | A percent of the screen width | `4vw` |

```html
<style>
  html {
    font-size: 16px;
  }
  body {
    font-family: Arial, sans-serif;
  }
  .rem-demo {
    font-size: 1.5rem;
  }
  .parent {
    font-size: 20px;
  }
  .child {
    font-size: 1.5em;
  }
</style>

<p class="rem-demo">1.5rem = 24px (1.5 x 16px)</p>
<div class="parent">
  Parent text is 20px
  <p class="child">Child is 1.5em = 30px (1.5 x 20px)</p>
</div>
```

**Why `rem` is a good choice:** people can change their browser's default text size for better readability. Sizes written in `rem` follow that choice, but fixed `px` sizes do not. Many developers use `rem` for font sizes.

---

## 7. Size Keywords

You can also use words such as `small`, `medium`, `large` and `x-large`. They are not common in modern projects. Most developers use `rem`, `em` or `px`.

---

## 8. The font-weight Property

`font-weight` controls how thick the letters are.

| Value | Meaning |
| ----- | ------- |
| `normal` | Regular text (same as `400`) |
| `bold` | Bold text (same as `700`) |
| `100` to `900` | Numbers for different thicknesses (works if the font has those weights) |
| `lighter` / `bolder` | Lighter or bolder than the parent |

```html
<style>
  body {
    font-family: Arial, sans-serif;
    font-size: 20px;
  }
  .w4 { font-weight: 400; }
  .w6 { font-weight: 600; }
  .w7 { font-weight: 700; }
  .w9 { font-weight: 900; }
</style>

<p class="w4">Weight 400 (normal)</p>
<p class="w6">Weight 600 (semi bold)</p>
<p class="w7">Weight 700 (bold)</p>
<p class="w9">Weight 900 (black, if the font has it)</p>
```

Some fonts have only two weights, normal and bold. In that case in-between numbers look the same as the nearest available weight.

---

## 9. The font-style Property

`font-style` is mainly used for italic text.

```html
<style>
  body {
    font-family: Georgia, serif;
    font-size: 20px;
  }
  .normal { font-style: normal; }
  .italic { font-style: italic; }
  .oblique { font-style: oblique; }
</style>

<p class="normal">Normal style</p>
<p class="italic">Italic style</p>
<p class="oblique">Oblique style (a slanted normal font)</p>
```

Use `font-style: normal` to remove the italics that browsers add to some elements such as `<em>` and `<address>`.

---

## 10. Line Height

`line-height` controls the space between lines of text. Good spacing makes long text far easier to read.

```html
<style>
  body {
    font-family: Arial, sans-serif;
    font-size: 17px;
  }
  p {
    width: 300px;
    margin-bottom: 18px;
  }
  .tight {
    line-height: 1;
  }
  .comfortable {
    line-height: 1.6;
  }
</style>

<p class="tight">Line height 1. The lines are very close, which makes a paragraph feel crowded and tiring to read.</p>
<p class="comfortable">Line height 1.6. The lines have more room, which makes a paragraph feel open and easy to read.</p>
```

For body text, a `line-height` between **1.4 and 1.7** works well. Write it **without a unit** (`1.6`), so it scales with each element's font size.

---

## 11. The font Shorthand

The `font` property sets several font values in one line.

```text
font: font-style font-weight font-size/line-height font-family;

font: italic bold 18px/1.5 Georgia, serif;
font: 16px Arial, sans-serif;
```

Rules for the shorthand:

* **font-size** and **font-family** are required, and must be in this order.
* Style and weight (optional) come **before** the size.
* `line-height` is added after the size with a slash.
* Any value you leave out is reset to its default.

```html
<style>
  .card {
    font: italic 700 22px/1.4 Georgia, serif;
    color: #7c3aed;
  }
</style>

<p class="card">Set with one font declaration.</p>
```

## Real-World Example

A readable article style with a clear text hierarchy:

```html
<style>
  html {
    font-size: 16px;
  }
  body {
    font-family: system-ui, "Segoe UI", Arial, sans-serif;
    font-size: 1rem;
    line-height: 1.6;
    color: #334155;
    background-color: #f8fafc;
    padding: 20px;
    max-width: 560px;
  }
  h1 {
    font-family: Georgia, "Times New Roman", serif;
    font-size: 2rem;
    line-height: 1.2;
    color: #0f172a;
    margin-bottom: 4px;
  }
  .meta {
    font-size: 0.85rem;
    color: #64748b;
    font-style: italic;
    margin-top: 0;
  }
  .lead {
    font-size: 1.15rem;
    font-weight: 600;
  }
  code {
    font-family: "Courier New", monospace;
    background-color: #e2e8f0;
    padding: 2px 6px;
    border-radius: 4px;
    font-size: 0.9rem;
  }
</style>

<h1>Why Fonts Matter</h1>
<p class="meta">Posted by Meena, 5 minute read</p>
<p class="lead">Good typography makes content easy and pleasant to read.</p>
<p>Use <code>rem</code> units for sizes and keep the <code>line-height</code> around 1.6 for body text. A strong heading, a clear lead paragraph and a comfortable body are the base of every readable page.</p>
```

The page has a clear **hierarchy**: a large serif heading, a small gray meta line, a bold lead paragraph, and normal body text.

## Common Mistakes

### Missing Quotes Around Names With Spaces

```text
font-family: Open Sans, sans-serif;       /* risky */
font-family: "Open Sans", sans-serif;     /* correct */
```

### No Fallback Font

```text
font-family: "Special Font";                  /* if missing, the browser picks any font */
font-family: "Special Font", Arial, sans-serif;  /* safe */
```

### Putting the Size Without a Unit

```text
font-size: 18;       /* invalid */
font-size: 18px;     /* correct */
```

### Wrong Order in the font Shorthand

```text
font: Arial 16px;    /* invalid: size must come before family */
font: 16px Arial;    /* correct */
```

### Using a Unit on line-height When You Do Not Need To

```text
line-height: 1.5;      /* scales with each element's font size */
line-height: 24px;     /* stays fixed, even if the font gets bigger */
```

### Very Small Text

```text
font-size: 10px;
```

Tiny text is hard to read, especially on phones. Keep body text at 16px or larger.

---

## Key Points

* `font-family` takes a **list of fonts** (a font stack), and the last should be a generic family.
* Generic families are `serif`, `sans-serif`, `monospace`, `cursive` and `system-ui`.
* Font names with spaces must be written in quotes.
* The default text size is **16px**. Use `rem` and `em` for sizes that respond to the user's settings.
* `em` is relative to the parent's font size, and `rem` is relative to the root font size.
* `font-weight` can be `normal`, `bold` or a number from 100 to 900.
* `font-style: italic` makes text italic.
* `line-height` between 1.4 and 1.7, written without a unit, makes text comfortable to read.
* The `font` shorthand needs at least a size and a family, in that order.

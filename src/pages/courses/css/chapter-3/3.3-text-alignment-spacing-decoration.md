# Chapter 3: Colors, Text and Typography

## Section 3: Text Alignment, Spacing and Decoration

Choosing a font is only the first step. How you **align**, **space** and **decorate** text decides whether a page feels neat and easy to read. In this lesson you will learn the CSS properties that control the position, spacing and appearance of text.

---

## 1. The text-align Property

`text-align` controls how text lines are lined up **inside their box**.

| Value | Result |
| ----- | ------ |
| `left` | Lines start at the left edge (default in left-to-right languages) |
| `right` | Lines end at the right edge |
| `center` | Lines are centered |
| `justify` | Lines are stretched so both edges are straight |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  p {
    width: 320px;
    background-color: #f1f5f9;
    padding: 10px;
    margin: 8px 0;
  }
  .left { text-align: left; }
  .center { text-align: center; }
  .right { text-align: right; }
  .justify { text-align: justify; }
</style>

<p class="left">Left aligned text starts at the left edge of the box.</p>
<p class="center">Center aligned text sits in the middle of the box.</p>
<p class="right">Right aligned text ends at the right edge of the box.</p>
<p class="justify">Justified text stretches each line so that both the left and the right edges are straight, like in a newspaper column.</p>
```

Justified text can create uneven gaps between words on narrow screens, so use it carefully.

---

## 2. text-align Aligns the Content, Not the Box

A common surprise: `text-align: center` moves the **text and inline content** inside an element. It does not move the box itself.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .wrapper {
    text-align: center;
    background-color: #e0f2fe;
    padding: 16px;
  }
  .wrapper img {
    width: 60px;
    height: 60px;
    background-color: #0ea5e9;
    border-radius: 50%;
  }
</style>

<div class="wrapper">
  <h3>Centered heading</h3>
  <p>Centered paragraph</p>
  <button>Centered button</button>
</div>
```

The heading, paragraph and button are all inline or text content, so they all center. You will learn how to center boxes themselves in Chapter 4.

---

## 3. The text-transform Property

`text-transform` changes the **capital letters** of the text without changing the HTML.

| Value | Result |
| ----- | ------ |
| `none` | No change |
| `uppercase` | ALL CAPITALS |
| `lowercase` | all lowercase |
| `capitalize` | First Letter Of Each Word Capitalized |

```html
<style>
  body {
    font-family: Arial, sans-serif;
    font-size: 18px;
  }
  .u { text-transform: uppercase; }
  .l { text-transform: lowercase; }
  .c { text-transform: capitalize; }
</style>

<p class="u">uppercase text</p>
<p class="l">LOWERCASE TEXT</p>
<p class="c">capitalize each word here</p>
```

---

## 4. The text-decoration Property

`text-decoration` adds lines to the text.

| Value | Result |
| ----- | ------ |
| `none` | No line (often used to remove link underlines) |
| `underline` | A line under the text |
| `overline` | A line above the text |
| `line-through` | A line through the middle (like a cancelled price) |

```html
<style>
  body {
    font-family: Arial, sans-serif;
    font-size: 18px;
  }
  .under { text-decoration: underline; }
  .over { text-decoration: overline; }
  .strike { text-decoration: line-through; color: #94a3b8; }
  .none { text-decoration: none; }
</style>

<p class="under">Underlined text</p>
<p class="over">Overlined text</p>
<p class="strike">Old price: $99</p>
<p><a href="#" class="none">A link without underline</a></p>
```

---

## 5. Style, Color and Thickness of Decoration

You can control the line in more detail with these properties, or write them together in the shorthand.

```html
<style>
  body {
    font-family: Arial, sans-serif;
    font-size: 20px;
  }
  .fancy {
    text-decoration-line: underline;
    text-decoration-style: wavy;
    text-decoration-color: #dc2626;
    text-decoration-thickness: 2px;
    text-underline-offset: 5px;
  }
  .short {
    text-decoration: underline dotted #2563eb 3px;
  }
</style>

<p class="fancy">Wavy red underline, a little below the text</p>
<p class="short">Dotted blue underline using the shorthand</p>
```

Available styles are `solid`, `double`, `dotted`, `dashed` and `wavy`. The property `text-underline-offset` moves the underline away from the letters, which often looks cleaner.

---

## 6. The text-indent Property

`text-indent` adds space before the **first line** of a paragraph, like in a printed book.

```html
<style>
  body {
    font-family: Georgia, serif;
    font-size: 18px;
    line-height: 1.6;
    width: 380px;
  }
  p {
    text-indent: 32px;
  }
</style>

<p>The first line of this paragraph starts a little to the right. The remaining lines begin at the normal left edge of the box.</p>
```

---

## 7. Letter Spacing and Word Spacing

* `letter-spacing` changes the space between **letters**.
* `word-spacing` changes the space between **words**.

```html
<style>
  body {
    font-family: Arial, sans-serif;
    font-size: 18px;
  }
  .wide {
    letter-spacing: 4px;
    text-transform: uppercase;
    font-weight: bold;
  }
  .tight {
    letter-spacing: -1px;
  }
  .words {
    word-spacing: 14px;
  }
</style>

<p class="wide">Wide letters</p>
<p class="tight">Tight letters</p>
<p class="words">Spaced out words in a line</p>
```

A little extra `letter-spacing` on small **uppercase** text (such as labels and buttons) looks professional. Avoid large negative spacing, because letters may touch each other.

---

## 8. Controlling Spaces and Line Breaks: white-space

By default, the browser joins extra spaces and wraps long lines. `white-space` changes this.

| Value | Result |
| ----- | ------ |
| `normal` | Default. Spaces are joined and lines wrap |
| `nowrap` | Spaces are joined, and the text stays on **one line** |
| `pre` | Spaces and line breaks are kept exactly (like the `<pre>` tag) |
| `pre-wrap` | Spaces and line breaks are kept, but long lines still wrap |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    width: 260px;
    background-color: #f1f5f9;
    padding: 10px;
    margin-bottom: 10px;
  }
  .nowrap { white-space: nowrap; overflow: hidden; }
  .pre { white-space: pre-wrap; }
</style>

<div class="box nowrap">This long sentence will not wrap to a second line.</div>
<div class="box pre">Line one
    Line two (spaces kept)
Line three</div>
```

## 9. Cutting Long Text with an Ellipsis

To show "..." when text is too long for its box, use these three properties **together**.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .title {
    width: 240px;
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
    background-color: #fef9c3;
    padding: 8px;
  }
</style>

<div class="title">This is a very long title that cannot fit inside the small box</div>
```

All three are needed: `white-space: nowrap` keeps one line, `overflow: hidden` hides the extra text, and `text-overflow: ellipsis` adds the dots.

---

## 10. Long Words and Wrapping

A very long word (such as a web address) can break your layout by sticking out of its box. `overflow-wrap` fixes this.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    width: 200px;
    background-color: #fee2e2;
    padding: 8px;
    margin-bottom: 10px;
  }
  .safe {
    overflow-wrap: anywhere;
    background-color: #dcfce7;
  }
</style>

<div class="box">https://example.com/a/very/long/web/address/that/does/not/fit</div>
<div class="box safe">https://example.com/a/very/long/web/address/that/does/not/fit</div>
```

The first box lets the text stick out of its edge. The second one breaks the long word so it stays inside the box.

---

## 11. A Quick Look at text-shadow

`text-shadow` adds a shadow behind the letters. It has four values: horizontal offset, vertical offset, blur and color. You will study shadows fully in Chapter 5.

```html
<style>
  h1 {
    font-family: Arial, sans-serif;
    font-size: 44px;
    color: white;
    background-color: #1e3a8a;
    padding: 20px;
    text-shadow: 2px 3px 6px rgba(0, 0, 0, 0.5);
  }
</style>

<h1>Shadow Text</h1>
```

## Real-World Example 🌍

A news card that combines alignment, transformation, spacing and decoration:

```html
<style>
  body {
    font-family: Georgia, serif;
    background-color: #f1f5f9;
    padding: 20px;
  }
  .news {
    width: 340px;
    background-color: white;
    padding: 20px;
    border-radius: 10px;
    box-shadow: 0 3px 10px rgba(0, 0, 0, 0.12);
  }
  .tag {
    font-family: Arial, sans-serif;
    font-size: 12px;
    font-weight: bold;
    letter-spacing: 2px;
    text-transform: uppercase;
    color: #dc2626;
    margin: 0 0 8px;
  }
  .news h2 {
    font-size: 24px;
    line-height: 1.25;
    margin: 0 0 10px;
    color: #0f172a;
  }
  .news p {
    line-height: 1.6;
    color: #475569;
    margin: 0 0 12px;
  }
  .price {
    text-align: right;
    font-family: Arial, sans-serif;
  }
  .price del {
    color: #94a3b8;
    margin-right: 8px;
  }
  .price strong {
    color: #16a34a;
    font-size: 20px;
  }
  .more {
    text-align: center;
    margin-bottom: 0;
  }
  .more a {
    color: #2563eb;
    text-decoration: underline;
    text-underline-offset: 4px;
  }
</style>

<div class="news">
  <p class="tag">Breaking</p>
  <h2>New Web Course Opens for Beginners</h2>
  <p>Students can now join a free class and learn how to design real websites from the start.</p>
  <p class="price"><del>$40</del> <strong>$25</strong></p>
  <p class="more"><a href="#">Read the full story</a></p>
</div>
```

Different text properties work together to create a clear structure: a small tag, a strong heading, readable body text, a right-aligned price and a centered link.

## Common Mistakes

### Expecting text-align to Move the Whole Box

```text
.card { text-align: center; }    /* centers the text inside, not the card itself */
```

### Forgetting That Ellipsis Needs Three Properties

```text
.title { text-overflow: ellipsis; }    /* nothing happens */

.title {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;             /* now it works */
}
```

### Removing Link Underlines Without Another Clue

```text
a { text-decoration: none; }
```

If links are not underlined, they must still look different from normal text (by color, weight or hover style), or users may not notice them.

### Using Uppercase in the HTML

```text
<p>WELCOME TO OUR SITE</p>              <!-- the text is permanently capitals -->
<p class="shout">Welcome to our site</p>  <!-- use text-transform: uppercase -->
```

### Too Much Letter Spacing on Body Text

```text
p { letter-spacing: 5px; }
```

Wide spacing on long paragraphs makes them very hard to read. Keep it for short labels and headings.

## Key Points

* `text-align` sets `left`, `right`, `center` or `justify` for text **inside** a box.
* `text-transform` changes the case of letters: `uppercase`, `lowercase`, `capitalize`.
* `text-decoration` adds or removes `underline`, `overline` and `line-through`.
* Use `text-decoration-style`, `text-decoration-color`, `text-decoration-thickness` and `text-underline-offset` to refine lines.
* `text-indent` indents the first line of a paragraph.
* `letter-spacing` and `word-spacing` change gaps between letters and words.
* `white-space` controls wrapping and how spaces and line breaks are shown.
* An ellipsis needs `white-space: nowrap`, `overflow: hidden` and `text-overflow: ellipsis` together.
* `overflow-wrap: anywhere` stops long words from breaking the layout.

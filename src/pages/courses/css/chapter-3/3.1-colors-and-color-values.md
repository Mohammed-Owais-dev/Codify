# Chapter 3: Colors, Text and Typography

## Section 1: CSS Colors and Color Values

Color is one of the first things people notice on a webpage. CSS gives you many ways to write a color: names, hex codes, RGB, HSL and more. In this lesson you will learn each format, where to use colors, and how to choose colors that are easy to read.

---

## 1. Where Colors Are Used

Three very common properties use colors. Many other properties (such as shadows and gradients) use them too.

| Property | What it colors |
| -------- | -------------- |
| `color` | The **text** (and text decorations) |
| `background-color` | The **background** of an element |
| `border-color` | The **border** of an element |

```html
<style>
  .box {
    color: white;
    background-color: #1d4ed8;
    border: 4px solid #93c5fd;
    padding: 16px;
    font-family: Arial, sans-serif;
    width: 260px;
  }
</style>

<div class="box">White text on a blue background with a light blue border.</div>
```

---

## 2. Color Names

CSS has about **140 named colors**. They are easy to read and remember, so they are good for learning and quick tests.

```html
<style>
  .swatch {
    display: inline-block;
    width: 90px;
    height: 60px;
    color: white;
    text-align: center;
    line-height: 60px;
    font-family: Arial, sans-serif;
    font-size: 13px;
    margin: 4px;
    border-radius: 6px;
  }
</style>

<div class="swatch" style="background-color: red;">red</div>
<div class="swatch" style="background-color: tomato;">tomato</div>
<div class="swatch" style="background-color: orange;">orange</div>
<div class="swatch" style="background-color: seagreen;">seagreen</div>
<div class="swatch" style="background-color: teal;">teal</div>
<div class="swatch" style="background-color: royalblue;">royalblue</div>
<div class="swatch" style="background-color: purple;">purple</div>
<div class="swatch" style="background-color: black;">black</div>
```

Names are simple, but you cannot get every shade with them. For exact brand colors, professionals use hex or other codes.

## 3. Hex Colors

A **hex color** starts with `#` followed by **six** hexadecimal digits (0-9 and A-F). The digits are in three pairs: **red, green, blue**.

```text
#RRGGBB

#ff0000  -> red   (ff red, 00 green, 00 blue)
#00ff00  -> green
#0000ff  -> blue
#000000  -> black (no light)
#ffffff  -> white (full light)
```

Each pair goes from `00` (none) to `ff` (maximum).

```html
<style>
  .swatch {
    display: inline-block;
    width: 110px;
    height: 60px;
    color: white;
    text-align: center;
    line-height: 60px;
    font-family: Arial, sans-serif;
    font-size: 13px;
    margin: 4px;
    border-radius: 6px;
  }
</style>

<div class="swatch" style="background-color: #ef4444;">#ef4444</div>
<div class="swatch" style="background-color: #22c55e;">#22c55e</div>
<div class="swatch" style="background-color: #3b82f6;">#3b82f6</div>
<div class="swatch" style="background-color: #a855f7;">#a855f7</div>
<div class="swatch" style="background-color: #0f172a;">#0f172a</div>
```

---

## 4. Short Hex Codes

If each pair has two identical digits, you can write each pair as one digit. This gives a **3-digit** hex code.

```text
#ff0000  ->  #f00
#ffffff  ->  #fff
#336699  ->  #369
#aabbcc  ->  #abc
```

`#ff5733` cannot be shortened, because the pairs are not made of repeated digits.

---

## 5. RGB Colors

The `rgb()` function mixes **red, green and blue** light. Each value is a number from **0 to 255**.

```html
<style>
  .swatch {
    display: inline-block;
    width: 150px;
    height: 60px;
    color: white;
    text-align: center;
    line-height: 60px;
    font-family: Arial, sans-serif;
    font-size: 13px;
    margin: 4px;
    border-radius: 6px;
  }
</style>

<div class="swatch" style="background-color: rgb(255, 0, 0);">rgb(255, 0, 0)</div>
<div class="swatch" style="background-color: rgb(0, 128, 128);">rgb(0, 128, 128)</div>
<div class="swatch" style="background-color: rgb(255, 165, 0);">rgb(255, 165, 0)</div>
<div class="swatch" style="background-color: rgb(30, 41, 59);">rgb(30, 41, 59)</div>
```

`rgb(0, 0, 0)` is black and `rgb(255, 255, 255)` is white. Equal values of all three give a shade of gray, such as `rgb(128, 128, 128)`.

---

## 6. Transparency with RGBA and Alpha

Adding a fourth value, **alpha**, controls transparency. It goes from `0` (fully transparent) to `1` (fully solid).

```html
<style>
  .backdrop {
    background-color: #0ea5e9;
    padding: 20px;
    font-family: Arial, sans-serif;
  }
  .glass {
    background-color: rgba(255, 255, 255, 0.5);
    padding: 16px;
    border-radius: 8px;
    color: #0f172a;
  }
</style>

<div class="backdrop">
  <div class="glass">A half transparent white box. The blue shows through.</div>
</div>
```

Hex codes can also have alpha. An **8-digit** hex adds two more digits at the end: `#0ea5e980` is about 50% opaque. Newer CSS also allows the space-separated form `rgb(14 165 233 / 50%)`.

---

## 7. HSL Colors

**HSL** stands for **Hue, Saturation, Lightness**. Many designers find it easier to understand than RGB.

| Part | Range | Meaning |
| ---- | ----- | ------- |
| Hue | 0 to 360 | The color on the color wheel (0 red, 120 green, 240 blue) |
| Saturation | 0% to 100% | How strong the color is (0% is gray) |
| Lightness | 0% to 100% | How bright it is (0% black, 50% normal, 100% white) |

```html
<style>
  .swatch {
    display: inline-block;
    width: 70px;
    height: 60px;
    margin: 3px;
    border-radius: 6px;
  }
</style>

<div class="swatch" style="background-color: hsl(210, 80%, 20%);"></div>
<div class="swatch" style="background-color: hsl(210, 80%, 35%);"></div>
<div class="swatch" style="background-color: hsl(210, 80%, 50%);"></div>
<div class="swatch" style="background-color: hsl(210, 80%, 65%);"></div>
<div class="swatch" style="background-color: hsl(210, 80%, 80%);"></div>
<div class="swatch" style="background-color: hsl(210, 80%, 92%);"></div>
```

All six swatches are the same blue (hue 210). Only the lightness changes. This makes it easy to create darker and lighter versions of one color for hover effects and themes. HSL also supports alpha: `hsla(210, 80%, 50%, 0.5)`.

---

## 8. Special Color Keywords

| Keyword | Meaning |
| ------- | ------- |
| `transparent` | Fully see-through |
| `currentColor` | The same as the element's current text `color` |

`currentColor` keeps related parts in the same color automatically.

```html
<style>
  .tag {
    color: #be123c;
    border: 2px solid currentColor;
    padding: 6px 14px;
    border-radius: 20px;
    display: inline-block;
    font-family: Arial, sans-serif;
  }
</style>

<span class="tag">Important</span>
```

The border uses the same red as the text. If you change `color`, the border follows.

---

## 9. opacity vs RGBA

Both can make things see-through, but they work differently.

| | `rgba()` / alpha | `opacity` |
| - | ---------------- | --------- |
| Affects | Only that one color | The **whole element**, including text and children |
| Example | `background-color: rgba(0,0,0,0.5)` | `opacity: 0.5` |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    padding: 14px;
    margin-bottom: 10px;
    color: white;
    width: 260px;
    border-radius: 6px;
  }
  .a {
    background-color: rgba(30, 64, 175, 0.4);
    color: #0f172a;
  }
  .b {
    background-color: #1e40af;
    opacity: 0.4;
  }
</style>

<div class="row a">Only the background is transparent. The text stays clear.</div>
<div class="row b">The whole box is transparent, even the text.</div>
```

Use alpha colors when you want clear text on a see-through background.

## 10. Choosing Readable Colors

A beautiful page is useless if the text cannot be read. Always make sure there is enough **contrast** between the text color and the background color.

* The common accessibility rule (WCAG level AA) asks for a contrast ratio of at least **4.5 : 1** for normal text, and **3 : 1** for large text.
* Light gray text on a white background is a very common mistake.
* Do not use color alone to give meaning. Some people cannot tell red from green, so add words or icons too.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  p {
    padding: 12px;
    width: 300px;
    margin: 6px 0;
    font-size: 17px;
  }
  .poor {
    color: #cbd5e1;
    background-color: white;
  }
  .good {
    color: #1e293b;
    background-color: white;
  }
  .dark {
    color: #f8fafc;
    background-color: #1e293b;
  }
</style>

<p class="poor">Poor contrast: hard to read.</p>
<p class="good">Good contrast: easy to read.</p>
<p class="dark">Good contrast on a dark background.</p>
```

---

## 11. Which Format Should I Use?

| Format | Example | Good for |
| ------ | ------- | -------- |
| Name | `tomato` | Learning, quick tests |
| Hex | `#3b82f6` | Copying colors from design tools (most common) |
| RGB / RGBA | `rgba(0, 0, 0, 0.3)` | Transparent colors, shadows |
| HSL / HSLA | `hsl(210, 80%, 50%)` | Making lighter or darker versions of a color |

All formats give the same result. Pick one and stay consistent in a project.

## Common Mistakes

### Forgetting the Hash in Hex Colors

```
color: ff0000;     /* wrong */
color: #ff0000;    /* correct */
```

### Wrong Number of Hex Digits

```text
color: #ff00;      /* wrong: 4 digits means RGBA short form, not what you intended */
color: #ff0000;    /* correct */
```

Hex colors should have 3, 6 or 8 digits (and 4 for the short alpha form).

### RGB Values Out of Range

```text
rgb(300, 0, 0)     /* too high: values are limited to 255 */
rgb(255, 0, 0)     /* correct */
```

### Low Contrast Text

```text
color: #ddd;
background-color: #fff;
```

Light text on a light background cannot be read by many people. Check your contrast.

### Using opacity When Only the Background Should Fade

```css
.box { opacity: 0.5; }                        /* text fades too */
.box { background-color: rgba(0, 0, 0, 0.5); }  /* only the background fades */
```

---

## Key Points

* Use `color` for text, `background-color` for backgrounds and `border-color` for borders.
* Colors can be written as **names**, **hex**, **rgb()**, **hsl()** and with **alpha** for transparency.
* A hex color is `#RRGGBB`. A short form like `#f00` is allowed when each pair repeats.
* `rgb()` values go from 0 to 255, and alpha goes from 0 to 1.
* **HSL** (hue, saturation, lightness) makes it easy to create lighter and darker shades.
* `transparent` is fully see-through, and `currentColor` copies the current text color.
* `rgba()` fades only one color, but `opacity` fades the whole element.
* Always check **contrast** so text is easy to read, and never use color alone to give meaning.

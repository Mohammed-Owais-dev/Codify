# Chapter 3: Colors, Text and Typography

## Section 5: Styling Links and Lists

Links and lists are everywhere on the web: menus, tables of contents, product lists, footers and more. Browsers give them plain default styles (blue underlined links and round bullets). In this lesson you will learn how to style links in all their states, and how to control and redesign lists.

---

## 1. Default Look of Links

Browsers show links as **blue, underlined text**. Visited links turn **purple**. This is easy to recognize, but it rarely matches your design. Let us see how to change it.

```html
<style>
  a {
    color: #0f766e;
    font-family: Arial, sans-serif;
  }
</style>

<a href="#">A link with our own color</a>
```

Changing the `color` of `a` is the simplest style for links.

---

## 2. The Four Link States

A link can be in different states, and you can style each one with a pseudo-class.

| Pseudo-class | State |
| ------------ | ----- |
| `a:link` | Normal, not visited |
| `a:visited` | Already visited |
| `a:hover` | Mouse is over it |
| `a:active` | Being clicked |

```html
<style>
  body {
    font-family: Arial, sans-serif;
    font-size: 20px;
  }
  a:link {
    color: #2563eb;
  }
  a:visited {
    color: #7c3aed;
  }
  a:hover {
    color: #dc2626;
    text-decoration: none;
  }
  a:active {
    color: #f97316;
  }
</style>

<a href="https://example.com">Hover, then click this link</a>
```

Keep the order **link, visited, hover, active** (LoVe HAte), as you learned in Chapter 2.

---

## 3. Controlling the Underline

Instead of removing the underline completely, you can make it look more modern.

```html
<style>
  body {
    font-family: Arial, sans-serif;
    font-size: 20px;
  }
  a {
    color: #1d4ed8;
    text-decoration: underline;
    text-decoration-color: #93c5fd;
    text-decoration-thickness: 2px;
    text-underline-offset: 5px;
    transition: text-decoration-color 0.2s;
  }
  a:hover {
    text-decoration-color: #1d4ed8;
  }
</style>

<a href="#">A softly underlined link</a>
```

The underline is light blue until you hover, when it turns dark blue. This is clean and still clear.

---

## 4. Links That Look Like Buttons

A link can be styled as a button. Add `display: inline-block` so that padding and size work properly, then add background, padding and rounded corners.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .btn {
    display: inline-block;
    background-color: #2563eb;
    color: white;
    padding: 12px 28px;
    border-radius: 8px;
    text-decoration: none;
    font-weight: bold;
  }
  .btn:hover {
    background-color: #1d4ed8;
  }
  .btn-outline {
    background-color: transparent;
    color: #2563eb;
    border: 2px solid #2563eb;
  }
  .btn-outline:hover {
    background-color: #2563eb;
    color: white;
  }
</style>

<a href="#" class="btn">Solid button</a>
<a href="#" class="btn btn-outline">Outline button</a>
```

---

## 5. Keyboard Focus on Links

Many people move through a page with the **Tab** key. The `:focus-visible` pseudo-class styles the link that is selected by the keyboard. It does not show for mouse clicks, which keeps the design clean.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  a {
    color: #1d4ed8;
    padding: 4px 6px;
    border-radius: 4px;
  }
  a:focus-visible {
    outline: 3px solid #f59e0b;
    outline-offset: 2px;
  }
</style>

<p><a href="#">First link</a> | <a href="#">Second link</a> | <a href="#">Third link</a></p>
<p>Press Tab inside the preview to move between the links.</p>
```

Never remove the outline without giving a clear replacement. Keyboard users need to see where they are.

## 6. HTML Lists in a Nutshell

| List | HTML | Default marker |
| ---- | ---- | -------------- |
| Unordered | `<ul>` with `<li>` items | Round bullets |
| Ordered | `<ol>` with `<li>` items | Numbers 1, 2, 3 |

Browsers also give lists a **left padding** (about 40px) to make room for the markers.

---

## 7. The list-style-type Property

`list-style-type` changes the marker of the items.

| For `ul` | Marker |
| -------- | ------ |
| `disc` | Filled circle (default) |
| `circle` | Empty circle |
| `square` | Filled square |
| `none` | No marker |

| For `ol` | Marker |
| -------- | ------ |
| `decimal` | 1, 2, 3 (default) |
| `lower-alpha` | a, b, c |
| `upper-alpha` | A, B, C |
| `lower-roman` | i, ii, iii |
| `upper-roman` | I, II, III |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .a { list-style-type: square; }
  .b { list-style-type: circle; }
  .c { list-style-type: upper-roman; }
  .d { list-style-type: lower-alpha; }
  ul, ol {
    display: inline-block;
    vertical-align: top;
    margin-right: 30px;
  }
</style>

<ul class="a"><li>Square</li><li>Square</li></ul>
<ul class="b"><li>Circle</li><li>Circle</li></ul>
<ol class="c"><li>Roman</li><li>Roman</li></ol>
<ol class="d"><li>Alpha</li><li>Alpha</li></ol>
```

---

## 8. Marker Position and Image Markers

* `list-style-position` can be `outside` (default, markers sit outside the text block) or `inside` (markers move inside the text block).
* `list-style-image` uses a picture as the marker.

```css
ul {
  list-style-position: inside;
  list-style-image: url("images/arrow.png");
}
```

The shorthand `list-style` sets all three at once:

```text
list-style: square inside;
list-style: none;
```

Image markers are hard to size and align. Modern designs more often use `::marker` or `::before` (see Section 11).

---

## 9. Removing Bullets and Default Spacing

To build menus from lists, remove the markers **and** the default padding and margin.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .clean {
    list-style: none;
    margin: 0;
    padding: 0;
    width: 240px;
  }
  .clean li {
    padding: 10px 14px;
    border-bottom: 1px solid #e2e8f0;
  }
  .clean li:hover {
    background-color: #f1f5f9;
  }
</style>

<ul class="clean">
  <li>Dashboard</li>
  <li>My Courses</li>
  <li>Certificates</li>
  <li>Settings</li>
</ul>
```

A list is still the best HTML for a group of related items, even if it does not look like a list.

---

## 10. A Horizontal Navigation Bar

Lists can be turned sideways to make a menu bar. One simple way is `display: inline-block` on the items. (Chapter 7 shows a better way with Flexbox.)

```html
<style>
  body {
    margin: 0;
    font-family: Arial, sans-serif;
  }
  .nav {
    list-style: none;
    margin: 0;
    padding: 0;
    background-color: #0f172a;
  }
  .nav li {
    display: inline-block;
  }
  .nav a {
    display: block;
    color: #e2e8f0;
    text-decoration: none;
    padding: 16px 20px;
  }
  .nav a:hover {
    background-color: #1e293b;
    color: #38bdf8;
  }
  .nav .current {
    border-bottom: 3px solid #38bdf8;
  }
</style>

<ul class="nav">
  <li><a href="#" class="current">Home</a></li>
  <li><a href="#">Courses</a></li>
  <li><a href="#">Exams</a></li>
  <li><a href="#">Contact</a></li>
</ul>
```

Making the `a` a block fills the whole item, so the full area is clickable, not just the text.

## 11. Custom Bullets with ::marker and ::before

`::marker` styles the bullet or number itself, with limited properties such as color and size.

```html
<style>
  body {
    font-family: Arial, sans-serif;
    font-size: 18px;
  }
  .pretty li::marker {
    color: #dc2626;
    font-weight: bold;
  }
  .check {
    list-style: none;
    padding-left: 0;
  }
  .check li {
    padding-left: 28px;
    margin-bottom: 8px;
    position: relative;
  }
  .check li::before {
    content: "✔";
    color: #16a34a;
    position: absolute;
    left: 0;
  }
</style>

<ul class="pretty">
  <li>Red bullet</li>
  <li>Red bullet</li>
</ul>

<ul class="check">
  <li>Learn selectors</li>
  <li>Learn colors</li>
  <li>Learn typography</li>
</ul>
```

For the check list, the real bullets are removed, and each item gets a green check mark added with `::before`. (You will study `position` in Chapter 6.)

---

## 12. Nested Lists

A list inside a list item is a **nested list**. Style them with the descendant or child combinators.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  ul {
    list-style-type: disc;
  }
  ul ul {
    list-style-type: circle;
    color: #475569;
  }
  ul ul ul {
    list-style-type: square;
  }
</style>

<ul>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS
        <ul>
          <li>Selectors</li>
          <li>Layout</li>
        </ul>
      </li>
    </ul>
  </li>
  <li>Backend</li>
</ul>
```

## Real-World Example 🌍

A sidebar menu and a "Table of Contents" built from links and lists:

```html
<style>
  body {
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
    padding: 20px;
  }
  .sidebar {
    width: 240px;
    background-color: white;
    border-radius: 10px;
    padding: 12px;
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
  }
  .sidebar h3 {
    margin: 4px 8px 10px;
    font-size: 13px;
    letter-spacing: 2px;
    text-transform: uppercase;
    color: #64748b;
  }
  .sidebar ul {
    list-style: none;
    margin: 0;
    padding: 0;
  }
  .sidebar a {
    display: block;
    padding: 10px 12px;
    border-radius: 6px;
    color: #334155;
    text-decoration: none;
  }
  .sidebar a:hover {
    background-color: #e0f2fe;
    color: #0369a1;
  }
  .sidebar a.active {
    background-color: #0ea5e9;
    color: white;
    font-weight: bold;
  }
  .sidebar a[href$=".pdf"]::after {
    content: " (PDF)";
    font-size: 12px;
    opacity: 0.7;
  }
  .sidebar a:focus-visible {
    outline: 3px solid #f59e0b;
  }
</style>

<nav class="sidebar">
  <h3>Course Menu</h3>
  <ul>
    <li><a href="#" class="active">Introduction</a></li>
    <li><a href="#">Selectors</a></li>
    <li><a href="#">Typography</a></li>
    <li><a href="notes.pdf">Download notes</a></li>
  </ul>
</nav>
```

Each link fills the whole row, the current page is highlighted, and a PDF label is added automatically using an attribute selector and `::after`.

## Common Mistakes

### Forgetting to Remove the Default Padding

```css
ul { list-style: none; }          /* bullets gone, but the left gap remains */

ul {
  list-style: none;
  margin: 0;
  padding: 0;                     /* now the list starts at the edge */
}
```

### Padding Not Working on a Link

```css
a { padding: 12px; }              /* inline elements do not push other lines away */
a { display: inline-block; padding: 12px; }   /* works as a button */
```

### Wrong Order of Link States

```css
a:hover { color: red; }
a:link { color: blue; }     /* overrides hover because it is later */
```

### Hiding Links Completely

```css
a { color: black; text-decoration: none; }
```

Links that look exactly like normal text are easy to miss. Give links a clear color, weight or underline.

### Removing the Focus Outline

```css
a:focus { outline: none; }
```

This makes the page very hard to use with a keyboard. Provide a visible `:focus-visible` style instead.

### Using Line Breaks Instead of a List

```html
Home<br>About<br>Contact
```

Use `<ul>` and `<li>` for groups of related items. It is better for accessibility and styling.

---

## Key Points

* Style link states with `a:link`, `a:visited`, `a:hover` and `a:active`, in that order.
* Use `text-decoration-*` properties and `text-underline-offset` for modern underlines.
* A link becomes button-like with `display: inline-block`, padding, background and `border-radius`.
* Use `:focus-visible` to show a clear outline for keyboard users, and never remove focus styles without a replacement.
* `list-style-type` changes the markers: `disc`, `circle`, `square`, `decimal`, `lower-alpha`, `upper-roman` and more.
* To make a menu from a list, use `list-style: none; margin: 0; padding: 0;`.
* Turn list items into a horizontal menu with `display: inline-block` (Flexbox later makes this easier).
* `::marker` styles the bullet, and `::before` can create custom bullets.
* Use a real list (`ul` or `ol`) for groups of related items.

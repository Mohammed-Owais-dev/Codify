# Chapter 5: Backgrounds, Borders and Effects

## Section 5: CSS Units: px, %, em, rem and vh

Almost every CSS property that sets a size needs a **unit**: font size, width, margin, padding and more. Choosing the right unit makes your page flexible and easy to read on every screen. In this lesson you will compare the most common units and learn when to use each one.

---

## 1. Absolute and Relative Units

CSS units are in two groups.

| Group | Meaning | Examples |
| ----- | ------- | -------- |
| **Absolute** | A fixed size that does not depend on anything else | `px`, `cm`, `mm`, `in`, `pt` |
| **Relative** | A size based on something else, such as the parent, the font or the screen | `%`, `em`, `rem`, `vw`, `vh` |

On screens, `px` is the only absolute unit that is commonly used. The others are mostly for printing.

---

## 2. px (Pixels)

A pixel is a fixed size. `16px` is always 16 CSS pixels, no matter the parent or the user settings.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .px-box {
    width: 240px;
    padding: 16px;
    border: 2px solid #0284c7;
    background-color: #e0f2fe;
    font-size: 18px;
  }
</style>

<div class="px-box">Everything here is set in pixels.</div>
```

Pixels are simple and exact. They are good for borders, small shadows and fine details. They are not the best choice for font sizes, because they ignore the user's font settings in some cases.

---

## 3. % (Percent)

A percentage is based on the **parent**.

* For `width`, it is a percent of the parent's width.
* For `font-size`, it is a percent of the parent's font size.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .parent {
    width: 300px;
    background-color: #e2e8f0;
    padding: 8px;
  }
  .child {
    width: 60%;
    background-color: #fb923c;
    color: white;
    padding: 8px;
  }
</style>

<div class="parent">
  <div class="child">60% of the parent</div>
</div>
```

---

## 4. em

`em` is based on the **font size of the element itself** (or, for `font-size`, the parent's font size). If an element has `font-size: 20px`, then `1em` is `20px`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .btn {
    font-size: 20px;
    padding: 0.5em 1em;
    background-color: #0ea5e9;
    color: white;
    border: none;
    border-radius: 0.3em;
  }
  .btn.small {
    font-size: 14px;
  }
</style>

<button class="btn">Big button</button>
<button class="btn small">Small button</button>
```

The padding and radius use `em`, so when the font size changes, the whole button scales together. This is the best use of `em`.

---

## 5. The em Compounding Problem

`em` for `font-size` is based on the **parent**, so nested elements multiply.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .level {
    font-size: 1.5em;
    background-color: #fef3c7;
    padding: 4px 8px;
    margin: 4px 0;
  }
</style>

<div class="level">
  Level 1 (1.5 x 16px = 24px)
  <div class="level">
    Level 2 (1.5 x 24px = 36px)
    <div class="level">Level 3 (1.5 x 36px = 54px)</div>
  </div>
</div>
```

Each level gets bigger and bigger. This is why many developers prefer `rem` for font sizes.

---

## 6. rem

`rem` means **root em**. It is always based on the font size of the root element (`html`). The browser default is `16px`, so `1rem` is usually `16px`.

```html
<style>
  html {
    font-size: 16px;
  }
  body {
    font-family: Arial, sans-serif;
  }
  .r {
    background-color: #dcfce7;
    padding: 0.5rem 1rem;
    margin-bottom: 8px;
  }
  .r1 { font-size: 1rem; }
  .r2 { font-size: 1.5rem; }
  .r3 { font-size: 2rem; }
</style>

<div class="r r1">1rem = 16px</div>
<div class="r r2">1.5rem = 24px</div>
<div class="r r3">2rem = 32px</div>
```

Nested elements do not multiply with `rem`, so the sizes are easy to predict. If a user changes the default font size in the browser, everything in `rem` scales with it. This is good for accessibility.

---

## 7. vw and vh

`vw` and `vh` are percentages of the **viewport**, which is the visible browser window.

| Unit | Meaning |
| ---- | ------- |
| `1vw` | 1% of the viewport width |
| `1vh` | 1% of the viewport height |
| `vmin` | 1% of the smaller side of the viewport |
| `vmax` | 1% of the larger side of the viewport |

```html
<style>
  body {
    margin: 0;
    font-family: Arial, sans-serif;
  }
  .full {
    height: 50vh;
    display: flex;
    align-items: center;
    justify-content: center;
    background-color: #1e293b;
    color: white;
    font-size: 5vw;
  }
</style>

<div class="full">50vh tall, text 5vw</div>
```

`100vh` makes a full-screen section. On phones, the browser toolbar can change the real height, so modern CSS also offers `100dvh` (dynamic viewport height), which follows the visible area.

---

## 8. Other Useful Units

| Unit | Meaning |
| ---- | ------- |
| `ch` | The width of the `0` character. Good for text line length. |
| `fr` | A fraction of free space in CSS Grid (chapter 7) |
| `pt` | A point, `1/72` inch. Mostly for print. |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .text {
    max-width: 40ch;
    line-height: 1.6;
    background-color: #f1f5f9;
    padding: 12px;
  }
</style>

<p class="text">A good reading line is about 40 to 75 characters wide, so max-width in ch keeps text comfortable to read.</p>
```

---

## 9. Which Unit Should I Use?

| Use | Best unit |
| --- | --------- |
| Font size | `rem` |
| Padding and margin inside a component that should scale with text | `em` |
| Borders, thin lines, small shadows | `px` |
| Widths that follow the parent | `%` |
| Full-screen sections | `vh` or `dvh` |
| Fluid text size | `vw` with `clamp()` |
| Line length of text | `ch` |

A handy function is `clamp(min, preferred, max)`. It keeps a value between a minimum and a maximum.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  h1 {
    font-size: clamp(1.5rem, 5vw, 3rem);
    margin: 0;
  }
</style>

<h1>I grow and shrink smoothly</h1>
```

## Real-World Example 🌍

A small page that uses several units together, each for its best job:

```html
<style>
  * {
    box-sizing: border-box;
  }
  html {
    font-size: 16px;
  }
  body {
    margin: 0;
    font-family: Arial, sans-serif;
    background-color: #f1f5f9;
  }
  .hero {
    min-height: 40vh;
    display: flex;
    flex-direction: column;
    align-items: center;
    justify-content: center;
    padding: 1.5rem;
    background-color: #0f172a;
    color: white;
    text-align: center;
  }
  .hero h1 {
    margin: 0 0 0.5rem 0;
    font-size: clamp(1.6rem, 6vw, 2.6rem);
  }
  .content {
    width: 90%;
    max-width: 60ch;
    margin: 1.5rem auto;
    padding: 1rem;
    background-color: white;
    border: 1px solid #cbd5e1;
    border-radius: 0.6rem;
    line-height: 1.6;
  }
  .btn {
    font-size: 1rem;
    padding: 0.6em 1.4em;
    border: none;
    border-radius: 0.4em;
    background-color: #0ea5e9;
    color: white;
  }
</style>

<div class="hero">
  <h1>Learn CSS Units</h1>
  <button class="btn">Get Started</button>
</div>
<div class="content">
  The hero uses vh, the title uses clamp with vw, the card uses a percent width with ch, and the spacing uses rem.
</div>
```

## Common Mistakes

### Forgetting the Unit

```text
.box { width: 200; }       /* invalid, no unit */
.box { width: 200px; }     /* correct */
```

Only `0` can be written without a unit, such as `margin: 0`.

### Space Between the Number and the Unit

```text
.box { width: 200 px; }    /* invalid */
.box { width: 200px; }     /* correct */
```

### Using em for Nested Font Sizes

```text
.menu li { font-size: 1.2em; }     /* grows again in each nested list */
.menu li { font-size: 1.2rem; }    /* always the same */
```

### Using 100vw for Page Width

```text
.page { width: 100vw; }    /* includes the scroll bar and can cause sideways scroll */
.page { width: 100%; }
```

### Percentage Height Without a Parent Height

```text
.child { height: 50%; }    /* does nothing if the parent height is auto */
```

---

## Key Points

* **Absolute** units like `px` are fixed. **Relative** units like `%`, `em`, `rem`, `vw` and `vh` depend on something else.
* `%` is based on the parent.
* `em` is based on the element's font size, and can multiply in nested elements.
* `rem` is based on the root font size (usually `16px`), so it is predictable and good for accessibility.
* `vw` and `vh` are percentages of the viewport width and height.
* Use `rem` for font sizes, `px` for thin details, `%` for flexible widths and `vh` for full-screen sections.
* `clamp()` keeps a value between a minimum and a maximum.
* Always write a unit, except for `0`.

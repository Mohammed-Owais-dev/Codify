# Chapter 6: Layout with Display and Position

## Section 5: Overflow and Visibility

In chapter 4 you met the `overflow` property for the box model. Now you will use it for **layout** work, such as scroll areas and tables, and you will learn how to hide elements in different ways with `visibility`, `display` and `opacity`.

---

## 1. A Quick Review of overflow

`overflow` decides what happens when content is bigger than its box.

| Value | Result |
| ----- | ------ |
| `visible` | Content spills out (default) |
| `hidden` | Extra content is cut off |
| `scroll` | Scroll bars always shown |
| `auto` | Scroll bars only if needed |
| `clip` | Cuts off content, and does not allow any scrolling |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .panel {
    width: 240px;
    height: 80px;
    padding: 8px;
    border: 2px solid #0284c7;
    background-color: #f0f9ff;
    overflow: auto;
  }
</style>

<div class="panel">
  This panel has a fixed height. When the text is longer than the box, a scroll bar appears so the reader can see all of it. Keep reading and scroll down to see this line too.
</div>
```

## 2. Scroll Areas for Layout

A page often needs a part that scrolls on its own, such as a sidebar, a chat or a code box.

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 14px;
    font-family: Arial, sans-serif;
  }
  .layout {
    display: flex;
    height: 180px;
    border: 2px solid #475569;
  }
  .sidebar {
    width: 110px;
    padding: 8px;
    overflow-y: auto;
    background-color: #1e293b;
    color: white;
  }
  .main {
    flex: 1;
    padding: 8px;
    background-color: #f8fafc;
  }
  .sidebar p {
    margin: 0 0 14px 0;
  }
</style>

<div class="layout">
  <div class="sidebar">
    <p>Link 1</p>
    <p>Link 2</p>
    <p>Link 3</p>
    <p>Link 4</p>
    <p>Link 5</p>
    <p>Link 6</p>
    <p>Link 7</p>
    <p>Link 8</p>
  </div>
  <div class="main">Main content stays in place while the sidebar scrolls.</div>
</div>
```

## 3. Scrolling Tables on Small Screens

Wide tables can break a phone layout. Put the table in a wrapper with `overflow-x: auto`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .table-wrap {
    max-width: 280px;
    overflow-x: auto;
    border: 2px solid #94a3b8;
  }
  table {
    border-collapse: collapse;
    min-width: 480px;
  }
  th, td {
    padding: 8px 12px;
    border: 1px solid #cbd5e1;
    white-space: nowrap;
  }
  th {
    background-color: #e2e8f0;
  }
</style>

<div class="table-wrap">
  <table>
    <tr><th>Name</th><th>Course</th><th>Score</th><th>Status</th></tr>
    <tr><td>Asha</td><td>CSS</td><td>92</td><td>Passed</td></tr>
    <tr><td>Ravi</td><td>HTML</td><td>85</td><td>Passed</td></tr>
  </table>
</div>
```

Only the wrapper scrolls sideways. The whole page does not.

## 4. Smooth Scrolling and Scroll Snap

Two small properties make scroll areas nicer.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .slider {
    display: flex;
    gap: 10px;
    width: 260px;
    overflow-x: auto;
    scroll-snap-type: x mandatory;
    scroll-behavior: smooth;
  }
  .slide {
    flex: 0 0 220px;
    height: 100px;
    display: flex;
    align-items: center;
    justify-content: center;
    scroll-snap-align: center;
    color: white;
    border-radius: 10px;
  }
  .s1 { background-color: #0ea5e9; }
  .s2 { background-color: #f97316; }
  .s3 { background-color: #16a34a; }
</style>

<div class="slider">
  <div class="slide s1">Slide 1</div>
  <div class="slide s2">Slide 2</div>
  <div class="slide s3">Slide 3</div>
</div>
```

* `scroll-snap-type` makes scrolling stop neatly at each item.
* `scroll-behavior: smooth` animates scrolling for links and scripts.

## 5. Long Words and Wrapping

Long words or links can overflow a small box. These properties help.

| Property | Use |
| -------- | --- |
| `overflow-wrap: anywhere` | Breaks a long word if there is no other way to fit it |
| `word-break: break-all` | Breaks words at any letter |
| `hyphens: auto` | Adds hyphens when breaking words |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .narrow {
    width: 170px;
    padding: 8px;
    border: 2px solid #7c3aed;
    overflow-wrap: anywhere;
  }
</style>

<div class="narrow">https://codify.example.com/a-very-long-link-without-any-spaces</div>
```

## 6. The visibility Property

`visibility` hides an element **but keeps its space**.

| Value | Meaning |
| ----- | ------- |
| `visible` | Shown normally (default) |
| `hidden` | Invisible, but the space remains |
| `collapse` | For table rows and columns, removes them |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    padding: 10px;
    margin-bottom: 6px;
    background-color: #e2e8f0;
  }
  .invisible {
    visibility: hidden;
  }
</style>

<div class="row">Row 1</div>
<div class="row invisible">Row 2 is invisible, but its space stays</div>
<div class="row">Row 3</div>
```

## 7. Three Ways to Hide: A Comparison

| Method | Space kept? | Can be clicked? | Screen readers | Can be animated? |
| ------ | ----------- | --------------- | -------------- | ---------------- |
| `display: none` | No | No | Skipped | No |
| `visibility: hidden` | Yes | No | Skipped | Partly |
| `opacity: 0` | Yes | **Yes** | **Still read** | Yes |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .demo {
    display: flex;
    gap: 8px;
  }
  .demo div {
    flex: 1;
    padding: 12px;
    background-color: #bae6fd;
    text-align: center;
  }
  .d1 { display: none; }
  .d2 { visibility: hidden; }
  .d3 { opacity: 0; }
</style>

<div class="demo">
  <div>Visible</div>
  <div class="d1">display none</div>
  <div class="d2">visibility hidden</div>
  <div class="d3">opacity 0</div>
  <div>Visible</div>
</div>
```

Look at the gaps. The `display: none` box leaves no space. The other two leave an empty space.

## 8. Hiding Content for Screen Readers Only

Sometimes you want text to be hidden on screen but still read by screen readers, such as a label for an icon button. A common pattern is a "visually hidden" class.

```css
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
  border: 0;
}
```

Do not use `display: none` for this, because screen readers skip it.

## Common Mistakes

### Using overflow: hidden on a Box That Needs Its Content

```css
.card { height: 100px; overflow: hidden; }    /* longer text is lost */
.card { max-height: 100px; overflow: auto; }  /* the reader can scroll */
```

### Expecting visibility: hidden to Remove the Space

```css
.box { visibility: hidden; }   /* the empty space remains */
.box { display: none; }        /* the space is removed */
```

### Hiding Important Text with display: none

```css
.label { display: none; }    /* screen readers skip it */
```

### A Wide Table Breaking the Page

```css
table { min-width: 600px; }                       /* the page scrolls sideways */
.wrap { overflow-x: auto; } /* put the table inside this wrapper */
```

### Using opacity: 0 and Forgetting It Is Still Clickable

```css
.menu { opacity: 0; }                             /* the invisible menu can still be clicked */
.menu { opacity: 0; pointer-events: none; }
```

---

## Key Points

* `overflow` can be `visible`, `hidden`, `scroll`, `auto` or `clip`.
* `overflow-y: auto` is great for sidebars, chat boxes and long lists.
* Wrap wide tables in a box with `overflow-x: auto`.
* `scroll-snap-type` and `scroll-behavior: smooth` improve scroll areas.
* `overflow-wrap: anywhere` helps long words and links fit small boxes.
* `visibility: hidden` hides an element but **keeps its space**.
* `display: none` removes the element and its space. `opacity: 0` keeps both the space and the click area.
* Use a visually hidden class when text is only for screen readers.

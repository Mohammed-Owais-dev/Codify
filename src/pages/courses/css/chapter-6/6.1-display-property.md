# Chapter 6: Layout with Display and Position

## Section 1: The display Property

Every HTML element has a **display type**. This type decides how the element sits on the page: on its own line, next to other elements, or not at all. The `display` property lets you change it. In this lesson you will learn the main values and when to use them.

---

## 1. Block Elements

A **block** element starts on a new line and takes the full width of its parent. Examples are `div`, `p`, `h1` to `h6`, `ul`, `section` and `header`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .block {
    background-color: #bae6fd;
    border: 2px solid #0284c7;
    padding: 8px;
    margin-bottom: 8px;
  }
</style>

<div class="block">Block one</div>
<div class="block">Block two</div>
<p class="block">A paragraph is also a block</p>
```

Block elements accept `width`, `height`, `margin` and `padding` on all sides.

---

## 2. Inline Elements

An **inline** element stays inside the line of text. It is only as wide as its content. Examples are `span`, `a`, `strong`, `em` and `img` (images are a special kind of inline).

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .tag {
    background-color: #fde68a;
    border: 2px solid #d97706;
    padding: 4px 10px;
    margin: 20px;
    width: 300px;
    height: 100px;
  }
</style>

<p>This is a line with <span class="tag">an inline span</span> inside it.</p>
```

For inline elements:

* `width` and `height` are **ignored**.
* Left and right `margin` and `padding` work.
* Top and bottom `margin` has no effect, and top and bottom `padding` does not push other lines away.

---

## 3. inline-block

`inline-block` is a mix. The element sits **in the line** like inline, but you can set `width`, `height` and all margins like a block.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .chip {
    display: inline-block;
    width: 90px;
    height: 40px;
    line-height: 40px;
    text-align: center;
    margin: 6px;
    background-color: #bbf7d0;
    border: 2px solid #16a34a;
    border-radius: 8px;
  }
</style>

<span class="chip">One</span>
<span class="chip">Two</span>
<span class="chip">Three</span>
```

This is great for buttons, tags and small cards in a row.

---

## 4. Changing the Display Type

You can turn any element into another type.

| Value | Behavior |
| ----- | -------- |
| `block` | New line, full width, all sizes work |
| `inline` | In the text line, sizes are ignored |
| `inline-block` | In the line, but sizes work |
| `none` | The element is removed from the page |
| `flex` | A flexible row or column container (chapter 7) |
| `grid` | A two-dimensional grid container (chapter 7) |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  nav a {
    display: block;
    width: 200px;
    padding: 10px;
    margin-bottom: 4px;
    background-color: #1e293b;
    color: white;
    text-decoration: none;
  }
</style>

<nav>
  <a href="#">Home</a>
  <a href="#">Courses</a>
  <a href="#">Contact</a>
</nav>
```

Links are inline by default. With `display: block`, the whole area becomes clickable and each link goes on its own line.

---

## 5. display: none

`display: none` hides an element **completely**. It takes no space, as if it was not in the HTML.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    background-color: #e2e8f0;
    padding: 10px;
    margin-bottom: 6px;
  }
  .gone {
    display: none;
  }
</style>

<div class="row">Row 1</div>
<div class="row gone">Row 2 is hidden and takes no space</div>
<div class="row">Row 3</div>
```

Screen readers also skip it. You will compare it with `visibility: hidden` in lesson 6.5.

---

## 6. Lists as Horizontal Menus

A common job for `display` is to turn a vertical list into a horizontal menu.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .menu {
    list-style: none;
    margin: 0;
    padding: 0;
    background-color: #0f172a;
  }
  .menu li {
    display: inline-block;
  }
  .menu a {
    display: block;
    padding: 12px 18px;
    color: white;
    text-decoration: none;
  }
</style>

<ul class="menu">
  <li><a href="#">Home</a></li>
  <li><a href="#">About</a></li>
  <li><a href="#">Contact</a></li>
</ul>
```

Today, most menus use `display: flex`, but this method still appears in older code.

---

## 7. The Whitespace Gap

Inline-block elements have a small gap between them. It comes from the space or line break in your HTML code, which the browser treats as a space character.

```html
<style>
  .box {
    display: inline-block;
    width: 80px;
    height: 50px;
    background-color: #f97316;
  }
</style>

<div class="box"></div>
<div class="box"></div>
<div class="box"></div>
```

You can fix it by removing the whitespace between the tags, by setting `font-size: 0` on the parent, or (best) by using Flexbox, which has no such gap.

---

## 8. Block vs Inline: Quick Comparison

| Feature | Block | Inline | Inline-block |
| ------- | ----- | ------ | ------------ |
| Starts on a new line | Yes | No | No |
| Width fills the parent | Yes | No | No |
| `width` and `height` work | Yes | No | Yes |
| Top and bottom margin work | Yes | No | Yes |

## Common Mistakes

### Setting Width on an Inline Element

```css
span { width: 200px; }                          /* ignored */
span { display: inline-block; width: 200px; }   /* works */
```

### Confusing display: none with Invisible

```css
.hidden { display: none; }    /* removed from the layout, no space left */
```

### Forgetting That a Link Is Inline

```css
a { padding: 20px; }                        /* the clickable area may overlap other lines */
a { display: inline-block; padding: 20px; } /* a proper button shape */
```

### Surprised by the Gap Between inline-block Items

```css
/* spaces in the HTML create a small gap, use flexbox for rows */
```

---

## Key Points

* **Block** elements start on a new line and fill the width.
* **Inline** elements stay in the text line and ignore `width` and `height`.
* **inline-block** sits in the line but accepts width, height and margins.
* `display: none` removes an element from the page completely.
* You can change any element's display type with the `display` property.
* `display: flex` and `display: grid` create modern layouts (chapter 7).
* Inline-block items show a small gap from whitespace in the HTML.

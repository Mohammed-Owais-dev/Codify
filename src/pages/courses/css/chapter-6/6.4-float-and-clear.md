# Chapter 6: Layout with Display and Position

## Section 4: Float and Clear

Before Flexbox and Grid, developers used `float` to build layouts. Today, float has one main job: letting text **wrap around** an image or a box. You will still see float in older code, so it is important to understand it. In this lesson you will learn `float`, `clear` and how to fix the famous "collapsing parent" problem.

---

## 1. What Does float Do?

`float` moves an element to the **left** or **right** of its container. The following content (usually text) flows around it.

| Value | Meaning |
| ----- | ------- |
| `left` | Floats the element to the left |
| `right` | Floats the element to the right |
| `none` | No float (default) |

```html
<style>
  body {
    font-family: Arial, sans-serif;
    line-height: 1.6;
  }
  .pic {
    float: left;
    width: 90px;
    height: 90px;
    margin: 0 14px 6px 0;
    background-color: #38bdf8;
    border-radius: 8px;
  }
</style>

<div class="pic"></div>
<p>Text wraps around a floated box. The box moves to the left, and the paragraph flows along its right side and then under it. This is the classic use of float, like a picture in a magazine article.</p>
```

---

## 2. Floating to the Right

```html
<style>
  body {
    font-family: Arial, sans-serif;
    line-height: 1.6;
  }
  .quote {
    float: right;
    width: 140px;
    margin: 0 0 8px 14px;
    padding: 10px;
    background-color: #fef3c7;
    border-left: 4px solid #f59e0b;
    font-style: italic;
  }
</style>

<div class="quote">Float can also go to the right side.</div>
<p>This paragraph keeps its place on the left, and the quote box sits on the right. The text flows around the box, and the margin on the box keeps a clear gap between the box and the words.</p>
```

---

## 3. How Floats Change the Layout

When an element floats:

* It is taken out of normal flow, but only partly. The **text** still wraps around it.
* It becomes a **block** in terms of width and height, even if it was inline.
* Block boxes that come after it **ignore it** and slide underneath it. Only the text inside them wraps.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .float {
    float: left;
    width: 100px;
    height: 80px;
    background-color: #f97316;
    color: white;
    padding: 6px;
  }
  .next {
    background-color: #e2e8f0;
    border: 2px solid #64748b;
    padding: 6px;
  }
</style>

<div class="float">Floated</div>
<div class="next">The grey box starts under the floated box, but its text wraps around it.</div>
```

---

## 4. The clear Property

`clear` tells an element not to sit next to a float. It moves **below** the floated element.

| Value | Meaning |
| ----- | ------- |
| `left` | Move below any left float |
| `right` | Move below any right float |
| `both` | Move below any float |
| `none` | Default |

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .float {
    float: left;
    width: 100px;
    height: 80px;
    background-color: #0ea5e9;
    color: white;
    padding: 6px;
    margin-right: 10px;
  }
  .footer {
    clear: both;
    background-color: #1e293b;
    color: white;
    padding: 10px;
    margin-top: 10px;
  }
</style>

<div class="float">Floated</div>
<p>Some text next to the floated box.</p>
<div class="footer">I cleared the float, so I sit below it</div>
```

## 5. The Collapsing Parent Problem

A parent does not include its floated children in its height. If all children are floated, the parent collapses to zero height.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .parent {
    border: 3px solid #dc2626;
    background-color: #fef2f2;
  }
  .child {
    float: left;
    width: 90px;
    height: 70px;
    margin: 6px;
    background-color: #f87171;
  }
</style>

<div class="parent">
  <div class="child"></div>
  <div class="child"></div>
</div>
<p>The red border is squashed above, because the parent has no height.</p>
```

---

## 6. Clearfix: The Fix

The classic fix is a **clearfix**. It adds an invisible element after the children that clears the floats, so the parent grows around them.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .parent {
    border: 3px solid #16a34a;
    background-color: #f0fdf4;
  }
  .parent::after {
    content: "";
    display: block;
    clear: both;
  }
  .child {
    float: left;
    width: 90px;
    height: 70px;
    margin: 6px;
    background-color: #4ade80;
  }
</style>

<div class="parent">
  <div class="child"></div>
  <div class="child"></div>
</div>
<p>Now the parent wraps around both floated boxes.</p>
```

You can also use `overflow: auto` or `display: flow-root` on the parent. `display: flow-root` is the modern and cleanest way.

```css
.parent { display: flow-root; }
```

## 7. Float for Layout: The Old Way

Floats were used to make columns.

```html
<style>
  * {
    box-sizing: border-box;
  }
  body {
    font-family: Arial, sans-serif;
  }
  .row {
    display: flow-root;
  }
  .col {
    float: left;
    width: 50%;
    padding: 14px;
    color: white;
  }
  .a { background-color: #0ea5e9; }
  .b { background-color: #7c3aed; }
</style>

<div class="row">
  <div class="col a">Column A</div>
  <div class="col b">Column B</div>
</div>
```

It works, but Flexbox and Grid are much easier and more powerful for columns. Use floats only for wrapping text around images.

## 8. shape-outside: Fancy Wrapping

With `shape-outside`, text can wrap around a **shape** instead of a rectangle.

```html
<style>
  body {
    font-family: Arial, sans-serif;
    line-height: 1.6;
  }
  .circle {
    float: left;
    width: 110px;
    height: 110px;
    margin: 0 14px 6px 0;
    border-radius: 50%;
    background-color: #f43f5e;
    shape-outside: circle(50%);
  }
</style>

<div class="circle"></div>
<p>The text bends around the round shape instead of keeping a straight edge. This looks nice in magazine-style articles, where a round picture sits next to the first paragraph of the story.</p>
```

## Common Mistakes

### Forgetting to Clear the Float

```css
.footer { }                  /* the footer slides up next to the float */
.footer { clear: both; }
```

### A Collapsed Parent

```css
.row { }                         /* height is 0 when all children float */
.row { display: flow-root; }     /* the parent contains its floats */
```

### Using Float for Page Layout in New Projects

```css
.col { float: left; width: 33%; }   /* old method */
.row { display: flex; }             /* modern method */
```

### Floating Without a Width

```css  
.box { float: left; }    /* shrinks to fit its content */
.box { float: left; width: 200px; }
```

---

## Key Points

* `float: left` or `float: right` moves an element aside and lets text wrap around it.
* Floated elements are partly out of normal flow.
* `clear` moves an element below floats: `left`, `right` or `both`.
* A parent with only floated children **collapses** to zero height.
* Fix it with `display: flow-root`, `overflow: auto` or a clearfix with `::after`.
* `shape-outside` lets text wrap around round or custom shapes.
* Use float only to wrap text around images. Use Flexbox or Grid for layouts.

# Chapter 6: Layout with Display and Position

## Section 2: Normal Flow and Positioning

Normal flow is how a browser places elements by default. The `position` property lets you break out of that flow and place an element exactly where you want. In this lesson you will learn the five position values and how they work together.

---

## 1. Normal Flow

In normal flow, the browser places block elements from top to bottom, and inline elements from left to right inside a line. This is `position: static`, the default for every element.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .item {
    background-color: #bae6fd;
    border: 2px solid #0284c7;
    padding: 10px;
    margin-bottom: 6px;
  }
</style>

<div class="item">First</div>
<div class="item">Second</div>
<div class="item">Third</div>
```

A **static** element ignores the `top`, `right`, `bottom`, `left` and `z-index` properties.

---

## 2. The Offset Properties

The properties `top`, `right`, `bottom` and `left` move a positioned element. They only work when the `position` is **not** `static`.

| Property | Moves the element from... |
| -------- | ------------------------- |
| `top` | the top edge |
| `right` | the right edge |
| `bottom` | the bottom edge |
| `left` | the left edge |

---

## 3. position: relative

A **relative** element stays in normal flow, but you can move it **from its original place**. The space it used to take is still kept.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .box {
    width: 140px;
    padding: 10px;
    margin-bottom: 8px;
    background-color: #fde68a;
    border: 2px solid #d97706;
  }
  .moved {
    position: relative;
    top: 12px;
    left: 40px;
    background-color: #fb923c;
  }
</style>

<div class="box">Box 1</div>
<div class="box moved">Box 2 (moved)</div>
<div class="box">Box 3</div>
```

Box 2 moves 12px down and 40px right, but Box 3 does not move up to fill the gap. The most common use of `relative` is to be a **reference point** for absolute children.

---

## 4. position: absolute

An **absolute** element is taken **out of normal flow**. Other elements act as if it is not there. It is placed using `top`, `right`, `bottom` and `left` compared to its **nearest positioned ancestor**. If there is none, it uses the page itself.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .parent {
    position: relative;
    width: 280px;
    height: 120px;
    background-color: #e2e8f0;
    border: 2px solid #64748b;
  }
  .badge {
    position: absolute;
    top: 8px;
    right: 8px;
    background-color: #ef4444;
    color: white;
    padding: 4px 10px;
    border-radius: 999px;
    font-size: 13px;
  }
</style>

<div class="parent">
  A card with a badge
  <span class="badge">New</span>
</div>
```

The badge is placed 8px from the top-right corner of `.parent`, because `.parent` has `position: relative`. Remember this rule:

**Relative parent + absolute child = a child placed inside its parent.**

---

## 5. Centering with Absolute

You can center an absolute element with `top: 50%`, `left: 50%` and a `transform` to pull it back by half of its own size.

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
  .stage {
    position: relative;
    width: 280px;
    height: 140px;
    background-color: #1e293b;
  }
  .center {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
    background-color: #38bdf8;
    padding: 10px 18px;
    border-radius: 8px;
  }
</style>

<div class="stage">
  <div class="center">Centered</div>
</div>
```

---

## 6. position: fixed

A **fixed** element is placed relative to the **viewport** (the browser window). It stays in the same place even when the page scrolls. It is also out of normal flow.

```html
<style>
  body {
    font-family: Arial, sans-serif;
    margin: 0;
    height: 600px;
    background-color: #f8fafc;
  }
  .top-bar {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    padding: 12px;
    background-color: #0f172a;
    color: white;
  }
  .content {
    padding: 70px 12px 12px;
  }
</style>

<div class="top-bar">Fixed header</div>
<div class="content">Scroll the page. The header stays at the top.</div>
```

Fixed elements are used for sticky headers, chat buttons and cookie banners. Because a fixed element leaves the flow, give the page some space (like `padding-top`) so it does not cover the content.

---

## 7. position: sticky

A **sticky** element acts like `relative` until you scroll to a set point. Then it sticks, like `fixed`. You need to set at least one offset, such as `top: 0`.

```html
<style>
  body {
    font-family: Arial, sans-serif;
    margin: 0;
  }
  .intro {
    height: 120px;
    background-color: #e0f2fe;
    padding: 10px;
  }
  .sticky {
    position: sticky;
    top: 0;
    background-color: #f97316;
    color: white;
    padding: 12px;
  }
  .more {
    height: 500px;
    padding: 10px;
    background-color: #f8fafc;
  }
</style>

<div class="intro">Scroll down inside the preview</div>
<div class="sticky">I stick to the top</div>
<div class="more">Long content</div>
```

A sticky element stays inside its parent. When the parent scrolls out of view, the sticky element leaves with it.

---

## 8. Summary of Position Values

| Value | In normal flow? | Placed relative to | Common use |
| ----- | --------------- | ------------------ | ---------- |
| `static` | Yes | Normal flow | Default |
| `relative` | Yes (keeps its space) | Its own original place | Reference for children, small shifts |
| `absolute` | No | Nearest positioned ancestor | Badges, icons, overlays |
| `fixed` | No | The viewport | Fixed headers, floating buttons |
| `sticky` | Yes, until it sticks | Its scroll container | Sticky headings and menus |

## Real-World Example 🌍

A product card with an absolute badge and a sticky title bar:

```html
<style>

    box-sizing: border-box;
  }
  body {
    margin: 0;
    padding: 16px;
    font-family: Arial, sans-serif;

<div class="product">

```

## Common Mistakes

### Using Offsets on a Static Element

```text
.box { top: 20px; left: 20px; }                         /* no effect */
.box { position: relative; top: 20px; left: 20px; }     /* works */
```

### Forgetting the Relative Parent

```text
.parent { }                          /* absolute child jumps to the page corner */
.parent { position: relative; }      /* the child stays inside the parent */
```

### Content Hidden Behind a Fixed Header

```text
.header { position: fixed; top: 0; }   /* covers the first lines of the page */
body { padding-top: 60px; }            /* make room */
```

### Sticky Without an Offset

```text
.nav { position: sticky; }              /* never sticks */
.nav { position: sticky; top: 0; }      /* works */
```

### Using Position for a Whole Layout

```text
/* Absolute positioning for every box makes pages hard to maintain.
   Use Flexbox and Grid for layouts. */
```

---

## Key Points

* Normal flow (`position: static`) is the default.
* `top`, `right`, `bottom` and `left` work only on positioned elements.
* `relative` shifts an element from its own place and keeps its space.
* `absolute` removes the element from the flow and places it by its nearest positioned ancestor.
* A parent with `position: relative` is the usual reference for absolute children.
* `fixed` places an element relative to the viewport, and it does not scroll.
* `sticky` scrolls normally, then sticks at an offset such as `top: 0`.
* Use positioning for small things like badges and headers, and use Flexbox or Grid for page layouts.
